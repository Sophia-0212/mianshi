# Go 高频 Top 10 面试题

## 1. Go 语言有什么特点？

Go 是静态类型、编译型语言，强调简洁、并发和工程效率。

- 编译为本地机器码，启动快、部署简单。
- 通过 goroutine 和 channel 支持并发。
- 自带 GC、格式化工具、测试工具和竞态检测器。
- 没有传统类继承，使用结构体、接口和组合。

## 2. `slice` 和数组有什么区别？

- 数组长度是类型的一部分，值语义，长度固定。
- Slice 是对底层数组的描述符，包含指针、长度和容量，长度可变。
- 多个 Slice 可能共享同一底层数组，修改元素可能互相影响。
- `append` 容量不足时会分配新数组，原 Slice 与新 Slice 可能不再共享。

```go
s := make([]int, 0, 2)
s = append(s, 1, 2)
```

## 3. `map` 的特点和并发问题是什么？

Map 是无序的 Key-Value 结构，读不存在的 Key 返回 Value 类型零值；可通过第二个返回值判断是否存在：

```go
value, ok := data[key]
```

Map 非线程安全，并发读写可能触发运行时错误。并发场景使用 `sync.RWMutex` 保护，或使用 `sync.Map`；复合操作仍需保证整体原子性。

## 4. Go 的接口是如何实现的？

Go 接口采用隐式实现：类型只要实现接口要求的全部方法，就满足该接口，无需显式声明。

接口适合定义行为和解耦依赖。接口值概念上包含动态类型和动态值；接口不为 `nil`，不代表内部指针一定不为 `nil`，要注意 typed nil 问题。

## 5. 指针、值接收者和指针接收者有什么区别？

- 值接收者操作对象副本，不能修改原对象。
- 指针接收者操作原对象，可修改字段，也避免复制大对象。
- 方法集不同：`T` 的方法集包含值接收者方法，`*T` 还包含指针接收者方法。

如果方法需要修改状态或结构体较大，通常使用指针接收者。

## 6. goroutine 和 channel 如何实现并发？

- Goroutine 是由 Go 运行时调度的轻量级执行单元。
- Channel 用于 goroutine 间通信和同步。
- 无缓冲 Channel 强调发送与接收同步。
- 有缓冲 Channel 可暂存指定数量的数据。
- 关闭 Channel 后不能发送；接收可继续读取剩余数据。

```go
go process()
ch := make(chan int, 1)
ch <- 1
value := <-ch
```

并发代码必须设计退出机制，避免 goroutine 泄漏。

## 7. `mutex`、`RWMutex` 和 `sync.Once` 怎么选？

- `sync.Mutex`：互斥访问临界区。
- `sync.RWMutex`：读多写少时允许多个读者并发。
- `sync.Once`：保证初始化逻辑只执行一次。
- `atomic`：适合简单数值或指针的原子操作。

锁的粒度要合理，持锁期间不要执行慢 I/O；可用 `go test -race` 检测数据竞争。

## 8. Go 的 `defer`、`panic`、`recover` 是什么？

- `defer`：函数返回前执行，常用于释放资源；多个 `defer` 按后进先出执行。
- `panic`：触发异常式流程，逐层退出并执行 defer。
- `recover`：只能在 defer 调用中捕获当前 goroutine 的 panic。

普通业务错误优先使用 `error` 返回，不要用 panic 替代正常错误处理。

## 9. Go 的错误处理为什么使用 `error`？

Go 通常显式返回错误：

```go
result, err := query()
if err != nil {
    return err
}
```

错误应补充上下文并保留原因：

```go
return fmt.Errorf("query customer: %w", err)
```

上层可使用 `errors.Is` 判断原因、`errors.As` 提取具体错误类型。不要无条件丢弃错误。

## 10. Go 的 GC 和逃逸分析是什么？

Go 使用并发、三色标记为核心的垃圾回收，自动回收不可达对象。GC 目标是降低停顿，但过多短生命周期对象和大对象仍会增加 GC 压力。

逃逸分析由编译器判断变量是否需要放到堆上：如果对象生命周期超出当前栈帧，或被外部引用，可能发生堆逃逸。可通过以下命令查看：

```bash
go build -gcflags='-m' .
```

优化重点是减少不必要分配、合理复用对象，并以基准测试和性能剖析为依据。

## 一分钟总结

Go 面试重点是 slice、map、接口、指针、goroutine、channel、锁、错误处理和 GC。回答时说明数据结构或运行机制，再补充并发安全、生命周期和适用边界；遇到性能问题，结合基准测试、竞态检测和 pprof 分析，避免只背结论。
