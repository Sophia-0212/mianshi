# 0098. 验证二叉搜索树

**题目描述**

给定一个二叉树的根节点 `root`，判断其是否是一个有效的二叉搜索树（BST）。

有效的二叉搜索树定义如下：
- 节点的左子树只包含**小于**当前节点的数。
- 节点的右子树只包含**大于**当前节点的数。
- 所有左子树和右子树自身必须也是二叉搜索树。

```
示例：
输入: root = [5,1,4,null,null,3,6]
输出: false
解释: 根节点的值是 5，但右子节点的值是 4，5 > 4 违反了 BST 性质。
```

## 思路

- 递归上下界：每个节点必须位于祖先限定的开区间；左子树更新上界，右子树更新下界。
- 中序遍历：用前驱值检查整个序列严格递增，不能只比较直接父子节点。

均为时间 O(n)，空间 O(h)，h 为树高。

func isValidBST(root *TreeNode) bool {
    var helper func(node *TreeNode, lower, upper int) bool
    helper = func(node *TreeNode, lower, upper int) bool {

    }

}

        if node == nil {
            return true
        }

            return false // 左子树已经不合法

            return false // 违反严格递增

class Solution {
public:
    // 解法一：递归传递上下界
    // 方法：isValidBST；按题目要求处理输入并返回结果，核心算法见方法体。
    bool isValidBST(TreeNode* root) {
        return helper(root, LONG_MIN, LONG_MAX);
    }

private:
    // 方法：helper；按题目要求处理输入并返回结果，核心算法见方法体。
    bool helper(TreeNode* root, long lower, long upper) {
        if (root == nullptr) return true; // 空树/空子树天然合法
        if (root->val <= lower || root->val >= upper) {
            return false; // 超出祖先节点约束的合法区间
        }
        // 左子树上界收窄为当前节点值，右子树下界收窄为当前节点值
        return helper(root->left, lower, root->val) &&
               helper(root->right, root->val, upper);
    }

public:
    // 解法二：中序遍历，判断是否严格递增
    // 方法：isValidBSTInorder；按题目要求处理输入并返回结果，核心算法见方法体。
    bool isValidBSTInorder(TreeNode* root) {
        TreeNode* pre = nullptr; // 记录中序遍历中上一个访问的节点
        return inorderCheck(root, pre);
    }

private:
    // 方法：inorderCheck；按题目要求处理输入并返回结果，核心算法见方法体。
    bool inorderCheck(TreeNode* root, TreeNode*& pre) {
        if (root == nullptr) return true;
        if (!inorderCheck(root->left, pre)) return false; // 先检查左子树
        if (pre != nullptr && pre->val >= root->val) {
            return false; // 当前节点不大于前一个节点，违反严格递增
        }
        pre = root; // 更新 pre 为当前节点
        return inorderCheck(root->right, pre); // 继续检查右子树
    }
};

        if (root->val <= lower || root->val >= upper) {
            return false; // 超出祖先节点约束的合法区间
        }
        // 左子树上界收窄为当前节点值，右子树下界收窄为当前节点值
        return helper(root->left, lower, root->val) &&
               helper(root->right, root->val, upper);
    }

// 解法二：中序遍历，判断是否严格递增
    // 方法：isValidBSTInorder；按题目要求处理输入并返回结果，核心算法见方法体。
    bool isValidBSTInorder(TreeNode* root) {
        TreeNode* pre = nullptr; // 记录中序遍历中上一个访问的节点
        return inorderCheck(root, pre);
    }

// 方法：inorderCheck；按题目要求处理输入并返回结果，核心算法见方法体。
    bool inorderCheck(TreeNode* root, TreeNode*& pre) {
        if (root == nullptr) return true;
        if (!inorderCheck(root->left, pre)) return false; // 先检查左子树
        if (pre != nullptr && pre->val >= root->val) {
            return false; // 当前节点不大于前一个节点，违反严格递增
        }
        pre = root; // 更新 pre 为当前节点
        return inorderCheck(root->right, pre); // 继续检查右子树
    }

}

int main() {
    // 用例 1：输入 ({'tree': [2, 1, 3]},)；期望 True。

## 总结

- 最容易踩的坑我再强调一下：只比较父子节点的大小关系是不够的，必须保证整个左子树都小于根节点、整个右子树都大于根节点，隔代的节点也得满足这个约束，不能漏。
- 解法一，也就是上下界传递，直接对应题目的定义，思路很直白；解法二，中序遍历判断严格递增，更优雅一些，是这道题公认的最佳解法，顺带还能帮你复习一下"BST 中序遍历结果是递增的"这个核心性质。
- 中序遍历判断递增的时候，有个边界情况你得注意，就是数值相等的问题——BST 的定义里左子树是严格小于、右子树是严格大于，所以中序遍历出来必须是严格递增，相等也要判成不合法。
- 上下界这种写法呢，要注意用能表示"负无穷/正无穷"的类型，比如 `long` 或者 `float('-inf')`，不然节点值刚好卡在 `int` 边界值上的时候，判断就会出错。
