# 后端面试高频力扣中等及困难题

共 43 道 LeetCode 题，另有 2 道页面置换自编模拟题。每题提供 Python、Go、C++ 普通函数、运行入口和正常/边界/空输入或异常测试。

## 缓存算法练习顺序

[循环队列](./0622.设计循环队列.md) → [LRU](./0146.LRU缓存.md) → [LFU](./0460.LFU缓存.md) → [FIFO 路由器](./3508.设计路由器.md)。

[OPT](./自编.OPT页面置换.md) 与 [Clock](./自编.Clock页面置换.md) 是自编模拟，没有力扣题号。

## 使用方式

- 新补全题以 `solve` 为普通函数入口，链表/树辅助函数操作真实节点。设计题用操作序列承载状态，并在题目中说明编码。
- 每种语言的完整代码块可保存为 `main.py`、`main.go`、`main.cpp` 独立运行。
- 输入约定优先遵循原题；零容量、空输入等扩展行为单独说明，不代表原题一定允许。
- Go 非法输入示例用 `panic`，测试入口用 `recover` 验证；工程代码可改为显式返回 `error`。
- 原有题解保留 LeetCode 写法，面试练习使用“普通函数写法”段落。
