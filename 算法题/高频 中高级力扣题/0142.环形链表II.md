# 0142. 环形链表 II

**题目描述**

给定一个链表的头节点 `head`，判断链表中是否存在环。如果存在，返回环的入口节点；如果不存在，返回 `null`。不允许通过修改链表本身来判断（比如给节点打标记）。

```
示例：
输入: head = [3,2,0,-4]，其中最后一个节点 -4 的 next 指向值为 2 的节点（形成环）
输出: 返回值为 2 的节点
解释: 链表中存在环，且环的入口节点是索引为 1（值为 2）的节点
```

## 思路

Floyd：快指针走两步，慢指针走一步。相遇后，一个指针回到头部，两者都每次走一步，再次相遇处即环入口；快指针到空则无环。

原因：头到入口的距离与相遇点到入口的距离模环长同余。

时间 O(n)，空间 O(1)。

```python
class ListNode:
    # 方法：__init__；按题目要求处理输入并返回结果，核心算法见方法体。
    def __init__(self, val=0, next=None):
        self.val = val
        self.next = next


class Solution:
    # 方法：detectCycle；按题目要求处理输入并返回结果，核心算法见方法体。
    def detectCycle(self, head: ListNode) -> ListNode:
        slow = fast = head

        # 阶段一：快慢指针判断是否有环
        while fast is not None and fast.next is not None:
            slow = slow.next
            fast = fast.next.next
            if slow is fast:  # 相遇，说明有环
                # 阶段二：p1 从头出发，p2 从相遇点出发，同步走，相遇即环入口
                p1, p2 = head, slow
                while p1 is not p2:
                    p1 = p1.next
                    p2 = p2.next
                return p1  # 环入口
        return None  # 无环
```

```cpp
class Solution {
public:
    ListNode* detectCycle(ListNode* head) {
        ListNode* slow = head;
        ListNode* fast = head;

        // 阶段一：快慢指针判断是否有环，slow 每次1步，fast 每次2步
        while (fast != nullptr && fast->next != nullptr) {
            slow = slow->next;
            fast = fast->next->next;
            if (slow == fast) {  // 相遇，说明有环，跳出进入阶段二
                // 阶段二：p1 从头节点出发，p2 从相遇点出发，同步走，相遇处即环入口
                ListNode* p1 = head;
                ListNode* p2 = slow;  // slow 此刻就是相遇点
                while (p1 != p2) {
                    p1 = p1->next;
                    p2 = p2->next;
                }
                return p1;  // p1 == p2，即为环入口
            }
        }
        return nullptr;  // fast 到达链表末尾，说明无环
    }
};
```

## 总结

- 判环就用快慢指针（速度比 2:1），能相遇就说明有环，原理是环内两指针的相对距离每走一步就缩小 1，必然会收敛到 0；快指针先到达 `null` 那就是无环。
- 找入口的核心，就是靠数学推导出来的这个等式 `a = c + (k-1)(b+c)`：头节点到环入口的距离 `a`，等于相遇点到环入口的距离 `c`（再加上若干整圈，反正不影响到达同一个目的地）。根据这个结论，让一个指针从头出发、另一个从相遇点出发，同步往前走，第二次相遇的地方就是环入口。
- 循环条件 `fast != nullptr && fast->next != nullptr` 这两个条件缺一不可：既要防止 `fast` 本身为空的时候还去访问 `fast->next` 导致崩溃，也要防止 `fast->next` 为空的时候访问 `fast->next->next` 崩溃。
- 这道题其实是快慢指针技巧的一个高阶应用，跟"删除倒数第N个节点"里"固定间距"的用法不一样，这里用的是"速度差"而不是"步数差"；同时它也是"链表相交"问题的一个变体思路来源——有些解法会把环入口问题转化成链表相交问题来统一处理。
