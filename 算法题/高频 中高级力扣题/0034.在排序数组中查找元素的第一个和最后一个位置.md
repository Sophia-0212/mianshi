# 34. 在排序数组中查找元素的第一个和最后一个位置

**题目描述**

给定一个按照升序排列的整数数组 `nums`，和一个目标值 `target`。请找出给定目标值在数组中的开始位置和结束位置。如果数组中不存在目标值 `target`，返回 `[-1, -1]`。

```
示例：
输入: nums = [5,7,7,8,8,10], target = 8
输出: [3,4]
解释: 8在数组中的下标3和4处，分别是第一个和最后一个位置

输入: nums = [5,7,7,8,8,10], target = 6
输出: [-1,-1]
解释: 数组中不存在6
```

## 思路

两次二分分别找左右边界：命中时记录下标，找左边界继续向左，找右边界继续向右。未命中返回 `[-1,-1]`。也可用 `bisect_left`、`bisect_right-1` 求边界。

时间 O(log n)，空间 O(1)。



## Python

### LeetCode 写法与原有示例

标准库一行解（`bisect_left` 找第一个 `>= target` 的位置，`bisect_right` 找第一个 `> target` 的位置，两者结合即可确定边界，这正是二分查找左右边界思路的库函数实现）：

```python
from bisect import bisect_left, bisect_right

# 依赖说明：Python 标准库 bisect：在有序列表中进行二分查找或插入。；len：Python 内置函数：返回容器中元素的数量。

class Solution:
    # 方法：searchRange；按题目要求处理输入并返回结果，核心算法见方法体。
    def searchRange(self, nums: list[int], target: int) -> list[int]:
        left = bisect_left(nums, target)   # 第一个>=target的位置
        if left == len(nums) or nums[left] != target:
            return [-1, -1]  # 该位置不存在或不等于target，说明target不存在
        right = bisect_right(nums, target) - 1  # 第一个>target的位置再减1，即最后一个等于target的位置
        return [left, right]
```


手写实现（面试考察点，两次独立二分查找，分别处理左右边界的收缩差异）：

```python
# 依赖说明：len：Python 内置函数：返回容器中元素的数量。

class Solution:
    # 方法：searchRange；按题目要求处理输入并返回结果，核心算法见方法体。
    def searchRange(self, nums: list[int], target: int) -> list[int]:
        # 方法：find_left_border；按题目要求处理输入并返回结果，核心算法见方法体。
        def find_left_border() -> int:
            left, right = 0, len(nums) - 1
            result = -1
            while left <= right:
                mid = left + (right - left) // 2
                if nums[mid] == target:
                    result = mid       # 记录候选答案
                    right = mid - 1    # 命中后继续往左找更小下标
                elif nums[mid] < target:
                    left = mid + 1
                else:
                    right = mid - 1
            return result

        # 方法：find_right_border；按题目要求处理输入并返回结果，核心算法见方法体。
        def find_right_border() -> int:
            left, right = 0, len(nums) - 1
            result = -1
            while left <= right:
                mid = left + (right - left) // 2
                if nums[mid] == target:
                    result = mid       # 记录候选答案
                    left = mid + 1     # 命中后继续往右找更大下标
                elif nums[mid] < target:
                    left = mid + 1
                else:
                    right = mid - 1
            return result

        left_border = find_left_border()
        if left_border == -1:
            return [-1, -1]  # target不存在
        right_border = find_right_border()
        return [left_border, right_border]
```

## 总结

- 这题其实是在 0704 二分查找那套"左闭右闭区间、`left <= right` 循环条件"的基础上做了个变体：命中 target 之后不能立刻返回，而是要先记下候选答案，然后继续朝那个方向收缩，一直收缩到区间空了为止，这样才能保证你找到的是真正的边界，而不是随便命中的某一个位置。
- 找左边界跟找右边界，说白了唯一的差别就是命中之后往哪个方向收缩——左边界是收右指针，右边界是收左指针。把这一个差异想明白了，两种边界查找的写法就都掌握了，完全不需要死记硬背两套代码。
- 这里有个挺好的记忆点，就是跟 `bisect_left`/`bisect_right` 的对应关系：`bisect_left` 本质上就是找左边界的思路，`bisect_right - 1` 就是找右边界的思路，把库函数背后的原理搞懂了，面试的时候手写版本也能很快写出来。
- 还有个容易踩坑的地方，就是判断 target 到底存不存在的时机——一定要先确认左边界查到了结果（不是 -1），才有必要再去查右边界；如果左边界压根就没找到，那说明数组里根本没有这个 target，这时候第二次二分查找就不用再做了。
