# 300. 最长上升子序列

**题目描述**

给定一个整数数组 `nums`，找到其中最长严格递增子序列的长度。

子序列不要求连续，只要求在原数组中保持相对顺序即可。

```
示例：
输入: nums = [10,9,2,5,3,7,101,18]
输出: 4
解释: 最长的上升子序列是 [2,3,7,101]，长度为 4
```

要求：数组长度不超过 2500，元素可以重复但子序列要求严格递增（相等不算递增）。

## 思路

- DP：`dp[i]` 为以 `i` 结尾的最长递增子序列长度，初值 1。正序枚举 `i`，对 `j<i && nums[j]<nums[i]` 更新 `dp[i]=max(dp[i],dp[j]+1)`，取全局最大。时间 O(n²)，空间 O(n)。
- 贪心＋二分：`tails[k]` 为长度 `k+1` 的最小结尾值；用当前值替换首个大于等于它的位置，无则追加。答案为 `tails` 长度。时间 O(n log n)，空间 O(n)。

```python
# 依赖说明：len：Python 内置函数：返回容器中元素的数量。；range：Python 内置函数：生成按步长遍历的整数序列。；max：Python 内置函数：返回最大值。

class Solution:
    # 方法：lengthOfLIS；按题目要求处理输入并返回结果，核心算法见方法体。
    def lengthOfLIS(self, nums: list[int]) -> int:
        n = len(nums)
        if n == 0:
            return 0
        dp = [1] * n  # dp[i] 初始化为 1，表示只包含自身
        result = 1
        for i in range(1, n):          # 外层遍历结尾位置 i
            for j in range(i):          # 内层枚举前面所有位置 j
                if nums[j] < nums[i]:   # 严格递增才能接续
                    dp[i] = max(dp[i], dp[j] + 1)  # 取最大接续长度
            result = max(result, dp[i])  # 更新全局最大值
        return result
```

```go
// 方法：lengthOfLIS；按题目要求处理输入并返回结果，核心算法见方法体。
func lengthOfLIS(nums []int) int {
    n := len(nums)
    if n == 0 {
        return 0
    }
    dp := make([]int, n)
    for i := range dp {
        dp[i] = 1 // dp[i] 初始化为 1，表示只包含自身
    }
    result := 1
    for i := 1; i < n; i++ { // 外层遍历结尾位置 i
        for j := 0; j < i; j++ { // 内层枚举前面所有位置 j
            if nums[j] < nums[i] { // 严格递增才能接续
                if dp[j]+1 > dp[i] {
                    dp[i] = dp[j] + 1 // 更新以 i 结尾的最长长度
                }
            }
        }
        if dp[i] > result {
            result = dp[i] // 更新全局最大值
        }
    }
    return result
}
```

// 依赖说明：vector：C++ STL 动态数组。

class Solution {
public:
    // 方法：lengthOfLIS；按题目要求处理输入并返回结果，核心算法见方法体。
    int lengthOfLIS(vector<int>& nums) {
        int n = nums.size();
        if (n == 0) return 0;
        vector<int> dp(n, 1);  // dp[i] 初始化为 1，表示只包含自身
        int result = 1;
        for (int i = 1; i < n; i++) {          // i 从 1 开始，dp[0] 已初始化

                    dp[i] = max(dp[i], dp[j] + 1);  // 取所有可能接续中的最大值
                }
            }
            result = max(result, dp[i]);       // 全局答案取 dp 数组最大值
        }
        return result;
    }
};```

## 总结

- `dp[i]` 定义为"以 `nums[i]` 结尾的最长上升子序列长度"，是子序列 DP 里最经典的定义方式，后续很多题目都沿用这个思路。
- 递推公式需要枚举所有 `j < i` 找可接续的位置，本质是在"以每个更早元素结尾的子序列"中挑最优的来延伸，这是 O(n²) 的根源。
- 最终答案是 `dp` 数组的最大值而不是 `dp[n-1]`，因为最优解不一定以最后一个元素结尾。
- O(n log n) 的贪心+二分解法通过维护"每个长度对应的最小结尾值"，把内层枚举替换为二分查找，是这道题从入门到进阶的经典优化路径。
