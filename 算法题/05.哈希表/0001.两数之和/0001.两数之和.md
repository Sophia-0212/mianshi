# 0001. 两数之和

**题目描述**

给定一个整数数组 `nums` 和一个目标值 `target`，在该数组中找出和为目标值的两个整数，返回它们的数组下标。假设每种输入只对应一个答案，且同一个元素不能重复使用。

```
示例 1：
输入: nums = [2,7,11,15], target = 9
输出: [0,1]
解释: nums[0] + nums[1] == 9，返回 [0, 1]

示例 2：
输入: nums = [3,2,4], target = 6
输出: [1,2]
```

## 思路

- 哈希表：记录已访问的“值→下标”。先查 `target-nums[i]`，命中即返回两个下标，否则存入当前值，避免重复使用同一元素。平均时间 O(n)，空间 O(n)。
- 暴力：枚举下标不同的两数。时间 O(n²)，空间 O(1)。

# 依赖说明：enumerate：Python 内置函数：遍历序列时同时得到下标和值。

class Solution:
    # 方法：twoSum；按题目要求处理输入并返回结果，核心算法见方法体。
    def twoSum(self, nums: list[int], target: int) -> list[int]:
        value_to_index = {}  # 记录 值->下标 的映射
        for i, num in enumerate(nums):
            complement = target - num  # 计算还需要的另一半
            if complement in value_to_index:  # 之前遍历过的元素中存在 complement
                return [value_to_index[complement], i]  # 返回两个下标
            value_to_index[num] = i  # 当前元素存入 map，供后续查找
        return []  # 题目保证有解，正常不会执行到这里```

    valueToIndex := make(map[int]int) // 记录 值->下标 的映射

## C++

### LeetCode 写法与原有示例

```cpp
class Solution {
public:
    // 方法：twoSum；按题目要求处理输入并返回结果，核心算法见方法体。
    vector<int> twoSum(vector<int>& nums, int target) {
        unordered_map<int, int> valueToIndex;  // 记录 值->下标 的映射
        for (int i = 0; i < nums.size(); i++) {
            int complement = target - nums[i];  // 计算还需要的另一半
            auto it = valueToIndex.find(complement);
            if (it != valueToIndex.end()) {  // 之前遍历过的元素中存在 complement
                return {it->second, i};  // 返回两个下标
            }
            valueToIndex[nums[i]] = i;  // 当前元素存入 map，供后续查找
        }
        return {};  // 题目保证有解，正常不会执行到这里
    }
};
```

## 总结

- 说白了，只要你需要"值 -> 下标"这种键值映射关系，就必须用 `map`，`set` 是搞不定的，因为它只能判断存在性，取不出下标来。
- "边遍历边查找边存储"是这道题从 O(n²) 优化到 O(n) 的关键所在：用一次遍历就同时完成了查询和更新，而不是先建好表再查两遍。
- 先查询 `complement`，再把当前元素存进 map，这个顺序很重要，它保证了不会出现"用自己和自己匹配"这种错误——因为当前元素在查询的那一刻，map 里还不包含它自己。
- 这道题其实是哈希表在算法题里最经典的入门应用，后面会讲到的三数之和、四数之和、四数相加II，说白了都是这个思路的不同变体或者推广。
