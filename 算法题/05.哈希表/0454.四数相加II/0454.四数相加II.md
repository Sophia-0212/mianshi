# 0454. 四数相加 II

**题目描述**

给定四个整数数组 `nums1`、`nums2`、`nums3`、`nums4`，数组长度都是 n，计算有多少个元组 `(i, j, k, l)` 能满足：

```
0 <= i, j, k, l < n
nums1[i] + nums2[j] + nums3[k] + nums4[l] == 0
```

```
示例：
输入: nums1 = [1,2], nums2 = [-2,-1], nums3 = [-1,2], nums4 = [0,2]
输出: 2
解释:
两个元组如下：
1. (0, 0, 0, 1) -> nums1[0] + nums2[0] + nums3[0] + nums4[1] = 1 + (-2) + (-1) + 2 = 0
2. (1, 1, 0, 0) -> nums1[1] + nums2[1] + nums3[0] + nums4[0] = 2 + (-1) + (-1) + 0 = 0
```

## 思路

- 分组哈希：统计前两个数组所有两数和的频次，遍历后两个数组，累加 `-(c+d)` 的频次。平均时间 O(n²)，空间 O(n²)。
- 暴力：四重循环枚举。时间 O(n⁴)，空间 O(1)。

手写实现（面试考察点，还原 map 统计+查询的完整过程）：

```python
class Solution:
    # 方法：fourSumCount；按题目要求处理输入并返回结果，核心算法见方法体。
    def fourSumCount(self, nums1: list[int], nums2: list[int], nums3: list[int], nums4: list[int]) -> int:
        sum_map = {}  # 记录 nums1+nums2 的和 -> 出现次数
        for a in nums1:
            for b in nums2:
                s = a + b
                sum_map[s] = sum_map.get(s, 0) + 1  # 累加该和出现的次数

        count = 0
        for c in nums3:
            for d in nums4:
                target = -(c + d)  # 需要在第一组找到的配对和
                count += sum_map.get(target, 0)  # 累加所有能配对的组合数
        return count
```

## C++

### LeetCode 写法与原有示例

```cpp
class Solution {
public:
    // 方法：fourSumCount；按题目要求处理输入并返回结果，核心算法见方法体。
    int fourSumCount(vector<int>& nums1, vector<int>& nums2, vector<int>& nums3, vector<int>& nums4) {
        unordered_map<int, int> sumMap;  // 记录 nums1+nums2 的和 -> 出现次数
        for (int a : nums1) {
            for (int b : nums2) {
                sumMap[a + b]++;  // 累加该和出现的次数
            }
        }
        int count = 0;
        for (int c : nums3) {
            for (int d : nums4) {
                int target = -(c + d);  // 需要在第一组找到的配对和
                auto it = sumMap.find(target);
                if (it != sumMap.end()) {
                    count += it->second;  // 累加所有能配对的 (i,j) 组合数
                }
            }
        }
        return count;
    }
};
```

## 总结

- 「分组预处理 + 哈希查询」是把 O(n⁴) 降到 O(n²) 的核心技巧，你记住这个套路：把四个数组两两分组，先穷举一组的所有和存进 map，再穷举另一组去查询"互补和"。
- 这里必须用 `map`，不能用 `set`，为什么呢，因为不同的 `(i,j)` 组合可能产生相同的和，我们需要记录并累加这个和出现的次数，而不只是判断它存不存在。
- `sumMap.getOrDefault(target, 0)`（Java 里这么写）或者 `sum_map.get(target, 0)`（Python 里这么写），还有 Go 里直接访问不存在的 key 会返回零值，这些都是处理"查询不存在的 key"的标准写法，能避免你额外做一次存在性判断。
- 这个「拆两组、以空间换时间」的思路，说白了跟两数之和是一致的，只是把"单个数"扩展成了"两两之和"而已，算是哈希表解决多数之和问题的一个进阶应用。
