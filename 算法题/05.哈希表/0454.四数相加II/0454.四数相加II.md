# 0454. 四数相加 II

**题目描述**

给定四个整数数组 `nums1`、`nums2`、`nums3`、`nums4`，数组长度都是 n，计算有多少个元组 `(i, j, k, l)` 能满足：

```
0 <= i, j, k, l < n
nums1[i] + nums2[j] + nums3[k] + nums4[l] == 0
```

```
示例：
输入: nums1 = [1,2], nums2 = [-2,-1], nums3 = [-1,2], nums4 = [0,2]
输出: 2
解释:
两个元组如下：
1. (0, 0, 0, 1) -> nums1[0] + nums2[0] + nums3[0] + nums4[1] = 1 + (-2) + (-1) + 2 = 0
2. (1, 1, 0, 0) -> nums1[1] + nums2[1] + nums3[0] + nums4[0] = 2 + (-1) + (-1) + 0 = 0
```

## 思路

这题你先想暴力解法：四重循环枚举所有组合，时间复杂度是 O(n⁴)，这个规模的数据肯定会直接超时，所以得靠哈希表把复杂度降下来。

**核心技巧是什么呢？就是分组 + 哈希映射，把四数之和拆成两次两数之和。**

具体怎么拆？把四个数组两两分组：`(nums1, nums2)` 一组，`(nums3, nums4)` 一组。为什么能这么拆呢，因为 `a + b + c + d == 0` 其实等价于 `a + b == -(c + d)`，所以我们可以先把其中一组所有可能的两两之和都算出来，存进哈希表，然后再遍历另一组，去查询「负的当前和」是不是在哈希表里出现过。

那具体步骤是怎样的呢？

1. 先开一个 `map`，遍历 `nums1` 和 `nums2` 的所有组合，也就是一个双重循环，跑 n² 次，把 `nums1[i] + nums2[j]` 的和算出来，用这个和当 key，出现的次数当 value，存进 map 里。比如 `sumMap[a+b]++` 这样。
2. 接着再遍历 `nums3` 和 `nums4` 的所有组合，也是一个双重循环，n² 次，算出 `target = -(nums3[k] + nums4[l])`，这就是我们要在第一组里找的"配对和"。
3. 然后查询 `sumMap` 里有没有 `target` 这个 key，如果有的话，就把它的 value（也就是出现次数）累加到结果计数器里——为什么要累加呢，因为这个 value 表示有多少种 `(i, j)` 组合能凑出这个和，每一种都能跟当前的 `(k, l)` 组成一个合法的元组。

那这里为什么用 `map` 而不是 `set` 呢？关键就在于，我们不只需要判断某个和是否存在，还得知道它**出现了多少次**，因为不同的 `(i,j)` 组合可能算出一样的和，这些组合数都要累加进答案里，这就是一个典型的键值映射场景。

**复杂度分析**：设数组长度为 n。
- 时间复杂度是 O(n²)，两次双重循环各是 O(n²)，比暴力的 O(n⁴) 大幅降低了。
- 空间复杂度是 O(n²)，最坏情况下 `sumMap` 得存 n² 个不同的和。

## 代码

### C++

```cpp
class Solution {
public:
    int fourSumCount(vector<int>& nums1, vector<int>& nums2, vector<int>& nums3, vector<int>& nums4) {
        unordered_map<int, int> sumMap;  // 记录 nums1+nums2 的和 -> 出现次数
        for (int a : nums1) {
            for (int b : nums2) {
                sumMap[a + b]++;  // 累加该和出现的次数
            }
        }
        int count = 0;
        for (int c : nums3) {
            for (int d : nums4) {
                int target = -(c + d);  // 需要在第一组找到的配对和
                auto it = sumMap.find(target);
                if (it != sumMap.end()) {
                    count += it->second;  // 累加所有能配对的 (i,j) 组合数
                }
            }
        }
        return count;
    }
};
```

### Java

```java
class Solution {
    public int fourSumCount(int[] nums1, int[] nums2, int[] nums3, int[] nums4) {
        Map<Integer, Integer> sumMap = new HashMap<>();  // 记录 nums1+nums2 的和 -> 出现次数
        for (int a : nums1) {
            for (int b : nums2) {
                sumMap.put(a + b, sumMap.getOrDefault(a + b, 0) + 1);  // 累加该和出现的次数
            }
        }
        int count = 0;
        for (int c : nums3) {
            for (int d : nums4) {
                int target = -(c + d);  // 需要在第一组找到的配对和
                count += sumMap.getOrDefault(target, 0);  // 累加所有能配对的组合数
            }
        }
        return count;
    }
}
```

### Python

标准库一行解（用 `collections.Counter` 统计前两个数组两两之和的分布，语义上等价于手写的 map 统计，直接调用避免重复实现累加逻辑）：

```python
from collections import Counter
from itertools import product

class Solution:
    def fourSumCount(self, nums1: list[int], nums2: list[int], nums3: list[int], nums4: list[int]) -> int:
        sum_count = Counter(a + b for a, b in product(nums1, nums2))  # 统计前两数组两两和的分布
        return sum(sum_count[-(c + d)] for c, d in product(nums3, nums4))  # 查询配对和累加次数
```

手写实现（面试考察点，还原 map 统计+查询的完整过程）：

```python
class Solution:
    def fourSumCount(self, nums1: list[int], nums2: list[int], nums3: list[int], nums4: list[int]) -> int:
        sum_map = {}  # 记录 nums1+nums2 的和 -> 出现次数
        for a in nums1:
            for b in nums2:
                s = a + b
                sum_map[s] = sum_map.get(s, 0) + 1  # 累加该和出现的次数

        count = 0
        for c in nums3:
            for d in nums4:
                target = -(c + d)  # 需要在第一组找到的配对和
                count += sum_map.get(target, 0)  # 累加所有能配对的组合数
        return count
```

### Go

```go
func fourSumCount(nums1 []int, nums2 []int, nums3 []int, nums4 []int) int {
    sumMap := make(map[int]int) // 记录 nums1+nums2 的和 -> 出现次数
    for _, a := range nums1 {
        for _, b := range nums2 {
            sumMap[a+b]++ // 累加该和出现的次数
        }
    }
    count := 0
    for _, c := range nums3 {
        for _, d := range nums4 {
            target := -(c + d)      // 需要在第一组找到的配对和
            count += sumMap[target] // 累加所有能配对的组合数（不存在时默认为0）
        }
    }
    return count
}
```

## 总结

- 「分组预处理 + 哈希查询」是把 O(n⁴) 降到 O(n²) 的核心技巧，你记住这个套路：把四个数组两两分组，先穷举一组的所有和存进 map，再穷举另一组去查询"互补和"。
- 这里必须用 `map`，不能用 `set`，为什么呢，因为不同的 `(i,j)` 组合可能产生相同的和，我们需要记录并累加这个和出现的次数，而不只是判断它存不存在。
- `sumMap.getOrDefault(target, 0)`（Java 里这么写）或者 `sum_map.get(target, 0)`（Python 里这么写），还有 Go 里直接访问不存在的 key 会返回零值，这些都是处理"查询不存在的 key"的标准写法，能避免你额外做一次存在性判断。
- 这个「拆两组、以空间换时间」的思路，说白了跟两数之和是一致的，只是把"单个数"扩展成了"两两之和"而已，算是哈希表解决多数之和问题的一个进阶应用。
