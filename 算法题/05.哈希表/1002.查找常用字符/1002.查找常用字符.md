# 1002. 查找常用字符

**题目描述**

给定一个字符串数组 `words`，找出所有在 `words` 的每个字符串中都出现的字符（包括重复出现的字符），以数组形式返回结果，返回结果中的每个元素都可以以任意顺序排列。

```
示例 1：
输入: words = ["bella","label","roller"]
输出: ["e","l","l"]

示例 2：
输入: words = ["cool","lock","cook"]
输出: ["c","o"]
```

假设字符串只包含小写字母。

## 思路

这道题你可以理解成「多个字符串求字符交集」，但它有个特殊要求——重复次数也要保留下来。比如例子里 `l` 出现了两次，为什么呢？因为三个字符串里，`l` 最少也出现了两次，所以结果里就得留两个 `l`。

那怎么做呢？你想啊，字符集就是小写字母，值域小而且连续，所以还是沿用数组哈希那套思路：

1. 先把第一个字符串里每个字符出现的次数统计一遍，当作初始的「最小出现次数」数组，叫它 `minCount`。
2. 接下来从第二个字符串开始，每统计出一个字符串的字符计数 `count`，就拿这 26 个字符逐一去比较，取 `minCount[i] = min(minCount[i], count[i])`。这一步是整个思路的关键：**取最小值，说白了就是在求交集的同时把重复次数也保留住**。为什么取最小值就能做到这一点？因为一个字符要想在所有字符串里都出现 k 次，那就必须保证每个字符串至少也能提供 k 个这个字符，谁出现次数最少，谁就是瓶颈。
3. 把所有字符串都遍历完之后，`minCount` 数组里每个位置存的值，就是这个字符在所有字符串里「公共出现的最少次数」。
4. 最后再遍历一遍 `minCount`，把每个字符按它对应的计数值，重复添加到结果数组里就行了。

这个「取最小值」的技巧，本质上是把原本逐个字符串两两比较的思路，转化成了逐位比较。你不需要真的去两两求字符串的交集，而是把每个字符串都转换成一个 26 维的计数向量，然后对这些向量做逐维度的 min 运算，最后得到的结果向量就是答案。

**复杂度分析**：设字符串数组长度为 n，每个字符串平均长度为 m。
- 时间复杂度是 O(n × m)，因为每个字符串都得遍历一遍去统计计数。
- 空间复杂度是 O(1)，因为用到的就是两个长度固定为 26 的数组，不会随着输入规模变大而增长。

## 代码

### C++

```cpp
class Solution {
public:
    vector<string> commonChars(vector<string>& words) {
        vector<int> minCount(26, INT_MAX);  // 记录每个字符的最小出现次数
        for (const string& word : words) {
            vector<int> count(26, 0);  // 当前字符串的字符计数
            for (char c : word) {
                count[c - 'a']++;
            }
            for (int i = 0; i < 26; i++) {
                minCount[i] = min(minCount[i], count[i]);  // 逐维取最小值，即求交集
            }
        }
        vector<string> result;
        for (int i = 0; i < 26; i++) {
            for (int j = 0; j < minCount[i]; j++) {  // 按最小次数重复添加该字符
                result.push_back(string(1, 'a' + i));
            }
        }
        return result;
    }
};
```

### Java

```java
class Solution {
    public List<String> commonChars(String[] words) {
        int[] minCount = new int[26];
        Arrays.fill(minCount, Integer.MAX_VALUE);  // 初始化为最大值，方便取最小
        for (String word : words) {
            int[] count = new int[26];  // 当前字符串的字符计数
            for (char c : word.toCharArray()) {
                count[c - 'a']++;
            }
            for (int i = 0; i < 26; i++) {
                minCount[i] = Math.min(minCount[i], count[i]);  // 逐维取最小值
            }
        }
        List<String> result = new ArrayList<>();
        for (int i = 0; i < 26; i++) {
            for (int j = 0; j < minCount[i]; j++) {  // 按最小次数重复添加
                result.add(String.valueOf((char) ('a' + i)));
            }
        }
        return result;
    }
}
```

### Python

这道题其实没有现成的标准库一行解，因为「多字符串按字符最小计数求交集」不是标准库内置的操作，所以还是直接手写数组哈希来实现：

```python
class Solution:
    def commonChars(self, words: list[str]) -> list[str]:
        min_count = [float('inf')] * 26  # 记录每个字符的最小出现次数
        for word in words:
            count = [0] * 26  # 当前字符串的字符计数
            for c in word:
                count[ord(c) - ord('a')] += 1
            for i in range(26):
                min_count[i] = min(min_count[i], count[i])  # 逐维取最小值，即求交集

        result = []
        for i in range(26):
            result.extend([chr(ord('a') + i)] * min_count[i])  # 按最小次数重复添加该字符
        return result
```

> 提示：你也可以用 `collections.Counter` 配合 `&` 运算符来实现同样的效果——`Counter` 的 `&` 运算本质上就是取多重集合的交集，天然就支持重复计数。不过这里为了体现哈希数组这种通用写法，还是以手写为主。

### Go

```go
func commonChars(words []string) []string {
    minCount := [26]int{}
    for i := range minCount {
        minCount[i] = 1 << 30 // 初始化为一个足够大的数，方便取最小
    }
    for _, word := range words {
        var count [26]int // 当前字符串的字符计数
        for _, c := range word {
            count[c-'a']++
        }
        for i := 0; i < 26; i++ {
            if count[i] < minCount[i] {
                minCount[i] = count[i] // 逐维取最小值，即求交集
            }
        }
    }

    var result []string
    for i := 0; i < 26; i++ {
        for j := 0; j < minCount[i]; j++ { // 按最小次数重复添加该字符
            result = append(result, string(rune('a'+i)))
        }
    }
    return result
}
```

## 总结

- 「所有字符串都出现的字符（还要保留重复次数）」这个要求，说白了就等价于把每个字符在各个字符串里出现的次数都取一个最小值——用数组逐维做 min 运算，天然就实现了多字符串求交集。
- 值域小而且连续（就 26 个字母）这一点，依然是我们选数组而不是用 map 的判断依据。
- 这种「先各自统计成计数向量，再逐维取 min 或 max」的技巧，其实可以推广到很多多字符串比较类的问题上，比如求所有字符串的公共前缀特征之类的。
- 有一点要特别注意：初始化 `minCount` 的时候，一定要用一个足够大的初值（比如 `INT_MAX`），不然第一次取 min 的时候就会出错。
