# 0242. 有效的字母异位词

**题目描述**

给定两个字符串 `s` 和 `t`，判断 `t` 是否是 `s` 的字母异位词（anagram，即由相同的字符按不同顺序组成，字符出现的次数也必须完全一致）。

```
示例 1：
输入: s = "anagram", t = "nagaram"
输出: true

示例 2：
输入: s = "rat", t = "car"
输出: false
```

假设字符串只包含小写字母。

## 思路

先说说这道题在问什么：判断两个字符串是不是字母异位词，说白了就是看这两个字符串里每个字符出现的**次数**是不是完全一样。你想啊，最直接的办法就是把两个字符串都排序，排完序如果两个字符串一样，那肯定就是异位词了，但这样时间复杂度是 O(n log n)，还有没有更快的办法？

这里的关键是要意识到：字符集是固定的小写字母，一共就 26 个，值域小而且连续。既然值域这么小，那我们就不需要用 `unordered_map` 这种通用哈希表了，直接开一个长度为 26 的数组就够用了，下标用 `c - 'a'` 算出来，正好对应到某个字符的计数位置。

那具体怎么做呢？我一步步来讲：

1. 先遍历字符串 `s`，每碰到一个字符 `c` 就执行 `count[c - 'a']++`，这样就把 `s` 里每个字符出现的次数都统计出来了。
2. 然后遍历字符串 `t`，每碰到一个字符就反过来做 `count[c - 'a']--`。你想，如果 `t` 和 `s` 的字符分布真的完全一样，那一加一减，这个数组最后应该全部变成 0。
3. 最后再遍历一遍这个长度 26 的数组，只要发现有一个位置不是 0，就说明这两个字符串不是字母异位词，直接返回 false。

为什么要用数组而不是 map 呢？这里的关键就是：字符集只有 26 个小写字母，值域小且连续，用数组的话下标访问是 O(1)，而且完全不需要哈希函数计算、也不用处理冲突，比 `unordered_map` 快多了，也更省内存。这其实就是「值域小就用数组代替哈希表」的一个典型套路。

**复杂度分析**：设字符串长度为 n。
- 时间复杂度是 O(n)，因为你只需要把两个字符串各遍历一遍就行。
- 空间复杂度是 O(1)，因为这个哈希数组的大小是固定的 26，不会随着输入规模变大而增长。

## 代码

### C++

```cpp
class Solution {
public:
    bool isAnagram(string s, string t) {
        if (s.size() != t.size()) return false;  // 长度不同直接排除
        int count[26] = {0};  // 长度26的数组做哈希，下标对应字符
        for (char c : s) {
            count[c - 'a']++;  // 统计 s 中每个字符出现次数
        }
        for (char c : t) {
            count[c - 'a']--;  // t 中每出现一次对应字符就减一
        }
        for (int i = 0; i < 26; i++) {
            if (count[i] != 0) return false;  // 只要有一位不为0，说明字符分布不同
        }
        return true;
    }
};
```

### Java

```java
class Solution {
    public boolean isAnagram(String s, String t) {
        if (s.length() != t.length()) return false;  // 长度不同直接排除
        int[] count = new int[26];  // 长度26的数组做哈希
        for (char c : s.toCharArray()) {
            count[c - 'a']++;  // 统计 s 中每个字符出现次数
        }
        for (char c : t.toCharArray()) {
            count[c - 'a']--;  // t 中每出现一次对应字符就减一
        }
        for (int i = 0; i < 26; i++) {
            if (count[i] != 0) return false;  // 存在未归零的位置，说明不是异位词
        }
        return true;
    }
}
```

### Python

标准库一行解（用 `collections.Counter` 直接比较两个字符串的字符计数是否相等，`Counter` 本质就是对哈希表计数的封装）：

```python
from collections import Counter

class Solution:
    def isAnagram(self, s: str, t: str) -> bool:
        return Counter(s) == Counter(t)  # 比较两个字符计数字典是否完全一致
```

手写实现（面试考察点，还原数组哈希计数原理）：

```python
class Solution:
    def isAnagram(self, s: str, t: str) -> bool:
        if len(s) != len(t):  # 长度不同直接排除
            return False
        count = [0] * 26  # 长度26的数组做哈希，下标对应 a~z
        for c in s:
            count[ord(c) - ord('a')] += 1  # 统计 s 中每个字符出现次数
        for c in t:
            count[ord(c) - ord('a')] -= 1  # t 中每出现一次对应字符就减一
        return all(v == 0 for v in count)  # 全部归零才是字母异位词
```

### Go

```go
func isAnagram(s string, t string) bool {
    if len(s) != len(t) {
        return false // 长度不同直接排除
    }
    var count [26]int // 长度26的数组做哈希
    for _, c := range s {
        count[c-'a']++ // 统计 s 中每个字符出现次数
    }
    for _, c := range t {
        count[c-'a']-- // t 中每出现一次对应字符就减一
    }
    for _, v := range count {
        if v != 0 {
            return false // 存在未归零的位置，说明不是异位词
        }
    }
    return true
}
```

## 总结

- 你记住一个信号：只要值域小且连续（比如这题就 26 个小写字母），基本就可以拿数组来模拟哈希表，比 `unordered_map`/`HashMap` 快、也更省空间。
- 这道题的核心其实是「计数」，不是「判重」，所以千万不能用 set，得老老实实记录每个字符出现了多少次。
- 用一次自增、一次自减去对比两个字符串的字符分布，比你分别统计完再逐位比较要简洁得多，这个写法值得记下来。
- 那如果字符集扩展到 Unicode 呢，比如字符串里包含了中文，这时候值域就不再小而且连续了，那就得退回去用 `unordered_map<char, int>` 或者 Python 里的 `dict` 来统计了。
