# 0383. 赎金信

**题目描述**

给定两个字符串 `ransomNote` 和 `magazine`，判断 `ransomNote` 能不能由 `magazine` 里面的字符构成。`magazine` 中的每个字符只能在 `ransomNote` 中使用一次。

```
示例 1：
输入: ransomNote = "a", magazine = "b"
输出: false

示例 2：
输入: ransomNote = "aa", magazine = "ab"
输出: false

示例 3：
输入: ransomNote = "aa", magazine = "aab"
输出: true
```

假设两个字符串只包含小写英文字母。

## 思路

这题你会发现和 242 题「有效的字母异位词」思路几乎是一模一样的，都是**字符计数比较**的问题，区别就在于比较的方向不一样了：不是要求「完全相等」，而是要求「`ransomNote` 的每个字符计数都不能超过 `magazine` 对应字符的计数」。

因为字符集还是固定的小写字母，值域小且连续，所以我们继续沿用数组哈希计数的思路：

1. 先用一个长度 26 的数组统计出 `magazine` 中每个字符出现的次数。
2. 然后遍历 `ransomNote`，每碰到一个字符就把数组里对应位置的计数减一，这个减一操作可以理解成"消耗"了 `magazine` 里的一个字符。
3. 那如果某个字符减到负数了呢？这就说明 `magazine` 提供的这个字符数量不够 `ransomNote` 需要的数量，直接返回 false 就行。
4. 如果把 `ransomNote` 遍历完都没出现负数的情况，那就说明能够构成，返回 true。

这里有个小优化：可以先判断一下 `ransomNote.length() > magazine.length()`，如果是的话直接返回 false，为什么呢？因为字符总数都不够，肯定不可能构成（当然不加这个判断也没关系，逐字符统计一样能得出正确结果，只是加上能提前剪枝，少跑几步）。

**复杂度分析**：设 `ransomNote` 长度为 m，`magazine` 长度为 n。
- 时间复杂度是 O(m + n)，就是把两个字符串分别遍历一次。
- 空间复杂度是 O(1)，因为哈希数组的大小固定是 26。

## 代码

### C++

```cpp
class Solution {
public:
    bool canConstruct(string ransomNote, string magazine) {
        if (ransomNote.size() > magazine.size()) return false;  // 总字符数不够，提前剪枝
        int count[26] = {0};  // 长度26的数组统计字符计数
        for (char c : magazine) {
            count[c - 'a']++;  // 统计 magazine 中每个字符出现次数
        }
        for (char c : ransomNote) {
            count[c - 'a']--;  // 消耗 magazine 提供的字符
            if (count[c - 'a'] < 0) {
                return false;  // 某字符不够用，无法构成
            }
        }
        return true;
    }
};
```

### Python

标准库一行解（用 `collections.Counter` 相减：`Counter` 支持减法后过滤负值，可以直接判断 `ransomNote` 的计数是否都被 `magazine` 覆盖）：

```python
from collections import Counter

class Solution:
    def canConstruct(self, ransomNote: str, magazine: str) -> bool:
        # Counter 减法：ransomNote 中超出 magazine 提供数量的字符会保留在结果里
        return not (Counter(ransomNote) - Counter(magazine))
```

手写实现（面试考察点，还原数组哈希计数+消耗的原理）：

```python
class Solution:
    def canConstruct(self, ransomNote: str, magazine: str) -> bool:
        if len(ransomNote) > len(magazine):  # 总字符数不够，提前剪枝
            return False
        count = [0] * 26  # 长度26的数组统计字符计数
        for c in magazine:
            count[ord(c) - ord('a')] += 1  # 统计 magazine 中每个字符出现次数
        for c in ransomNote:
            idx = ord(c) - ord('a')
            count[idx] -= 1  # 消耗 magazine 提供的字符
            if count[idx] < 0:
                return False  # 某字符不够用，无法构成
        return True
```

## 总结

- 这题其实就是 242 题字符计数思路的直接迁移：值域小且连续（26 个小写字母），所以继续用数组哈希而不是 map。
- 跟「异位词判断」的区别在哪呢？就是比较方式不同：异位词要求计数完全相等，最终全部归零；这题只要求 `ransomNote` 不超过 `magazine` 的供给，也就是过程中不能出现负数。
- 提前判断总长度可以剪枝，但不是必须的，逐字符统计到负数一样能正确判断出结果，只是少了一次快速失败的机会而已。
- 所以你记住，遇到"能否用字符集 A 拼出字符串 B"这类问题，第一反应就应该是字符计数比较，而不是真的去做字符串拼接或者排列尝试。
