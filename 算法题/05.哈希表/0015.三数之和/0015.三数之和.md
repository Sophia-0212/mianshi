# 0015. 三数之和

**题目描述**

给定一个整数数组 `nums`，判断是否存在三元组 `[nums[i], nums[j], nums[k]]` 满足 `i != j`、`i != k`、`j != k`，且 `nums[i] + nums[j] + nums[k] == 0`。请找出所有满足条件且不重复的三元组。

```
示例：
输入: nums = [-1,0,1,2,-1,-4]
输出: [[-1,-1,2],[-1,0,1]]
解释: 满足要求的三元组集合为上面两个，结果不能包含重复的三元组
```

## 思路

排序后固定 `i`，用左右指针找另外两数：和小于 0 右移左指针，大于 0 左移右指针，等于 0 收集并跳过重复值。固定值也须去重；`nums[i]>0` 可结束。

时间 O(n²)；辅助空间取决于排序，C++ 常见 O(log n)、Python O(n)，不计结果。

也可固定一数后用哈希表找两数，平均时间 O(n²)，需 O(n) 哈希空间及结果去重。



## Python

### LeetCode 写法与原有示例

本题不适合用哈希法，因为去重会很麻烦，所以这里没有什么"标准库一行解"，直接给你排序加双指针的手写实现：

```python
# 依赖说明：len：Python 内置函数：返回容器中元素的数量。；range：Python 内置函数：生成按步长遍历的整数序列。

class Solution:
    # 方法：threeSum；按题目要求处理输入并返回结果，核心算法见方法体。
    def threeSum(self, nums: list[int]) -> list[list[int]]:
        nums.sort()  # 排序，为双指针和去重提供基础
        n = len(nums)
        result = []
        for i in range(n - 2):
            if nums[i] > 0:  # 排序后最小值大于0，后面不可能凑出0
                break
            if i > 0 and nums[i] == nums[i - 1]:  # 外层去重：跳过重复的第一个数
                continue

            left, right = i + 1, n - 1
            while left < right:
                total = nums[i] + nums[left] + nums[right]
                if total == 0:
                    result.append([nums[i], nums[left], nums[right]])  # 记录一个解
                    while left < right and nums[left] == nums[left + 1]:
                        left += 1  # 内层去重：跳过重复的left
                    while left < right and nums[right] == nums[right - 1]:
                        right -= 1  # 内层去重：跳过重复的right
                    left += 1
                    right -= 1
                elif total > 0:
                    right -= 1  # 和太大，右指针左移
                else:
                    left += 1  # 和太小，左指针右移
        return result```

func threeSum(nums []int) [][]int {
    sort.Ints(nums) // 排序，为双指针和去重提供基础
    n := len(nums)
    result := [][]int{}
    for i := 0; i < n-2; i++ {
        if nums[i] > 0 {
            break // 排序后最小值大于0，后面不可能凑出0
        }
        if i > 0 && nums[i] == nums[i-1] {
            continue // 外层去重：跳过重复的第一个数
        }

        left, right := i+1, n-1
        for left < right {
            sum := nums[i] + nums[left] + nums[right]
            if sum == 0 {
                result = append(result, []int{nums[i], nums[left], nums[right]}) // 记录一个解
                for left < right && nums[left] == nums[left+1] {
                    left++ // 内层去重：跳过重复的left
                }
                for left < right && nums[right] == nums[right-1] {
                    right-- // 内层去重：跳过重复的right
                }
                left++
                right--
            } else if sum > 0 {
                right-- // 和太大，右指针左移
            } else {
                left++ // 和太小，左指针右移
            }
        }
    }
    return result
}```

### LeetCode 写法与原有示例

class Solution {
public:
    vector<vector<int>> threeSum(vector<int>& nums) {
        vector<vector<int>> result;
        sort(nums.begin(), nums.end());  // 排序，为双指针和去重提供基础
        int n = nums.size();
        for (int i = 0; i < n - 2; i++) {
            if (nums[i] > 0) break;  // 排序后最小值大于0，后面不可能凑出0，直接结束
            if (i > 0 && nums[i] == nums[i - 1]) continue;  // 外层去重：跳过重复的第一个数

            int left = i + 1, right = n - 1;
            while (left < right) {
                int sum = nums[i] + nums[left] + nums[right];
                if (sum == 0) {
                    result.push_back({nums[i], nums[left], nums[right]});  // 记录一个解
                    while (left < right && nums[left] == nums[left + 1]) left++;  // 内层去重：跳过重复的left
                    while (left < right && nums[right] == nums[right - 1]) right--;  // 内层去重：跳过重复的right
                    left++;
                    right--;
                } else if (sum > 0) {
                    right--;  // 和太大，右指针左移减小sum
                } else {
                    left++;  // 和太小，左指针右移增大sum
                }
            }
        }
        return result;
    }
};
```

## 总结

- 三数之和为什么不用哈希法了？核心就是**去重这个需求在作怪**：哈希法找出来的解是基于下标的，去重就得对结果值再做一遍额外处理；而排序之后用双指针，可以直接在遍历过程中利用相邻元素相等这个性质，顺手就把重复分支跳过去了。
- 排序是双指针法能生效的前提，你想啊，只有数组是有序的，才能利用"sum 大了就右指针左移，sum 小了就左指针右移"这种单调性去收缩区间，这个前提丢了双指针就玩不转了。
- 三层去重逻辑一定要分清楚：外层 `i` 的去重，是为了避免以相同数字开头的三元组重复出现；内层 `left`/`right` 的去重，是为了避免同一个 `i` 下面产生重复的第二、三个数的组合——这两者作用的层级不一样，缺哪个都不行。
- 说到 `nums[i] > 0` 时的那个 break 剪枝，它利用的是排序后数组单调不减的性质，本质上是个不影响正确性的性能优化。你把这行代码去掉，结果照样是对的，只不过会多跑几轮没意义的循环而已。
