# 0018. 四数之和

**题目描述**

给定一个整数数组 `nums` 和一个目标值 `target`，找出所有满足条件且不重复的四元组 `[nums[a], nums[b], nums[c], nums[d]]`（`a`、`b`、`c`、`d` 互不相同），使得 `nums[a] + nums[b] + nums[c] + nums[d] == target`。

```
示例：
输入: nums = [1,0,-1,0,-2,2], target = 0
输出: [[-2,-1,1,2],[-2,0,0,2],[-1,0,0,1]]
```

## 思路

排序后两层循环固定前两数，双指针寻找剩余两数。每层固定值及命中后的左右指针均去重；用最小、最大可达和剪枝，求和使用足够宽的整数类型。

时间 O(n³)；辅助空间取决于排序，C++ 常见 O(log n)、Python O(n)，不计结果。



## Python

### LeetCode 写法与原有示例

跟三数之和一样，这题也不适合用哈希法去重，所以还是直接给你排序加双指针的手写实现：

```python
# 依赖说明：len：Python 内置函数：返回容器中元素的数量。；range：Python 内置函数：生成按步长遍历的整数序列。

class Solution:
    # 方法：fourSum；按题目要求处理输入并返回结果，核心算法见方法体。
    def fourSum(self, nums: list[int], target: int) -> list[list[int]]:
        nums.sort()  # 排序，为双指针和去重提供基础
        n = len(nums)
        result = []

        for i in range(n - 3):
            if i > 0 and nums[i] == nums[i - 1]:  # 第一层去重
                continue
            if nums[i] + nums[i+1] + nums[i+2] + nums[i+3] > target:  # 最小组合已超target
                break
            if nums[i] + nums[n-1] + nums[n-2] + nums[n-3] < target:  # 最大组合仍不够
                continue

            for j in range(i + 1, n - 2):
                if j > i + 1 and nums[j] == nums[j - 1]:  # 第二层去重
                    continue
                if nums[i] + nums[j] + nums[j+1] + nums[j+2] > target:  # 剪枝
                    break
                if nums[i] + nums[j] + nums[n-1] + nums[n-2] < target:  # 剪枝
                    continue

                left, right = j + 1, n - 1
                while left < right:
                    total = nums[i] + nums[j] + nums[left] + nums[right]
                    if total == target:
                        result.append([nums[i], nums[j], nums[left], nums[right]])
                        while left < right and nums[left] == nums[left + 1]:
                            left += 1  # 第三层去重
                        while left < right and nums[right] == nums[right - 1]:
                            right -= 1  # 第四层去重
                        left += 1
                        right -= 1
                    elif total > target:
                        right -= 1  # 和太大，右指针左移
                    else:
                        left += 1  # 和太小，左指针右移
        return result```

        if nums[i]+nums[i+1]+nums[i+2]+nums[i+3] > target {
            break // 最小组合已超target
        }
        if nums[i]+nums[n-1]+nums[n-2]+nums[n-3] < target {
            continue // 最大组合仍不够
        }

        for j := i + 1; j < n-2; j++ {
            if j > i+1 && nums[j] == nums[j-1] {
                continue // 第二层去重
            }
            if nums[i]+nums[j]+nums[j+1]+nums[j+2] > target {
                break // 剪枝
            }
            if nums[i]+nums[j]+nums[n-1]+nums[n-2] < target {
                continue // 剪枝
            }

            left, right := j+1, n-1
            for left < right {
                sum := nums[i] + nums[j] + nums[left] + nums[right]
                if sum == target {
                    result = append(result, []int{nums[i], nums[j], nums[left], nums[right]})
                    for left < right && nums[left] == nums[left+1] {
                        left++ // 第三层去重
                    }
                    for left < right && nums[right] == nums[right-1] {
                        right-- // 第四层去重
                    }
                    left++
                    right--
                } else if sum > target {
                    right-- // 和太大，右指针左移
                } else {
                    left++ // 和太小，左指针右移
                }
            }
        }
    }
    return result

## C++

### LeetCode 写法与原有示例

class Solution {
public:
    vector<vector<int>> fourSum(vector<int>& nums, int target) {
        vector<vector<int>> result;
        sort(nums.begin(), nums.end());  // 排序，为双指针和去重提供基础
        int n = nums.size();

        for (int i = 0; i < n - 3; i++) {
            if (i > 0 && nums[i] == nums[i - 1]) continue;  // 第一层去重
            // 剪枝：用 long 防止溢出
            if ((long)nums[i] + nums[i+1] + nums[i+2] + nums[i+3] > target) break;  // 最小组合已超target，后面更不可能
            if ((long)nums[i] + nums[n-1] + nums[n-2] + nums[n-3] < target) continue;  // 最大组合仍不够，当前i无解

            for (int j = i + 1; j < n - 2; j++) {
                if (j > i + 1 && nums[j] == nums[j - 1]) continue;  // 第二层去重
                if ((long)nums[i] + nums[j] + nums[j+1] + nums[j+2] > target) break;  // 剪枝
                if ((long)nums[i] + nums[j] + nums[n-1] + nums[n-2] < target) continue;  // 剪枝

                int left = j + 1, right = n - 1;
                while (left < right) {
                    long sum = (long)nums[i] + nums[j] + nums[left] + nums[right];
                    if (sum == target) {
                        result.push_back({nums[i], nums[j], nums[left], nums[right]});
                        while (left < right && nums[left] == nums[left + 1]) left++;  // 第三层去重
                        while (left < right && nums[right] == nums[right - 1]) right--;  // 第四层去重
                        left++;
                        right--;
                    } else if (sum > target) {
                        right--;  // 和太大，右指针左移
                    } else {
                        left++;  // 和太小，左指针右移
                    }
                }
            }
        }
        return result;
    }
};

## 总结

- 四数之和说白了就是三数之和的推广：外层多加一层固定循环，也就是多固定一个数，内层还是老套路用双指针处理最后两个数，去重逻辑也跟着从两层扩展成了四层，也就是 `i`、`j`、`left`、`right`。
- N 数之和这类问题存在一个通用的递归模式：固定住 N-2 个数之后，剩下两个数用双指针去解决，这个模式还能继续往上套，比方说五数之和之类更高阶的变体，一般会用递归来实现会更通用一些。
- 剪枝逻辑一定要跟 target 比较，不能像三数之和那样简单套用 `>0` 的判断，因为这里的 target 可以是任意值，甚至是负数，而且要同时兼顾两个方向的剪枝——"最小组合超过 target 就 break"和"最大组合还不够 target 就 continue"，这两个都得处理到。
- 算和的过程中要留意可能的整数溢出，这题的数据范围下 4 个 int 加起来是有可能超出 int 范围的，所以 C++ 和 Java 里建议用 `long` 类型来做中间计算，避免溢出出问题。
