# 0020. 有效的括号

**题目描述**

给定一个只包含 `'('`、`')'`、`'{'`、`'}'`、`'['`、`']'` 的字符串 `s`，判断字符串是否有效。有效需要满足：

1. 左括号必须用相同类型的右括号闭合。
2. 左括号必须以正确的顺序闭合。
3. 每个右括号都有一个对应的相同类型的左括号。

```
示例：
输入: s = "()[]{}"
输出: true

输入: s = "([)]"
输出: false
解释: 括号交叉嵌套，顺序不对，无效

输入: s = "("
输出: false
解释: 左括号没有被闭合
```

## 思路

栈匹配：左括号入栈，右括号须与栈顶匹配后弹栈；栈空或类型不符则失败，结束时栈必须为空。也可入栈预期的右括号，直接比较。

时间 O(n)，空间 O(n)。



## Python

### LeetCode 写法与原有示例

普通 `list` 当栈用即可，属于基本操作，不涉及库解/手写的区分。

```python
class Solution:
    # 方法：isValid；按题目要求处理输入并返回结果，核心算法见方法体。
    def isValid(self, s: str) -> bool:
        stack = []
        pairs = {'(': ')', '{': '}', '[': ']'}  # 左括号 -> 期望匹配的右括号
        for c in s:
            if c in pairs:
                stack.append(pairs[c])  # 存入期望匹配的右括号
            else:
                # 情况一：栈为空说明没有左括号可匹配；情况二：类型不匹配
                if not stack or stack[-1] != c:
                    return False
                stack.pop()  # 匹配成功
        return not stack  # 情况三：栈不为空说明有左括号未闭合
```

## Go

### LeetCode 写法与原有示例

```go
// 方法：isValid；按题目要求处理输入并返回结果，核心算法见方法体。
func isValid(s string) bool {
    stack := make([]byte, 0, len(s))
    pairs := map[byte]byte{'(': ')', '{': '}', '[': ']'} // 左括号 -> 期望匹配的右括号

    for i := 0; i < len(s); i++ {
        c := s[i]
        if expect, isLeft := pairs[c]; isLeft {
            stack = append(stack, expect) // 存入期望匹配的右括号
        } else {
            // 情况一：栈为空说明没有左括号可匹配
            if len(stack) == 0 {
                return false
            }
            top := stack[len(stack)-1]
            if top != c { // 情况二：类型不匹配
                return false
            }
            stack = stack[:len(stack)-1] // 匹配成功，弹出栈顶
        }
    }
    return len(stack) == 0 // 情况三：栈不为空说明有左括号未闭合
}
```

## C++

### LeetCode 写法与原有示例

```cpp
class Solution {
public:
    // 方法：isValid；按题目要求处理输入并返回结果，核心算法见方法体。
    bool isValid(string s) {
        stack<char> st;
        for (char c : s) {
            if (c == '(') {
                st.push(')');  // 直接存入期望匹配的右括号，简化后续比较
            } else if (c == '{') {
                st.push('}');
            } else if (c == '[') {
                st.push(']');
            } else {
                // 当前是右括号：情况一，栈为空说明没有左括号可匹配
                if (st.empty() || st.top() != c) {
                    return false;  // 情况一（栈空）或情况二（类型不匹配）
                }
                st.pop();  // 匹配成功，弹出栈顶
            }
        }
        return st.empty();  // 情况三：遍历结束栈不为空说明有左括号未闭合
    }
};
```

## 总结

- 说白了，括号匹配就是栈的入门级经典应用，核心就是利用 LIFO 这个特性，保证"最近的左括号最先被匹配上"。
- 一定要记住覆盖三种不匹配的情况：栈空的时候遇到右括号、栈顶类型跟当前右括号不一致、遍历结束后栈还非空——这三种缺了任何一种，结果都会判错。
- 有个优化技巧可以用一下：入栈的时候直接存"期望匹配的右括号"，而不是左括号本身，这样就能省掉额外的映射查找，比较逻辑会更直接、更清爽。
- 这个思路其实不止能用在括号上，你可以推广到任何"成对出现、需要按顺序闭合"的场景，比如 XML/HTML 标签匹配、代码编辑器里的括号高亮提示，都是同一套逻辑。
