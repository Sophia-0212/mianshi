# 0020. 有效的括号

**题目描述**

给定一个只包含 `'('`、`')'`、`'{'`、`'}'`、`'['`、`']'` 的字符串 `s`，判断字符串是否有效。有效需要满足：

1. 左括号必须用相同类型的右括号闭合。
2. 左括号必须以正确的顺序闭合。
3. 每个右括号都有一个对应的相同类型的左括号。

```
示例：
输入: s = "()[]{}"
输出: true

输入: s = "([)]"
输出: false
解释: 括号交叉嵌套，顺序不对，无效

输入: s = "("
输出: false
解释: 左括号没有被闭合
```

## 思路

这题一看到"括号匹配"，你就应该反应过来——这是栈的经典应用场景。为什么呢？关键是这么想：最近出现的、还没被匹配上的那个左括号，一定就是下一个右括号应该去匹配的对象。你想啊，这不就是栈的 LIFO 特性嘛——最后进去的，最先被弹出来。

那具体怎么做呢？我的算法流程是这样的：

1. 从头遍历这个字符串，遇到左括号（`(`、`{`、`[`）就直接扔进栈里。
2. 遇到右括号的时候，先看看栈顶是什么：
   - 如果栈是空的，说明压根没有左括号能跟它匹配，这肯定是无效的。
   - 如果栈顶的左括号跟当前这个右括号类型不对（比如栈顶是 `(`，但现在来了个 `]`），也是无效的。
   - 如果类型对上了，就把栈顶弹出来，接着往下遍历。
3. 遍历完了之后，还要看一眼栈——如果栈不为空，说明还有左括号没被闭合，无效；只有栈空了，才说明所有括号都严丝合缝地匹配上了。

这里的关键点是：有三种不匹配的情况，必须全部覆盖到，少判断一种都会出错。我一个一个说：

- **第一种情况：遇到右括号，但栈已经空了**。比如字符串 `")"`，还没有任何左括号入栈呢，直接就来了个右括号，那这个右括号肯定找不到对象匹配，直接判无效。这里要特别小心，如果不先判断栈是不是空的，直接去取栈顶元素，会越界访问，程序直接崩了。
- **第二种情况：栈顶的括号类型对不上**。比如 `"([)]"` 这个例子，遍历到 `)` 的时候，栈顶其实是 `[`（因为前面 `(` 和 `[` 都已经入栈了，栈顶变成了 `[`），类型不一致，说明括号是交叉嵌套的，顺序不对，这也是无效的。
- **第三种情况：遍历完了，但栈里还有剩**。比如 `"((("`，全是左括号，遍历完一看，栈里还剩 3 个左括号没人理，说明它们都没被正确闭合，无效。这一步特别容易被忽略——很多人只做了前两种判断就直接返回 true 了，漏掉了"左括号多余"这种情况，一定要小心。

再说个实用的小技巧：入栈左括号的时候，你可以不存左括号本身，而是直接存它对应的右括号。这样遇到右括号的时候，只需要比较"栈顶元素是不是等于当前字符"就行了，不用另外写个映射表来回查，代码会简洁很多。

**复杂度分析**：时间复杂度是 O(n)，n 是字符串长度，因为每个字符最多入栈出栈一次；空间复杂度也是 O(n)，最坏情况下——比如全是左括号——所有字符都得进栈。

## 代码

### C++

```cpp
class Solution {
public:
    bool isValid(string s) {
        stack<char> st;
        for (char c : s) {
            if (c == '(') {
                st.push(')');  // 直接存入期望匹配的右括号，简化后续比较
            } else if (c == '{') {
                st.push('}');
            } else if (c == '[') {
                st.push(']');
            } else {
                // 当前是右括号：情况一，栈为空说明没有左括号可匹配
                if (st.empty() || st.top() != c) {
                    return false;  // 情况一（栈空）或情况二（类型不匹配）
                }
                st.pop();  // 匹配成功，弹出栈顶
            }
        }
        return st.empty();  // 情况三：遍历结束栈不为空说明有左括号未闭合
    }
};
```

### Java

```java
class Solution {
    public boolean isValid(String s) {
        Deque<Character> stack = new ArrayDeque<>();
        for (char c : s.toCharArray()) {
            if (c == '(') {
                stack.push(')');  // 存入期望匹配的右括号
            } else if (c == '{') {
                stack.push('}');
            } else if (c == '[') {
                stack.push(']');
            } else {
                // 情况一：栈为空说明没有左括号可匹配；情况二：类型不匹配
                if (stack.isEmpty() || stack.peek() != c) {
                    return false;
                }
                stack.pop();  // 匹配成功
            }
        }
        return stack.isEmpty();  // 情况三：栈不为空说明有左括号未闭合
    }
}
```

### Python

普通 `list` 当栈用即可，属于基本操作，不涉及库解/手写的区分。

```python
class Solution:
    def isValid(self, s: str) -> bool:
        stack = []
        pairs = {'(': ')', '{': '}', '[': ']'}  # 左括号 -> 期望匹配的右括号
        for c in s:
            if c in pairs:
                stack.append(pairs[c])  # 存入期望匹配的右括号
            else:
                # 情况一：栈为空说明没有左括号可匹配；情况二：类型不匹配
                if not stack or stack[-1] != c:
                    return False
                stack.pop()  # 匹配成功
        return not stack  # 情况三：栈不为空说明有左括号未闭合
```

### Go

```go
func isValid(s string) bool {
    stack := make([]byte, 0, len(s))
    pairs := map[byte]byte{'(': ')', '{': '}', '[': ']'} // 左括号 -> 期望匹配的右括号

    for i := 0; i < len(s); i++ {
        c := s[i]
        if expect, isLeft := pairs[c]; isLeft {
            stack = append(stack, expect) // 存入期望匹配的右括号
        } else {
            // 情况一：栈为空说明没有左括号可匹配
            if len(stack) == 0 {
                return false
            }
            top := stack[len(stack)-1]
            if top != c { // 情况二：类型不匹配
                return false
            }
            stack = stack[:len(stack)-1] // 匹配成功，弹出栈顶
        }
    }
    return len(stack) == 0 // 情况三：栈不为空说明有左括号未闭合
}
```

## 总结

- 说白了，括号匹配就是栈的入门级经典应用，核心就是利用 LIFO 这个特性，保证"最近的左括号最先被匹配上"。
- 一定要记住覆盖三种不匹配的情况：栈空的时候遇到右括号、栈顶类型跟当前右括号不一致、遍历结束后栈还非空——这三种缺了任何一种，结果都会判错。
- 有个优化技巧可以用一下：入栈的时候直接存"期望匹配的右括号"，而不是左括号本身，这样就能省掉额外的映射查找，比较逻辑会更直接、更清爽。
- 这个思路其实不止能用在括号上，你可以推广到任何"成对出现、需要按顺序闭合"的场景，比如 XML/HTML 标签匹配、代码编辑器里的括号高亮提示，都是同一套逻辑。
