# 栈与队列总结

| 场景 | 方法 | 时间 | 空间 |
|---|---|---|---|
| 括号匹配 | 栈保存待匹配项 | O(n) | O(n) |
| 后缀表达式 | 数字入栈，运算时先弹右操作数 | O(n) | O(n) |
| 相邻重复消除 | 相同弹栈，不同入栈 | O(n) | O(n) |
| 双栈模拟队列 | 输出栈空时才倒入输入栈 | 单次最坏 O(n)，均摊 O(1) | O(n) |
| 队列模拟栈 | 入队后轮转旧元素，新元素到队头 | push O(n)，pop O(1) | O(n) |
| 单调栈 | 遇更大／更小值时结算等待元素 | O(n) | O(n) |
| 单调队列 | 队尾维护候选，队头删除过期项 | O(n) | O(k)，不计结果 |
| 前 k 高频 | 哈希计数＋大小 k 的小顶堆 | O(n+m log(k+1)) | O(m+k) |

m 为不同值数，k 为窗口／堆大小。单调结构中每个元素入、出各至多一次。
