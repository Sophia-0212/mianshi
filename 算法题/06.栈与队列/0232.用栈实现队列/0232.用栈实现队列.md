# 0232. 用栈实现队列

**题目描述**

仅使用两个栈实现先入先出队列，支持以下操作：

- `push(x)`：将元素 x 推到队列末尾
- `pop()`：从队列开头移除并返回元素
- `peek()`：返回队列开头的元素
- `empty()`：判断队列是否为空

```
示例：
输入:
["MyQueue", "push", "push", "peek", "pop", "empty"]
[[], [1], [2], [], [], []]
输出:
[null, null, null, 1, 1, false]
```

要求：只能使用栈的标准操作（push、pop、peek、empty、size）。

## 思路

双栈：入队写输入栈，出队或查看队头读输出栈。仅当输出栈为空时，将输入栈全部倒入，反转顺序。

入队时间 O(1)，出队/查看最坏 O(n)、均摊 O(1)；空间 O(n)。

```python
class MyQueue:
    # 方法：__init__；按题目要求处理输入并返回结果，核心算法见方法体。
    def __init__(self):
        self.in_stack = []   # 输入栈：接收 push 的新元素
        self.out_stack = []  # 输出栈：负责 pop/peek

    # 方法：_transfer；按题目要求处理输入并返回结果，核心算法见方法体。
    def _transfer(self):
        # 仅当输出栈为空时，才把输入栈整体倒入输出栈
        if not self.out_stack:
            while self.in_stack:
                self.out_stack.append(self.in_stack.pop())

    # 方法：push；按题目要求处理输入并返回结果，核心算法见方法体。
    def push(self, x: int) -> None:
        self.in_stack.append(x)  # 直接压入输入栈

    # 方法：pop；按题目要求处理输入并返回结果，核心算法见方法体。
    def pop(self) -> int:
        self._transfer()
        return self.out_stack.pop()  # 输出栈栈顶即队头

    # 方法：peek；按题目要求处理输入并返回结果，核心算法见方法体。
    def peek(self) -> int:
        self._transfer()
        return self.out_stack[-1]

    # 方法：empty；按题目要求处理输入并返回结果，核心算法见方法体。
    def empty(self) -> bool:
        return not self.in_stack and not self.out_stack
```

## Go

### LeetCode 写法与原有示例

```go
type MyQueue struct {
    inStack  []int // 输入栈：接收 Push 的新元素
    outStack []int // 输出栈：负责 Pop/Peek
}

// 方法：Constructor；按题目要求处理输入并返回结果，核心算法见方法体。
func Constructor() MyQueue {
    return MyQueue{}
}

// 仅当输出栈为空时才整体倒入
// 方法：transfer；按题目要求处理输入并返回结果，核心算法见方法体。
func (q *MyQueue) transfer() {
    if len(q.outStack) == 0 {
        for len(q.inStack) > 0 {
            n := len(q.inStack)
            q.outStack = append(q.outStack, q.inStack[n-1]) // 取输入栈栈顶
            q.inStack = q.inStack[:n-1]                     // 弹出
        }
    }
}

// 方法：Push；按题目要求处理输入并返回结果，核心算法见方法体。
func (q *MyQueue) Push(x int) {
    q.inStack = append(q.inStack, x) // 压入输入栈
}

// 方法：Pop；按题目要求处理输入并返回结果，核心算法见方法体。
func (q *MyQueue) Pop() int {
    q.transfer()
    n := len(q.outStack)
    val := q.outStack[n-1]
    q.outStack = q.outStack[:n-1]
    return val
}

// 方法：Peek；按题目要求处理输入并返回结果，核心算法见方法体。
func (q *MyQueue) Peek() int {
    q.transfer()
    return q.outStack[len(q.outStack)-1]
}

// 方法：Empty；按题目要求处理输入并返回结果，核心算法见方法体。
func (q *MyQueue) Empty() bool {
    return len(q.inStack) == 0 && len(q.outStack) == 0
}
```

## C++

### LeetCode 写法与原有示例

```cpp
// 依赖说明：stack：C++ STL 栈容器。

class MyQueue {
private:
    stack<int> inStack;   // 输入栈：只负责接收 push 的新元素
    stack<int> outStack;  // 输出栈：只负责弹出/查看队头元素

    // 仅当输出栈为空时，才把输入栈整体倒入输出栈
    // 方法：transfer；按题目要求处理输入并返回结果，核心算法见方法体。
    void transfer() {
        if (outStack.empty()) {
            while (!inStack.empty()) {
                outStack.push(inStack.top());
                inStack.pop();
            }
        }
    }

public:
    MyQueue() {}

    // 方法：push；按题目要求处理输入并返回结果，核心算法见方法体。
    void push(int x) {
        inStack.push(x);  // 新元素直接压入输入栈
    }

    // 方法：pop；按题目要求处理输入并返回结果，核心算法见方法体。
    int pop() {
        transfer();              // 保证输出栈有数据（或本来就有）
        int val = outStack.top();
        outStack.pop();
        return val;
    }

    // 方法：peek；按题目要求处理输入并返回结果，核心算法见方法体。
    int peek() {
        transfer();               // 保证输出栈有数据
        return outStack.top();
    }

    // 方法：empty；按题目要求处理输入并返回结果，核心算法见方法体。
    bool empty() {
        return inStack.empty() && outStack.empty();  // 两个栈都空才算队列空
    }
};```

## 总结

- 双栈模拟队列的核心思路，说白了就是"输入栈只管进、输出栈只管出"，通过一次性把顺序倒转过来，把 LIFO 转换成 FIFO。
- 倒入的时机是这题的关键：必须等输出栈**完全空了**才倒入输入栈的数据，不然会把新旧元素的顺序全搞乱了。
- 均摊时间复杂度 O(1) 是怎么证明的呢？你可以这样想：给每个元素分配"两次操作"的信用（一次入输入栈、一次倒进输出栈），总的操作次数跟元素数量是成正比的，所以平均到单次操作上就是常数时间了。
- 这其实是"用一种数据结构去模拟另一种数据结构语义"的典型题目，把均摊分析这个方法理解透了之后，0225 题（用队列实现栈）就可以用类似的思路对称地去想，会容易很多。
