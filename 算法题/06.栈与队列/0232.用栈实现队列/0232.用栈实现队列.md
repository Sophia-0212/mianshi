# 0232. 用栈实现队列

**题目描述**

仅使用两个栈实现先入先出队列，支持以下操作：

- `push(x)`：将元素 x 推到队列末尾
- `pop()`：从队列开头移除并返回元素
- `peek()`：返回队列开头的元素
- `empty()`：判断队列是否为空

```
示例：
输入:
["MyQueue", "push", "push", "peek", "pop", "empty"]
[[], [1], [2], [], [], []]
输出:
[null, null, null, 1, 1, false]
```

要求：只能使用栈的标准操作（push、pop、peek、empty、size）。

## 思路

你想啊，栈是 LIFO，队列是 FIFO，两者的出入顺序正好是反的。如果只用一个栈，是没法直接模拟出队列那种顺序的，因为栈顶元素永远是最后 push 进去的那个，但队列需要弹出的却是最先 push 进去的那个，这就矛盾了。

那怎么解决呢？核心技巧是**用两个栈分工合作**：

- **输入栈（inStack）**：只负责接收新 push 进来的元素，永远保持"最新元素在栈顶"这个状态。
- **输出栈（outStack）**：只负责弹出或者查看队头元素。

那什么时候倒腾数据呢？当需要 pop 或者 peek，但输出栈这时候是空的，就把输入栈里的元素**全部**倒进输出栈。为什么这样倒一次就行了呢？因为栈是 LIFO，倒过去之后，原来在输入栈最底部的那个元素（也就是最早 push 进去的），会变成输出栈的栈顶——这正好就是队列语义要求的那个"最先进先出"的元素,刚好对上了。

**这里有个关键点你必须注意**：倒入这个操作不是每次 pop 都要做的，而是"只有当输出栈为空的时候才倒入"。为什么呢？如果输出栈里还有元素在,说明上一轮倒进去的元素还没消费完，这时候新 push 进来的元素就必须老老实实留在输入栈里，不能提前倒过去，不然会把顺序打乱——新元素会插到那些还没被消费的旧元素前面去，这就出问题了。

**复杂度分析**：

- push：只操作输入栈，是 O(1)。
- pop / peek：最坏情况下得把输入栈整个倒进输出栈，看起来是 O(n)；但你细想一下，每个元素这一辈子只会被倒一次（一旦倒进输出栈，后面的操作都是直接弹输出栈，不会再倒回去了），所以**均摊时间复杂度其实是 O(1)**。这就是均摊分析（amortized analysis）的经典例子：单次操作可能挺贵，但平均到每个元素身上，其实是很便宜的。
- 空间复杂度是 O(n)，n 是队列里元素的个数。

## 代码

### C++

```cpp
class MyQueue {
private:
    stack<int> inStack;   // 输入栈：只负责接收 push 的新元素
    stack<int> outStack;  // 输出栈：只负责弹出/查看队头元素

    // 仅当输出栈为空时，才把输入栈整体倒入输出栈
    void transfer() {
        if (outStack.empty()) {
            while (!inStack.empty()) {
                outStack.push(inStack.top());
                inStack.pop();
            }
        }
    }

public:
    MyQueue() {}

    void push(int x) {
        inStack.push(x);  // 新元素直接压入输入栈
    }

    int pop() {
        transfer();              // 保证输出栈有数据（或本来就有）
        int val = outStack.top();
        outStack.pop();
        return val;
    }

    int peek() {
        transfer();               // 保证输出栈有数据
        return outStack.top();
    }

    bool empty() {
        return inStack.empty() && outStack.empty();  // 两个栈都空才算队列空
    }
};
```

### Java

```java
class MyQueue {
    private Deque<Integer> inStack;   // 输入栈：接收 push 的新元素
    private Deque<Integer> outStack;  // 输出栈：负责 pop/peek

    public MyQueue() {
        inStack = new ArrayDeque<>();
        outStack = new ArrayDeque<>();
    }

    // 仅当输出栈为空时才整体倒入，避免打乱顺序
    private void transfer() {
        if (outStack.isEmpty()) {
            while (!inStack.isEmpty()) {
                outStack.push(inStack.pop());
            }
        }
    }

    public void push(int x) {
        inStack.push(x);  // 直接压入输入栈
    }

    public int pop() {
        transfer();
        return outStack.pop();  // 输出栈栈顶即队头
    }

    public int peek() {
        transfer();
        return outStack.peek();
    }

    public boolean empty() {
        return inStack.isEmpty() && outStack.isEmpty();
    }
}
```

### Python

Python 中普通 `list` 就能当栈用（`append`/`pop` 都是 O(1) 摊还），不涉及"库解/手写"的区分。

```python
class MyQueue:
    def __init__(self):
        self.in_stack = []   # 输入栈：接收 push 的新元素
        self.out_stack = []  # 输出栈：负责 pop/peek

    def _transfer(self):
        # 仅当输出栈为空时，才把输入栈整体倒入输出栈
        if not self.out_stack:
            while self.in_stack:
                self.out_stack.append(self.in_stack.pop())

    def push(self, x: int) -> None:
        self.in_stack.append(x)  # 直接压入输入栈

    def pop(self) -> int:
        self._transfer()
        return self.out_stack.pop()  # 输出栈栈顶即队头

    def peek(self) -> int:
        self._transfer()
        return self.out_stack[-1]

    def empty(self) -> bool:
        return not self.in_stack and not self.out_stack
```

### Go

```go
type MyQueue struct {
    inStack  []int // 输入栈：接收 Push 的新元素
    outStack []int // 输出栈：负责 Pop/Peek
}

func Constructor() MyQueue {
    return MyQueue{}
}

// 仅当输出栈为空时才整体倒入
func (q *MyQueue) transfer() {
    if len(q.outStack) == 0 {
        for len(q.inStack) > 0 {
            n := len(q.inStack)
            q.outStack = append(q.outStack, q.inStack[n-1]) // 取输入栈栈顶
            q.inStack = q.inStack[:n-1]                     // 弹出
        }
    }
}

func (q *MyQueue) Push(x int) {
    q.inStack = append(q.inStack, x) // 压入输入栈
}

func (q *MyQueue) Pop() int {
    q.transfer()
    n := len(q.outStack)
    val := q.outStack[n-1]
    q.outStack = q.outStack[:n-1]
    return val
}

func (q *MyQueue) Peek() int {
    q.transfer()
    return q.outStack[len(q.outStack)-1]
}

func (q *MyQueue) Empty() bool {
    return len(q.inStack) == 0 && len(q.outStack) == 0
}
```

## 总结

- 双栈模拟队列的核心思路，说白了就是"输入栈只管进、输出栈只管出"，通过一次性把顺序倒转过来，把 LIFO 转换成 FIFO。
- 倒入的时机是这题的关键：必须等输出栈**完全空了**才倒入输入栈的数据，不然会把新旧元素的顺序全搞乱了。
- 均摊时间复杂度 O(1) 是怎么证明的呢？你可以这样想：给每个元素分配"两次操作"的信用（一次入输入栈、一次倒进输出栈），总的操作次数跟元素数量是成正比的，所以平均到单次操作上就是常数时间了。
- 这其实是"用一种数据结构去模拟另一种数据结构语义"的典型题目，把均摊分析这个方法理解透了之后，0225 题（用队列实现栈）就可以用类似的思路对称地去想，会容易很多。
