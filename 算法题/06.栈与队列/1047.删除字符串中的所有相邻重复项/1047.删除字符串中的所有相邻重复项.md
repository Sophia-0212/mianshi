# 1047. 删除字符串中的所有相邻重复项

**题目描述**

给定一个由小写字母组成的字符串 `s`，重复项删除操作会选择两个**相邻且相同**的字母，并删除它们。在对 `s` 重复进行重复项删除操作后，返回最终的结果字符串。答案是唯一的。

```
示例：
输入: s = "abbaca"
输出: "ca"
解释:
"abbaca" -> "aaca"（删除 "bb"）
"aaca" -> "ca"（删除 "aa"）
最终得到 "ca"，无法再删除
```

要求：结果字符串中不存在相邻且相同的字符。

## 思路

如果按照题目字面意思去模拟——每次都扫描整个字符串找相邻相同的字符对，删除完再重新扫描一遍，你想啊，这样会非常低效，因为每删除一次就要重新扫描整个字符串，最坏情况下时间复杂度会退化到 O(n²) 甚至更高，实现起来也挺繁琐的。

这里的关键是什么呢？这个过程说白了就很像"消消乐"游戏——用一个栈从左到右扫描字符串，栈顶始终代表"当前还未被消除、且紧邻着下一个待处理字符"的字符。

具体怎么做呢，我说一下步骤：

1. 遍历字符串的每个字符 `c`。
2. 如果栈不为空，而且栈顶元素正好等于 `c`，说明这两个字符相邻且相同，那就直接**弹出栈顶**，相当于把这一对消除掉，`c` 也不用入栈了。
3. 如果栈是空的，或者栈顶元素不等于 `c`，那就把 `c` **入栈**。
4. 遍历结束之后，栈中剩下的字符，从栈底到栈顶的顺序，就是最终结果。

那为什么这样做是对的呢？你可以这么理解：栈顶元素始终代表的是"当前处理到的位置往前看，最近一个还没被消除的字符"。当新字符跟栈顶相同的时候，不管后续还会不会继续消除，这一次消除都是必须发生的——因为它们相邻且相同，题目要求把所有这样的对都消除掉。消除之后，栈的新栈顶会自动变成"消除对"之前的那个字符，如果它恰好又跟后面新出现的字符相同，就会在后续遍历中被继续消除，这样就自然实现了"连锁消除"的效果，根本不需要额外的回溯逻辑。

咱们用示例 `"abbaca"` 走一遍看看：
- `a` 入栈，栈：`[a]`
- `b` 与栈顶 `a` 不同，入栈，栈：`[a, b]`
- `b` 与栈顶 `b` 相同，弹出，栈：`[a]`
- `a` 与栈顶 `a` 相同，弹出，栈：`[]`
- `c` 栈空，入栈，栈：`[c]`
- `a` 与栈顶 `c` 不同，入栈，栈：`[c, a]`
- 遍历结束，栈内容 `"ca"` 即为答案。

可以看到，第三步弹出 `b` 之后，栈顶重新变成 `a`，正好跟第四步的新字符 `a` 相同，就触发了连锁消除，全程只用一次线性遍历就搞完了，根本不需要真的多次扫描字符串。

**复杂度分析**：时间复杂度 O(n)，每个字符最多入栈出栈一次；空间复杂度 O(n)，最坏情况下（也就是没有任何相邻重复的情况）所有字符都会留在栈中。

## 代码

### C++

```cpp
class Solution {
public:
    string removeDuplicates(string s) {
        string stack;  // 用 string 当栈用，末尾即栈顶，方便直接作为结果返回
        for (char c : s) {
            if (!stack.empty() && stack.back() == c) {
                stack.pop_back();  // 与栈顶相同，消除这一对
            } else {
                stack.push_back(c);  // 不同，入栈
            }
        }
        return stack;  // 栈中剩余内容即最终结果
    }
};
```

### Java

```java
class Solution {
    public String removeDuplicates(String s) {
        Deque<Character> stack = new ArrayDeque<>();
        for (char c : s.toCharArray()) {
            if (!stack.isEmpty() && stack.peek() == c) {
                stack.pop();  // 与栈顶相同，消除这一对
            } else {
                stack.push(c);  // 不同，入栈
            }
        }
        // ArrayDeque 的栈顶在队首，需要反转后拼接才是正确顺序
        StringBuilder sb = new StringBuilder();
        while (!stack.isEmpty()) {
            sb.append(stack.pollLast());  // 从栈底开始取，还原原始顺序
        }
        return sb.toString();
    }
}
```

### Python

用 `list` 当栈，天然支持按顺序拼接，属于基本操作。

```python
class Solution:
    def removeDuplicates(self, s: str) -> str:
        stack = []
        for c in s:
            if stack and stack[-1] == c:
                stack.pop()  # 与栈顶相同，消除这一对
            else:
                stack.append(c)  # 不同，入栈
        return ''.join(stack)  # 栈底到栈顶的顺序即最终结果
```

### Go

```go
func removeDuplicates(s string) string {
    stack := make([]byte, 0, len(s)) // 用 byte slice 当栈，末尾即栈顶
    for i := 0; i < len(s); i++ {
        c := s[i]
        if len(stack) > 0 && stack[len(stack)-1] == c {
            stack = stack[:len(stack)-1] // 与栈顶相同，消除这一对
        } else {
            stack = append(stack, c) // 不同，入栈
        }
    }
    return string(stack) // 栈中剩余内容即最终结果
}
```

## 总结

- 用栈模拟"消消乐"是这类相邻消除问题的通用套路：栈顶始终代表"当前还未被消除、紧邻下一个字符"的元素，新字符跟栈顶一比较，就能决定是消除还是入栈。
- 这种做法天然支持连锁消除：一次弹出之后，新的栈顶可能恰好又跟后续字符相同，就会自动触发下一轮消除，全程只需要一次线性遍历，不需要显式的回溯或重复扫描，这点挺巧妙的。
- 有个实现细节要注意：Java 因为 `Deque` 的栈顶在数据结构的"头部"，最终需要反转一下顺序才能还原出正确的字符串；而 C++/Python/Go 直接用数组类结构模拟栈，末尾就是栈顶，顺序天然就是对的。
- 这个思路还可以推广到更一般的"栈消除"问题，比如判断字符串经过若干次相邻消除操作后是否能变成空串，或者需要消除的不是"完全相同"而是某种特定关系的字符对，思路都是一样的。
