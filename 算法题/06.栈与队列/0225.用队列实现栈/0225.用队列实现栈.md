# 0225. 用队列实现栈

**题目描述**

仅使用一个或两个队列实现后入先出栈，支持以下操作：

- `push(x)`：将元素 x 压入栈顶
- `pop()`：移除并返回栈顶元素
- `top()`：返回栈顶元素
- `empty()`：判断栈是否为空

```
示例：
输入:
["MyStack", "push", "push", "top", "pop", "empty"]
[[], [1], [2], [], [], []]
输出:
[null, null, null, 2, 2, false]
```

要求：只能使用队列的标准操作（push、peek/front、pop、size、empty）。

## 思路

- 单队列：新元素入队后，将原有元素依次出队再入队，使新元素成为队头。
- 双队列：新元素放入空队列，再转入旧队列全部元素，交换两队列。

两种方法均为 `push` 时间 O(n)，`pop/top/empty` 时间 O(1)，空间 O(n)。



## Python

### LeetCode 写法与原有示例

用 `collections.deque` 作为队列（`popleft` 是 O(1)，若用 `list.pop(0)` 会退化为 O(n)，不适合这里）。

```python
from collections import deque

# 依赖说明：Python 标准库 collections：deque 是双端队列，Counter 是计数器，defaultdict 是带默认值的字典。；len：Python 内置函数：返回容器中元素的数量。；range：Python 内置函数：生成按步长遍历的整数序列。

class MyStack:
    # 方法：__init__；按题目要求处理输入并返回结果，核心算法见方法体。
    def __init__(self):
        self.queue = deque()  # 单队列模拟栈，队头始终是"栈顶"

    # 方法：push；按题目要求处理输入并返回结果，核心算法见方法体。
    def push(self, x: int) -> None:
        self.queue.append(x)          # 新元素入队，排在队尾
        n = len(self.queue)
        for _ in range(n - 1):        # 把 x 前面的旧元素依次挪到它后面
            self.queue.append(self.queue.popleft())
        # x 被转到队头，即栈顶

    # 方法：pop；按题目要求处理输入并返回结果，核心算法见方法体。
    def pop(self) -> int:
        return self.queue.popleft()   # 队头即栈顶

    # 方法：top；按题目要求处理输入并返回结果，核心算法见方法体。
    def top(self) -> int:
        return self.queue[0]          # 队头即栈顶

    # 方法：empty；按题目要求处理输入并返回结果，核心算法见方法体。
    def empty(self) -> bool:
        return len(self.queue) == 0
```

## Go

### LeetCode 写法与原有示例

```go
type MyStack struct {
    queue []int // 用 slice 模拟队列，队头是 queue[0]，队尾是 append 的位置
}

// 方法：Constructor；按题目要求处理输入并返回结果，核心算法见方法体。
func Constructor() MyStack {
    return MyStack{}
}

// 方法：Push；按题目要求处理输入并返回结果，核心算法见方法体。
func (s *MyStack) Push(x int) {
    s.queue = append(s.queue, x) // 新元素入队，排在队尾
    n := len(s.queue)
    for i := 0; i < n-1; i++ { // 把 x 前面的旧元素依次挪到它后面
        front := s.queue[0]
        s.queue = s.queue[1:]             // 队头出队
        s.queue = append(s.queue, front)  // 重新入队，排到队尾
    }
    // x 被转到队头，即栈顶
}

// 方法：Pop；按题目要求处理输入并返回结果，核心算法见方法体。
func (s *MyStack) Pop() int {
    val := s.queue[0] // 队头即栈顶
    s.queue = s.queue[1:]
    return val
}

// 方法：Top；按题目要求处理输入并返回结果，核心算法见方法体。
func (s *MyStack) Top() int {
    return s.queue[0] // 队头即栈顶
}

// 方法：Empty；按题目要求处理输入并返回结果，核心算法见方法体。
func (s *MyStack) Empty() bool {
    return len(s.queue) == 0
}

## C++

### LeetCode 写法与原有示例

```cpp
// 依赖说明：queue/priority_queue：C++ STL 队列容器。

class MyStack {
private:
    queue<int> q;  // 单队列模拟栈，队头始终是"栈顶"

public:
    MyStack() {}

    // 方法：push；按题目要求处理输入并返回结果，核心算法见方法体。
    void push(int x) {
        q.push(x);                     // 新元素先入队，排在队尾
        int n = q.size();
        for (int i = 0; i < n - 1; i++) {  // 把 x 前面的旧元素依次挪到它后面
            q.push(q.front());
            q.pop();
        }
        // 循环结束后，x 被转到了队头，即栈顶
    }

    // 方法：pop；按题目要求处理输入并返回结果，核心算法见方法体。
    int pop() {
        int val = q.front();  // 队头就是栈顶
        q.pop();
        return val;
    }

    // 方法：top；按题目要求处理输入并返回结果，核心算法见方法体。
    int top() {
        return q.front();  // 队头即栈顶
    }

    // 方法：empty；按题目要求处理输入并返回结果，核心算法见方法体。
    bool empty() {
        return q.empty();
    }
};```

## 总结

- 单队列模拟栈的核心技巧就是"push 的时候把新元素之前的所有旧元素重新入队一次"，让新元素始终占据队头这个位置，这样队头就等价于栈顶了。
- 跟双队列写法比起来，单队列版本更省空间，但本质上是同一个思路的两种实现方式：双队列显式区分出"当前队列"和"临时队列"，单队列则是原地绕圈来达到同样的效果。
- 复杂度上跟 0232 题（用栈实现队列）呈一种镜像关系：这里是 push 贵（O(n)）、pop 便宜（O(1)），而且 push 的代价没法像 0232 的 pop 那样被均摊掉，因为每次 push 都必须重新排一次队，没有"复用上次工作"的空间。
- 判断空的逻辑很简单，只需要看底层队列是不是空的就行，不需要额外维护一个计数器。
