# 栈与队列理论基础

栈后进先出，适合括号匹配、表达式求值、DFS；队列先进先出，适合 BFS、按到达顺序处理。

- 数组栈：尾部追加／删除，均摊 O(1)。
- 链表栈：头插／头删，O(1)。
- 循环数组队列：首尾下标循环移动，避免搬移，操作均摊 O(1)。
- 链表队列：维护头尾指针，入队／出队 O(1)。

均需 O(n) 存储；普通数组逐次删除首项会产生 O(n) 搬移。

| 语言 | 栈 | 队列 |
|---|---|---|
| C++ | `stack` | `queue/deque` |
| Java | `ArrayDeque` | `ArrayDeque` |
| Python | `list.append/pop` | `deque.append/popleft` |
| Go | slice 尾部操作 | 环形缓冲区、slice 或 `container/list` |

单调队列需两端操作：队尾淘汰劣候选，队头淘汰过期项。
