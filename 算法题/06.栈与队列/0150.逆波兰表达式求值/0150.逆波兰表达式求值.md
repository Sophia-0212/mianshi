# 0150. 逆波兰表达式求值

**题目描述**

给定一个逆波兰表达式（后缀表达式）的字符串数组 `tokens`，求表达式的值。逆波兰表达式的特点是运算符写在操作数**后面**，不需要括号来决定运算优先级。有效的运算符是 `+`、`-`、`*`、`/`。

```
示例：
输入: tokens = ["2","1","+","3","*"]
输出: 9
解释: 该算式转化为常见的中缀算术表达式为：((2 + 1) * 3) = 9

输入: tokens = ["4","13","5","/","+"]
输出: 6
解释: 该算式转化为中缀表达式为：4 + (13 / 5) = 6
```

要求：假设表达式总是有效的，除数不为 0。

## 思路

后缀表达式有个特别好的地方——你完全不用考虑运算符优先级，也不用管括号。为什么呢？因为运算符出现的位置本身就已经把运算顺序表达清楚了：一个运算符永远作用在它前面**最近的两个操作数**上。你发现了吗，这个"最近"的语义，正好就是栈的 LIFO 特性在起作用。

那具体怎么操作呢：

1. 从左到右遍历 `tokens`。
2. 如果当前这个 token 是数字，直接扔进栈里。
3. 如果是运算符，就从栈里弹出两个数来做运算，算完把结果重新压回栈中。
4. 遍历完了之后，栈里剩的那唯一一个元素，就是最终答案。

这里有个关键点你一定要记住，别搞反了：**弹出顺序**。栈弹两次会拿到两个操作数，第一次弹出来的其实是**右操作数**，第二次弹出来的才是**左操作数**。为什么是这样呢？你想啊，在遍历到运算符之前，两个操作数入栈的顺序是"左操作数先进去、右操作数后进去"（因为后缀表达式里左操作数写在前面，右操作数紧跟着，运算符放在最后）。根据栈的 LIFO 特性，最后进去的右操作数肯定是最先被弹出来的。

我拿示例 `["4","13","5","/","+"]` 带你走一遍：
- `4` 入栈，栈：`[4]`
- `13` 入栈，栈：`[4, 13]`
- `5` 入栈，栈：`[4, 13, 5]`
- 遇到 `/`：第一次弹出 `5`（这是右操作数），第二次弹出 `13`（这是左操作数），算一下 `13 / 5 = 2`（整除），结果入栈，栈：`[4, 2]`
- 遇到 `+`：第一次弹出 `2`（右操作数），第二次弹出 `4`（左操作数），算一下 `4 + 2 = 6`，结果入栈，栈：`[6]`
- 遍历结束，栈里剩下的 `6` 就是答案。

你可能会说，加法和乘法操作数顺序调换了也不影响结果，这确实容易让人放松警惕；但减法和除法可不一样，顺序一旦搞反，结果会完全不同（比如 `13 / 5` 跟 `5 / 13` 差得可不是一点半点），所以一定要严格按"先弹出的是右操作数，后弹出的是左操作数"来写，也就是 `左操作数 运算符 右操作数` 这个顺序，绝对不能写反。

还有一点容易踩坑：不同语言里除法和取整的语义是不一样的。这道题一般要求"截断除法"，也就是结果向零截断，而不是向负无穷取整。C++、Java、Go 的整数除法默认就是截断除法，直接用没问题；但 Python 的 `//` 其实是向负无穷取整（floor division），在负数场景下两者结果会不一样，所以得用 `int(a / b)`，或者手动处理一下符号，才能实现截断语义。

**复杂度分析**：时间复杂度是 O(n)，n 是 `tokens` 的长度，每个 token 只处理一次；空间复杂度也是 O(n)，最坏情况下（全是数字、没有运算符压缩栈）栈里会存下所有数字。

## 代码

### C++

```cpp
class Solution {
public:
    int evalRPN(vector<string>& tokens) {
        stack<int> st;
        for (const string& token : tokens) {
            if (token == "+" || token == "-" || token == "*" || token == "/") {
                int right = st.top(); st.pop();  // 先弹出的是右操作数
                int left = st.top(); st.pop();   // 后弹出的是左操作数
                int result = 0;
                if (token == "+") result = left + right;
                else if (token == "-") result = left - right;
                else if (token == "*") result = left * right;
                else result = left / right;  // C++ 整数除法默认向零截断，符合题目要求
                st.push(result);
            } else {
                st.push(stoi(token));  // 数字直接入栈
            }
        }
        return st.top();  // 最终栈中唯一元素即结果
    }
};
```

### Java

```java
class Solution {
    public int evalRPN(String[] tokens) {
        Deque<Integer> stack = new ArrayDeque<>();
        for (String token : tokens) {
            switch (token) {
                case "+": case "-": case "*": case "/":
                    int right = stack.pop();  // 先弹出的是右操作数
                    int left = stack.pop();   // 后弹出的是左操作数
                    int result;
                    switch (token) {
                        case "+": result = left + right; break;
                        case "-": result = left - right; break;
                        case "*": result = left * right; break;
                        default:  result = left / right; break;  // Java 整数除法向零截断，符合要求
                    }
                    stack.push(result);
                    break;
                default:
                    stack.push(Integer.parseInt(token));  // 数字直接入栈
            }
        }
        return stack.pop();  // 最终栈中唯一元素即结果
    }
}
```

### Python

普通 `list` 当栈用即可，属于基本操作。注意 Python 的 `/` 和 `//` 都不是截断除法（`/` 是浮点除法，`//` 是向负无穷取整），需要用 `int(left / right)` 来实现截断语义。

```python
class Solution:
    def evalRPN(self, tokens: list[str]) -> int:
        stack = []
        operators = {'+', '-', '*', '/'}
        for token in tokens:
            if token in operators:
                right = stack.pop()  # 先弹出的是右操作数
                left = stack.pop()   # 后弹出的是左操作数
                if token == '+':
                    result = left + right
                elif token == '-':
                    result = left - right
                elif token == '*':
                    result = left * right
                else:
                    result = int(left / right)  # 向零截断，而不是用 // 向负无穷取整
                stack.append(result)
            else:
                stack.append(int(token))  # 数字直接入栈
        return stack[-1]  # 最终栈中唯一元素即结果
```

### Go

```go
import (
    "strconv"
)

func evalRPN(tokens []string) int {
    stack := make([]int, 0, len(tokens)) // 用 slice 当栈

    isOperator := func(s string) bool {
        return s == "+" || s == "-" || s == "*" || s == "/"
    }

    for _, token := range tokens {
        if isOperator(token) {
            n := len(stack)
            right := stack[n-1] // 先弹出的是右操作数
            left := stack[n-2]  // 后弹出的是左操作数
            stack = stack[:n-2]

            var result int
            switch token {
            case "+":
                result = left + right
            case "-":
                result = left - right
            case "*":
                result = left * right
            default:
                result = left / right // Go 整数除法向零截断，符合题目要求
            }
            stack = append(stack, result)
        } else {
            num, _ := strconv.Atoi(token) // 数字直接入栈
            stack = append(stack, num)
        }
    }
    return stack[0] // 最终栈中唯一元素即结果
}
```

## 总结

- 说白了，逆波兰表达式天生就适合用栈求值，因为运算符总是作用在"最近的两个操作数"上，跟栈的 LIFO 特性完全对得上，根本不需要处理优先级和括号这些麻烦事。
- 最容易出错的地方就是弹出顺序：第一次弹出的是右操作数，第二次弹出的才是左操作数。加法乘法你搞反了也没事，但减法除法必须严格按这个顺序算，不然结果会完全错。
- 还要留意不同语言的整数除法语义不一样：C++、Java、Go 默认是向零截断，但 Python 得用 `int(left / right)` 显式实现截断，不能直接用 `//`——那个是向负无穷取整,跟题目要求的不是一回事。
- 这道题其实也从另一个角度证明了栈在"表达式求值"这类问题上有多好用——不管是中缀表达式转后缀，还是后缀表达式求值，本质上都是在用栈处理"运算符跟它相邻操作数"之间的匹配关系。
