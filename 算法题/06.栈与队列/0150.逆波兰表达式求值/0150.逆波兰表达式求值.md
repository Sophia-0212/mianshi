# 0150. 逆波兰表达式求值

**题目描述**

给定一个逆波兰表达式（后缀表达式）的字符串数组 `tokens`，求表达式的值。逆波兰表达式的特点是运算符写在操作数**后面**，不需要括号来决定运算优先级。有效的运算符是 `+`、`-`、`*`、`/`。

```
示例：
输入: tokens = ["2","1","+","3","*"]
输出: 9
解释: 该算式转化为常见的中缀算术表达式为：((2 + 1) * 3) = 9

输入: tokens = ["4","13","5","/","+"]
输出: 6
解释: 该算式转化为中缀表达式为：4 + (13 / 5) = 6
```

要求：假设表达式总是有效的，除数不为 0。

## 思路

栈求值：数字入栈；运算符先弹右操作数，再弹左操作数，计算后入栈。除法向零截断，最终栈顶即答案。

时间 O(n)，空间 O(n)。



## Python

### LeetCode 写法与原有示例

普通 `list` 当栈用即可，属于基本操作。注意 Python 的 `/` 和 `//` 都不是截断除法（`/` 是浮点除法，`//` 是向负无穷取整），需要用 `int(left / right)` 来实现截断语义。

```python
class Solution:
    # 方法：evalRPN；按题目要求处理输入并返回结果，核心算法见方法体。
    def evalRPN(self, tokens: list[str]) -> int:
        stack = []
        operators = {'+', '-', '*', '/'}
        for token in tokens:
            if token in operators:
                right = stack.pop()  # 先弹出的是右操作数
                left = stack.pop()   # 后弹出的是左操作数
                if token == '+':
                    result = left + right
                elif token == '-':
                    result = left - right
                elif token == '*':
                    result = left * right
                else:
                    result = int(left / right)  # 向零截断，而不是用 // 向负无穷取整
                stack.append(result)
            else:
                stack.append(int(token))  # 数字直接入栈
        return stack[-1]  # 最终栈中唯一元素即结果
```

## Go

### LeetCode 写法与原有示例

```go
// 依赖说明：Go 标准库 strconv：字符串与数字转换。
import (
    "strconv"
)

// 方法：evalRPN；按题目要求处理输入并返回结果，核心算法见方法体。
func evalRPN(tokens []string) int {
    stack := make([]int, 0, len(tokens)) // 用 slice 当栈

    isOperator := func(s string) bool {
        return s == "+" || s == "-" || s == "*" || s == "/"
    }

    for _, token := range tokens {
        if isOperator(token) {
            n := len(stack)
            right := stack[n-1] // 先弹出的是右操作数
            left := stack[n-2]  // 后弹出的是左操作数
            stack = stack[:n-2]

            var result int
            switch token {
            case "+":
                result = left + right
            case "-":
                result = left - right
            case "*":
                result = left * right
            default:
                result = left / right // Go 整数除法向零截断，符合题目要求
            }
            stack = append(stack, result)
        } else {
            num, _ := strconv.Atoi(token) // 数字直接入栈
            stack = append(stack, num)
        }
    }
    return stack[0] // 最终栈中唯一元素即结果
}```

## C++

### LeetCode 写法与原有示例

```cpp
class Solution {
public:
    // 方法：evalRPN；按题目要求处理输入并返回结果，核心算法见方法体。
    int evalRPN(vector<string>& tokens) {
        stack<int> st;
        for (const string& token : tokens) {
            if (token == "+" || token == "-" || token == "*" || token == "/") {
                int right = st.top(); st.pop();  // 先弹出的是右操作数
                int left = st.top(); st.pop();   // 后弹出的是左操作数
                int result = 0;
                if (token == "+") result = left + right;
                else if (token == "-") result = left - right;
                else if (token == "*") result = left * right;
                else result = left / right;  // C++ 整数除法默认向零截断，符合题目要求
                st.push(result);
            } else {
                st.push(stoi(token));  // 数字直接入栈
            }
        }
        return st.top();  // 最终栈中唯一元素即结果
    }
};
```

## 总结

- 说白了，逆波兰表达式天生就适合用栈求值，因为运算符总是作用在"最近的两个操作数"上，跟栈的 LIFO 特性完全对得上，根本不需要处理优先级和括号这些麻烦事。
- 最容易出错的地方就是弹出顺序：第一次弹出的是右操作数，第二次弹出的才是左操作数。加法乘法你搞反了也没事，但减法除法必须严格按这个顺序算，不然结果会完全错。
- 还要留意不同语言的整数除法语义不一样：C++、Java、Go 默认是向零截断，但 Python 得用 `int(left / right)` 显式实现截断，不能直接用 `//`——那个是向负无穷取整,跟题目要求的不是一回事。
- 这道题其实也从另一个角度证明了栈在"表达式求值"这类问题上有多好用——不管是中缀表达式转后缀，还是后缀表达式求值，本质上都是在用栈处理"运算符跟它相邻操作数"之间的匹配关系。
