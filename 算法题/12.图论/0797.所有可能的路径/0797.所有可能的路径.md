# 797. 所有可能的路径

**题目描述**

给定一个有 `n` 个节点的有向无环图（DAG），节点编号从 `0` 到 `n-1`，用邻接表 `graph` 表示：`graph[i]` 是一个列表，存放节点 `i` 所有的直接后继节点。请找出所有从节点 `0` 到节点 `n-1` 的路径，并以任意顺序返回这些路径（路径本身内部节点顺序是固定的，不能打乱）。

```
示例：
输入: graph = [[1,2],[3],[3],[]]
输出: [[0,1,3],[0,2,3]]
解释: 图中有两条从 0 到 3（n-1=3）的路径：
     0 -> 1 -> 3
     0 -> 2 -> 3
```

因为题目保证是有向无环图，所以不用担心递归死循环；但也正因为要收集"所有"路径，同一个节点可能出现在多条不同的合法路径里，这就决定了这道题不能用一次性标记的 `visited` 数组。

## 思路

这道题本质上就是图论 DFS 回溯的直接应用，跟二叉树的"收集所有路径"题（比如求根到叶子的所有路径）思路完全一致，只是把二叉树的"孩子指针"换成了图的"邻接表邻居"。

**为什么不需要（也不能用）visited 数组**

前面图论深搜理论基础里提到过，`visited` 的使用方式取决于题目类型：

- 如果任务是"遍历一次图、每个节点只处理一次"（比如统计连通分量），那就需要 `visited` 且不撤销，防止同一节点被重复访问导致死循环或重复计算。
- 但如果任务是"穷举所有路径"，同一个节点很可能出现在两条不同的路径中（比如本题的节点 3 就出现在两条路径里）。你想啊，如果给节点 3 打上 `visited = true` 且不撤销，那么第二条路径 `0 -> 2 -> 3` 走到节点 3 的时候会发现"已访问"而被错误地剪掉，这就漏解了。

所以说这道题的"防重复/防死循环"责任不落在 `visited` 数组上，而是落在两点上：

1. **题目保证是有向无环图（DAG）**，天然不存在环，所以即使不加任何标记，DFS 也不会陷入死循环。
2. **用 `path` 数组的增删来实现路径的回溯**：每递归进入一个节点就把它加入 `path` 末尾，递归返回后（不管这条分支是否找到了终点）都要把它从 `path` 末尾移除，这样 `path` 在整个递归过程中始终精确反映"从根到当前节点的路径"，不会把不同分支的节点串到一起。

**递归三部曲**

1. **参数与返回值**：递归函数需要传入图 `graph`、当前节点 `node`；用一个成员变量（或引用参数）`path` 记录当前路径，用另一个成员变量 `result` 收集所有找到的完整路径。不需要显式返回值，直接在递归内部修改 `result`。
2. **终止条件**：当 `node == n - 1`（到达终点）时，说明 `path` 就是一条完整路径，把 `path` 的拷贝加入 `result`，然后 `return`（注意到达终点后不再继续往下遍历，因为图中终点也可能有出边，但题目只要"到达 n-1 的路径"，走到就应该收集并停止这一分支）。
3. **单层搜索逻辑**：遍历 `graph[node]` 里的每一个邻居 `next`，把 `next` 加入 `path`，递归调用 `dfs(graph, next)`，递归返回后把 `next` 从 `path` 末尾弹出（回溯），再继续下一个邻居。

**复杂度分析**

这里的时间复杂度并不是简单的 O(V + E)，因为咱们要穷举所有路径，而 DAG 中从起点到终点的路径数量在最坏情况下（比如完全图结构的 DAG）可以是指数级的，记为 O(2^n)（大致上界，具体证明较复杂，直觉上每个节点都可能"分叉"一次）；每条路径长度最多为 O(n)，拷贝进 `result` 需要 O(n)，所以总的时间复杂度约为 O(2^n · n)。空间复杂度主要是递归栈深度 O(n) 加上 `path` 和 `result` 占用的空间。

## 代码

### C++

```cpp
class Solution {
private:
    vector<vector<int>> result;  // 收集所有满足条件的路径
    vector<int> path;            // 当前递归路径，回溯用

    void dfs(vector<vector<int>>& graph, int node, int n) {
        if (node == n - 1) {          // 终止条件：到达终点 n-1
            result.push_back(path);   // 拷贝当前路径加入结果集
            return;
        }
        for (int next : graph[node]) {  // 遍历当前节点的所有邻居
            path.push_back(next);       // 把邻居加入路径
            dfs(graph, next, n);        // 递归深入这个邻居
            path.pop_back();            // 回溯：撤销刚才加入的节点
        }
    }

public:
    vector<vector<int>> allPathsSourceTarget(vector<vector<int>>& graph) {
        int n = graph.size();
        path.push_back(0);   // 起点 0 先放入路径
        dfs(graph, 0, n);    // 从节点 0 开始搜索
        return result;
    }
};
```

### Java

```java
class Solution {
    private List<List<Integer>> result = new ArrayList<>(); // 收集所有路径
    private LinkedList<Integer> path = new LinkedList<>();  // 当前路径，回溯用

    public List<List<Integer>> allPathsSourceTarget(int[][] graph) {
        int n = graph.length;
        path.add(0);           // 起点 0 先放入路径
        dfs(graph, 0, n);      // 从节点 0 开始搜索
        return result;
    }

    private void dfs(int[][] graph, int node, int n) {
        if (node == n - 1) {                       // 终止条件：到达终点
            result.add(new ArrayList<>(path));      // 拷贝当前路径加入结果
            return;
        }
        for (int next : graph[node]) {   // 遍历当前节点所有邻居
            path.add(next);               // 加入路径
            dfs(graph, next, n);          // 递归深入
            path.removeLast();            // 回溯，撤销加入的节点
        }
    }
}
```

### Python

```python
class Solution:
    def allPathsSourceTarget(self, graph: list[list[int]]) -> list[list[int]]:
        n = len(graph)
        result = []   # 收集所有路径
        path = [0]    # 当前路径，起点 0 先放入

        def dfs(node: int) -> None:
            if node == n - 1:          # 终止条件：到达终点 n-1
                result.append(path[:]) # 拷贝当前路径（切片拷贝，防止后续修改影响已收集结果）
                return
            for next_node in graph[node]:  # 遍历当前节点的所有邻居
                path.append(next_node)      # 加入路径
                dfs(next_node)               # 递归深入这个邻居
                path.pop()                   # 回溯：撤销刚才加入的节点

        dfs(0)  # 从节点 0 开始搜索
        return result
```

### Go

```go
func allPathsSourceTarget(graph [][]int) [][]int {
    n := len(graph)
    result := make([][]int, 0)
    path := []int{0} // 当前路径，起点 0 先放入

    var dfs func(node int)
    dfs = func(node int) {
        if node == n-1 { // 终止条件：到达终点 n-1
            tmp := make([]int, len(path)) // 拷贝当前路径，避免共享底层数组
            copy(tmp, path)
            result = append(result, tmp)
            return
        }
        for _, next := range graph[node] { // 遍历当前节点的所有邻居
            path = append(path, next) // 加入路径
            dfs(next)                 // 递归深入这个邻居
            path = path[:len(path)-1] // 回溯：撤销刚才加入的节点
        }
    }

    dfs(0) // 从节点 0 开始搜索
    return result
}
```

## 总结

- 这道题就是图论 DFS + 回溯模板的直接套用，跟二叉树"收集根到叶子路径"是同一套思路，区别只是邻居来源从"左右孩子"变成了"邻接表"。
- 因为要收集所有路径而不是判断连通性，不能用一次性标记的 `visited`，必须靠 `path` 的"入队-递归-出队"来实现回溯，让每条分支互不干扰。
- 题目保证是有向无环图（DAG），天然无环，所以省去了防死循环的判断，这也是这道题和"钥匙和房间"这种通用图遍历题的关键区别。
- 复杂度不是 O(V+E)，因为路径数本身可能是指数级的，这是"穷举所有解"类图论题的共性，要和"只遍历一次"类题目的复杂度区分开。
