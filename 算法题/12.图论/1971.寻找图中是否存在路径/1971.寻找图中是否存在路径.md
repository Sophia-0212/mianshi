# 1971. 寻找图中是否存在路径

**题目描述**

给定一个包含 n 个节点的无向图，节点编号从 0 到 n-1，`edges` 是一个二维数组，`edges[i] = [ui, vi]` 表示节点 `ui` 和 `vi` 之间存在一条无向边。给定两个节点 `source` 和 `destination`，判断是否存在从 `source` 到 `destination` 的路径（路径可以经过任意数量的中间节点，包括0个）。

```
示例：
输入: n = 3, edges = [[0,1],[1,2],[2,0]], source = 0, destination = 2
输出: true
解释: 0 -> 1 -> 2 或者 0 -> 2 都可以到达

输入: n = 6, edges = [[0,1],[0,2],[3,5],[5,4],[4,3]], source = 0, destination = 5
输出: false
解释: 0 和 5 分别在两个不连通的分量里，无法互相到达
```

## 思路

- 并查集：合并每条无向边的端点，比较起终点根是否相同。当前仅路径压缩，时间 O((V+E)log V) 上界，辅助空间 O(V)；加按秩合并可为 O(V+Eα(V))。
- DFS/BFS：建邻接表，从起点搜索，访问到终点即成功。时间、空间 O(V+E)，含建图。

# 依赖说明：range：Python 内置函数：生成按步长遍历的整数序列。

class Solution:
    # 方法：validPath；按题目要求处理输入并返回结果，核心算法见方法体。
    def validPath(self, n: int, edges: list[list[int]], source: int, destination: int) -> bool:
        parent = list(range(n))  # 初始化，每个节点的父节点是自己

        # 方法：find；按题目要求处理输入并返回结果，核心算法见方法体。
        def find(x: int) -> int:
            if parent[x] != x:
                parent[x] = find(parent[x])  # 路径压缩
            return parent[x]

        # 方法：union；按题目要求处理输入并返回结果，核心算法见方法体。
        def union(x: int, y: int) -> None:
            root_x, root_y = find(x), find(y)
            if root_x != root_y:
                parent[root_x] = root_y  # 合并两个集合

        for u, v in edges:
            union(u, v)  # 把每条边的两个端点合并

        return find(source) == find(destination)  # 判断是否属于同一集合```

## C++

### LeetCode 写法与原有示例

```cpp
class Solution {
public:
    vector<int> parent;  // 并查集的父节点数组

    // 方法：find；按题目要求处理输入并返回结果，核心算法见方法体。
    int find(int x) {
        if (parent[x] != x) {
            parent[x] = find(parent[x]);  // 路径压缩：递归查找根节点，同时把路径上的节点直接接到根节点
        }
        return parent[x];
    }

    // 方法：unite；按题目要求处理输入并返回结果，核心算法见方法体。
    void unite(int x, int y) {
        int rootX = find(x), rootY = find(y);
        if (rootX != rootY) {
            parent[rootX] = rootY;  // 把 x 的根接到 y 的根下面，合并两个集合
        }
    }

    // 方法：validPath；按题目要求处理输入并返回结果，核心算法见方法体。
    bool validPath(int n, vector<vector<int>>& edges, int source, int destination) {
        parent.resize(n);
        for (int i = 0; i < n; i++) {
            parent[i] = i;  // 初始化，每个节点的父节点是自己
        }
        for (auto& edge : edges) {
            unite(edge[0], edge[1]);  // 把每条边的两个端点合并到同一个集合
        }
        return find(source) == find(destination);  // 根节点相同说明连通
    }
};
```

## 总结

- 这道题是并查集最基础的应用：把每条边的两个端点合并到同一集合，最后判断两个目标节点是否属于同一集合。
- 因为这道题是静态图、只查询一次连通性，DFS/BFS 遍历一次同样能解决，复杂度相当；并查集的优势要在"边动态增加"或"多次查询"的场景下才能体现出来。
- 路径压缩是并查集能保持接近 O(1) 查询效率的关键，写 `find` 函数时要记得在回溯路径上把节点直接接到根节点，而不是简单地逐级向上找。
