# 127. 单词接龙

**题目描述**

给定两个单词 `beginWord` 和 `endWord`，以及一个字典 `wordList`。规则是：每次转换只能改变单词中的一个字母，并且每次转换得到的中间单词都必须存在于 `wordList` 中。求从 `beginWord` 转换到 `endWord` 的最短转换序列的**单词个数**（包含 `beginWord` 和 `endWord` 本身）。如果不存在这样的转换序列，返回 0。

```
示例：
输入: beginWord = "hit", endWord = "cog"
      wordList = ["hot","dot","dog","lot","log","cog"]
输出: 5
解释: 最短转换序列是 "hit" -> "hot" -> "dot" -> "dog" -> "cog"，共 5 个单词
```

```
示例：
输入: beginWord = "hit", endWord = "cog"
      wordList = ["hot","dot","dog","lot","log"]
输出: 0
解释: endWord "cog" 不在 wordList 中，无法转换
```

## 思路

BFS：单词为节点，相差一个字母即相邻。从 `beginWord` 分层搜索，枚举每位的 26 种替换，字典中未访问的词入队并立即标记。首次到达终点返回层数，包含起点；终点不在字典或不可达返回 0。

时间 O(NL²)，空间 O(NL)，N 为单词数，L 为词长，含字符串构造与哈希开销。

from collections import deque

# 依赖说明：Python 标准库 collections：deque 是双端队列，Counter 是计数器，defaultdict 是带默认值的字典。；len：Python 内置函数：返回容器中元素的数量。；range：Python 内置函数：生成按步长遍历的整数序列。

class Solution:
    # 方法：ladderLength；按题目要求处理输入并返回结果，核心算法见方法体。
    def ladderLength(self, beginWord: str, endWord: str, wordList: list[str]) -> int:
        word_set = set(wordList)  # 单词表转哈希集合，便于 O(1) 查找
        if endWord not in word_set:
            return 0  # 终点不在字典里，不可能转换成功

        queue = deque([beginWord])
        word_set.discard(beginWord)  # 起点从候选集合移除，充当 visited 标记
        step = 1  # 序列长度从 1 开始，因为要把 beginWord 自己计入

        while queue:
            level_size = len(queue)  # 固定当前层的元素个数，实现按层扩展
            for _ in range(level_size):
                cur = queue.popleft()
                for i in range(len(cur)):  # 枚举单词的每一位
                    for c in "abcdefghijklmnopqrstuvwxyz":  # 枚举该位替换成的每个字母
                        if c == cur[i]:
                            continue  # 跳过原字母
                        next_word = cur[:i] + c + cur[i + 1:]  # 构造替换后的新单词
                        if next_word == endWord:
                            return step + 1  # 命中终点，返回长度
                        if next_word in word_set:
                            word_set.discard(next_word)  # 标记 visited
                            queue.append(next_word)         # 加入下一层队列
            step += 1  # 当前层处理完毕，进入下一层
        return 0  # 队列耗尽仍未到达终点，无法转换```

## Go

### LeetCode 写法与原有示例

```go
// 方法：ladderLength；按题目要求处理输入并返回结果，核心算法见方法体。
func ladderLength(beginWord string, endWord string, wordList []string) int {
    wordSet := make(map[string]bool) // 单词表转哈希集合，便于 O(1) 查找
    for _, w := range wordList {
        wordSet[w] = true
    }
    if !wordSet[endWord] {
        return 0 // 终点不在字典里，不可能转换成功
    }

    queue := []string{beginWord}
    delete(wordSet, beginWord) // 起点从候选集合移除，充当 visited 标记
    step := 1                  // 序列长度从 1 开始，因为要把 beginWord 自己计入

    for len(queue) > 0 {
        levelSize := len(queue) // 固定当前层的元素个数，实现按层扩展
        for i := 0; i < levelSize; i++ {
            cur := queue[0]
            queue = queue[1:]
            bytes := []byte(cur)
            for j := 0; j < len(bytes); j++ { // 枚举单词的每一位
                origin := bytes[j]
                for c := byte('a'); c <= 'z'; c++ { // 枚举该位替换成的每个字母
                    if c == origin {
                        continue // 跳过原字母
                    }
                    bytes[j] = c
                    next := string(bytes)
                    if next == endWord {
                        return step + 1 // 命中终点，返回长度
                    }
                    if wordSet[next] {
                        delete(wordSet, next)          // 标记 visited
                        queue = append(queue, next)    // 加入下一层队列
                    }
                }
                bytes[j] = origin // 恢复原字母，继续枚举下一位
            }
        }
        step++ // 当前层处理完毕，进入下一层
    }
    return 0 // 队列耗尽仍未到达终点，无法转换
}
```

## C++

### LeetCode 写法与原有示例

```cpp
class Solution {
public:
    // 方法：ladderLength；按题目要求处理输入并返回结果，核心算法见方法体。
    int ladderLength(string beginWord, string endWord, vector<string>& wordList) {
        unordered_set<string> wordSet(wordList.begin(), wordList.end()); // 单词表转哈希集合，便于 O(1) 查找
        if (wordSet.find(endWord) == wordSet.end()) {
            return 0; // 终点不在字典里，不可能转换成功
        }

        queue<string> q;
        q.push(beginWord);
        wordSet.erase(beginWord); // 起点不需要再作为候选边，顺便充当 visited 标记
        int step = 1; // 序列长度从 1 开始，因为要把 beginWord 自己计入

        while (!q.empty()) {
            int levelSize = q.size(); // 固定当前层的元素个数，实现按层扩展
            for (int i = 0; i < levelSize; i++) {
                string cur = q.front();
                q.pop();
                for (int j = 0; j < (int)cur.size(); j++) { // 枚举单词的每一位
                    char origin = cur[j];
                    for (char c = 'a'; c <= 'z'; c++) { // 枚举该位替换成的每个字母
                        if (c == origin) continue; // 跳过原字母，没有变化不算一次转换
                        cur[j] = c;
                        if (cur == endWord) {
                            return step + 1; // 命中终点，返回长度
                        }
                        if (wordSet.count(cur)) {
                            wordSet.erase(cur); // 从候选集合移除，等同于标记 visited
                            q.push(cur);         // 加入下一层队列
                        }
                    }
                    cur[j] = origin; // 恢复原字母，继续枚举下一位
                }
            }
            step++; // 当前层处理完毕，进入下一层
        }
        return 0; // 队列耗尽仍未到达终点，无法转换
    }
};
```

## 总结

- 这道题的核心就是"隐式建图"：咱们不预先枚举所有单词对之间的边，而是在 BFS 扩展的时候，对当前单词的每一位尝试替换 26 个字母，动态判断是否存在到某个邻居单词的边，这样就省去了 O(N²) 级别的建图开销。
- 必须用 BFS 而不是 DFS，因为这道题求的是最短转换序列的长度，BFS 是按层扩散的，第一次到达终点的层数就是最短路径长度；而 DFS 只能找到某一条可行路径，没法保证是最短的，要保证最短就得穷举全部路径，代价是指数级的。
- 用哈希集合而不是数组来存 `wordList`，是为了把"新单词是否可达"的判断从 O(N) 降到 O(1)；而把已访问单词直接从哈希集合里删掉，就省去了单独维护一个 `visited` 集合的空间。
- 整体时间复杂度约 O(N × 26 × L²)，这里 26×L 是每个单词能枚举出的邻居数量上限，L² 来自构造新字符串和哈希计算的开销；空间复杂度 O(N)，用在哈希集合和 BFS 队列上。
