# 127. 单词接龙

**题目描述**

给定两个单词 `beginWord` 和 `endWord`，以及一个字典 `wordList`。规则是：每次转换只能改变单词中的一个字母，并且每次转换得到的中间单词都必须存在于 `wordList` 中。求从 `beginWord` 转换到 `endWord` 的最短转换序列的**单词个数**（包含 `beginWord` 和 `endWord` 本身）。如果不存在这样的转换序列，返回 0。

```
示例：
输入: beginWord = "hit", endWord = "cog"
      wordList = ["hot","dot","dog","lot","log","cog"]
输出: 5
解释: 最短转换序列是 "hit" -> "hot" -> "dot" -> "dog" -> "cog"，共 5 个单词
```

```
示例：
输入: beginWord = "hit", endWord = "cog"
      wordList = ["hot","dot","dog","lot","log"]
输出: 0
解释: endWord "cog" 不在 wordList 中，无法转换
```

## 思路

**如何把单词转换问题建模成图**

你看这道题表面上是个字符串变换的问题，但其实本质上就是一个最短路径问题。所以第一步咱们要做的，是把它"翻译"成图论的语言：把 `wordList` 里的每个单词看成图上的一个节点，如果两个单词只相差一个字母（也就是长度相同，恰好有一位字符不一样），那就认为它们之间连了一条边——因为一次合法的转换，说白了就是沿着这条边走一步。

这里的关键点是，这张图**不需要提前构造出来**。为什么呢？如果真的两两去比较 `wordList` 里所有单词对来建边，那需要 O(N²·L) 的时间（N 是单词数，L 是单词长度），当 N 比较大的时候就很浪费了。所以更好的做法是**隐式建图**：在 BFS 扩展某个单词的时候，咱们不去查"这个单词在图里连了哪些边"，而是主动去构造它的所有"邻居"——对当前单词的每一位，依次尝试替换成 `a` 到 `z` 这 26 个字母（跳过原字母），得到一个新单词，再看看这个新单词是不是在 `wordList` 的哈希集合里。如果在，就说明这条边是真实存在的，这个新单词就是一个可以扩展过去的邻居节点。这样一来，"建边"这个动作其实是被延迟到了 BFS 遍历的过程中按需生成的，就省去了预处理整张图的开销。

**为什么必须用 BFS，不能用 DFS**

题目要求的是"最短转换序列的长度"，这其实是一个标准的**无权图最短路径问题**。前面理论基础篇里提到过，BFS 的遍历方式是按"层"扩散的——第一层是起点能直接到达的所有节点，第二层是从第一层节点再走一步能到达的所有节点，以此类推。因为每一步转换的"代价"都是一样的（都是改变一个字母），所以 BFS 第一次到达 `endWord` 的时候所在的层数，就精确对应了从 `beginWord` 出发的最短转换步数，这是 BFS 天然就有的性质，不需要额外证明或者比较。

那如果换成 DFS 会怎么样呢？情况就完全不一样了。DFS 的遍历方式是"一条路走到底"——从 `beginWord` 出发，选一个方向的邻居往下钻，走不通了再回溯换个方向。这样做即使最终能找到一条从 `beginWord` 到 `endWord` 的路径，也**完全不能保证这是最短的那条**，因为 DFS 找到的第一条路径可能绕了很多不必要的弯路。要用 DFS 求出真正的最短路径，唯一的办法就是把所有可能的转换路径都穷举出来，记录每条路径的长度，最后取最小值——但转换路径的数量可能是指数级的（每一步都有多个邻居可选，路径数会随长度指数增长），这样做就完全失去效率了，不可接受。所以说，本题这种最短路径的性质，就决定了必须用 BFS，不能用 DFS。

**具体实现步骤**

1. 先把 `wordList` 存入一个哈希集合 `wordSet`，方便 O(1) 判断某个单词是否存在。如果 `endWord` 不在 `wordSet` 里，直接返回 0（不可能转换成功）。
2. 用一个队列做 BFS，初始把 `beginWord` 放入队列，同时用一个 `visited` 集合记录已经访问过的单词（防止同一个单词被重复加入队列造成死循环或重复计算）。也可以不单独开 `visited` 集合，而是每访问到一个单词就直接把它从 `wordSet` 里移除，效果完全一样，还能省掉一个数据结构。
3. 维护一个层数计数器 `step`，初始为 1（因为最终返回的单词个数要把 `beginWord` 自己算进去，所以从 1 开始而不是从 0 开始）。
4. 每一轮从队列中取出**当前这一层的所有单词**（这是 BFS 按层扩展的标准写法：先记录当前队列长度，只处理这么多个元素，新扩展出的邻居放入队列尾部，自然形成下一层），对每个单词的每一位字符尝试替换成 `a` 到 `z`（跳过原字符，一共尝试 `26 × L` 种可能，`L` 是单词长度）：
   - 如果替换后的新单词等于 `endWord`，说明到达终点，返回 `step + 1`。
   - 如果新单词存在于 `wordSet` 中且未被访问过，标记为已访问（或从 `wordSet` 中移除），并加入下一层队列。
5. 处理完当前层所有单词后，`step` 加 1，继续处理下一层，直到队列为空。如果队列耗尽仍未找到 `endWord`，说明无法转换，返回 0。

**复杂度分析**

咱们设 `wordList` 长度为 N，单词长度为 L。每个从队列中取出的单词，需要尝试 `26 × L` 种字符替换，每种替换要花 O(L) 的时间构造新字符串，再花费接近 O(L)（哈希计算本身也和字符串长度相关）的时间去哈希集合里查找。所以每个单词的处理开销是 O(26 × L²)，最多有 N 个单词会被处理（每个单词只入队一次），因此总的时间复杂度约为 **O(N × 26 × L²)**，可以近似看成 O(N·L²)。空间复杂度是 **O(N)**，主要开销在哈希集合 `wordSet` 和 BFS 队列上，最坏情况下所有单词都会被存进去。

## 代码

### C++

```cpp
class Solution {
public:
    int ladderLength(string beginWord, string endWord, vector<string>& wordList) {
        unordered_set<string> wordSet(wordList.begin(), wordList.end()); // 单词表转哈希集合，便于 O(1) 查找
        if (wordSet.find(endWord) == wordSet.end()) {
            return 0; // 终点不在字典里，不可能转换成功
        }

        queue<string> q;
        q.push(beginWord);
        wordSet.erase(beginWord); // 起点不需要再作为候选边，顺便充当 visited 标记
        int step = 1; // 序列长度从 1 开始，因为要把 beginWord 自己计入

        while (!q.empty()) {
            int levelSize = q.size(); // 固定当前层的元素个数，实现按层扩展
            for (int i = 0; i < levelSize; i++) {
                string cur = q.front();
                q.pop();
                for (int j = 0; j < (int)cur.size(); j++) { // 枚举单词的每一位
                    char origin = cur[j];
                    for (char c = 'a'; c <= 'z'; c++) { // 枚举该位替换成的每个字母
                        if (c == origin) continue; // 跳过原字母，没有变化不算一次转换
                        cur[j] = c;
                        if (cur == endWord) {
                            return step + 1; // 命中终点，返回长度
                        }
                        if (wordSet.count(cur)) {
                            wordSet.erase(cur); // 从候选集合移除，等同于标记 visited
                            q.push(cur);         // 加入下一层队列
                        }
                    }
                    cur[j] = origin; // 恢复原字母，继续枚举下一位
                }
            }
            step++; // 当前层处理完毕，进入下一层
        }
        return 0; // 队列耗尽仍未到达终点，无法转换
    }
};
```

```java
class Solution {
    public int ladderLength(String beginWord, String endWord, List<String> wordList) {
        Set<String> wordSet = new HashSet<>(wordList); // 单词表转哈希集合，便于 O(1) 查找
        if (!wordSet.contains(endWord)) {
            return 0; // 终点不在字典里，不可能转换成功
        }

        Queue<String> queue = new LinkedList<>();
        queue.offer(beginWord);
        wordSet.remove(beginWord); // 起点从候选集合移除，充当 visited 标记
        int step = 1; // 序列长度从 1 开始，因为要把 beginWord 自己计入

        while (!queue.isEmpty()) {
            int levelSize = queue.size(); // 固定当前层的元素个数，实现按层扩展
            for (int i = 0; i < levelSize; i++) {
                String cur = queue.poll();
                char[] chars = cur.toCharArray();
                for (int j = 0; j < chars.length; j++) { // 枚举单词的每一位
                    char origin = chars[j];
```

### Python

```python
from collections import deque

class Solution:
    def ladderLength(self, beginWord: str, endWord: str, wordList: list[str]) -> int:
        word_set = set(wordList)  # 单词表转哈希集合，便于 O(1) 查找
        if endWord not in word_set:
            return 0  # 终点不在字典里，不可能转换成功

        queue = deque([beginWord])
        word_set.discard(beginWord)  # 起点从候选集合移除，充当 visited 标记
        step = 1  # 序列长度从 1 开始，因为要把 beginWord 自己计入

        while queue:
            level_size = len(queue)  # 固定当前层的元素个数，实现按层扩展
            for _ in range(level_size):
                cur = queue.popleft()
                for i in range(len(cur)):  # 枚举单词的每一位
                    for c in "abcdefghijklmnopqrstuvwxyz":  # 枚举该位替换成的每个字母
                        if c == cur[i]:
                            continue  # 跳过原字母
                        next_word = cur[:i] + c + cur[i + 1:]  # 构造替换后的新单词
                        if next_word == endWord:
                            return step + 1  # 命中终点，返回长度
                        if next_word in word_set:
                            word_set.discard(next_word)  # 标记 visited
                            queue.append(next_word)         # 加入下一层队列
            step += 1  # 当前层处理完毕，进入下一层
        return 0  # 队列耗尽仍未到达终点，无法转换
```

### Go

```go
func ladderLength(beginWord string, endWord string, wordList []string) int {
    wordSet := make(map[string]bool) // 单词表转哈希集合，便于 O(1) 查找
    for _, w := range wordList {
        wordSet[w] = true
    }
    if !wordSet[endWord] {
        return 0 // 终点不在字典里，不可能转换成功
    }

    queue := []string{beginWord}
    delete(wordSet, beginWord) // 起点从候选集合移除，充当 visited 标记
    step := 1                  // 序列长度从 1 开始，因为要把 beginWord 自己计入

    for len(queue) > 0 {
        levelSize := len(queue) // 固定当前层的元素个数，实现按层扩展
        for i := 0; i < levelSize; i++ {
            cur := queue[0]
            queue = queue[1:]
            bytes := []byte(cur)
            for j := 0; j < len(bytes); j++ { // 枚举单词的每一位
                origin := bytes[j]
                for c := byte('a'); c <= 'z'; c++ { // 枚举该位替换成的每个字母
                    if c == origin {
                        continue // 跳过原字母
                    }
                    bytes[j] = c
                    next := string(bytes)
                    if next == endWord {
                        return step + 1 // 命中终点，返回长度
                    }
                    if wordSet[next] {
                        delete(wordSet, next)          // 标记 visited
                        queue = append(queue, next)    // 加入下一层队列
                    }
                }
                bytes[j] = origin // 恢复原字母，继续枚举下一位
            }
        }
        step++ // 当前层处理完毕，进入下一层
    }
    return 0 // 队列耗尽仍未到达终点，无法转换
}
```

## 总结

- 这道题的核心就是"隐式建图"：咱们不预先枚举所有单词对之间的边，而是在 BFS 扩展的时候，对当前单词的每一位尝试替换 26 个字母，动态判断是否存在到某个邻居单词的边，这样就省去了 O(N²) 级别的建图开销。
- 必须用 BFS 而不是 DFS，因为这道题求的是最短转换序列的长度，BFS 是按层扩散的，第一次到达终点的层数就是最短路径长度；而 DFS 只能找到某一条可行路径，没法保证是最短的，要保证最短就得穷举全部路径，代价是指数级的。
- 用哈希集合而不是数组来存 `wordList`，是为了把"新单词是否可达"的判断从 O(N) 降到 O(1)；而把已访问单词直接从哈希集合里删掉，就省去了单独维护一个 `visited` 集合的空间。
- 整体时间复杂度约 O(N × 26 × L²)，这里 26×L 是每个单词能枚举出的邻居数量上限，L² 来自构造新字符串和哈希计算的开销；空间复杂度 O(N)，用在哈希集合和 BFS 队列上。
