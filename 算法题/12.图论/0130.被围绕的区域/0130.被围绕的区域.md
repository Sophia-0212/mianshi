# 0130. 被围绕的区域

**题目描述**

给定一个 `m x n` 的二维网格 `board`，网格中只包含两种字符：`'X'` 和 `'O'`。找到所有被 `'X'` 完全包围的区域，把这些区域里的每一个 `'O'` 都变成 `'X'`。

这里"包围"有一个特殊规则：**如果一个 `'O'` 区域和网格边界上的 `'O'` 直接或间接相连（上下左右方向），那么这个区域就不算被包围**，要原样保留，不能替换。只有那些完全被 `'X'` 包裹、无法通过相邻的 `'O'` 走到边界的区域，才会被替换成 `'X'`。

```
示例：
输入：
board = [
  ["X","X","X","X"],
  ["X","O","O","X"],
  ["X","X","O","X"],
  ["X","O","X","X"]
]
输出：
board = [
  ["X","X","X","X"],
  ["X","X","X","X"],
  ["X","X","X","X"],
  ["X","O","X","X"]
]
解释：中间那一片 O（(1,1)(1,2)(2,2)）没有任何一个格子挨着边界，被 X 完全包围，所以全部变成 X。
但是 (3,1) 这个 O 本身就在网格的边界上（最后一行），它不算被包围，原样保留。
```

## 思路

从四条边界的 `O` 出发，用 DFS/BFS 标记所有连通的 `O`。再次遍历：未标记的 `O` 改为 `X`，已标记的恢复为 `O`。

时间 O(mn)，空间 O(mn)（递归栈或队列）。

### LeetCode 写法与原有示例

图论题这里没有能一行解决的标准库函数，直接给手写 DFS 实现：

```python
# 依赖说明：len：Python 内置函数：返回容器中元素的数量。；range：Python 内置函数：生成按步长遍历的整数序列。

class Solution:
    # 方法：solve；按题目要求处理输入并返回结果，核心算法见方法体。
    def solve(self, board: list[list[str]]) -> None:
        if not board:
            return
        m, n = len(board), len(board[0])

        # 方法：dfs；按题目要求处理输入并返回结果，核心算法见方法体。
        def dfs(row: int, col: int) -> None:
            # 越界或不是待标记的 O，直接终止
            if row < 0 or row >= m or col < 0 or col >= n:
                return
            if board[row][col] != 'O':
                return
            board[row][col] = 'A'  # 标记为安全区，防止重复访问
            dfs(row - 1, col)  # 上
            dfs(row + 1, col)  # 下
            dfs(row, col - 1)  # 左
            dfs(row, col + 1)  # 右

        # 第一遍：只从四条边界出发标记安全区
        for i in range(m):
            dfs(i, 0)      # 最左列
            dfs(i, n - 1)  # 最右列
        for j in range(n):
            dfs(0, j)      # 最上行
            dfs(m - 1, j)  # 最下行

        # 第二遍：把没被标记的 O 变成 X，把标记过的 A 还原成 O
        for i in range(m):
            for j in range(n):
                if board[i][j] == 'O':
                    board[i][j] = 'X'  # 被围住，替换
                elif board[i][j] == 'A':
                    board[i][j] = 'O'  # 安全，还原```

## C++

### LeetCode 写法与原有示例

```cpp
class Solution {
public:
    // 方法：solve；按题目要求处理输入并返回结果，核心算法见方法体。
    void solve(vector<vector<char>>& board) {
        int m = board.size(), n = board[0].size();

        // 从 (row, col) 出发做 DFS，把相连的 'O' 标记为安全字符 'A'
        function<void(int, int)> dfs = [&](int row, int col) {
            if (row < 0 || row >= m || col < 0 || col >= n) return; // 越界，终止
            if (board[row][col] != 'O') return; // 不是待标记的 O，终止（包括已标记过的 A）
            board[row][col] = 'A'; // 标记为安全区，防止重复访问，同时作为最终还原的依据
            dfs(row - 1, col); // 上
            dfs(row + 1, col); // 下
            dfs(row, col - 1); // 左
            dfs(row, col + 1); // 右
        };

        // 第一遍：只从四条边界出发标记安全区
        for (int i = 0; i < m; i++) {
            dfs(i, 0);     // 最左列
            dfs(i, n - 1); // 最右列
        }
        for (int j = 0; j < n; j++) {
            dfs(0, j);     // 最上行
            dfs(m - 1, j); // 最下行
        }

        // 第二遍：把没被标记的 O 变成 X，把标记过的 A 还原成 O
        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                if (board[i][j] == 'O') board[i][j] = 'X'; // 未连到边界，被围住，替换
                else if (board[i][j] == 'A') board[i][j] = 'O'; // 连到边界，安全，还原
            }
        }
    }
};
```

## 总结

- 判断"是否被包围"这类否定性条件，正面枚举每个点去验证往往效率低，逻辑也绕；反过来先标记"一定不会被处理"的部分（本题就是连到边界的 `'O'`），再统一处理剩余部分，这样做才是更清晰也更高效的思路。
- 这道题的标记阶段本质上就是在网格上做连通分量的 DFS/BFS，只不过搜索的起点固定在边界格子，而不是任意格子。
- 它和 1020 题"飞地的数量"共享同一套"边界出发标记安全区 + 二次遍历"模板，区别仅在于最后一步是做统计计数还是做原地修改，这就说明同一套图论范式其实可以套用在不同的输出需求上。
- 用临时字符（比如 `'A'`）代替额外的 `visited` 数组，既完成了标记去重，也天然区分出了三种最终状态（安全区、被围区、原始 X），这是网格类问题里常见的一个空间优化技巧。
