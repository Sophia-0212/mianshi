# 0827. 最大人工岛

**题目描述**

给定一个 `n x n` 的二维网格 `grid`，每个格子的值是 `0`（水域）或 `1`（陆地）。规则规定：**最多可以选择一个海洋格子（值为 0），把它变成陆地（值为 1）**，求执行这个操作之后，能得到的最大岛屿面积（岛屿由上下左右相邻的陆地组成一片连通区域）。

需要注意两种边界情况：如果网格中已经没有任何海洋格子（全是陆地），说明无法再填海，直接返回整个网格的陆地总数；如果填了某个海洋格子后面积反而不比原来任何一个岛屿更大，也要正确地返回填海后能得到的最大值（而不是漏判）。

```
示例：
输入：
grid = [
  [1,0],
  [0,1]
]
输出：3
解释：网格里有两个独立的岛屿，面积都是 1。把 (0,1) 或 (1,0) 这个海洋格子填成陆地后，
可以把两个岛屿连起来，得到一个面积为 3 的岛屿（1 + 1 + 新填的这 1 格）。
```

## 思路

这道题是”岛屿最大面积”（695 题）的进阶版：如果只是求已有网格中最大的岛屿面积，直接对每个未访问的陆地格子做一次 DFS/BFS 统计面积就够了。但这题多了一个”可以填一个海洋格子”的操作，而填海之后，这个新陆地格子可能会把周围**多个原本不连通的岛屿连成一片**，面积就不是简单的”某个岛屿面积 + 1”了，而是”周围所有不同岛屿面积之和 + 1”。

如果按照最朴素的想法——对每个海洋格子，真的把它改成陆地，然后重新跑一次全网格的岛屿面积统计，再改回来——这样对每个海洋格子都要花 O(n²) 去重新扫描整个网格，海洋格子最多有 O(n²) 个，总复杂度会退化到 O(n⁴)，对大网格是不可接受的。

更好的做法是分成两个阶段，**预处理阶段** + **枚举阶段**，两个阶段各自只需要一次线性扫描。

**第一阶段：预处理，给每个岛屿编号并记录面积**

遍历整个网格，对每一个还没访问过的陆地格子（值为 1），做一次 DFS，但这次 DFS 不是简单地标记 `true/false`，而是**给这个岛屿分配一个唯一的编号**，编号从 2 开始（因为网格里原本只用 0 表示水、1 表示陆地，如果编号也从 0 或 1 开始就会跟原始数据混在一起，没法区分；从 2 开始就能保证编号本身携带信息，同时天然区分了”水域””未编号陆地”和”已编号陆地”这几种状态——不过这道题里陆地会全部编号完，所以只需要区分 0 和 >=2 的编号）。DFS 过程中，把这个岛屿包含的所有陆地格子都改写成这个编号，同时用一个哈希表 `areaOfIsland` 记录 `编号 -> 该岛屿的格子总数（面积）`。

这一步做完之后，网格里的每个陆地格子都不再是单纯的 `1`，而是变成了它所属岛屿的编号；水域格子仍然是 `0`。

**第二阶段：枚举每个海洋格子，计算填海后的面积**

遍历网格中所有值为 `0` 的海洋格子，对每一个海洋格子，看看它上下左右四个方向的相邻格子（跳过越界和仍然是水域的方向）。如果相邻格子是陆地，它上面记录的就是所属岛屿的编号，把这些编号收集到一个**集合（Set）**里——这里用集合而不是列表是关键：因为同一个海洋格子的多个方向可能都连到了同一个岛屿（比如上方和左方恰好是同一片岛屿伸出来的两个角），如果不用集合去重，直接把这两个方向对应的面积都累加进去，就会把同一个岛屿的面积重复计算两次，导致结果偏大。

用集合收集完这个海洋格子四周所有**不同**的岛屿编号之后，把这些编号在 `areaOfIsland` 里对应的面积依次累加，再加上填海本身新增的这 1 格面积，就得到了”把这个海洋格子填成陆地后，能形成的岛屿面积”。用这个值去更新一个全局最大值 `maxArea`。

把所有海洋格子都枚举一遍之后，`maxArea` 就是答案。

**为什么必须先分配编号，不能只用简单的 true/false 标记**

你想啊，如果预处理阶段只是把陆地标记成”已访问”（布尔值），那么在第二阶段枚举海洋格子的时候，看到某个方向是”已访问的陆地”，只能知道”这个方向有陆地”，却无法判断”上边的陆地”和”左边的陆地”是不是属于同一个岛屿。如果它们实际上是同一个岛屿（比如一个 U 形的岛屿，从中间凹进去的海洋格子看，上边和左边都连到了这个 U 形岛屿的两侧），布尔标记就区分不了了，只能把两侧都当成”有效邻居”分别累加面积，这样就会把同一个岛屿的面积算了两次，结果比实际值虚高。只有先给每个岛屿分配一个能相互区分的唯一编号，才能在第二阶段通过编号是否相同来判断”这几个方向连到的是不是同一个岛屿”，从而用集合正确去重。

**边界情况处理**

如果网格中根本没有海洋格子（所有格子都是陆地），说明一个岛屿都填不了，此时应该直接返回网格的陆地总数，也就是 `n * n`（因为整个网格已经连成一片，不需要再枚举）。这个判断可以放在主逻辑最后：如果遍历完所有海洋格子后 `maxArea` 仍然是初始值（说明网格里没有 0），就返回 `n*n` 或者原有各岛屿面积的最大值中的较大者；更直接的写法是在枚举前先检查网格中是否存在 0，不存在就直接返回 `n*n`。

**复杂度分析**

设网格边长为 `n`。第一阶段的 DFS 给所有岛屿编号，每个陆地格子只会被访问一次，复杂度 O(n²)；第二阶段遍历所有海洋格子，每个格子只查看常数个（4 个）方向，复杂度 O(n²)。两阶段加起来总时间复杂度 O(n²)，空间复杂度主要是编号哈希表和递归栈，O(n²)。

```cpp
class Solution {
public:
    int largestIsland(vector<vector<int>>& grid) {
        int n = grid.size();
        unordered_map<int, int> areaOfIsland; // 岛屿编号 -> 面积
        int islandId = 2; // 编号从 2 开始，避免和原始的 0（水）、1（未编号陆地）混淆

        // 给 (row, col) 所在岛屿标记编号 id，同时统计面积
        function<int(int, int, int)> dfs = [&](int row, int col, int id) -> int {
            if (row < 0 || row >= n || col < 0 || col >= n) return 0; // 越界
            if (grid[row][col] != 1) return 0; // 不是待编号的陆地（水域或已编号的其他岛屿）
            grid[row][col] = id; // 标记为当前岛屿编号
            int area = 1; // 当前格子贡献 1 的面积
            area += dfs(row - 1, col, id); // 上
            area += dfs(row + 1, col, id); // 下
            area += dfs(row, col - 1, id); // 左
            area += dfs(row, col + 1, id); // 右
            return area;
        };

        // 第一阶段：给每个岛屿编号并记录面积
        for (int i = 0; i < n; i++) {
            for (int j = 0; j < n; j++) {
                if (grid[i][j] == 1) {
                    int area = dfs(i, j, islandId);
                    areaOfIsland[islandId] = area;
                    islandId++;
                }
            }
        }

        int maxArea = 0;
        for (auto& [id, area] : areaOfIsland) {
            maxArea = max(maxArea, area); // 先考虑不填海的情况（网格里可能没有海洋格子）
        }

        int dirs[4][2] = {{-1, 0}, {1, 0}, {0, -1}, {0, 1}};

        // 第二阶段：枚举每个海洋格子，计算填海后的面积
        for (int i = 0; i < n; i++) {
            for (int j = 0; j < n; j++) {
                if (grid[i][j] != 0) continue; // 只处理海洋格子
                unordered_set<int> neighborIds; // 收集四周不同的岛屿编号，去重
                for (auto& d : dirs) {
                    int ni = i + d[0], nj = j + d[1];
                    if (ni < 0 || ni >= n || nj < 0 || nj >= n) continue; // 越界跳过
                    if (grid[ni][nj] == 0) continue; // 仍是水域，跳过
                    neighborIds.insert(grid[ni][nj]); // 记录这个方向的岛屿编号
                }
                int total = 1; // 填海本身贡献 1 格
                for (int id : neighborIds) {
                    total += areaOfIsland[id]; // 累加每个不同岛屿的面积（集合已去重，不会重复累加）
                }
                maxArea = max(maxArea, total);
            }
        }

        return maxArea;
    }
};
```

```java
    int n;

    public int largestIsland(int[][] grid) {
        n = grid.length;
        Map<Integer, Integer> areaOfIsland = new HashMap<>(); // 岛屿编号 -> 面积
        int islandId = 2; // 编号从 2 开始，避免和原始的 0/1 混淆

                    areaOfIsland.put(islandId, area);
                    islandId++;
                }
            }
        }

        int maxArea = 0;
        for (int area : areaOfIsland.values()) {
            maxArea = Math.max(maxArea, area); // 先考虑不填海的情况
        }

        int[][] dirs = {{-1, 0}, {1, 0}, {0, -1}, {0, 1}};

                for (int[] d : dirs) {
                    int ni = i + d[0], nj = j + d[1];
                    if (ni < 0 || ni >= n || nj < 0 || nj >= n) continue; // 越界跳过
                    if (grid[ni][nj] == 0) continue; // 仍是水域，跳过
                    neighborIds.add(grid[ni][nj]); // 记录这个方向的岛屿编号

                int total = 1; // 填海本身贡献 1 格
                for (int id : neighborIds) {
                    total += areaOfIsland.get(id); // 累加每个不同岛屿的面积
                }
                maxArea = Math.max(maxArea, total);
            }
        }

        return maxArea;
    }

    // 给 (row, col) 所在岛屿标记编号 id，同时统计面积
    private int dfs(int[][] grid, int row, int col, int id) {
        if (row < 0 || row >= n || col < 0 || col >= n) return 0; // 越界

        area += dfs(grid, row - 1, col, id); // 上
        area += dfs(grid, row + 1, col, id); // 下
        area += dfs(grid, row, col - 1, id); // 左
        area += dfs(grid, row, col + 1, id); // 右
        return area;
    }
```

```python
            return area

        # 第一阶段：给每个岛屿编号并记录面积
        for i in range(n):
            for j in range(n):

                    area_of_island[island_id] = area
                    island_id += 1

        max_area = max(area_of_island.values(), default=0)  # 先考虑不填海的情况

        dirs = [(-1, 0), (1, 0), (0, -1), (0, 1)]

        # 第二阶段：枚举每个海洋格子，计算填海后的面积
```

```go
func largestIsland(grid [][]int) int {
    n := len(grid)
    areaOfIsland := make(map[int]int) // 岛屿编号 -> 面积
    islandId := 2                     // 编号从 2 开始，避免和原始的 0/1 混淆

    // 给 (row, col) 所在岛屿标记编号，同时统计面积
    var dfs func(row, col, id int) int
    dfs = func(row, col, id int) int {
        if row < 0 || row >= n || col < 0 || col >= n {
            return 0 // 越界
        }
        if grid[row][col] != 1 {
            return 0 // 不是待编号的陆地
        }
        grid[row][col] = id // 标记为当前岛屿编号
        area := 1
        area += dfs(row-1, col, id) // 上
        area += dfs(row+1, col, id) // 下
        area += dfs(row, col-1, id) // 左
        area += dfs(row, col+1, id) // 右
        return area
    }

    // 第一阶段：给每个岛屿编号并记录面积
    for i := 0; i < n; i++ {
        for j := 0; j < n; j++ {
            if grid[i][j] == 1 {
                area := dfs(i, j, islandId)
                areaOfIsland[islandId] = area
                islandId++
            }
        }
    }

    maxArea := 0
    for _, area := range areaOfIsland {
        if area > maxArea {
            maxArea = area // 先考虑不填海的情况
        }
    }

    dirs := [4][2]int{{-1, 0}, {1, 0}, {0, -1}, {0, 1}}

    // 第二阶段：枚举每个海洋格子，计算填海后的面积
    for i := 0; i < n; i++ {
        for j := 0; j < n; j++ {
            if grid[i][j] != 0 {
                continue // 只处理海洋格子
            }
            neighborIds := make(map[int]bool) // 收集四周不同的岛屿编号，去重
            for _, d := range dirs {
                ni, nj := i+d[0], j+d[1]
                if ni < 0 || ni >= n || nj < 0 || nj >= n {
                    continue // 越界跳过
                }
                if grid[ni][nj] == 0 {
                    continue // 仍是水域，跳过
                }
                neighborIds[grid[ni][nj]] = true // 记录这个方向的岛屿编号
            }
            total := 1 // 填海本身贡献 1 格
            for id := range neighborIds {
                total += areaOfIsland[id] // 累加每个不同岛屿的面积
            }
            if total > maxArea {
                maxArea = total
            }
        }
    }

    return maxArea
}
```

## 总结

- 这道题是"岛屿最大面积"的进阶版，多了一步"填一格海洋，最多能连通多少个已有岛屿"，如果每次真的修改网格再重新统计，会导致复杂度退化到 O(n⁴)，必须用"预处理编号 + 枚举"的两阶段思路把复杂度控制在 O(n²)。
- 给岛屿分配唯一编号（而不是简单的布尔标记）是这道题的关键：只有编号能让"枚举海洋格子时判断四周是否属于同一岛屿"这件事变得可行，否则就没法区分不同方向的陆地是不是同一片，容易重复累加面积。
- 用集合对相邻岛屿编号去重，是避免"同一岛屿从多个方向被重复累加面积"这一常见错误的核心手段，体现了图论题里"先去重再累加"的通用处理套路。
- 必须单独处理"网格中没有海洋格子"的边界情况：这种情况下枚举阶段不会产生任何候选值，如果不特殊处理会漏判，正确做法是让 `maxArea` 在枚举前先取一次"所有已有岛屿面积的最大值"（这时候如果网格全是陆地，恰好等于 `n*n`，逻辑自然就覆盖了这个边界）。
