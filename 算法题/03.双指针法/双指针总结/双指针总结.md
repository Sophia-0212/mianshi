# 双指针法总结

双指针通过控制移动规则避免重复扫描；总复杂度取决于累计移动次数及每步开销。

**快慢指针**：原地覆盖保留元素，适用于移除元素、移动零。时间 O(n)，辅助空间 O(1)。

```
slow = 0
for fast in range(n):
    if nums[fast] != val:
        nums[slow] = nums[fast]
        slow += 1
return slow  # 新数组长度
```

**对撞指针**：两端向内，适用于反转、有序数组配对及平方排序。反转无需有序，配对依赖有序性。扫描 O(n)，下例结果空间 O(n)。

```
left, right = 0, n - 1
i = n - 1  # 结果数组从后往前填
while left <= right:
    if nums[left]**2 > nums[right]**2:
        result[i] = nums[left]**2; left += 1
    else:
        result[i] = nums[right]**2; right -= 1
    i -= 1
```

**滑动窗口**：维护连续区间，正整数和随扩张增大、收缩减小。时间 O(n)，辅助空间 O(1)。

```
left = 0; sum = 0; ans = 无穷大
for right in range(n):
    sum += nums[right]          # 窗口右边界扩张
    while sum >= target:        # 窗口满足条件，尝试收缩左边界
        ans = min(ans, right - left + 1)
        sum -= nums[left]
        left += 1
```

**链表指针**：快二慢一找中点／判环；固定间距找倒数位置；相遇后从头与相遇点同步走可找环入口。时间 O(n)，空间 O(1)。

**链表相交**：先对齐长度，或分别走完两条链表再相遇。时间 O(m+n)，空间 O(1)，比较节点身份。

无序两数之和可用哈希表：平均时间 O(n)，空间 O(n)；三数、四数之和排序后固定前面的数，用双指针及相邻去重。
