# 0052. N皇后II

**题目描述**

n 皇后问题研究的是如何将 n 个皇后放置在 n×n 的棋盘上，并且使皇后彼此之间不能相互攻击（即任意两个皇后都不能处于同一行、同一列或同一条斜线上）。

给定一个整数 n，返回 n 皇后问题不同的解决方案的**数量**（不需要返回具体的棋盘摆法）。

```
示例：
输入：n = 4
输出：2
解释：4 皇后问题存在两种不同的解法。
```

## 思路

这题和经典的「51. N皇后」在算法主体上完全一致，唯一的区别在于输出形式：51 题要收集每一种合法棋盘的具体摆法（字符串矩阵），这题只需要统计合法摆法的**总数**就行。这个区别看似很小，但恰好点出了回溯算法的一个重要特性：回溯的搜索过程和"要不要保存结果"其实是两件独立的事，保存结果只是搜索到达叶子节点时的一个动作，去掉这个动作、换成计数器自增，算法的骨架完全不变。

核心思路仍然是逐行放置皇后。因为任意两个皇后不能同行，所以可以规定每一行必须且只能放一个皇后，这样回溯的过程就变成了"决定第 row 行皇后放在哪一列"，天然避开了行冲突，问题规模从二维降到一维（只需要确定每行的列号）。

判断冲突需要三个维度：
- **列冲突**：某一列是否已经被上面某个皇后占用。
- **正斜线冲突（左上到右下，↘方向）**：这条斜线上所有格子满足 `row - col` 为定值。
- **反斜线冲突（右上到左下，↙方向）**：这条斜线上所有格子满足 `row + col` 为定值。

利用这两个恒等式，可以用三个布尔标记集合（列集合、正斜线集合、反斜线集合）在 O(1) 时间内判断新皇后是否与已放置的皇后冲突，而不需要每次都遍历棋盘检查。这是 N 皇后问题的标准优化手段，能把每次冲突检测从 O(n) 降到 O(1)。

回溯的框架是这样的：
1. 从第 0 行开始尝试，对每一行遍历所有列 `col`。
2. 若 `col` 不在列集合中，且 `row - col` 不在正斜线集合中，且 `row + col` 不在反斜线集合中，说明可以放置。
3. 放置后把三个标记加入对应集合，递归进入下一行。
4. 递归返回后，撤销标记（回溯），尝试当前行的下一个列。
5. 当 `row == n` 时说明成功放满了所有皇后，这时候不是把棋盘存入结果集，而是让计数器加一，然后直接返回，不再继续深入。

边界条件上得注意一下：n=0 或 n=1 时应该按题目定义返回对应的解数（n=1 时答案是 1，因为唯一的摆法本身就成立；n=2、n=3 时不存在合法解，返回 0），代码里回溯函数天然处理这些情况，不需要额外特判。

复杂度分析：时间复杂度理论上界是 O(n!)，因为第一行有 n 种选择，第二行最多 n-1 种可行选择（排除同列），依次递减，但实际执行中大量分支会因为斜线冲突被更早剪枝，实际运行远快于 n!。空间复杂度为 O(n)，也就是三个标记集合和递归栈的深度，都与 n 成正比（不需要像 51 题那样额外存储所有棋盘方案，这也是这题相对省空间的地方）。

## 代码

### C++

```cpp
class Solution {
public:
    int totalNQueens(int n) {
        cols.resize(n, false);           // 列是否被占用
        diag1.resize(2 * n, false);      // 正斜线 row-col，偏移 n 避免负数下标
        diag2.resize(2 * n, false);      // 反斜线 row+col
        count = 0;
        backtrack(0, n);
        return count;
    }

private:
    vector<bool> cols, diag1, diag2;
    int count;

    void backtrack(int row, int n) {
        if (row == n) {          // 所有行都成功放置，找到一个合法解
            count++;             // 只计数，不保存棋盘
            return;
        }
        for (int col = 0; col < n; col++) {
            int d1 = row - col + n;  // 加 n 偏移，保证下标非负
            int d2 = row + col;
            if (cols[col] || diag1[d1] || diag2[d2]) {
                continue;         // 冲突，跳过该列
            }
            cols[col] = diag1[d1] = diag2[d2] = true;  // 放置皇后并标记
            backtrack(row + 1, n);                       // 递归下一行
            cols[col] = diag1[d1] = diag2[d2] = false;   // 回溯，撤销标记
        }
    }
};
```

class Solution {
    private boolean[] cols, diag1, diag2;
    private int count;

    public int totalNQueens(int n) {
        cols = new boolean[n];        // 列占用标记
        diag1 = new boolean[2 * n];   // 正斜线 row-col，偏移 n
        diag2 = new boolean[2 * n];   // 反斜线 row+col
        count = 0;
        backtrack(0, n);
        return count;
    }

    private void backtrack(int row, int n) {
        if (row == n) {               // 所有行放置完成，得到一个合法解
            count++;                  // 计数即可，无需存棋盘
            return;
        }
        for (int col = 0; col < n; col++) {
            int d1 = row - col + n;   // 偏移防止负下标
            int d2 = row + col;
            if (cols[col] || diag1[d1] || diag2[d2]) {
                continue;             // 三个方向任一冲突则跳过
            }
            cols[col] = diag1[d1] = diag2[d2] = true;   // 标记占用
            backtrack(row + 1, n);                        // 递归处理下一行
            cols[col] = diag1[d1] = diag2[d2] = false;    // 回溯撤销
        }
    }
}

### Python

本题没有直接对应的标准库函数（这是纯组合搜索问题），只有手写回溯实现：

```python
class Solution:
    def totalNQueens(self, n: int) -> int:
        cols = set()   # 已占用的列
        diag1 = set()  # 已占用的正斜线，用 row - col 标识
        diag2 = set()  # 已占用的反斜线，用 row + col 标识
        self.count = 0

        def backtrack(row: int) -> None:
            if row == n:               # 所有行都放置成功
                self.count += 1        # 只累加计数，不记录具体棋盘
                return
            for col in range(n):
                if col in cols or (row - col) in diag1 or (row + col) in diag2:
                    continue           # 存在冲突，跳过这一列
                cols.add(col)
                diag1.add(row - col)
                diag2.add(row + col)
                backtrack(row + 1)     # 递归放置下一行
                cols.remove(col)       # 回溯：撤销本次选择
                diag1.remove(row - col)
                diag2.remove(row + col)

        backtrack(0)
        return self.count
```

### Go

```go
func totalNQueens(n int) int {
    cols := make([]bool, n)       // 列占用标记
    diag1 := make([]bool, 2*n)    // 正斜线 row-col，偏移 n
    diag2 := make([]bool, 2*n)    // 反斜线 row+col
    count := 0

    var backtrack func(row int)
    backtrack = func(row int) {
        if row == n {              // 所有行放置完成
            count++                // 计数，不保存棋盘
            return
        }
        for col := 0; col < n; col++ {
            d1 := row - col + n    // 偏移防止负下标
            d2 := row + col
            if cols[col] || diag1[d1] || diag2[d2] {
                continue           // 冲突则跳过
            }
            cols[col], diag1[d1], diag2[d2] = true, true, true   // 标记
            backtrack(row + 1)                                     // 递归
            cols[col], diag1[d1], diag2[d2] = false, false, false  // 回溯
        }
    }

    backtrack(0)
    return count
}
```

## 总结

- 这题跟 51 题「N皇后」共享完全相同的搜索骨架（按行放置 + 列/正斜线/反斜线三标记冲突检测），区别仅在于叶子节点处的动作：51 题要把棋盘转成字符串存入结果集，这题只需要计数器加一，这提示我们回溯算法的"搜索逻辑"和"结果收集逻辑"应当解耦看待。
- 用 `row - col` 和 `row + col` 表示两条斜线方向，是棋盘类回溯题的通用技巧，本质上是利用了同一条斜线上的格子在这两个表达式下取值恒定的几何性质。
- 因为不需要保存棋盘，这题相比 51 题更省空间，这也从侧面说明了在只需要计数而非枚举方案时，应当优先考虑是否可以省去不必要的结果存储开销。
- 剪枝越早、越精确，回溯树被砍掉的无效分支就越多，列/斜线标记法把每次冲突检测降到 O(1)，是保证这题在合理时间内跑完的关键优化。
