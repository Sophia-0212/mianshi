# 0052. N皇后II

**题目描述**

n 皇后问题研究的是如何将 n 个皇后放置在 n×n 的棋盘上，并且使皇后彼此之间不能相互攻击（即任意两个皇后都不能处于同一行、同一列或同一条斜线上）。

给定一个整数 n，返回 n 皇后问题不同的解决方案的**数量**（不需要返回具体的棋盘摆法）。

```
示例：
输入：n = 4
输出：2
解释：4 皇后问题存在两种不同的解法。
```

## 思路

按行回溯，用集合记录已占列、`row-col`、`row+col`。无冲突则加入标记并递归，返回时撤销；放满 `n` 行只累加计数。

当前每层扫描全部列，时间上界 O(n·n!)，空间 O(n)。

### LeetCode 写法与原有示例

本题没有直接对应的标准库函数（这是纯组合搜索问题），只有手写回溯实现：

```python
# 依赖说明：range：Python 内置函数：生成按步长遍历的整数序列。

class Solution:
    # 方法：totalNQueens；按题目要求处理输入并返回结果，核心算法见方法体。
    def totalNQueens(self, n: int) -> int:
        cols = set()   # 已占用的列
        diag1 = set()  # 已占用的正斜线，用 row - col 标识
        diag2 = set()  # 已占用的反斜线，用 row + col 标识
        self.count = 0

        # 方法：backtrack；按题目要求处理输入并返回结果，核心算法见方法体。
        def backtrack(row: int) -> None:
            if row == n:               # 所有行都放置成功
                self.count += 1        # 只累加计数，不记录具体棋盘
                return
            for col in range(n):
                if col in cols or (row - col) in diag1 or (row + col) in diag2:
                    continue           # 存在冲突，跳过这一列
                cols.add(col)
                diag1.add(row - col)
                diag2.add(row + col)
                backtrack(row + 1)     # 递归放置下一行
                cols.remove(col)       # 回溯：撤销本次选择
                diag1.remove(row - col)
                diag2.remove(row + col)

        backtrack(0)
        return self.count```

### LeetCode 写法与原有示例

```go
// 方法：totalNQueens；按题目要求处理输入并返回结果，核心算法见方法体。
func totalNQueens(n int) int {
    cols := make([]bool, n)       // 列占用标记
    diag1 := make([]bool, 2*n)    // 正斜线 row-col，偏移 n
    diag2 := make([]bool, 2*n)    // 反斜线 row+col
    count := 0

    var backtrack func(row int)
    backtrack = func(row int) {
        if row == n {              // 所有行放置完成
            count++                // 计数，不保存棋盘
            return
        }
        for col := 0; col < n; col++ {
            d1 := row - col + n    // 偏移防止负下标
            d2 := row + col
            if cols[col] || diag1[d1] || diag2[d2] {
                continue           // 冲突则跳过
            }
            cols[col], diag1[d1], diag2[d2] = true, true, true   // 标记
            backtrack(row + 1)                                     // 递归
            cols[col], diag1[d1], diag2[d2] = false, false, false  // 回溯
        }
    }

    backtrack(0)
    return count
}
```

```cpp
class Solution {
public:
    // 方法：totalNQueens；按题目要求处理输入并返回结果，核心算法见方法体。
    int totalNQueens(int n) {
        cols.resize(n, false);           // 列是否被占用
        diag1.resize(2 * n, false);      // 正斜线 row-col，偏移 n 避免负数下标
        diag2.resize(2 * n, false);      // 反斜线 row+col
        count = 0;
        backtrack(0, n);
        return count;
    }

private:
    vector<bool> cols, diag1, diag2;
    int count;

    // 方法：backtrack；按题目要求处理输入并返回结果，核心算法见方法体。
    void backtrack(int row, int n) {
        if (row == n) {          // 所有行都成功放置，找到一个合法解
            count++;             // 只计数，不保存棋盘
            return;
        }
        for (int col = 0; col < n; col++) {
            int d1 = row - col + n;  // 加 n 偏移，保证下标非负
            int d2 = row + col;
            if (cols[col] || diag1[d1] || diag2[d2]) {
                continue;         // 冲突，跳过该列
            }
            cols[col] = diag1[d1] = diag2[d2] = true;  // 放置皇后并标记
            backtrack(row + 1, n);                       // 递归下一行
            cols[col] = diag1[d1] = diag2[d2] = false;   // 回溯，撤销标记
        }
    }
};
```

## 总结

- 这题跟 51 题「N皇后」共享完全相同的搜索骨架（按行放置 + 列/正斜线/反斜线三标记冲突检测），区别仅在于叶子节点处的动作：51 题要把棋盘转成字符串存入结果集，这题只需要计数器加一，这提示我们回溯算法的"搜索逻辑"和"结果收集逻辑"应当解耦看待。
- 用 `row - col` 和 `row + col` 表示两条斜线方向，是棋盘类回溯题的通用技巧，本质上是利用了同一条斜线上的格子在这两个表达式下取值恒定的几何性质。
- 因为不需要保存棋盘，这题相比 51 题更省空间，这也从侧面说明了在只需要计数而非枚举方案时，应当优先考虑是否可以省去不必要的结果存储开销。
- 剪枝越早、越精确，回溯树被砍掉的无效分支就越多，列/斜线标记法把每次冲突检测降到 O(1)，是保证这题在合理时间内跑完的关键优化。
