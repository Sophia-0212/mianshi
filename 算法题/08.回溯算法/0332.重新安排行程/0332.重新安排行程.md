# 0332. 重新安排行程

**题目描述**

给定一个机票的字符串二维数组 `tickets`，其中 `tickets[i] = [fromi, toi]` 表示一张机票的起飞机场和降落机场。请你重新规划路线，使得从 `JFK` 出发能够刚好用掉所有机票。如果存在多种有效的行程，请返回按字典序排列最小的行程。假设所有机票至少存在一种合理的行程，且所有机票必须都用一次且只能用一次。

```
示例：
输入: tickets = [["MUC","LHR"],["JFK","MUC"],["LHR","SFO"]]
输出: ["JFK","MUC","LHR","SFO"]

输入: tickets = [["JFK","SFO"],["JFK","ATL"],["SFO","ATL"],["ATL","JFK"],["ATL","SFO"]]
输出: ["JFK","ATL","JFK","SFO","ATL","SFO"]
```

## 思路

这是一道困难题，本质是图论中的**欧拉路径问题**（用完所有边，走过一条路径），但可以用"回溯 + 贪心排序"的方式求解，不需要专门实现欧拉路径的经典算法（比如 Hierholzer 算法），理解起来更直观，但要处理好几个细节。

**建图**：把每个机场看作图中的一个节点，每张机票 `[from, to]` 看作一条从 `from` 指向 `to` 的有向边。用一个哈希表 `map<string, vector<string>>`（或等价结构）存储每个机场出发能到达的所有目的地列表。

**贪心排序怎么保证字典序最小呢**：题目要求存在多种合法行程时，返回字典序最小的一种。做法是：对每个机场对应的目的地列表**提前按字典序排序**，这样在回溯过程中，for 循环总是优先尝试字典序更小的目的地，一旦找到一条能用完所有机票的路径，因为总是"贪心地"优先选字典序小的分支，第一条找到的完整路径就必然是字典序最小的，不需要再比较其他路径。

**回溯的选择与标记已用机票**：这里不能像排列问题那样用一个简单的 `used` 数组标记机场是否用过（机场可以重复经过，只是每张具体的"机票"只能用一次）。做法是给每条边（每张机票）标记是否已被使用——比如把每个机场的目的地列表存成 `vector<pair<string, bool>>`（目的地和是否已使用的标记），或者用一个和列表下标对应的 `used` 数组。当尝试从当前机场飞往某个目的地时，检查这条边是否已经使用过，没用过才可以选择。

**终止条件（这题的关键难点）**：因为要求必须用完所有机票（一共 `tickets.size()` 张），所以完整的行程包含 `tickets.size() + 1` 个机场节点（起点 JFK 加上每张机票飞到的目的地）。当 `path` 的长度等于 `tickets.size() + 1` 时，说明找到了一条用完所有机票的合法行程。

**为什么找到一个解就要立即终止整个递归，不能继续回溯其他分支呢**：因为题目已经保证存在一种合法行程，并且我们通过贪心排序保证了"第一条找到的完整路径就是字典序最小的"，所以一旦 `path` 达到目标长度，就应该立即向上层层返回终止信号，而不能让递归继续往下探索其他分支——不然可能会用回溯法覆盖掉已经找到的正确答案，或者浪费大量时间去寻找本不需要找的其他路径。具体做法是让 `backtrack` 函数返回一个布尔值 `true`/`false` 表示"这个分支是否已经找到最终答案"，一旦某一层递归返回 `true`，它的调用者也立即返回 `true`（不再继续 for 循环的下一次迭代），这样 `true` 就会一路从找到答案的那一层"传递"回最外层调用，实现真正意义上的整体终止，而不是只终止某一层。

**说说"选择 - 递归 - 撤销选择"这三步**：

1. 选择：把目的地机场加入 `path`，并标记对应的机票（边）为已使用。
2. 递归：以这个目的地为新的出发点，继续寻找下一段行程。
3. 撤销选择：如果递归返回 `false`（这个分支没能找到合法行程），把刚加入的目的地弹出，同时把对应机票标记为未使用，让 for 循环尝试下一个候选目的地。**注意**：如果递归返回 `true`，则不需要撤销，直接把 `true` 继续向上传递，保留已经找到的合法路径。

**复杂度分析**：最坏情况下时间复杂度接近 O(E!)（E 为边数，即机票数），因为要枚举所有可能的边使用顺序；但由于贪心排序和及时终止，实际运行远比这个理论上界快。空间复杂度 O(E)（图存储 + 递归深度）。

## 代码

### C++

```cpp
class Solution {
private:
    // targets[机场] = 该机场可飞往的目的地列表（已按字典序排序），
    // pair 的第二个元素表示这张机票是否已被使用
    unordered_map<string, vector<pair<string, bool>>> targets;
    vector<string> path;
    int ticketCount;

    bool backtrack(const string& cur) {
        if (path.size() == ticketCount + 1) {   // 终止条件：用完所有机票，路径长度=机票数+1
            return true;                            // 找到答案，直接返回 true，不再继续搜索
        }
        if (targets.find(cur) == targets.end()) {
            return false;                            // 当前机场没有可飞往的目的地，此分支失败
        }
        for (auto& target : targets[cur]) {          // 遍历已排序的目的地列表（贪心：优先字典序小）
            if (target.second) continue;               // 这张机票已经用过，跳过
            target.second = true;               // 【选择】标记这张机票已使用
            path.push_back(target.first);        // 【选择】加入路径
            if (backtrack(target.first)) {       // 【递归】
                return true;                          // 子递归已找到答案，直接向上传递 true，不再回溯
            }
            path.pop_back();                       // 【撤销选择】此分支失败，回退路径
            target.second = false;                  // 【撤销选择】恢复机票未使用状态
        }
        return false;                              // 所有目的地都尝试过仍未找到答案
    }

public:
    vector<string> findItinerary(vector<vector<string>>& tickets) {
        ticketCount = tickets.size();
        for (auto& t : tickets) {
            targets[t[0]].push_back({t[1], false});   // 建图：记录每张机票，初始未使用
        }
        for (auto& [airport, list] : targets) {
            sort(list.begin(), list.end());             // 贪心排序：目的地按字典序排列
        }
        path.push_back("JFK");                         // 起点固定为 JFK
        backtrack("JFK");
        return path;
    }
};
```

### Java

```java
class Solution {
    // 每个机场 -> 目的地列表（已排序），及机票是否已使用的并行数组
    private Map<String, List<String>> targets = new HashMap<>();
    private Map<String, List<Boolean>> used = new HashMap<>();
    private List<String> path = new ArrayList<>();
    private int ticketCount;

    public List<String> findItinerary(List<List<String>> tickets) {
        ticketCount = tickets.size();
        for (List<String> t : tickets) {
            targets.computeIfAbsent(t.get(0), k -> new ArrayList<>()).add(t.get(1));
        }
        for (String airport : targets.keySet()) {
            Collections.sort(targets.get(airport));           // 贪心排序：目的地字典序
            List<Boolean> u = new ArrayList<>();
            for (int i = 0; i < targets.get(airport).size(); i++) u.add(false);
            used.put(airport, u);
        }
        path.add("JFK");
        backtrack("JFK");
        return path;
    }

    private boolean backtrack(String cur) {
        if (path.size() == ticketCount + 1) {     // 终止条件：用完所有机票
            return true;                              // 找到答案，立即向上返回 true
        }
        if (!targets.containsKey(cur)) {
            return false;                              // 无出边，此分支失败
        }
        List<String> dests = targets.get(cur);
        List<Boolean> flags = used.get(cur);
        for (int i = 0; i < dests.size(); i++) {        // 遍历已排序的目的地（贪心）
            if (flags.get(i)) continue;                   // 该机票已使用，跳过
            flags.set(i, true);                    // 【选择】
            path.add(dests.get(i));                 // 【选择】
            if (backtrack(dests.get(i))) {          // 【递归】
                return true;                             // 已找到答案，直接向上传递，不再回溯
            }
            path.remove(path.size() - 1);            // 【撤销选择】
            flags.set(i, false);                      // 【撤销选择】
        }
        return false;
    }
}
```

### Python

```python
from collections import defaultdict

class Solution:
    def findItinerary(self, tickets: list[list[str]]) -> list[str]:
        targets = defaultdict(list)   # 机场 -> [目的地, ...]（未排序前先收集）
        for src, dst in tickets:
            targets[src].append(dst)
        for airport in targets:
            targets[airport].sort()    # 贪心排序：目的地按字典序排列，保证优先尝试小的

        used = {airport: [False] * len(dsts) for airport, dsts in targets.items()}
        path = ["JFK"]
        ticket_count = len(tickets)

        def backtrack(cur: str) -> bool:
            if len(path) == ticket_count + 1:   # 终止条件：用完所有机票
                return True                          # 找到答案，立即返回 True
            if cur not in targets:
                return False                          # 无出边，此分支失败
            for i, dst in enumerate(targets[cur]):    # 遍历已排序的目的地（贪心）
                if used[cur][i]:                        # 该机票已使用，跳过
                    continue
                used[cur][i] = True         # 【选择】标记已使用
                path.append(dst)             # 【选择】加入路径
                if backtrack(dst):            # 【递归】
                    return True                   # 已找到答案，直接向上传递 True，不再回溯
                path.pop()                     # 【撤销选择】
                used[cur][i] = False            # 【撤销选择】
            return False

        backtrack("JFK")
        return path
```

### Go

```go
func findItinerary(tickets [][]string) []string {
    targets := make(map[string][]string)   // 机场 -> 目的地列表
    for _, t := range tickets {
        targets[t[0]] = append(targets[t[0]], t[1])
    }
    for airport := range targets {
        sort.Strings(targets[airport])      // 贪心排序：目的地按字典序排列
    }
    used := make(map[string][]bool)
    for airport, dsts := range targets {
        used[airport] = make([]bool, len(dsts))
    }
    path := []string{"JFK"}
    ticketCount := len(tickets)

    var backtrack func(cur string) bool
    backtrack = func(cur string) bool {
        if len(path) == ticketCount+1 {        // 终止条件：用完所有机票
            return true                             // 找到答案，立即返回 true
        }
        dsts, ok := targets[cur]
        if !ok {
            return false                             // 无出边，此分支失败
        }
        for i, dst := range dsts {               // 遍历已排序的目的地（贪心）
            if used[cur][i] {                        // 该机票已使用，跳过
                continue
            }
            used[cur][i] = true              // 【选择】
            path = append(path, dst)          // 【选择】
            if backtrack(dst) {                // 【递归】
                return true                          // 已找到答案，直接向上传递 true
            }
            path = path[:len(path)-1]           // 【撤销选择】
            used[cur][i] = false                 // 【撤销选择】
        }
        return false
    }
    backtrack("JFK")
    return path
}
```

## 总结

- 这题是欧拉路径问题的回溯解法：把机票看作图的边，用回溯搜索一条能用完所有边的路径，而不是套用经典的 Hierholzer 欧拉路径算法，这样代码更符合回溯思维习惯。
- 贪心排序（每个机场的目的地列表预先按字典序排序）是保证结果字典序最小的关键，配合"找到答案就立即终止"的策略，第一条走到底的完整路径就是最优解，不需要枚举比较所有合法路径。
- 终止条件要通过返回布尔值的方式一路向上传递：一旦某层递归返回 `true`，所有调用它的上层函数都要立即返回 `true`，不能继续走 for 循环的其他分支，这是区别于普通回溯题"找到一个答案后仍需撤销继续搜索"的特殊之处。
- 标记"已使用"的对象是每一条具体的边（机票），而不是机场节点本身，为什么呢？因为同一个机场可以在行程中被经过多次，只有对应的某张机票用过一次后不能再用。
