# 0216. 组合总和 III

**题目描述**

找出所有相加之和为 `n` 的 `k` 个数的组合，且满足下列条件：只使用数字 1 到 9，每个数字最多使用一次。返回所有可能的组合列表，解集不能包含重复的组合。

```
示例：
输入: k = 3, n = 7
输出: [[1,2,4]]

输入: k = 3, n = 9
输出: [[1,2,6],[1,3,5],[2,3,4]]
```

## 思路

这题是在 0077 题"组合"的基础上，多加了一个"总和等于 n"的约束条件，属于组合类问题的变形。

**递归树的结构**：候选集合固定在 1~9，树的深度还是 `k`（选够 k 个数就到叶子节点了），每一层的宽度是当前 `startIndex` 到 9 的范围。跟 0077 题一样，用 `startIndex` 保证每层只能选比上一层大的数字，避免顺序不同的重复组合。区别在哪呢？终止条件多了一层判断：不仅要 `path.size() == k`，还要 `sum(path) == n`，这两个条件都满足才收集结果；如果选够了 k 个数但总和不等于 n，那就直接返回，不收集。

**能不能提前剪枝呢**：这题在递归过程中可以提前发现"不可能凑出结果"的分支，主要是两种情况：

1. **和已经超过 n**：如果当前 `path` 的总和已经大于 `n` 了，那即使不再往下选，也不可能凑出等于 `n` 的组合了，这时候可以直接不再递归这个分支——累加到当前层的 `sum` 就够判断了，不用等到选够 k 个数再检查。
2. **结合 0077 的个数剪枝**：同样可以用"剩余候选数字个数是否够凑够 k 个数"这个剪枝，因为候选集合固定为 1~9，这个剪枝在这道题里体现为 for 循环上界是 `9 - (k - path.size()) + 1`。

这两种剪枝可以同时用：一个是基于"数量是否够"，体现在 for 循环的范围上；另一个是基于"和是否超"，体现在递归调用之前的判断上。

**复杂度分析**：候选数字固定就 9 个，而且总和还有约束，实际搜索空间比 0077 题要小很多。时间复杂度上界仍然是组合数级别 O(C(9,k))，但由于有总和剪枝，实际访问的节点数会明显减少。空间复杂度 O(k)（递归栈深度）。

## 代码

### C++

```cpp
class Solution {
private:
    vector<vector<int>> result;
    vector<int> path;
    int pathSum = 0;  // 记录当前路径的和，避免每次都重新累加

    void backtrack(int k, int n, int startIndex) {
        if (pathSum > n) {          // 剪枝：和已经超过 n，不可能凑出结果，直接返回
            return;
        }
        if (path.size() == k) {                  // 已经选够 k 个数
            if (pathSum == n) {                   // 且和恰好等于 n，才是合法解
                result.push_back(path);
            }
            return;                               // 无论和是否等于 n，选够 k 个都要返回
        }
        // 剪枝：结合个数剪枝，候选集合固定为 1~9
        for (int i = startIndex; i <= 9 - (k - path.size()) + 1; i++) {
            path.push_back(i);          // 【选择】
            pathSum += i;                // 维护路径和
            backtrack(k, n, i + 1);     // 【递归】
            pathSum -= i;                // 【撤销选择】撤销路径和
            path.pop_back();            // 【撤销选择】撤销路径
        }
    }

public:
    vector<vector<int>> combinationSum3(int k, int n) {
        backtrack(k, n, 1);
        return result;
    }
};
```

### Java

```java
class Solution {
    private List<List<Integer>> result = new ArrayList<>();
    private LinkedList<Integer> path = new LinkedList<>();
    private int pathSum = 0;

    public List<List<Integer>> combinationSum3(int k, int n) {
        backtrack(k, n, 1);
        return result;
    }

    private void backtrack(int k, int n, int startIndex) {
        if (pathSum > n) {                      // 剪枝：和已超过 n
            return;
        }
        if (path.size() == k) {                 // 已经选够 k 个数
            if (pathSum == n) {                  // 且和恰好等于 n
                result.add(new ArrayList<>(path));
            }
            return;
        }
        for (int i = startIndex; i <= 9 - (k - path.size()) + 1; i++) {
            path.addLast(i);        // 【选择】
            pathSum += i;
            backtrack(k, n, i + 1); // 【递归】
            pathSum -= i;           // 【撤销选择】
            path.removeLast();      // 【撤销选择】
        }
    }
}
```

### Python

```python
class Solution:
    def combinationSum3(self, k: int, n: int) -> list[list[int]]:
        result = []
        path = []
        path_sum = 0  # 用外部变量记录路径和，Python 闭包中修改需要 nonlocal

        def backtrack(start_index: int):
            nonlocal path_sum
            if path_sum > n:                      # 剪枝：和已超过 n，不可能凑出结果
                return
            if len(path) == k:                    # 已经选够 k 个数
                if path_sum == n:                  # 且和恰好等于 n
                    result.append(path[:])
                return
            upper_bound = 9 - (k - len(path)) + 1  # 个数剪枝上界
            for i in range(start_index, upper_bound + 1):
                path.append(i)          # 【选择】
                path_sum += i
                backtrack(i + 1)         # 【递归】
                path_sum -= i            # 【撤销选择】
                path.pop()               # 【撤销选择】

        backtrack(1)
        return result
```

### Go

```go
func combinationSum3(k int, n int) [][]int {
    var result [][]int
    var path []int
    pathSum := 0

    var backtrack func(startIndex int)
    backtrack = func(startIndex int) {
        if pathSum > n {                          // 剪枝：和已超过 n
            return
        }
        if len(path) == k {                       // 已经选够 k 个数
            if pathSum == n {                      // 且和恰好等于 n
                tmp := make([]int, len(path))
                copy(tmp, path)
                result = append(result, tmp)
            }
            return
        }
        upperBound := 9 - (k - len(path)) + 1      // 个数剪枝上界
        for i := startIndex; i <= upperBound; i++ {
            path = append(path, i)        // 【选择】
            pathSum += i
            backtrack(i + 1)               // 【递归】
            pathSum -= i                   // 【撤销选择】
            path = path[:len(path)-1]      // 【撤销选择】
        }
    }
    backtrack(1)
    return result
}
```

## 总结

- 这题是组合问题叠加"和约束"的典型例子：终止条件从"个数够即收集"变成了"个数够且和等于 n 才收集"，这两个条件缺一不可。
- "和超过 n 就剪枝"是这题最关键的优化点，应该在累加路径和之后就立即判断，而不是等选够 k 个数再判断——不然会有大量注定失败的分支被递归到底才发现无解，白白浪费时间。
- 维护一个 `pathSum` 变量来累加路径和，比每次都对 `path` 求和效率要高，但代价是撤销选择的时候要同步撤销 `pathSum` 的修改，这个地方容易漏写，得格外注意。
- 个数剪枝（剩余候选够不够选够 k 个）和和值剪枝（和是否已超过 n）可以同时用，二者分别作用于 for 循环范围和递归调用前的判断，互不冲突。
