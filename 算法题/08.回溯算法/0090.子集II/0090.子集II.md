# 0090. 子集 II

**题目描述**

给定一个可能包含重复元素的整数数组 `nums`，返回该数组所有可能的子集（幂集），解集不能包含重复的子集，可以按任意顺序返回。

```
示例：
输入: nums = [1,2,2]
输出: [[],[1],[1,2],[1,2,2],[2],[2,2]]
```

## 思路

排序＋回溯：进入每层保存当前子集；同层跳过相邻相同值，即 `i>startIndex && nums[i]==nums[i-1]`。下一层从 `i+1` 开始，返回时撤销。

最坏时间 O(n·2ⁿ)，辅助空间 O(n)，不计结果。

### LeetCode 写法与原有示例

```python
# 依赖说明：len：Python 内置函数：返回容器中元素的数量。；range：Python 内置函数：生成按步长遍历的整数序列。

class Solution:
    # 方法：subsetsWithDup；按题目要求处理输入并返回结果，核心算法见方法体。
    def subsetsWithDup(self, nums: list[int]) -> list[list[int]]:
        nums.sort()   # 排序，为树层去重做准备
        result = []
        path = []

        # 方法：backtrack；按题目要求处理输入并返回结果，核心算法见方法体。
        def backtrack(start_index: int):
            result.append(path[:])       # 子集问题：每个节点都收集
            if start_index >= len(nums):
                return
            for i in range(start_index, len(nums)):
                # 树层去重：i > start_index 表示非本层第一个位置，值相同则跳过
                if i > start_index and nums[i] == nums[i - 1]:
                    continue
                path.append(nums[i])       # 【选择】
                backtrack(i + 1)             # 【递归】
                path.pop()                    # 【撤销选择】

        backtrack(0)
        return result```

## Go

### LeetCode 写法与原有示例

```go
// 方法：subsetsWithDup；按题目要求处理输入并返回结果，核心算法见方法体。
func subsetsWithDup(nums []int) [][]int {
    sort.Ints(nums)   // 排序，为树层去重做准备
    var result [][]int
    var path []int

    var backtrack func(startIndex int)
    backtrack = func(startIndex int) {
        tmp := make([]int, len(path))
        copy(tmp, path)
        result = append(result, tmp)      // 子集问题：每个节点都收集
        if startIndex >= len(nums) {
            return
        }
        for i := startIndex; i < len(nums); i++ {
            // 树层去重：非本层第一个位置且值相同则跳过
            if i > startIndex && nums[i] == nums[i-1] {
                continue
            }
            path = append(path, nums[i])    // 【选择】
            backtrack(i + 1)                  // 【递归】
            path = path[:len(path)-1]          // 【撤销选择】
        }
    }
    backtrack(0)
    return result
}
```

## C++

### LeetCode 写法与原有示例

```cpp
class Solution {
private:
    vector<vector<int>> result;
    vector<int> path;

    // 方法：backtrack；按题目要求处理输入并返回结果，核心算法见方法体。
    void backtrack(vector<int>& nums, int startIndex) {
        result.push_back(path);            // 子集问题：每个节点都收集，包括空集
        if (startIndex >= nums.size()) {
            return;
        }
        for (int i = startIndex; i < nums.size(); i++) {
            // 树层去重：i > startIndex 表示非本层第一个位置，值相同则跳过，
            // 避免生成与前一个分支完全相同的子集
            if (i > startIndex && nums[i] == nums[i - 1]) {
                continue;
            }
            path.push_back(nums[i]);        // 【选择】
            backtrack(nums, i + 1);         // 【递归】
            path.pop_back();                  // 【撤销选择】
        }
    }

public:
    vector<vector<int>> subsetsWithDup(vector<int>& nums) {
        sort(nums.begin(), nums.end());   // 排序，为树层去重做准备
        backtrack(nums, 0);
        return result;
    }
};
```

## 总结

- 这题的去重逻辑跟 0040 组合总和 II 完全一样（排序后同层跳过相邻重复值），这说明"树层去重"是一个可以跨题型复用的通用技巧，不局限于组合问题。
- 子集问题"每个节点都收集"的特性和去重逻辑是相互独立的：去重决定要不要展开某个分支，收集结果的时机则始终是"进入函数就收集"，这两者互不冲突。
- `i > startIndex && nums[i] == nums[i-1]` 这个判断条件要牢牢记住：它只在同一层内比较相邻元素，不会影响跨层（树枝方向）的重复值被合法保留下来。
- 排序是几乎所有"数值去重"类回溯题目的前置步骤，你想啊，没有排序就没法简单通过比较相邻元素来判断是否重复。
