# 0090. 子集 II

**题目描述**

给定一个可能包含重复元素的整数数组 `nums`，返回该数组所有可能的子集（幂集），解集不能包含重复的子集，可以按任意顺序返回。

```
示例：
输入: nums = [1,2,2]
输出: [[],[1],[1,2],[1,2,2],[2],[2,2]]
```

## 思路

这题是"子集问题 + 去重技巧"的结合，去重的思路跟 0040 组合总和 II 里的"树层去重"完全一致：先排序，再在同一层 for 循环中跳过与前一个元素相同的值。

**为什么直接套用 0078 的做法会出错呢**：你想啊，如果不做任何处理，直接对 `[1,2,2]` 跑 0078 的子集回溯逻辑，会在处理第二个 `2` 的时候，重复生成一遍"以第一个 2 结尾"时已经生成过的所有子集分支（比如 `[2]` 会被生成两次，一次是选第一个 2，一次是选第二个 2）。这正是"树层重复"的典型场景——同一层 for 循环中，两个下标对应的数值相同，往下展开的子树是完全一样的。

**去重方案是什么呢**（跟 0040 一模一样的判断条件）：先对 `nums` 排序，让相同的数值相邻；然后在 for 循环中，如果 `i > startIndex && nums[i] == nums[i-1]`，说明当前这个数值在本层已经被处理过一次了（前一个相同的值已经展开了对应的子树），直接跳过，不再重复展开。

`i > startIndex` 这个条件依然是关键：它确保这次跳过只发生在"同一层内、非第一个位置"的情况，如果去掉这个限制，会把合法的"树枝"重复值（比如 `path=[2]` 之后继续选下一个 `2`，得到合法子集 `[2,2]`）也误跳过了。

**收集结果的时机**：跟 0078 题一样，子集问题在每个递归节点（包括根节点）都要收集当前 `path`，而不是只在叶子节点收集。这一点不受去重逻辑的影响，去重只作用于"要不要展开某个分支"，不影响"要不要收集当前已经走到的路径"。

**复杂度分析**：排序耗时 O(n log n)，回溯过程本身最坏是 O(n × 2^n)（跟 0078 相同的量级，去重只是减少实际访问的重复分支数，不改变最坏情况的渐进复杂度上界）。

## 代码

### C++

```cpp
class Solution {
private:
    vector<vector<int>> result;
    vector<int> path;

    void backtrack(vector<int>& nums, int startIndex) {
        result.push_back(path);            // 子集问题：每个节点都收集，包括空集
        if (startIndex >= nums.size()) {
            return;
        }
        for (int i = startIndex; i < nums.size(); i++) {
            // 树层去重：i > startIndex 表示非本层第一个位置，值相同则跳过，
            // 避免生成与前一个分支完全相同的子集
            if (i > startIndex && nums[i] == nums[i - 1]) {
                continue;
            }
            path.push_back(nums[i]);        // 【选择】
            backtrack(nums, i + 1);         // 【递归】
            path.pop_back();                  // 【撤销选择】
        }
    }

public:
    vector<vector<int>> subsetsWithDup(vector<int>& nums) {
        sort(nums.begin(), nums.end());   // 排序，为树层去重做准备
        backtrack(nums, 0);
        return result;
    }
};
```

### Java

```java
class Solution {
    private List<List<Integer>> result = new ArrayList<>();
    private LinkedList<Integer> path = new LinkedList<>();

    public List<List<Integer>> subsetsWithDup(int[] nums) {
        Arrays.sort(nums);   // 排序，为树层去重做准备
        backtrack(nums, 0);
        return result;
    }

    private void backtrack(int[] nums, int startIndex) {
        result.add(new ArrayList<>(path));   // 子集问题：每个节点都收集
        if (startIndex >= nums.length) {
            return;
        }
        for (int i = startIndex; i < nums.length; i++) {
            // 树层去重：非本层第一个位置且值相同则跳过
            if (i > startIndex && nums[i] == nums[i - 1]) {
                continue;
            }
            path.addLast(nums[i]);       // 【选择】
            backtrack(nums, i + 1);      // 【递归】
            path.removeLast();             // 【撤销选择】
        }
    }
}
```

### Python

```python
class Solution:
    def subsetsWithDup(self, nums: list[int]) -> list[list[int]]:
        nums.sort()   # 排序，为树层去重做准备
        result = []
        path = []

        def backtrack(start_index: int):
            result.append(path[:])       # 子集问题：每个节点都收集
            if start_index >= len(nums):
                return
            for i in range(start_index, len(nums)):
                # 树层去重：i > start_index 表示非本层第一个位置，值相同则跳过
                if i > start_index and nums[i] == nums[i - 1]:
                    continue
                path.append(nums[i])       # 【选择】
                backtrack(i + 1)             # 【递归】
                path.pop()                    # 【撤销选择】

        backtrack(0)
        return result
```

func subsetsWithDup(nums []int) [][]int {
    sort.Ints(nums)   // 排序，为树层去重做准备
    var result [][]int
    var path []int

    var backtrack func(startIndex int)
    backtrack = func(startIndex int) {
        tmp := make([]int, len(path))
        copy(tmp, path)
        result = append(result, tmp)      // 子集问题：每个节点都收集
        if startIndex >= len(nums) {
            return
        }
        for i := startIndex; i < len(nums); i++ {
            // 树层去重：非本层第一个位置且值相同则跳过
            if i > startIndex && nums[i] == nums[i-1] {
                continue
            }
            path = append(path, nums[i])    // 【选择】
            backtrack(i + 1)                  // 【递归】
            path = path[:len(path)-1]          // 【撤销选择】
        }
    }
    backtrack(0)
    return result
}

## 总结

- 这题的去重逻辑跟 0040 组合总和 II 完全一样（排序后同层跳过相邻重复值），这说明"树层去重"是一个可以跨题型复用的通用技巧，不局限于组合问题。
- 子集问题"每个节点都收集"的特性和去重逻辑是相互独立的：去重决定要不要展开某个分支，收集结果的时机则始终是"进入函数就收集"，这两者互不冲突。
- `i > startIndex && nums[i] == nums[i-1]` 这个判断条件要牢牢记住：它只在同一层内比较相邻元素，不会影响跨层（树枝方向）的重复值被合法保留下来。
- 排序是几乎所有"数值去重"类回溯题目的前置步骤，你想啊，没有排序就没法简单通过比较相邻元素来判断是否重复。
