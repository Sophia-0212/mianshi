# 0047. 全排列 II

**题目描述**

给定一个可能包含重复数字的数组 `nums`，按任意顺序返回所有不重复的全排列。

```
示例：
输入: nums = [1,1,2]
输出: [[1,1,2],[1,2,1],[2,1,1]]
```

## 思路

排序＋回溯：每层遍历全部下标。跳过已用元素；若 `nums[i]==nums[i-1]` 且前一个相同元素未在当前路径使用，也跳过，避免同层重复。选满保存，返回时撤销。

最坏时间 O(n·n!)，辅助空间 O(n)，不计结果。

### LeetCode 写法与原有示例

```python
# 依赖说明：len：Python 内置函数：返回容器中元素的数量。；range：Python 内置函数：生成按步长遍历的整数序列。

class Solution:
    # 方法：permuteUnique；按题目要求处理输入并返回结果，核心算法见方法体。
    def permuteUnique(self, nums: list[int]) -> list[list[int]]:
        nums.sort()   # 排序，为树层去重提供相邻关系
        result = []
        path = []
        used = [False] * len(nums)

        # 方法：backtrack；按题目要求处理输入并返回结果，核心算法见方法体。
        def backtrack():
            if len(path) == len(nums):        # 终止条件
                result.append(path[:])
                return
            for i in range(len(nums)):
                # 树层去重：前一个相同值当前未被使用（used[i-1] is False），
                # 说明前一个刚被撤销，属于同层重复尝试，跳过；
                # 若前一个正被使用（在树枝上），则不跳过，允许出现如 [1,1,2] 这样的合法结果
                if i > 0 and nums[i] == nums[i - 1] and not used[i - 1]:
                    continue
                if used[i]:                       # 该元素已在当前路径使用，跳过
                    continue
                used[i] = True             # 【选择】
                path.append(nums[i])        # 【选择】
                backtrack()                   # 【递归】
                path.pop()                     # 【撤销选择】
                used[i] = False               # 【撤销选择】

        backtrack()
        return result```

// 方法：permuteUnique；按题目要求处理输入并返回结果，核心算法见方法体。
func permuteUnique(nums []int) [][]int {
    sort.Ints(nums)   // 排序，为树层去重提供相邻关系
    var result [][]int
    var path []int
    used := make([]bool, len(nums))

    var backtrack func()
    backtrack = func() {
        if len(path) == len(nums) {           // 终止条件
            tmp := make([]int, len(path))
            copy(tmp, path)
            result = append(result, tmp)
            return
        }
        for i := 0; i < len(nums); i++ {
            // 树层去重：前一个相同值当前未被使用，说明是同层重复尝试，跳过
            if i > 0 && nums[i] == nums[i-1] && !used[i-1] {
                continue
            }
            if used[i] {                         // 该元素已在当前路径使用，跳过
                continue
            }
            used[i] = true                 // 【选择】
            path = append(path, nums[i])   // 【选择】
            backtrack()                      // 【递归】
            path = path[:len(path)-1]         // 【撤销选择】
            used[i] = false                    // 【撤销选择】
        }
    }
    backtrack()
    return result
}
```

## C++

### LeetCode 写法与原有示例

```cpp
class Solution {
private:
    vector<vector<int>> result;
    vector<int> path;
    vector<bool> used;

    // 方法：backtrack；按题目要求处理输入并返回结果，核心算法见方法体。
    void backtrack(vector<int>& nums) {
        if (path.size() == nums.size()) {     // 终止条件：排列长度达到数组长度
            result.push_back(path);
            return;
        }
        for (int i = 0; i < nums.size(); i++) {
            // 树层去重：nums[i] 与前一个值相同，且前一个值当前未被使用（说明前一个刚被撤销，
            // 属于同层重复尝试），跳过；如果 used[i-1]==true 说明前一个值在树枝上，不跳过
            if (i > 0 && nums[i] == nums[i - 1] && !used[i - 1]) {
                continue;
            }
            if (used[i]) {                       // 该元素已在当前路径中使用，跳过
                continue;
            }
            used[i] = true;                // 【选择】标记已使用
            path.push_back(nums[i]);       // 【选择】加入路径
            backtrack(nums);               // 【递归】
            path.pop_back();                 // 【撤销选择】
            used[i] = false;                 // 【撤销选择】恢复未使用状态
        }
    }

public:
    vector<vector<int>> permuteUnique(vector<int>& nums) {
        sort(nums.begin(), nums.end());   // 排序，为树层去重提供相邻关系
        used.assign(nums.size(), false);
        backtrack(nums);
        return result;
    }
};
```

## 总结

- 排列去重的判断条件比组合去重多了 `!used[i-1]` 这一项，原因是排列问题没有 `startIndex` 区分层次，只能借助 `used` 的状态间接判断"前一个相同值是同层刚撤销的（要去重）"还是"跨层挂在路径上的（不去重）"。
- 理解 `used[i-1]` 的两种状态是这题的关键：`false` 代表同层重复尝试（去重），`true` 代表树枝上的合法重复（不去重），这跟组合问题里单纯依靠下标位置判断层次的方式完全不一样。
- `used` 数组在这题承担两个职责——防止同一元素重复使用（0046 已有的职责）和辅助去重判断（这题新增的职责），两者的判断逻辑要分开写清楚，不要混在一个条件里。
- 也可以把 `i > 0 && nums[i] == nums[i-1] && !used[i-1]` 改成 `&& used[i-1]`（跳过条件反过来），同样能正确去重，但效率上前者（跳过 `used[i-1]==false` 的情况）通常被认为剪枝更彻底，建议按本文的写法记忆，遇到变体时理解本质而不是死记条件式。
