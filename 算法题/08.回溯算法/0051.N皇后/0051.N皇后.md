# 0051. N 皇后

**题目描述**

按照国际象棋的规则，皇后可以攻击与它同一行、同一列或同一斜线上的棋子。`n` 皇后问题研究的是如何将 `n` 个皇后放置在 `n×n` 的棋盘上，并且使皇后彼此之间不能相互攻击。给定整数 `n`，返回所有不同的 `n` 皇后问题的解决方案，每一种解法包含不同的 `n` 皇后问题的棋子放置方案，其中 `Q` 和 `.` 分别代表皇后和空位。

```
示例：
输入: n = 4
输出：
[
  [".Q..","...Q","Q...","..Q."],
  ["..Q.","Q...","...Q",".Q.."]
]
解释：4 皇后问题存在两种不同的解法。
```

## 思路

N 皇后是经典的回溯棋盘问题，核心思路是"按行递归 + 每行放一个皇后前先检查冲突"。

**为什么用行数作为递归深度呢**：题目要求每行、每列、每条对角线上都最多只能有一个皇后。你想啊，如果用"按行递归"的方式——递归的第 `row` 层专门负责在第 `row` 行放置一个皇后，那么**同一行只放一个皇后**这个约束就被递归的结构天然满足了，完全不需要额外写代码去检查"同一行是否已经放过"。这就是这道题选择"以行数为递归深度"的巧妙之处：直接把其中一个约束条件融入了递归结构本身。

**递归树的结构**：树的深度是 `n`（对应棋盘的 `n` 行，每一层决定这一行皇后放在哪一列），树的每一层宽度是 `n`（这一行皇后可以尝试放在 0 到 n-1 的任意一列，具体能不能放需要检查冲突）。

**放置前需要检查哪三种冲突呢**（注意：不需要检查同行冲突，原因刚才说过了）：

1. **同列冲突**：检查棋盘上第 `col` 列，是否已经有其他行在这一列放置了皇后。
2. **左上到右下的对角线冲突（主对角线方向）**：判断方式是"行差等于列差"，也就是说，对于已放置的皇后 `(r, c)` 和当前要放置的位置 `(row, col)`，如果 `row - r == col - c`，说明它们在同一条主对角线上。
3. **右上到左下的对角线冲突（副对角线方向）**：判断方式是"行和列之和相等"，如果 `row + col == r + c`，说明它们在同一条副对角线上。

在实际代码里，通常不需要遍历所有已放置的皇后来分别判断这三种冲突，而是可以利用"棋盘按行递归"这个特性——**只需要检查当前要放置的位置往上（已经放置过皇后的那些行）三个方向（正上方、左上方、右上方）是否有冲突**，为什么呢？因为按行递归保证了下面的行还没有放置任何皇后，不需要检查下方。

**说说"选择 - 递归 - 撤销选择"这三步**：

1. 选择：在棋盘的 `[row][col]` 位置放置 `'Q'`。
2. 递归：处理下一行 `row+1`，继续放置皇后。
3. 撤销选择：递归返回后，把 `[row][col]` 位置重新恢复为 `'.'`，尝试这一行的下一个候选列。

**终止条件**：当 `row == n` 时，说明前面 `n` 行都成功放置了互不冲突的皇后，把当前棋盘状态转换成字符串数组形式，加入结果集。

**复杂度分析**：最坏情况下时间复杂度是 O(n!)（第一行有 n 种选择，第二行最多 n-1 种不冲突的选择，以此类推，实际因为冲突剪枝会远小于这个上界）。空间复杂度是 O(n^2)（棋盘存储）。

## 代码

### C++

```cpp
class Solution {
private:
    vector<vector<string>> result;
    vector<string> board;   // 棋盘，board[row] 是一个长度为 n 的字符串，'.'表示空，'Q'表示皇后

    bool isValid(int row, int col, int n) {
        // 检查同列：遍历当前行往上的所有行
        for (int r = 0; r < row; r++) {
            if (board[r][col] == 'Q') return false;      // 同列冲突
        }
        // 检查左上方对角线（主对角线方向，行列差递减）
        for (int r = row - 1, c = col - 1; r >= 0 && c >= 0; r--, c--) {
            if (board[r][c] == 'Q') return false;
        }
        // 检查右上方对角线（副对角线方向）
        for (int r = row - 1, c = col + 1; r >= 0 && c < n; r--, c++) {
            if (board[r][c] == 'Q') return false;
        }
        return true;   // 三种冲突都没有，可以放置
    }

    void backtrack(int row, int n) {
        if (row == n) {                     // 终止条件：n 行都放置完毕
            result.push_back(board);
            return;
        }
        for (int col = 0; col < n; col++) {    // 横向遍历：这一行皇后可以尝试放在哪一列
            if (!isValid(row, col, n)) continue;  // 剪枝：与已放置的皇后冲突，跳过
            board[row][col] = 'Q';         // 【选择】放置皇后
            backtrack(row + 1, n);         // 【递归】处理下一行
            board[row][col] = '.';           // 【撤销选择】恢复空位，尝试这一行的下一列
        }
    }

public:
    vector<vector<string>> solveNQueens(int n) {
        board.assign(n, string(n, '.'));   // 初始化 n×n 全空棋盘
        backtrack(0, n);
        return result;
    }
};
```

### Java

```java
class Solution {
    private List<List<String>> result = new ArrayList<>();
    private char[][] board;

    public List<List<String>> solveNQueens(int n) {
        board = new char[n][n];
        for (char[] row : board) Arrays.fill(row, '.');   // 初始化全空棋盘
        backtrack(0, n);
        return result;
    }

    private void backtrack(int row, int n) {
        if (row == n) {                        // 终止条件：n 行都放置完毕
            List<String> snapshot = new ArrayList<>();
            for (char[] r : board) snapshot.add(new String(r));
            result.add(snapshot);
            return;
        }
        for (int col = 0; col < n; col++) {       // 横向遍历：这一行的候选列
            if (!isValid(row, col, n)) continue;    // 剪枝：冲突则跳过
            board[row][col] = 'Q';            // 【选择】
            backtrack(row + 1, n);            // 【递归】
            board[row][col] = '.';              // 【撤销选择】
        }
    }

    private boolean isValid(int row, int col, int n) {
        for (int r = 0; r < row; r++) {              // 同列
            if (board[r][col] == 'Q') return false;
        }
        for (int r = row - 1, c = col - 1; r >= 0 && c >= 0; r--, c--) {  // 左上对角线
            if (board[r][c] == 'Q') return false;
        }
        for (int r = row - 1, c = col + 1; r >= 0 && c < n; r--, c++) {   // 右上对角线
            if (board[r][c] == 'Q') return false;
        }
        return true;
    }
}
```

### Python

```python
class Solution:
    def solveNQueens(self, n: int) -> list[list[str]]:
        result = []
        board = [['.'] * n for _ in range(n)]   # 初始化 n×n 全空棋盘

        def is_valid(row: int, col: int) -> bool:
            for r in range(row):                  # 检查同列
                if board[r][col] == 'Q':
                    return False
            r, c = row - 1, col - 1               # 检查左上方对角线
            while r >= 0 and c >= 0:
                if board[r][c] == 'Q':
                    return False
                r -= 1
                c -= 1
            r, c = row - 1, col + 1               # 检查右上方对角线
            while r >= 0 and c < n:
                if board[r][c] == 'Q':
                    return False
                r -= 1
                c += 1
            return True

        def backtrack(row: int):
            if row == n:                          # 终止条件：n 行都放置完毕
                result.append([''.join(r) for r in board])
                return
            for col in range(n):                    # 横向遍历：这一行的候选列
                if not is_valid(row, col):             # 剪枝：冲突则跳过
                    continue
                board[row][col] = 'Q'          # 【选择】
                backtrack(row + 1)              # 【递归】
                board[row][col] = '.'            # 【撤销选择】

        backtrack(0)
        return result
```

### Go

```go
func solveNQueens(n int) [][]string {
    var result [][]string
    board := make([][]byte, n)
    for i := range board {
        board[i] = make([]byte, n)
        for j := range board[i] {
            board[i][j] = '.'          // 初始化全空棋盘
        }
    }

    isValid := func(row, col int) bool {
        for r := 0; r < row; r++ {          // 检查同列
            if board[r][col] == 'Q' {
                return false
            }
        }
        for r, c := row-1, col-1; r >= 0 && c >= 0; r, c = r-1, c-1 {  // 左上对角线
            if board[r][c] == 'Q' {
                return false
            }
        }
        for r, c := row-1, col+1; r >= 0 && c < n; r, c = r-1, c+1 {   // 右上对角线
            if board[r][c] == 'Q' {
                return false
            }
        }
        return true
    }

    var backtrack func(row int)
    backtrack = func(row int) {
        if row == n {                       // 终止条件：n 行都放置完毕
            snapshot := make([]string, n)
            for i, r := range board {
                snapshot[i] = string(r)
            }
            result = append(result, snapshot)
            return
        }
        for col := 0; col < n; col++ {         // 横向遍历：这一行的候选列
            if !isValid(row, col) {              // 剪枝：冲突则跳过
                continue
            }
            board[row][col] = 'Q'          // 【选择】
            backtrack(row + 1)              // 【递归】
            board[row][col] = '.'            // 【撤销选择】
        }
    }
    backtrack(0)
    return result
}
```

## 总结

- 用"行数"作为递归深度是这题最巧妙的设计：它把"每行只能放一个皇后"这个约束直接融入了递归结构，代码里完全不需要专门检查同行冲突。
- 放置皇后前只需要检查"同列"和"两条对角线"这三个方向的冲突，而且因为按行递归的顺序，只需要检查已放置皇后所在的行（当前行的上方），不需要考虑下方尚未处理的行。
- 判断对角线冲突的两个数学关系要记牢：主对角线方向是"行差等于列差"（`row-r == col-c`），副对角线方向是"行列之和相等"（`row+col == r+c`），也可以用两个方向的双指针遍历来实现，效果是等价的。
- N 皇后是棋盘类回溯问题的入门代表，理解了"按维度递归、每层检查冲突、选择-递归-撤销"的模式之后，就可以进一步过渡到更复杂的棋盘问题了，比如数独。
