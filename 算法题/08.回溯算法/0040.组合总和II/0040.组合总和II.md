# 0040. 组合总和 II

**题目描述**

给定一个候选数组 `candidates` 和一个目标数 `target`，找出 `candidates` 中所有可以使数字和为 `target` 的组合。`candidates` 中的**每个数字在每个组合中只能使用一次**，但数组本身**可能包含重复数字**，解集不能包含重复的组合。

```
示例：
输入: candidates = [10,1,2,7,6,1,5], target = 8
输出:
[
[1,1,6],
[1,2,5],
[1,7],
[2,6]
]
```

## 思路

这题是回溯去重里的经典难题，为什么难呢？因为它同时具备两个容易混淆的特点：数组本身有重复元素，而且每个元素只能用一次。要同时避免"同一元素重复使用"和"不同位置的相同值元素导致的重复组合"，你得先把两种去重场景区分清楚。

**先排序**：所有去重技巧的前提都是先对 `candidates` 排序，这样相同的数值就会挨在一起，方便比较相邻元素。

**"树层去重" vs "树枝去重"，这里的关键是不要搞混**：

你把整个递归过程画成一棵树，树的每一层代表"这一次要选第几个数"，同一层内 for 循环遍历到的不同下标，对应的就是这一层的不同分支节点；而从根节点到某个叶子节点的一条路径，就是一条"树枝"。

- **树层去重（同一层内，避免选择相同的数值）**：在同一次 for 循环里，如果当前遍历到的数字和前一个遍历到的数字数值相同，那这两个分支往下递归得到的所有组合肯定是完全一样的集合——为什么呢？因为候选数字的值相同，位置不同并不影响组合的值，所以要跳过，只让"第一次遇到这个值"的那个分支继续递归。这是"横向"的重复，得避免。
- **树枝去重（同一条路径上，避免同一个数字被用两次）**：这题规定每个数字最多用一次，这个靠 `startIndex` 从 `i+1` 开始就已经保证了——"同一个下标不会被同一条路径选两次"，这是"纵向"沿着一条路径的约束，本身已经由标准的组合模板处理好了，不需要额外逻辑。

**代码上怎么区分这两种情况呢**：树层去重的判断条件是 `i > startIndex && candidates[i] == candidates[i-1]`。这里的 `i > startIndex` 是关键——它表示"当前 `i` 不是本层 for 循环的第一个位置"，也就是说前一个值 `candidates[i-1]` 在**同一层**已经被遍历并处理过了（不管是否被跳过），所以这次如果数值相同就要跳过。那如果去掉 `i > startIndex` 这个条件会怎样呢？直接判断 `candidates[i] == candidates[i-1]`，会错误地把"树枝"上的重复值也跳过——比如 `path` 里已经选了 `candidates[startIndex]`，接下来本应该可以选 `candidates[startIndex+1]`（哪怕数值相同也没关系，因为它们是不同位置的元素，允许出现在同一条路径里，比如示例里的 `[1,1,6]`），但如果不加 `i > startIndex` 判断，就会误将这个合法分支跳过。

换句话说：`i > startIndex` 保证了这次的"跳过判断"只发生在**新的一层 for 循环内部**（横向比较相邻分支），而不会影响到"递归进入下一层后，新的一层从 `startIndex` 开始的第一个数字"（这时候 `i == startIndex`，不受这条去重逻辑约束，哪怕它和上一层选的数值相同，也允许被选中，因为它们是树枝关系，不是树层关系）。

**剪枝**：排序之后，如果 `pathSum + candidates[i] > target`，说明后面的数字更大，必然也超过，直接 `break` 就行。

**终止条件**：`pathSum == target` 收集结果。

**复杂度分析**：最坏情况下时间复杂度还是指数级的（组合问题的通病），空间复杂度是 O(n)（排序）加上 O(target/min) 的递归深度。

## 代码

### C++

```cpp
class Solution {
private:
    vector<vector<int>> result;
    vector<int> path;
    int pathSum = 0;

    void backtrack(vector<int>& candidates, int target, int startIndex) {
        if (pathSum == target) {              // 终止条件：和恰好等于 target
            result.push_back(path);
            return;
        }
        for (int i = startIndex; i < candidates.size(); i++) {
            if (pathSum + candidates[i] > target) {  // 剪枝：已排序，超过 target 直接结束
                break;
            }
            // 树层去重：i > startIndex 表示不是本层第一个位置，
            // 且当前值与前一个值相同，说明这个分支和前一个分支会产生完全相同的组合，跳过
            if (i > startIndex && candidates[i] == candidates[i - 1]) {
                continue;
            }
            path.push_back(candidates[i]);       // 【选择】
            pathSum += candidates[i];
            backtrack(candidates, target, i + 1); // 【递归】i+1，保证同一数字不被重复使用（树枝去重已由此保证）
            pathSum -= candidates[i];              // 【撤销选择】
            path.pop_back();                        // 【撤销选择】
        }
    }

public:
    vector<vector<int>> combinationSum2(vector<int>& candidates, int target) {
        sort(candidates.begin(), candidates.end());  // 排序，为去重和剪枝做准备
        backtrack(candidates, target, 0);
        return result;
    }
};
```

### Java

```java
class Solution {
    private List<List<Integer>> result = new ArrayList<>();
    private LinkedList<Integer> path = new LinkedList<>();
    private int pathSum = 0;

    public List<List<Integer>> combinationSum2(int[] candidates, int target) {
        Arrays.sort(candidates);  // 排序，为去重和剪枝做准备
        backtrack(candidates, target, 0);
        return result;
    }

    private void backtrack(int[] candidates, int target, int startIndex) {
        if (pathSum == target) {                  // 终止条件：和恰好等于 target
            result.add(new ArrayList<>(path));
            return;
        }
        for (int i = startIndex; i < candidates.length; i++) {
            if (pathSum + candidates[i] > target) {  // 剪枝：已排序，超过 target 直接结束
                break;
            }
            // 树层去重：i > startIndex 说明不是本层第一个位置，值相同则跳过，
            // 避免产生和前一个分支完全相同的组合
            if (i > startIndex && candidates[i] == candidates[i - 1]) {
                continue;
            }
            path.addLast(candidates[i]);              // 【选择】
            pathSum += candidates[i];
            backtrack(candidates, target, i + 1);     // 【递归】i+1，同一数字不重复使用
            pathSum -= candidates[i];                  // 【撤销选择】
            path.removeLast();                          // 【撤销选择】
        }
    }
}
```

### Python

```python
class Solution:
    def combinationSum2(self, candidates: list[int], target: int) -> list[list[int]]:
        candidates.sort()  # 排序，为去重和剪枝做准备
        result = []
        path = []
        path_sum = 0

        def backtrack(start_index: int):
            nonlocal path_sum
            if path_sum == target:                  # 终止条件：和恰好等于 target
                result.append(path[:])
                return
            for i in range(start_index, len(candidates)):
                if path_sum + candidates[i] > target:   # 剪枝：已排序，超过 target 直接结束
                    break
                # 树层去重：i > start_index 表示不是本层第一个位置，
                # 值相同则说明会产生与前一个分支相同的组合，跳过
                if i > start_index and candidates[i] == candidates[i - 1]:
                    continue
                path.append(candidates[i])           # 【选择】
                path_sum += candidates[i]
                backtrack(i + 1)                       # 【递归】i+1，同一数字不重复使用
                path_sum -= candidates[i]               # 【撤销选择】
                path.pop()                               # 【撤销选择】

        backtrack(0)
        return result
```

```go
func combinationSum2(candidates []int, target int) [][]int {
    sort.Ints(candidates)  // 排序，为去重和剪枝做准备
    var result [][]int
    var path []int
    pathSum := 0

    var backtrack func(startIndex int)
    backtrack = func(startIndex int) {
        if pathSum == target {                        // 终止条件：和恰好等于 target
            tmp := make([]int, len(path))
            copy(tmp, path)
            result = append(result, tmp)
            return
        }
        for i := startIndex; i < len(candidates); i++ {
            if pathSum+candidates[i] > target {       // 剪枝：已排序，超过 target 直接结束
                break
            }
            // 树层去重：i > startIndex 表示不是本层第一个位置，值相同则跳过
            if i > startIndex && candidates[i] == candidates[i-1] {
                continue
            }
            path = append(path, candidates[i])        // 【选择】
            pathSum += candidates[i]
            backtrack(i + 1)                           // 【递归】i+1，同一数字不重复使用
            pathSum -= candidates[i]                     // 【撤销选择】
            path = path[:len(path)-1]                     // 【撤销选择】
        }
    }
    backtrack(0)
    return result
}
```

## 总结

- 树层去重解决的是"同一层内相邻分支值相同导致的重复组合"，树枝去重解决的是"同一条路径上同一个数字被重复使用"，这两者是完全不同维度的问题，这题需要同时处理。
- 树枝去重靠 `startIndex` 从 `i+1` 开始递归天然就满足了，不需要额外代码；树层去重则需要显式加上 `i > startIndex && candidates[i] == candidates[i-1]` 这个判断。
- `i > startIndex` 是树层去重判断里最容易漏掉、但又最关键的一个条件，它把去重的作用范围限定在"同一层的横向比较"，避免误伤合法的树枝分支（比如示例中的 `[1,1,6]`）。
- 排序是这题去重和剪枝能成立的共同前提，你想啊，没有排序，相同数值根本不会相邻，也就没法通过比较 `candidates[i]` 和 `candidates[i-1]` 来判断是否重复了。
