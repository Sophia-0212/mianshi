# 0040. 组合总和 II

**题目描述**

给定一个候选数组 `candidates` 和一个目标数 `target`，找出 `candidates` 中所有可以使数字和为 `target` 的组合。`candidates` 中的**每个数字在每个组合中只能使用一次**，但数组本身**可能包含重复数字**，解集不能包含重复的组合。

```
示例：
输入: candidates = [10,1,2,7,6,1,5], target = 8
输出:
[
[1,1,6],
[1,2,5],
[1,7],
[2,6]
]
```

## 思路

排序＋回溯：递归从 `i+1` 开始，每个元素仅用一次。同层遇到 `i>startIndex` 且与前值相等则跳过；和超目标直接结束循环，和等于目标保存结果，返回时撤销。

最坏时间 O(n·2ⁿ)，辅助空间 O(n)，不计结果。

```python
# 依赖说明：len：Python 内置函数：返回容器中元素的数量。；range：Python 内置函数：生成按步长遍历的整数序列。

class Solution:
    # 方法：combinationSum2；按题目要求处理输入并返回结果，核心算法见方法体。
    def combinationSum2(self, candidates: list[int], target: int) -> list[list[int]]:
        candidates.sort()  # 排序，为去重和剪枝做准备
        result = []
        path = []
        path_sum = 0

        # 方法：backtrack；按题目要求处理输入并返回结果，核心算法见方法体。
        def backtrack(start_index: int):
            nonlocal path_sum
            if path_sum == target:                  # 终止条件：和恰好等于 target
                result.append(path[:])
                return
            for i in range(start_index, len(candidates)):
                if path_sum + candidates[i] > target:   # 剪枝：已排序，超过 target 直接结束
                    break
                # 树层去重：i > start_index 表示不是本层第一个位置，
                # 值相同则说明会产生与前一个分支相同的组合，跳过
                if i > start_index and candidates[i] == candidates[i - 1]:
                    continue
                path.append(candidates[i])           # 【选择】
                path_sum += candidates[i]
                backtrack(i + 1)                       # 【递归】i+1，同一数字不重复使用
                path_sum -= candidates[i]               # 【撤销选择】
                path.pop()                               # 【撤销选择】

        backtrack(0)
        return result
```

// 方法：combinationSum2；按题目要求处理输入并返回结果，核心算法见方法体。
func combinationSum2(candidates []int, target int) [][]int {
    sort.Ints(candidates)  // 排序，为去重和剪枝做准备
    var result [][]int
    var path []int
    pathSum := 0

    var backtrack func(startIndex int)
    backtrack = func(startIndex int) {
        if pathSum == target {                        // 终止条件：和恰好等于 target
            tmp := make([]int, len(path))
            copy(tmp, path)
            result = append(result, tmp)
            return
        }
        for i := startIndex; i < len(candidates); i++ {
            if pathSum+candidates[i] > target {       // 剪枝：已排序，超过 target 直接结束
                break
            }
            // 树层去重：i > startIndex 表示不是本层第一个位置，值相同则跳过
            if i > startIndex && candidates[i] == candidates[i-1] {
                continue
            }
            path = append(path, candidates[i])        // 【选择】
            pathSum += candidates[i]
            backtrack(i + 1)                           // 【递归】i+1，同一数字不重复使用
            pathSum -= candidates[i]                     // 【撤销选择】
            path = path[:len(path)-1]                     // 【撤销选择】
        }
    }
    backtrack(0)
    return result
}

## C++

### LeetCode 写法与原有示例

```cpp
// 依赖说明：vector：C++ STL 动态数组。；sort：C++ STL algorithm 提供的排序函数。

class Solution {
private:
    vector<vector<int>> result;
    vector<int> path;
    int pathSum = 0;

    // 方法：backtrack；按题目要求处理输入并返回结果，核心算法见方法体。
    void backtrack(vector<int>& candidates, int target, int startIndex) {
        if (pathSum == target) {              // 终止条件：和恰好等于 target
            result.push_back(path);
            return;
        }
        for (int i = startIndex; i < candidates.size(); i++) {
            if (pathSum + candidates[i] > target) {  // 剪枝：已排序，超过 target 直接结束
                break;
            }
            // 树层去重：i > startIndex 表示不是本层第一个位置，
            // 且当前值与前一个值相同，说明这个分支和前一个分支会产生完全相同的组合，跳过
            if (i > startIndex && candidates[i] == candidates[i - 1]) {
                continue;
            }
            path.push_back(candidates[i]);       // 【选择】
            pathSum += candidates[i];
            backtrack(candidates, target, i + 1); // 【递归】i+1，保证同一数字不被重复使用（树枝去重已由此保证）
            pathSum -= candidates[i];              // 【撤销选择】
            path.pop_back();                        // 【撤销选择】
        }
    }

public:
    vector<vector<int>> combinationSum2(vector<int>& candidates, int target) {
        sort(candidates.begin(), candidates.end());  // 排序，为去重和剪枝做准备
        backtrack(candidates, target, 0);
        return result;
    }
};```

## 总结

- 树层去重解决的是"同一层内相邻分支值相同导致的重复组合"，树枝去重解决的是"同一条路径上同一个数字被重复使用"，这两者是完全不同维度的问题，这题需要同时处理。
- 树枝去重靠 `startIndex` 从 `i+1` 开始递归天然就满足了，不需要额外代码；树层去重则需要显式加上 `i > startIndex && candidates[i] == candidates[i-1]` 这个判断。
- `i > startIndex` 是树层去重判断里最容易漏掉、但又最关键的一个条件，它把去重的作用范围限定在"同一层的横向比较"，避免误伤合法的树枝分支（比如示例中的 `[1,1,6]`）。
- 排序是这题去重和剪枝能成立的共同前提，你想啊，没有排序，相同数值根本不会相邻，也就没法通过比较 `candidates[i]` 和 `candidates[i-1]` 来判断是否重复了。
