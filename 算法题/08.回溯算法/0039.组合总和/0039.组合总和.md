# 0039. 组合总和

**题目描述**

给定一个无重复元素的整数数组 `candidates` 和一个目标整数 `target`，找出 `candidates` 中可以使数字和为目标数 `target` 的所有不同组合，`candidates` 中的**同一个数字可以无限制重复被选取**。返回的组合中不能有重复的组合。

```
示例：
输入: candidates = [2,3,6,7], target = 7
输出: [[2,2,3],[7]]

输入: candidates = [2,3,5], target = 8
输出: [[2,2,2,2],[2,3,3],[3,5]]
```

## 思路

这题和 0077/0216 的核心区别其实就一点：**同一个元素可以被重复选取**，但你想啊，这个区别会直接体现在递归调用传参上，改动不大，理解起来却很关键。

**递归树的结构**：这题仍然是组合类问题，`path` 记录当前选择的数字，`sum(path) == target` 的时候就收集结果。区别在哪呢？每一层的候选集合不再是"比上一层大的数字"了，而是"从上一层选择的位置开始（包含自身）"的所有数字，为什么呢？因为同一个数字现在可以重复使用了。

**为什么递归时传的是 `i` 而不是 `i+1`**：这里的关键是，0077 题里递归调用是 `backtrack(n, k, i+1)`，目的是避免同一个数字被重复选取（下一层从 `i` 之后开始选）。但这道题允许同一个数字重复选取，所以递归调用要传 `backtrack(candidates, target, i)`，这样才能让下一层仍然可以从 `i` 这个位置开始选——也就是还能再选一次 `candidates[i]`。

**那为什么还要保留 `startIndex` 呢**：你可能会想，既然能重复选了，是不是就不需要 `startIndex` 了？其实不是，虽然同一个数字可以重复选，但**不同数字之间仍然不能乱序选**，不然 `[2,2,3]` 和 `[2,3,2]` 就会被当成两个不同的组合重复统计了。`startIndex` 的作用就是保证每一层只能选"不小于上一层已选数字"的数字，从而保证结果里的数字是非递减排列的，这样就天然避免了顺序不同的重复组合。

**剪枝怎么做**：跟 0216 题类似，如果排序后发现 `candidates[i] > 剩余目标值（target - pathSum）`，说明从 `i` 开始往后的数字（排序后更大）都不可能再满足了，可以直接结束 for 循环。不过这个剪枝得先对 `candidates` 排序才能生效。

**终止条件**：`pathSum == target` 的时候收集结果并返回；`pathSum > target` 的时候直接返回，不用收集，也不用继续递归了，因为再往下加数字只会让和更大，没有意义。

**复杂度分析**：由于允许重复选取，递归树的深度就不再固定为某个常数了，最坏情况下深度能达到 `target / min(candidates)`。时间复杂度不太好精确表示，一般记为和目标值、候选数组大小相关的指数级；空间复杂度是 O(target / min(candidates))，也就是最大递归深度。

## 代码

### C++

```cpp
class Solution {
private:
    vector<vector<int>> result;
    vector<int> path;
    int pathSum = 0;

    void backtrack(vector<int>& candidates, int target, int startIndex) {
        if (pathSum == target) {           // 终止条件：和恰好等于 target
            result.push_back(path);
            return;
        }
        for (int i = startIndex; i < candidates.size(); i++) {
            if (pathSum + candidates[i] > target) {  // 剪枝：candidates 已排序，超过 target 直接结束
                break;
            }
            path.push_back(candidates[i]);   // 【选择】
            pathSum += candidates[i];
            backtrack(candidates, target, i);  // 【递归】传 i 而不是 i+1，允许重复选取当前数字
            pathSum -= candidates[i];          // 【撤销选择】
            path.pop_back();                    // 【撤销选择】
        }
    }

public:
    vector<vector<int>> combinationSum(vector<int>& candidates, int target) {
        sort(candidates.begin(), candidates.end());  // 排序是剪枝的前提
        backtrack(candidates, target, 0);
        return result;
    }
};
```

### Java

```java
class Solution {
    private List<List<Integer>> result = new ArrayList<>();
    private LinkedList<Integer> path = new LinkedList<>();
    private int pathSum = 0;

    public List<List<Integer>> combinationSum(int[] candidates, int target) {
        Arrays.sort(candidates);           // 排序是剪枝的前提
        backtrack(candidates, target, 0);
        return result;
    }

    private void backtrack(int[] candidates, int target, int startIndex) {
        if (pathSum == target) {           // 终止条件：和恰好等于 target
            result.add(new ArrayList<>(path));
            return;
        }
        for (int i = startIndex; i < candidates.length; i++) {
            if (pathSum + candidates[i] > target) {  // 剪枝：已排序，超过 target 直接结束循环
                break;
            }
            path.addLast(candidates[i]);      // 【选择】
            pathSum += candidates[i];
            backtrack(candidates, target, i); // 【递归】传 i，允许重复选取当前数字
            pathSum -= candidates[i];          // 【撤销选择】
            path.removeLast();                 // 【撤销选择】
        }
    }
}
```

### Python

```python
class Solution:
    def combinationSum(self, candidates: list[int], target: int) -> list[list[int]]:
        candidates.sort()  # 排序是剪枝的前提
        result = []
        path = []
        path_sum = 0

        def backtrack(start_index: int):
            nonlocal path_sum
            if path_sum == target:              # 终止条件：和恰好等于 target
                result.append(path[:])
                return
            for i in range(start_index, len(candidates)):
                if path_sum + candidates[i] > target:  # 剪枝：已排序，超过 target 直接结束
                    break
                path.append(candidates[i])       # 【选择】
                path_sum += candidates[i]
                backtrack(i)                      # 【递归】传 i，允许重复选取当前数字（不是 i+1）
                path_sum -= candidates[i]          # 【撤销选择】
                path.pop()                          # 【撤销选择】

        backtrack(0)
        return result
```

### Go

```go
func combinationSum(candidates []int, target int) [][]int {
    sort.Ints(candidates)  // 排序是剪枝的前提
    var result [][]int
    var path []int
    pathSum := 0

    var backtrack func(startIndex int)
    backtrack = func(startIndex int) {
        if pathSum == target {                    // 终止条件：和恰好等于 target
            tmp := make([]int, len(path))
            copy(tmp, path)
            result = append(result, tmp)
            return
        }
        for i := startIndex; i < len(candidates); i++ {
            if pathSum+candidates[i] > target {   // 剪枝：已排序，超过 target 直接结束
                break
            }
            path = append(path, candidates[i])    // 【选择】
            pathSum += candidates[i]
            backtrack(i)                           // 【递归】传 i，允许重复选取当前数字
            pathSum -= candidates[i]                // 【撤销选择】
            path = path[:len(path)-1]               // 【撤销选择】
        }
    }
    backtrack(0)
    return result
}
```

## 总结

- 跟 0077/0216 的核心区别其实就是递归调用传参从 `i+1` 变成了 `i`，一字之差，却决定了"当前元素能不能被重复选取"，这是理解这道题最关键的一点。
- `startIndex` 依然保留，但它的作用变了：从"避免同一数字重复选取"变成了"避免不同数字的选择顺序导致重复组合"，这两个作用一定要分清楚，不能混为一谈。
- 剪枝依赖排序：先排好序之后，一旦当前候选数字加上路径和超过了 target，后面的候选数字（更大）必然也会超过，这时候可以直接 `break`，而不是 `continue`。
- 递归深度不再受固定的 `k` 限制了，而是取决于 `target` 和候选数组里最小值的比值，这就是允许重复选取带来的直接影响。
