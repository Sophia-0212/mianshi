# 0077. 组合

**题目描述**

给定两个整数 `n` 和 `k`，返回范围 `[1, n]` 中所有可能的 `k` 个数的组合。可以按任何顺序返回答案。

```
示例：
输入：n = 4, k = 2
输出：
[
  [2,4],
  [3,4],
  [2,3],
  [1,2],
  [1,3],
  [1,4],
]
```

要求：组合不强调顺序，`[2,4]` 和 `[4,2]` 算同一种组合，只能出现一次。

## 思路

- 回溯：从 `startIndex` 递增选数，下一层从 `i+1` 开始，选满 k 个保存，返回时撤销。未剪枝时间上界 O(2ⁿ+k·C(n,k))，辅助空间 O(k)。
- 库函数：`itertools.combinations` 枚举组合后转列表。时间 O(n+k·C(n,k))，辅助空间 O(n)，不计结果。

```python
from itertools import combinations

# 依赖说明：Python 标准库 itertools：提供高效的迭代器工具。；range：Python 内置函数：生成按步长遍历的整数序列。

    def combine(self, n: int, k: int) -> list[list[int]]:

```


手写实现（还原回溯算法源码，面试真正考察的写法）：

```python
# 依赖说明：len：Python 内置函数：返回容器中元素的数量。；range：Python 内置函数：生成按步长遍历的整数序列。

class Solution:
    # 方法：combine；按题目要求处理输入并返回结果，核心算法见方法体。
    def combine(self, n: int, k: int) -> list[list[int]]:
        result = []  # 收集所有组合结果
        path = []    # 当前递归路径

        # 方法：backtrack；按题目要求处理输入并返回结果，核心算法见方法体。
        def backtrack(start_index: int):
            if len(path) == k:              # 终止条件：已经选够 k 个数
                result.append(path[:])      # 收集路径的拷贝（切片复制，不能直接 append(path)）
                return
            for i in range(start_index, n + 1):  # 横向遍历：本层可选的数字
                path.append(i)              # 【选择】把 i 加入路径
                backtrack(i + 1)            # 【递归】纵向进入下一层，起点为 i+1
                path.pop()                  # 【撤销选择】回退，尝试下一个候选

        backtrack(1)
        return result
```

### LeetCode 写法与原有示例

```go
// 方法：combine；按题目要求处理输入并返回结果，核心算法见方法体。
func combine(n int, k int) [][]int {
    var result [][]int  // 收集所有组合结果
    var path []int       // 当前递归路径

    var backtrack func(startIndex int)
    backtrack = func(startIndex int) {
        if len(path) == k {                  // 终止条件：已经选够 k 个数
            tmp := make([]int, len(path))
            copy(tmp, path)                  // 拷贝当前路径，避免后续修改影响已收集结果
            result = append(result, tmp)
            return
        }
        for i := startIndex; i <= n; i++ {   // 横向遍历：本层可选的数字
            path = append(path, i)           // 【选择】把 i 加入路径
            backtrack(i + 1)                 // 【递归】纵向进入下一层
            path = path[:len(path)-1]        // 【撤销选择】回退，尝试下一个候选
        }
    }
    backtrack(1)
    return result
}
```

## C++

### LeetCode 写法与原有示例

```cpp
// 依赖说明：vector：C++ STL 动态数组。

class Solution {
private:
    vector<vector<int>> result;  // 收集所有组合结果
    vector<int> path;            // 当前递归路径（当前已选的数字）

    // 方法：backtrack；按题目要求处理输入并返回结果，核心算法见方法体。
    void backtrack(int n, int k, int startIndex) {
        if (path.size() == k) {          // 终止条件：已经选够 k 个数
            result.push_back(path);      // 收集当前路径（拷贝）
            return;
        }
        for (int i = startIndex; i <= n; i++) {  // 横向遍历：本层可选的数字
            path.push_back(i);              // 【选择】把 i 加入路径
            backtrack(n, k, i + 1);         // 【递归】纵向进入下一层，起点为 i+1
            path.pop_back();                // 【撤销选择】回退，尝试下一个候选
        }
    }

public:
    vector<vector<int>> combine(int n, int k) {
        backtrack(n, k, 1);  // 从数字 1 开始选
        return result;
    }
};```

## 总结

- `startIndex` 是组合类问题避免重复的核心手段，说白了就是让每一层递归只能从"上一层选择的数字之后"开始选，这样天然就保证了结果里数字是递增排列的，也就不会出现顺序不同但内容相同的重复组合。
- 递归树的深度对应的是"还需要选几个数"，宽度对应的是"当前层还有多少候选数字可选"，你把这棵树画出来，就能直观理解为什么需要终止条件和 `startIndex` 了。
- "选择 - 递归 - 撤销选择"这三步里，撤销选择（也就是 `pop`/`removeLast`）是最容易被忽略、但又必不可少的一步——没有这一步，`path` 会一直累积下去，没法正确回退到上一层的状态。
- 还有个细节要注意：Python 和 Java 里收集结果的时候必须拷贝一份 `path`（比如 `path[:]`、`new ArrayList<>(path)`），为什么呢？因为 `path` 是引用类型，后续的修改会影响到已经存进 `result` 里的记录。
