# 0077. 组合

**题目描述**

给定两个整数 `n` 和 `k`，返回范围 `[1, n]` 中所有可能的 `k` 个数的组合。可以按任何顺序返回答案。

```
示例：
输入：n = 4, k = 2
输出：
[
  [2,4],
  [3,4],
  [2,3],
  [1,2],
  [1,3],
  [1,4],
]
```

要求：组合不强调顺序，`[2,4]` 和 `[4,2]` 算同一种组合，只能出现一次。

## 思路

这题算是回溯法的入门题，也是"组合类"问题的标准模型，我先讲讲怎么想。

**这道题该怎么画递归树呢**：你可以把整个搜索过程想象成一棵树——根节点就是"还没选任何数"的状态，每往下一层，代表"这是在选第几个数"，因为一共要选 `k` 个数，所以你想啊，**树的深度自然就是 `k`**；然后每一层里能从当前剩余的候选数字里选一个，候选数字最多有 `n` 个，所以**树的宽度最多就是 `n`**。拿 `n=4, k=2` 举个例子，第一层可以在 1、2、3、4 里选一个，选完第一个数之后，关键是什么呢？第二层只能从"比第一个数大"的数字里选——为什么要这么限制？就是为了避免出现顺序不同但内容一样的重复组合，比如你选了 `[2,1]`，那就不该再选出 `[1,2]` 了。这也是为什么我们需要引入 `startIndex` 这个东西。

**横向遍历和纵向递归怎么理解**：

- **横向遍历，也就是 for 循环**：在当前这一层，从 `startIndex` 开始一直遍历到 `n`，每个数字都是一个可选的分支。
- **纵向递归，就是 backtrack 调用**：选定一个数字之后，递归进入下一层，这里的关键是传进去的 `startIndex` 要变成"当前选的数字 + 1"，这样才能保证下一层只能选比当前数字更大的数，从根本上避免顺序不同但内容相同的重复组合。

**终止条件是什么**：当 `path` 的长度达到 `k` 的时候，说明已经选够了 `k` 个数，这时候把 `path` 拷贝一份加入 `result`，然后直接返回——不用再继续往下递归了，因为已经不需要再选更多数字了。

**说说"选择 - 递归 - 撤销选择"这三步**：

1. 选择：把当前遍历到的数字 `i` 加入 `path`。
2. 递归：调用 `backtrack(n, k, i+1)`。这里要注意，传的是 `i+1`，不是 `startIndex+1`，为什么呢？因为要保证下一层从"当前选择的数字之后"开始选，而不是从"这一层开始遍历的位置之后"开始选，这两者是不一样的。
3. 撤销选择：递归调用返回之后，把刚加入 `path` 的数字弹出来，这样 for 循环才能继续尝试当前层的下一个数字。

**复杂度怎么分析**：这是一棵最多 `k` 层、每层最多 `n` 个分支的树，不考虑剪枝的话，时间复杂度大概是 O(C(n,k) × k)，也就是组合数乘上 k，因为每找到一个合法组合，还需要 O(k) 的时间把它复制到 `result` 里。空间复杂度是 O(k)，也就是递归栈的深度加上 `path` 的长度。

## 代码

### C++

```cpp
class Solution {
private:
    vector<vector<int>> result;  // 收集所有组合结果
    vector<int> path;            // 当前递归路径（当前已选的数字）

    void backtrack(int n, int k, int startIndex) {
        if (path.size() == k) {          // 终止条件：已经选够 k 个数
            result.push_back(path);      // 收集当前路径（拷贝）
            return;
        }
        for (int i = startIndex; i <= n; i++) {  // 横向遍历：本层可选的数字
            path.push_back(i);              // 【选择】把 i 加入路径
            backtrack(n, k, i + 1);         // 【递归】纵向进入下一层，起点为 i+1
            path.pop_back();                // 【撤销选择】回退，尝试下一个候选
        }
    }

public:
    vector<vector<int>> combine(int n, int k) {
        backtrack(n, k, 1);  // 从数字 1 开始选
        return result;
    }
};
```

### Java

```java
class Solution {
    private List<List<Integer>> result = new ArrayList<>();  // 收集所有组合结果
    private LinkedList<Integer> path = new LinkedList<>();   // 当前递归路径

    public List<List<Integer>> combine(int n, int k) {
        backtrack(n, k, 1);
        return result;
    }

    private void backtrack(int n, int k, int startIndex) {
        if (path.size() == k) {              // 终止条件：已经选够 k 个数
            result.add(new ArrayList<>(path)); // 收集当前路径的拷贝（不能直接存引用）
            return;
        }
        for (int i = startIndex; i <= n; i++) {  // 横向遍历：本层可选的数字
            path.addLast(i);                 // 【选择】把 i 加入路径
            backtrack(n, k, i + 1);          // 【递归】纵向进入下一层
            path.removeLast();               // 【撤销选择】回退，尝试下一个候选
        }
    }
}
```

手写实现（还原回溯算法源码，面试真正考察的写法）：

```python
class Solution:
    def combine(self, n: int, k: int) -> list[list[int]]:
        result = []  # 收集所有组合结果
        path = []    # 当前递归路径

        def backtrack(start_index: int):
            if len(path) == k:              # 终止条件：已经选够 k 个数
                result.append(path[:])      # 收集路径的拷贝（切片复制，不能直接 append(path)）
                return
            for i in range(start_index, n + 1):  # 横向遍历：本层可选的数字
                path.append(i)              # 【选择】把 i 加入路径
                backtrack(i + 1)            # 【递归】纵向进入下一层，起点为 i+1
                path.pop()                  # 【撤销选择】回退，尝试下一个候选

        backtrack(1)
        return result
```

### Go

```go
func combine(n int, k int) [][]int {
    var result [][]int  // 收集所有组合结果
    var path []int       // 当前递归路径

    var backtrack func(startIndex int)
    backtrack = func(startIndex int) {
        if len(path) == k {                  // 终止条件：已经选够 k 个数
            tmp := make([]int, len(path))
            copy(tmp, path)                  // 拷贝当前路径，避免后续修改影响已收集结果
            result = append(result, tmp)
            return
        }
        for i := startIndex; i <= n; i++ {   // 横向遍历：本层可选的数字
            path = append(path, i)           // 【选择】把 i 加入路径
            backtrack(i + 1)                 // 【递归】纵向进入下一层
            path = path[:len(path)-1]        // 【撤销选择】回退，尝试下一个候选
        }
    }
    backtrack(1)
    return result
}
```

## 总结

- `startIndex` 是组合类问题避免重复的核心手段，说白了就是让每一层递归只能从"上一层选择的数字之后"开始选，这样天然就保证了结果里数字是递增排列的，也就不会出现顺序不同但内容相同的重复组合。
- 递归树的深度对应的是"还需要选几个数"，宽度对应的是"当前层还有多少候选数字可选"，你把这棵树画出来，就能直观理解为什么需要终止条件和 `startIndex` 了。
- "选择 - 递归 - 撤销选择"这三步里，撤销选择（也就是 `pop`/`removeLast`）是最容易被忽略、但又必不可少的一步——没有这一步，`path` 会一直累积下去，没法正确回退到上一层的状态。
- 还有个细节要注意：Python 和 Java 里收集结果的时候必须拷贝一份 `path`（比如 `path[:]`、`new ArrayList<>(path)`），为什么呢？因为 `path` 是引用类型，后续的修改会影响到已经存进 `result` 里的记录。
