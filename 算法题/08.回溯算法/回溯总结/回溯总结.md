# 回溯总结

回溯模板：选择→递归→撤销；结果保存副本，剪掉确定无解的分支。

```
result = []
path = []

function backtrack(参数):
    if (终止条件):
        result.add(path 的拷贝)   // 或者：在函数入口处收集（子集类问题）
        return
    for 选择 in 本层可选择的集合:
        path.add(选择)          // 【选择】
        backtrack(更新后的参数)   // 【递归】
        path.removeLast()       // 【撤销选择】
```

| 类型 | 关键状态 | 保存条件 |
|---|---|---|
| 组合 | 起始下标、长度／和 | 达到目标 |
| 切割 | 下一段起点 | 恰好耗尽字符串 |
| 子集 | 起始下标 | 每层入口，按题意过滤长度 |
| 排列 | 已用下标 | 选满元素 |
| 棋盘 | 行／空格、冲突标记 | 全部放置完成 |

可排序时用相邻比较做同层去重；需保留原序时用每层独立集合。起点传 i 允许重复用，传 i+1 则不允许。

时间取决于搜索树与输出复制，子集常为 O(n·2ⁿ)、排列 O(n·n!)；辅助空间包括路径、递归栈及标记，结果另计。
