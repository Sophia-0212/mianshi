# 20201112 回溯周末总结

| 类型 | 下一层候选 | 路径占用 | 保存时机 |
|---|---|---|---|
| 组合 | 从 i+1 开始；可重复选时从 i 开始 | 起点控制 | 满足长度／总和 |
| 子集 | 从 i+1 开始 | 起点控制 | 每层入口 |
| 排列 | 每次遍历全部下标 | `used` 数组 | 选满 n 个 |

排序后同层去重：组合／子集跳过 `i>start && nums[i]==nums[i-1]`；排列还须判断 `!used[i-1]`，保留路径中选取另一份相同值的可能。

子集最坏时间 O(n·2ⁿ)，排列 O(n·n!)；辅助空间 O(n)，结果另计。
