# 0078. 子集

**题目描述**

给定一个不含重复元素的整数数组 `nums`，返回该数组所有可能的子集（幂集）。解集不能包含重复的子集，可以按任意顺序返回。

```
示例：
输入: nums = [1,2,3]
输出: [[],[1],[1,2],[1,2,3],[1,3],[2],[2,3],[3]]
```

## 思路

回溯：进入每层都保存当前路径，包括空集；枚举后续元素，选入后从 `i+1` 递归，返回时撤销。也可枚举长度 0～n，用 `itertools.combinations` 生成各长度子集。

时间 O(n·2ⁿ)，辅助空间 O(n)，不计结果。

### LeetCode 写法与原有示例

标准库对比（`itertools.combinations` 枚举各个长度的组合再拼起来可以得到所有子集，但需要循环长度 0 到 n，本质仍是绕不开手写逻辑的封装，这里仅作对比）：

```python
from itertools import combinations

# 依赖说明：Python 标准库 itertools：提供高效的迭代器工具。；len：Python 内置函数：返回容器中元素的数量。；range：Python 内置函数：生成按步长遍历的整数序列。

class Solution:
    # 方法：subsets；按题目要求处理输入并返回结果，核心算法见方法体。
    def subsets(self, nums: list[int]) -> list[list[int]]:
        result = []
        for size in range(len(nums) + 1):          # 依次枚举子集长度 0 到 n
            result.extend(list(c) for c in combinations(nums, size))
        return result```


手写回溯实现（体现"每个节点都收集"的核心逻辑）：

```python
# 依赖说明：len：Python 内置函数：返回容器中元素的数量。；range：Python 内置函数：生成按步长遍历的整数序列。

class Solution:
    # 方法：subsets；按题目要求处理输入并返回结果，核心算法见方法体。
    def subsets(self, nums: list[int]) -> list[list[int]]:
        result = []
        path = []

        # 方法：backtrack；按题目要求处理输入并返回结果，核心算法见方法体。
        def backtrack(start_index: int):
            result.append(path[:])       # 关键区别：每次进入函数都收集当前路径（包括空集）
            if start_index >= len(nums):   # 终止条件：没有更多元素可选
                return
            for i in range(start_index, len(nums)):   # 横向遍历
                path.append(nums[i])        # 【选择】
                backtrack(i + 1)              # 【递归】
                path.pop()                     # 【撤销选择】

        backtrack(0)
        return result```

## Go

### LeetCode 写法与原有示例

```go
// 方法：subsets；按题目要求处理输入并返回结果，核心算法见方法体。
func subsets(nums []int) [][]int {
    var result [][]int
    var path []int

    var backtrack func(startIndex int)
    backtrack = func(startIndex int) {
        tmp := make([]int, len(path))
        copy(tmp, path)
        result = append(result, tmp)    // 关键区别：每次进入函数都收集当前路径
        if startIndex >= len(nums) {      // 终止条件：没有更多元素可选
            return
        }
        for i := startIndex; i < len(nums); i++ {  // 横向遍历
            path = append(path, nums[i])   // 【选择】
            backtrack(i + 1)                 // 【递归】
            path = path[:len(path)-1]         // 【撤销选择】
        }
    }
    backtrack(0)
    return result
}
```

## C++

### LeetCode 写法与原有示例

```cpp
class Solution {
private:
    vector<vector<int>> result;
    vector<int> path;

    // 方法：backtrack；按题目要求处理输入并返回结果，核心算法见方法体。
    void backtrack(vector<int>& nums, int startIndex) {
        result.push_back(path);      // 关键区别：每进入一次函数就收集当前路径，而不是等到叶子节点
        if (startIndex >= nums.size()) {   // 终止条件：没有更多元素可选，自然结束
            return;
        }
        for (int i = startIndex; i < nums.size(); i++) {  // 横向遍历：本层可选的元素
            path.push_back(nums[i]);        // 【选择】
            backtrack(nums, i + 1);         // 【递归】纵向进入下一层
            path.pop_back();                  // 【撤销选择】
        }
    }

public:
    vector<vector<int>> subsets(vector<int>& nums) {
        backtrack(nums, 0);
        return result;
    }
};
```

## 总结

- 子集问题与组合、切割问题最本质的区别是：组合、切割问题收集的是树的叶子节点（满足特定条件才收集），子集问题收集的是树的**所有节点**（每次进入递归函数就收集，不需要额外的终止条件判断）。
- 代码上的调整其实很小——就是把收集结果的代码从"终止条件判断之后"移到"函数最开始"，但背后的思路转变（叶子节点 vs 所有节点）得理解清楚，不然遇到类似的变形题容易写错。
- 终止条件在子集问题里依然存在，但它的作用变成了"没有更多元素可选时停止递归"，不再承担"决定是否收集结果"的职责，这点要分清楚。
- `n` 个元素的子集总数是 `2^n`，这是判断子集类问题时间复杂度的常用基准，跟组合问题的 `C(n,k)` 形成对比，记住这个对比能帮你快速估算复杂度。
