# 0491. 递增子序列

**题目描述**

给定一个整数数组 `nums`，找出并返回所有该数组中不同的递增子序列，递增子序列中**至少有两个元素**。数组中可能含有重复元素，如果出现两个由**相同数字序列**组成的递增子序列，只需要返回一个。

```
示例：
输入: nums = [4,6,7,7]
输出: [[4,6],[4,6,7],[4,6,7,7],[4,7],[4,7,7],[6,7],[6,7,7],[7,7]]

输入: nums = [4,4,3,2,1]
输出: [[4,4]]
```

## 思路

回溯保持原下标顺序，不能排序。只选不小于路径末值的元素；每层用独立集合跳过重复值。长度至少为 2 就保存，递归从 `i+1` 开始，返回时撤销路径。

最坏时间 O(n·2ⁿ)，辅助空间 O(n·min(n,U))，不计结果；U 为值域大小，本题固定值域下为 O(n)。

# 依赖说明：len：Python 内置函数：返回容器中元素的数量。；range：Python 内置函数：生成按步长遍历的整数序列。

class Solution:
    # 方法：findSubsequences；按题目要求处理输入并返回结果，核心算法见方法体。
    def findSubsequences(self, nums: list[int]) -> list[list[int]]:
        result = []
        path = []

        # 方法：backtrack；按题目要求处理输入并返回结果，核心算法见方法体。
        def backtrack(start_index: int):
            if len(path) >= 2:               # 满足长度>=2的每个节点都收集
                result.append(path[:])
            used = set()                      # 本层去重专用，局部变量，每次进入函数重新创建
            for i in range(start_index, len(nums)):
                # 递增校验：path 非空时，当前值必须 >= path 最后一个元素
                if path and nums[i] < path[-1]:
                    continue
                # 树层去重：不排序，直接用哈希 set 判断本层是否已用过这个值
                if nums[i] in used:
                    continue
                used.add(nums[i])             # 记录本层已使用的数值
                path.append(nums[i])           # 【选择】
                backtrack(i + 1)                 # 【递归】
                path.pop()                        # 【撤销选择】

        backtrack(0)
        return result```

## Go

### LeetCode 写法与原有示例

```go
// 方法：findSubsequences；按题目要求处理输入并返回结果，核心算法见方法体。
func findSubsequences(nums []int) [][]int {
    var result [][]int
    var path []int

    var backtrack func(startIndex int)
    backtrack = func(startIndex int) {
        if len(path) >= 2 {                    // 满足长度>=2的每个节点都收集
            tmp := make([]int, len(path))
            copy(tmp, path)
            result = append(result, tmp)
        }
        used := make(map[int]bool)              // 本层去重专用，局部变量，每次进入函数重新创建
        for i := startIndex; i < len(nums); i++ {
            // 递增校验：path 非空时，当前值必须 >= path 最后一个元素
            if len(path) > 0 && nums[i] < path[len(path)-1] {
                continue
            }
            // 树层去重：不排序，直接用哈希 map 判断本层是否已用过这个值
            if used[nums[i]] {
                continue
            }
            used[nums[i]] = true               // 记录本层已使用的数值
            path = append(path, nums[i])        // 【选择】
            backtrack(i + 1)                      // 【递归】
            path = path[:len(path)-1]              // 【撤销选择】
        }
    }
    backtrack(0)
    return result
}
```

## C++

### LeetCode 写法与原有示例

```cpp
class Solution {
private:
    vector<vector<int>> result;
    vector<int> path;

    // 方法：backtrack；按题目要求处理输入并返回结果，核心算法见方法体。
    void backtrack(vector<int>& nums, int startIndex) {
        if (path.size() >= 2) {          // 子序列问题：满足长度>=2的每个节点都收集
            result.push_back(path);
        }
        unordered_set<int> used;          // 本层去重专用，只在当前递归层生效（局部变量）
        for (int i = startIndex; i < nums.size(); i++) {
            // 递增校验：path 非空时，当前值必须 >= path 最后一个元素
            if (!path.empty() && nums[i] < path.back()) {
                continue;
            }
            // 树层去重：本层已经用过这个数值，跳过（不依赖排序，直接用哈希 set 记录）
            if (used.find(nums[i]) != used.end()) {
                continue;
            }
            used.insert(nums[i]);          // 记录本层已使用的数值
            path.push_back(nums[i]);       // 【选择】
            backtrack(nums, i + 1);        // 【递归】
            path.pop_back();                 // 【撤销选择】
        }
    }

public:
    vector<vector<int>> findSubsequences(vector<int>& nums) {
        backtrack(nums, 0);
        return result;
    }
};
```

## 总结

- 这题不能排序，为什么呢？因为要保持"子序列"相对于原数组的顺序，这是跟 0040/0090 题最本质的区别，直接决定了去重方式必须改变。
- 去重改用哈希 set 记录"本层已经使用过的数值"，`set` 必须是每层递归独立的局部变量，只对同一层内的重复值生效，不影响不同层选择相同数值（比如 `[4,4]`）。
- 判断递增用 `path` 的最后一个元素跟当前候选值比较，允许相等（非严格递增），这就是本题结果里能出现 `[7,7]`、`[4,4]` 这类相邻相等值组合的原因。
- 这题是"子集类"收集方式（每个满足条件的节点都收集，不是只收集叶子），额外叠加了递增约束和长度 >= 2 的限制，是子集问题的进阶变形。
