# 0491. 递增子序列

**题目描述**

给定一个整数数组 `nums`，找出并返回所有该数组中不同的递增子序列，递增子序列中**至少有两个元素**。数组中可能含有重复元素，如果出现两个由**相同数字序列**组成的递增子序列，只需要返回一个。

```
示例：
输入: nums = [4,6,7,7]
输出: [[4,6],[4,6,7],[4,6,7,7],[4,7],[4,7,7],[6,7],[6,7,7],[7,7]]

输入: nums = [4,4,3,2,1]
输出: [[4,4]]
```

## 思路

**这题看着和 0090 子集 II 很像（数组有重复元素、要去重），但关键约束不一样：不能对数组排序**，为什么呢？因为题目要求找的是"子序列"（subsequence），子序列必须保持元素在原数组中的相对顺序，如果排序就把原始顺序信息破坏了，找出来的就不是原数组的子序列了。

**为什么之前的去重方法（排序后跳过相邻重复值）在这里不适用呢**：0040/0090 题的去重依赖"排序后相同的值相邻"，但这题不能排序，相同的值在原数组里可能相隔很远（比如 `[4,4,3,2,1]` 里两个 4 相邻，但换成 `[4,3,4,2,1]` 两个 4 就不相邻了）。不排序的情况下，就没法简单通过"比较 `nums[i]` 和 `nums[i-1]`"来判断是否是本层的重复选择。

**去重必须用哈希 set 记录当前层已经用过的值**：在进入某一层的 for 循环之前，创建一个空的 `set`（比如 `unordered_set<int>` 或者 Python 的 `set()`），每次遍历到一个候选值 `nums[i]`，先检查这个值是否已经在本层的 `set` 中出现过——如果出现过，说明本层已经选过一个数值相同的分支了，跳过；如果没出现过，把它加入 `set`，然后正常执行"选择-递归-撤销选择"。**注意 `set` 只在本层生效**，也就是说它应该是 `backtrack` 函数内部的局部变量，每次进入函数时新建一个空 `set`，这样才能保证只对"同一层"的重复值去重，不会影响不同层之间可以出现相同的数值（比如 `[4,4]` 这个结果本身就是合法的，两个 4 分别在不同的递归层被选中）。

**为什么这个方法不需要排序也能正确去重呢**：`set` 判断的是"这个值在本层是否已经被选过"，跟数组中元素的物理位置无关，只关心数值本身和"当前递归层"这个维度，所以不需要依赖排序带来的相邻关系。

**递增约束**：这题除了去重，还要保证子序列是递增的（非严格递增，允许相等，看示例 `[7,7]` 是合法的）。判断方式是：只有当 `nums[i] >= path` 的最后一个元素（或者 `path` 为空）时，才可以把 `nums[i]` 加入 `path`。

**递归树的结构与终止条件**：仍然用 `startIndex` 保证每层只能选后面的元素（不需要考虑重复使用的问题，因为不允许乱序选择，`i+1` 的写法就足够）。因为这是子序列问题（类似子集，不要求"够数量才收集"），在满足"`path` 长度 >= 2"的任意节点都应该收集结果。

**复杂度分析**：最坏情况下与子集问题类似是指数级 O(2^n)，每次去重判断和递增判断都是 O(1)（哈希 set 的插入和查找）。

## 代码

### C++

```cpp
class Solution {
private:
    vector<vector<int>> result;
    vector<int> path;

    void backtrack(vector<int>& nums, int startIndex) {
        if (path.size() >= 2) {          // 子序列问题：满足长度>=2的每个节点都收集
            result.push_back(path);
        }
        unordered_set<int> used;          // 本层去重专用，只在当前递归层生效（局部变量）
        for (int i = startIndex; i < nums.size(); i++) {
            // 递增校验：path 非空时，当前值必须 >= path 最后一个元素
            if (!path.empty() && nums[i] < path.back()) {
                continue;
            }
            // 树层去重：本层已经用过这个数值，跳过（不依赖排序，直接用哈希 set 记录）
            if (used.find(nums[i]) != used.end()) {
                continue;
            }
            used.insert(nums[i]);          // 记录本层已使用的数值
            path.push_back(nums[i]);       // 【选择】
            backtrack(nums, i + 1);        // 【递归】
            path.pop_back();                 // 【撤销选择】
        }
    }

public:
    vector<vector<int>> findSubsequences(vector<int>& nums) {
        backtrack(nums, 0);
        return result;
    }
};
```

### Java

```java
class Solution {
    private List<List<Integer>> result = new ArrayList<>();
    private LinkedList<Integer> path = new LinkedList<>();

    public List<List<Integer>> findSubsequences(int[] nums) {
        backtrack(nums, 0);
        return result;
    }

    private void backtrack(int[] nums, int startIndex) {
        if (path.size() >= 2) {                  // 满足长度>=2的每个节点都收集
            result.add(new ArrayList<>(path));
        }
        Set<Integer> used = new HashSet<>();       // 本层去重专用，局部变量，只在本层生效
        for (int i = startIndex; i < nums.length; i++) {
            // 递增校验
            if (!path.isEmpty() && nums[i] < path.getLast()) {
                continue;
            }
            // 树层去重：不排序，直接用哈希 set 记录本层已用过的值
            if (used.contains(nums[i])) {
                continue;
            }
            used.add(nums[i]);
            path.addLast(nums[i]);       // 【选择】
            backtrack(nums, i + 1);      // 【递归】
            path.removeLast();             // 【撤销选择】
        }
    }
}
```

### Python

```python
class Solution:
    def findSubsequences(self, nums: list[int]) -> list[list[int]]:
        result = []
        path = []

        def backtrack(start_index: int):
            if len(path) >= 2:               # 满足长度>=2的每个节点都收集
                result.append(path[:])
            used = set()                      # 本层去重专用，局部变量，每次进入函数重新创建
            for i in range(start_index, len(nums)):
                # 递增校验：path 非空时，当前值必须 >= path 最后一个元素
                if path and nums[i] < path[-1]:
                    continue
                # 树层去重：不排序，直接用哈希 set 判断本层是否已用过这个值
                if nums[i] in used:
                    continue
                used.add(nums[i])             # 记录本层已使用的数值
                path.append(nums[i])           # 【选择】
                backtrack(i + 1)                 # 【递归】
                path.pop()                        # 【撤销选择】

        backtrack(0)
        return result
```

### Go

```go
func findSubsequences(nums []int) [][]int {
    var result [][]int
    var path []int

    var backtrack func(startIndex int)
    backtrack = func(startIndex int) {
        if len(path) >= 2 {                    // 满足长度>=2的每个节点都收集
            tmp := make([]int, len(path))
            copy(tmp, path)
            result = append(result, tmp)
        }
        used := make(map[int]bool)              // 本层去重专用，局部变量，每次进入函数重新创建
        for i := startIndex; i < len(nums); i++ {
            // 递增校验：path 非空时，当前值必须 >= path 最后一个元素
            if len(path) > 0 && nums[i] < path[len(path)-1] {
                continue
            }
            // 树层去重：不排序，直接用哈希 map 判断本层是否已用过这个值
            if used[nums[i]] {
                continue
            }
            used[nums[i]] = true               // 记录本层已使用的数值
            path = append(path, nums[i])        // 【选择】
            backtrack(i + 1)                      // 【递归】
            path = path[:len(path)-1]              // 【撤销选择】
        }
    }
    backtrack(0)
    return result
}
```

## 总结

- 这题不能排序，为什么呢？因为要保持"子序列"相对于原数组的顺序，这是跟 0040/0090 题最本质的区别，直接决定了去重方式必须改变。
- 去重改用哈希 set 记录"本层已经使用过的数值"，`set` 必须是每层递归独立的局部变量，只对同一层内的重复值生效，不影响不同层选择相同数值（比如 `[4,4]`）。
- 判断递增用 `path` 的最后一个元素跟当前候选值比较，允许相等（非严格递增），这就是本题结果里能出现 `[7,7]`、`[4,4]` 这类相邻相等值组合的原因。
- 这题是"子集类"收集方式（每个满足条件的节点都收集，不是只收集叶子），额外叠加了递增约束和长度 >= 2 的限制，是子集问题的进阶变形。
