# 0077. 组合（剪枝优化）

**题目描述**

在 0077 题"求 1 到 n 中 k 个数的组合"的基础上，本篇讨论如何对回溯过程做剪枝优化，减少不必要的递归调用，提升效率。题目本身不变：

```
示例：
输入：n = 4, k = 2
输出：[[1,2],[1,3],[1,4],[2,3],[2,4],[3,4]]
```

## 思路

回溯选组合，剩余还需 `k-path.size()` 个数，因此本层只枚举到 `n-(k-path.size())+1`。下一层从 `i+1` 开始，选满保存，返回时撤销。

时间 O(k·C(n,k))，辅助空间 O(k)，不计结果。

### LeetCode 写法与原有示例

# 依赖说明：len：Python 内置函数：返回容器中元素的数量。；range：Python 内置函数：生成按步长遍历的整数序列。

class Solution:
    # 方法：combine；按题目要求处理输入并返回结果，核心算法见方法体。
    def combine(self, n: int, k: int) -> list[list[int]]:
        result = []
        path = []

        # 方法：backtrack；按题目要求处理输入并返回结果，核心算法见方法体。
        def backtrack(start_index: int):
            if len(path) == k:                   # 终止条件：已经选够 k 个数
                result.append(path[:])
                return
            # 剪枝：上界为 n - (k - len(path)) + 1，超过则剩余数字不够凑够 k 个
            upper_bound = n - (k - len(path)) + 1
            for i in range(start_index, upper_bound + 1):
                path.append(i)                   # 【选择】
                backtrack(i + 1)                  # 【递归】
                path.pop()                        # 【撤销选择】

        backtrack(1)
        return result```

## Go

### LeetCode 写法与原有示例

```go
// 方法：combine；按题目要求处理输入并返回结果，核心算法见方法体。
func combine(n int, k int) [][]int {
    var result [][]int
    var path []int

    var backtrack func(startIndex int)
    backtrack = func(startIndex int) {
        if len(path) == k {                       // 终止条件：已经选够 k 个数
            tmp := make([]int, len(path))
            copy(tmp, path)
            result = append(result, tmp)
            return
        }
        // 剪枝：上界为 n - (k - len(path)) + 1，超过这个值不可能凑够 k 个数
        upperBound := n - (k - len(path)) + 1
        for i := startIndex; i <= upperBound; i++ {
            path = append(path, i)                // 【选择】
            backtrack(i + 1)                       // 【递归】
            path = path[:len(path)-1]              // 【撤销选择】
        }
    }
    backtrack(1)
    return result
}
```

## C++

### LeetCode 写法与原有示例

```cpp
class Solution {
private:
    vector<vector<int>> result;
    vector<int> path;

    // 方法：backtrack；按题目要求处理输入并返回结果，核心算法见方法体。
    void backtrack(int n, int k, int startIndex) {
        if (path.size() == k) {              // 终止条件：已经选够 k 个数
            result.push_back(path);
            return;
        }
        // 剪枝：i 的上界是 n - (k - path.size()) + 1，超过这个值不可能凑够 k 个数
        for (int i = startIndex; i <= n - (k - path.size()) + 1; i++) {
            path.push_back(i);               // 【选择】把 i 加入路径
            backtrack(n, k, i + 1);          // 【递归】进入下一层
            path.pop_back();                 // 【撤销选择】回退
        }
    }

public:
    vector<vector<int>> combine(int n, int k) {
        backtrack(n, k, 1);
        return result;
    }
};
```

## 总结

- 剪枝条件的本质其实就是一种"必要条件检查"：拿候选区间剩余的数量和还需要选择的数量做个对比，一旦发现剩余数量不够了，就直接放弃这个分支以及它之后的所有分支。
- 剪枝上界 `n - (k - path.size()) + 1` 要结合具体的 `path` 长度动态算出来，每次进入 for 循环都要重新算一遍，不是一个固定的常量，这点要注意。
- 剪枝优化不会改变最终的结果集合，它只是提前排除了注定失败的搜索路径，是回溯法优化的常规手段，写完基础版本之后值得追加考虑一下。
- 剪枝的效果会随着 `n` 增大、`k` 接近 `n/2` 附近变得更明显，为什么呢？因为这时候"刚好选不够"的边界情况在未剪枝版本里会被频繁触发。
