# 0131. 分割回文串

**题目描述**

给定一个字符串 `s`，将 `s` 分割成若干子串，使每个子串都是回文串，返回所有可能的分割方案。

```
示例：
输入: s = "aab"
输出: [["a","a","b"],["aa","b"]]
```

要求：判断一个字符串是否是回文串（正读反读都一样）。

## 思路

**切割问题其实也是一种回溯**，你可以把它理解成组合问题的变种：把字符串的每个"切割点"看作一次选择，这样就把"分割字符串"转化成了"从字符串的下标序列中选一些切割点"的组合问题了。

**用 startIndex 表示切割线的位置**：这是理解切割类回溯的关键。这里的 `startIndex` 不再表示"从数组的第几个数字开始选"了，而是表示"上一次切割结束的位置，本次切割从这里开始"。每一次递归，都尝试从 `startIndex` 到字符串末尾之间的某个位置 `i` 切一刀，把 `[startIndex, i]` 这一段作为一个子串。

**递归树的结构**：树的深度对应"切了多少段"，树的每一层的宽度对应"从 startIndex 开始，可以在哪些位置切下一刀"（`i` 可以取 `startIndex` 到 `s.length()-1` 之间的任意值）。拿 `"aab"` 举个例子，第一层可以选择切 `"a"`（i=0）、`"aa"`（i=1）、`"aab"`（i=2）三种切法，选定一种切法之后，再递归处理剩下的子串。

**先判断回文再决定要不要递归下去**：在 for 循环遍历切割位置 `i` 的时候，先判断子串 `s[startIndex..i]` 是不是回文串。如果不是回文串，说明这个切法本身就不合法，直接跳过就行（不用递归，因为往下切更不可能让已经不合法的这一段变合法）；如果是回文串，才把这一段加入 `path`，然后递归处理 `s[i+1..]` 这部分剩余字符串。这一步"判断后再决定是否递归"，本质上也是一种剪枝，能避免在不合法的分支上浪费时间。

**终止条件**：当 `startIndex` 达到字符串末尾（等于 `s.length()`）的时候，说明整个字符串都已经被成功切割成回文子串了，把当前 `path`（记录了每一段子串）加入结果集。

**说说"选择 - 递归 - 撤销选择"这三步**：

1. 选择：把 `s[startIndex..i]` 这个子串加入 `path`。
2. 递归：调用 `backtrack(s, i+1)`，处理剩余部分。
3. 撤销选择：递归返回后，把刚加入 `path` 的子串移除，尝试下一个切割位置 `i+1`。

**复杂度分析**：最坏情况下（比如字符串全部由同一个字符组成），每个位置都可能是切割点，递归树接近满二叉树的形态，时间复杂度是指数级 O(2^n)（n 为字符串长度），每次判断回文的开销是 O(n)，所以总时间复杂度大概是 O(2^n × n)。空间复杂度是 O(n)（递归深度加 path 存储）。

## 代码

### C++

```cpp
class Solution {
private:
    vector<vector<string>> result;
    vector<string> path;

    bool isPalindrome(const string& s, int left, int right) {
        while (left < right) {           // 双指针从两端向中间收缩
            if (s[left] != s[right]) return false;
            left++;
            right--;
        }
        return true;
    }

    void backtrack(const string& s, int startIndex) {
        if (startIndex == s.size()) {        // 终止条件：切割线到达字符串末尾，说明切割完成
            result.push_back(path);
            return;
        }
        for (int i = startIndex; i < s.size(); i++) {  // 横向遍历：本次切割线可以落在哪个位置
            if (!isPalindrome(s, startIndex, i)) {     // 剪枝：不是回文串就不递归
                continue;
            }
            path.push_back(s.substr(startIndex, i - startIndex + 1)); // 【选择】把回文子串加入路径
            backtrack(s, i + 1);                       // 【递归】处理剩余字符串
            path.pop_back();                             // 【撤销选择】回退，尝试下一个切割位置
        }
    }

public:
    vector<vector<string>> partition(string s) {
        backtrack(s, 0);
        return result;
    }
};
```

### Java

```java
class Solution {
    private List<List<String>> result = new ArrayList<>();
    private LinkedList<String> path = new LinkedList<>();

    public List<List<String>> partition(String s) {
        backtrack(s, 0);
        return result;
    }

    private void backtrack(String s, int startIndex) {
        if (startIndex == s.length()) {       // 终止条件：切割完成
            result.add(new ArrayList<>(path));
            return;
        }
        for (int i = startIndex; i < s.length(); i++) {  // 横向遍历：切割线的位置
            if (!isPalindrome(s, startIndex, i)) {         // 剪枝：不是回文串直接跳过
                continue;
            }
            path.addLast(s.substring(startIndex, i + 1));   // 【选择】
            backtrack(s, i + 1);                              // 【递归】
            path.removeLast();                                 // 【撤销选择】
        }
    }

    private boolean isPalindrome(String s, int left, int right) {
        while (left < right) {           // 双指针从两端向中间收缩
            if (s.charAt(left) != s.charAt(right)) return false;
            left++;
            right--;
        }
        return true;
    }
}
```

### Python

```python
class Solution:
    def partition(self, s: str) -> list[list[str]]:
        result = []
        path = []

        def is_palindrome(left: int, right: int) -> bool:
            while left < right:              # 双指针从两端向中间收缩
                if s[left] != s[right]:
                    return False
                left += 1
                right -= 1
            return True

        def backtrack(start_index: int):
            if start_index == len(s):         # 终止条件：切割线到达字符串末尾
                result.append(path[:])
                return
            for i in range(start_index, len(s)):     # 横向遍历：切割线的位置
                if not is_palindrome(start_index, i):  # 剪枝：不是回文串就不递归
                    continue
                path.append(s[start_index:i + 1])      # 【选择】把回文子串加入路径
                backtrack(i + 1)                         # 【递归】处理剩余字符串
                path.pop()                                # 【撤销选择】

        backtrack(0)
        return result
```

```go
func partition(s string) [][]string {
    var result [][]string
    var path []string

    isPalindrome := func(left, right int) bool {
        for left < right {                 // 双指针从两端向中间收缩
            if s[left] != s[right] {
                return false
            }
            left++
            right--
        }
        return true
    }

    var backtrack func(startIndex int)
    backtrack = func(startIndex int) {
        if startIndex == len(s) {          // 终止条件：切割线到达字符串末尾
            tmp := make([]string, len(path))
            copy(tmp, path)
            result = append(result, tmp)
            return
        }
        for i := startIndex; i < len(s); i++ {   // 横向遍历：切割线的位置
            if !isPalindrome(startIndex, i) {      // 剪枝：不是回文串就不递归
                continue
            }
            path = append(path, s[startIndex:i+1]) // 【选择】把回文子串加入路径
            backtrack(i + 1)                        // 【递归】处理剩余字符串
            path = path[:len(path)-1]               // 【撤销选择】
        }
    }
    backtrack(0)
    return result
}
```

## 总结

- 切割问题的本质是组合问题的变种：把"选数字"换成了"选切割位置"，`startIndex` 表示的是"上一次切割结束、本次切割开始"的位置，而不是数组下标的下界。
- 判断当前子串是否合法（这题是判断回文）应该在加入 `path` 之前就完成，不合法就直接跳过这个分支，这本身就是一种针对切割问题的剪枝方式。
- 终止条件是 `startIndex == s.length()`，表示整个字符串被完全消耗、切割完成了，这跟组合问题里"选够 k 个数"的终止条件形式不太一样，但本质都是"任务已完成"。
- 判断回文子串可以用双指针 O(n) 判断，也可以提前用动态规划预处理所有子串是否为回文（空间换时间），后者能优化整体的时间复杂度，是这题常见的进阶优化方向。
