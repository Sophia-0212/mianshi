# 0093. 复原 IP 地址

**题目描述**

给定一个只包含数字的字符串 `s`，用 `.` 将字符串分割成 4 段，返回所有可能从 `s` 得到的**有效 IP 地址**。可以按任何顺序返回答案。

```
示例：
输入：s = "25525511135"
输出：["255.255.11.135","255.255.111.35"]

输入：s = "0000"
输出：["0.0.0.0"]
```

要求：有效的 IP 地址每一段的整数值在 `0` 到 `255` 之间（包含边界），不能包含前导零（除非该段本身就是 `0`）。

## 思路

回溯切四段，每段尝试 1～3 位，数值须在 0～255，除单独的 0 外不能有前导零。四段且恰好耗尽字符时保存；剩余长度不在 `[剩余段数,3×剩余段数]` 内则剪枝。

长度先限定 4～12；最多枚举 3⁴ 种切法，时间、辅助空间均 O(1)。

class Solution:
    # 方法：restoreIpAddresses；按题目要求处理输入并返回结果，核心算法见方法体。
    def restoreIpAddresses(self, s: str) -> list[str]:
        if len(s) < 4 or len(s) > 12:      # 长度剪枝：不可能组成合法 IP
            return []

        result = []
        path = []

        # 方法：is_valid；按题目要求处理输入并返回结果，核心算法见方法体。
        def is_valid(start: int, end: int) -> bool:
            if start > end:
                return False
            if end - start > 2:              # 段长度超过 3 位，必然大于 255
                return False
            if s[start] == '0' and start != end:  # 前导零（长度>1且以0开头）不合法
                return False
            return int(s[start:end + 1]) <= 255    # 数值范围校验

        # 方法：backtrack；按题目要求处理输入并返回结果，核心算法见方法体。
        def backtrack(start_index: int):
            if len(path) == 4:                      # 已经切了 4 段
                if start_index == len(s):              # 且字符串正好用完
                    result.append('.'.join(path))
                return
            # 单段最多 3 个字符
            for i in range(start_index, min(start_index + 3, len(s))):
                if not is_valid(start_index, i):        # 段不合法，跳过
                    continue
                path.append(s[start_index:i + 1])        # 【选择】
                backtrack(i + 1)                            # 【递归】
                path.pop()                                    # 【撤销选择】

        backtrack(0)
        return result```

### LeetCode 写法与原有示例

class Solution {
private:
    vector<string> result;
    vector<string> path;   // 保存已经切好的每一段

    // 方法：isValid；按题目要求处理输入并返回结果，核心算法见方法体。
    bool isValid(const string& s, int start, int end) {
        if (start > end) return false;
        if (end - start > 2) return false;         // 段长度超过 3 位，必然大于 255
        if (s[start] == '0' && start != end) return false;  // 前导零（长度>1且以0开头）不合法
        int num = 0;
        for (int i = start; i <= end; i++) {
            num = num * 10 + (s[i] - '0');
        }
        return num <= 255;                            // 数值范围校验
    }

    // 方法：backtrack；按题目要求处理输入并返回结果，核心算法见方法体。
    void backtrack(const string& s, int startIndex) {
        if (path.size() == 4) {                 // 已经切了 4 段
            if (startIndex == s.size()) {         // 且字符串正好用完，才是合法 IP
                string ip = path[0] + "." + path[1] + "." + path[2] + "." + path[3];
                result.push_back(ip);
            }
            return;                                 // 4 段已切完（无论是否合法），不再继续递归
        }
        // 单段最多 3 个字符，i 最多到 startIndex+2，且不能越界
        for (int i = startIndex; i < s.size() && i <= startIndex + 2; i++) {
            if (!isValid(s, startIndex, i)) {         // 这一段不合法，跳过（更长的也不会合法，可 continue）
                continue;
            }
            path.push_back(s.substr(startIndex, i - startIndex + 1)); // 【选择】
            backtrack(s, i + 1);                        // 【递归】处理剩余字符串
            path.pop_back();                              // 【撤销选择】
        }
    }

public:
    // 方法：restoreIpAddresses；按题目要求处理输入并返回结果，核心算法见方法体。
    vector<string> restoreIpAddresses(string s) {
        if (s.size() < 4 || s.size() > 12) return result;  // 长度剪枝：不可能组成合法 IP
        backtrack(s, 0);
        return result;
    }
};

## 总结

- 这题在 0131 分割回文串的基础上多了一层"段数必须恰好为 4"的约束，终止条件从"字符串用完即可"变成了"字符串用完且段数恰好为 4"两个条件同时满足。
- 判断一段是否合法（长度、前导零、数值范围）是这题的核心细节，尤其是前导零的判断容易漏掉"长度为 1 时 0 本身合法"这个特例，得留意。
- 通过限制 for 循环单段最多截取 3 个字符（`i <= startIndex + 2`），可以直接从枚举范围上避免生成过长的非法段，这是一种源于问题性质本身的天然剪枝。
- 整体搜索空间很小（字符串长度上限 12，每段最多 3 种切法，总共 4 段），所以即使不做复杂的数值剪枝，暴力回溯的实际效率也很高。
