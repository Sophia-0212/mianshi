# 0093. 复原 IP 地址

**题目描述**

给定一个只包含数字的字符串 `s`，用 `.` 将字符串分割成 4 段，返回所有可能从 `s` 得到的**有效 IP 地址**。可以按任何顺序返回答案。

```
示例：
输入：s = "25525511135"
输出：["255.255.11.135","255.255.111.35"]

输入：s = "0000"
输出：["0.0.0.0"]
```

要求：有效的 IP 地址每一段的整数值在 `0` 到 `255` 之间（包含边界），不能包含前导零（除非该段本身就是 `0`）。

## 思路

这题是切割问题的另一个典型应用，思路跟 0131 分割回文串一脉相承，区别在哪呢？在于**判断"这一段是否合法"的规则不同**（这里是判断 IP 段合法性，而不是回文判断），还需要**额外控制切割的段数正好为 4 段**。

**用 startIndex 表示切割线的位置**：跟 0131 题一样，`startIndex` 表示上一次切割结束的位置，本次切割从这里继续往后找下一个切割点。

**多了一个"段数"要维护**：IP 地址正好由 4 段组成，所以需要一个额外变量（或者用 `path` 的长度）记录"当前已经切了几段"，作为终止条件的一部分。

**判断某一段是否合法的规则是什么呢**（这是这题的核心难点）：

1. **段的长度不能超过 3 位**：为什么呢？因为 `255` 是最大值，超过 3 位数字必然大于 255，直接不合法。
2. **不能有前导零**：如果这一段长度大于 1 且以 `'0'` 开头（比如 `"01"`），说明有前导零，不合法；但如果这一段本身就是单独一个 `"0"`，那是合法的，这个特例容易漏掉。
3. **数值必须在 0~255 之间**：把这一段转成整数后判断范围就行。

**为什么要控制段数为 4 段，还要提前剪枝呢**：

- 每递归一层，段数就加一。当已经切了 4 段但字符串还没用完，说明这种切法不可能得到合法的 IP 了（4 段已经用完，但还剩字符没有归属），这时候直接放弃这个分支。
- 反过来，如果字符串已经用完了（`startIndex == s.length()`）但段数还不够 4 段，说明切割段数不足，也不合法。
- 只有"段数恰好等于 4，且字符串正好用完"这两个条件同时满足，才算是一个合法的 IP 地址，加入结果集。

**怎么加速剪枝呢**：可以在 for 循环里限制单段最多截取 3 个字符（`i` 最多到 `startIndex + 2`），这样就不需要等切出很长的一段再判断"长度超过 3 位不合法"了，直接从循环范围上就排除了这种情况。同时如果剩余字符数明显不足以再切出足够的段数（或者已经超过能切出的段数上限），也可以提前返回。

**复杂度分析**：由于每段最多 3 位数字，且总共只切 4 段，实际搜索空间非常有限（近似常数级，字符串长度最多 12），可以看作是"有限深度、有限宽度"的小型回溯树，实际运行效率很高。

## 代码

### C++

```cpp
class Solution {
private:
    vector<string> result;
    vector<string> path;   // 保存已经切好的每一段

    bool isValid(const string& s, int start, int end) {
        if (start > end) return false;
        if (end - start > 2) return false;         // 段长度超过 3 位，必然大于 255
        if (s[start] == '0' && start != end) return false;  // 前导零（长度>1且以0开头）不合法
        int num = 0;
        for (int i = start; i <= end; i++) {
            num = num * 10 + (s[i] - '0');
        }
        return num <= 255;                            // 数值范围校验
    }

    void backtrack(const string& s, int startIndex) {
        if (path.size() == 4) {                 // 已经切了 4 段
            if (startIndex == s.size()) {         // 且字符串正好用完，才是合法 IP
                string ip = path[0] + "." + path[1] + "." + path[2] + "." + path[3];
                result.push_back(ip);
            }
            return;                                 // 4 段已切完（无论是否合法），不再继续递归
        }
        // 单段最多 3 个字符，i 最多到 startIndex+2，且不能越界
        for (int i = startIndex; i < s.size() && i <= startIndex + 2; i++) {
            if (!isValid(s, startIndex, i)) {         // 这一段不合法，跳过（更长的也不会合法，可 continue）
                continue;
            }
            path.push_back(s.substr(startIndex, i - startIndex + 1)); // 【选择】
            backtrack(s, i + 1);                        // 【递归】处理剩余字符串
            path.pop_back();                              // 【撤销选择】
        }
    }

public:
    vector<string> restoreIpAddresses(string s) {
        if (s.size() < 4 || s.size() > 12) return result;  // 长度剪枝：不可能组成合法 IP
        backtrack(s, 0);
        return result;
    }
};
```

### Java

```java
class Solution {
    private List<String> result = new ArrayList<>();
    private LinkedList<String> path = new LinkedList<>();

    public List<String> restoreIpAddresses(String s) {
        if (s.length() < 4 || s.length() > 12) return result;  // 长度剪枝
        backtrack(s, 0);
        return result;
    }

    private void backtrack(String s, int startIndex) {
        if (path.size() == 4) {                     // 已经切了 4 段
            if (startIndex == s.length()) {           // 且字符串正好用完
                result.add(String.join(".", path));
            }
            return;
        }
        for (int i = startIndex; i < s.length() && i <= startIndex + 2; i++) {
            if (!isValid(s, startIndex, i)) {           // 段不合法，跳过
                continue;
            }
            path.addLast(s.substring(startIndex, i + 1)); // 【选择】
            backtrack(s, i + 1);                            // 【递归】
            path.removeLast();                                // 【撤销选择】
        }
    }

    private boolean isValid(String s, int start, int end) {
        if (start > end) return false;
        if (end - start > 2) return false;               // 长度超过 3 位
        if (s.charAt(start) == '0' && start != end) return false;  // 前导零
        int num = 0;
        for (int i = start; i <= end; i++) {
            num = num * 10 + (s.charAt(i) - '0');
        }
        return num <= 255;
    }
}

class Solution:
    def restoreIpAddresses(self, s: str) -> list[str]:
        if len(s) < 4 or len(s) > 12:      # 长度剪枝：不可能组成合法 IP
            return []

        result = []
        path = []

        def is_valid(start: int, end: int) -> bool:
            if start > end:
                return False
            if end - start > 2:              # 段长度超过 3 位，必然大于 255
                return False
            if s[start] == '0' and start != end:  # 前导零（长度>1且以0开头）不合法
                return False
            return int(s[start:end + 1]) <= 255    # 数值范围校验

        def backtrack(start_index: int):
            if len(path) == 4:                      # 已经切了 4 段
                if start_index == len(s):              # 且字符串正好用完
                    result.append('.'.join(path))
                return
            # 单段最多 3 个字符
            for i in range(start_index, min(start_index + 3, len(s))):
                if not is_valid(start_index, i):        # 段不合法，跳过
                    continue
                path.append(s[start_index:i + 1])        # 【选择】
                backtrack(i + 1)                            # 【递归】
                path.pop()                                    # 【撤销选择】

        backtrack(0)
        return result
```

## 总结

- 这题在 0131 分割回文串的基础上多了一层"段数必须恰好为 4"的约束，终止条件从"字符串用完即可"变成了"字符串用完且段数恰好为 4"两个条件同时满足。
- 判断一段是否合法（长度、前导零、数值范围）是这题的核心细节，尤其是前导零的判断容易漏掉"长度为 1 时 0 本身合法"这个特例，得留意。
- 通过限制 for 循环单段最多截取 3 个字符（`i <= startIndex + 2`），可以直接从枚举范围上避免生成过长的非法段，这是一种源于问题性质本身的天然剪枝。
- 整体搜索空间很小（字符串长度上限 12，每段最多 3 种切法，总共 4 段），所以即使不做复杂的数值剪枝，暴力回溯的实际效率也很高。
