# 0236. 二叉树的最近公共祖先

**题目描述**

给定一个二叉树，找到该树中两个指定节点 `p` 和 `q` 的最近公共祖先（LCA）。这是一棵**普通二叉树**，不是二叉搜索树，节点值没有大小顺序可以利用。

最近公共祖先的定义：对于有根树 `T` 的两个节点 `p`、`q`，最近公共祖先表示为一个节点 `x`，满足 `x` 是 `p`、`q` 的祖先且 `x` 的深度尽可能大（一个节点也可以是它自己的祖先）。

```
示例：
输入: root = [3,5,1,6,2,0,8,null,null,7,4], p = 5, q = 1
输出: 3
解释: 节点 5 和节点 1 的最近公共祖先是节点 3。
```

## 思路

这道题是二叉树递归回溯里一个很经典的难题，第一次碰到的时候很容易不知道从哪下手，因为它既不是简单的遍历，也不是简单的路径查找。要想清楚这道题，得先搞明白一个问题：**从递归函数的角度来看，子问题到底需要"返回"什么信息给父问题？**

**核心思路是这样的：用后序遍历做回溯，让每一层递归都"报告"一下它在自己管辖的这棵子树里看到了什么。**

我定义一个递归函数 `lowestCommonAncestor(node, p, q)`，它的含义是：**在以 `node` 为根的这棵子树里，去找 `p` 和 `q`，然后把找到的结果返回**。这个返回值有三种可能：

1. 如果这棵子树里同时找到了 `p` 和 `q`，那就返回它们的最近公共祖先——也就是最终答案，一旦找到了就不会再变了。
2. 如果这棵子树里只找到了 `p`（`q` 不在这棵子树里），那就返回 `p` 本身——为什么呢？因为如果 `q` 在别的地方，那 `p` 本身或者 `p` 的某个祖先就会是最终答案，所以先把 `p` "冒泡"往上传，交给上一层去判断。
3. 如果这棵子树里什么都没找到，那就返回 `null`。

具体的递归逻辑是这样的：

- **先说终止条件**：如果当前节点是空的，返回 `null`，说明什么都没找到；如果当前节点恰好就是 `p` 或者 `q`，那就直接返回当前节点——找到其中一个就够了，不需要再往下递归了（这里有个特殊情况，就是 `p` 恰好是 `q` 的祖先，这种情况其实也能被正确处理，因为找到 `p` 就直接返回，并不会漏掉"`q` 可能在 `p` 子树里"这种情况，这一点我下面单独说一下）。
- **单层递归的逻辑**：分别去递归左子树和右子树，得到 `left` 和 `right` 这两个结果。
  - 如果 `left` 和 `right` 都不是空的，说明什么？说明 `p` 和 `q` 分别出现在当前节点的左右两侧子树里，那这时候**当前节点**自然就是它们的最近公共祖先，直接返回当前节点。
  - 如果只有 `left` 不是空的（`right` 是空的），说明 `p`、`q`（或者其中已经确定是答案的某个节点）都在左子树里，那就把 `left` 直接返回，交给上一层继续处理。
  - 同理，只有 `right` 不是空的，就返回 `right`。
  - 那如果两边都是空的呢？就返回 `null`，说明这棵子树里啥也没找到。

**那为什么这道题必须用后序遍历（也就是先处理左右子树，再处理当前节点）呢？** 你想啊，要判断"当前节点是不是最近公共祖先"，前提是必须先知道左子树和右子树各自的查找结果（也就是 `left` 和 `right`），才能做出判断。如果用前序遍历，也就是先处理当前节点再递归子树，那处理当前节点的那一刻，你根本不知道 `p`、`q` 到底有没有分布在左右两侧，自然就没法做出正确判断了。这其实正体现了"后序遍历天然适合那种需要先知道子问题结果才能处理当前层"的问题类型。

**再说说 `p` 是 `q` 祖先这种特殊情况**：假设 `p` 就是 `q` 的祖先节点。那递归到 `p` 节点的时候，因为 `p == node` 了，就直接返回 `p`，不会继续往下递归去找 `q`，尽管 `q` 确实在 `p` 的子树里。那这个提前返回会不会"漏掉"什么信息呢？答案是不会，因为 `p` 自己本身就是最终的正确答案——一个节点是可以是它自己的祖先的，`p` 既是 `p` 的祖先，同时也是 `q` 的祖先（因为 `p` 是 `q` 的祖先嘛），所以 `p` 就是最近公共祖先，提前返回 `p` 正好就是正确结果，根本不需要再去验证 `q` 是不是真的在子树里。

复杂度这块，每个节点最多被访问一次，所以时间复杂度是 O(n)；空间复杂度是递归调用栈的开销，也就是 O(h)，h 是树的高度，最坏情况下（树退化成一条链）是 O(n)。

## 代码

二叉树节点定义：

```cpp
struct TreeNode {
    int val;
    TreeNode *left;
    TreeNode *right;
    TreeNode(int x) : val(x), left(NULL), right(NULL) {}
};
```

### C++

```cpp
class Solution {
public:
    TreeNode* lowestCommonAncestor(TreeNode* root, TreeNode* p, TreeNode* q) {
        if (root == nullptr || root == p || root == q) {
            return root; // 终止条件：空节点，或当前节点恰好是 p/q
        }
        TreeNode* left = lowestCommonAncestor(root->left, p, q);   // 在左子树中查找
        TreeNode* right = lowestCommonAncestor(root->right, p, q); // 在右子树中查找

        if (left != nullptr && right != nullptr) {
            return root; // 左右子树都找到了目标，当前节点就是最近公共祖先
        }
        return left != nullptr ? left : right; // 只有一侧找到，把结果向上传递
    }
};
```

### Java

```java
class Solution {
    public TreeNode lowestCommonAncestor(TreeNode root, TreeNode p, TreeNode q) {
        if (root == null || root == p || root == q) {
            return root; // 终止条件
        }
        TreeNode left = lowestCommonAncestor(root.left, p, q);   // 左子树查找
        TreeNode right = lowestCommonAncestor(root.right, p, q); // 右子树查找

        if (left != null && right != null) {
            return root; // 左右都找到，当前节点是最近公共祖先
        }
        return left != null ? left : right; // 向上传递唯一找到的结果
    }
}
```

### Python

```python
class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right


class Solution:
    def lowestCommonAncestor(self, root: TreeNode, p: TreeNode, q: TreeNode) -> TreeNode:
        if root is None or root == p or root == q:
            return root  # 终止条件：空节点，或当前节点恰好是 p/q

        left = self.lowestCommonAncestor(root.left, p, q)   # 左子树查找
        right = self.lowestCommonAncestor(root.right, p, q)  # 右子树查找

        if left is not None and right is not None:
            return root  # 左右都找到，当前节点是最近公共祖先
        return left if left is not None else right  # 向上传递唯一找到的结果
```

### Go

```go
type TreeNode struct {
    Val   int
    Left  *TreeNode
    Right *TreeNode
}

func lowestCommonAncestor(root, p, q *TreeNode) *TreeNode {
    if root == nil || root == p || root == q {
        return root // 终止条件
    }
    left := lowestCommonAncestor(root.Left, p, q)   // 左子树查找
    right := lowestCommonAncestor(root.Right, p, q) // 右子树查找

    if left != nil && right != nil {
        return root // 左右都找到，当前节点是最近公共祖先
    }
    if left != nil {
        return left // 向上传递左子树的结果
    }
    return right // 向上传递右子树的结果（可能是 nil）
}
```

## 总结

- 这道题的核心是后序遍历回溯：必须先知道左右子树各自的查找结果，才能判断当前节点是不是最近公共祖先，这就决定了处理当前节点这一步必须放在两次递归调用之后。
- 递归函数返回值的含义要想清楚——它代表的是"在这棵子树里找到的、需要往上汇报的节点"，可能是 `p`、`q`、最终答案，也可能是 `null`，这三种非空情况语义各不相同，但代码上用同一个返回值类型统一处理，这正是这道题最巧妙的地方。
- `left` 和 `right` 都不为空的时候，当前节点就是答案，这是这道题最关键的判断逻辑，它的正确性靠的是"两个目标节点分别出现在不相交的两侧子树里"这个事实。
- `p` 是 `q` 祖先这种特殊情况能被正确处理，靠的是终止条件里"当前节点等于 p 或 q 时立即返回"这一步，它其实暗含了"一个节点是它自己的祖先"这个定义，根本不需要额外做特判。
