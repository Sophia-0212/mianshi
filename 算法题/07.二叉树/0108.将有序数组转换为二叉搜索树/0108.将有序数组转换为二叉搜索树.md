# 0108. 将有序数组转换为二叉搜索树

**题目描述**

给定一个整数数组 `nums`，其中元素已按**升序**排列，请将其转换为一棵**高度平衡**的二叉搜索树（BST）。

高度平衡二叉树是指该树所有节点的左右两个子树的高度差绝对值不超过 1。

```
示例：
输入: nums = [-10,-3,0,5,9]
输出: [0,-3,9,-10,null,5]（答案不唯一，只要是高度平衡的合法 BST 即可）
解释: 取中间元素 0 作为根节点，左边 [-10,-3] 构造左子树，右边 [5,9] 构造右子树。
```

## 思路

分治：取区间中点为根，递归构造左右半区间；空区间返回空。每层均分，保证高度平衡。

时间 O(n)，辅助空间 O(log n)，结果树 O(n)。

class TreeNode:
    # 方法：__init__；按题目要求处理输入并返回结果，核心算法见方法体。
    def __init__(self, val=0, left=None, right=None):

        self.left = left
        self.right = right


class Solution:
    # 方法：sortedArrayToBST；按题目要求处理输入并返回结果，核心算法见方法体。
    def sortedArrayToBST(self, nums: list[int]) -> TreeNode:
        # 方法：build；按题目要求处理输入并返回结果，核心算法见方法体。
        def build(left: int, right: int) -> TreeNode:
            if left > right:
                return None  # 区间为空
            mid = left + (right - left) // 2  # 取中间位置作为根节点
            root = TreeNode(nums[mid])
            root.left = build(left, mid - 1)    # 左半区间构造左子树
            root.right = build(mid + 1, right)   # 右半区间构造右子树
            return root

        return build(0, len(nums) - 1)

## 总结

- 核心思路是递归取区间中点当根节点，这个选择动作和二分查找里"取中点"这个动作形式上一样，但目的不一样——二分查找用中点做比较来缩小搜索范围，这道题用中点做"分割点"来保证左右子树节点数量均衡。
- 因为输入数组本身有序，所以随便哪种"取中点切分"的构造方式都自动满足 BST 性质，不需要额外验证，这也是这道题比 0654（最大二叉树）更简单的地方——0654 需要扫描找最大值，这道题只需要算一下中点下标就行。
- 每次递归把区间大致均分成两半，这是保证整棵树高度平衡的关键：数量均衡这个性质会一层一层往下传，最终让任意节点的左右子树高度差都不超过 1。
- 当区间长度为偶数的时候，中点选偏左还是偏右不影响平衡性，只会影响具体的树形状，题目本身也允许多种正确答案。
