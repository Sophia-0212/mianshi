# 0108. 将有序数组转换为二叉搜索树

**题目描述**

给定一个整数数组 `nums`，其中元素已按**升序**排列，请将其转换为一棵**高度平衡**的二叉搜索树（BST）。

高度平衡二叉树是指该树所有节点的左右两个子树的高度差绝对值不超过 1。

```
示例：
输入: nums = [-10,-3,0,5,9]
输出: [0,-3,9,-10,null,5]（答案不唯一，只要是高度平衡的合法 BST 即可）
解释: 取中间元素 0 作为根节点，左边 [-10,-3] 构造左子树，右边 [5,9] 构造右子树。
```

## 思路

这道题的解法思路和 0704（二分查找）之间有个挺有意思的联系：**都是"取中间元素"这个动作，但目的完全不一样**。二分查找取中间元素，是为了拿它跟目标值比较，决定丢弃哪一半区间；这道题取中间元素呢，是为了把它当成**根节点**，从而保证左右两部分的节点数量尽量均衡。

具体递归过程是这样的：

1. 给定当前处理的区间 `[left, right]`（对应 `nums` 的一段有序子数组）。
2. 取区间中间位置的元素 `nums[mid]`，当成当前子树的根节点。
3. 递归处理左半区间 `[left, mid-1]`，构造左子树。
4. 递归处理右半区间 `[mid+1, right]`，构造右子树。
5. 终止条件：区间为空（也就是 `left > right`）的时候返回 `null`。

**那为什么取中间元素就能保证高度平衡呢？** 你想啊，每次递归都把当前区间大致一分为二，左右子树各自的节点数量最多相差 1（区间长度是偶数的时候，中间元素两侧的元素个数不完全相等，一侧会比另一侧多 1 个）。这种"数量均衡"会一层一层递归传递下去，最终就能保证整棵树任意节点的左右子树高度差都不超过 1，这就满足了高度平衡的要求。

同时呢，因为 `nums` 本身是有序的，所以不管用哪种"取中点切分"的方式构造出的树，天然就满足 BST 性质：左半区间的所有元素都小于中间元素，右半区间的所有元素都大于中间元素，往下递归的话左右子树内部也一直保持这个关系，所以不需要额外去验证，构造出来的树自动就是一棵合法的 BST。

**再说说"中间元素"怎么选：当区间长度为偶数的时候，中点其实有两个候选**（比如长度为 4 的区间，下标 0~3，中点可以是 1 也可以是 2），取左边那个还是右边那个都是合法的，只是最终生成的具体树形状不一样，但两种选择构造出来的树都满足高度平衡的要求。这道题本身答案就不唯一，只要求平衡就行，所以这个细节不影响正确性，代码里给出一种固定的取法（`mid = left + (right - left) / 2`，这个公式在区间长度为偶数的时候取的是偏左的中点）。

复杂度这块怎么分析呢？每个元素恰好被访问一次用来创建一个节点，时间复杂度是 O(n)；空间复杂度是 O(log n)，也就是递归调用栈的深度，因为这棵树是平衡的，高度是 O(log n)，如果把构造出来的树本身占用的空间也算上，那就是 O(n)。

## 代码

二叉树节点定义：

```cpp
struct TreeNode {
    int val;
    TreeNode *left;
    TreeNode *right;
    TreeNode(int x) : val(x), left(NULL), right(NULL) {}
};
```

### C++

```cpp
class Solution {
public:
    TreeNode* sortedArrayToBST(vector<int>& nums) {
        return build(nums, 0, nums.size() - 1);
    }

private:
    // [left, right] 闭区间
    TreeNode* build(vector<int>& nums, int left, int right) {
        if (left > right) {
            return nullptr; // 区间为空，无节点
        }
        int mid = left + (right - left) / 2; // 取中间位置作为根节点，防止溢出
        TreeNode* root = new TreeNode(nums[mid]);
        root->left = build(nums, left, mid - 1);   // 左半区间构造左子树
        root->right = build(nums, mid + 1, right);  // 右半区间构造右子树
        return root;
    }
};
```

### Python

区间取中点递归构造是结构性递归，没有对应的标准库一行解，只给手写实现：

```python
class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right


class Solution:
    def sortedArrayToBST(self, nums: list[int]) -> TreeNode:
        def build(left: int, right: int) -> TreeNode:
            if left > right:
                return None  # 区间为空
            mid = left + (right - left) // 2  # 取中间位置作为根节点
            root = TreeNode(nums[mid])
            root.left = build(left, mid - 1)    # 左半区间构造左子树
            root.right = build(mid + 1, right)   # 右半区间构造右子树
            return root

        return build(0, len(nums) - 1)
```

### Go

```go
type TreeNode struct {
    Val   int
    Left  *TreeNode
    Right *TreeNode
}

func sortedArrayToBST(nums []int) *TreeNode {
    var build func(left, right int) *TreeNode
    build = func(left, right int) *TreeNode {
        if left > right {
            return nil // 区间为空
        }
        mid := left + (right-left)/2 // 取中间位置作为根节点
        root := &TreeNode{Val: nums[mid]}
        root.Left = build(left, mid-1)   // 左半区间构造左子树
        root.Right = build(mid+1, right)  // 右半区间构造右子树
        return root
    }
    return build(0, len(nums)-1)
}
```

## 总结

- 核心思路是递归取区间中点当根节点，这个选择动作和二分查找里"取中点"这个动作形式上一样，但目的不一样——二分查找用中点做比较来缩小搜索范围，这道题用中点做"分割点"来保证左右子树节点数量均衡。
- 因为输入数组本身有序，所以随便哪种"取中点切分"的构造方式都自动满足 BST 性质，不需要额外验证，这也是这道题比 0654（最大二叉树）更简单的地方——0654 需要扫描找最大值，这道题只需要算一下中点下标就行。
- 每次递归把区间大致均分成两半，这是保证整棵树高度平衡的关键：数量均衡这个性质会一层一层往下传，最终让任意节点的左右子树高度差都不超过 1。
- 当区间长度为偶数的时候，中点选偏左还是偏右不影响平衡性，只会影响具体的树形状，题目本身也允许多种正确答案。
