# 0102. 二叉树的层序遍历

**题目描述**

给你二叉树的根节点 `root`，返回其按**层序遍历**得到的节点值（即逐层地，从左到右访问所有节点）。返回结果是一个二维数组，每个子数组对应一层的节点值。

```
示例：
输入: root = [3,9,20,null,null,15,7]
      3
     / \
    9  20
      /  \
     15   7
输出: [[3],[9,20],[15,7]]
```

## 思路

层序遍历说白了就是广度优先遍历（BFS）用在二叉树上，标准做法就是拿一个队列来搞。

那这里的关键是什么呢？关键是**怎么区分层与层之间的边界**。你想啊，如果只是把节点一个一个入队出队，那出来的就是一条扁平的序列，你根本分不清哪些节点是同一层的。那怎么解决呢？办法是：**在开始处理某一层之前，先记一下当前队列的长度**，这个长度就代表"这一层一共有多少个节点"。为什么这么记就对呢？因为在处理上一层的时候，你往队列里塞的只会是下一层的节点，不会把当前层还没处理的节点混进去，所以"处理当前层之前那一刻队列的长度"，正好就精确等于当前层的节点数，这个是整个思路的核心。

具体怎么做呢？

1. 先把根节点入队。
2. 只要队列不为空，就记录 `size = queue.size()`，这一轮循环只处理这 `size` 个节点，代表的就是当前这一层。
3. 循环 `size` 次：每次出队一个节点，把它的值放进当前层的临时数组里，同时它的左右孩子如果不是空的，也都塞进队列（这些就是下一层的节点了）。
4. 当前层处理完了，把临时数组加进最终结果里，然后重复第2步，一直到队列空了为止。

这个"记录当前层队列长度"的技巧，其实是层序遍历所有变体题的通用模板，比如说你要每层的结果，或者只要每层最后一个、第一个元素，都是在这个模板上做点局部调整就行了，说白了都是万变不离其宗。

时间复杂度是 O(n)，因为每个节点入队出队各一次；空间复杂度是 O(n)，最坏情况下队列里要同时存下一整层的节点，比如一棵满二叉树最后一层的节点数能接近 n/2，那这时候空间开销就上来了。

## 代码

二叉树节点定义：

```cpp
struct TreeNode {
    int val;
    TreeNode *left;
    TreeNode *right;
    TreeNode(int x) : val(x), left(NULL), right(NULL) {}
};
```

```python
class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right
```

### C++

```cpp
class Solution {
public:
    vector<vector<int>> levelOrder(TreeNode* root) {
        vector<vector<int>> result;
        if (root == nullptr) return result;
        queue<TreeNode*> que;
        que.push(root);                     // 根节点入队
        while (!que.empty()) {
            int size = que.size();          // 记录当前层的节点数
            vector<int> level;              // 存放当前层的结果
            for (int i = 0; i < size; i++) {
                TreeNode* node = que.front();
                que.pop();
                level.push_back(node->val);        // 访问当前节点
                if (node->left) que.push(node->left);   // 左孩子入队（下一层）
                if (node->right) que.push(node->right); // 右孩子入队（下一层）
            }
            result.push_back(level);        // 当前层处理完毕，加入结果
        }
        return result;
    }
};
```

### Java

```java
class Solution {
    public List<List<Integer>> levelOrder(TreeNode root) {
        List<List<Integer>> result = new ArrayList<>();
        if (root == null) return result;
        Queue<TreeNode> queue = new LinkedList<>();
        queue.offer(root);                     // 根节点入队
        while (!queue.isEmpty()) {
            int size = queue.size();           // 记录当前层的节点数
            List<Integer> level = new ArrayList<>();
            for (int i = 0; i < size; i++) {
                TreeNode node = queue.poll();
                level.add(node.val);           // 访问当前节点
                if (node.left != null) queue.offer(node.left);   // 下一层
                if (node.right != null) queue.offer(node.right); // 下一层
            }
            result.add(level);                 // 当前层处理完毕
        }
        return result;
    }
}
```

### Python

```python
from collections import deque

class Solution:
    def levelOrder(self, root):
        result = []
        if root is None:
            return result
        queue = deque([root])          # 根节点入队
        while queue:
            size = len(queue)          # 记录当前层的节点数
            level = []
            for _ in range(size):
                node = queue.popleft()
                level.append(node.val)         # 访问当前节点
                if node.left:
                    queue.append(node.left)    # 左孩子入队（下一层）
                if node.right:
                    queue.append(node.right)   # 右孩子入队（下一层）
            result.append(level)       # 当前层处理完毕
        return result
```

### Go

```go
func levelOrder(root *TreeNode) [][]int {
    result := [][]int{}
    if root == nil {
        return result
    }
    queue := []*TreeNode{root} // 根节点入队
    for len(queue) > 0 {
        size := len(queue) // 记录当前层的节点数
        level := make([]int, 0, size)
        for i := 0; i < size; i++ {
            node := queue[0]
            queue = queue[1:]
            level = append(level, node.Val) // 访问当前节点
            if node.Left != nil {
                queue = append(queue, node.Left) // 下一层
            }
            if node.Right != nil {
                queue = append(queue, node.Right) // 下一层
            }
        }
        result = append(result, level) // 当前层处理完毕
    }
    return result
}
```

## 总结

- 层序遍历的核心技巧就是"记录处理当前层之前的队列长度"，拿这个长度当循环次数，用来区分层与层的边界，这是整道题最关键的一点。
- 这个模板是层序遍历所有变体题的基础，你只要在"处理当前层"这一步做点局部调整，就能衍生出很多题，比如找每层最右边的值、按之字形顺序输出，说白了都是同一个套路。
- 时间复杂度 O(n)，空间复杂度最坏情况是 O(n)，因为满二叉树最后一层的节点数能接近总数的一半。
