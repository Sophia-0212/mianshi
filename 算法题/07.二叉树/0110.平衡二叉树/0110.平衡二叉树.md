# 0110. 平衡二叉树

**题目描述**

给定一个二叉树，判断它是否是高度平衡的二叉树。这里定义平衡二叉树为：一个二叉树中每个节点的左右两个子树的高度差的绝对值不超过 1。

```
示例1（平衡）：
输入: root = [3,9,20,null,null,15,7]
输出: true

示例2（不平衡）：
输入: root = [1,2,2,3,3,null,null,4,4]
输出: false
```

## 思路

- 后序 DFS：返回子树高度；子树已失衡或左右高度差超过 1，返回 -1；否则返回 `1+max(左右高度)`。时间 O(n)，空间 O(h)。
- 自顶向下：每个节点重新求左右高度并检查。最坏时间 O(n²)，空间 O(h)。

h 为树高。

```python
# 依赖说明：max：Python 内置函数：返回最大值。；abs：Python 内置函数：返回数值的绝对值。

class Solution:
    # 方法：isBalanced；按题目要求处理输入并返回结果，核心算法见方法体。
    def isBalanced(self, root):
        return self.getHeight(root) != -1  # 只要不是-1，说明整棵树平衡

    # 方法：getHeight；按题目要求处理输入并返回结果，核心算法见方法体。
    def getHeight(self, node):
        # 返回以node为根的子树高度；不平衡时返回-1
        if node is None:
            return 0                            # 终止条件
        left_height = self.getHeight(node.left)   # 左子树高度
        if left_height == -1:
            return -1                           # 左子树已不平衡，剪枝
        right_height = self.getHeight(node.right) # 右子树高度
        if right_height == -1:
            return -1                           # 右子树已不平衡，剪枝
        if abs(left_height - right_height) > 1:
            return -1                           # 高度差超过1，标记不平衡
        return max(left_height, right_height) + 1  # 正常返回高度
```

```go
// 方法：getHeight；按题目要求处理输入并返回结果，核心算法见方法体。
func getHeight(node *TreeNode) int {
    if node == nil {
        return 0 // 终止条件
    }
    leftHeight := getHeight(node.Left) // 左子树高度
    if leftHeight == -1 {
        return -1 // 左子树已不平衡，剪枝
    }
    rightHeight := getHeight(node.Right) // 右子树高度
    if rightHeight == -1 {
        return -1 // 右子树已不平衡，剪枝
    }
    diff := leftHeight - rightHeight
    if diff > 1 || diff < -1 {
        return -1 // 高度差超过1，标记不平衡
    }
    if leftHeight > rightHeight {
        return leftHeight + 1 // 正常返回高度
    }
    return rightHeight + 1
```

```cpp
class Solution {
public:
    // 返回以node为根的子树高度；如果已经不平衡，返回-1作为标记
    // 方法：getHeight；按题目要求处理输入并返回结果，核心算法见方法体。
    int getHeight(TreeNode* node) {

    bool isBalanced(TreeNode* root) {
        return getHeight(root) != -1;  // 只要最终返回值不是-1，说明整棵树平衡
    }
};
```

## 总结

- 朴素解法在每个节点都重新算一次子树高度，会造成大量重复计算，时间复杂度会退化到 O(n²)。
- 优化解法把"求高度"和"判断平衡"合并到同一次后序遍历里，用 -1 当作"已发现不平衡"的标记，一旦某个子树标记为不平衡，就立即往上返回，不再继续算下去，实现提前剪枝。
- 优化之后每个节点只访问一次，时间复杂度降到 O(n)，空间复杂度就是递归调用栈的开销 O(h)。
- 这种"用特殊返回值同时携带结果和错误/终止信号"的技巧，在树形递归里是很常见的性能优化手段，值得你在类似题目里举一反三。
