# 1382. 将二叉搜索树变平衡

**题目描述**

给定一棵二叉搜索树（BST），请将其转换为一棵**高度平衡**的二叉搜索树，返回任意一个符合要求的新二叉搜索树的根节点即可（答案不唯一）。

```
示例：
输入: root = [1,null,2,null,3,null,4,null,null]  （一条向右倾斜的链）
输出: [2,1,3,null,null,null,4]  （或任意其他高度平衡的合法 BST）
解释: 原树退化成链表形态，高度为 4；转换后的树高度平衡，高度为 2 或 3
```

要求：转换后的树必须仍然是合法的 BST（中序遍历结果不变），且任意节点的左右子树高度差不超过 1。

## 思路

这题的关键洞察是这样的：**任何一棵 BST 的中序遍历结果，都是一个严格升序的有序数组**。而"有序数组转平衡 BST"呢，这其实是一个已经解决过的经典问题，也就是 LeetCode 108 题：每次取数组的中间位置当根节点，左半部分递归构建左子树，右半部分递归构建右子树，这样构建出来的树天然就是高度平衡的，为什么呢？因为每一层的左右子树节点数量差最多是 1。

所以你看，整道题其实可以拆成两个独立的、而且都很成熟的子步骤：

**第一步：BST → 有序数组（中序遍历）**

这里的关键是，BST 的性质保证了中序遍历（左 - 根 - 右）访问节点的顺序就是数值升序的。这一步只需要做一次标准的中序遍历，把节点值依次存进数组就行，不用额外排序。

**第二步：有序数组 → 平衡 BST（也就是 108 题的方法）**

对数组区间 `[left, right]`，取中间下标 `mid = left + (right - left) / 2`（也可以取 `(left+right+1)/2`，这两种取整方式都能保证高度差不超过 1，只是构建出来的具体树形不一样，因为这题本身就允许多解）。用 `nums[mid]` 新建一个节点当当前子树的根，然后递归处理 `[left, mid-1]` 作为左子树、`[mid+1, right]` 作为右子树。

那为什么这样构建出来的一定是高度平衡的呢？因为每次划分都是从中间切开的，左右两部分的节点数量最多相差 1，这个性质在递归的每一层都成立，所以整棵树里任意节点的左右子树高度差都不会超过 1，这就满足平衡二叉树的定义了。

边界条件这块，递归到 `left > right` 的时候说明区间为空了，返回 `nullptr`（也就是空节点），这就是递归的终止条件。取中点用 `left + (right - left) / 2` 而不是 `(left + right) / 2`，是为了避免下标很大的时候发生整数溢出——虽然这题的数据规模不会真的溢出，但这是二分类问题的标准写法习惯，得养成这个习惯。

这道题真正的考点其实不是这两步本身实现起来有多难，而是你能不能识别出"BST 中序遍历能得到有序数组"和"有序数组可以确定性地构建平衡 BST"这两个知识点是可以拼在一起解决一个新问题的——这其实是一种很典型的**问题分解**能力：把一个看起来陌生的问题，转化成两个已知解法的组合。你想啊，任何 BST，不管它原来长什么形状（哪怕退化成一条链），只要能拿到它的中序遍历数组，就都能用同一套方法重建成平衡树。

复杂度这块，中序遍历会把每个节点访问一次，时间是 O(n)；重建过程也是遍历数组每个元素一次去构建一个节点，时间也是 O(n)；所以总的时间复杂度是 O(n)。空间复杂度上，存储中序数组需要 O(n)，加上递归调用栈在平衡重建时深度是 O(log n)，而原来的中序遍历如果原树退化成链的话，调用栈深度会是 O(n)，所以总体空间复杂度是 O(n)。

## 代码

### C++

```cpp
struct TreeNode {
    int val;
    TreeNode *left;
    TreeNode *right;
    TreeNode() : val(0), left(nullptr), right(nullptr) {}
    TreeNode(int x) : val(x), left(nullptr), right(nullptr) {}
    TreeNode(int x, TreeNode *left, TreeNode *right) : val(x), left(left), right(right) {}
};

class Solution {
public:
    TreeNode* balanceBST(TreeNode* root) {
        vector<int> sortedVals;
        inorder(root, sortedVals);           // 第一步：中序遍历得到有序数组
        return buildBalanced(sortedVals, 0, (int)sortedVals.size() - 1);  // 第二步：重建平衡 BST
    }

private:
    void inorder(TreeNode* node, vector<int>& vals) {
        if (node == nullptr) return;
        inorder(node->left, vals);   // 先访问左子树
        vals.push_back(node->val);   // 再记录当前节点值（保证升序）
        inorder(node->right, vals);  // 最后访问右子树
    }

    TreeNode* buildBalanced(vector<int>& vals, int left, int right) {
        if (left > right) return nullptr;  // 区间为空，返回空节点
        int mid = left + (right - left) / 2;  // 取中点作为根，防止溢出
        TreeNode* node = new TreeNode(vals[mid]);
        node->left = buildBalanced(vals, left, mid - 1);   // 左半区间构建左子树
        node->right = buildBalanced(vals, mid + 1, right); // 右半区间构建右子树
        return node;
    }
};
```

### Java

```java
class TreeNode {
    int val;
    TreeNode left;
    TreeNode right;
    TreeNode() {}
    TreeNode(int val) { this.val = val; }
    TreeNode(int val, TreeNode left, TreeNode right) {
        this.val = val;
        this.left = left;
        this.right = right;
    }
}

class Solution {
    public TreeNode balanceBST(TreeNode root) {
        List<Integer> sortedVals = new ArrayList<>();
        inorder(root, sortedVals);  // 第一步：中序遍历得到有序数组
        return buildBalanced(sortedVals, 0, sortedVals.size() - 1);  // 第二步：重建平衡 BST
    }

    private void inorder(TreeNode node, List<Integer> vals) {
        if (node == null) return;
        inorder(node.left, vals);   // 先访问左子树
        vals.add(node.val);         // 再记录当前节点值
        inorder(node.right, vals);  // 最后访问右子树
    }

    private TreeNode buildBalanced(List<Integer> vals, int left, int right) {
        if (left > right) return null;  // 区间为空
        int mid = left + (right - left) / 2;  // 取中点作为根
        TreeNode node = new TreeNode(vals.get(mid));
        node.left = buildBalanced(vals, left, mid - 1);   // 左半区间构建左子树
        node.right = buildBalanced(vals, mid + 1, right); // 右半区间构建右子树
        return node;
    }
}
```

### Python

标准库没有直接的一行解法能同时完成"中序遍历 + 重建平衡树"，这是一个需要显式实现两阶段算法的问题，直接给出手写实现：

```python
class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right


class Solution:
    def balanceBST(self, root: TreeNode) -> TreeNode:
        sorted_vals = []
        self._inorder(root, sorted_vals)  # 第一步：中序遍历得到有序数组
        return self._build_balanced(sorted_vals, 0, len(sorted_vals) - 1)  # 第二步：重建平衡 BST

    def _inorder(self, node: TreeNode, vals: list) -> None:
        if node is None:
            return
        self._inorder(node.left, vals)   # 先访问左子树
        vals.append(node.val)            # 再记录当前节点值（保证升序）
        self._inorder(node.right, vals)  # 最后访问右子树

    def _build_balanced(self, vals: list, left: int, right: int) -> TreeNode:
        if left > right:
            return None  # 区间为空
        mid = left + (right - left) // 2  # 取中点作为根
        node = TreeNode(vals[mid])
        node.left = self._build_balanced(vals, left, mid - 1)    # 左半区间构建左子树
        node.right = self._build_balanced(vals, mid + 1, right)  # 右半区间构建右子树
        return node
```

面试考察点：能不能主动联想到"BST 中序遍历有序"和"有序数组转平衡 BST"这两个知识点，并把它们串联起来，这才是这道题区分度的核心，而不是编码本身有多复杂。

### Go

```go
type TreeNode struct {
    Val   int
    Left  *TreeNode
    Right *TreeNode
}

func balanceBST(root *TreeNode) *TreeNode {
    var sortedVals []int
    inorder(root, &sortedVals)                       // 第一步：中序遍历得到有序数组
    return buildBalanced(sortedVals, 0, len(sortedVals)-1) // 第二步：重建平衡 BST
}

func inorder(node *TreeNode, vals *[]int) {
    if node == nil {
        return
    }
    inorder(node.Left, vals)          // 先访问左子树
    *vals = append(*vals, node.Val)   // 再记录当前节点值
    inorder(node.Right, vals)         // 最后访问右子树
}

func buildBalanced(vals []int, left, right int) *TreeNode {
    if left > right {
        return nil // 区间为空
    }
    mid := left + (right-left)/2 // 取中点作为根
    node := &TreeNode{Val: vals[mid]}
    node.Left = buildBalanced(vals, left, mid-1)   // 左半区间构建左子树
    node.Right = buildBalanced(vals, mid+1, right) // 右半区间构建右子树
    return node
}
```

## 总结

- 核心技巧是"BST → 中序有序数组 → 平衡 BST"这个两段式转化，把一个新问题拆解成两个已知的经典子问题（中序遍历、108 题有序数组转平衡 BST）的组合。
- 这体现了一个通用规律：**任何 BST 都可以先转换成中序有序数组，再用同一套构建方法重建**，不管原树形态多么退化（比如完全变成一条链）都一样。
- 容易出错的地方在于取中点的下标计算要用 `left + (right - left) / 2` 来防止溢出，还有递归终止条件 `left > right` 不能写错（要是写成 `left >= right` 就会漏掉单节点区间）。
- 这题答案不唯一，只要中序遍历结果跟原树一致（也就是 BST 性质不变）而且高度平衡就行，不用纠结于非得构造出某个"标准"形态的树。
