# 0654. 最大二叉树

**题目描述**

给定一个不含重复元素的整数数组 `nums`，请用如下方法递归地构造最大二叉树：

1. 二叉树的根是数组 `nums` 中的最大元素。
2. 左子树是通过数组中**最大值左边**的子数组构造出的最大二叉树。
3. 右子树是通过数组中**最大值右边**的子数组构造出的最大二叉树。

返回有根节点 `root`，由 `nums` 构建的最大二叉树。

```
示例：
输入: nums = [3,2,1,6,0,5]
输出: [6,3,5,null,2,0,null,null,1]
解释: 6 是最大值，左边子数组 [3,2,1] 构造左子树，右边子数组 [0,5] 构造右子树，
      递归地重复这个过程构造出整棵树。
```

## 思路

你想啊，这道题其实跟 0106（从中序与后序遍历构造二叉树）是一个套路："先找到当前区间的根节点，再拿这个根节点把区间切成左右两半，然后递归构造左右子树"。区别就在于根节点怎么找——这里更简单，不用靠遍历序列的性质去反推，题目直接告诉你了：**当前区间的最大值就是根节点**。

那具体怎么递归呢？说白了就是这么几步：

1. 在当前处理的区间 `[left, right]` 里扫一遍，找到最大值和它的下标 `maxIdx`。
2. 拿这个最大值建一个根节点。
3. 左子树递归处理区间 `[left, maxIdx-1]`，也就是最大值左边那一段。
4. 右子树递归处理区间 `[maxIdx+1, right]`，最大值右边那一段。
5. 递归的终止条件也很直白：区间为空了（`left > right`），直接返回 `null`。

那为什么这样递归下去，构造出来的树一定是唯一确定的呢？这里的关键是数组里所有元素都不重复，所以每个区间内的最大值肯定是唯一的，根节点的位置一定了，左右两个子区间自然也就唯一确定了，不会有歧义。这也是这题比 0106 简单的地方——不需要像 0106 那样额外搞个哈希表去加速定位根节点，因为找根节点和切分区间本来就是同一个动作，不用在两个不同数组之间来回换算下标。

**这里还有个值得聊的点，就是要不要原地操作还是新建子数组**。一种比较直观的写法是每次递归都用 `nums[left+1:maxIdx]`、`nums[maxIdx+1:right+1]` 这种切片方式建一个新数组传给子问题，代码看起来更直白，但问题是每次切片都要拷贝数据，最坏情况下——比如树退化成一条链，输入是严格递增或递减的序列——总的拷贝代价就变成 O(n²) 了。更好的做法是不新建数组，而是像 0106 一样只传区间的左右边界下标 `[left, right]`，直接在原数组上操作，这样就把额外的拷贝开销给省掉了。所以这里代码采用的是后一种下标传递的写法。

再说说复杂度。每一层递归都要扫一遍当前区间去找最大值，最坏情况下——比如输入是严格递增序列，每次最大值都卡在区间最右端，整棵树退化成单链——总的扫描次数就是 `n + (n-1) + ... + 1`，时间复杂度是 O(n²)；但平均情况下，最大值大致落在区间中部，跟平衡二分差不多，那就是 O(n log n)。空间复杂度就是递归栈的开销，最坏 O(n)，平均 O(log n)。如果还想进一步优化到 O(n)，可以用单调栈维护"下一个更大元素"的关系一次性构造出来，不过这属于更进阶的技巧了，这道题按常规递归理解就够了。

## 代码

二叉树节点定义：

```cpp
struct TreeNode {
    int val;
    TreeNode *left;
    TreeNode *right;
    TreeNode(int x) : val(x), left(NULL), right(NULL) {}
};
```

### C++

```cpp
class Solution {
public:
    TreeNode* constructMaximumBinaryTree(vector<int>& nums) {
        return build(nums, 0, nums.size() - 1);
    }

private:
    // [left, right] 闭区间
    TreeNode* build(vector<int>& nums, int left, int right) {
        if (left > right) {
            return nullptr; // 区间为空，无节点
        }
        int maxIdx = left;
        for (int i = left + 1; i <= right; i++) {
            if (nums[i] > nums[maxIdx]) {
                maxIdx = i; // 更新区间内最大值下标
            }
        }
        TreeNode* root = new TreeNode(nums[maxIdx]);
        root->left = build(nums, left, maxIdx - 1);   // 最大值左边的子数组构造左子树
        root->right = build(nums, maxIdx + 1, right);  // 最大值右边的子数组构造右子树
        return root;
    }
};
```

### Python

区间最大值分割是结构性递归，没有对应的标准库一行解，只给手写实现：

```python
class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right


class Solution:
    def constructMaximumBinaryTree(self, nums: list[int]) -> TreeNode:
        def build(left: int, right: int) -> TreeNode:
            if left > right:
                return None  # 区间为空
            max_idx = left
            for i in range(left + 1, right + 1):
                if nums[i] > nums[max_idx]:
                    max_idx = i  # 更新区间内最大值下标
            root = TreeNode(nums[max_idx])
            root.left = build(left, max_idx - 1)    # 左边子数组构造左子树
            root.right = build(max_idx + 1, right)   # 右边子数组构造右子树
            return root

        return build(0, len(nums) - 1)
```

## 总结

- 这道题延续的是 0106 那套核心分割思路（找根节点 -> 切分区间 -> 递归构造左右子树），只不过根节点的确定规则更简单直接：区间最大值就是根。
- 用左右边界下标在原数组上直接操作，而不是每层递归都切片新建子数组，这样能省掉额外的拷贝开销，这也是处理"区间递归构造"这类问题时通用的优化手段。
- 因为数组元素不重复，所以每个区间的最大值都是唯一的，这么一来左右子树的切分点也就唯一确定了，不会有构造上的歧义。
- 平均时间复杂度是 O(n log n)，但最坏情况下（输入近似有序）会退化到 O(n²)；如果对性能要求更高，可以考虑用单调栈把复杂度优化到 O(n)。
