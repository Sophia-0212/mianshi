# 0654. 最大二叉树

**题目描述**

给定一个不含重复元素的整数数组 `nums`，请用如下方法递归地构造最大二叉树：

1. 二叉树的根是数组 `nums` 中的最大元素。
2. 左子树是通过数组中**最大值左边**的子数组构造出的最大二叉树。
3. 右子树是通过数组中**最大值右边**的子数组构造出的最大二叉树。

返回有根节点 `root`，由 `nums` 构建的最大二叉树。

```
示例：
输入: nums = [3,2,1,6,0,5]
输出: [6,3,5,null,2,0,null,null,1]
解释: 6 是最大值，左边子数组 [3,2,1] 构造左子树，右边子数组 [0,5] 构造右子树，
      递归地重复这个过程构造出整棵树。
```

## 思路

分治：找到当前区间最大值作为根，递归构造其左右区间。传下标区间避免复制子数组。

最坏时间 O(n²)，均衡划分时 O(n log n)；辅助空间 O(h)，结果树 O(n)。切片递归在偏斜输入下峰值空间可达 O(n²)。

class TreeNode:

    def constructMaximumBinaryTree(self, nums: list[int]) -> TreeNode:
        # 方法：build；按题目要求处理输入并返回结果，核心算法见方法体。
        def build(left: int, right: int) -> TreeNode:

            root.right = build(max_idx + 1, right)   # 右边子数组构造右子树
            return root

        return build(0, len(nums) - 1)```

class Solution {
public:
    TreeNode* constructMaximumBinaryTree(vector<int>& nums) {
        return build(nums, 0, nums.size() - 1);

    // [left, right] 闭区间
    TreeNode* build(vector<int>& nums, int left, int right) {
        if (left > right) {
            return nullptr; // 区间为空，无节点
        }
        int maxIdx = left;

        return root;
    }
};

## 总结

- 这道题延续的是 0106 那套核心分割思路（找根节点 -> 切分区间 -> 递归构造左右子树），只不过根节点的确定规则更简单直接：区间最大值就是根。
- 用左右边界下标在原数组上直接操作，而不是每层递归都切片新建子数组，这样能省掉额外的拷贝开销，这也是处理"区间递归构造"这类问题时通用的优化手段。
- 因为数组元素不重复，所以每个区间的最大值都是唯一的，这么一来左右子树的切分点也就唯一确定了，不会有构造上的歧义。
- 平均时间复杂度是 O(n log n)，但最坏情况下（输入近似有序）会退化到 O(n²)；如果对性能要求更高，可以考虑用单调栈把复杂度优化到 O(n)。
