# 二叉树中递归带着回溯

回溯维护共享路径：加入当前选择→递归→撤销，防止兄弟分支互相污染。

```
def backtrack(路径, 选择列表):
    if 满足终止条件:
        记录路径
        return
    for 选择 in 选择列表:
        做出选择（路径.append(选择)）
        backtrack(路径, 新的选择列表)
        撤销选择（路径.pop()）
```

树中收集根到叶子路径时，到叶子保存副本。数值参数按值传递无需撤销；新建独立字符串／列表可免撤销，但有复制开销。

不复制路径的 DFS 辅助空间 O(h)；收集全部路径时间 O(n+L)、结果空间 O(L)，L 为输出总长度。
