# 0450. 删除二叉搜索树中的节点

**题目描述**

给定二叉搜索树（BST）的根节点 `root` 和一个值 `key`，删除 BST 中值为 `key` 的节点，并保证删除后的树仍然是有效的 BST。返回删除后 BST 的根节点。

```
示例：
输入: root = [5,3,6,2,4,null,7], key = 3
输出: [5,4,6,2,null,null,7]
解释: 节点 3 有左右两个孩子（2 和 4），删除后可以用右子树的最小值节点 4 顶替它的位置。
```

## 思路

删除操作在二叉树这块算是比较难的一类题了，难点在哪呢？就是你不能简单地把一个节点"抹掉"就完事了，得处理好它原来挂着的左右子树，保证删除完之后整棵树依然满足 BST 的性质。所以这里的关键就是要对删除节点的情况做分类讨论。

第一步，先得找到要删除的那个节点。这一步跟 0700，也就是 BST 中的搜索，完全是一样的思路：利用 BST 的有序性，拿 `key` 跟当前节点的值比一比，决定是往左走还是往右走，一直递归下去，直到找到 `root->val == key` 的那个节点为止。

第二步，找到节点之后，要根据它的孩子情况来分类处理删除逻辑。你想啊，假设当前递归到的节点就是要删除的那个节点，记作 `root`，这里其实一共有四种情况：

1. 第一种，`root` 是叶子节点，也就是左右孩子都为空。这种最简单，直接删掉，返回 `null`，让父节点对应的指针指向空就行了。
2. 第二种，`root` 只有左子树，右孩子是空的。这种情况直接用左子树顶替 `root` 的位置，返回 `root->left` 就行。为什么这么做是安全的呢？因为 `root` 的父节点其实只关心"这个位置该接哪个子树的根节点"，而左子树本身已经是一棵合法的 BST 了，直接拿它顶上去不会破坏任何性质。
3. 第三种，`root` 只有右子树，左孩子是空的，道理是一样的，直接用右子树顶替，返回 `root->right`。
4. 第四种，也是最复杂的情况：`root` 的左右子树都存在。这时候就不能像前两种情况那样简单粗暴地"顶替"了，因为如果只用左子树或者右子树去顶，那另外一棵子树就没地方安放了。这里正确的做法是：去右子树里找到那个值最小的节点（或者反过来，去左子树里找值最大的节点也行），用这个节点的值去顶替 `root` 本来的值，然后再递归地跑到右子树里，把这个最小值节点删掉——因为它的值已经"复制"到 `root` 这个位置上了，原来那个节点就得挪走，不然树里就会出现重复值。

那为什么找右子树里的最小值节点是安全的呢？你这么想：右子树里的最小值节点，一定比左子树的所有节点都大，这是因为它本身就在右子树里，而右子树整体比 `root` 大，自然也就比左子树所有节点都大；同时它又是右子树里最小的那个。所以用它去顶替 `root` 之后，依然满足"左子树 < 顶替节点 < 右子树剩下的节点"这个 BST 性质。而且这个最小值节点在右子树里的位置，必然是一路往左走到底的那个点，也就是说它自己最多只有右孩子——不可能有左孩子，否则它就不是最小值了。所以递归删除它的时候，一定会落到情况1或者情况3里去，不会再掉进情况4这种复杂情况，递归深度是可控的。

（对称地来看，你也可以选择用左子树的最大值节点去顶替，两种做法都是对的，只是效果上会让删除后树的形状稍微有点不一样，但都能保持住 BST 的性质。这里采用的是"右子树最小值"这种写法，是比较常见的解法。）

递归返回值怎么对接呢？这里跟 0701，也就是 BST 插入那道题一样，也得用"递归返回值重新赋值给子节点指针"这个模式——也就是 `root->left = deleteNode(root->left, key)` 或者 `root->right = deleteNode(root->right, key)`，这样才能保证删除操作在子树内部完成之后，能正确地把改完的子树接回父节点上去。

复杂度分析这块，查找要删除的节点需要 O(h)；如果命中了第四种情况，还得额外花 O(h) 去右子树找最小值节点并把它删掉。所以整体的时间复杂度仍然是 O(h)，h 是树的高度。空间复杂度是 O(h)，主要是递归调用栈的开销。

## 代码

二叉树节点定义：

```cpp
struct TreeNode {
    int val;
    TreeNode *left;
    TreeNode *right;
    TreeNode(int x) : val(x), left(NULL), right(NULL) {}
};
```

### C++

```cpp
class Solution {
public:
    TreeNode* deleteNode(TreeNode* root, int key) {
        if (root == nullptr) {
            return nullptr; // 没找到要删除的值，空树/空子树直接返回
        }
        if (key < root->val) {
            root->left = deleteNode(root->left, key);   // 目标更小，去左子树删除并接回
            return root;
        }
        if (key > root->val) {
            root->right = deleteNode(root->right, key);  // 目标更大，去右子树删除并接回
            return root;
        }

        // 走到这里说明 root->val == key，root 就是要删除的节点
        if (root->left == nullptr && root->right == nullptr) {
            delete root;
            return nullptr; // 情况1：叶子节点，直接删除
        }
        if (root->left == nullptr) {
            TreeNode* rightChild = root->right;
            delete root;
            return rightChild; // 情况2：只有右子树，用右子树顶替
        }
        if (root->right == nullptr) {
            TreeNode* leftChild = root->left;
            delete root;
            return leftChild; // 情况3：只有左子树，用左子树顶替
        }

        // 情况4：左右子树都存在，找右子树最小值节点顶替
        TreeNode* successor = root->right;
        while (successor->left != nullptr) {
            successor = successor->left; // 一路向左找到右子树的最小值节点
        }
        root->val = successor->val;                          // 用最小值顶替当前节点的值
        root->right = deleteNode(root->right, successor->val); // 递归删除右子树中的这个最小值节点
        return root;
    }
};
```

        root.right = deleteNode(root.right, successor.val); // 递归删除该最小值节点

### Go

```go
type TreeNode struct {
    Val   int
    Left  *TreeNode
    Right *TreeNode
}

func deleteNode(root *TreeNode, key int) *TreeNode {
    if root == nil {
        return nil // 没找到目标值
    }
    if key < root.Val {
        root.Left = deleteNode(root.Left, key) // 去左子树删除并接回
        return root
    }
    if key > root.Val {
        root.Right = deleteNode(root.Right, key) // 去右子树删除并接回
        return root
    }

    // root.Val == key，root 就是要删除的节点
    if root.Left == nil && root.Right == nil {
        return nil // 情况1：叶子节点
    }
    if root.Left == nil {
        return root.Right // 情况2：只有右子树
    }
    if root.Right == nil {
        return root.Left // 情况3：只有左子树
    }

    // 情况4：左右子树都存在，找右子树最小值节点
    successor := root.Right
    for successor.Left != nil {
        successor = successor.Left // 一路向左找到最小值节点
    }
    root.Val = successor.Val                          // 用最小值顶替当前节点的值
    root.Right = deleteNode(root.Right, successor.Val) // 递归删除该节点
    return root
}
```

## 总结

- 删除 BST 节点这里的关键是得分类讨论四种情况：叶子节点直接删掉；只有一侧子树的话就用那个子树顶替；左右子树都有的话，就得找一个"后继节点"，也就是右子树的最小值，或者对称地用左子树的最大值，拿它顶替当前节点的值，再递归把这个后继节点原来的位置删掉。
- 找右子树最小值节点这个路径，说白了就是"一路向左走到底"，这个节点本身最多只有右孩子，所以递归删除它的时候不会再掉进"左右子树都存在"这种复杂情况里，递归深度是可控的。
- 这里沿用了 0701（BST 插入）那道题的套路，也就是"递归返回值重新赋值给子节点指针"这个模式，这样才能保证子树内部改完之后能正确接回父节点，这也是二叉树结构性修改类题目通用的写法。
- 用右子树最小值还是左子树最大值去顶替，两种写法都是对的，只是会让删除后树的具体形状不太一样，但不管选哪种，都得保证递归删除后继节点的时候不会引入重复值，也不会破坏 BST 的性质。
