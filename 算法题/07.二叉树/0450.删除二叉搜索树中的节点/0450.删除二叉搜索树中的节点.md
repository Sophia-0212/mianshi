# 0450. 删除二叉搜索树中的节点

**题目描述**

给定二叉搜索树（BST）的根节点 `root` 和一个值 `key`，删除 BST 中值为 `key` 的节点，并保证删除后的树仍然是有效的 BST。返回删除后 BST 的根节点。

```
示例：
输入: root = [5,3,6,2,4,null,7], key = 3
输出: [5,4,6,2,null,null,7]
解释: 节点 3 有左右两个孩子（2 和 4），删除后可以用右子树的最小值节点 4 顶替它的位置。
```

## 思路

按 BST 有序性查找目标，删除后返回新子树根：

- 无孩子：返回空。
- 仅一个孩子：返回该孩子。
- 两个孩子：用右子树最小值替换当前值，再删除该后继节点；也可对称地用左子树最大值替换并删除。

时间 O(h)，递归空间 O(h)，h 为树高。

    # 方法：__init__；按题目要求处理输入并返回结果，核心算法见方法体。

class Solution:
    # 方法：deleteNode；按题目要求处理输入并返回结果，核心算法见方法体。
    def deleteNode(self, root: TreeNode, key: int) -> TreeNode:
        if root is None:
            return None  # 没找到目标值

        if key < root.val:
            root.left = self.deleteNode(root.left, key)  # 去左子树删除并接回
            return root
        if key > root.val:
            root.right = self.deleteNode(root.right, key)  # 去右子树删除并接回
            return root

        # root.val == key，root 就是要删除的节点
        if root.left is None and root.right is None:
            return None  # 情况1：叶子节点
        if root.left is None:
            return root.right  # 情况2：只有右子树
        if root.right is None:
            return root.left  # 情况3：只有左子树

        # 情况4：左右子树都存在，找右子树最小值节点
        successor = root.right
        while successor.left is not None:
            successor = successor.left  # 一路向左找到最小值节点
        root.val = successor.val  # 用最小值顶替当前节点的值
        root.right = self.deleteNode(root.right, successor.val)  # 递归删除该节点
        return root

```cpp
class Solution {
public:
    TreeNode* deleteNode(TreeNode* root, int key) {
        if (root == nullptr) {
            return nullptr; // 没找到要删除的值，空树/空子树直接返回
        }
        if (key < root->val) {
            root->left = deleteNode(root->left, key);   // 目标更小，去左子树删除并接回
            return root;
        }
        if (key > root->val) {
            root->right = deleteNode(root->right, key);  // 目标更大，去右子树删除并接回
            return root;
        }

        // 走到这里说明 root->val == key，root 就是要删除的节点
        if (root->left == nullptr && root->right == nullptr) {
            delete root;
            return nullptr; // 情况1：叶子节点，直接删除
        }
        if (root->left == nullptr) {
            TreeNode* rightChild = root->right;
            delete root;
            return rightChild; // 情况2：只有右子树，用右子树顶替
        }
        if (root->right == nullptr) {
            TreeNode* leftChild = root->left;
            delete root;
            return leftChild; // 情况3：只有左子树，用左子树顶替
        }

        // 情况4：左右子树都存在，找右子树最小值节点顶替
        TreeNode* successor = root->right;
        while (successor->left != nullptr) {
            successor = successor->left; // 一路向左找到右子树的最小值节点
        }
        root->val = successor->val;                          // 用最小值顶替当前节点的值
        root->right = deleteNode(root->right, successor->val); // 递归删除右子树中的这个最小值节点
        return root;
    }
};
```

        root->val = successor->val;                          // 用最小值顶替当前节点的值
        root->right = deleteNode(root->right, successor->val); // 递归删除右子树中的这个最小值节点
        return root;
    }

}

int main() {
    // 用例 1：输入 ({'tree': [5, 3, 6, 2, 4, None, 7]}, 3)；期望 [2, 4, 5, 6, 7]。
    {
        auto* arg0 = buildTreeInput({5, 3, 6, 2, 4, nullopt, 7});
        int arg1 = 3;
        auto result = interview::deleteNode(arg0, arg1);
        cout << "用例 1: 期望=[2, 4, 5, 6, 7] 实际=";
        show(inorderValues(result));
        cout << "\n";
    }
    // 用例 2：输入 ({'tree': [1]}, 1)；期望 []。
    {
        auto* arg0 = buildTreeInput({1});
        int arg1 = 1;
        auto result = interview::deleteNode(arg0, arg1);
        cout << "用例 2: 期望=[] 实际=";
        show(inorderValues(result));
        cout << "\n";
    }
    // 用例 3：输入 ({'tree': [2, 1, 3]}, 4)；期望 [1, 2, 3]。
    {
        auto* arg0 = buildTreeInput({2, 1, 3});
        int arg1 = 4;
        auto result = interview::deleteNode(arg0, arg1);
        cout << "用例 3: 期望=[1, 2, 3] 实际=";

}

## 总结

- 删除 BST 节点这里的关键是得分类讨论四种情况：叶子节点直接删掉；只有一侧子树的话就用那个子树顶替；左右子树都有的话，就得找一个"后继节点"，也就是右子树的最小值，或者对称地用左子树的最大值，拿它顶替当前节点的值，再递归把这个后继节点原来的位置删掉。
- 找右子树最小值节点这个路径，说白了就是"一路向左走到底"，这个节点本身最多只有右孩子，所以递归删除它的时候不会再掉进"左右子树都存在"这种复杂情况里，递归深度是可控的。
- 这里沿用了 0701（BST 插入）那道题的套路，也就是"递归返回值重新赋值给子节点指针"这个模式，这样才能保证子树内部改完之后能正确接回父节点，这也是二叉树结构性修改类题目通用的写法。
- 用右子树最小值还是左子树最大值去顶替，两种写法都是对的，只是会让删除后树的具体形状不太一样，但不管选哪种，都得保证递归删除后继节点的时候不会引入重复值，也不会破坏 BST 的性质。
