# 0101. 对称二叉树

**题目描述**

给定一个二叉树的根节点 `root`，检查它是否轴对称（即左右子树是否互为镜像）。

```
示例1（对称）：
    1
   / \
  2   2
 / \ / \
3  4 4  3
输出: true

示例2（不对称）：
    1
   / \
  2   2
   \   \
   3    3
输出: false
```

## 思路

你想啊，这题第一次拿到手很容易掉进一个坑：觉得对称不就是"左子树遍历结果等于右子树遍历结果的逆序"嘛，那我一次遍历完了反转一下比较不就行了？但这个想法其实是错的，为什么呢？因为遍历结果只留下了节点值的序列，树的结构信息全丢了，你想两棵结构完全不一样的树，说不定还真能遍历出一样的序列，所以这条路走不通。

那正确的思路是什么呢？说白了，判断对称，本质上就是要同时看两棵子树是否互为镜像，所以这里递归函数就不能只传一个节点进去了，得传两个节点，分别代表要比较的这两棵子树的根。

我定义一个递归函数 `isMirror(left, right)`，意思是"以 left 为根的树和以 right 为根的树是不是互为镜像"。这一层递归要分三种情况处理：

1. `left` 和 `right` 都是空的：那这俩都是空树，肯定互为镜像，直接返回 `true`。
2. `left`、`right` 里只有一个是空的：这形状已经不对称了，返回 `false`。
3. `left`、`right` 都不为空：这时候先看两个节点的值是不是相等，不相等的话直接返回 `false` 就行；如果相等，还不能马上下结论，得接着往下递归比较——这里的关键是**外侧跟外侧比，内侧跟内侧比**，也就是 `left` 的左孩子要去跟 `right` 的右孩子比，`left` 的右孩子要去跟 `right` 的左孩子比，这两部分递归结果都得是 `true`，这一层才算镜像成立。

那为什么是"外侧比外侧，内侧比内侧"呢？这才是这道题真正的核心。你想啊，镜像对称要求的是，把右子树整个翻转过来之后，得跟左子树长得一模一样，翻转之后原来在右边的节点就跑到左边去了，所以这个配对关系其实是交叉的，不是你想的那种"左比左、右比右"的简单对应。

除了递归写法，这道题也能用迭代法来做：拿一个队列（或者栈也行），每次成对取出两个节点来比较，如果值相等，就把"左的左孩子跟右的右孩子"、"左的右孩子跟右的左孩子"这两组按同样的交叉配对方式塞进队列，接着进行下一轮比较，思路跟递归其实是一致的。

时间复杂度是 O(n)，因为每个节点最多被比较一次；空间复杂度递归情况下是 O(h)，迭代的话最坏情况队列里要存下一层所有配对节点，是 O(n)。

## 代码

二叉树节点定义：

```cpp
struct TreeNode {
    int val;
    TreeNode *left;
    TreeNode *right;
    TreeNode(int x) : val(x), left(NULL), right(NULL) {}
};
```

```python
class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right
```

### C++

```cpp
class Solution {
public:
    // 判断以 left、right 为根的两棵树是否互为镜像
    bool isMirror(TreeNode* left, TreeNode* right) {
        if (left == nullptr && right == nullptr) return true;  // 都为空，镜像成立
        if (left == nullptr || right == nullptr) return false; // 只有一个为空，形状不对称
        if (left->val != right->val) return false;             // 值不相等，直接false
        // 外侧比外侧，内侧比内侧，两部分都要成立
        bool outside = isMirror(left->left, right->right);
        bool inside = isMirror(left->right, right->left);
        return outside && inside;
    }

    bool isSymmetric(TreeNode* root) {
        if (root == nullptr) return true;
        return isMirror(root->left, root->right); // 比较根的左右子树
    }
};
```

### Java

class Solution {
    public boolean isSymmetric(TreeNode root) {
        if (root == null) return true;
        return isMirror(root.left, root.right);   // 比较根的左右子树
    }

    private boolean isMirror(TreeNode left, TreeNode right) {
        if (left == null && right == null) return true;   // 都为空，镜像成立
        if (left == null || right == null) return false;  // 只有一个为空
        if (left.val != right.val) return false;          // 值不相等
        boolean outside = isMirror(left.left, right.right); // 外侧比外侧
        boolean inside = isMirror(left.right, right.left);  // 内侧比内侧
        return outside && inside;
    }
}
```

### Python

class Solution:
    def isSymmetric(self, root):

    def isMirror(self, left, right):
        if left is None and right is None:
            return True                     # 都为空，镜像成立
        if left is None or right is None:
            return False                    # 只有一个为空
        if left.val != right.val:
            return False                    # 值不相等
        outside = self.isMirror(left.left, right.right)  # 外侧比外侧
        inside = self.isMirror(left.right, right.left)   # 内侧比内侧
        return outside and inside
```

### Go

```go
func isSymmetric(root *TreeNode) bool {
    if root == nil {
        return true
    }
    return isMirror(root.Left, root.Right) // 比较根的左右子树
}

// 判断以 left、right 为根的两棵树是否互为镜像
func isMirror(left, right *TreeNode) bool {
    if left == nil && right == nil {
        return true // 都为空，镜像成立
    }
    if left == nil || right == nil {
        return false // 只有一个为空
    }
    if left.Val != right.Val {
        return false // 值不相等
    }
    outside := isMirror(left.Left, right.Right) // 外侧比外侧
    inside := isMirror(left.Right, right.Left)   // 内侧比内侧
    return outside && inside
}
```

## 总结

- 这道题不能只靠一次遍历加反转比较来搞定，必须同时递归比较两棵子树，所以递归函数得传两个节点参数进去。
- 最关键的地方就是"外侧跟外侧比，内侧跟内侧比"，也就是 `left.left` 对 `right.right`，`left.right` 对 `right.left`，这是镜像翻转之后节点位置交叉对应导致的，一定要想清楚这个逻辑。
- 递归的三种终止情况得考虑全面：都是空的、只有一个空的、值不相等，这三种情况一个都不能漏。
- 迭代法其实思路是一样的，就是拿队列成对存放要比较的节点，按同样的交叉规则继续往队列里放，本质上就是把递归的比较顺序换成了用队列显式维护而已。
