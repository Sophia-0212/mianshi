# 129. 求根到叶子节点数字之和

**题目描述**

给定一棵二叉树，树中每个节点都存放一个 0-9 的数字，每一条从根节点到叶子节点的路径都代表一个数字。求所有从根到叶子路径代表的数字之和。

```
示例：
输入: root = [1,2,3]
输出: 25
解释: 从根到叶子节点路径 1->2 代表数字 12，路径 1->3 代表数字 13，12 + 13 = 25
```

```
示例：
输入: root = [4,9,0,5,1]
输出: 1026
解释: 从根到叶子节点路径 4->9->5 代表数字 495
      从根到叶子节点路径 4->9->1 代表数字 491
      从根到叶子节点路径 4->0 代表数字 40
      495 + 491 + 40 = 1026
```

## 思路

这道题说白了就是一次带状态的 DFS，这个状态是什么呢？就是"从根节点一路走到当前节点，已经拼出来的数字"。

那关键的地方在哪呢？就是这个状态要怎么往下传。你想啊，数字的十进制表示其实有个很自然的规律：每往下走一层，就相当于把手上已有的数字整体乘以 10，再加上新节点的值。比如从根节点开始数字是 1，走到值为 2 的子节点，新数字就变成了 `1 * 10 + 2 = 12`；再往下走到值为 5 的子节点，就是 `12 * 10 + 5 = 125`。这个递推关系其实天然就适合用 DFS 的参数往下传，根本不需要额外拼字符串或者用数组记路径。

具体怎么做呢？我设计一个递归函数 `dfs(node, curNum)`，这里的 `curNum` 表示从根节点走到 `node` 的父节点为止，已经拼出来的数字。进到 `node` 之后，先算一下 `curNum = curNum * 10 + node.val`，这样就得到了"包含当前节点"的数字。

- 那如果 `node` 是叶子节点呢（也就是左右孩子都是空的），说明这条路径已经走到底了，直接把这个 `curNum` 加进全局答案里，或者当作返回值往上返回就行。
- 如果不是叶子节点呢，那就把当前算出来的 `curNum` 分别传给左子树和右子树，让它们继续往下递归——为什么要分别传呢？因为二叉树里每一条从根到叶子的路径都是相互独立的，一个节点很可能同时是好几条路径的公共前缀。

边界条件这里要注意两点：第一，空节点直接返回 0，不参与计算（题目已经保证根节点非空，所以空子节点这种情况只在递归内部处理就行）；第二，"叶子节点"的判定一定要左右孩子都为空才算，不能只看某一侧是不是空的，不然会把只有单侧子树的节点错误地当成叶子，提前把路径截断了。

那这里可能有人会问，为什么不用回溯呢，比如先把路径记下来再统一算数字？其实道理很简单：乘 10 加当前值这种"边走边算"的方式，已经把整条路径的信息压缩成了一个数字状态，根本不需要保留整条路径的数组，代码写起来更简洁，而且返回的时候也不需要做撤销操作——这里跟那种经典的回溯场景不一样，经典回溯是多个分支共享同一个可变结构（比如一个列表），需要进去 push、出来 pop；而这道题每次递归传的是值的一份拷贝，天然就不会互相污染，所以完全用不上回溯那套撤销逻辑。

复杂度这块，每个节点只会被访问一次，所以时间复杂度是 O(n)，n 就是节点总数。空间复杂度主要来自递归调用栈，最坏情况下（树退化成一条链）是 O(n)，平均情况下（树高度比较平衡）是 O(log n)。

## 代码

### C++

```cpp
struct TreeNode {
    int val;
    TreeNode *left;
    TreeNode *right;
    TreeNode() : val(0), left(nullptr), right(nullptr) {}
    TreeNode(int x) : val(x), left(nullptr), right(nullptr) {}
    TreeNode(int x, TreeNode *left, TreeNode *right) : val(x), left(left), right(right) {}
};

class Solution {
public:
    int sumNumbers(TreeNode* root) {
        return dfs(root, 0);  // 从根节点开始，初始已组成数字为 0
    }

private:
    int dfs(TreeNode* node, int curNum) {
        if (node == nullptr) {
            return 0;  // 空节点不产生数字，直接返回 0
        }
        curNum = curNum * 10 + node->val;  // 把当前节点值拼接到已有数字末位
        if (node->left == nullptr && node->right == nullptr) {
            return curNum;  // 叶子节点，这条路径的数字已经完整，直接返回
        }
        // 非叶子节点，把 curNum 分别传给左右子树继续拼接，两条路径互不影响
        return dfs(node->left, curNum) + dfs(node->right, curNum);
    }
};
```

### Python

标准库层面没有直接对应"路径数字求和"的一行解法，本题以手写递归为主：

```python
class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right


class Solution:
    def sumNumbers(self, root: TreeNode) -> int:
        def dfs(node: TreeNode, cur_num: int) -> int:
            if node is None:
                return 0  # 空节点不产生数字
            cur_num = cur_num * 10 + node.val  # 拼接当前节点值到已有数字末位
            if node.left is None and node.right is None:
                return cur_num  # 叶子节点，数字已完整，直接返回
            # 非叶子节点，分别递归左右子树，两条路径的 cur_num 互不影响
            return dfs(node.left, cur_num) + dfs(node.right, cur_num)

        return dfs(root, 0)
```

面试考察点：面试官这里主要看你能不能想到"数字 = 父数字 * 10 + 当前值"这个递推式，还有能不能正确处理叶子节点的判定和空节点这些边界条件，而不是单纯看你会不会搭个递归框架。

## 总结

- 这道题的核心技巧就是把"路径"这种本来需要额外存储的信息，压缩成一个跟着递归一起传递的标量状态（也就是 `curNum = curNum * 10 + val`），这样就不用再拿数组或字符串去显式保存路径了。
- 判断叶子节点的时候一定要同时检查左右孩子都是空的，只要漏掉任何一侧，就会导致遍历不完整，或者路径提前被截断。
- 这一类"从根到叶子路径求某种聚合值"的题目，不管是求和、求最大路径还是求路径个数，其实都可以套用同一个模板：递归函数带一个"路径累积状态"的参数，走到叶子节点就结算，走到非叶子节点就把状态原样或者变换一下传给左右子树。
- 跟那种需要显式回溯（进子树前 push，退出来再 pop）的题目不一样，这道题每次递归传的都是值的一份拷贝，根本不存在共享可变状态需要撤销这回事，这其实是判断"这道题要不要写回溯撤销逻辑"的一个很重要的分界点。
