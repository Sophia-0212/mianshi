# 二叉树周末总结（2020.10.17）

- BST 查找、插入：比较大小，只沿一侧前进。时间 O(h)，迭代空间 O(1)，递归 O(h)。
- 中序遍历：验证严格递增、比较相邻差、统计相同值连续次数。时间 O(n)，辅助空间 O(h)。

```
// pre 指针模式伪代码（中序遍历）
def inorder(node):
    if node is None: return
    inorder(node.left)
    if pre is not None:
        与 pre 比较，更新答案（最小差值 / 连续计数等）
    pre = node
    inorder(node.right)
```

普通树最近公共祖先用后序：左右均找到目标则返回当前节点，仅一侧找到则返回该侧。时间 O(n)，空间 O(h)。h 为树高，最坏 O(n)。
