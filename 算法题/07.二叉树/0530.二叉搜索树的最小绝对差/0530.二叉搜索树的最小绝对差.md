# 0530. 二叉搜索树的最小绝对差

**题目描述**

给定一个二叉搜索树（BST）的根节点 `root`，返回树中任意两个不同节点值之间的最小绝对差。

```
示例：
输入: root = [4,2,6,1,3]
输出: 1
解释: 所有节点值排序后是 [1,2,3,4,6]，相邻差值分别是 1,1,1,2，最小值是 1。
```

## 思路

如果不考虑 BST 的性质，暴力解法就是把所有节点值都收集到一个数组里，排序之后遍历相邻元素求最小差值，这样时间复杂度是 O(n log n)，主要花在排序上。但既然这是一棵 BST，那我们就应该想想怎么利用它自带的有序性。

BST 的核心性质是什么呢？就是中序遍历出来的结果是一个严格递增的序列。那既然结果已经是有序的了，最小差值就没必要在"任意两个节点"之间去找了——你想啊，最小差值必然出现在这个有序序列里相邻的两个元素之间。这其实是个很直观的数学事实：在一个递增序列里，任意两个不相邻元素之间的差值，一定大于或等于它们之间某一对相邻元素的差值，为什么呢？因为中间的这些元素把这段距离拆成了好几段，其中肯定有一段不超过整体的平均跨度。所以说白了，只需要比较中序遍历结果里"相邻"的元素对就够了，不用去比较所有 `n*(n-1)/2` 种组合。

有了这个结论，具体实现上还能再优化一步：其实不需要真的把整个中序遍历结果存到一个数组里，因为我们只关心"相邻两个值的差"，所以可以在遍历的过程中用一个 `pre` 指针记录"上一个访问的节点"，每访问到一个新节点，就立刻用"当前节点值减去 pre 节点值"来更新最小差值，然后把 `pre` 更新成当前节点。这么一来，只需要 O(1) 的额外空间就够了（不算递归栈），而不是 O(n) 去存整个序列。

这个"pre 指针加边遍历边比较"的技巧，其实是处理"BST 相邻节点关系"这类问题的通用套路，后面讲 0501（BST 中的众数）的时候也会用到同样的模式。

递归的三要素说一下：终止条件是节点为空就直接返回，什么比较都不做；单层递归逻辑就是中序遍历——先递归左子树，然后处理当前节点，这一步要跟 `pre` 比较、更新最小差值、再更新 `pre`，最后才递归右子树。

复杂度这块，时间复杂度是 O(n)，每个节点访问一次；空间复杂度是 O(h)，h 是树的高度，这里就是递归调用栈的开销，`pre` 指针本身占的是常数空间。

## 代码

二叉树节点定义：

```cpp
struct TreeNode {
    int val;
    TreeNode *left;
    TreeNode *right;
    TreeNode(int x) : val(x), left(NULL), right(NULL) {}
};
```

### C++

```cpp
class Solution {
public:
    int getMinimumDifference(TreeNode* root) {
        inorder(root);
        return result;
    }

private:
    TreeNode* pre = nullptr;      // 记录中序遍历中上一个访问的节点
    int result = INT_MAX;          // 维护当前最小差值

    void inorder(TreeNode* root) {
        if (root == nullptr) return; // 终止条件：空节点
        inorder(root->left);          // 先递归左子树
        if (pre != nullptr) {
            result = min(result, root->val - pre->val); // 与上一个节点比较，更新最小差
        }
        pre = root;                    // 更新 pre 为当前节点
        inorder(root->right);          // 最后递归右子树
    }
};
```

### Java

```java
class Solution {
    private TreeNode pre = null;   // 记录上一个访问的节点
    private int result = Integer.MAX_VALUE; // 最小差值

    public int getMinimumDifference(TreeNode root) {
        pre = null;
        result = Integer.MAX_VALUE; // 重置状态，避免多次调用间污染
        inorder(root);
        return result;
    }

    private void inorder(TreeNode root) {
        if (root == null) return; // 终止条件
        inorder(root.left);         // 先递归左子树
        if (pre != null) {
            result = Math.min(result, root.val - pre.val); // 更新最小差
        }
        pre = root;                  // 更新 pre
        inorder(root.right);         // 最后递归右子树
    }
}
```

### Python

```python
class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right


class Solution:
    def getMinimumDifference(self, root: TreeNode) -> int:
        self.pre = None            # 记录上一个访问的节点
        self.result = float("inf")  # 最小差值

        def inorder(node: TreeNode) -> None:
            if node is None:
                return  # 终止条件
            inorder(node.left)  # 先递归左子树
            if self.pre is not None:
                self.result = min(self.result, node.val - self.pre.val)  # 更新最小差
            self.pre = node  # 更新 pre
            inorder(node.right)  # 最后递归右子树

        inorder(root)
        return self.result
```

### Go

```go
type TreeNode struct {
    Val   int
    Left  *TreeNode
    Right *TreeNode
}

func getMinimumDifference(root *TreeNode) int {
    var pre *TreeNode      // 记录上一个访问的节点
    result := math.MaxInt64 // 最小差值

    var inorder func(node *TreeNode)
    inorder = func(node *TreeNode) {
        if node == nil {
            return // 终止条件
        }
        inorder(node.Left) // 先递归左子树
        if pre != nil {
            diff := node.Val - pre.Val
            if diff < result {
                result = diff // 更新最小差
            }
        }
        pre = node          // 更新 pre
        inorder(node.Right) // 最后递归右子树
    }

    inorder(root)
    return result
}
```

## 总结

- 核心结论就是：BST 中序遍历结果是严格递增的，最小差值必然出现在相邻元素之间，所以说不需要把所有节点两两组合都比较一遍，只要比较中序遍历里相邻的元素对就行。
- 用 `pre` 指针记录中序遍历的上一个节点，边遍历边比较，这样就能把"先存整个序列再遍历比较"那种 O(n) 的额外空间，优化到 O(1)（不含递归栈），这是处理 BST 相邻关系类问题的通用技巧。
- 递归结构其实还是标准的中序遍历模板，唯一的变化就是在"处理当前节点"这一步，插入了跟 `pre` 比较的逻辑。
