# 0530. 二叉搜索树的最小绝对差

**题目描述**

给定一个二叉搜索树（BST）的根节点 `root`，返回树中任意两个不同节点值之间的最小绝对差。

```
示例：
输入: root = [4,2,6,1,3]
输出: 1
解释: 所有节点值排序后是 [1,2,3,4,6]，相邻差值分别是 1,1,1,2，最小值是 1。
```

## 思路

- 中序遍历：BST 有序，最小差必在相邻值间；用前驱值更新最小差。时间 O(n)，空间 O(h)。
- 收集后排序：排序全部节点值，再比较相邻差。时间 O(n log n)，空间 O(n)。

h 为树高。

class TreeNode:
    # 方法：__init__；按题目要求处理输入并返回结果，核心算法见方法体。

    # 方法：getMinimumDifference；按题目要求处理输入并返回结果，核心算法见方法体。
    def getMinimumDifference(self, root: TreeNode) -> int:
        self.pre = None            # 记录上一个访问的节点
        self.result = float("inf")  # 最小差值

        # 方法：inorder；按题目要求处理输入并返回结果，核心算法见方法体。
        def inorder(node: TreeNode) -> None:
            if node is None:
                return  # 终止条件
            inorder(node.left)  # 先递归左子树
            if self.pre is not None:
                self.result = min(self.result, node.val - self.pre.val)  # 更新最小差
            self.pre = node  # 更新 pre
            inorder(node.right)  # 最后递归右子树

        inorder(root)
        return self.result```

### LeetCode 写法与原有示例

```go
type TreeNode struct {
    Val   int
    Left  *TreeNode
    Right *TreeNode
}

// 方法：getMinimumDifference；按题目要求处理输入并返回结果，核心算法见方法体。
func getMinimumDifference(root *TreeNode) int {
    var pre *TreeNode      // 记录上一个访问的节点
    result := math.MaxInt64 // 最小差值

    var inorder func(node *TreeNode)
    inorder = func(node *TreeNode) {
        if node == nil {
            return // 终止条件
        }
        inorder(node.Left) // 先递归左子树
        if pre != nil {
            diff := node.Val - pre.Val
            if diff < result {
                result = diff // 更新最小差
            }
        }
        pre = node          // 更新 pre
        inorder(node.Right) // 最后递归右子树
    }

    inorder(root)
    return result
}
```

## 总结

- 核心结论就是：BST 中序遍历结果是严格递增的，最小差值必然出现在相邻元素之间，所以说不需要把所有节点两两组合都比较一遍，只要比较中序遍历里相邻的元素对就行。
- 用 `pre` 指针记录中序遍历的上一个节点，边遍历边比较，这样就能把"先存整个序列再遍历比较"那种 O(n) 的额外空间，优化到 O(1)（不含递归栈），这是处理 BST 相邻关系类问题的通用技巧。
- 递归结构其实还是标准的中序遍历模板，唯一的变化就是在"处理当前节点"这一步，插入了跟 `pre` 比较的逻辑。
- 这道题跟后面要讲的 0501（BST 中的众数）共享的是同一个"pre 指针加中序遍历"的模式，把这道题的写法理解透了，后面可以直接照搬过去用。
