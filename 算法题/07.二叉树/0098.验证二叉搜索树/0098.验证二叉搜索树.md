# 0098. 验证二叉搜索树

**题目描述**

给定一个二叉树的根节点 `root`，判断其是否是一个有效的二叉搜索树（BST）。

有效的二叉搜索树定义如下：
- 节点的左子树只包含**小于**当前节点的数。
- 节点的右子树只包含**大于**当前节点的数。
- 所有左子树和右子树自身必须也是二叉搜索树。

```
示例：
输入: root = [5,1,4,null,null,3,6]
输出: false
解释: 根节点的值是 5，但右子节点的值是 4，5 > 4 违反了 BST 性质。
```

## 思路

这道题你要小心，最容易踩的一个坑就是：光比较父子节点的大小关系，其实是不够的。很多人第一反应会这么写：递归的时候检查一下 `root->left->val < root->val` 而且 `root->val < root->right->val`，只要都满足，就觉得这是一棵合法的 BST 了。但这个写法其实是错的，我给你举个反例：

```
    5
   / \
  1   6
     / \
    3   7
```

你看这棵树，根节点 5 和它的直接孩子（1、6）比一下，没毛病；节点 6 和它的直接孩子（3、7）比一下，也没毛病。但问题就出在这儿：5 的右子树里藏着一个节点 3，`3 < 5`，这就违反了"右子树所有节点都要大于根节点"这条规则。为什么只看父子关系会漏掉这种问题呢？因为它只能管住"隔一层"的关系，管不住"隔代"的情况。

所以正确的做法是什么呢？说白了就是要保证：整个左子树的所有节点都得小于当前节点，整个右子树的所有节点都得大于当前节点，不能只看直接的左右孩子。这里我说两种主流的解法。

第一种解法，是递归传递上下界。这里的关键是：每个节点能取的合法范围，其实是由它的祖先节点决定的。根节点一开始的合法范围是 `(-∞, +∞)`，没有限制；往左子树递归的时候，因为当前节点的值必须比左子树所有节点都大，所以左子树的合法范围就收窄成了 `(lower, root->val)`；往右子树递归呢，范围就收窄成 `(root->val, upper)`。就这样一层一层递归下去，不断把这个 `(lower, upper)` 区间收紧，只要发现某个节点的值跳出了这个区间，立刻就能判定整棵树不合法。这种写法基本就是把题目定义直接翻译成代码，是最好理解、也最不容易写错的方式。

第二种解法，是用中序遍历来判断是不是严格递增。这里的关键是什么呢？BST 还有一个等价的性质：对 BST 做中序遍历，得到的序列一定是严格递增的。反过来说也成立——如果一棵树中序遍历出来是严格递增的，那这棵树本身就一定是合法的 BST，这是个双向的充要关系。那问题就转化成了：中序遍历这棵树，同时拿当前节点跟"上一个访问过的节点"比一下，只要当前值不大于上一个值，那就说明不是严格递增，直接判不合法。这个解法为什么更优雅呢？因为它不需要显式地传上下界，只要维护一个 `pre` 指针记住上一个访问的节点就行了，一边遍历一边比较，这也是这道题公认最漂亮的解法。

那这两种解法的复杂度怎么样呢？时间上都是 O(n)，因为每个节点只访问一次；空间上，解法一是 O(h)，也就是递归栈的深度；解法二额外只需要一个 `pre` 指针，如果算上遍历本身用到的递归栈，空间也是 O(h)。

## 代码

二叉树节点定义：

```cpp
struct TreeNode {
    int val;
    TreeNode *left;
    TreeNode *right;
    TreeNode(int x) : val(x), left(NULL), right(NULL) {}
};
```

### C++

```cpp
class Solution {
public:
    // 解法一：递归传递上下界
    bool isValidBST(TreeNode* root) {
        return helper(root, LONG_MIN, LONG_MAX);
    }

private:
    bool helper(TreeNode* root, long lower, long upper) {
        if (root == nullptr) return true; // 空树/空子树天然合法
        if (root->val <= lower || root->val >= upper) {
            return false; // 超出祖先节点约束的合法区间
        }
        // 左子树上界收窄为当前节点值，右子树下界收窄为当前节点值
        return helper(root->left, lower, root->val) &&
               helper(root->right, root->val, upper);
    }

public:
    // 解法二：中序遍历，判断是否严格递增
    bool isValidBSTInorder(TreeNode* root) {
        TreeNode* pre = nullptr; // 记录中序遍历中上一个访问的节点
        return inorderCheck(root, pre);
    }

private:
    bool inorderCheck(TreeNode* root, TreeNode*& pre) {
        if (root == nullptr) return true;
        if (!inorderCheck(root->left, pre)) return false; // 先检查左子树
        if (pre != nullptr && pre->val >= root->val) {
            return false; // 当前节点不大于前一个节点，违反严格递增
        }
        pre = root; // 更新 pre 为当前节点
        return inorderCheck(root->right, pre); // 继续检查右子树
    }
};
```

### Python

```python
class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right


class Solution:
    def isValidBST(self, root: TreeNode) -> bool:
        # 解法一：递归传递上下界
        def helper(node: TreeNode, lower: float, upper: float) -> bool:
            if node is None:
                return True  # 空子树天然合法
            if node.val <= lower or node.val >= upper:
                return False  # 超出合法区间
            return helper(node.left, lower, node.val) and \
                   helper(node.right, node.val, upper)

        return helper(root, float("-inf"), float("inf"))

    def isValidBSTInorder(self, root: TreeNode) -> bool:
        # 解法二：中序遍历，判断是否严格递增
        self.pre = None  # 记录上一个访问的节点

        def inorder_check(node: TreeNode) -> bool:
            if node is None:
                return True
            if not inorder_check(node.left):
                return False  # 左子树已经不合法
            if self.pre is not None and self.pre.val >= node.val:
                return False  # 违反严格递增
            self.pre = node  # 更新 pre
            return inorder_check(node.right)

        return inorder_check(root)
```

## 总结

- 最容易踩的坑我再强调一下：只比较父子节点的大小关系是不够的，必须保证整个左子树都小于根节点、整个右子树都大于根节点，隔代的节点也得满足这个约束，不能漏。
- 解法一，也就是上下界传递，直接对应题目的定义，思路很直白；解法二，中序遍历判断严格递增，更优雅一些，是这道题公认的最佳解法，顺带还能帮你复习一下"BST 中序遍历结果是递增的"这个核心性质。
- 中序遍历判断递增的时候，有个边界情况你得注意，就是数值相等的问题——BST 的定义里左子树是严格小于、右子树是严格大于，所以中序遍历出来必须是严格递增，相等也要判成不合法。
- 上下界这种写法呢，要注意用能表示"负无穷/正无穷"的类型，比如 `long` 或者 `float('-inf')`，不然节点值刚好卡在 `int` 边界值上的时候，判断就会出错。
