# 0111. 二叉树的最小深度

**题目描述**

给定一个二叉树的根节点 `root`，返回其最小深度。最小深度是从根节点到**最近叶子节点**的最短路径上的节点数。

```
示例：
输入: root = [3,9,20,null,null,15,7]
      3
     / \
    9  20
      /  \
     15   7
输出: 2  （根到叶子节点9的路径长度为2）

容易踩坑的示例：
输入: root = [2,null,3,null,4,null,5,null,6]
      2
       \
        3
         \
          4
           \
            5
             \
              6
输出: 5  （因为根节点只有右子树，左子树为空但不是叶子，必须走到最深的6才是叶子节点）
```

## 思路

这题看起来像是"最大深度"的镜像问题，所以很多人会直接照搬最大深度的代码，把 `max` 换成 `min`，结果在某些用例上就翻车了。**问题出在哪呢？根源就在于"叶子节点"的定义**：叶子节点必须是左右孩子都为空的节点。如果你直接套用 `min(左子树高度, 右子树高度) + 1` 这个公式，当左子树为空、右子树不为空的时候，左子树高度是 0，就会导致 `min(0, 右子树高度) + 1` 直接算出 1——但这是错的，为什么呢？因为根节点本身不是叶子节点（它还有一个非空的右孩子呢），不能把它当成"深度为1的叶子路径"。

那正确的做法是什么呢？就是在递归里特判一下"当前节点只有一侧子树为空、另一侧不为空"这种情况：这种情况下当前节点不是叶子，不能直接返回较小的那个子树深度（很可能就是0），而必须返回非空那一侧子树的深度加1，因为这条路径必须继续往非空的那一侧走，一直走到真正找到叶子节点为止。

递归这里要分四种情况分别处理：

第一种，左右子树都为空：当前节点自己就是叶子，最小深度是 1。

第二种，左子树为空，右子树不为空：这时候不能走左边，因为无路可走，必须走右边，最小深度就等于右子树最小深度加 1。

第三种，右子树为空，左子树不为空：同理，最小深度等于左子树最小深度加 1。

第四种，左右子树都不为空：这是正常情况，最小深度就是 min(左子树最小深度, 右子树最小深度) 再加 1。

那这里我再跟你说一个更省心的办法——用层序遍历（BFS）来做反而更简单：从根节点开始一层一层往外扩展，**第一次遇到某个节点的左右孩子都为空**的时候（也就是第一次遇到真正的叶子节点），直接返回当前层数就行了，为什么这样可以呢？因为 BFS 保证了先遇到的叶子节点一定是深度最小的那个，根本不需要考虑上面递归里那些特判问题，思路上更干净。

那复杂度怎么样呢？递归法和 BFS 法最坏情况都是 O(n)（树退化成一条链，而且叶子在最底部），但 BFS 在很多情况下可以提前结束，不用把整棵树遍历完；空间复杂度递归是 O(h)，BFS 最坏是 O(n)。

## 代码

二叉树节点定义：

```cpp
struct TreeNode {
    int val;
    TreeNode *left;
    TreeNode *right;
    TreeNode(int x) : val(x), left(NULL), right(NULL) {}
};
```

### C++

```cpp
class Solution {
public:
    // 递归法：注意处理单侧子树为空的特殊情况
    int minDepth(TreeNode* root) {
        if (root == nullptr) return 0;                 // 终止条件：空树深度为0
        if (root->left == nullptr && root->right == nullptr) return 1; // 叶子节点，深度为1
        if (root->left == nullptr) return minDepth(root->right) + 1;   // 只有右子树，必须走右边
        if (root->right == nullptr) return minDepth(root->left) + 1;   // 只有左子树，必须走左边
        return min(minDepth(root->left), minDepth(root->right)) + 1;   // 左右都存在，取较小值
    }

    // BFS法：第一次遇到叶子节点就是最小深度
    int minDepthBFS(TreeNode* root) {
        if (root == nullptr) return 0;
        queue<TreeNode*> que;
        que.push(root);
        int depth = 0;
        while (!que.empty()) {
            int size = que.size();
            depth++;                             // 进入新的一层，深度加一
            for (int i = 0; i < size; i++) {
                TreeNode* node = que.front();
                que.pop();
                if (node->left == nullptr && node->right == nullptr) {
                    return depth;                 // 第一次遇到叶子节点，直接返回
                }
                if (node->left) que.push(node->left);
                if (node->right) que.push(node->right);
            }
        }
        return depth;
    }
};
```

```java
class Solution {
    // 递归法
    public int minDepth(TreeNode root) {
        if (root == null) return 0;                          // 终止条件
        if (root.left == null && root.right == null) return 1; // 叶子节点
        if (root.left == null) return minDepth(root.right) + 1; // 只有右子树
        if (root.right == null) return minDepth(root.left) + 1; // 只有左子树
        return Math.min(minDepth(root.left), minDepth(root.right)) + 1; // 都存在，取较小值
    }

    // BFS法
    public int minDepthBFS(TreeNode root) {
        if (root == null) return 0;
        Queue<TreeNode> queue = new LinkedList<>();
        queue.offer(root);
        int depth = 0;
        while (!queue.isEmpty()) {
            int size = queue.size();
            depth++;                                    // 进入新的一层
            for (int i = 0; i < size; i++) {
                TreeNode node = queue.poll();
                if (node.left == null && node.right == null) {
                    return depth;                        // 第一次遇到叶子节点
                }
                if (node.left != null) queue.offer(node.left);
                if (node.right != null) queue.offer(node.right);
            }
        }
        return depth;
    }
}
```

### Python

```python
class Solution:
    def minDepth(self, root):
        # 递归法
        if root is None:
            return 0                                # 终止条件
        if root.left is None and root.right is None:
            return 1                                # 叶子节点
        if root.left is None:
            return self.minDepth(root.right) + 1    # 只有右子树，必须走右边
        if root.right is None:
            return self.minDepth(root.left) + 1     # 只有左子树，必须走左边
        return min(self.minDepth(root.left), self.minDepth(root.right)) + 1  # 都存在，取较小值

    def minDepthBFS(self, root):
        # BFS法
        from collections import deque
        if root is None:
            return 0
        queue = deque([root])
        depth = 0
        while queue:
            size = len(queue)
            depth += 1                              # 进入新的一层
            for _ in range(size):
                node = queue.popleft()
                if node.left is None and node.right is None:
                    return depth                    # 第一次遇到叶子节点，直接返回
                if node.left:
                    queue.append(node.left)
                if node.right:
                    queue.append(node.right)
        return depth
```

### Go

```go
// 递归法
func minDepth(root *TreeNode) int {
    if root == nil {
        return 0 // 终止条件
    }
    if root.Left == nil && root.Right == nil {
        return 1 // 叶子节点
    }
    if root.Left == nil {
        return minDepth(root.Right) + 1 // 只有右子树
    }
    if root.Right == nil {
        return minDepth(root.Left) + 1 // 只有左子树
    }
    leftDepth := minDepth(root.Left)
    rightDepth := minDepth(root.Right)
    if leftDepth < rightDepth {
        return leftDepth + 1 // 都存在，取较小值
    }
    return rightDepth + 1
}

// BFS法
func minDepthBFS(root *TreeNode) int {
    if root == nil {
        return 0
    }
    queue := []*TreeNode{root}
    depth := 0
    for len(queue) > 0 {
        size := len(queue)
        depth++ // 进入新的一层
        for i := 0; i < size; i++ {
            node := queue[0]
            queue = queue[1:]
            if node.Left == nil && node.Right == nil {
                return depth // 第一次遇到叶子节点，直接返回
            }
            if node.Left != nil {
                queue = append(queue, node.Left)
            }
            if node.Right != nil {
                queue = append(queue, node.Right)
            }
        }
    }
    return depth
}
```

## 总结

- 最小深度不能简单地把最大深度代码里的 `max` 换成 `min`，因为"叶子节点"要求左右孩子都为空，单侧子树为空的时候不能把那一侧的 0 也拿去比较。
- 递归解法需要对"左空右不空""右空左不空""左右都不空""左右都空"这四种情况分别处理，漏掉中间那两种情况是最容易犯的错误。
- BFS 解法更省心：按层扩展，第一次遇到左右孩子都为空的节点，直接返回当前层数就是答案，完全不需要处理那些特判逻辑。
- 这道题算是理解"叶子节点定义"和"边界条件完整性"的经典题目，提醒你做题的时候一定要把题目定义反复确认清楚，不能想当然地照搬相似题目的模板。
