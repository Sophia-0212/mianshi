# 0222. 完全二叉树的节点个数

**题目描述**

给你一棵完全二叉树的根节点 `root`，求出该树的节点个数。

```
示例：
输入: root = [1,2,3,4,5,6]
       1
      / \
     2   3
    / \  /
   4  5 6
输出: 6
```

## 思路

- 完全树优化：比较根到最左、最右叶子的层数；相同则为满树，节点数 `2^h-1`；否则递归统计左右子树再加一。时间 O(log² n)，空间 O(log n)。
- 通用递归：空树为 0，否则返回左右节点数之和加一。时间 O(n)，完全树栈空间 O(log n)。

```python
class Solution:
    # 方法：countNodesGeneral；按题目要求处理输入并返回结果，核心算法见方法体。
    def countNodesGeneral(self, root):
        # 通用解法：O(n)
        if root is None:
            return 0
        left_count = self.countNodesGeneral(root.left)
        right_count = self.countNodesGeneral(root.right)
        return left_count + right_count + 1

    # 方法：countNodes；按题目要求处理输入并返回结果，核心算法见方法体。
    def countNodes(self, root):
        # 优化解法：O(log n * log n)
        if root is None:
            return 0
        left, right = root.left, root.right
        left_depth, right_depth = 0, 0
        while left:              # 一直往左走到底，统计深度
            left_depth += 1
            left = left.left
        while right:              # 一直往右走到底，统计深度
            right_depth += 1
            right = right.right
        if left_depth == right_depth:
            return (1 << (left_depth + 1)) - 1   # 满二叉树，公式计算
        return self.countNodes(root.left) + self.countNodes(root.right) + 1  # 递归处理
```

```cpp
class Solution {
public:
    // 通用解法：O(n) 后序遍历
    // 方法：countNodesGeneral；按题目要求处理输入并返回结果，核心算法见方法体。
    int countNodesGeneral(TreeNode* root) {
        if (root == nullptr) return 0;               // 终止条件
        int leftCount = countNodesGeneral(root->left);   // 左子树节点数
        int rightCount = countNodesGeneral(root->right); // 右子树节点数
        return leftCount + rightCount + 1;            // 加上自己
    }

    // 优化解法：利用完全二叉树性质，O(log n * log n)
    // 方法：countNodes；按题目要求处理输入并返回结果，核心算法见方法体。
    int countNodes(TreeNode* root) {
        if (root == nullptr) return 0;
        TreeNode* left = root->left;
        TreeNode* right = root->right;
        int leftDepth = 0, rightDepth = 0;
        while (left) { leftDepth++; left = left->left; }    // 一直往左走到底，统计深度
        while (right) { rightDepth++; right = right->right; } // 一直往右走到底，统计深度
        if (leftDepth == rightDepth) {
            // 左右深度相等，说明是满二叉树，直接用位运算公式 2^depth - 1
            return (1 << (leftDepth + 1)) - 1;
        }
        // 不是满二叉树，递归左右子树（其中必有一侧下一层判断会命中满二叉树分支）
        return countNodes(root->left) + countNodes(root->right) + 1;
    }
};
```

## 总结

- 通用解法就是用后序遍历，累加左右子树的节点数就行，能适用于任意二叉树，复杂度是 O(n)。
- 优化解法呢，利用的是完全二叉树"最左路径深度等于最右路径深度时，一定是满二叉树"这个性质，把满二叉树那部分直接用公式 `2^depth - 1` 算出来，不用再一个个节点去访问了。
- 优化解法的递归深度是 O(log n)，每一层还需要花 O(log n) 的时间去统计左右深度，所以总的复杂度是 O(log n × log n)，比通用解法快得多。
- 这道题的价值就在于，它展示了"通用算法 + 特殊结构性质 = 更优解法"这样一种思路，算是数据结构性质应用类题目里比较有代表性的一道。
