# 二叉树的递归遍历

**内容概述**

这篇讲二叉树前序、中序、后序遍历的递归实现。你会发现三种遍历的递归代码结构几乎一模一样，唯一的区别就是"访问当前节点"这一行代码放在递归调用左子树、右子树的前面、中间还是后面。理解了这一点，三种遍历就不需要死记硬背了，而是能自己推导出来。

节点定义（后续代码统一使用）：

## 思路

递归遍历：空节点返回；访问当前值与递归左右子树的顺序决定结果。

- 前序：根→左→右。
- 中序：左→根→右。
- 后序：左→右→根。

时间 O(n)，辅助空间 O(h)，结果空间 O(n)，h 为树高。

```python
class Solution:
    # 方法：preorder；按题目要求处理输入并返回结果，核心算法见方法体。
    def preorder(self, root, result):
        # 前序遍历：根 -> 左 -> 右
        if root is None:
            return  # 终止条件：空节点直接返回
        result.append(root.val)     # 先处理当前节点
        self.preorder(root.left, result)   # 再递归左子树
        self.preorder(root.right, result)  # 最后递归右子树

    # 方法：inorder；按题目要求处理输入并返回结果，核心算法见方法体。
    def inorder(self, root, result):
        # 中序遍历：左 -> 根 -> 右
        if root is None:
            return
        self.inorder(root.left, result)    # 先递归左子树
        result.append(root.val)     # 左子树处理完后处理当前节点
        self.inorder(root.right, result)   # 最后递归右子树

    # 方法：postorder；按题目要求处理输入并返回结果，核心算法见方法体。
    def postorder(self, root, result):
        # 后序遍历：左 -> 右 -> 根
        if root is None:
            return
        self.postorder(root.left, result)  # 先递归左子树
        self.postorder(root.right, result) # 再递归右子树
        result.append(root.val)     # 左右都处理完才处理当前节点
```

```go
// 方法：preorder；按题目要求处理输入并返回结果，核心算法见方法体。
func preorder(root *TreeNode, result *[]int) {
    if root == nil {
        return // 终止条件：空节点直接返回

    inorder(root.Right, result)         // 最后递归右子树
```

```cpp
class Solution {
public:
    // 前序遍历：根 -> 左 -> 右
    // 方法：preorder；按题目要求处理输入并返回结果，核心算法见方法体。
    void preorder(TreeNode* root, vector<int>& result) {
        if (root == nullptr) return;   // 终止条件：空节点直接返回
        result.push_back(root->val);   // 先处理当前节点（根）
        preorder(root->left, result);  // 再递归处理左子树
        preorder(root->right, result); // 最后递归处理右子树
    }

    // 中序遍历：左 -> 根 -> 右
    // 方法：inorder；按题目要求处理输入并返回结果，核心算法见方法体。
    void inorder(TreeNode* root, vector<int>& result) {
        if (root == nullptr) return;
        inorder(root->left, result);   // 先递归处理左子树
        result.push_back(root->val);   // 左子树处理完后处理当前节点
        inorder(root->right, result);  // 最后递归处理右子树
    }

    // 后序遍历：左 -> 右 -> 根
    // 方法：postorder；按题目要求处理输入并返回结果，核心算法见方法体。
    void postorder(TreeNode* root, vector<int>& result) {
        if (root == nullptr) return;
        postorder(root->left, result);  // 先递归处理左子树
        postorder(root->right, result); // 再递归处理右子树
        result.push_back(root->val);    // 左右子树都处理完后才处理当前节点
    }
```

        postorder(root->left, result);  // 先递归处理左子树
        postorder(root->right, result); // 再递归处理右子树
        result.push_back(root->val);    // 左右子树都处理完后才处理当前节点
    }

}

int main() {
    // 用例 1：输入 ({'tree': [1, None, 2, 3]}, [])；期望 [1, 3, 2]。
    {
        auto* arg0 = buildTreeInput({1, nullopt, 2, 3});
        vector<int> arg1 = {};
        interview::inorder(arg0, arg1);
        cout << "用例 1: 期望=[1, 3, 2] 实际=";
        show(arg1);
        cout << "\n";
    }
    // 用例 2：输入 ({'tree': [1]}, [])；期望 [1]。
    {
        auto* arg0 = buildTreeInput({1});
        vector<int> arg1 = {};
        interview::inorder(arg0, arg1);
        cout << "用例 2: 期望=[1] 实际=";
        show(arg1);
        cout << "\n";
    }
    // 用例 3：输入 ({'tree': []}, [])；期望 []。
    {
        auto* arg0 = buildTreeInput({});
        vector<int> arg1 = {};
        interview::inorder(arg0, arg1);
        cout << "用例 3: 期望=[] 实际=";

    }
    return 0;
}```

## 总结

- 二叉树递归遍历的三要素：参数与返回值、终止条件（节点为空）、单层递归逻辑（也就是处理当前节点插入的位置）。
- 前中后序遍历的代码结构完全相同，唯一的区别就是"处理当前节点"这一行代码相对于两次递归调用的位置。
- 递归的时间复杂度是 O(n)，空间复杂度取决于递归调用栈的深度，也就是树的高度 O(h)，最坏情况会退化成 O(n)。
- 理解递归遍历是后面理解迭代遍历（用栈显式模拟）和统一迭代法的基础，说白了迭代版本本质上就是把递归调用栈的行为手动搬到一个显式的栈里去。
