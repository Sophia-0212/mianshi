# 0112. 路径总和

**题目描述**

给你二叉树的根节点 `root` 和一个表示目标和的整数 `targetSum`，判断该树中是否存在**根节点到叶子节点**的路径，这条路径上所有节点值相加等于 `targetSum`。存在则返回 `true`，否则返回 `false`。

```
示例：
输入: root = [5,4,8,11,null,13,4,7,2,null,null,null,1], targetSum = 22
       5
      / \
     4   8
    /   / \
   11  13  4
  /  \      \
 7    2      1
输出: true
解释: 存在路径 5->4->11->2，和为22
```

## 思路

DFS 沿路径传递剩余目标值，每到一个节点减去其值；到叶子时剩余值为 0 即成功。也可累加路径和，到叶子时与目标比较。

时间 O(n)，空间 O(h)，h 为树高。

### LeetCode 写法与原有示例

```python
class Solution:
    # 方法：hasPathSum；按题目要求处理输入并返回结果，核心算法见方法体。
    def hasPathSum(self, root, targetSum):
        if root is None:
            return False                 # 空树不存在任何路径
        return self.traverse(root, targetSum)

    # 方法：traverse；按题目要求处理输入并返回结果，核心算法见方法体。
    def traverse(self, node, remain):
        # remain 用值传递（Python整数不可变，天然实现隐式回溯）
        if node is None:
            return False                 # 空节点不构成有效路径
        remain -= node.val               # 抵消剩余目标值
        if node.left is None and node.right is None:
            return remain == 0           # 叶子节点，判断是否恰好凑够
        return self.traverse(node.left, remain) or self.traverse(node.right, remain)  # 任一子树满足即可
```

```go
// remain 用值传递（Go中int是值类型），实现隐式回溯
// 方法：traverse；按题目要求处理输入并返回结果，核心算法见方法体。

        return false // 空节点不构成有效路径
    }
    remain -= node.Val // 抵消剩余目标值
    if node.Left == nil && node.Right == nil {
        return remain == 0 // 叶子节点，判断是否恰好凑够
    }
    // 任一子树满足即可
    return traverse(node.Left, remain) || traverse(node.Right, remain)
}
```

```cpp
class Solution {
public:
    // remain 表示还需要凑够多少值才能达到目标，用值传递天然实现隐式回溯
    // 方法：traverse；按题目要求处理输入并返回结果，核心算法见方法体。
    bool traverse(TreeNode* node, int remain) {
        if (node == nullptr) return false;         // 空节点不构成有效路径
        remain -= node->val;                       // 用当前节点值抵消剩余目标值
        if (node->left == nullptr && node->right == nullptr) {
            // 到达叶子节点，判断是否恰好凑够目标值
            return remain == 0;
        }
        // 只要左子树或右子树中有一条路径满足条件即可
        return traverse(node->left, remain) || traverse(node->right, remain);
    }

    // 方法：hasPathSum；按题目要求处理输入并返回结果，核心算法见方法体。
    bool hasPathSum(TreeNode* root, int targetSum) {
        if (root == nullptr) return false;  // 空树不存在任何路径
        return traverse(root, targetSum);
    }
};
```

## 总结

- 用"剩余目标值不断减去当前节点值，到叶子节点判断是不是恰好为0"这种写法，比维护"当前路径和再跟目标比较"更简洁，这两种逻辑是等价的。
- `remain` 这个参数以值传递的方式在递归中往下传，天然就实现了回溯，不需要手动去撤销状态，这是"隐式回溯"在实际题目里的一个具体应用，正好呼应了本系列里专门讲回溯思想的那篇方法论文档。
- 判断是不是存在满足条件的路径，只需要左子树或者右子树里**任意一条**满足就行，用逻辑或连接两次递归结果，不需要把两侧都探索完再去决策。
- 这道题跟 0257 题（收集所有路径）的区别在于：0257 要收集所有的路径，这道题只需要判断"是否存在"一条路径就够了，所以不需要显式维护一个路径列表，只需要维护一个数值即可，是同一类问题在不同要求下的简化版本。
