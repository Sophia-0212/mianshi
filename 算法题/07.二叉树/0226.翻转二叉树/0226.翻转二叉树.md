# 0226. 翻转二叉树

**题目描述**

给你一棵二叉树的根节点 `root`，翻转这棵二叉树，并返回其根节点（即每个节点的左右子树互换）。

```
示例：
输入: root = [4,2,7,1,3,6,9]
输出: [4,7,2,9,6,3,1]

     4                4
    / \              / \
   2   7    -->     7   2
  / \  / \          / \ / \
 1  3 6   9        9  6 3  1
```

## 思路

翻转二叉树这个操作说白了本质很简单：**对每一个节点，把它的左右孩子交换一下**。你只要把树里每个节点都做一次这样的交换，整棵树自然就翻转完成了，所以这道题的核心就变成了"怎么去遍历整棵树，并且在遍历的过程中对每个节点做一次交换"。

那这里天然就适合用递归也就是 DFS 来解决：递归函数负责的事情是"翻转以某个节点为根的这棵子树"，单层递归的逻辑就是先交换当前节点的左右孩子，然后再递归去处理交换之后的左子树和右子树——这里递归调用哪个子树先都没关系，因为已经交换过了，两个子树最终都会被处理到。

**这里遍历顺序的选择是个关键点，我来说说三种情况**：

- 前序遍历，也就是先交换根节点，再递归左右子树，这个是可行的，因为交换这个动作只依赖当前节点自身的左右指针，跟子树内部是不是已经翻转完成没关系。
- 后序遍历，先把左右子树各自递归处理完，再交换根节点，这个也是可行的，逻辑就是先把两个子树分别翻转好，再把它们换个位置挂到根节点上。
- 中序遍历呢？**这个是不行的**。为什么呢？你想啊，中序遍历的顺序是"左、根、右"，如果先递归左子树，然后交换根节点的左右孩子，这时候右子树还没被处理过，等处理完根节点之后再去递归"新的右子树"——但问题是，这个"新的右子树"其实就是原来的左子树（已经被处理过一次了），这就导致左子树被翻转了两次，相当于没翻转，而原来那个真正的右子树反而完全没被处理到。这是这道题一个很经典的踩坑点，面试的时候经常会被问到。

除了递归，其实也可以用迭代法来写，也就是前序遍历的迭代写法，用栈或者队列都行，只要保证是"每访问到一个节点就交换它的左右孩子"这个原则，遍历顺序其实不影响正确性，唯独中序遍历不行。

时间复杂度是 O(n)，因为每个节点都会被访问一次，并且执行一次常数时间的交换；空间复杂度是 O(h)，也就是递归调用栈的深度，等于树的高度。

## 代码

二叉树节点定义：

```cpp
struct TreeNode {
    int val;
    TreeNode *left;
    TreeNode *right;
    TreeNode(int x) : val(x), left(NULL), right(NULL) {}
};
```

```python
class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right
```

### C++

```cpp
class Solution {
public:
    // 递归法（前序遍历：先交换，再递归左右子树）
    TreeNode* invertTree(TreeNode* root) {
        if (root == nullptr) return root;  // 终止条件：空节点无需处理
        swap(root->left, root->right);     // 交换当前节点的左右孩子
        invertTree(root->left);            // 递归处理新的左子树（原右子树）
        invertTree(root->right);           // 递归处理新的右子树（原左子树）
        return root;
    }

    // 迭代法（用栈模拟前序遍历，遇到节点就交换左右孩子）
    TreeNode* invertTreeIterative(TreeNode* root) {
        if (root == nullptr) return root;
        stack<TreeNode*> st;
        st.push(root);
        while (!st.empty()) {
            TreeNode* node = st.top();
            st.pop();
            swap(node->left, node->right);       // 访问即交换
            if (node->left) st.push(node->left);   // 交换后的左孩子（原右孩子）入栈
            if (node->right) st.push(node->right); // 交换后的右孩子（原左孩子）入栈
        }
        return root;
    }
};
```

### Java

```java
class Solution {
    // 递归法
    public TreeNode invertTree(TreeNode root) {
        if (root == null) return root;    // 终止条件
        TreeNode temp = root.left;        // 交换左右孩子
        root.left = root.right;
        root.right = temp;
        invertTree(root.left);            // 递归处理新的左子树
        invertTree(root.right);           // 递归处理新的右子树
        return root;
    }

    // 迭代法（栈模拟前序遍历）
    public TreeNode invertTreeIterative(TreeNode root) {
        if (root == null) return root;
        Deque<TreeNode> stack = new ArrayDeque<>();
        stack.push(root);
        while (!stack.isEmpty()) {
            TreeNode node = stack.pop();
            TreeNode temp = node.left;     // 访问即交换
            node.left = node.right;
            node.right = temp;
            if (node.left != null) stack.push(node.left);
            if (node.right != null) stack.push(node.right);
        }
        return root;
    }
}
```

### Python

```python
class Solution:
    def invertTree(self, root):
        # 递归法
        if root is None:
            return root                     # 终止条件
        root.left, root.right = root.right, root.left  # 交换左右孩子
        self.invertTree(root.left)          # 递归处理新的左子树
        self.invertTree(root.right)         # 递归处理新的右子树
        return root

    def invertTreeIterative(self, root):
        # 迭代法（栈模拟前序遍历）
        if root is None:
            return root
        stack = [root]
        while stack:
            node = stack.pop()
            node.left, node.right = node.right, node.left  # 访问即交换
            if node.left:
                stack.append(node.left)
            if node.right:
                stack.append(node.right)
        return root
```

### Go

```go
// 递归法
func invertTree(root *TreeNode) *TreeNode {
    if root == nil {
        return root // 终止条件
    }
    root.Left, root.Right = root.Right, root.Left // 交换左右孩子
    invertTree(root.Left)                          // 递归处理新的左子树
    invertTree(root.Right)                         // 递归处理新的右子树
    return root
}

// 迭代法（栈模拟前序遍历）
func invertTreeIterative(root *TreeNode) *TreeNode {
    if root == nil {
        return root
    }
    stack := []*TreeNode{root}
    for len(stack) > 0 {
        node := stack[len(stack)-1]
        stack = stack[:len(stack)-1]
        node.Left, node.Right = node.Right, node.Left // 访问即交换
        if node.Left != nil {
            stack = append(stack, node.Left)
        }
        if node.Right != nil {
            stack = append(stack, node.Right)
        }
    }
    return root
}
```

## 总结

- 翻转二叉树的本质就是对每个节点执行一次"交换左右孩子"的操作，任何能遍历到每个节点的方式都能完成这个任务。
- 前序、后序遍历都能正确翻转，唯独中序遍历不行——因为中序遍历在处理完根节点之后，会把已经处理过的子树当成新的子树再递归一次，这样一来就会导致重复翻转和漏翻转。
- 递归和迭代（用栈模拟）在本质上是等价的，选哪种写法主要看个人习惯，或者面试官有没有特别要求。
- 这道题是理解"遍历顺序会怎么影响算法正确性"的一个很好的例子，以后遇到需要修改树结构的题目，都要先想清楚该用哪种遍历顺序才不会产生副作用上的冲突。
