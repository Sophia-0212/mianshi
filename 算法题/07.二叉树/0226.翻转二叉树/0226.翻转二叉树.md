# 0226. 翻转二叉树

**题目描述**

给你一棵二叉树的根节点 `root`，翻转这棵二叉树，并返回其根节点（即每个节点的左右子树互换）。

```
示例：
输入: root = [4,2,7,1,3,6,9]
输出: [4,7,2,9,6,3,1]

     4                4
    / \              / \
   2   7    -->     7   2
  / \  / \          / \ / \
 1  3 6   9        9  6 3  1
```

## 思路

遍历每个节点并交换左右孩子。可用递归 DFS、显式栈或队列，确保每个节点只交换一次。

时间 O(n)；递归或 DFS 栈空间 O(h)，BFS 队列空间 O(w)。h 为树高，w 为最大层宽。

### LeetCode 写法与原有示例

```python
class Solution:
    # 方法：invertTree；按题目要求处理输入并返回结果，核心算法见方法体。
    def invertTree(self, root):
        # 递归法
        if root is None:
            return root                     # 终止条件
        root.left, root.right = root.right, root.left  # 交换左右孩子
        self.invertTree(root.left)          # 递归处理新的左子树
        self.invertTree(root.right)         # 递归处理新的右子树
        return root

    # 方法：invertTreeIterative；按题目要求处理输入并返回结果，核心算法见方法体。
    def invertTreeIterative(self, root):
        # 迭代法（栈模拟前序遍历）
        if root is None:
            return root
        stack = [root]
        while stack:
            node = stack.pop()
            node.left, node.right = node.right, node.left  # 访问即交换
            if node.left:
                stack.append(node.left)
            if node.right:
                stack.append(node.right)
        return root
```

def build_tree(values):
    """按层序构造树，None 表示空节点。"""
    if not values or values[0] is None:
        return None
    root = TreeNode(values[0])
    queue = deque([root])
    i = 1
    while queue and i < len(values):
        parent = queue.popleft()
        for side in ('left', 'right'):
            if i < len(values) and values[i] is not None:
                child = TreeNode(values[i])
                setattr(parent, side, child)
                queue.append(child)
            i += 1
    return root

        result.append(node.val if node else None)
        if node:
            queue.extend([node.left, node.right])

        result.pop()
    return result

func invertTree(root *TreeNode) *TreeNode {
    if root == nil {
        return root // 终止条件
    }
    root.Left, root.Right = root.Right, root.Left // 交换左右孩子
    invertTree(root.Left)                          // 递归处理新的左子树
    invertTree(root.Right)                         // 递归处理新的右子树
    return root
}

// 迭代法（栈模拟前序遍历）
// 方法：invertTreeIterative；按题目要求处理输入并返回结果，核心算法见方法体。
func invertTreeIterative(root *TreeNode) *TreeNode {
    if root == nil {
        return root
    }
    stack := []*TreeNode{root}
    for len(stack) > 0 {
        node := stack[len(stack)-1]
        stack = stack[:len(stack)-1]
        node.Left, node.Right = node.Right, node.Left // 访问即交换
        if node.Left != nil {
            stack = append(stack, node.Left)
        }
        if node.Right != nil {
            stack = append(stack, node.Right)
        }
    }
    return root
}

```cpp
// 依赖说明：stack：C++ STL 栈容器。

class Solution {
public:
    // 递归法（前序遍历：先交换，再递归左右子树）
    TreeNode* invertTree(TreeNode* root) {
        if (root == nullptr) return root;  // 终止条件：空节点无需处理
        swap(root->left, root->right);     // 交换当前节点的左右孩子
        invertTree(root->left);            // 递归处理新的左子树（原右子树）
        invertTree(root->right);           // 递归处理新的右子树（原左子树）
        return root;
    }

    // 迭代法（用栈模拟前序遍历，遇到节点就交换左右孩子）
    TreeNode* invertTreeIterative(TreeNode* root) {
        if (root == nullptr) return root;
        stack<TreeNode*> st;
        st.push(root);
        while (!st.empty()) {
            TreeNode* node = st.top();
            st.pop();
            swap(node->left, node->right);       // 访问即交换
            if (node->left) st.push(node->left);   // 交换后的左孩子（原右孩子）入栈
            if (node->right) st.push(node->right); // 交换后的右孩子（原左孩子）入栈
        }
        return root;
    }
};```

## 总结

- 翻转二叉树的本质就是对每个节点执行一次"交换左右孩子"的操作，任何能遍历到每个节点的方式都能完成这个任务。
- 前序、后序遍历都能正确翻转，唯独中序遍历不行——因为中序遍历在处理完根节点之后，会把已经处理过的子树当成新的子树再递归一次，这样一来就会导致重复翻转和漏翻转。
- 递归和迭代（用栈模拟）在本质上是等价的，选哪种写法主要看个人习惯，或者面试官有没有特别要求。
- 这道题是理解"遍历顺序会怎么影响算法正确性"的一个很好的例子，以后遇到需要修改树结构的题目，都要先想清楚该用哪种遍历顺序才不会产生副作用上的冲突。
