# 0669. 修剪二叉搜索树

**题目描述**

给定二叉搜索树（BST）的根节点 `root`，以及最小边界 `low` 和最大边界 `high`，通过修剪 BST，使得所有节点的值都在 `[low, high]` 区间内。修剪树**不应该改变保留在树中的元素的相对结构**（即如果没有被移除，原有的父子关系应当保留）。返回修剪后 BST 的根节点。

```
示例：
输入: root = [3,0,4,null,2,null,null,1], low = 1, high = 3
输出: [3,2,null,1]
解释: 值为 0 和 4 的节点超出了 [1,3] 区间，需要被移除，同时保留剩余节点原有的相对结构。
```

## 思路

BST 递归剪枝：当前值小于 `low`，返回修剪后的右子树；大于 `high`，返回修剪后的左子树；范围内则修剪并接回左右孩子。

时间 O(n)，空间 O(h)，h 为树高。

```python
class TreeNode:
    # 方法：__init__；按题目要求处理输入并返回结果，核心算法见方法体。
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right


class Solution:
    # 方法：trimBST；按题目要求处理输入并返回结果，核心算法见方法体。
    def trimBST(self, root: TreeNode, low: int, high: int) -> TreeNode:
        if root is None:
            return None  # 终止条件

        if root.val < low:
            # 当前节点和整个左子树都小于 low，丢弃，只保留右子树修剪结果
            return self.trimBST(root.right, low, high)
        if root.val > high:
            # 当前节点和整个右子树都大于 high，丢弃，只保留左子树修剪结果
            return self.trimBST(root.left, low, high)

        # 当前节点在合法区间内，分别修剪左右子树并接回
        root.left = self.trimBST(root.left, low, high)
        root.right = self.trimBST(root.right, low, high)
        return root
```

```go
    Right *TreeNode

// 方法：trimBST；按题目要求处理输入并返回结果，核心算法见方法体。
func trimBST(root *TreeNode, low, high int) *TreeNode {
    if root == nil {
        return nil // 终止条件
    }
    if root.Val < low {
        return trimBST(root.Right, low, high) // 丢弃当前节点和左子树
    }
    if root.Val > high {
        return trimBST(root.Left, low, high) // 丢弃当前节点和右子树
    }
    root.Left = trimBST(root.Left, low, high)   // 在区间内，修剪左子树
    root.Right = trimBST(root.Right, low, high) // 修剪右子树
    return root
}
```

## 总结

- 修剪 BST 的关键是利用有序性去判断"哪一整片子树必然全部超出边界"：值小于 `low` 的时候左子树整体作废，值大于 `high` 的时候右子树整体作废，不用逐一去检查子树内每个节点是否越界。
- 当前节点不合法的时候，直接返回"另一侧子树递归修剪后的结果"，这一步就完成了"跳过不合法节点、把它的子树直接接到上一层"这个操作，保证剩下的节点之间的相对结构（也就是祖先-后代关系）不被破坏。
- 和 0701、0450 一样，这里沿用的是"递归返回值重新赋值给子节点指针"这套模式，这是二叉树结构性修改类题目的通用写法。
- 虽然有些不合法的子树会被整体"跳过判断细节"，但递归调用还是会深入这些子树内部去找可能存在的合法节点，所以整体时间复杂度依然是 O(n)，不要误以为是 O(h)。
