# 0669. 修剪二叉搜索树

**题目描述**

给定二叉搜索树（BST）的根节点 `root`，以及最小边界 `low` 和最大边界 `high`，通过修剪 BST，使得所有节点的值都在 `[low, high]` 区间内。修剪树**不应该改变保留在树中的元素的相对结构**（即如果没有被移除，原有的父子关系应当保留）。返回修剪后 BST 的根节点。

```
示例：
输入: root = [3,0,4,null,2,null,null,1], low = 1, high = 3
输出: [3,2,null,1]
解释: 值为 0 和 4 的节点超出了 [1,3] 区间，需要被移除，同时保留剩余节点原有的相对结构。
```

## 思路

这道题跟 0450（删除 BST 节点）其实是一类的，都是"修改 BST 结构"的问题，不过修剪操作要简单一些，因为它能充分利用 BST 的有序性去判断"哪一整片子树可以直接丢掉"，不用像删除单个节点那样去处理复杂的"用谁顶替"的问题。

这里的关键是什么呢？**如果当前节点的值小于 `low`，那你想啊，根据 BST 的性质，它整个左子树的值肯定都比它还小，那必然也都小于 `low`，所以左子树可以整体丢弃，不用再去检查了**；同时，当前节点自己也不满足要求，得被移除，但它的右子树里说不定还有满足 `[low, high]` 的节点，所以得继续递归处理右子树，而且**要用右子树修剪完的结果直接顶替当前节点的位置**。

反过来也是一样的道理，**如果当前节点的值大于 `high`，那它整个右子树都比它还大，肯定也都大于 `high`，右子树就可以整体丢弃**，这时候要递归处理左子树，并用左子树修剪后的结果去顶替当前节点的位置。

那如果当前节点的值恰好落在 `[low, high]` 区间内呢？说明这个节点本身是要保留的，这时候只需要分别递归修剪它的左子树和右子树，把修剪后的结果重新接到 `root->left` 和 `root->right` 上就行了。

把这三种情况写成递归，大概是这样：

- **终止条件**：当前节点为空，直接返回 `null`。
- **单层递归逻辑**：
  - 若 `root->val < low`：直接返回 `trim(root->right, low, high)`，也就是丢弃当前节点和整个左子树，只留右子树修剪后的结果。
  - 若 `root->val > high`：直接返回 `trim(root->left, low, high)`，丢弃当前节点和整个右子树，只留左子树修剪后的结果。
  - 否则，也就是在区间内：`root->left = trim(root->left, low, high)`，`root->right = trim(root->right, low, high)`，然后返回 `root`。

**这里最容易出错的地方，就是返回值怎么正确对接**。当 `root->val < low` 的时候，直接返回 `trim(root->right, ...)` 的结果，这个返回值会被上一层递归赋值给某个指针（比如 `root->left = trim(root->left, ...)`），这意味着什么呢？意味着"当前这个不合法的节点被跳过了，它的右子树直接和上一层连接"——这正好就是题目要求的"不改变保留节点的相对结构"：虽然中间跳过了一个不合法节点，但合法节点之间原有的祖先-后代关系并没有被破坏，只是路径上那个不合法的节点被"摘除"掉了。

再说说复杂度。每个节点最多被访问一次——即使是被丢弃的子树，也只需要一次比较就整体跳过，不用逐一去访问它内部的每个节点，因为返回的是"递归修剪右子树/左子树"这个动作，而不是直接遍历整棵子树。不过这里要注意，"丢弃"指的是不需要单独去判断子树内每个节点是否要删除，但递归调用本身还是会进入这个子树内部继续判断，所以严格来说时间复杂度依然是 O(n)，n 是原树的节点数。空间复杂度是 O(h)，这个是递归调用栈的开销。

## 代码

二叉树节点定义：

```cpp
struct TreeNode {
    int val;
    TreeNode *left;
    TreeNode *right;
    TreeNode(int x) : val(x), left(NULL), right(NULL) {}
};
```

### C++

```cpp
class Solution {
public:
    TreeNode* trimBST(TreeNode* root, int low, int high) {
        if (root == nullptr) {
            return nullptr; // 终止条件：空节点
        }
        if (root->val < low) {
            // 当前节点及其左子树全部小于 low，整体丢弃，只保留右子树修剪结果
            return trimBST(root->right, low, high);
        }
        if (root->val > high) {
            // 当前节点及其右子树全部大于 high，整体丢弃，只保留左子树修剪结果
            return trimBST(root->left, low, high);
        }
        // 当前节点在合法区间内，分别修剪左右子树并接回
        root->left = trimBST(root->left, low, high);
        root->right = trimBST(root->right, low, high);
        return root;
    }
};
```

### Java

```java
class Solution {
    public TreeNode trimBST(TreeNode root, int low, int high) {
        if (root == null) {
            return null; // 终止条件
        }
        if (root.val < low) {
            return trimBST(root.right, low, high); // 丢弃当前节点和左子树
        }
        if (root.val > high) {
            return trimBST(root.left, low, high); // 丢弃当前节点和右子树
        }
        root.left = trimBST(root.left, low, high);   // 在区间内，修剪左子树
        root.right = trimBST(root.right, low, high); // 修剪右子树
        return root;
    }
}
```

class TreeNode:

        self.left = left
        self.right = right

    def trimBST(self, root: TreeNode, low: int, high: int) -> TreeNode:

            return self.trimBST(root.left, low, high)

        root.left = self.trimBST(root.left, low, high)

### Go

```go

    Right *TreeNode

func trimBST(root *TreeNode, low, high int) *TreeNode {
    if root == nil {
        return nil // 终止条件
    }
    if root.Val < low {

```

## 总结

- 修剪 BST 的关键是利用有序性去判断"哪一整片子树必然全部超出边界"：值小于 `low` 的时候左子树整体作废，值大于 `high` 的时候右子树整体作废，不用逐一去检查子树内每个节点是否越界。
- 当前节点不合法的时候，直接返回"另一侧子树递归修剪后的结果"，这一步就完成了"跳过不合法节点、把它的子树直接接到上一层"这个操作，保证剩下的节点之间的相对结构（也就是祖先-后代关系）不被破坏。
- 和 0701、0450 一样，这里沿用的是"递归返回值重新赋值给子节点指针"这套模式，这是二叉树结构性修改类题目的通用写法。
- 虽然有些不合法的子树会被整体"跳过判断细节"，但递归调用还是会深入这些子树内部去找可能存在的合法节点，所以整体时间复杂度依然是 O(n)，不要误以为是 O(h)。
