# 0235. 二叉搜索树的最近公共祖先

**题目描述**

给定一个二叉搜索树（BST），找到该树中两个指定节点 `p` 和 `q` 的最近公共祖先（LCA）。

```
示例：
输入: root = [6,2,8,0,4,7,9,null,null,3,5], p = 2, q = 8
输出: 6
解释: 节点 2 和节点 8 的最近公共祖先是根节点 6。
```

## 思路

利用 BST 有序性：两目标均小于当前值则向左，均大于则向右；否则当前节点即最近公共祖先，包括当前节点等于某个目标的情况。

时间 O(h)；递归空间 O(h)，迭代空间 O(1)，h 为树高。

```python
class TreeNode:
    # 方法：__init__；按题目要求处理输入并返回结果，核心算法见方法体。
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right


class Solution:
    # 方法：lowestCommonAncestor；按题目要求处理输入并返回结果，核心算法见方法体。
    def lowestCommonAncestor(self, root: TreeNode, p: TreeNode, q: TreeNode) -> TreeNode:
        # 递归写法
        if p.val < root.val and q.val < root.val:
            return self.lowestCommonAncestor(root.left, p, q)  # 都比当前节点小，往左走
        if p.val > root.val and q.val > root.val:
            return self.lowestCommonAncestor(root.right, p, q)  # 都比当前节点大，往右走
        return root  # 分岔点，即为答案

    # 方法：lowestCommonAncestorIterative；按题目要求处理输入并返回结果，核心算法见方法体。
    def lowestCommonAncestorIterative(self, root: TreeNode, p: TreeNode, q: TreeNode) -> TreeNode:
        # 迭代写法
        node = root
        while node is not None:
            if p.val < node.val and q.val < node.val:
                node = node.left
            elif p.val > node.val and q.val > node.val:
                node = node.right
            else:
                return node  # 分岔点
        return None
```

```cpp
class Solution {
public:
    // 递归写法
    TreeNode* lowestCommonAncestor(TreeNode* root, TreeNode* p, TreeNode* q) {
        if (p->val < root->val && q->val < root->val) {
            return lowestCommonAncestor(root->left, p, q);  // 都比当前节点小，往左走
        }
        if (p->val > root->val && q->val > root->val) {
            return lowestCommonAncestor(root->right, p, q); // 都比当前节点大，往右走
        }
        return root; // 分岔点（或其中一个等于当前节点），当前节点即为答案
    }

    // 迭代写法：不需要递归栈
    TreeNode* lowestCommonAncestorIterative(TreeNode* root, TreeNode* p, TreeNode* q) {
        TreeNode* node = root;
        while (node != nullptr) {
            if (p->val < node->val && q->val < node->val) {
                node = node->left; // 都比当前节点小，往左走
            } else if (p->val > node->val && q->val > node->val) {
                node = node->right; // 都比当前节点大，往右走
            } else {
                return node; // 分岔点，即为答案
            }
        }
        return nullptr;
    }
};
```

```cpp
        auto result = interview::lowestCommonAncestor(arg0, arg1, arg2);
        cout << "用例 2: 期望=2 实际=";
        show((result ? optional<int>(result->val) : nullopt));
        cout << "\n";
    }
    // 用例 3：输入 ({'tree': [2, 1]}, {'ref': 2}, {'ref': 1})；期望 2。
    {
        auto* arg0 = buildTreeInput({2, 1});
        auto* arg1 = findNode(arg0, 2);
        auto* arg2 = findNode(arg0, 1);
        auto result = interview::lowestCommonAncestor(arg0, arg1, arg2);
        cout << "用例 3: 期望=2 实际=";
        show((result ? optional<int>(result->val) : nullopt));
        cout << "\n";
    }
    return 0;
}
```

## 总结

- 跟 0236 那种普通二叉树的解法比起来，BST 解法不需要用后序遍历去回溯，只要根据 `p`、`q` 的值和当前节点值的大小关系，就能直接判断该往哪走，这也是利用有序性做剪枝的又一次体现。
- 当 `p`、`q` 分别落在当前节点两侧的时候（或者其中一个正好等于当前节点），说明路径在这里分岔了，当前节点就是最近公共祖先，这个判断逻辑比 0236 要简单直接得多。
- 因为只需要沿着一条路径走到分岔点就行，所以时间复杂度是 O(h) 而不是 O(n)，比普通二叉树的解法效率更高，因为不用去访问那些不相关的子树。
- 这道题特别适合用迭代来实现，因为不需要回溯，空间复杂度可以做到 O(1)，这一点又进一步体现出了 BST 解法相对于普通二叉树解法的优势。
