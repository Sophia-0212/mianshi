# 0235. 二叉搜索树的最近公共祖先

**题目描述**

给定一个二叉搜索树（BST），找到该树中两个指定节点 `p` 和 `q` 的最近公共祖先（LCA）。

```
示例：
输入: root = [6,2,8,0,4,7,9,null,null,3,5], p = 2, q = 8
输出: 6
解释: 节点 2 和节点 8 的最近公共祖先是根节点 6。
```

## 思路

这道题其实是 0236（普通二叉树的最近公共祖先）的一个变体，但因为多了一个"这是 BST"的条件，解法就能简化很多。

先回顾一下 0236 是怎么做的：因为普通二叉树没有任何顺序信息，所以必须递归去探测左右两个子树，通过"左右子树是不是都找到了目标"来判断当前节点是不是最近公共祖先，整个过程需要遍历到可能涉及的所有节点，用后序遍历那种回溯的方式来处理。

那 BST 呢？它的有序性（左子树全部小于根节点，右子树全部大于根节点）就给了我们一个更直接的判断方式：**根本不需要真的去"查找" `p` 和 `q` 具体在哪，只要根据它们的值和当前节点值的大小关系，就能直接判断该往左走还是往右走，或者说当前节点本身就是答案**。

具体怎么判断呢？从根节点开始，设当前节点为 `node`：

- 如果 `p->val < node->val` 而且 `q->val < node->val`，这说明什么？说明 `p` 和 `q` 都比当前节点小，根据 BST 的性质，它们俩肯定都在左子树里，那最近公共祖先也必然在左子树中，直接递归 `node->left` 就行，右子树根本不用管。
- 如果反过来，`p->val > node->val` 而且 `q->val > node->val`，道理是一样的，说明两者都在右子树里，直接递归 `node->right`。
- 那还有一种情况呢，就是既不满足都小于、也不满足都大于（比方说一个 `<=`、一个 `>=`，或者两者中有一个正好等于 `node->val`），这说明什么？说明 `p` 和 `q` 分别落在了当前节点的两侧，或者其中一个就是当前节点本身，这就意味着从当前节点开始，`p` 和 `q` 的路径要在这里分岔了（或者其中一条路径直接就终止在当前节点上了），所以这时候**当前节点就是最近公共祖先**，直接返回就可以了。

这个过程说白了本质上就是：**从根节点开始走一条唯一确定的路径**，每一步都能靠值的比较确定唯一的前进方向，完全不需要像普通二叉树那样"两边都要探测一遍"。这其实是"BST 能利用有序性来做剪枝"这个思想的又一次体现（跟 0700 二叉搜索树中的搜索是同一类优化思路）。

正因为不需要真正去查找 `p`、`q` 的位置，也不需要回溯（也就是不需要知道子树递归的返回结果来做判断），所以这道题就不用像后序遍历那种"先处理子树再处理自己"的模式了，用最简单的从根往下走的单向遍历（迭代或者递归都可以）就能解决。而且效率上比普通二叉树的解法更高，因为普通二叉树解法需要访问可能涉及的所有节点，而 BST 解法只需要沿着一条路径走到分岔点就够了，根本不用去探测整棵树。

复杂度这块，时间复杂度是 O(h)，h 是树的高度，因为只走一条从根到分岔点的路径；如果是平衡树，那就是 O(log n)，最坏情况下（退化成一条链）是 O(n)。空间复杂度上，递归写法是 O(h)（也就是调用栈的开销），迭代写法则能做到 O(1)。

## 代码

二叉树节点定义：

```cpp
struct TreeNode {
    int val;
    TreeNode *left;
    TreeNode *right;
    TreeNode(int x) : val(x), left(NULL), right(NULL) {}
};
```

### C++

```cpp
class Solution {
public:
    // 递归写法
    TreeNode* lowestCommonAncestor(TreeNode* root, TreeNode* p, TreeNode* q) {
        if (p->val < root->val && q->val < root->val) {
            return lowestCommonAncestor(root->left, p, q);  // 都比当前节点小，往左走
        }
        if (p->val > root->val && q->val > root->val) {
            return lowestCommonAncestor(root->right, p, q); // 都比当前节点大，往右走
        }
        return root; // 分岔点（或其中一个等于当前节点），当前节点即为答案
    }

    // 迭代写法：不需要递归栈
    TreeNode* lowestCommonAncestorIterative(TreeNode* root, TreeNode* p, TreeNode* q) {
        TreeNode* node = root;
        while (node != nullptr) {
            if (p->val < node->val && q->val < node->val) {
                node = node->left; // 都比当前节点小，往左走
            } else if (p->val > node->val && q->val > node->val) {
                node = node->right; // 都比当前节点大，往右走
            } else {
                return node; // 分岔点，即为答案
            }
        }
        return nullptr;
    }
};
```

## 总结

- 跟 0236 那种普通二叉树的解法比起来，BST 解法不需要用后序遍历去回溯，只要根据 `p`、`q` 的值和当前节点值的大小关系，就能直接判断该往哪走，这也是利用有序性做剪枝的又一次体现。
- 当 `p`、`q` 分别落在当前节点两侧的时候（或者其中一个正好等于当前节点），说明路径在这里分岔了，当前节点就是最近公共祖先，这个判断逻辑比 0236 要简单直接得多。
- 因为只需要沿着一条路径走到分岔点就行，所以时间复杂度是 O(h) 而不是 O(n)，比普通二叉树的解法效率更高，因为不用去访问那些不相关的子树。
- 这道题特别适合用迭代来实现，因为不需要回溯，空间复杂度可以做到 O(1)，这一点又进一步体现出了 BST 解法相对于普通二叉树解法的优势。
