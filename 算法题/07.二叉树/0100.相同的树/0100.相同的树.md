# 100. 相同的树

**题目描述**

给定两棵二叉树的根节点 `p` 和 `q`，判断这两棵树是否相同。如果两个树在结构上相同，且节点具有相同的值，则认为它们是相同的。

```
示例：
输入: p = [1,2,3], q = [1,2,3]
输出: true

输入: p = [1,2], q = [1,null,2]
输出: false
解释: 结构不同（一个是左孩子，一个是右孩子），即使数值都出现过

输入: p = [1,2,1], q = [1,1,2]
输出: false
解释: 结构相同，但对应位置的值不同
```

## 思路

你想啊，判断两棵树是不是相同，其实要同时满足两个条件：一个是结构完全一致，就是每个位置的空/非空状态都得一样；另一个是对应位置的值也要完全一致。这种问题天然就适合用递归来做，为什么呢？因为"两棵树相同"这件事可以拆解成"根节点值相同，而且左子树分别相同，而且右子树也分别相同"——这就是一个典型的分治、递归的定义。

具体怎么设计呢？我们写一个递归函数 `isSameTree(p, q)`，每次同步比较 `p` 和 `q` 这一对节点，这里分四种情况讨论：

第一种情况，两个节点都为空，那结构上这个位置就是一致的，都是空嘛，直接返回 `true`，这是递归的一个终止条件。

第二种情况，一个为空另一个不为空，那结构就不一致了，一边有节点一边没有，直接返回 `false`。这也是递归的终止条件，注意这一步必须写在处理值之前，不然去访问空节点的 `val` 就会报错。

第三种情况，两个都不为空，但是值不一样，那即使结构位置上都有节点，只要数值不相等，也不能算相同，照样返回 `false`。

第四种情况，两个都不为空而且值也相同，这一层是过了，但还不能就此断定整棵树相同，得接着往下递归，看左子树是不是相同、右子树是不是相同，这两个必须同时满足才行，也就是逻辑 AND 的关系。

那为什么这个递归一定会结束呢？关键就在第一步和第二步这两个终止条件——每次递归调用都是往树的下一层走，节点一旦为空必然会触发终止条件，不会没完没了递归下去。核心的递归关系式可以这样概括：

```
isSameTree(p, q) =
    true                                              若 p 和 q 都为空
    false                                             若只有一个为空，或值不相等
    isSameTree(p.left, q.left) && isSameTree(p.right, q.right)   否则
```

这道题其实是后面 101 题"对称二叉树"的简化基础版本。为什么这么说呢？101 题本质上是判断一棵树的左右子树是不是互为镜像，做法是把同一棵树拆成两个"指针"，一个从根的左子树出发，一个从根的右子树出发，然后用跟本题类似的同步递归去比较，只不过比较方式变成了"镜像对称"——比较 `p.left` 和 `q.right`、`p.right` 和 `q.left`，而不是本题这种"结构对齐"的比较方式，也就是比较 `p.left` 和 `q.left`、`p.right` 和 `q.right`。所以你把本题这个双指针同步递归的框架理解透了，后面做 101 题、572 题子树这一系列"双树比较"的题目就都有基础了。

复杂度这块怎么分析呢？递归会同步遍历两棵树里较小的那棵树的所有节点——因为一旦某处结构不一致，就会提前返回，不会把整棵树遍历完。最坏情况是两棵树完全相同，这时候得遍历所有节点，时间复杂度是 O(min(m, n))，m、n 分别是两棵树的节点数，通常我们就简写成 O(n)。空间复杂度取决于递归调用栈的深度，最坏情况下树退化成一条链，是 O(n)；如果是平衡树的话，就是 O(log n)。

## 代码

### C++

```cpp
struct TreeNode {
    int val;
    TreeNode *left;
    TreeNode *right;
    TreeNode() : val(0), left(nullptr), right(nullptr) {}
    TreeNode(int x) : val(x), left(nullptr), right(nullptr) {}
    TreeNode(int x, TreeNode *left, TreeNode *right) : val(x), left(left), right(right) {}
};

class Solution {
public:
    bool isSameTree(TreeNode* p, TreeNode* q) {
        if (p == nullptr && q == nullptr) {
            return true;  // 两边都为空，这个位置结构一致
        }
        if (p == nullptr || q == nullptr) {
            return false;  // 只有一边为空，结构不一致
        }
        if (p->val != q->val) {
            return false;  // 都非空但值不同
        }
        // 值相同，继续同步比较左子树和右子树，二者必须都成立
        return isSameTree(p->left, q->left) && isSameTree(p->right, q->right);
    }
};
```

### Python

标准库没有直接对应"两棵二叉树结构比较"的一行解法，本题是需要自定义递归逻辑的问题，直接给出手写实现：

```python
class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right


class Solution:
    def isSameTree(self, p: TreeNode, q: TreeNode) -> bool:
        if p is None and q is None:
            return True  # 两边都为空，结构一致
        if p is None or q is None:
            return False  # 只有一边为空，结构不一致
        if p.val != q.val:
            return False  # 都非空但值不同
        # 值相同，继续同步比较左右子树，二者必须都成立
        return self.isSameTree(p.left, q.left) and self.isSameTree(p.right, q.right)
```

面试的时候这道题主要考什么呢？就是看你能不能正确处理空节点比较的三种组合情况——都空、一空一非空、都非空，还要把值比较和结构比较分清楚，这是本题的核心考点。代码本身其实很简单，但边界条件很容易漏判，这才是容易翻车的地方。

```go
type TreeNode struct {
    Val   int

    Right *TreeNode

func isSameTree(p *TreeNode, q *TreeNode) bool {
    if p == nil && q == nil {
        return true // 两边都为空，结构一致

        return false // 只有一边为空，结构不一致
    }
    if p.Val != q.Val {

}
```

## 总结

- 这道题的核心说白了就是"同步递归双指针"这个框架：两个指针分别在两棵树上同步移动，每一层先判空、再判值、最后递归比较左右子树，这个框架是处理所有"双树比较"类问题的基础模板，记住它很有用。
- 判空逻辑一定要写在判值逻辑前面，而且要分清楚"都为空"和"只有一个为空"这是两种不同的结果，不然直接去访问空节点的 `val` 会报运行时错误。
- 递归的终止条件其实是由树的结构天然保证的，因为沿着树往下走，一定会遇到空节点，所以不需要额外去维护深度或者计数器。
- 这道题是 101 题"对称二叉树"的简化版本，区别就在于比较左右子树时的配对方式不一样——一个是对齐比较，一个是镜像比较。你把本题的框架掌握了，可以直接迁移到 101 题、572 题判断子树这些题目上去。
