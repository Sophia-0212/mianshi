# 100. 相同的树

**题目描述**

给定两棵二叉树的根节点 `p` 和 `q`，判断这两棵树是否相同。如果两个树在结构上相同，且节点具有相同的值，则认为它们是相同的。

```
示例：
输入: p = [1,2,3], q = [1,2,3]
输出: true

输入: p = [1,2], q = [1,null,2]
输出: false
解释: 结构不同（一个是左孩子，一个是右孩子），即使数值都出现过

输入: p = [1,2,1], q = [1,1,2]
输出: false
解释: 结构相同，但对应位置的值不同
```

## 思路

同步递归：两节点均空则相同；仅一方为空或值不同则失败；否则分别比较左右子树。

时间 O(min(m,n)+1)，空间 O(min(h₁,h₂)+1)，m、n 为节点数，h₁、h₂ 为树高。

### LeetCode 写法与原有示例

标准库没有直接对应"两棵二叉树结构比较"的一行解法，本题是需要自定义递归逻辑的问题，直接给出手写实现：

```python
class TreeNode:
    # 方法：__init__；按题目要求处理输入并返回结果，核心算法见方法体。
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right


class Solution:
    # 方法：isSameTree；按题目要求处理输入并返回结果，核心算法见方法体。
    def isSameTree(self, p: TreeNode, q: TreeNode) -> bool:
        if p is None and q is None:
            return True  # 两边都为空，结构一致
        if p is None or q is None:
            return False  # 只有一边为空，结构不一致
        if p.val != q.val:
            return False  # 都非空但值不同
        # 值相同，继续同步比较左右子树，二者必须都成立
        return self.isSameTree(p.left, q.left) and self.isSameTree(p.right, q.right)
```


面试的时候这道题主要考什么呢？就是看你能不能正确处理空节点比较的三种组合情况——都空、一空一非空、都非空，还要把值比较和结构比较分清楚，这是本题的核心考点。代码本身其实很简单，但边界条件很容易漏判，这才是容易翻车的地方。

    """按层序构造树，None 表示空节点。"""
    if not values or values[0] is None:
        return None

    queue = deque([root])

                child = TreeNode(values[i])
                setattr(parent, side, child)
                queue.append(child)
            i += 1
    return root

    # 层序输出并去掉末尾空节点，方便和题目示例比较。
    result, queue = [], deque([root])

        node = queue.popleft()
        result.append(node.val if node else None)
        if node:
            queue.extend([node.left, node.right])
    while result and result[-1] is None:
        result.pop()
    return result

        return 0

## 总结

- 这道题的核心说白了就是"同步递归双指针"这个框架：两个指针分别在两棵树上同步移动，每一层先判空、再判值、最后递归比较左右子树，这个框架是处理所有"双树比较"类问题的基础模板，记住它很有用。
- 判空逻辑一定要写在判值逻辑前面，而且要分清楚"都为空"和"只有一个为空"这是两种不同的结果，不然直接去访问空节点的 `val` 会报运行时错误。
- 递归的终止条件其实是由树的结构天然保证的，因为沿着树往下走，一定会遇到空节点，所以不需要额外去维护深度或者计数器。
- 这道题是 101 题"对称二叉树"的简化版本，区别就在于比较左右子树时的配对方式不一样——一个是对齐比较，一个是镜像比较。你把本题的框架掌握了，可以直接迁移到 101 题、572 题判断子树这些题目上去。
