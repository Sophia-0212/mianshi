# 0501. 二叉搜索树中的众数

**题目描述**

给定一个含重复值的二叉搜索树（BST）的根节点 `root`，找出并返回 BST 中的所有众数（出现频率最高的元素）。如果树中有多个众数，则返回它们的数组（顺序任意）。

```
示例：
输入: root = [1,null,2,2]
输出: [2]
解释: 节点值 2 出现了 2 次，1 出现了 1 次，2 是众数。
```

## 思路

最直接的想法你肯定能想到：用一个哈希表统计每个值出现的次数，遍历一遍树，再扫一遍哈希表把最大频率对应的值都找出来。这个思路完全没问题，时间复杂度是 O(n)，但是额外用了 O(n) 的哈希表空间。那这里的关键是什么呢？既然这棵树是 BST，我们就应该想想能不能利用它的有序性把这个额外空间给省掉。

这里的关键观察点跟 0530（BST 的最小绝对差）是一样的：BST 中序遍历出来的结果是一个有序的序列，因为本题允许重复值，所以准确说是非严格递增。那在一个有序序列里，相同的值必然是挨在一起的，你想啊，比如 `[1,2,2,2,3,3,5]` 这个序列，所有的 2 都连在一起，所有的 3 也连在一起。这就意味着，统计每个值出现了多少次，根本不需要哈希表，只要在中序遍历的过程中，拿"当前节点的值"跟"上一个节点的值"（也就是 `pre`）比一比是不是相同就行了：

- 如果相同，说明当前值和上一个值属于同一段连续区间，那就把这个值的计数 `count` 加 1。
- 如果不同，说明进入了一个新的值的区间，这时候就要把 `count` 重置成 1。

每次更新完 `count` 之后，还得动态维护两个东西："当前最大频率 `maxCount`"和"对应的众数列表 `result`"：

- 如果 `count > maxCount`，说明发现了一个新的、频率更高的众数，这时候 `maxCount` 要更新成 `count`，同时 `result` 得清空，只放入当前这个值——为什么呢？因为之前记录的那些众数已经不再是众数了。
- 如果 `count == maxCount`，说明当前值和已经知道的众数频率是一样的，那它也算众数，就把当前值加进 `result` 里，注意这里不能清空之前的结果。
- 如果 `count < maxCount`，说明当前值的频率还没超过已知的最大值，那就什么都不用做。

这个过程其实和 0530 的"pre 指针"技巧是一脉相承的，区别在哪呢？0530 只需要维护"最小差值"这一个标量就够了，而这道题还要额外维护"当前值的连续计数 `count`"和"众数列表 `result`"，逻辑上多了一层，但核心的遍历框架完全是一样的。

这么一来，这种做法就做到了：不用额外的哈希表，只靠中序遍历加上常数个变量（`pre`、`count`、`maxCount`）加上结果列表，就把额外空间从 O(n)，也就是哈希表那份，降到了 O(1)——这里不算结果列表本身和递归栈，因为结果列表本来就是必须返回的输出，不算"额外"空间。

递归的三要素说一下：终止条件是节点为空就直接返回；单层递归逻辑就是中序遍历——先递归左子树，然后处理当前节点（更新 `count`，判断要不要更新 `maxCount` 或 `result`，再更新 `pre`），最后递归右子树。

复杂度这块，时间复杂度是 O(n)，每个节点访问一次；空间复杂度是 O(h)，就是递归调用栈的开销，这里同样不计结果列表，因为它是必须输出的内容。

## 代码

二叉树节点定义：

```cpp
struct TreeNode {
    int val;
    TreeNode *left;
    TreeNode *right;
    TreeNode(int x) : val(x), left(NULL), right(NULL) {}
};
```

### C++

```cpp
class Solution {
public:
    vector<int> findMode(TreeNode* root) {
        inorder(root);
        return result;
    }

private:
    TreeNode* pre = nullptr;   // 中序遍历中上一个访问的节点
    int count = 0;              // 当前值的连续出现次数
    int maxCount = 0;           // 目前为止的最大出现次数
    vector<int> result;         // 众数列表

    void inorder(TreeNode* root) {
        if (root == nullptr) return; // 终止条件
        inorder(root->left);           // 先递归左子树

        // 处理当前节点：更新连续计数
        if (pre != nullptr && pre->val == root->val) {
            count++;         // 与上一个值相同，连续计数加 1
        } else {
            count = 1;         // 进入新的值区间，重置计数
        }

        // 根据 count 与 maxCount 的关系更新众数列表
        if (count > maxCount) {
            maxCount = count;    // 发现频率更高的众数
            result.clear();       // 之前记录的都不再是众数
            result.push_back(root->val);
        } else if (count == maxCount) {
            result.push_back(root->val); // 频率相同，也是众数之一
        }

        pre = root;             // 更新 pre
        inorder(root->right);   // 最后递归右子树
    }
};
```

```java
class Solution {
    private TreeNode pre = null;  // 上一个访问的节点
    private int count = 0;          // 当前值连续出现次数
    private int maxCount = 0;       // 最大出现次数
    private List<Integer> resultList = new ArrayList<>();

    public int[] findMode(TreeNode root) {
        inorder(root);
        int[] result = new int[resultList.size()];
        for (int i = 0; i < resultList.size(); i++) {
            result[i] = resultList.get(i);
        }
        return result;
    }

    private void inorder(TreeNode root) {
        if (root == null) return; // 终止条件
        inorder(root.left);         // 先递归左子树

        if (pre != null && pre.val == root.val) {
            count++;     // 与上一个值相同，计数加 1
```

### Python

```python
class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right


class Solution:
    def findMode(self, root: TreeNode) -> list[int]:
        self.pre = None       # 上一个访问的节点
        self.count = 0          # 当前值连续出现次数
        self.max_count = 0      # 最大出现次数
        self.result = []        # 众数列表

        def inorder(node: TreeNode) -> None:
            if node is None:
                return  # 终止条件
            inorder(node.left)  # 先递归左子树

            if self.pre is not None and self.pre.val == node.val:
                self.count += 1  # 与上一个值相同，计数加 1
            else:
                self.count = 1     # 新的值区间，重置计数

            if self.count > self.max_count:
                self.max_count = self.count  # 发现更高频率的众数
                self.result = [node.val]        # 清空之前的记录
            elif self.count == self.max_count:
                self.result.append(node.val)     # 频率相同，加入众数列表

            self.pre = node       # 更新 pre
            inorder(node.right)  # 最后递归右子树

        inorder(root)
        return self.result
```

```go
func findMode(root *TreeNode) []int {
    var pre *TreeNode  // 上一个访问的节点
    count := 0           // 当前值连续出现次数
    maxCount := 0         // 最大出现次数
    result := []int{}      // 众数列表

    var inorder func(node *TreeNode)
    inorder = func(node *TreeNode) {
        if node == nil {
            return // 终止条件
        }
        inorder(node.Left) // 先递归左子树

        if pre != nil && pre.Val == node.Val {
            count++ // 与上一个值相同，计数加 1
        } else {
            count = 1 // 新的值区间，重置计数
        }

        if count > maxCount {
            maxCount = count           // 发现更高频率的众数
            result = []int{node.Val}     // 清空之前的记录
        } else if count == maxCount {
            result = append(result, node.Val) // 频率相同，加入众数列表
        }

        pre = node          // 更新 pre
        inorder(node.Right) // 最后递归右子树
    }

    inorder(root)
    return result
}
```

## 总结

- 这道题的核心就是利用 BST 中序遍历的有序性：相同的值在中序遍历结果里必然是连续排列的，所以可以用一个 `pre` 指针比较相邻节点是否相同，来统计连续出现的次数，完全不需要额外的哈希表。
- 需要维护三个状态变量：`count`（当前值的连续计数）、`maxCount`（目前的最大计数）、`result`（众数列表），然后根据 `count` 跟 `maxCount` 之间大于、等于、小于这三种关系，来决定要不要更新众数列表。
- 有一点要特别注意：`count > maxCount` 的时候一定要记得清空之前的 `result`，为什么呢？因为之前记录的众数已经被更频繁出现的新值给取代了。
- 说白了，这道题就是 0530 那个技巧的自然延伸，都是"中序遍历 + pre 指针"这个模式在不同统计需求下的应用，把这个模式吃透了，就能应对更多"BST 相邻关系"这一类的题目。
