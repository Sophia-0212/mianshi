# 0538. 把二叉搜索树转换为累加树

**题目描述**

给定一个二叉搜索树（BST），将其转换为累加树（Greater Sum Tree），使得每个节点的值等于原来的值加上所有大于它的节点值之和。

```
示例：
输入: root = [5,2,13]
输出: [18,20,13]
解释: 节点 2 的新值 = 2 + 13 + 5 = 20；节点 5 的新值 = 5 + 13 = 18；节点 13 没有比它大的节点，新值不变。
```

## 思路

这道题跟 0530、0501 一样，都是利用了 BST 中序遍历的有序性，但方向恰好是反过来的：那两道题要的是"递增序列"，而这道题需要的是"每个节点右侧、也就是更大的那部分的和"，这自然就引出一个想法——如果按照从大到小的顺序去遍历节点，那就可以边遍历边累加，累加到当前节点的时候，这个总和正好就是所有比它大的节点值加起来的和。

你想啊，BST 标准的中序遍历顺序是"左子树、根节点、右子树"，得到的是从小到大的递增序列。那如果把这个顺序倒过来，变成"右子树、根节点、左子树"，得到的就是从大到小的递减序列了，这个叫"反中序遍历"。

按照反中序遍历去访问节点：第一个访问到的节点，是整棵树里的最大值，这时候它没有比它更大的节点了，所以新值就等于原值；第二个访问到的是次大值，比它大的节点只有"最大值"这一个，所以新值就等于原值加上最大值；依此类推，每访问到一个新节点，就把它加到一个累加变量 `pre` 上面——这个 `pre` 表示"到目前为止已经遍历过的所有节点值之和"，然后把累加后的结果作为这个节点的新值，同时更新 `pre` 为这个新值，为什么要这么更新呢？因为后面的节点还需要加上"这个节点更新后的值"。

具体展开说一下：终止条件是节点为空就直接返回；单层递归逻辑是反中序，也就是先右子树，再当前节点，最后左子树，具体是这样：

1. 先递归处理右子树，因为右子树的值都比当前节点大，得先把它们都处理完并累加上去。
2. 然后处理当前节点：`pre += root->val`，把当前节点的原值加到累加和上，接着 `root->val = pre`，把这个累加和赋值给当前节点，这样就完成了"变成累加树"的转换。
3. 最后再递归处理左子树。

这里 `pre` 变量的含义是随着遍历推进不断变化的：它始终代表"当前已经处理过的所有节点（在原树里）的值之和"，因为处理顺序是从大到小的，"已经处理过的节点"正好就是"比当前节点大的所有节点"，所以 `pre` 累加完之后立刻赋值给当前节点，这样就精确地实现了题目要求的——每个节点的值等于原值加上所有比它大的节点值之和。

这个技巧说白了本质上就是 0530 和 0501 用到的"pre 指针"模式的一个变体：不同的地方在于，这里 `pre` 存的不是"上一个节点"本身，而是"累加和"，而且遍历方向也从"从小到大"变成了"从大到小"。所以你看，只要把 pre 指针在中序遍历中的通用用法掌握了，稍微调整一下遍历方向和 `pre` 的含义，就能把这一类问题都解决掉。

复杂度这块，时间复杂度是 O(n)，每个节点访问一次；空间复杂度是 O(h)，也就是递归调用栈的开销，`pre` 本身占的是常数空间。

## 代码

二叉树节点定义：

```cpp
struct TreeNode {
    int val;
    TreeNode *left;
    TreeNode *right;
    TreeNode(int x) : val(x), left(NULL), right(NULL) {}
};
```

### C++

```cpp
class Solution {
public:
    TreeNode* convertBST(TreeNode* root) {
        reverseInorder(root);
        return root;
    }

private:
    int pre = 0; // 累加和：目前已处理过的所有节点值之和

    void reverseInorder(TreeNode* root) {
        if (root == nullptr) return; // 终止条件
        reverseInorder(root->right);  // 先处理右子树（值更大的部分）
        pre += root->val;               // 累加当前节点原值
        root->val = pre;                 // 把累加和赋给当前节点，完成转换
        reverseInorder(root->left);    // 最后处理左子树（值更小的部分）
    }
};
```

### Java

```java
class Solution {
    private int pre = 0; // 累加和

    public TreeNode convertBST(TreeNode root) {
        pre = 0; // 重置状态，避免多次调用间污染
        reverseInorder(root);
        return root;
    }

    private void reverseInorder(TreeNode root) {
        if (root == null) return; // 终止条件
        reverseInorder(root.right); // 先处理右子树
        pre += root.val;             // 累加当前节点原值
        root.val = pre;               // 赋值给当前节点
        reverseInorder(root.left);  // 最后处理左子树
    }
}
```

class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right


class Solution:
    def convertBST(self, root: TreeNode) -> TreeNode:

            if node is None:

            reverse_inorder(node.right)  # 先处理右子树（值更大的部分）

            node.val = self.pre  # 把累加和赋给当前节点
            reverse_inorder(node.left)  # 最后处理左子树

        reverse_inorder(root)
        return root

### Go

```go
type TreeNode struct {
    Val   int
    Left  *TreeNode
    Right *TreeNode
}

func convertBST(root *TreeNode) *TreeNode {
    pre := 0 // 累加和

    var reverseInorder func(node *TreeNode)
    reverseInorder = func(node *TreeNode) {
        if node == nil {
            return // 终止条件
        }
        reverseInorder(node.Right) // 先处理右子树
        pre += node.Val              // 累加当前节点原值
        node.Val = pre                // 赋值给当前节点
        reverseInorder(node.Left)    // 最后处理左子树
    }

    reverseInorder(root)
    return root
}
```

## 总结

- 核心技巧就是"反中序遍历"，也就是先右子树、再当前节点、最后左子树，这样得到的访问顺序是从大到小，天然适合"累加所有比当前节点大的值"这类需求。
- `pre` 这个变量在这里扮演的角色是"到目前为止已处理节点值之和"，处理当前节点的时候要先累加原值，再把结果赋值给节点本身，这个顺序不能颠倒，不然会把累加和本身重复算进去。
- 这道题说白了就是 0530 和 0501 那种"pre 指针加中序遍历"模式的一个变体：遍历方向从"从小到大"改成了"从大到小"，`pre` 的含义也从"上一个节点"变成了"累加和"，这体现的是同一个模式在不同问题上的灵活迁移。
- 这个转换是原地修改节点的 `val`，不需要新建一棵树的结构，空间开销就只有递归调用栈，这也是这类"基于中序遍历顺序做原地统计或转换"问题典型的效率特征。
