# 0617. 合并二叉树

**题目描述**

给定两棵二叉树 `root1` 和 `root2`，想象当你将其中一棵覆盖到另一棵上时，两棵树的一些节点会重叠，而另一些节点则不会。你需要将这两棵树合并成一棵新树。合并的规则是：如果两个节点重叠，那么将两个节点的值相加作为合并后节点的新值；否则，不为 `null` 的节点将直接作为新树的节点。

```
示例：
输入: root1 = [1,3,2,5], root2 = [2,1,3,null,4,null,7]
输出: [3,4,5,5,4,null,7]
解释: 对应位置节点值相加，root1 有的位置 root2 没有（或反过来），直接用存在的那个节点。
```

## 思路

同步递归：一棵子树为空则直接返回另一棵；均非空则节点值相加，递归合并左右孩子并接回。

时间 O(min(m,n)+1)，辅助空间 O(min(h₁,h₂)+1)，m、n 为节点数，h₁、h₂ 为树高。

```python
class Solution:
    # 方法：mergeTrees；按题目要求处理输入并返回结果，核心算法见方法体。
    def mergeTrees(self, root1: TreeNode, root2: TreeNode) -> TreeNode:
        # 复用 root1 的结构，直接在其上修改
        if root1 is None:
            return root2  # root1 为空，结果取决于 root2

            return root1  # root2 为空，直接用 root1
        root1.val += root2.val  # 两者都非空，值相加
        root1.left = self.mergeTrees(root1.left, root2.left)    # 递归合并左子树
        root1.right = self.mergeTrees(root1.right, root2.right)  # 递归合并右子树
        return root1

    def mergeTreesNew(self, root1: TreeNode, root2: TreeNode) -> TreeNode:
        # 新建节点版本，不修改任意一棵原树
        if root1 is None:
            return root2
        if root2 is None:
            return root1
        node = TreeNode(root1.val + root2.val)  # 新建节点承载合并结果
        node.left = self.mergeTreesNew(root1.left, root2.left)
        node.right = self.mergeTreesNew(root1.right, root2.right)
```

```python
def build_tree(values):
    """按层序构造树，None 表示空节点。"""
    if not values or values[0] is None:
        return None
    root = TreeNode(values[0])
    queue = deque([root])
    i = 1
    while queue and i < len(values):
        parent = queue.popleft()
        for side in ('left', 'right'):
            if i < len(values) and values[i] is not None:
                child = TreeNode(values[i])
                setattr(parent, side, child)
                queue.append(child)
            i += 1
    return root

        node = queue.popleft()
        result.append(node.val if node else None)
        if node:
            queue.extend([node.left, node.right])
    while result and result[-1] is None:
        result.pop()
    return result
```

```cpp
        cout << "用例 1: 期望=[3, 4, 5, 5, 4, null, 7] 实际=";
        show(result);
        cout << "\n";
    }
    // 用例 2：输入 ({'tree': [1]}, {'tree': [1, 2]})；期望 [2, 2]。
    {
        auto* arg0 = buildTreeInput({1});
        auto* arg1 = buildTreeInput({1, 2});
        auto result = interview::mergeTrees(arg0, arg1);
        cout << "用例 2: 期望=[2, 2] 实际=";
        show(result);
        cout << "\n";
    }
    // 用例 3：输入 ({'tree': []}, {'tree': [1]})；期望 [1]。
    {
        auto* arg0 = buildTreeInput({});
        auto* arg1 = buildTreeInput({1});
        auto result = interview::mergeTrees(arg0, arg1);
        cout << "用例 3: 期望=[1] 实际=";
        show(result);
        cout << "\n";
    }
    return 0;
}
```

## 总结

- 合并二叉树的核心就是"两棵树同步递归"：只要有一个节点非空，结果就要保留这个位置的节点；两个都为空的时候，才是真正的空。
- 终止条件那两行判断——`root1` 为空就返回 `root2`，`root2` 为空就返回 `root1`——已经隐式地覆盖了"两者都为空"这种情况，不需要再额外判断。
- 要不要复用原树结构，这是个工程上的权衡点：复用能省空间，但会破坏原树；新建节点能保留原树，但要多花 O(n) 空间，面试的时候可以主动把这个权衡点提出来聊一聊。
- 时间复杂度取决于两棵树里比较小的那一棵，因为递归只要碰到任意一侧为空，就不会再往下深入了。
