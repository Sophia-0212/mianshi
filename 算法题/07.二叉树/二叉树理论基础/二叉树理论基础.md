# 二叉树理论基础

二叉树每个节点最多两个孩子，左右有区别。

- 满二叉树：每层填满，h 层共 `2^h-1` 个节点。
- 完全二叉树：除末层外填满，末层从左连续排列。
- BST：左子树值小于根，右子树值大于根；是否允许重复依题意。
- AVL：BST 每个节点的左右高度差不超过 1，维护平衡后查找／增删 O(log n)。

链式节点：

```
struct TreeNode {
    int val;
    TreeNode *left;
    TreeNode *right;
    TreeNode(int x) : val(x), left(NULL), right(NULL) {}
};
```

数组以 0 为根时，孩子下标为 `2i+1、2i+2`，适合完全树；偏斜树可能浪费存储。

DFS 为前序“根左右”、中序“左根右”、后序“左右根”；BFS 用队列逐层处理。时间 O(n)，DFS 辅助空间 O(h)，BFS O(w)。
