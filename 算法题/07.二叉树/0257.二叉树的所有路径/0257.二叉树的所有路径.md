# 0257. 二叉树的所有路径

**题目描述**

给你一个二叉树的根节点 `root`，按**任意顺序**，返回所有从根节点到叶子节点的路径。路径用字符串表示，节点值之间用 `"->"` 分隔。

```
示例：
输入: root = [1,2,3,null,5]
     1
   /   \
  2     3
   \
    5
输出: ["1->2->5","1->3"]
```

## 思路

这道题要收集的是"从根节点到每一个叶子节点"的完整路径，这其实天然就是一个 DFS 问题：用递归去模拟"沿着一条路径往下走"这个过程，当走到叶子节点的时候，当前维护的这条路径就是一条完整的答案，把它记录下来；如果还不是叶子节点，那就继续往左右子树递归下去。

这里的关键点在于**怎么去维护"当前路径"这个状态**。一般的做法是用一个数组（或者列表）叫 `path`，记录从根节点到当前节点沿途经过的所有节点值。递归进入一个子节点之前，先把这个子节点的值加进 `path`；等递归返回之后（也就是说这个子节点的子树已经处理完了），就需要把刚才加进去的值从 `path` 里再拿出来，为什么呢？因为要回到当前这一层，去尝试别的分支了（比如递归完左子树之后要去递归右子树，这时候 `path` 里就不应该还残留着左子树那一支的节点）。

**"加入路径 → 递归 → 移除路径"** 这个动作模式，说白了就是回溯法的标准写法：先做出一个选择（把当前节点加入路径），基于这个选择继续往下递归探索，等递归返回了，就要撤销这个选择（把当前节点从路径里移除），这样才能保证去尝试下一个分支的时候，路径状态是干净正确的，不会残留上一个分支留下的数据。

具体到二叉树上怎么写呢：

1. 递归函数接收当前节点和当前路径 `path`（可以用列表，也可以直接用字符串拼接）。
2. 把当前节点值加入 `path`。
3. 判断一下当前节点是不是叶子节点（也就是左右孩子都为空）：如果是，就把 `path` 转成字符串格式加入结果集，这就是一条完整路径的终点了。
4. 如果不是叶子节点，那就继续递归处理左子树（如果存在的话）和右子树（如果存在的话）。
5. 递归调用左右子树前后，要特别注意 `path` 的状态管理：如果用的是可变的列表，递归调用完左子树之后需要把刚加入的那个值弹出来（也就是回溯），然后再去递归右子树；但如果每次递归的时候用的是新的列表或字符串（也就是值传递而不是引用传递），那就不需要手动去弹出了，因为每次递归的分支拿到的都是各自独立的一份拷贝，天然就不会互相污染。

这也是为什么有些实现"看起来完全没有显式的回溯代码"——你看啊，如果参数是以值传递的方式（比如 Python 里用字符串拼接 `path + "->" + str(val)` 生成一个新字符串，而不是在原字符串上直接改），那每次递归调用天然就拿到了一份独立的路径，副作用根本不会向兄弟分支泄露出去，这种写法其实可以理解成是回溯思想的一种隐式实现。

时间复杂度是 O(n²)（最坏情况下，每个叶子节点对应的路径长度是 O(n)，一共有 O(n) 个叶子，拼接字符串的时候还有额外开销），空间复杂度是 O(n)（递归栈加上路径存储的开销）。

## 代码

二叉树节点定义：

```cpp
struct TreeNode {
    int val;
    TreeNode *left;
    TreeNode *right;
    TreeNode(int x) : val(x), left(NULL), right(NULL) {}
};
```

```python
class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right
```

### C++

```cpp
class Solution {
public:
    void traverse(TreeNode* node, vector<int>& path, vector<string>& result) {
        path.push_back(node->val);              // 做出选择：把当前节点加入路径
        if (node->left == nullptr && node->right == nullptr) {
            // 叶子节点，拼接路径字符串加入结果
            string pathStr;
            for (int i = 0; i < path.size(); i++) {
                pathStr += to_string(path[i]);
                if (i != path.size() - 1) pathStr += "->";
            }
            result.push_back(pathStr);
            return; // 叶子节点没有子节点可以继续递归，直接返回
        }
        if (node->left) {
            traverse(node->left, path, result);  // 递归探索左子树
            path.pop_back();                     // 撤销选择：回溯，移除刚加入的左孩子
        }
        if (node->right) {
            traverse(node->right, path, result); // 递归探索右子树
            path.pop_back();                     // 撤销选择：回溯，移除刚加入的右孩子
        }
    }

    vector<string> binaryTreePaths(TreeNode* root) {
        vector<string> result;
        if (root == nullptr) return result;
        vector<int> path;
        traverse(root, path, result);
        return result;
    }
};
```

### Java

```java
class Solution {
    public List<String> binaryTreePaths(TreeNode root) {
        List<String> result = new ArrayList<>();
        if (root == null) return result;
        List<Integer> path = new ArrayList<>();
        traverse(root, path, result);
        return result;
    }

    private void traverse(TreeNode node, List<Integer> path, List<String> result) {
        path.add(node.val);                       // 做出选择：加入路径
        if (node.left == null && node.right == null) {
            // 叶子节点，拼接结果
            StringBuilder sb = new StringBuilder();
            for (int i = 0; i < path.size(); i++) {
                sb.append(path.get(i));
                if (i != path.size() - 1) sb.append("->");
            }
            result.add(sb.toString());
            return;
        }
        if (node.left != null) {
            traverse(node.left, path, result);    // 递归左子树
            path.remove(path.size() - 1);         // 回溯：撤销刚加入的左孩子
        }
        if (node.right != null) {
            traverse(node.right, path, result);   // 递归右子树
            path.remove(path.size() - 1);         // 回溯：撤销刚加入的右孩子
        }
    }
}
```

### Python

```python
class Solution:
    def binaryTreePaths(self, root):
        result = []
        if root is None:
            return result
        self.traverse(root, [], result)
        return result

    def traverse(self, node, path, result):
        path = path + [node.val]  # 用新列表而不是原地修改，天然实现了"隐式回溯"
        if node.left is None and node.right is None:
            result.append("->".join(map(str, path)))  # 叶子节点，拼接路径加入结果
            return
        if node.left:
            self.traverse(node.left, path, result)   # 递归左子树，传入的是新列表，不影响后续右子树
        if node.right:
            self.traverse(node.right, path, result)  # 递归右子树
```

### Go

```go
func binaryTreePaths(root *TreeNode) []string {
    result := []string{}
    if root == nil {
        return result
    }
    var traverse func(node *TreeNode, path []int)
    traverse = func(node *TreeNode, path []int) {
        path = append(path, node.Val) // 追加到新的切片（Go中append不保证不影响原切片，这里按值语义处理更安全）
        if node.Left == nil && node.Right == nil {
            // 叶子节点，拼接路径字符串
            strs := make([]string, len(path))
            for i, v := range path {
                strs[i] = strconv.Itoa(v)
            }
            result = append(result, strings.Join(strs, "->"))
            return
        }
        if node.Left != nil {
            traverse(node.Left, path) // 递归左子树
        }
        if node.Right != nil {
            traverse(node.Right, path) // 递归右子树
        }
    }
    traverse(root, []int{})
    return result
}
```

## 总结

- 收集"根到叶子"的所有路径，是回溯法在二叉树上的一个很典型的应用：递归探索一条路径的过程中不断在"做选择"（把当前节点加入路径），走到叶子节点的时候就收集结果，返回上一层之前需要"撤销选择"（把当前节点移除），这样才能避免污染到其他分支的路径。
- 如果路径参数用的是可变容器（比如 C++、Java 里的可变列表）并且是通过引用传递的，那就必须手动在递归调用之后写 `pop_back`、`remove` 之类的操作来完成回溯；但如果每次递归传进去的是"值拷贝"（比如 Python 里的字符串拼接或者新建一个列表），那就不需要写显式的回溯代码了，因为每个分支天然拿到的就是一份独立的路径副本。
- 判断叶子节点的条件是左右孩子都为空，只有真正走到叶子节点才算是完成了一条完整路径，中间节点是不应该被当成终点的。
- 这道题算是理解"二叉树递归里其实藏着回溯思想"的一道入门题，后面会有专门一篇去讲这个思想的普适性。
