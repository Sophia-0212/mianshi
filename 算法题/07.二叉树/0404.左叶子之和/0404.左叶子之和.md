# 0404. 左叶子之和

**题目描述**

给定二叉树的根节点 `root`，返回所有**左叶子之和**。

```
示例：
输入: root = [3,9,20,null,null,15,7]
      3
     / \
    9  20
      /  \
     15   7
输出: 24
解释: 左叶子节点是9和15，9+15=24
```

## 思路

遍历时检查左孩子：若非空且没有孩子，累加其值；继续处理左右子树。左叶子须同时满足“左孩子”和“叶子”。

可用递归 DFS 或队列 BFS。时间 O(n)；DFS 空间 O(h)，BFS 空间 O(w)，h 为树高，w 为最大层宽。

class Solution:
    # 方法：sumOfLeftLeaves；按题目要求处理输入并返回结果，核心算法见方法体。
    def sumOfLeftLeaves(self, root):
        if root is None:
            return 0                             # 终止条件
        left_value = 0
        if root.left and root.left.left is None and root.left.right is None:
            left_value = root.left.val           # 左孩子是叶子，记录值
        else:
            left_value = self.sumOfLeftLeaves(root.left)  # 继续往下找
        right_value = self.sumOfLeftLeaves(root.right)    # 右子树内部同样递归
        return left_value + right_value

func sumOfLeftLeaves(root *TreeNode) int {
    if root == nil {
        return 0 // 终止条件
    }
    leftValue := 0
    if root.Left != nil && root.Left.Left == nil && root.Left.Right == nil {

## 总结

- 说白了，"左叶子"的判断关键就是要结合父子关系：节点自己是不是叶子（左右孩子都空）这个好判断，但"是不是左孩子"这个信息只有在父节点这一层才拿得到，所以判断逻辑得放在父节点那里做，不能等递归进到子节点内部再去判断。
- 递归的时候，"左孩子是叶子"和"左孩子不是叶子或不存在"这两种情况要分开处理：前一种直接把值累加进去，后一种就继续往下递归接着找。
- 右子树这边也不能漏，得照样递归遍历，因为右子树内部同样可能藏着"某个节点的左孩子是叶子"的情况，只是这些左叶子相对于最开始的根节点来说，是处在右子树这个范围里的。
- 那 BFS 的写法呢，逻辑上是等价的，只是用队列迭代代替了递归调用栈，如果不想用递归，或者担心递归深度太深爆栈，用这种写法会更稳一些。
