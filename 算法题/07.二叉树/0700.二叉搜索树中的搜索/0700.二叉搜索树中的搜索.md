# 0700. 二叉搜索树中的搜索

**题目描述**

给定二叉搜索树（BST）的根节点 `root` 和一个整数值 `val`，在 BST 中找到值等于 `val` 的节点，返回该节点为根的子树。如果节点不存在，返回 `null`。

```
示例：
输入: root = [4,2,7,1,3], val = 2
输出: [2,1,3]
解释: BST 中值为 2 的节点，其子树包含 1 和 3。
```

## 思路

BST 查找：目标小于当前值向左，大于向右，相等返回当前子树；走到空返回空。可递归或迭代。

时间 O(h)；递归空间 O(h)，迭代空间 O(1)。h 为树高，平衡时 O(log n)，最坏 O(n)。

```python
class TreeNode:
    # 方法：__init__；按题目要求处理输入并返回结果，核心算法见方法体。
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right


class Solution:
    # 方法：searchBST；按题目要求处理输入并返回结果，核心算法见方法体。
    def searchBST(self, root: TreeNode, val: int) -> TreeNode:
        # 递归写法：利用 BST 有序性剪枝
        if root is None or root.val == val:
            return root  # 找到或未找到
        if val < root.val:
            return self.searchBST(root.left, val)  # 只查左子树
        return self.searchBST(root.right, val)  # 只查右子树

    # 方法：searchBSTIterative；按题目要求处理输入并返回结果，核心算法见方法体。
    def searchBSTIterative(self, root: TreeNode, val: int) -> TreeNode:
        # 迭代写法：不需要回溯
        while root is not None and root.val != val:
            root = root.left if val < root.val else root.right  # 决定移动方向
        return root
```

```cpp
class Solution {
public:
    // 递归写法：利用 BST 有序性，每次只需要探测一侧
    TreeNode* searchBST(TreeNode* root, int val) {
        if (root == nullptr || root->val == val) {
            return root; // 找到或者已经走到空节点（未找到）
        }
        if (val < root->val) {
            return searchBST(root->left, val); // 目标更小，只需查左子树
        }
        return searchBST(root->right, val); // 目标更大，只需查右子树
    }

    // 迭代写法：不需要回溯，用一个指针不断往一个方向移动
    TreeNode* searchBSTIterative(TreeNode* root, int val) {
        while (root != nullptr && root->val != val) {
            root = (val < root->val) ? root->left : root->right; // 决定往左还是往右走
        }
        return root; // 循环结束时，root 是目标节点或 nullptr
    }
};
```

## 总结

- BST 查找的关键就是利用"左小右大"的有序性去剪枝：每一步都能确定目标只可能在一侧，另一侧根本不用探测，这跟普通二叉树"两边都要递归"是完全不同的两种玩法。
- BST 上的查找说白了就是二分查找的思想搬到了树形结构上，把"数组的中点"换成了"当前节点"，把"数组的左右半区"换成了"左右子树"。
- 因为每一步只需要往一个方向走，不用回溯，所以这道题很适合写成迭代形式，用一个指针代替递归调用栈，这样空间复杂度就能做到 O(1)。
- 平衡 BST 上查找是 O(log n)，但如果树退化成一条链（比如插入的数据本身就是有序的），就会退化到 O(n)，这也是后面要学"平衡二叉搜索树"（比如红黑树、AVL树）的原因之一。
