# 0700. 二叉搜索树中的搜索

**题目描述**

给定二叉搜索树（BST）的根节点 `root` 和一个整数值 `val`，在 BST 中找到值等于 `val` 的节点，返回该节点为根的子树。如果节点不存在，返回 `null`。

```
示例：
输入: root = [4,2,7,1,3], val = 2
输出: [2,1,3]
解释: BST 中值为 2 的节点，其子树包含 1 和 3。
```

## 思路

你想啊，如果这是一棵普通的二叉树，要查找一个值就只能老老实实两边都递归：先递归查左子树，没找到再递归查右子树，任何一边找到了就返回。这种查法的时间复杂度是 O(n)，为什么呢？因为你不知道目标值到底在哪一侧，必须把所有节点都遍历一遍，才能确保"这个值不存在"这个结论是对的。

但这道题的树是**二叉搜索树**，BST 有个核心性质——**对于任意一个节点，它左子树所有节点的值都比它小，右子树所有节点的值都比它大**。这个性质就厉害了，它能让查找像二分查找一样"剪枝"：

- 如果 `root->val == val`：那就是找到了，直接返回 `root`。
- 如果 `val < root->val`：说明目标值比当前节点还小，根据 BST 性质，它绝对不可能出现在右子树里（右子树所有值都比 `root->val` 大，自然也就比 `val` 大），所以只需要递归查左子树就行了。
- 如果 `val > root->val`：同理，只用递归查右子树。

**这里其实就是普通二叉树递归和 BST 递归最核心的区别**：普通二叉树的递归是"两边都得探测一下，因为不知道目标在哪一侧"；BST 的递归呢，是"每一步都能确定目标只可能在一侧，另一侧可以直接放弃"。这种"每次排除一半可能性"的模式，跟二分查找的思想完全是一回事——说白了，BST 的查找就是把二分查找从"有序数组"搬到了"树形结构"上，只是数组的"左半区/右半区"变成了"左子树/右子树"而已。

那递归的终止条件是什么呢？如果 `root` 为空了（走到叶子节点的下一层，或者输入本身就是空树），说明沿着这条路径找到底也没找到目标值，那就返回 `null`。

除了递归写法，这道题其实也很适合用迭代来实现，为什么呢？因为每一步只需要往一个方向走，不需要回溯，用一个指针从根节点开始不断往左或往右移动就行了，不用显式地维护一个栈。

复杂度这块，因为每一步都能排除一半的子树（假设树相对平衡），时间复杂度是 O(log n)，h 是树高；但最坏情况下，如果树退化成一条链（比如所有节点都只有右孩子），复杂度就退化到 O(n) 了。空间复杂度呢，递归写法是 O(h)，也就是调用栈的开销；迭代写法是 O(1)，因为不需要额外空间。

## 代码

二叉树节点定义：

```cpp
struct TreeNode {
    int val;
    TreeNode *left;
    TreeNode *right;
    TreeNode(int x) : val(x), left(NULL), right(NULL) {}
};
```

### C++

```cpp
class Solution {
public:
    // 递归写法：利用 BST 有序性，每次只需要探测一侧
    TreeNode* searchBST(TreeNode* root, int val) {
        if (root == nullptr || root->val == val) {
            return root; // 找到或者已经走到空节点（未找到）
        }
        if (val < root->val) {
            return searchBST(root->left, val); // 目标更小，只需查左子树
        }
        return searchBST(root->right, val); // 目标更大，只需查右子树
    }

    // 迭代写法：不需要回溯，用一个指针不断往一个方向移动
    TreeNode* searchBSTIterative(TreeNode* root, int val) {
        while (root != nullptr && root->val != val) {
            root = (val < root->val) ? root->left : root->right; // 决定往左还是往右走
        }
        return root; // 循环结束时，root 是目标节点或 nullptr
    }
};
```

### Python

```python
class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right


class Solution:
    def searchBST(self, root: TreeNode, val: int) -> TreeNode:
        # 递归写法：利用 BST 有序性剪枝
        if root is None or root.val == val:
            return root  # 找到或未找到
        if val < root.val:
            return self.searchBST(root.left, val)  # 只查左子树
        return self.searchBST(root.right, val)  # 只查右子树

    def searchBSTIterative(self, root: TreeNode, val: int) -> TreeNode:
        # 迭代写法：不需要回溯
        while root is not None and root.val != val:
            root = root.left if val < root.val else root.right  # 决定移动方向
        return root
```

### Go

```go
type TreeNode struct {
    Val   int
    Left  *TreeNode
    Right *TreeNode
}

// 递归写法
func searchBST(root *TreeNode, val int) *TreeNode {
    if root == nil || root.Val == val {
        return root // 找到或未找到
    }
    if val < root.Val {
        return searchBST(root.Left, val) // 只查左子树
    }
    return searchBST(root.Right, val) // 只查右子树
}

// 迭代写法
func searchBSTIterative(root *TreeNode, val int) *TreeNode {
    for root != nil && root.Val != val {
        if val < root.Val {
            root = root.Left // 往左走
        } else {
            root = root.Right // 往右走
        }
    }
    return root
}
```

## 总结

- BST 查找的关键就是利用"左小右大"的有序性去剪枝：每一步都能确定目标只可能在一侧，另一侧根本不用探测，这跟普通二叉树"两边都要递归"是完全不同的两种玩法。
- BST 上的查找说白了就是二分查找的思想搬到了树形结构上，把"数组的中点"换成了"当前节点"，把"数组的左右半区"换成了"左右子树"。
- 因为每一步只需要往一个方向走，不用回溯，所以这道题很适合写成迭代形式，用一个指针代替递归调用栈，这样空间复杂度就能做到 O(1)。
- 平衡 BST 上查找是 O(log n)，但如果树退化成一条链（比如插入的数据本身就是有序的），就会退化到 O(n)，这也是后面要学"平衡二叉搜索树"（比如红黑树、AVL树）的原因之一。
