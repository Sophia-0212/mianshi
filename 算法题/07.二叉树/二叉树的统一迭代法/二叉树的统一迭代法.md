# 二叉树的统一迭代法

**内容概述**

上一篇讲的迭代遍历里，前序和后序的写法很接近，但中序遍历需要额外引入一个 `cur` 指针，逻辑上和另外两种不统一，代码没法直接复用。这篇讲一种"标记法"，用同一套代码模板就能写出前中后序三种迭代遍历，只需要调整节点重新入栈的相对顺序就行。

节点定义（后续代码统一使用）：

```cpp
struct TreeNode {
    int val;
    TreeNode *left;
    TreeNode *right;
    TreeNode(int x) : val(x), left(NULL), right(NULL) {}
};
```

```python
class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right
```

## 思路

之前中序遍历迭代法麻烦的根本原因是什么呢？就是栈里存的节点，"弹出"和"访问"这两个动作没法绑在一起——弹出一个节点的时候，我们不知道它的左子树是不是已经处理完了，所以不能立刻访问它的值。

那标记法的思路是什么呢？说白了就是：**给每个入栈的节点带上一个"是否已经处理过一次"的标记**。第一次把某个节点压入栈的时候，只是表示"我们发现了这个节点，但还没打算访问它的值"，这时候紧接着往栈里压入一个特殊标记（比如 `nullptr`/`None`）当作"待访问"的信号，再把节点本身重新压回栈顶。等再次从栈里弹出这个节点的时候，如果发现它前面（栈顶方向）跟着一个标记，说明这是第二次遇到这个节点了，这时候才真正去访问它的值。

具体怎么做呢？我们以中序遍历为例：

1. 弹出栈顶节点 `node`。
2. 如果 `node` 不为空：按照"右、根、左"的顺序依次压栈——先压右孩子（如果有），再压 `node` 本身，然后紧跟着压一个空标记 `nullptr`，最后压左孩子（如果有）。为什么这么压呢？因为栈是后进先出，这样入栈之后，出栈顺序就会是"左、根（带标记）、右"，正好符合中序遍历的要求。
3. 如果弹出的是空标记 `nullptr`：那就说明标记后面紧跟着的就是真正要访问的节点，这时候再弹出一次，把这个节点的值加入结果就行了。

这个模板对前序、后序也完全适用，唯一需要改变的是什么呢？就是**压栈时"根、左、右"三者的相对顺序**：

- 中序（左根右）：压栈顺序为 右、根+标记、左 → 出栈顺序左、根、右
- 前序（根左右）：压栈顺序为 右、左、根+标记 → 出栈顺序根、左、右
- 后序（左右根）：压栈顺序为 根+标记、右、左 → 出栈顺序左、右、根

你看，三种遍历的代码框架完全一样，只是三行"压栈"语句的排列顺序不一样，这样就不再需要像前一篇那样为中序单独设计一个 `cur` 指针，也不需要像后序那样借助"反转结果"的技巧，说白了是一种更通用、更容易记忆的写法。

时间复杂度是 O(n)，空间复杂度是 O(n)，因为栈中最多要存储所有节点及其标记。

## 代码

### C++

```cpp
class Solution {
public:
    // 中序遍历统一迭代法：左 -> 根 -> 右
    vector<int> inorderTraversal(TreeNode* root) {
        vector<int> result;
        stack<TreeNode*> st;
        if (root != nullptr) st.push(root);
        while (!st.empty()) {
            TreeNode* node = st.top();
            if (node != nullptr) {
                st.pop();
                if (node->right) st.push(node->right); // 右孩子先压，最后出栈
                st.push(node);                          // 根节点重新压回
                st.push(nullptr);                       // 紧跟一个标记，表示下次弹出即访问
                if (node->left) st.push(node->left);    // 左孩子最后压，最先出栈
            } else {
                st.pop();                    // 弹出标记
                result.push_back(st.top()->val); // 标记后面就是真正要访问的节点
                st.pop();
            }
        }
        return result;
    }

    // 前序遍历统一迭代法：根 -> 左 -> 右
    vector<int> preorderTraversal(TreeNode* root) {
        vector<int> result;
        stack<TreeNode*> st;
        if (root != nullptr) st.push(root);
        while (!st.empty()) {
            TreeNode* node = st.top();
            if (node != nullptr) {
                st.pop();
                if (node->right) st.push(node->right); // 右孩子先压
                if (node->left) st.push(node->left);   // 左孩子次之
                st.push(node);                          // 根节点最后压，最先出栈访问
                st.push(nullptr);                       // 紧跟标记
            } else {
                st.pop();
                result.push_back(st.top()->val);
                st.pop();
            }
        }
        return result;
    }

    // 后序遍历统一迭代法：左 -> 右 -> 根
    vector<int> postorderTraversal(TreeNode* root) {
        vector<int> result;
        stack<TreeNode*> st;
        if (root != nullptr) st.push(root);
        while (!st.empty()) {
            TreeNode* node = st.top();
            if (node != nullptr) {
                st.pop();
                st.push(node);                          // 根节点先压（最后访问）
                st.push(nullptr);                       // 紧跟标记
                if (node->right) st.push(node->right);  // 右孩子次之
                if (node->left) st.push(node->left);    // 左孩子最后压，最先出栈
            } else {
                st.pop();
                result.push_back(st.top()->val);
                st.pop();
            }
        }
        return result;
    }
};
```

class Solution {
    // 中序遍历统一迭代法：左 -> 根 -> 右
    public List<Integer> inorderTraversal(TreeNode root) {
        List<Integer> result = new ArrayList<>();
        Deque<TreeNode> stack = new ArrayDeque<>();
        if (root != null) stack.push(root);
        while (!stack.isEmpty()) {
            TreeNode node = stack.peek();
            if (node != null) {
                stack.pop();
                if (node.right != null) stack.push(node.right); // 右先压
                stack.push(node);                                 // 根重新压回
                stack.push(null);                                 // 标记
                if (node.left != null) stack.push(node.left);    // 左最后压
            } else {
                stack.pop();                        // 弹出标记
                result.add(stack.pop().val);         // 弹出并访问真正的节点
            }
        }
        return result;
    }

    // 前序遍历统一迭代法：根 -> 左 -> 右
    public List<Integer> preorderTraversal(TreeNode root) {
        List<Integer> result = new ArrayList<>();
        Deque<TreeNode> stack = new ArrayDeque<>();
        if (root != null) stack.push(root);
        while (!stack.isEmpty()) {
            TreeNode node = stack.peek();
            if (node != null) {
                stack.pop();
                if (node.right != null) stack.push(node.right);
                if (node.left != null) stack.push(node.left);
                stack.push(node);
                stack.push(null);
            } else {
                stack.pop();
                result.add(stack.pop().val);
            }
        }
        return result;
    }

    // 后序遍历统一迭代法：左 -> 右 -> 根
    public List<Integer> postorderTraversal(TreeNode root) {
        List<Integer> result = new ArrayList<>();
        Deque<TreeNode> stack = new ArrayDeque<>();
        if (root != null) stack.push(root);
        while (!stack.isEmpty()) {
            TreeNode node = stack.peek();
            if (node != null) {
                stack.pop();
                stack.push(node);
                stack.push(null);
                if (node.right != null) stack.push(node.right);
                if (node.left != null) stack.push(node.left);
            } else {
                stack.pop();
                result.add(stack.pop().val);
            }
        }
        return result;
    }
}

func inorderTraversal(root *TreeNode) []int {
    result := []int{}
    var stack []*TreeNode
    if root != nil {
        stack = append(stack, root)
    }
    for len(stack) > 0 {
        node := stack[len(stack)-1]
        if node != nil {
            stack = stack[:len(stack)-1]
            if node.Right != nil {
                stack = append(stack, node.Right) // 右先压
            }
            stack = append(stack, node) // 根重新压回
            stack = append(stack, nil)  // 标记

                stack = append(stack, node.Left) // 左最后压
            }
        } else {
            stack = stack[:len(stack)-1] // 弹出标记
            node = stack[len(stack)-1]
            stack = stack[:len(stack)-1]
            result = append(result, node.Val) // 访问真正的节点
        }
    }
    return result
}

## 总结

- 统一迭代法的核心是给节点加一个"访问标记"：第一次遇到只入栈不访问，标记后紧跟着重新压回，第二次遇到（也就是弹出标记）的时候才真正去访问。
- 三种遍历顺序只需要调整"根、左、右"三者压栈的相对顺序，代码框架完全一致，不用再像中序那样单独引入额外指针，也不用像后序那样依赖"反转结果"的技巧。
- 压栈顺序跟出栈顺序是相反的：想要出栈顺序是"左、根、右"，压栈顺序就得反过来写成"右、根+标记、左"，这个地方要转个弯想一下。
- 这种写法虽然更统一，但引入了 `nullptr`/`None` 当标记，代码可读性上不如前一篇那种"专用写法"直观，实际面试中两种写法都可以选，理解思想比死记代码更重要。
