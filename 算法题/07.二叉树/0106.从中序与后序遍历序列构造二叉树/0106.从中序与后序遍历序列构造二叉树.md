# 0106. 从中序与后序遍历序列构造二叉树

**题目描述**

给定两个整数数组 `inorder` 和 `postorder`，其中 `inorder` 是二叉树的中序遍历，`postorder` 是同一棵树的后序遍历，请构造并返回这棵二叉树。假设树中没有重复的值。

```
示例：
输入: inorder = [9,3,15,20,7], postorder = [9,15,7,20,3]
输出: [3,9,20,null,null,15,7]
解释: 还原出的树结构是：
      3
     / \
    9  20
       / \
      15  7
```

## 思路

这道题的核心问题是：我们只知道两种遍历顺序，怎么反过来把树的结构还原出来呢？关键就在于要抓住这两种遍历序列各自"暴露"出了什么信息。

**你想啊，后序遍历的最后一个元素一定是根节点。** 为什么呢？因为后序遍历的顺序是"左子树、右子树、根节点"，根节点永远是最后被访问到的，所以 `postorder` 的最后一个元素，就是当前这棵（子）树的根，这个是白拿的信息。

**那中序遍历呢，它能把树切成左右两半。** 中序遍历的顺序是"左子树、根节点、右子树"，那一旦你知道了根节点的值，就可以拿这个值去 `inorder` 数组里找它的位置——这个位置左边的所有元素，其实就构成了左子树的中序遍历；右边的所有元素，就构成了右子树的中序遍历，这么一来左右子树就被你切开了。

那有了左右子树各自的节点数量（这里分别记为 `leftSize` 和 `rightSize`），后序遍历数组也可以按同样的比例去切分：`postorder` 前 `leftSize` 个元素就是左子树的后序遍历，接下来 `rightSize` 个元素是右子树的后序遍历，最后一个元素（前面已经用掉了）就是根节点。

这么一来，整个构造过程就变成一个递归了：

1. 取 `postorder` 最后一个元素当根节点的值，创建根节点。
2. 在 `inorder` 里定位根节点值所在的下标 `rootIdx`，这样就能得到左子树的中序区间 `[0, rootIdx-1]`，右子树的中序区间 `[rootIdx+1, end]`。
3. 根据左子树中序区间的长度，把后序遍历里对应左子树的区间和右子树的区间也切出来。
4. 递归地去构造左子树、右子树，分别挂到根节点的 `left`、`right` 上面。
5. 递归的终止条件很简单：区间为空的时候就返回 `null`。

**那这里有个问题，为什么"中序+后序"或者"中序+前序"就能唯一确定一棵二叉树，而"前序+后序"却不行呢？** 这是个很关键的面试追问点，你得说清楚。

说白了，根本原因是：中序遍历携带了"某个节点左右两侧各自是哪些节点"的信息，而这个信息正是切分左右子树所必需的东西。前序遍历知道根节点（就是第一个元素），后序遍历也知道根节点（就是最后一个元素），但这两者都回答不了一个问题——"给定根节点之后，剩下这些节点里，哪些属于左子树，哪些属于右子树？"它们只能给你一个整体的节点集合，没法告诉你切分点在哪。

这里我举个反例你就明白了：前序 `[1,2]`，后序 `[2,1]`。按前序看，根是 1，剩下的节点是 2；按后序看，根也是 1，剩下的节点还是 2。但问题是，节点 2 到底是根节点 1 的左孩子，还是右孩子呢？你想，前序遍历里，如果 2 是左孩子，遍历顺序是"根->左->右"，那就是 `[1,2]`；但如果 2 是右孩子，遍历顺序同样也是"根->左->右"，因为左子树是空的直接跳过，那结果照样是 `[1,2]`。后序遍历同理也分不出来。所以说，"前序+后序"这个组合，只要树里存在只有一个孩子的节点，就会有歧义，只有当这棵树是**满二叉树**（也就是每个节点不是 0 个孩子就是 2 个孩子）的时候，才能唯一确定下来，因为满二叉树天然不会出现"只有一个孩子，还分不清是左是右"这种歧义情况。

而中序遍历就不一样了，中序遍历里根节点左边的元素必然全部来自左子树，右边的元素必然全部来自右子树，这个"左右分界"的信息恰恰是前序和后序都不具备的。所以说，只要中序遍历参与进来，"根节点位置"和"左右子树的范围"就都能被唯一确定，这就是为什么中序遍历这么重要。

最后说一下复杂度：为了避免每次都在 `inorder` 里线性查找根节点位置（不然会退化成 O(n²)），一般的做法是先用一个哈希表把"值 -> 下标"这个映射记下来，这样查找就变成 O(1) 了，整体时间复杂度是 O(n)，因为每个节点只被创建一次；空间复杂度是 O(n)，主要是哈希表和递归栈带来的开销。

## 代码

二叉树节点定义：

```cpp
struct TreeNode {
    int val;
    TreeNode *left;
    TreeNode *right;
    TreeNode(int x) : val(x), left(NULL), right(NULL) {}
};
```

### C++

```cpp
class Solution {
public:
    TreeNode* buildTree(vector<int>& inorder, vector<int>& postorder) {
        unordered_map<int, int> idxMap; // 值 -> 中序遍历下标，加速定位根节点
        for (int i = 0; i < inorder.size(); i++) {
            idxMap[inorder[i]] = i;
        }
        return build(inorder, 0, inorder.size() - 1,
                     postorder, 0, postorder.size() - 1, idxMap);
    }

private:
    // inLeft/inRight：中序区间；postLeft/postRight：后序区间，均为闭区间
    TreeNode* build(vector<int>& inorder, int inLeft, int inRight,
                     vector<int>& postorder, int postLeft, int postRight,
                     unordered_map<int, int>& idxMap) {
        if (inLeft > inRight || postLeft > postRight) {
            return nullptr; // 区间为空，无节点可构造
        }
        int rootVal = postorder[postRight]; // 后序遍历最后一个元素是根节点值
        TreeNode* root = new TreeNode(rootVal);
        int rootIdx = idxMap[rootVal];        // 根节点在中序遍历中的位置
        int leftSize = rootIdx - inLeft;       // 左子树节点数量

        // 左子树：中序区间 [inLeft, rootIdx-1]，后序区间对应前 leftSize 个
        root->left = build(inorder, inLeft, rootIdx - 1,
                            postorder, postLeft, postLeft + leftSize - 1, idxMap);
        // 右子树：中序区间 [rootIdx+1, inRight]，后序区间是剩余部分（不含根节点）
        root->right = build(inorder, rootIdx + 1, inRight,
                             postorder, postLeft + leftSize, postRight - 1, idxMap);
        return root;
    }
};
```

### Java

```java
class Solution {
    private Map<Integer, Integer> idxMap = new HashMap<>(); // 值 -> 中序遍历下标

    public TreeNode buildTree(int[] inorder, int[] postorder) {
        for (int i = 0; i < inorder.length; i++) {
            idxMap.put(inorder[i], i);
        }
        return build(inorder, 0, inorder.length - 1,
                     postorder, 0, postorder.length - 1);
    }

    private TreeNode build(int[] inorder, int inLeft, int inRight,
                            int[] postorder, int postLeft, int postRight) {
        if (inLeft > inRight || postLeft > postRight) {
            return null; // 区间为空
        }
        int rootVal = postorder[postRight];      // 后序最后一个元素是根节点
        TreeNode root = new TreeNode(rootVal);
        int rootIdx = idxMap.get(rootVal);        // 根节点在中序中的位置
        int leftSize = rootIdx - inLeft;           // 左子树节点数

        root.left = build(inorder, inLeft, rootIdx - 1,
                           postorder, postLeft, postLeft + leftSize - 1);
        root.right = build(inorder, rootIdx + 1, inRight,
                            postorder, postLeft + leftSize, postRight - 1);
        return root;
    }
}
```

### Python

二叉树构造是结构性递归，没有对应的标准库一行解，只给手写实现：

```python
class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right


class Solution:
    def buildTree(self, inorder: list[int], postorder: list[int]) -> TreeNode:
        idx_map = {val: i for i, val in enumerate(inorder)}  # 值 -> 中序下标

        def build(in_left, in_right, post_left, post_right):
            if in_left > in_right or post_left > post_right:
                return None  # 区间为空，无节点
            root_val = postorder[post_right]  # 后序最后一个元素是根节点
            root = TreeNode(root_val)
            root_idx = idx_map[root_val]       # 根节点在中序中的位置
            left_size = root_idx - in_left      # 左子树节点数量

            root.left = build(in_left, root_idx - 1,
                               post_left, post_left + left_size - 1)
            root.right = build(root_idx + 1, in_right,
                                post_left + left_size, post_right - 1)
            return root

        return build(0, len(inorder) - 1, 0, len(postorder) - 1)
```

### Go

```go
type TreeNode struct {
    Val   int
    Left  *TreeNode
    Right *TreeNode
}

func buildTree(inorder []int, postorder []int) *TreeNode {
    idxMap := make(map[int]int) // 值 -> 中序遍历下标
    for i, v := range inorder {
        idxMap[v] = i
    }

    var build func(inLeft, inRight, postLeft, postRight int) *TreeNode
    build = func(inLeft, inRight, postLeft, postRight int) *TreeNode {
        if inLeft > inRight || postLeft > postRight {
            return nil // 区间为空
        }
        rootVal := postorder[postRight] // 后序最后一个元素是根节点
        root := &TreeNode{Val: rootVal}
        rootIdx := idxMap[rootVal]        // 根节点在中序中的位置
        leftSize := rootIdx - inLeft       // 左子树节点数量

        root.Left = build(inLeft, rootIdx-1, postLeft, postLeft+leftSize-1)
        root.Right = build(rootIdx+1, inRight, postLeft+leftSize, postRight-1)
        return root
    }

    return build(0, len(inorder)-1, 0, len(postorder)-1)
}
```

## 总结

- 这类构造类问题的通用套路是：先从一种遍历序列里找到"根节点"，再用另一种遍历序列（必须包含中序）切分出左右子树各自对应的区间，最后递归去构造。
- 用哈希表预先处理好"值 -> 中序下标"的映射，这样就不用每层递归都线性扫描去找根节点位置了，这是把复杂度从 O(n²) 优化到 O(n) 的关键一步。
- "中序+后序"能唯一确定一棵二叉树，"前序+后序"不行（除非是满二叉树），根本原因就是中序遍历提供了"根节点左右两侧分别是哪些节点"的分界信息，而前序、后序都缺这个信息。
- 区间的开闭约定和长度计算这里很容易出错，建议写代码之前先在纸上画一个具体例子，把每一段区间的边界确认清楚（这里采用的是闭区间 `[left, right]`），再对照代码逐行核实切分对不对齐。
