# 0701. 二叉搜索树中的插入操作

**题目描述**

给定二叉搜索树（BST）的根节点 `root` 和要插入树中的值 `val`，将值 `val` 插入到 BST 中，返回插入后 BST 的根节点。可以假设原始 BST 中不存在与 `val` 相同的值，插入操作可以以任意有效方式完成，只要在插入后，原有的每个不同值对应的节点值保持不变。

```
示例：
输入: root = [4,2,7,1,3], val = 5
输出: [4,2,7,1,3,5]
解释: 5 应该插在 4 的右子树（因为 5>4），再插在 7 的左子树（因为 5<7）。
```

## 思路

沿 BST 查找路径前进，遇到空位置创建节点。递归返回新子树根并接回；迭代记录父节点后连接。

时间 O(h)；递归空间 O(h)，迭代辅助空间 O(1)，h 为树高。

```python
class TreeNode:
    # 方法：__init__；按题目要求处理输入并返回结果，核心算法见方法体。
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right


class Solution:
    # 方法：insertIntoBST；按题目要求处理输入并返回结果，核心算法见方法体。
    def insertIntoBST(self, root: TreeNode, val: int) -> TreeNode:
        # 递归写法
        if root is None:
            return TreeNode(val)  # 找到空位置，创建新节点

        if val < root.val:
            root.left = self.insertIntoBST(root.left, val)  # 插入左子树并接回
        else:
            root.right = self.insertIntoBST(root.right, val)  # 插入右子树并接回
        return root

    # 方法：insertIntoBSTIterative；按题目要求处理输入并返回结果，核心算法见方法体。
    def insertIntoBSTIterative(self, root: TreeNode, val: int) -> TreeNode:
        # 迭代写法
        if root is None:
            return TreeNode(val)  # 空树

        cur = root
        parent = None
        while cur is not None:
            parent = cur  # 记录父节点
            cur = cur.left if val < cur.val else cur.right

        if val < parent.val:
            parent.left = TreeNode(val)  # 接到左侧
        else:
            parent.right = TreeNode(val)  # 接到右侧
        return root
```

def build_tree(values):
    """按层序构造树，None 表示空节点。"""
    if not values or values[0] is None:
        return None
    root = TreeNode(values[0])
    queue = deque([root])
    i = 1
    while queue and i < len(values):
        parent = queue.popleft()
        for side in ('left', 'right'):
            if i < len(values) and values[i] is not None:
                child = TreeNode(values[i])
                setattr(parent, side, child)
                queue.append(child)
            i += 1
    return root

def tree_values(root):
    # 层序输出并去掉末尾空节点，方便和题目示例比较。
    result, queue = [], deque([root])

        node = queue.popleft()
        result.append(node.val if node else None)
        if node:
            queue.extend([node.left, node.right])
    while result and result[-1] is None:
        result.pop()
    return result

```cpp
class Solution {
public:
    // 递归写法
    TreeNode* insertIntoBST(TreeNode* root, int val) {
        if (root == nullptr) {
            return new TreeNode(val); // 找到空位置，创建新节点
        }
        if (val < root->val) {
            root->left = insertIntoBST(root->left, val);  // 插入左子树，并把结果接回
        } else {
            root->right = insertIntoBST(root->right, val); // 插入右子树，并把结果接回
        }
        return root; // 当前节点本身不变，返回给上一层
    }

    // 迭代写法：需要额外记录父节点，才能把新节点接上去
    TreeNode* insertIntoBSTIterative(TreeNode* root, int val) {
        if (root == nullptr) {
            return new TreeNode(val); // 空树，新节点即为根
        }
        TreeNode* cur = root;
        TreeNode* parent = nullptr;
        while (cur != nullptr) {
            parent = cur; // 记录父节点，供后续接回新节点
            cur = (val < cur->val) ? cur->left : cur->right; // 决定移动方向
        }
        if (val < parent->val) {
            parent->left = new TreeNode(val); // 接到父节点左侧
        } else {
            parent->right = new TreeNode(val); // 接到父节点右侧
        }
        return root;
    }
};
```

    {
        auto* arg0 = buildTreeInput({1});
        int arg1 = 2;
        auto result = interview::insertIntoBST(arg0, arg1);
        cout << "用例 3: 期望=[1, null, 2] 实际=";
        show(result);
        cout << "\n";
    }
    return 0;
}```

## 总结

- BST 插入说白了就是沿着"比当前节点小往左、比当前节点大往右"这条路径走到空位置，插入位置是唯一确定的，不用考虑树的平衡性。
- 递归写法的关键模式是 `root.left = insertIntoBST(root.left, val)`——用递归返回值重新赋值给子节点指针，这样才能保证修改后的子树被正确"接回"父节点，这个模式后面在删除、修剪类题目里还会反复出现。
- 迭代写法需要额外维护一个 `parent` 指针，为什么呢？因为迭代过程中一旦到达空位置，就得立即用父节点的指针把新节点接上去，不像递归那样可以靠返回值自动完成。
- 时间复杂度取决于树高，也就是 O(h)，因为只需要走一条路径，不用探测整棵树，这跟 0700 的查找操作是同一类效率特征。
