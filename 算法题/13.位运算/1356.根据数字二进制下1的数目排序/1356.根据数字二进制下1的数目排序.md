# 1356. 根据数字二进制下1的数目排序

**题目描述**

给你一个整数数组 `arr`。请你将数组中的元素按照其二进制表示中数字 1 的数目升序排序。

如果存在多个数字二进制中 1 的数目相同，则按照数值大小升序排序。

请你返回排序后的数组。

```
示例：
输入：arr = [0,1,2,3,4,5,6,7,8]
输出：[0,1,2,4,8,3,5,6,7]
解释：
0 的二进制表示：0    -> 0 个 1
1 的二进制表示：1    -> 1 个 1
2 的二进制表示：10   -> 1 个 1
4 的二进制表示：100  -> 1 个 1
8 的二进制表示：1000 -> 1 个 1
3 的二进制表示：11   -> 2 个 1
5 的二进制表示：101  -> 2 个 1
6 的二进制表示：110  -> 2 个 1
7 的二进制表示：111  -> 3 个 1
[0,1,2,4,8] 二进制中 1 的数目均为 1，按数值大小排序；[3,5,6] 二进制中 1 的数目均为 2，按数值大小排序。
```

## 思路

这道题你想啊，其实就是一次自定义排序。排序规则说白了是个二元组 `(popcount(x), x)`（`popcount` 就是二进制里 1 的个数），先按 popcount 升序排，popcount 一样再按数值本身升序排。所以只要能又快又准地把每个数字的 popcount 算出来，剩下的直接丢给语言自带的排序函数、传个自定义比较器就完事了。那这道题真正的重点其实就落在"怎么统计一个整数二进制表示里 1 的个数"上，这里我讲两种方法，重点会把第二种方法的位运算原理讲透。

**方法一：逐位右移判断最低位。** 这个最直观——数字只要还没变成 0，就反复看当前最低位是不是 1（用 `n & 1` 判断），是的话计数器加一，然后把整个数字右移一位（`n >>= 1`），一直到 `n` 变成 0 为止。这个方法有个特点：每一步只处理一个二进制位，不管这一位是 0 还是 1 都要走一次循环，所以对一个 32 位整数来说，最坏情况得循环 32 次。就算数字很小、前面全是 0，也不会提前结束，因为得移到最高位的那个 1 才能保证低位全处理完。

**方法二：`n & (n - 1)` 这个技巧，每次消掉最低位的 1。** 这个明显更高效，因为它能直接跳过所有的 0 位，只在有 1 的地方才操作一次，循环次数等于这个数字二进制里 1 的个数，而不是总位数。理解它的关键在哪呢？你去观察 `n` 和 `n - 1` 在二进制上的关系：假设 `n` 最低位的 1 出现在第 k 位（从 0 开始数），那 `n` 的第 k 位是 1，第 0 到 k-1 位全是 0——因为这才叫"最低位的 1"嘛。这时候做 `n - 1`，因为借位规则，第 k 位的这个 1 会被借走变成 0，而第 0 到 k-1 位原本全是 0，借位之后就全变成 1 了。为什么会这样呢？因为减法借位是连锁反应，从最低位开始借，可这几位都是 0 借不出来，只能一直往上借，借到第 k 位才有 1 可借。第 k 位往上的所有位呢，完全不受影响，保持原样。

那咱们把 `n` 和 `n-1` 按位对比一下：第 k 位以上（不含 k）两者完全一样；第 k 位，`n` 是 1、`n-1` 是 0；第 0 到 k-1 位，`n` 全是 0、`n-1` 全是 1。这时候做按位与 `n & (n-1)`：k 位以上因为两边相同，与出来还是原值不变；第 k 位是 `1 & 0 = 0`；第 0 到 k-1 位是 `0 & 1 = 0`。所以 `n & (n-1)` 干的事儿就是把 `n` 最低位那个 1 精确清成 0，其他所有位都原样保留——这就是这个技巧背后的数学原理。

用这个技巧统计 popcount 的过程其实很简单：计数器先初始化成 0，只要 `n != 0`，就执行 `n = n & (n - 1)`（清掉一个最低位的 1），同时计数器加一，一直循环到 `n` 变成 0，这时候计数器的值就是原来 `n` 二进制里 1 的总个数。因为每次循环恰好消掉一个 1，所以循环次数正好等于 1 的个数——如果这个数字本身二进制里 1 很少，比如是 2 的幂、只有一个 1，那这个方法只需要循环一次就结束了，比逐位判断快得多。

算出每个数字的 popcount 之后，剩下的就是标准的自定义排序了：比较两个数字 `a` 和 `b` 的时候，先比 `popcount(a)` 和 `popcount(b)`，相等的话再比 `a` 和 `b` 的数值大小。这里可以提前把每个数字的 popcount 算好存进辅助数组或者哈希表，避免排序过程中反复重复算——虽然这道题数据量一般不大，重复计算影响也不大，但预计算这种做法更规范一些。

边界条件说一下：数字 0 的 popcount 是 0，两种方法都能正确处理，因为循环条件 `n != 0` 直接就不成立，返回 0；数组为空的时候排序结果自然也是空数组，这个不用特判。

复杂度这块：设数组长度为 n，数字最大值对应的二进制位数是 w（对 32 位整数来说 w=32）。算出所有数字的 popcount 总共需要 O(n·w)——这是逐位法的最坏情况，消位法通常会明显更快，具体快多少取决于数据本身 1 的密度。排序本身是 O(n log n) 次比较，每次比较是 O(1)，因为 popcount 已经提前算好了。整体时间复杂度可以看成 O(n log n + n·w)，如果 w 是常数（比如固定 32 位），那就能简化成 O(n log n)。空间复杂度是 O(n)，用来存每个数字对应的 popcount。

## 代码

### C++

```cpp
class Solution {
public:
    vector<int> sortByBits(vector<int>& arr) {
        // 自定义排序比较器：先按 popcount 升序，再按数值升序
        sort(arr.begin(), arr.end(), [](int a, int b) {
            int pa = popcount(a), pb = popcount(b);
            if (pa != pb) return pa < pb;  // popcount 不同，按 popcount 排
            return a < b;                   // popcount 相同，按数值排
        });
        return arr;
    }

private:
    // n & (n-1) 技巧：每次清除最低位的 1，循环次数即为 1 的个数
    static int popcount(int n) {
        int count = 0;
        while (n != 0) {
            n &= (n - 1);  // 消除最低位的 1
            count++;
        }
        return count;
    }
};
```

### Java

```java
class Solution {
    public int[] sortByBits(int[] arr) {
        // 装箱后使用 Integer 数组，方便自定义比较器
        Integer[] boxed = new Integer[arr.length];
        for (int i = 0; i < arr.length; i++) boxed[i] = arr[i];

        Arrays.sort(boxed, (a, b) -> {
            int pa = popcount(a), pb = popcount(b);
            if (pa != pb) return pa - pb;  // popcount 不同，按 popcount 排
            return a - b;                    // popcount 相同，按数值排
        });

        for (int i = 0; i < arr.length; i++) arr[i] = boxed[i];
        return arr;
    }

    // n & (n-1) 技巧：每次清除最低位的 1
    private int popcount(int n) {
        int count = 0;
        while (n != 0) {
            n &= (n - 1);  // 消除最低位的 1
            count++;
        }
        return count;
    }
}
```

### Python

Python 这边其实有个现成的库函数可以直接用，`bin(n).count('1')` 就能统计出二进制里 1 的个数，直接配合 `sorted` 的 `key` 参数用就行：

```python
class Solution:
    def sortByBits(self, arr: list[int]) -> list[int]:
        # 库解：bin(n) 转成二进制字符串（形如 '0b101'），count('1') 统计 1 的个数
        # key 返回元组 (popcount, 数值本身)，sorted 按元组自然顺序排序
        return sorted(arr, key=lambda n: (bin(n).count('1'), n))
```

手写位运算实现（这是面试考察点，用来展示 `n & (n-1)` 这个技巧）：

```python
class Solution:
    def sortByBits(self, arr: list[int]) -> list[int]:
        def popcount(n: int) -> int:
            count = 0
            while n != 0:
                n &= (n - 1)  # 消除最低位的 1，位运算原理见思路部分
                count += 1
            return count

        return sorted(arr, key=lambda n: (popcount(n), n))
```

### Go

```go
func sortByBits(arr []int) []int {
    // popcount 使用 n & (n-1) 技巧，每次清除最低位的 1
    popcount := func(n int) int {
        count := 0
        for n != 0 {
            n &= n - 1 // 消除最低位的 1
            count++
        }
        return count
    }

    sort.Slice(arr, func(i, j int) bool {
        pi, pj := popcount(arr[i]), popcount(arr[j])
        if pi != pj {
            return pi < pj // popcount 不同，按 popcount 升序
        }
        return arr[i] < arr[j] // popcount 相同，按数值升序
    })

    return arr
}
```

## 总结

- `n & (n - 1)` 为什么能清除最低位的 1 呢？关键就在于减一操作会让最低位的 1 以及它右边所有的 0 发生借位翻转（1 变 0，右边的 0 全变 1），跟原数做按位与之后，正好只保留了原数中比这个最低位更高的部分，最低位的 1 被精确清零——这是位运算里最经典、也最值得掌握的技巧之一。
- 跟逐位右移判断相比（那种循环次数等于二进制总位数），`n & (n-1)` 消位法的循环次数正好等于 1 的个数，在 1 比较稀疏的数字上性能优势特别明显，比如 2 的幂只需要循环一次就够了。这其实体现的是"跳过无效的 0，只处理有效的 1"这种优化思想。
- 这道题的排序部分其实是"多关键字排序"的典型写法：先比主要关键字（popcount），相等了再比次要关键字（数值本身），这个模式在需要多级排序规则的题目里非常通用，可以扩展到任意多个比较维度。
- Python 的 `bin(n).count('1')` 提供了一个简洁的库解思路，但面试更看重你是不是理解位运算本身的原理——能不能写出 `n & (n-1)` 的手写版本、并解释清楚它的借位原理，这是考察对位运算底层理解程度的常见方式。
