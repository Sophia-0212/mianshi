# 0657. 机器人能否返回原点

**题目描述**

在二维平面上，有一个机器人从原点 `(0, 0)` 开始。给出它的移动顺序，判断这个机器人在完成移动后是否在 `(0, 0)` 处结束。

移动顺序由字符串 `moves` 表示，字符 `moves[i]` 表示其第 i 次移动，只能有四种不同类型的移动：
- `'U'`：向上移动一格（y 坐标 +1）
- `'D'`：向下移动一格（y 坐标 -1）
- `'L'`：向左移动一格（x 坐标 -1）
- `'R'`：向右移动一格（x 坐标 +1）

如果机器人在完成所有动作后返回原点，返回 `true`，否则返回 `false`。

```
示例：
输入：moves = "UD"
输出：true
解释：机器人先向上移动一格，然后向下移动一格，所有动作都完成后，机器人回到原点，所以返回 true。

输入：moves = "LL"
输出：false
解释：机器人向左移动两次，最终它位于原点的左侧，距离原点有两次单位距离，所以返回 false。
```

## 思路

- 坐标模拟：左右改变 x，上下改变 y，最终 `x==0 && y==0` 即回到原点。
- 字符计数：判断 `L、R` 次数相等，且 `U、D` 次数相等。

两种方法均为时间 O(n)，空间 O(1)。



## Python

### LeetCode 写法与原有示例

标准库这边没有针对这类模拟题的通用一行解，不过可以用 `collections.Counter` 统计次数让代码更简洁一点，这里先给计数法，再给坐标累加的手写版本对比一下。

计数法（借助库函数）：

```python
from collections import Counter

# 依赖说明：Python 标准库 collections：deque 是双端队列，Counter 是计数器，defaultdict 是带默认值的字典。

class Solution:
    # 方法：judgeCircle；按题目要求处理输入并返回结果，核心算法见方法体。
    def judgeCircle(self, moves: str) -> bool:
        cnt = Counter(moves)  # 统计每种指令出现的次数
        # 上下抵消、左右抵消，两组次数分别相等即可回到原点
        return cnt['U'] == cnt['D'] and cnt['L'] == cnt['R']
```


手写坐标累加版本（面试更常考察这种直接模拟的写法，逻辑上最直观）：

```python
class Solution:
    # 方法：judgeCircle；按题目要求处理输入并返回结果，核心算法见方法体。
    def judgeCircle(self, moves: str) -> bool:
        x, y = 0, 0  # 水平、垂直方向的净位移
        for c in moves:
            if c == 'U':
                y += 1
            elif c == 'D':
                y -= 1
            elif c == 'L':
                x -= 1
            elif c == 'R':
                x += 1
        return x == 0 and y == 0  # 两个方向都归零才算回到原点
```

```go
// 方法：judgeCircle；按题目要求处理输入并返回结果，核心算法见方法体。
func judgeCircle(moves string) bool {
    x, y := 0, 0 // 水平、垂直方向的净位移
    for _, c := range moves {
        switch c {
        case 'U':
            y++ // 向上
        case 'D':
            y-- // 向下
        case 'L':
            x-- // 向左
        case 'R':
            x++ // 向右
        }
    }
    return x == 0 && y == 0 // 两轴净位移都为 0 即回到原点
```
```cpp
}
```

## 总结

- 判断"是否回到原点"这类多维坐标问题，你会发现可以拆解成各坐标轴独立判断，只要每一维都归零，整体自然就归零了，这种拆解思路在处理多维模拟问题时特别常用。
- 坐标累加法和"相反方向次数相等"的计数法本质上是等价的，累加本身其实就是次数相减的另一种表达方式，遇到类似的方向抵消问题时，这两种写法可以互相转化，看场景选更合适的一种就行。
- 这道题算是最简单的模拟类问题了，重点不在算法技巧上，而是在于培养"把复杂条件拆解成若干独立可判断的子条件"这种思维习惯，这个技巧在更复杂的模拟题里同样用得上。
- 容易踩的坑是方向和坐标轴的对应关系搞反了，比如把上下当成 x 轴而不是 y 轴。做这类题的时候建议先把坐标系约定明确好再动手写代码，避免中途搞混。
