# 0070. 爬楼梯

**题目描述**

假设你正在爬楼梯，需要 n 阶你才能到达楼顶。每次你可以爬 1 或 2 个台阶，问有多少种不同的方法可以爬到楼顶。

```
示例：
输入: n = 3
输出: 3
解释: 有三种方法可以爬到楼顶。
1 阶 + 1 阶 + 1 阶
1 阶 + 2 阶
2 阶 + 1 阶
```

## 思路

DP：`dp[i]` 表示到第 `i` 阶的方法数，最后一步只能来自 `i-1` 或 `i-2`，故 `dp[i]=dp[i-1]+dp[i-2]`。初值 `dp[1]=1、dp[2]=2`，正序递推。

时间 O(n)，数组空间 O(n)；代码用两个滚动变量，空间 O(1)。



## Python

### LeetCode 写法与原有示例

```python
# 依赖说明：range：Python 内置函数：生成按步长遍历的整数序列。

class Solution:
    # 方法：climbStairs；按题目要求处理输入并返回结果，核心算法见方法体。
    def climbStairs(self, n: int) -> int:
        if n <= 2:
            return n  # n=1 返回1，n=2 返回2，对应初始化
        prev2, prev1 = 1, 2  # prev2=dp[i-2]，prev1=dp[i-1]
        curr = 0
        for i in range(3, n + 1):
            curr = prev1 + prev2  # 核心递推：到达第i阶 = 从i-1爬1阶的方法数 + 从i-2爬2阶的方法数
            prev2, prev1 = prev1, curr  # 同步滚动，避免用错旧值
        return curr```

        return n // n=1 返回1，n=2 返回2，对应初始化

## 总结

- 递推公式长得和斐波那契数列一样，不代表这是同一个问题：斐波那契数列的公式是数学定义直接给出来的，而爬楼梯的公式是从"到达第 i 阶只能由 i-1 阶爬1步或 i-2 阶爬2步而来"这个物理事实分析推导出来的，两边公式长得一样只是分析结果的巧合，不是分析的起点。
- DP 五部曲里"确定 dp 数组含义"和"推导递推公式的道理"这两步，才是区分"真正理解题目"和"照抄公式"的关键；一旦题目条件变了（比方说允许爬 1~3 阶），只有真正理解了推导过程的人才能正确地把公式改成 dp[i]=dp[i-1]+dp[i-2]+dp[i-3]。
- 初始化选择从 dp[1]、dp[2] 开始而不是 dp[0]，是因为这两个值有清晰、没有歧义的现实含义，避免为了凑边界硬引入不自然的定义。
- 同样可以用两个滚动变量把空间复杂度从 O(n) 优化到 O(1)，这是这种递推形状（只依赖前两个状态）通用的优化手段。
