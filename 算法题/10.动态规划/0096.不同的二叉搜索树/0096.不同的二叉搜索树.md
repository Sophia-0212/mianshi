# 0096. 不同的二叉搜索树

**题目描述**

给你一个整数 `n`，求由 `1` 到 `n` 这 `n` 个数字组成的、结构不同的二叉搜索树（BST）有多少种？返回满足题意的二叉搜索树的种数。

```
示例：
输入: n = 3
输出: 5
解释: 以 1、2、3 为节点值，能构成如下 5 种结构不同的二叉搜索树：
   1          3      3      2       1
    \        /      /      / \       \
     3      2      1      1   3       2
    /                                  \
   2                                    3
（共5种不同的树形结构）
```

## 思路

这道题跟上一题"整数拆分"在递推设计的思路上高度相似，都是"枚举一个分割变量，把大问题拆成两个独立子问题，再组合子问题的解"，只不过这道题子问题的组合方式是乘法后再求和，而不是简单取最大值。下面按DP五部曲展开分析。

**第一步，先确定dp数组（下标）的含义**

我定义 `dp[i]` 表示由 `i` 个节点能构成的结构不同的二叉搜索树的种数。这里要特别说一个容易被忽视的关键点：`dp[i]` 只关心节点的**数量**，不关心节点具体的取值是多少。换句话说，无论是用 `{1,2,3}` 这三个数构成BST，还是用 `{5,6,7}` 这三个连续的数构成BST，能构成的树形结构种数是完全一样的。为什么呢？因为二叉搜索树的结构只由"相对大小关系"决定：给定任意 `i` 个从小到大排好序的数字，其中第 `k` 小的数字作为根节点时，比它小的 `k-1` 个数字一定构成左子树，比它大的 `i-k` 个数字一定构成右子树，这个相对关系跟数字的具体取值没关系，只跟"有多少个数字"有关系。这正是为什么我们能只用一个一维的 `dp[i]`（而不需要记录具体是哪些数字）就能描述这个问题的原因。

**第二步，确定递推公式**

要算 `dp[i]`，可以枚举根节点选哪一个数。假设这 `i` 个数字是 `1` 到 `i`（不失一般性，因为前面说了只跟数量有关），枚举根节点的值为 `j`（`j` 从 `1` 到 `i` 中任取一个）：

- 一旦确定根节点是 `j`，那么比 `j` 小的 `j-1` 个数字（也就是 `1` 到 `j-1`）必须全部在左子树里，能构成 `dp[j-1]` 种不同的左子树结构；
- 比 `j` 大的 `i-j` 个数字（也就是 `j+1` 到 `i`）必须全部在右子树里，能构成 `dp[i-j]` 种不同的右子树结构。

左子树的任意一种结构，都可以跟右子树的任意一种结构自由搭配组合成一棵完整的树（左右子树互不影响，是完全独立的两个子问题），根据乘法原理，固定根节点为 `j` 时，总共能构成 `dp[j-1] * dp[i-j]` 种不同的树。

由于根节点 `j` 可以取 `1` 到 `i` 之间的任意一个值，每一种选择都会得到一批互不相同的树形结构（根节点不同，树的结构必然不同），所以要把 `j` 取遍所有可能值时各自贡献的种数累加起来（这里用加法而不是取最大值，因为统计的是**方案总数**，跟"不同路径"里用加法统计路径总数的逻辑是类似的，而不是"整数拆分"里求最优值的那种逻辑）：

```
dp[i] = sum_{j=1}^{i} dp[j-1] * dp[i-j]
```

这里可以顺带提一句，这个递推公式实际上正是组合数学里"卡特兰数（Catalan Number）"的经典递推定义。很多人是直接记住卡特兰数的公式 `C(2n,n)/(n+1)`，但通过这样一步步的DP推导，我们可以从"枚举根节点、左右子树独立组合"这个非常朴素直观的角度，构造性地推出同样的结果，不需要死记公式，理解会更深刻。

**第三步，dp数组怎么初始化**

`dp[0] = 1`，这是整个递推能正确工作的关键初始化。`dp[0]` 表示"0个节点能构成的BST种数"，也就是空树的情况。为什么空树要算作1种，而不是0种呢？因为在递推公式里，当根节点 `j` 取到边界值（`j=1` 或 `j=i`）时，左子树或右子树会退化成"0个节点"的情况，比如 `j=1` 时左子树是 `dp[0]`，`j=i` 时右子树是 `dp[i-i]=dp[0]`。这种情况下，"没有左子树"或"没有右子树"本身也是一种合法且唯一确定的结构（就是"不存在"这一种情况），所以必须把 `dp[0]` 设为1，代表"空子树"是一种合法搭配；如果错误地把 `dp[0]` 设为0，会导致所有依赖它的乘法项都变成0，从而丢掉根节点取在两端时应该有的合法树形，让最终结果偏小。

**第四步，确定遍历顺序**

外层循环 `i` 从 `1` 遍历到 `n`，表示当前要算的节点总数从小到大递增；内层循环 `j` 从 `1` 遍历到 `i`，表示枚举根节点的位置。因为 `dp[i]` 依赖比 `i` 更小的 `dp[j-1]` 和 `dp[i-j]`（两者都严格小于 `i`，因为 `j>=1` 保证 `i-j<i`，`j<=i` 保证 `j-1<i`），所以外层从小到大遍历 `i` 就能保证算 `dp[i]` 的时候，所有它需要用到的更小规模的dp值都已经提前算好了。

**第五步，举例推导一下dp数组，验证一下**

先初始化 `dp[0] = 1`。接下来我们逐步推导到 `dp[3]`：

**算 `dp[1]`**（1个节点）：枚举 `j=1`（唯一选择），左子树0个节点、右子树0个节点：`dp[1] = dp[0] * dp[0] = 1 * 1 = 1`。（只有一种结构：单个根节点，没有子树。）

**算 `dp[2]`**（2个节点）：
- `j=1`：左子树0个节点，右子树1个节点：`dp[0] * dp[1] = 1 * 1 = 1`；
- `j=2`：左子树1个节点，右子树0个节点：`dp[1] * dp[0] = 1 * 1 = 1`；

求和：`dp[2] = 1 + 1 = 2`。（对应根为1、右挂2；或根为2、左挂1，两种结构。）

**算 `dp[3]`**（3个节点）：
- `j=1`：左子树0个节点（`dp[0]=1`），右子树2个节点（`dp[2]=2`）：贡献 `1 * 2 = 2`；
- `j=2`：左子树1个节点（`dp[1]=1`），右子树1个节点（`dp[1]=1`）：贡献 `1 * 1 = 1`；
- `j=3`：左子树2个节点（`dp[2]=2`），右子树0个节点（`dp[0]=1`）：贡献 `2 * 1 = 2`；

求和：`dp[3] = 2 + 1 + 2 = 5`。

`dp[3] = 5`，跟题目给出的示例答案完全一致，验证了递推公式和初始化都是对的。可以看到，根节点取在两端（`j=1` 或 `j=3`）的时候各贡献2种结构，根节点取在中间（`j=2`）的时候贡献1种结构，加起来正好是5种。

**复杂度说一下**

时间复杂度：外层循环 `i` 从1到 `n`，内层循环 `j` 从1到 `i`，是双层嵌套循环，总时间复杂度是O(n²)。

空间复杂度：用一个长度为 `n+1` 的一维数组存所有 `dp[i]`，空间复杂度是O(n)。

## 代码

### C++

```cpp
class Solution {
public:
    int numTrees(int n) {
        vector<int> dp(n + 1, 0); // dp[i]：i个节点能构成的不同BST种数
        dp[0] = 1; // 空树是一种合法结构，是递推的关键初始值
        for (int i = 1; i <= n; i++) {
            for (int j = 1; j <= i; j++) {
                // 递推：枚举根节点j，左子树(j-1个节点)与右子树(i-j个节点)的结构数相乘，
                // 再对所有根节点选择求和，得到i个节点的总结构数
                dp[i] += dp[j - 1] * dp[i - j];
            }
        }
        return dp[n];
    }
};
```

### Java

```java
class Solution {
    public int numTrees(int n) {
        int[] dp = new int[n + 1]; // dp[i]：i个节点能构成的不同BST种数
        dp[0] = 1; // 空树算一种合法结构，保证j取边界值时递推公式仍然成立
        for (int i = 1; i <= n; i++) {
            for (int j = 1; j <= i; j++) {
                // 核心递推：以j为根，左子树dp[j-1]种结构 × 右子树dp[i-j]种结构，
                // 累加所有可能的根节点选择j，得到总的结构数
                dp[i] += dp[j - 1] * dp[i - j];
            }
        }
        return dp[n];
    }
}
```

### Python

```python
class Solution:
    def numTrees(self, n: int) -> int:
        dp = [0] * (n + 1)  # dp[i]：i个节点能构成的不同BST种数
        dp[0] = 1  # 空树是一种合法结构，递推公式在j取1或i时需要用到dp[0]

        for i in range(1, n + 1):
            for j in range(1, i + 1):
                # 递推公式：以j为根节点，左子树有dp[j-1]种结构，右子树有dp[i-j]种结构，
                # 两者独立组合(相乘)，再对所有根节点位置j求和
                dp[i] += dp[j - 1] * dp[i - j]

        return dp[n]
```

## 总结

- `dp[i]` 只跟节点数量相关，跟具体数值没关系，这是因为BST的结构完全由元素间的相对大小关系决定，这个观察是这道题能用一维dp求解的前提。
- 递推的核心技巧是"枚举根节点 j，左子树 `dp[j-1]` 与右子树 `dp[i-j]` 相乘再对所有j求和"，这跟"整数拆分"那题"枚举拆分点"的思路结构上非常相似，都是把大问题拆成两个独立子问题再组合。
- `dp[0] = 1` 是这道题初始化的关键难点，代表"空子树"是一种合法且唯一的结构，缺少这个初始值会导致根节点取在两端时的情形被错误地算成0。
- 这个递推公式本质上就是卡特兰数的构造性推导，通过DP的视角可以更直观地理解卡特兰数背后的组合意义，不需要死记公式。
