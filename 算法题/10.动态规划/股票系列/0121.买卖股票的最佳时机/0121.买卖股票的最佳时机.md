# 121. 买卖股票的最佳时机

**题目描述**

给定一个数组 `prices`，其中 `prices[i]` 表示某支股票第 `i` 天的价格。规定只能进行一次买入和一次卖出（必须先买后卖，即卖出的那一天一定在买入的那一天之后），求能获得的最大利润。如果无法获利，返回 0。

```
示例：
输入: prices = [7,1,5,3,6,4]
输出: 5
解释: 第 2 天（价格 = 1）买入，第 5 天（价格 = 6）卖出，利润 = 6 - 1 = 5。
```

## 思路

你想啊，这题其实是整个"股票系列"DP 的起点，后面一大堆变体题都是在这个基础模型上加条件。所以我这里不打算只背公式，而是把状态机这套思路讲透。

**1. 确定 dp 数组（状态）的含义**

先想动作：买卖股票，说白了核心动作就两个——买入、卖出。那任意一天结束的时候，你手上的持股状态其实只有两种可能：手里"持有"着股票，或者手里"不持有"股票。所以我就定义两个状态：

- `dp[i][0]`：第 `i` 天结束时处于"持有股票"状态，此时手上现金的最大值
- `dp[i][1]`：第 `i` 天结束时处于"不持有股票"状态，此时手上现金的最大值

这里"手上现金"你可以理解成一个相对的量，就是说"如果这一刻把所有持仓都清算掉，账户里能有多少钱"——买入会让这个数变小，因为花钱了嘛；卖出会让它变大，因为收钱了。那最终答案是什么？就是 `dp[n-1][1]`，也就是最后一天不持有股票时的现金，这个一定是全局最优的，为什么呢？因为你持有股票状态下的钱还没变现，不可能比卖出后更大。

**2. 确定递推公式**

先看第 `i` 天"持有"的状态是怎么来的，其实只有两种情况：

- 昨天就已经持有了，今天啥也不干，延续昨天的现金：`dp[i-1][0]`
- 昨天不持有，今天买入。这里的关键是，因为本题只允许买卖一次，所以"今天买入"就意味着这是唯一一次买入机会，账户在这之前没有任何交易利润可用，买入前的现金就当作 0，买入之后现金就变成 `-prices[i]`

两种情况取较大值：

```
dp[i][0] = max(dp[i-1][0], -prices[i])
```

那第 `i` 天"不持有"的状态呢，同样也是两种情况来的：

- 昨天就不持有，今天啥也不干：`dp[i-1][1]`
- 昨天持有，今天卖出，现金增加 `prices[i]`：`dp[i-1][0] + prices[i]`

同样取较大值：

```
dp[i][1] = max(dp[i-1][1], dp[i-1][0] + prices[i])
```

这两条公式里有个点我要提一下："不持有"这条递推式，在后面几道股票题里基本不会变，因为卖出这个逻辑本身是一样的。真正决定题目之间差异的，是"持有"状态里买入那一项怎么写——本题固定用 `-prices[i]`，是因为只能买一次，买入之前的基准现金永远锁定在 0，这一点等我讲到 122 题的时候对比一下会更清楚。

**3. 确定初始化**

第 0 天（下标从 0 开始），怎么初始化呢：

- `dp[0][0] = -prices[0]`：意思是第一天就买入，花掉 `prices[0]`
- `dp[0][1] = 0`：第一天不买，现金就是 0（这里不能是负数，也不能凭空产生利润，这个很好理解）

**4. 确定遍历顺序**

因为 `dp[i]` 只依赖前一天的 `dp[i-1]`，所以从前往后遍历就行了，`i` 从 1 遍历到 `n-1`。

**5. 举例推导 dp 数组**

那我拿 `prices = [7,1,5,3,6,4]` 这个例子手推一遍：

| i | prices[i] | dp[i][0]（持有） | dp[i][1]（不持有） |
|---|---|---|---|
| 0 | 7 | -7 | 0 |
| 1 | 1 | max(-7, -1) = -1 | max(0, -7+1) = 0 |
| 2 | 5 | max(-1, -5) = -1 | max(0, -1+5) = 4 |
| 3 | 3 | max(-1, -3) = -1 | max(4, -1+3) = 4 |
| 4 | 6 | max(-1, -6) = -1 | max(4, -1+6) = 5 |
| 5 | 4 | max(-1, -4) = -1 | max(5, -1+4) = 5 |

最终 `dp[5][1] = 5`，对应第 2 天（价格 1）买入、第 5 天（价格 6）卖出，利润 5，跟预期是一致的。你观察一下 `dp[i][0]` 这一列会发现个有意思的现象：一旦在价格 1 处买入，后续它会一直保持 -1，为什么呢？因为再也找不到更低的买入点了，这其实就是"只能买一次"在数值上的直观体现。

**复杂度分析**

- 时间复杂度：O(n)，只需遍历一次数组
- 空间复杂度：O(n)（用滚动变量优化后可以做到 O(1)，因为 `dp[i]` 只依赖 `dp[i-1]`）

**与贪心解法的对比**

这道题其实还有一个经典的贪心解法：维护一个"历史最低价" `minPrice`，遍历过程中每天算一下"如果今天卖出"的利润 `prices[i] - minPrice`，用它去更新答案的最大值，同时把 `minPrice = min(minPrice, prices[i])` 也更新一下。

说白了，贪心解法和 DP 解法本质上是等价的——贪心里的 `minPrice`，其实就是 `dp[i][0]` 取相反数后的极限情况（因为只能买一次，最优买入点必然是历史最低点），贪心里"今天卖出的利润"对应的正是 `dp[i-1][0] + prices[i]` 这一项。贪心写起来确实更短更直观，但它是依赖"只能交易一次"这个特殊条件才能简化成"只跟踪最低价"的；一旦交易次数变多了，比如后面的 122、123 题，单纯维护一个最低价就不够用了，得靠状态机 DP 来处理更复杂的状态转移。所以你理解状态机 DP 的意义在哪呢？它是一个能随着交易规则变化而自然扩展的通用框架，贪心只是本题这个特殊场景下的简化产物而已。这也是我为什么这里重点讲 DP 思路而不是贪心——后面几道题基本都是在 `dp[i][0]`/`dp[i][1]` 这套状态定义上做扩展。

## 代码

### C++

```cpp
class Solution {
public:
    int maxProfit(vector<int>& prices) {
        int n = prices.size();
        if (n == 0) return 0;
        vector<vector<int>> dp(n, vector<int>(2, 0)); // dp[i][0]持有 dp[i][1]不持有
        dp[0][0] = -prices[0]; // 第一天买入，花掉本金
        dp[0][1] = 0;          // 第一天不买，现金为0
        for (int i = 1; i < n; i++) {
            // 持有：昨天已持有 或 今天从0基准买入（只能买一次）
            dp[i][0] = max(dp[i - 1][0], -prices[i]);
            // 不持有：昨天已不持有 或 今天卖出昨天持有的股票
            dp[i][1] = max(dp[i - 1][1], dp[i - 1][0] + prices[i]);
        }
        return dp[n - 1][1]; // 最后一天不持有状态即为最大利润
    }
};
```

### Java

```java
class Solution {
    public int maxProfit(int[] prices) {
        int n = prices.length;
        if (n == 0) return 0;
        int[][] dp = new int[n][2]; // dp[i][0]持有 dp[i][1]不持有
        dp[0][0] = -prices[0]; // 第一天买入
        dp[0][1] = 0;          // 第一天不买
        for (int i = 1; i < n; i++) {
            // 持有：延续昨天 或 今天以0为基准买入
            dp[i][0] = Math.max(dp[i - 1][0], -prices[i]);
            // 不持有：延续昨天 或 今天卖出
            dp[i][1] = Math.max(dp[i - 1][1], dp[i - 1][0] + prices[i]);
        }
        return dp[n - 1][1]; // 全局最大利润
    }
}
```

### Python

```python
class Solution:
    def maxProfit(self, prices: list[int]) -> int:
        n = len(prices)
        if n == 0:
            return 0
        # dp[0]表示持有状态现金，dp[1]表示不持有状态现金
        dp0, dp1 = -prices[0], 0  # 第一天买入 / 第一天不买
        for i in range(1, n):
            # 持有：延续昨天持有 或 今天以0基准买入（只能买一次）
            new_dp0 = max(dp0, -prices[i])
            # 不持有：延续昨天不持有 或 今天用昨天的持有状态卖出
            new_dp1 = max(dp1, dp0 + prices[i])
            dp0, dp1 = new_dp0, new_dp1  # 滚动更新，省去二维数组
        return dp1  # 最终不持有状态即最大利润
```

### Go

```go
func maxProfit(prices []int) int {
    n := len(prices)
    if n == 0 {
        return 0
    }
    dp0, dp1 := -prices[0], 0 // dp0持有 dp1不持有，第一天初始化
    for i := 1; i < n; i++ {
        // 持有：延续昨天 或 以0为基准今天买入
        newDp0 := max(dp0, -prices[i])
        // 不持有：延续昨天 或 今天卖出昨天持有的股票
        newDp1 := max(dp1, dp0+prices[i])
        dp0, dp1 = newDp0, newDp1 // 滚动更新
    }
    return dp1 // 最大利润
}

func max(a, b int) int {
    if a > b {
        return a
    }
    return b
}
```

## 总结

- 状态机 DP 最关键的第一步，就是想清楚"状态"到底是什么：本题只有"持有/不持有"两种，用 `dp[i][0]`、`dp[i][1]` 分别表示，之后所有股票系列题基本都是在这个基础上加状态维度。
- 递推公式的核心思路是"今天的状态是从昨天的哪些状态转移过来的"：持有来自"延续持有"或者"买入"，不持有来自"延续不持有"或者"卖出"，这套转移逻辑是通用的。
- 本题"只能买一次"体现在哪呢？就体现在买入公式里用的是固定基准 `-prices[i]`，而不是"昨天不持有的现金 - prices[i]"，这是跟 122 题最本质的区别，也是你判断一道股票题属于哪种子类型的关键线索。
- 贪心解法（维护历史最低价）在这道题上和 DP 是等价的，但说到底它只是个特例简化，状态机 DP 才是真正能推广到多次交易、限次交易、含手续费等各种变体的通用框架。
