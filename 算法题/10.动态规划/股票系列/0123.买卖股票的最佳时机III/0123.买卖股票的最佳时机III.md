# 123. 买卖股票的最佳时机 III

**题目描述**

给定一个数组 `prices`，其中 `prices[i]` 表示某支股票第 `i` 天的价格。最多可以完成两笔交易（可以不用完两次机会，也可以只交易 0 次或 1 次），求能获得的最大利润。注意：必须在再次购买前出售掉之前的股票。

```
示例：
输入: prices = [3,3,5,0,0,3,1,4]
输出: 6
解释: 第4天（价格=0）买入，第6天（价格=3）卖出，利润3；第7天（价格=1）买入，第8天（价格=4）卖出，利润3。总利润 = 3 + 3 = 6。
```

## 思路

状态 DP：`b1、s1、b2、s2` 为至多两次交易的买入／卖出状态。初值 `b1=b2=-prices[0]、s1=s2=0`，每天用旧值更新：

`b1'=max(b1,-p)`；`s1'=max(s1,b1+p)`；`b2'=max(b2,s1-p)`；`s2'=max(s2,b2+p)`。

返回 `s2`，覆盖 0～2 次交易。时间 O(n)，滚动空间 O(1)，完整状态表 O(n)。

# 依赖说明：len：Python 内置函数：返回容器中元素的数量。；range：Python 内置函数：生成按步长遍历的整数序列。

class Solution:
    # 方法：maxProfit；按题目要求处理输入并返回结果，核心算法见方法体。
    def maxProfit(self, prices: list[int]) -> int:
        n = len(prices)
        if n == 0:
            return 0
        # 5个状态：0无操作 1第一次持有 2第一次不持有 3第二次持有 4第二次不持有
        dp0, dp1, dp2, dp3, dp4 = 0, -prices[0], 0, -prices[0], 0
        for i in range(1, n):
            # dp0恒为0，无需更新
            new_dp1 = max(dp1, dp0 - prices[i])   # 延续 或 从无操作买入
            new_dp2 = max(dp2, dp1 + prices[i])   # 延续 或 第一次卖出
            new_dp3 = max(dp3, dp2 - prices[i])   # 延续 或 站在第一次利润上买入
            new_dp4 = max(dp4, dp3 + prices[i])   # 延续 或 第二次卖出
            dp1, dp2, dp3, dp4 = new_dp1, new_dp2, new_dp3, new_dp4  # 滚动更新
        return dp4  # 覆盖0/1/2次交易的最优解```

## C++

### LeetCode 写法与原有示例

```cpp
class Solution {
public:
    // 方法：maxProfit；按题目要求处理输入并返回结果，核心算法见方法体。
    int maxProfit(vector<int>& prices) {
        int n = prices.size();
        if (n == 0) return 0;
        vector<vector<int>> dp(n, vector<int>(5, 0));
        dp[0][0] = 0;             // 无操作
        dp[0][1] = -prices[0];    // 第一次持有：第一天买入
        dp[0][2] = 0;             // 第一次不持有：还未发生买卖
        dp[0][3] = -prices[0];    // 第二次持有：占位初始值，不影响正确路径
        dp[0][4] = 0;             // 第二次不持有：还未发生买卖
        for (int i = 1; i < n; i++) {
            dp[i][0] = dp[i - 1][0]; // 无操作恒为0
            // 第一次持有：延续 或 从无操作状态今天买入（基准0）
            dp[i][1] = max(dp[i - 1][1], dp[i - 1][0] - prices[i]);
            // 第一次不持有：延续 或 从第一次持有卖出
            dp[i][2] = max(dp[i - 1][2], dp[i - 1][1] + prices[i]);
            // 第二次持有：延续 或 站在第一次已实现的利润上今天再买入
            dp[i][3] = max(dp[i - 1][3], dp[i - 1][2] - prices[i]);
            // 第二次不持有：延续 或 从第二次持有卖出
            dp[i][4] = max(dp[i - 1][4], dp[i - 1][3] + prices[i]);
        }
        return dp[n - 1][4]; // 状态编号最大，覆盖0/1/2次交易的最优解
    }
};
```

## 总结

- 本题的核心突破在于状态维度的扩展：从 121/122 题的 2 种状态（持有/不持有）扩展为 5 种（无操作、第一次持有、第一次不持有、第二次持有、第二次不持有），因为"最多两次交易"这个约束要求区分"这是第几次买卖"。
- 状态转移的规律是单向递进的链条：持有状态（1、3）只能来自"前一个不持有状态"买入转移，不持有状态（2、4）只能来自"前一个持有状态"卖出转移，操作次数不会倒退。
- 状态 3 的买入基准是 `dp[i-1][2]` 而不是 0，这跟 122 题"买入基准滚动"的道理是完全一致的——只要买入前已经有过交易利润，就应该站在这笔利润上出发，而不是回到 0。
- 最终答案取 `dp[n-1][4]`（编号最大的状态）就能覆盖交易 0/1/2 次的所有情况，因为每个状态的递推都包含"延续前一状态"这一项，保证了状态编号越大数值不会更小；这个"取最大编号状态即为答案"的结论，在后面 188 题（最多 k 次交易）中会以同样的方式推广为 `dp[n-1][2k]`。
