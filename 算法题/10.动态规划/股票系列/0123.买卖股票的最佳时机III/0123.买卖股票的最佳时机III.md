# 123. 买卖股票的最佳时机 III

**题目描述**

给定一个数组 `prices`，其中 `prices[i]` 表示某支股票第 `i` 天的价格。最多可以完成两笔交易（可以不用完两次机会，也可以只交易 0 次或 1 次），求能获得的最大利润。注意：必须在再次购买前出售掉之前的股票。

```
示例：
输入: prices = [3,3,5,0,0,3,1,4]
输出: 6
解释: 第4天（价格=0）买入，第6天（价格=3）卖出，利润3；第7天（价格=1）买入，第8天（价格=4）卖出，利润3。总利润 = 3 + 3 = 6。
```

## 思路

你想啊，这道题其实是状态机 DP"维度扩展"的典型代表。121、122 两题都只用"持有/不持有"两种状态就能描述局面，但本题限定了"最多两次交易"，这时候光靠"持有/不持有"就区分不了"这是第一次持有还是第二次持有"了——而这两者在后续能否再买入这件事上，意义完全不同。所以这里的关键是，本题必须在状态里新增一个"这是第几次交易"的维度。

**1. 确定 dp 数组（状态）的含义**

我把每一天的局面细分成 5 种状态，用 `dp[i][j]`（`j` 取 0~4）表示第 `i` 天结束时处于状态 `j` 时手上现金的最大值：

- `j = 0`：无操作（从未进行过任何买卖）
- `j = 1`：第一次持有股票
- `j = 2`：第一次不持有股票（已经完成了第一次完整的买卖）
- `j = 3`：第二次持有股票
- `j = 4`：第二次不持有股票（已经完成了第二次完整的买卖）

为什么要把"持有"和"不持有"各分成两组（第一次/第二次）呢？因为"第一次持有"和"第二次持有"虽然都是"手里有股票"，但它们能转移到的下一个状态完全不同：第一次持有卖出后进入状态 2，第二次持有卖出后进入状态 4，两者不能混用同一个变量，不然递推的时候会分不清"这次卖出是完成第几笔交易"。

**2. 确定递推公式**

先明确一个大前提：状态编号越大，代表"操作越多"，而操作数是单调不减的，不会倒退。因此每个状态 `dp[i][j]` 只能来自"昨天同一个状态延续"或者"昨天上一个状态转移过来"这两种情况，取较大值。

我逐条讲清楚：

- **状态 0（无操作）**：

  ```
  dp[i][0] = dp[i-1][0]
  ```

  无操作状态下现金永远是 0，不会发生任何变化，所以严格来说这一项甚至不需要写递推式，直接在初始化时定为 0、之后每天保持不变就行。之所以还列出来，是为了让 5 个状态的递推逻辑保持形式上的统一。

- **状态 1（第一次持有）**：

  ```
  dp[i][1] = max(dp[i-1][1], dp[i-1][0] - prices[i])
  ```

  今天处于"第一次持有"，要么是延续昨天已经持有的状态（`dp[i-1][1]`），要么是昨天还处于"无操作"状态，今天第一次买入，花掉 `prices[i]`，基准是 `dp[i-1][0]`，也就是 0。这一条和 121 题的买入公式是同构的——本质上都是"从上一个未持有过的基准状态买入"，因为这是全局第一次买入，没有之前的交易利润可用。

- **状态 2（第一次不持有）**：

  ```
  dp[i][2] = max(dp[i-1][2], dp[i-1][1] + prices[i])
  ```

  今天处于"第一次不持有"（已完成第一次买卖），要么延续昨天已经卖出的状态，要么昨天还处于"第一次持有"，今天卖出，现金增加 `prices[i]`。这一条和 121/122 题里"不持有"的公式结构是一致的：延续或卖出。

- **状态 3（第二次持有）**：

  ```
  dp[i][3] = max(dp[i-1][3], dp[i-1][2] - prices[i])
  ```

  今天处于"第二次持有"，要么延续昨天已经持有的状态，要么昨天处于"第一次不持有"，也就是已经完成一次买卖、手上有之前攒下的利润，今天用这笔利润再次买入。你注意这里的买入基准是 `dp[i-1][2]`，不是 0——这正好和 122 题"买入基准是滚动的 dp[i-1][1]"是同一个道理：只要"买入前已经有过交易"，买入的本金就应该是"之前交易积累的现金"，而不是重新从 0 开始。

- **状态 4（第二次不持有）**：

  ```
  dp[i][4] = max(dp[i-1][4], dp[i-1][3] + prices[i])
  ```

  今天处于"第二次不持有"（已完成第二次买卖），要么延续昨天已经卖出的状态，要么昨天处于"第二次持有"，今天卖出。

**3. 状态转移图（文字描述）**

我把 5 个状态按"操作次数"从左到右排列：`0 → 1 → 2 → 3 → 4`。你能观察到一个很清晰的规律：

- 状态 1 和状态 3 都是"持有"状态，它们只能由"前一个不持有状态"转移而来（状态 1 来自状态 0，状态 3 来自状态 2），转移方式是"减去今天的股价"，也就是花钱买入。
- 状态 2 和状态 4 都是"不持有"状态，它们只能由"前一个持有状态"转移而来（状态 2 来自状态 1，状态 4 来自状态 3），转移方式是"加上今天的股价"，也就是收钱卖出。
- 每个状态还都可以"原地不动"，也就是延续昨天的同一个状态（今天不做任何操作）。

画成箭头就是：

```
状态0 --(买入,-price)--> 状态1 --(卖出,+price)--> 状态2 --(买入,-price)--> 状态3 --(卖出,+price)--> 状态4
  |                        |                        |                        |                        |
  └──(不动)────────────────┘                        └──(不动)────────────────┘                        │
  （0自身也可以不动，但恒为0，不影响）                                                                    └──(不动)
```

你能看到，整条链路是"单向递进"的：持有状态只能从"前一个更靠左的不持有状态"或者"自身延续"转移过来，绝不会从"更靠右的状态"倒退回来，因为操作次数不会减少。这也是为什么递推公式里，每个状态只引用 `dp[i-1][j]` 和 `dp[i-1][j-1]` 这两项，而不会引用 `dp[i-1][j+1]`。

**4. 确定初始化**

第 0 天，怎么初始化呢：

- `dp[0][0] = 0`：无操作，现金为 0
- `dp[0][1] = -prices[0]`：第一天买入，第一次持有
- `dp[0][2] = 0`：第一天不可能已经完成一次买卖，所以"第一次不持有"只能是"还没买卖过"，现金为 0
- `dp[0][3] = -prices[0]`：第一天理论上是不可能完成"第二次持有"的（需要先完成第一次买卖），但为了让递推公式在 `i=1` 时不出错，我把它初始化为 `-prices[0]`——这个初始值不会影响最终结果，为什么呢？因为要真正走到状态 3，必须先经过状态 2，而状态 2 在第 0 天是 0，第 1 天状态 3 的递推会自动通过 `dp[0][2] - prices[1]` 这条路径取到正确的值，`dp[0][3]` 只是一个占位值，只要不比正确路径更优就行（这里取 `-prices[0]` 是常见写法，也可以理解为"假设当天完成两次买卖是不可能的，但数值上不会导致错误的最大值被选中"）
- `dp[0][4] = 0`：同理，第一天不可能完成两次买卖，现金为 0

**5. 确定遍历顺序**

`dp[i]` 只依赖 `dp[i-1]`，那就从前往后遍历，`i` 从 1 到 `n-1`。同一天内，状态 1~4 的计算顺序不影响结果，因为它们都只读取"昨天"的数组，不会互相干扰。

**6. 举例推导 dp 数组**

我拿 `prices = [3,3,5,0,0,3,1,4]` 这个例子，只展示关键几天的计算过程（篇幅原因，完整过程你可以自己按公式补全）：

初始化（i=0，price=3）：`dp[0] = [0, -3, 0, -3, 0]`

i=1（price=3）：
- `dp[1][1] = max(-3, 0-3) = -3`
- `dp[1][2] = max(0, -3+3) = 0`
- `dp[1][3] = max(-3, 0-3) = -3`
- `dp[1][4] = max(0, -3+3) = 0`

i=3（price=0，此时能看到关键买入点）：
- 假设 `dp[2] = [0, -3, 2, -3, 2]`（i=2, price=5 时 `dp[2][2]=max(0,-3+5)=2`）
- `dp[3][1] = max(-3, 0-0) = 0`（第一次持有，今天以更好的价格 0 重新买入）
- `dp[3][3] = max(-3, 2-0) = 2`（第二次持有，站在第一次已赚到的利润 2 上再买入，花费 0，现金仍是 2）

一路推到最后一天（i=7，price=4）：`dp[7][4]` 应该是 6，跟题目预期一致。你可以直观感受到：状态 3、4 的数值始终"站在状态 2 已经积累的利润基础上"继续滚动，这正是"两次交易利润可以叠加"的数值体现。

**最终答案**

答案是 `dp[n-1][4]`，也就是最后一天"第二次不持有"状态下的现金。这里有一个需要讲清楚的细节：为什么不需要比较 `dp[n-1][0]`、`dp[n-1][2]` 等其他状态，直接取 `dp[n-1][4]` 就是全局最优呢？原因是"多操作不会让结果变差"——`dp[i][j]` 的递推公式里都包含"延续昨天同状态"这一项，这就保证了状态编号越大的 `dp` 值，在数值上一定不会小于它前面状态的值（因为它至少可以"不发生新的买卖"而继承前一个状态达到过的最大现金，这个性质通过递推链条逐级传递）。所以 `dp[n-1][4] >= dp[n-1][3] >= dp[n-1][2] >= dp[n-1][1] >= dp[n-1][0] = 0`，取编号最大的状态 4 就能保证覆盖了"进行 0 次、1 次、2 次交易"这三种情况里的最优解。

**复杂度分析**

- 时间复杂度：O(n)，每天更新 5 个状态，仍是线性遍历
- 空间复杂度：O(n × 5)，可用滚动变量优化到 O(5) = O(1)

## 代码

### C++

```cpp
class Solution {
public:
    int maxProfit(vector<int>& prices) {
        int n = prices.size();
        if (n == 0) return 0;
        vector<vector<int>> dp(n, vector<int>(5, 0));
        dp[0][0] = 0;             // 无操作
        dp[0][1] = -prices[0];    // 第一次持有：第一天买入
        dp[0][2] = 0;             // 第一次不持有：还未发生买卖
        dp[0][3] = -prices[0];    // 第二次持有：占位初始值，不影响正确路径
        dp[0][4] = 0;             // 第二次不持有：还未发生买卖
        for (int i = 1; i < n; i++) {
            dp[i][0] = dp[i - 1][0]; // 无操作恒为0
            // 第一次持有：延续 或 从无操作状态今天买入（基准0）
            dp[i][1] = max(dp[i - 1][1], dp[i - 1][0] - prices[i]);
            // 第一次不持有：延续 或 从第一次持有卖出
            dp[i][2] = max(dp[i - 1][2], dp[i - 1][1] + prices[i]);
            // 第二次持有：延续 或 站在第一次已实现的利润上今天再买入
            dp[i][3] = max(dp[i - 1][3], dp[i - 1][2] - prices[i]);
            // 第二次不持有：延续 或 从第二次持有卖出
            dp[i][4] = max(dp[i - 1][4], dp[i - 1][3] + prices[i]);
        }
        return dp[n - 1][4]; // 状态编号最大，覆盖0/1/2次交易的最优解
    }
};
```

### Java

```java
class Solution {
    public int maxProfit(int[] prices) {
        int n = prices.length;
        if (n == 0) return 0;
        int[][] dp = new int[n][5];
        dp[0][0] = 0;
        dp[0][1] = -prices[0]; // 第一次持有
        dp[0][2] = 0;          // 第一次不持有
        dp[0][3] = -prices[0]; // 第二次持有（占位初始值）
        dp[0][4] = 0;          // 第二次不持有
        for (int i = 1; i < n; i++) {
            dp[i][0] = dp[i - 1][0]; // 无操作恒为0
            // 第一次持有：延续 或 从无操作基准买入
            dp[i][1] = Math.max(dp[i - 1][1], dp[i - 1][0] - prices[i]);
            // 第一次不持有：延续 或 卖出
            dp[i][2] = Math.max(dp[i - 1][2], dp[i - 1][1] + prices[i]);
            // 第二次持有：延续 或 站在第一次利润上再买入
            dp[i][3] = Math.max(dp[i - 1][3], dp[i - 1][2] - prices[i]);
            // 第二次不持有：延续 或 卖出
            dp[i][4] = Math.max(dp[i - 1][4], dp[i - 1][3] + prices[i]);
        }
        return dp[n - 1][4];
    }
}
```

### Python

```python
class Solution:
    def maxProfit(self, prices: list[int]) -> int:
        n = len(prices)
        if n == 0:
            return 0
        # 5个状态：0无操作 1第一次持有 2第一次不持有 3第二次持有 4第二次不持有
        dp0, dp1, dp2, dp3, dp4 = 0, -prices[0], 0, -prices[0], 0
        for i in range(1, n):
            # dp0恒为0，无需更新
            new_dp1 = max(dp1, dp0 - prices[i])   # 延续 或 从无操作买入
            new_dp2 = max(dp2, dp1 + prices[i])   # 延续 或 第一次卖出
            new_dp3 = max(dp3, dp2 - prices[i])   # 延续 或 站在第一次利润上买入
            new_dp4 = max(dp4, dp3 + prices[i])   # 延续 或 第二次卖出
            dp1, dp2, dp3, dp4 = new_dp1, new_dp2, new_dp3, new_dp4  # 滚动更新
        return dp4  # 覆盖0/1/2次交易的最优解
```

### Go

```go
func maxProfit(prices []int) int {
    n := len(prices)
    if n == 0 {
        return 0
    }
    // 5个状态：dp0无操作 dp1第一次持有 dp2第一次不持有 dp3第二次持有 dp4第二次不持有
    dp0, dp1, dp2, dp3, dp4 := 0, -prices[0], 0, -prices[0], 0
    for i := 1; i < n; i++ {
        // dp0恒为0
        newDp1 := max(dp1, dp0-prices[i]) // 延续 或 从无操作买入
        newDp2 := max(dp2, dp1+prices[i]) // 延续 或 第一次卖出
        newDp3 := max(dp3, dp2-prices[i]) // 延续 或 站在第一次利润上买入
        newDp4 := max(dp4, dp3+prices[i]) // 延续 或 第二次卖出
        dp1, dp2, dp3, dp4 = newDp1, newDp2, newDp3, newDp4 // 滚动更新
    }
    return dp4 // 覆盖0/1/2次交易的最优解
}

func max(a, b int) int {
    if a > b {
        return a
    }
    return b
}
```

## 总结

- 本题的核心突破在于状态维度的扩展：从 121/122 题的 2 种状态（持有/不持有）扩展为 5 种（无操作、第一次持有、第一次不持有、第二次持有、第二次不持有），因为"最多两次交易"这个约束要求区分"这是第几次买卖"。
- 状态转移的规律是单向递进的链条：持有状态（1、3）只能来自"前一个不持有状态"买入转移，不持有状态（2、4）只能来自"前一个持有状态"卖出转移，操作次数不会倒退。
- 状态 3 的买入基准是 `dp[i-1][2]` 而不是 0，这跟 122 题"买入基准滚动"的道理是完全一致的——只要买入前已经有过交易利润，就应该站在这笔利润上出发，而不是回到 0。
- 最终答案取 `dp[n-1][4]`（编号最大的状态）就能覆盖交易 0/1/2 次的所有情况，因为每个状态的递推都包含"延续前一状态"这一项，保证了状态编号越大数值不会更小；这个"取最大编号状态即为答案"的结论，在后面 188 题（最多 k 次交易）中会以同样的方式推广为 `dp[n-1][2k]`。
