# 188. 买卖股票的最佳时机IV

**题目描述**

给定一个整数数组 `prices`，其中 `prices[i]` 表示某支股票第 `i` 天的价格，再给定一个整数 `k`，最多可以完成 `k` 次交易（一次买入加一次卖出算一次交易，且必须先卖出手头持有的股票才能再次买入），求能获得的最大利润。

```
示例：
输入: k = 2, prices = [3,2,6,5,0,3]
输出: 7
解释: 在第 2 天（价格 = 2）买入，第 3 天（价格 = 6）卖出，利润 = 6-2 = 4。
     随后，在第 5 天（价格 = 0）买入，第 6 天（价格 = 3）卖出，利润 = 3-0 = 3。
     总利润 4+3 = 7。
```

## 思路

状态 DP：0 为无操作；奇数状态表示买入后持有，偶数表示卖出后不持有，共 `2k+1` 个。奇数初值 `-prices[0]`，偶数初值 0。

每日按状态递增更新：奇数 `dp[j]=max(dp[j],dp[j-1]-price)`，偶数改为加价格。返回 `dp[2k]`，表示至多 `k` 次交易；同日买卖收益为 0，不改变最优值。

时间 O(nk)，滚动空间 O(k)，完整状态表 O(nk)。

# 依赖说明：len：Python 内置函数：返回容器中元素的数量。；range：Python 内置函数：生成按步长遍历的整数序列。；max：Python 内置函数：返回最大值。

# 依赖说明：len：Python 内置函数：返回容器中元素的数量。；range：Python 内置函数：生成按步长遍历的整数序列。

class Solution:
    # 方法：maxProfit；按题目要求处理输入并返回结果，核心算法见方法体。
    def maxProfit(self, k: int, prices: list[int]) -> int:
        n = len(prices)
        if n == 0 or k == 0:
            return 0
        # dp[j]：滚动数组，表示当前天处于状态j的最大现金，状态数2k+1个
        dp = [0] * (2 * k + 1)
        for j in range(1, 2 * k + 1):
            if j % 2 == 1:
                dp[j] = -prices[0]  # 奇数位：第0天买入的唯一本金基准
            else:
                dp[j] = 0  # 偶数位：第0天不可能完成一次交易

        for i in range(1, n):
            for j in range(1, 2 * k + 1):
                if j % 2 == 1:
                    # 持有：延续昨天 或 从上一状态(j-1)买入
                    dp[j] = max(dp[j], dp[j - 1] - prices[i])
                else:
                    # 卖出：延续昨天 或 从上一状态(j-1)持有中卖出
                    dp[j] = max(dp[j], dp[j - 1] + prices[i])
        return dp[2 * k]  # 用完k次交易机会对应的最大利润
```


注意 Python 版本这里用同一个 `dp` 数组原地更新，因为循环内 `dp[j-1]` 用到的是"本轮循环中已经被更新过的 `j-1`"，而不是上一天的旧值——这一点和 C++/Java 的二维写法不同，是刻意利用了"买入用的是同一天里前一个状态刚更新出的现金"这个特性（等价于把同一天内的一次交易看作可以连续发生），能得到相同的最终结果，因为买入操作里"上一状态"的现金只会因为当天卖出而变大，用当天更新后的值不会让答案变差，反而更贴近"同一天内可以连续买卖"的直觉。

// 方法：maxProfit；按题目要求处理输入并返回结果，核心算法见方法体。
func maxProfit(k int, prices []int) int {
    n := len(prices)
    if n == 0 || k == 0 {
        return 0
    }
    // dp[j]：滚动数组，当前天处于状态j的最大现金，状态数2k+1个
    dp := make([]int, 2*k+1)
    for j := 1; j <= 2*k; j++ {
        if j%2 == 1 {
            dp[j] = -prices[0] // 奇数位：第0天买入的唯一本金基准
        } else {
            dp[j] = 0 // 偶数位：第0天不可能完成一次交易
        }
    }
    for i := 1; i < n; i++ {
        for j := 1; j <= 2*k; j++ {
            if j%2 == 1 {
                // 持有：延续昨天 或 从上一状态买入
                if v := dp[j-1] - prices[i]; v > dp[j] {
                    dp[j] = v
                }
            } else {
                // 卖出：延续昨天 或 从上一状态（持有）卖出
                if v := dp[j-1] + prices[i]; v > dp[j] {
                    dp[j] = v
                }
            }
        }
    }
    return dp[2*k] // 最多k次交易下的最大利润
}
```

## C++

### LeetCode 写法与原有示例

```cpp
// 依赖说明：vector：C++ STL 动态数组。

class Solution {
public:
    // 方法：maxProfit；按题目要求处理输入并返回结果，核心算法见方法体。
    int maxProfit(int k, vector<int>& prices) {
        int n = prices.size();
        if (n == 0 || k == 0) return 0;
        // dp[i][j]：第i天处于状态j的最大现金，状态数为2k+1个
        vector<vector<int>> dp(n, vector<int>(2 * k + 1, 0));
        // 初始化第0天：所有奇数位（持有）本金只能是-prices[0]，偶数位（卖出）为0
        for (int j = 1; j <= 2 * k; j++) {
            if (j % 2 == 1) {
                dp[0][j] = -prices[0]; // 第0天买入，唯一本金基准
            } else {
                dp[0][j] = 0; // 第0天不可能完成买入又卖出
            }
        }
        for (int i = 1; i < n; i++) {
            for (int j = 1; j <= 2 * k; j++) {
                if (j % 2 == 1) {
                    // 奇数位：持有状态，延续昨天持有，或从上一状态(j-1)买入
                    dp[i][j] = max(dp[i - 1][j], dp[i - 1][j - 1] - prices[i]);
                } else {
                    // 偶数位：卖出状态，延续昨天卖出，或从上一状态(j-1)持有中卖出
                    dp[i][j] = max(dp[i - 1][j], dp[i - 1][j - 1] + prices[i]);
                }
            }
        }
        return dp[n - 1][2 * k]; // 用完k次交易机会的最终状态即为最大利润
    }
};```

## 总结

- 188 题是 123 题的通用化：123 题因为 `k=2` 固定，可以把 5 个状态手写展开成 5 行递推式；188 题的 `k` 是变量，状态数 `2k+1` 只能在运行时确定，因此必须把"逐个枚举状态"这一步从人工硬编码升级为循环遍历 `j`，这是同一套状态机思想在工程实现上的抽象。
- 递推公式按 `j` 的奇偶性统一处理：奇数位（持有）从"上一状态买入"或"延续持有"转移，偶数位（卖出）从"上一状态卖出"或"延续卖出"转移，这个"奇偶对应持有/卖出"的编码方式是本题可以用循环表达任意 `k` 的关键设计。
- 初始化时要注意所有奇数位在第 0 天的本金基准统一是 `-prices[0]`，因为不管这是第几次交易的"持有"，第 0 天能用的钱都只能来自当天的价格，此前不可能有任何利润积累。
- 空间复杂度可以从 O(n·k) 压缩到 O(k)，用滚动数组滚动更新即可，这与 121/122 题里的滚动变量优化是同一个思路的扩展。
