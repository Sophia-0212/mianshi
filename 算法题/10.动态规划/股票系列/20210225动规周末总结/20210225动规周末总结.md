# 20210225动规周末总结

## 思路

这周把打家劫舍系列（198、213、337）刷完了，你会发现这三题表面上都是"不能选相邻元素求最大和"，但放一起看会看出一条很清晰的演进路线：DP 处理的数据结构从"一维线性结构"逐步推广到了"环形结构"，再到"树形结构"，而这条路线背后真正在变化的，说白了就是"状态定义"这一步的复杂程度。

**198题：线性结构，状态定义最朴素**

198 是最基础的版本，房子排成一排，`dp[i]` 表示"考虑前 `i` 间房，能偷到的最大金额"。递推公式很直接：`dp[i] = max(dp[i-1], dp[i-2] + nums[i])`——你想啊，今天这间房要么不偷（延续 `dp[i-1]`），要么偷（那昨天必须不偷，所以是 `dp[i-2] + nums[i]`）。这里状态定义只是一个一维数组，"状态"里没有额外的维度信息，为什么呢？因为线性排列的房子只有"偷不偷当前这间"一个决策点。

**213题：环形结构，状态定义没变，但多了一次"拆解"**

213 把房子首尾相连成一个环，直接套 198 的做法会有一个问题：`dp` 递推没法同时保证"不偷第一间"和"不偷最后一间"（因为环形相邻，首尾也算相邻）。213 的关键技巧不是改变状态定义本身，而是先对"输入"做一次分类讨论：把环形问题拆成两个线性子问题——"考虑 [0, n-2] 区间"和"考虑 [1, n-1] 区间"，分别用 198 的方法算一遍，取较大值。这一步的启发是：遇到环形约束时，如果状态定义很难直接表达"首尾不能同时选"这个条件，你可以尝试从问题输入的角度切一刀，把环形拆成若干个线性问题，复用已有的线性 DP。这其实是一种"结构降维"的技巧，而不是状态定义本身的升级。

**337题：树形结构，状态定义第一次真正变复杂**

337 把房子换成一棵二叉树，节点之间的"相邻"变成了"父子关系"。这时候线性 DP 的下标递推方式（`dp[i]` 依赖 `dp[i-1]`、`dp[i-2]`）已经完全不适用了，为什么呢？因为树不是线性顺序，一个节点的"前驱"是不确定数量的子节点。这时状态定义必须发生质变：不能再用一个单纯的数值 `dp[i]`，而要在每个节点上维护一个"状态数组"——`dp[node] = [不偷这个节点的最大值, 偷这个节点的最大值]`。也就是说，状态定义从"一维数组"变成了"每个节点对应一个二维小数组"，递推方式也从"跟前面的下标做比较"变成了"从子节点的状态数组向上合并到父节点"（后序遍历，先算子节点再算父节点）。

三题串起来看，能看到一条明显的推广逻辑："状态定义的复杂度"是跟着"数据结构的复杂度"一起升级的：线性结构下标序即可表达全部信息，环形结构靠拆解规避特殊约束，树形结构则必须让状态本身"跟着节点走"，每个节点维护一组状态而不是一个数。这其实提示了一个更一般的规律：DP 状态定义不是死记硬背某个模板，而是要问自己"当前问题里，光知道'走到第几步'够不够表达清楚局面"，如果不够（比如树形结构里，光知道"当前节点"不知道"这个节点选不选"，就无法往上合并），就需要在状态里加一个维度去区分不同的"局面"。

**过渡：从"选不选"到"持有状态机"**

这条"状态维度不断增加"的思路，恰好也是下周要开始的股票买卖系列 DP 的核心。打家劫舍系列里状态数组的维度表示的是"选/不选这个节点"，而股票系列里，状态数组的维度 `dp[i][j]` 中的 `j` 会用来表示更丰富的"持有状态"——比如 `j=0/1` 表示"持有/不持有"，如果限制交易次数，`j` 还会进一步细分成"第几次买入/卖出"（比如最多两次交易时 `j` 会扩展到 5 个取值）。这里可以预告一下：接下来的 121、122、123、188、309、714 六道题，本质上都是同一个"状态机 DP"框架的不同参数版本——区别只在于"能交易几次"和"有没有冷冻期/手续费"这些约束如何影响 `j` 的维度设计和递推公式里买入基准的写法。理解了"状态定义随约束复杂度而升级"这条主线，后面这几题就不再是孤立的题目，而是同一个框架在不同参数下的自然展开。

## 总结

- 198（线性）→ 213（环形拆解）→ 337（树形状态数组）这条路线的本质是：DP 状态定义的复杂度要跟着数据结构和约束条件的复杂度同步升级，而不是套固定模板。
- 环形结构的处理技巧是"拆解输入、复用线性 DP"，属于问题分解层面的技巧，状态定义本身没有变复杂。
- 树形结构第一次要求状态定义从"一个数"变成"一组数"（每个节点维护多状态数组），递推方式也从"下标顺序"变成"后序遍历、子节点向父节点合并"。
- 这个"状态维度随约束增加"的规律会在股票买卖系列 DP 中延续：用 `dp[i][j]` 的 `j` 维度表示不同的持有/交易状态，是打家劫舍系列思路的自然延伸。
