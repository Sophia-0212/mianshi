# 72. 编辑距离

**题目描述**

给定两个字符串 `word1` 和 `word2`，求将 `word1` 转换成 `word2` 所需的最少操作数。每次操作可以选择以下三种之一：

- 插入一个字符
- 删除一个字符
- 替换一个字符

```
示例：
输入: word1 = "horse", word2 = "ros"
输出: 3
解释: horse -> rorse（替换h为r） -> rose（删除r） -> ros（删除e）
```

## 思路

编辑距离这道题，可以说是子序列、字符串 DP 里最经典、最有代表性的一道难题了，也是"卡尔三步铺垫"——也就是 392 判断子序列、115 不同的子序列、583 删除操作，一路铺到 72 编辑距离——的最终落点。你想啊，前面几题其实分别在练一个小能力：392 练的是怎么用 DP 去表达"匹配"这件事，115 练的是怎么去"计数"，583 练的是怎么把"删除"这个操作用 DP 表达出来。到了这一题，就是要把插入、删除、替换这三种操作全部统一放进同一个递推公式里，可以理解成是前面这条思路链的一次综合大练兵。

**1. 确定 dp 数组以及下标的含义**

先说 dp 数组的含义：`dp[i][j]` 表示的是，把 `word1` 的前 `i` 个字符变成 `word2` 的前 `j` 个字符，最少需要多少次操作。

**2. 确定递推公式**

这一步的关键是分两种情况讨论：`word1[i-1]` 和 `word2[j-1]` 这两个字符，到底相不相等。

**情况一：`word1[i-1] == word2[j-1]`**

如果这两个字符本来就相等，那就完全不用对它做任何操作了，问题自然就退化成了"前 i-1 个字符转换成前 j-1 个字符"这个更小的子问题，所以有：

```
dp[i][j] = dp[i-1][j-1]
```

**情况二：`word1[i-1] != word2[j-1]`**

那如果这两个字符不相等呢？这时候就必须动手做一次操作来消除这个差异了，那具体做哪种操作最划算，就要在三种操作里挑一个代价最小的：

```
dp[i][j] = min(dp[i-1][j], dp[i][j-1], dp[i-1][j-1]) + 1
```

这里边其实是三个分支，分别对应三种操作，我一个个来说：

- **删除**：对应 `dp[i-1][j] + 1`。也就是把 `word1` 的第 `i` 个字符删掉，删掉之后问题就变成了"word1 前 i-1 个字符转换成 word2 前 j 个字符"，那这个子问题的答案再加上这一次删除操作，就是当前这种做法的代价。
- **插入**：对应 `dp[i][j-1] + 1`。这个稍微有点绕，是说在 `word1` 末尾插入一个字符，让它正好等于 `word2[j-1]`。插入之后，`word1` 前 i 个字符加上新插进去的这一个，就刚好匹配上了 `word2` 前 j 个字符，所以问题就变成了"word1 前 i 个字符转换成 word2 前 j-1 个字符"，再加上这一次插入操作。这里有个转换角度要理解一下：插入操作说白了是"给 word1 加字符"，但效果上等价于"word2 这边多出来的那个字符先不用管了，我继续去看 word2 前 j-1 个字符就行"。
- **替换**：对应 `dp[i-1][j-1] + 1`。这个最直接，就是把 `word1[i-1]` 直接换成 `word2[j-1]`，换完之后两个字符就相等了，问题变成"word1 前 i-1 个字符转换成 word2 前 j-1 个字符"，再加上这一次替换操作。

那这三种操作说白了有个共同点：它们都是在花"一次操作"的代价，把原问题缩小成一个更小的子问题，最后取这三者里最小的那个，就是当前状态的最优解。

**3. dp 数组如何初始化**

初始化这一步要怎么想呢？`dp[i][0]` 表示的是把 `word1` 前 `i` 个字符变成空字符串，那这种情况下你只能一直删，删 `i` 次才能删完，所以 `dp[i][0] = i`。

反过来，`dp[0][j]` 表示把空字符串变成 `word2` 前 `j` 个字符，这时候你只能一直插入，插 `j` 次才能插够，所以 `dp[0][j] = j`。

**4. 确定遍历顺序**

遍历顺序这块，就是从上到下、从左到右去遍历 `i` 和 `j`，为什么呢？因为 `dp[i][j]` 要依赖它左边、上边、左上边这三个已经算出来的值，所以必须保证这三个位置先算完。

**5. 举例推导 dp 数组**

拿 `word1 = "horse"`，`word2 = "ros"` 来举个例子（下面是部分表格，行是 word1，列是 word2）：

| dp | "" | r | o | s |
|----|----|---|---|---|
| "" | 0  | 1 | 2 | 3 |
| h  | 1  | 1 | 2 | 3 |
| o  | 2  | 2 | 1 | 2 |
| r  | 3  | 2 | 2 | 2 |
| s  | 4  | 3 | 3 | 2 |
| e  | 5  | 4 | 4 | 3 |

最后推出来 `dp[5][3] = 3`，跟预期输出是对得上的。这里边可以重点看一下 `word1[1]='o'` 和 `word2[1]='o'` 相等的这一格：`dp[2][2] = dp[1][1] = 1`，直接从左上角继承过来，没有做任何额外操作，这就是"字符相等就白嫖左上角"的直观体现。

**复杂度分析**

- 时间复杂度这块，两层循环遍历整张表，是 O(n·m)。
- 空间复杂度上，开了一张 n×m 的二维表，也是 O(n·m)，不过这里可以用滚动数组优化，压到 O(m)。

## 代码

### C++

```cpp
class Solution {
public:
    int minDistance(string word1, string word2) {
        int n = word1.size(), m = word2.size();
        vector<vector<int>> dp(n + 1, vector<int>(m + 1, 0));
        for (int i = 0; i <= n; i++) dp[i][0] = i;  // 转换成空串，需要i次删除
        for (int j = 0; j <= m; j++) dp[0][j] = j;  // 空串转换成目标，需要j次插入

        for (int i = 1; i <= n; i++) {
            for (int j = 1; j <= m; j++) {
                if (word1[i - 1] == word2[j - 1]) {
                    dp[i][j] = dp[i - 1][j - 1];  // 字符相等，不需要操作，直接继承左上角
                } else {
                    dp[i][j] = min({
                        dp[i - 1][j] + 1,      // 删除word1[i-1]
                        dp[i][j - 1] + 1,      // 插入一个字符匹配word2[j-1]
                        dp[i - 1][j - 1] + 1   // 替换word1[i-1]为word2[j-1]
                    });
                }
            }
        }
        return dp[n][m];
    }
};
```

### Java

```java
class Solution {
    public int minDistance(String word1, String word2) {
        int n = word1.length(), m = word2.length();
        int[][] dp = new int[n + 1][m + 1];
        for (int i = 0; i <= n; i++) dp[i][0] = i;  // 删除i次变为空串
        for (int j = 0; j <= m; j++) dp[0][j] = j;  // 插入j次由空串变为目标

        for (int i = 1; i <= n; i++) {
            for (int j = 1; j <= m; j++) {
                if (word1.charAt(i - 1) == word2.charAt(j - 1)) {
                    dp[i][j] = dp[i - 1][j - 1];  // 字符相等，不需要操作
                } else {
                    int del = dp[i - 1][j] + 1;       // 删除
                    int ins = dp[i][j - 1] + 1;       // 插入
                    int rep = dp[i - 1][j - 1] + 1;    // 替换
                    dp[i][j] = Math.min(del, Math.min(ins, rep));
                }
            }
        }
        return dp[n][m];
    }
}
```

```go
func minDistance(word1 string, word2 string) int {
    n, m := len(word1), len(word2)
    dp := make([][]int, n+1)
    for i := range dp {
        dp[i] = make([]int, m+1)
    }
    for i := 0; i <= n; i++ {
        dp[i][0] = i // 删除i次变为空串
    }
    for j := 0; j <= m; j++ {
        dp[0][j] = j // 插入j次由空串变为目标
    }

    min3 := func(a, b, c int) int {
        m := a
        if b < m {
            m = b
        }
        if c < m {
            m = c
        }
        return m
    }

    for i := 1; i <= n; i++ {
        for j := 1; j <= m; j++ {
            if word1[i-1] == word2[j-1] {
                dp[i][j] = dp[i-1][j-1] // 字符相等，不需要操作
            } else {
                del := dp[i-1][j] + 1   // 删除
                ins := dp[i][j-1] + 1   // 插入
                rep := dp[i-1][j-1] + 1 // 替换
                dp[i][j] = min3(del, ins, rep)
            }
        }
    }
    return dp[n][m]
}
```

## 总结

- 先说状态定义：`dp[i][j]` 表示 `word1` 前 `i` 个字符转换为 `word2` 前 `j` 个字符所需要的最少操作数。这个定义在双字符串 DP 里算是最"通用"的一种了，因为它能同时承载插入、删除、替换这三种操作的语义，不用为每种操作单独开一套状态。
- 递推公式这里的核心思路是：字符相等的时候，直接从 `dp[i-1][j-1]` 继承过来就行，不需要花任何操作；字符不相等的时候，就必须在删除、插入、替换这三个方向里选一个最优的，这也是整道题递推公式真正的核心。
- 再说说这三个方向怎么理解：删除对应 `dp[i-1][j]+1`，插入对应 `dp[i][j-1]+1`，替换对应 `dp[i-1][j-1]+1`。你可以把它们理解成三个不同的移动方向——"少一个word1字符"、"多一个word2字符对应的跳过"、"两边都往前挪一格"，把这三个方向的几何意义想明白了，公式基本就不用死记了。
- 最后串一下整条线：编辑距离其实是 392→115→583→72 这条思维链的终点。392 学的是"用长度去表达匹配"，115 学的是"计数要相加"，583 学的是"删除操作怎么建模"，到了 72 这一题，就是把删除、插入、替换这三个操作一次性统一进了同一个递推框架里。
