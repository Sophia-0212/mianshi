# 72. 编辑距离

**题目描述**

给定两个字符串 `word1` 和 `word2`，求将 `word1` 转换成 `word2` 所需的最少操作数。每次操作可以选择以下三种之一：

- 插入一个字符
- 删除一个字符
- 替换一个字符

```
示例：
输入: word1 = "horse", word2 = "ros"
输出: 3
解释: horse -> rorse（替换h为r） -> rose（删除r） -> ros（删除e）
```

## 思路

DP：`dp[i][j]` 为两串前 `i、j` 个字符的编辑距离。初值 `dp[i][0]=i、dp[0][j]=j`，逐行正序：

- 末字符相同：`dp[i][j]=dp[i-1][j-1]`。
- 不同：`dp[i][j]=1+min(dp[i-1][j],dp[i][j-1],dp[i-1][j-1])`，依次为删除、插入、替换。

返回 `dp[n][m]`。时间、空间 O(nm)；滚动保存两行，空间可降至 O(m)。

    def minDistance(self, word1: str, word2: str) -> int:

        dp = [[0] * (m + 1) for _ in range(n + 1)]
        for i in range(n + 1):
            dp[i][0] = i  # 删除i次变为空串
        for j in range(m + 1):
            dp[0][j] = j  # 插入j次由空串变为目标

        for i in range(1, n + 1):
            for j in range(1, m + 1):

                    dp[i][j] = dp[i - 1][j - 1]  # 字符相等，不需要操作，继承左上角
                else:
                    dp[i][j] = min(
                        dp[i - 1][j] + 1,      # 删除word1[i-1]
                        dp[i][j - 1] + 1,      # 插入字符匹配word2[j-1]
                        dp[i - 1][j - 1] + 1,  # 替换word1[i-1]为word2[j-1]
                    )
        return dp[n][m]```

```go
// 方法：minDistance；按题目要求处理输入并返回结果，核心算法见方法体。
func minDistance(word1 string, word2 string) int {
    n, m := len(word1), len(word2)
    dp := make([][]int, n+1)
    for i := range dp {
        dp[i] = make([]int, m+1)
    }
    for i := 0; i <= n; i++ {
        dp[i][0] = i // 删除i次变为空串
    }
    for j := 0; j <= m; j++ {
        dp[0][j] = j // 插入j次由空串变为目标
    }

    min3 := func(a, b, c int) int {
        m := a
        if b < m {
            m = b
        }
        if c < m {
            m = c
        }
        return m
    }

    for i := 1; i <= n; i++ {
        for j := 1; j <= m; j++ {
            if word1[i-1] == word2[j-1] {
                dp[i][j] = dp[i-1][j-1] // 字符相等，不需要操作
            } else {
                del := dp[i-1][j] + 1   // 删除
                ins := dp[i][j-1] + 1   // 插入
                rep := dp[i-1][j-1] + 1 // 替换
                dp[i][j] = min3(del, ins, rep)
            }
        }
    }
    return dp[n][m]
}
```

```cpp
class Solution {
public:
    // 方法：minDistance；按题目要求处理输入并返回结果，核心算法见方法体。
    int minDistance(string word1, string word2) {
        int n = word1.size(), m = word2.size();
        vector<vector<int>> dp(n + 1, vector<int>(m + 1, 0));
        for (int i = 0; i <= n; i++) dp[i][0] = i;  // 转换成空串，需要i次删除
        for (int j = 0; j <= m; j++) dp[0][j] = j;  // 空串转换成目标，需要j次插入

        for (int i = 1; i <= n; i++) {
            for (int j = 1; j <= m; j++) {
                if (word1[i - 1] == word2[j - 1]) {
                    dp[i][j] = dp[i - 1][j - 1];  // 字符相等，不需要操作，直接继承左上角
                } else {
                    dp[i][j] = min({
                        dp[i - 1][j] + 1,      // 删除word1[i-1]
                        dp[i][j - 1] + 1,      // 插入一个字符匹配word2[j-1]
                        dp[i - 1][j - 1] + 1   // 替换word1[i-1]为word2[j-1]
                    });
                }
            }
        }
        return dp[n][m];
    }
};
```

## 总结

- 先说状态定义：`dp[i][j]` 表示 `word1` 前 `i` 个字符转换为 `word2` 前 `j` 个字符所需要的最少操作数。这个定义在双字符串 DP 里算是最"通用"的一种了，因为它能同时承载插入、删除、替换这三种操作的语义，不用为每种操作单独开一套状态。
- 递推公式这里的核心思路是：字符相等的时候，直接从 `dp[i-1][j-1]` 继承过来就行，不需要花任何操作；字符不相等的时候，就必须在删除、插入、替换这三个方向里选一个最优的，这也是整道题递推公式真正的核心。
- 再说说这三个方向怎么理解：删除对应 `dp[i-1][j]+1`，插入对应 `dp[i][j-1]+1`，替换对应 `dp[i-1][j-1]+1`。你可以把它们理解成三个不同的移动方向——"少一个word1字符"、"多一个word2字符对应的跳过"、"两边都往前挪一格"，把这三个方向的几何意义想明白了，公式基本就不用死记了。
- 最后串一下整条线：编辑距离其实是 392→115→583→72 这条思维链的终点。392 学的是"用长度去表达匹配"，115 学的是"计数要相加"，583 学的是"删除操作怎么建模"，到了 72 这一题，就是把删除、插入、替换这三个操作一次性统一进了同一个递推框架里。
