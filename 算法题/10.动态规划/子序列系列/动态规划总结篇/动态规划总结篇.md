# 动态规划总结篇

DP 先定义状态，再确定转移、初值、依赖顺序及答案位置；用最小例子验证。

| 类型 | 核心状态／规则 | 时间 | 空间 |
|---|---|---|---|
| 线性递推 | 前几项决定下一项 | O(n) | 滚动 O(1) |
| 网格路径 | 上方＋左方，障碍清零 | O(mn) | O(mn)，滚动 O(n) |
| 01 背包 | 物品在外、容量倒序 | O(nC) | O(C) |
| 完全背包 | 容量正序；计数组合物品在外，排列容量在外 | O(nC) | O(C) |
| 打家劫舍 | 线性选／不选；环拆两段；树后序合并 | O(n) | 线性滚动 O(1)，树 O(h) |
| 股票 | 持有、交易次数、冷冻状态 | O(nk) | 滚动 O(k) |
| 回文区间 | 两端字符＋内部状态，左端点倒序 | O(n²) | O(n²) |
| 双序列 | 比较两前缀末项，依赖上／左／左上 | O(nm) | O(nm) |

C 为容量，k 为交易额度，h 为树高。方案数用加法，最优值用 min/max，可行性用逻辑或；独立子方案组合时相乘。
