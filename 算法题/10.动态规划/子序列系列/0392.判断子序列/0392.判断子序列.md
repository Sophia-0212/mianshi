# 392. 判断子序列

**题目描述**

给定字符串 `s` 和 `t`，判断 `s` 是否是 `t` 的子序列。子序列不要求连续，只要求在 `t` 中能找到与 `s` 顺序一致的字符（可以跳过 `t` 中任意字符）。

```
示例：
输入: s = "abc", t = "ahbgdc"
输出: true
解释: t 中依次出现 a(下标0)、b(下标2)、c(下标5)，顺序与 s 一致，所以 s 是 t 的子序列。
```

一般假设 `s` 的长度远小于 `t`（例如 `s` 长度不超过 100，`t` 长度可达 10000 以上），这个数据规模的提示很重要，后面会解释原因。

## 思路

- 双指针：扫描 `t`，匹配时推进 `s` 指针，最终 `s` 全部匹配即成功。时间 O(n+m)，空间 O(1)。
- DP：`dp[i][j]` 为两串对应前缀的最长公共子序列长度，边界为 0。字符相等取左上加一，否则沿用 `dp[i][j-1]`；逐行正序，判断 `dp[n][m]==n`。时间、空间 O(nm)。

n、m 分别为 `s、t` 长度。



## Python

### LeetCode 写法与原有示例

```python
# 依赖说明：len：Python 内置函数：返回容器中元素的数量。；range：Python 内置函数：生成按步长遍历的整数序列。

# 解法一：双指针（推荐）
class Solution:
    # 方法：isSubsequence；按题目要求处理输入并返回结果，核心算法见方法体。
    def isSubsequence(self, s: str, t: str) -> bool:
        i, j = 0, 0  # i指向s，j指向t
        while i < len(s) and j < len(t):
            if s[i] == t[j]:
                i += 1  # 匹配成功，s的指针前进
            j += 1      # t的指针总是前进
        return i == len(s)  # i走到s末尾，说明s被完整匹配


# 解法二：动态规划（理解状态设计用）
class SolutionDP:
    # 方法：isSubsequence；按题目要求处理输入并返回结果，核心算法见方法体。
    def isSubsequence(self, s: str, t: str) -> bool:
        n, m = len(s), len(t)
        dp = [[0] * (m + 1) for _ in range(n + 1)]  # 默认初始化为0
        for i in range(1, n + 1):
            for j in range(1, m + 1):
                if s[i - 1] == t[j - 1]:
                    dp[i][j] = dp[i - 1][j - 1] + 1  # 字符匹配，长度加1
                else:
                    dp[i][j] = dp[i][j - 1]  # 不匹配，只能跳过t当前字符
        return dp[n][m] == n  # 最长公共子序列长度等于s总长
```


下面代码把两种解法都给出来了：双指针解法（实际用这个）和 DP 解法（拿来理解状态设计）。

## C++

### LeetCode 写法与原有示例

// 依赖说明：vector：C++ STL 动态数组。；string：C++ STL 字符串类型。

// 解法一：双指针（推荐）
class Solution {
public:
    // 方法：isSubsequence；按题目要求处理输入并返回结果，核心算法见方法体。
    bool isSubsequence(string s, string t) {
        int i = 0, j = 0;  // i指向s，j指向t
        while (i < s.size() && j < t.size()) {
            if (s[i] == t[j]) {
                i++;  // 匹配成功，s的指针前进
            }
            j++;      // t的指针总是前进（无论是否匹配）
        }
        return i == s.size();  // i走到s末尾，说明s被完整匹配
    }
};

// 解法二：动态规划（理解状态设计用）
class SolutionDP {
public:
    // 方法：isSubsequence；按题目要求处理输入并返回结果，核心算法见方法体。
    bool isSubsequence(string s, string t) {
        int n = s.size(), m = t.size();
        vector<vector<int>> dp(n + 1, vector<int>(m + 1, 0));  // 默认初始化为0
        for (int i = 1; i <= n; i++) {
            for (int j = 1; j <= m; j++) {
                if (s[i - 1] == t[j - 1]) {
                    dp[i][j] = dp[i - 1][j - 1] + 1;  // 字符匹配，长度加1
                } else {
                    dp[i][j] = dp[i][j - 1];  // 不匹配，只能跳过t当前字符（s不能跳）
                }
            }
        }
        return dp[n][m] == n;  // 最长公共子序列长度等于s总长，说明s被完整包含
    }
};```

## 总结

- 双指针才是本题最直接高效的解法（O(m) 时间、O(1) 空间），实际做题的时候优先用它。
- DP 解法的思路是把"是否子序列"这个问题，转化成"求最长公共子序列长度，再看是否等于 `s` 的长度"，这个转化才是本题真正的核心价值：用长度去代替布尔值，给后面更复杂的双字符串 DP 问题铺路。
- 本题的递推公式跟 1143 题最长公共子序列几乎一模一样，唯一的区别就是字符不匹配的时候只能跳过 `t`（也就是 `dp[i][j-1]`），不能跳过 `s`（所以不取 `dp[i-1][j]`），说白了就是因为本题要求 `s` 必须被整体匹配上，`s` 和 `t` 的地位并不对等。
- 本题是"卡尔三步铺垫"（392→115→583→72）的起点，这里学到的"用状态表达匹配关系"会在后续三题里被逐步复用、逐步扩展。
