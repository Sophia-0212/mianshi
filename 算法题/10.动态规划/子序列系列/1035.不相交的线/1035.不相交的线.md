# 1035. 不相交的线

**题目描述**

给定两个整数数组 `nums1` 和 `nums2`，在两条平行线上分别按顺序写下这两个数组的数字。现在要在 `nums1[i]` 和 `nums2[j]` 之间画一条直线，前提是 `nums1[i] == nums2[j]`。要求所有画出的连线中，任意两条连线都不能相交（也不能与坐标轴平行的线重叠）。求最多能画出多少条连线。

```
示例：
输入: nums1 = [1,4,2], nums2 = [1,2,4]
输出: 2
解释: 可以连接 1-1 和 2-2（或者 1-1 和 4-4），最多画 2 条不相交的线。
     如果三条线 1-1、4-4、2-2 都画出来，会发现 4-4 和 2-2 这两条线相互交叉，
     所以不能三条都要，最多只能保留其中两条不相交的。
```

## 思路

不相交要求匹配下标顺序一致，转为最长公共子序列。

`dp[i][j]` 为两数组前 `i、j` 项的最大连线数，边界为 0。末项相同取左上加一，不同取上、左最大值；逐行正序，返回 `dp[n][m]`。

时间、空间 O(nm)。

```python
# 依赖说明：len：Python 内置函数：返回容器中元素的数量。；range：Python 内置函数：生成按步长遍历的整数序列。；max：Python 内置函数：返回最大值。

# 依赖说明：len：Python 内置函数：返回容器中元素的数量。；range：Python 内置函数：生成按步长遍历的整数序列。

class Solution:
    # 方法：maxUncrossedLines；按题目要求处理输入并返回结果，核心算法见方法体。
    def maxUncrossedLines(self, nums1: list[int], nums2: list[int]) -> int:
        n, m = len(nums1), len(nums2)
        # dp[i][j] 表示 nums1 前 i 个数字与 nums2 前 j 个数字的最长公共子序列长度
        dp = [[0] * (m + 1) for _ in range(n + 1)]  # 第0行第0列天然为0

        for i in range(1, n + 1):
            for j in range(1, m + 1):
                if nums1[i - 1] == nums2[j - 1]:
                    # 数字相等：等价于LCS的字符匹配递推，可画一条连线
                    dp[i][j] = dp[i - 1][j - 1] + 1
                else:
                    # 数字不等：继承左、上两个方向中较大的值
                    dp[i][j] = max(dp[i - 1][j], dp[i][j - 1])

        return dp[n][m]  # 最终答案
```

class Solution {
public:
    // 方法：maxUncrossedLines；按题目要求处理输入并返回结果，核心算法见方法体。
    int maxUncrossedLines(vector<int>& nums1, vector<int>& nums2) {
        int n = nums1.size(), m = nums2.size();
        // dp[i][j] 表示 nums1 前 i 个数字与 nums2 前 j 个数字的最长公共子序列长度
        // 也就是最多能画出的不相交连线数
        vector<vector<int>> dp(n + 1, vector<int>(m + 1, 0)); // 第0行第0列天然为0

        for (int i = 1; i <= n; i++) {
            for (int j = 1; j <= m; j++) {
                if (nums1[i - 1] == nums2[j - 1]) {
                    // 数字相等：可以画一条连线，等价于LCS里字符匹配的递推
                    dp[i][j] = dp[i - 1][j - 1] + 1;
                } else {
                    // 数字不等：无法连线，继承舍弃nums1当前数字或舍弃nums2当前数字中较大的结果
                    dp[i][j] = max(dp[i - 1][j], dp[i][j - 1]);
                }
            }
        }
        return dp[n][m]; // 两数组全部比较完后的最终连线数
    }

## 总结

- 这道题的难点根本不在 DP 推导本身，而在"问题转化"：两条连线不相交，说白了就等价于连接的下标对在 `nums1` 和 `nums2` 中都保持相对递增，这不就是子序列"保持相对顺序"的定义嘛，所以"最多不相交连线数"其实就等价于"两数组的最长公共子序列长度"，之后套用 1143 的模型就行了。
- 很多题目表面上看是全新的场景——几何连线、区间调度、字符串匹配变体——但只要你能抽象出背后的数学结构，往往会发现它就是某个已经见过的经典模型（LCS、背包、区间 DP 等）的变形。培养这种"识别本质、做等价转化"的建模能力，比死记某一类题的代码模板重要得多。
- 一旦完成转化，代码实现就可以直接复用已有的解法（本题跟 1143 的代码几乎逐行对应），这也说明一个道理：扎实掌握少数几个经典 DP 模型，往往比刷大量表面上不同的题目更有效率。
