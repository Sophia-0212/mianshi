# 1035. 不相交的线

**题目描述**

给定两个整数数组 `nums1` 和 `nums2`，在两条平行线上分别按顺序写下这两个数组的数字。现在要在 `nums1[i]` 和 `nums2[j]` 之间画一条直线，前提是 `nums1[i] == nums2[j]`。要求所有画出的连线中，任意两条连线都不能相交（也不能与坐标轴平行的线重叠）。求最多能画出多少条连线。

```
示例：
输入: nums1 = [1,4,2], nums2 = [1,2,4]
输出: 2
解释: 可以连接 1-1 和 2-2（或者 1-1 和 4-4），最多画 2 条不相交的线。
     如果三条线 1-1、4-4、2-2 都画出来，会发现 4-4 和 2-2 这两条线相互交叉，
     所以不能三条都要，最多只能保留其中两条不相交的。
```

## 思路

**这道题最关键的地方，其实不是设计 DP，而是"问题转化"——你得看出来，它本质上就是 1143 最长公共子序列。**

咱们先想清楚，"不相交"这个几何约束到底在限制什么。假设画了两条线，第一条连接 `nums1[i1]` 和 `nums2[j1]`，第二条连接 `nums1[i2]` 和 `nums2[j2]`，而且 `i1 < i2`（也就是第一条线在 `nums1` 这边连的位置更靠左）。这两条线要想不相交，唯一的条件就是 `j1 < j2`，也就是说在 `nums2` 这边，第一条线连的位置也必须更靠左才行。反过来想，如果 `i1 < i2` 但 `j1 > j2` 呢？两条线一定会交叉——一条从左上到右下，一条从右上到左下，必然会穿过对方。

把这个结论推广到任意多条线上：一组连线两两不相交，等价于什么呢？等价于——如果把这些连线按照在 `nums1` 中的位置从左到右排个序，那么它们在 `nums2` 中的位置也必然是严格递增的。换句话说，所有连线对应的下标对 `(i, j)`，在 `nums1` 和 `nums2` 两边保持的是同一个相对顺序。

那"从一个序列里取出若干个元素、但不改变它们的相对顺序"，这说的不就是**子序列**吗？所以你看，"一组两两不相交的连线"，说白了本质上就是从 `nums1` 和 `nums2` 里各取出一个子序列，这两个子序列还得逐位相等（因为每条线两端的数字必须相同），而且长度正好就是连线的条数。要让连线数最多，就是要在 `nums1` 和 `nums2` 之间找出最长的一对"逐位相等、还保持顺序"的子序列——这不多不少，正好就是**两个数组的最长公共子序列（LCS）**。

想清楚这一层转化之后，这道题基本上就退化成了 1143 最长公共子序列的原题，只是把字符串换成了整数数组，字符比较换成了数字比较，思路跟 1143 完全一致，这里简单过一遍：

- **dp 数组定义**：`dp[i][j]` 表示 `nums1` 前 `i` 个数字与 `nums2` 前 `j` 个数字的最长公共子序列长度。
- **递推公式**：如果 `nums1[i-1] == nums2[j-1]`（对应画一条连线），`dp[i][j] = dp[i-1][j-1] + 1`；否则（这两个数字凑不成一对连线），`dp[i][j] = max(dp[i-1][j], dp[i][j-1])`，继承舍弃 `nums1` 当前数字或舍弃 `nums2` 当前数字中较大的结果，不清零——原因和 1143 一样，子序列允许跳过元素，之前已经找到的公共部分不会因为当前不匹配就失效。
- **初始化**：`dp[i][0] = 0`，`dp[0][j] = 0`，对应有一边是空数组时连线数必为 0。
- **遍历顺序**：从上到下、从左到右遍历 `i`、`j`，保证计算 `dp[i][j]` 时它依赖的 `dp[i-1][j-1]`、`dp[i-1][j]`、`dp[i][j-1]` 都已算好。

拿示例简单推一下：`nums1 = [1,4,2]`，`nums2 = [1,2,4]`。走到 `i=1（数字1）, j=1（数字1）` 时相等，`dp[1][1] = 1`，对应连上 1-1 这条线。继续走到 `i=2（数字4）, j=2（数字2）` 时不相等，取 `max(dp[1][2], dp[2][1])`；走到 `i=2（数字4）, j=3（数字4）` 时相等，`dp[2][3] = dp[1][2] + 1`。但你注意到没有，`nums2` 里 2 排在 4 前面，而 `nums1` 里 4 排在 2 前面，这就导致 4 和 2 没法同时入选——这正是"不相交"这个约束在起作用。最终填完整张表得到 `dp[3][3] = 2`，也就是最多能画 2 条不相交的线，跟示例输出一致。

**复杂度分析**：时间复杂度是 O(n×m)，空间复杂度也是 O(n×m)，n、m 分别是 `nums1`、`nums2` 的长度，跟 1143 完全一样。

## 代码

### C++

```cpp
class Solution {
public:
    int maxUncrossedLines(vector<int>& nums1, vector<int>& nums2) {
        int n = nums1.size(), m = nums2.size();
        // dp[i][j] 表示 nums1 前 i 个数字与 nums2 前 j 个数字的最长公共子序列长度
        // 也就是最多能画出的不相交连线数
        vector<vector<int>> dp(n + 1, vector<int>(m + 1, 0)); // 第0行第0列天然为0

        for (int i = 1; i <= n; i++) {
            for (int j = 1; j <= m; j++) {
                if (nums1[i - 1] == nums2[j - 1]) {
                    // 数字相等：可以画一条连线，等价于LCS里字符匹配的递推
                    dp[i][j] = dp[i - 1][j - 1] + 1;
                } else {
                    // 数字不等：无法连线，继承舍弃nums1当前数字或舍弃nums2当前数字中较大的结果
                    dp[i][j] = max(dp[i - 1][j], dp[i][j - 1]);
                }
            }
        }
        return dp[n][m]; // 两数组全部比较完后的最终连线数
    }
};
```

### Java

```java
class Solution {
    public int maxUncrossedLines(int[] nums1, int[] nums2) {
        int n = nums1.length, m = nums2.length;
        // dp[i][j] 表示 nums1 前 i 个数字与 nums2 前 j 个数字的最长公共子序列长度
        int[][] dp = new int[n + 1][m + 1]; // 默认初始化为0，对应边界情况

        for (int i = 1; i <= n; i++) {
            for (int j = 1; j <= m; j++) {
                if (nums1[i - 1] == nums2[j - 1]) {
                    // 数字相等：等价于LCS里字符匹配，可画一条连线
                    dp[i][j] = dp[i - 1][j - 1] + 1;
                } else {
                    // 数字不等：继承左、上方向中较大的值，而不是清零
                    dp[i][j] = Math.max(dp[i - 1][j], dp[i][j - 1]);
                }
            }
        }
        return dp[n][m]; // 最终答案
    }
}
```

```python
class Solution:
    def maxUncrossedLines(self, nums1: list[int], nums2: list[int]) -> int:
        n, m = len(nums1), len(nums2)
        # dp[i][j] 表示 nums1 前 i 个数字与 nums2 前 j 个数字的最长公共子序列长度
        dp = [[0] * (m + 1) for _ in range(n + 1)]  # 第0行第0列天然为0

        for i in range(1, n + 1):
            for j in range(1, m + 1):

                    dp[i][j] = dp[i - 1][j - 1] + 1
                else:
                    # 数字不等：继承左、上两个方向中较大的值

        return dp[n][m]  # 最终答案
```

```go
func maxUncrossedLines(nums1 []int, nums2 []int) int {
    n, m := len(nums1), len(nums2)
    // dp[i][j] 表示 nums1 前 i 个数字与 nums2 前 j 个数字的最长公共子序列长度
    dp := make([][]int, n+1)
    for i := range dp {
        dp[i] = make([]int, m+1) // 初始化为0，第0行第0列为边界
    }

    for i := 1; i <= n; i++ {
        for j := 1; j <= m; j++ {
            if nums1[i-1] == nums2[j-1] {
                // 数字相等：等价于LCS的字符匹配，可画一条连线
                dp[i][j] = dp[i-1][j-1] + 1
            } else {
                // 数字不等：继承左、上两个方向中较大的值
                dp[i][j] = max(dp[i-1][j], dp[i][j-1])
            }
        }
    }
    return dp[n][m] // 最终答案
}

func max(a, b int) int {
    if a > b {
        return a
    }
    return b
}
```

## 总结

- 这道题的难点根本不在 DP 推导本身，而在"问题转化"：两条连线不相交，说白了就等价于连接的下标对在 `nums1` 和 `nums2` 中都保持相对递增，这不就是子序列"保持相对顺序"的定义嘛，所以"最多不相交连线数"其实就等价于"两数组的最长公共子序列长度"，之后套用 1143 的模型就行了。
- 很多题目表面上看是全新的场景——几何连线、区间调度、字符串匹配变体——但只要你能抽象出背后的数学结构，往往会发现它就是某个已经见过的经典模型（LCS、背包、区间 DP 等）的变形。培养这种"识别本质、做等价转化"的建模能力，比死记某一类题的代码模板重要得多。
- 一旦完成转化，代码实现就可以直接复用已有的解法（本题跟 1143 的代码几乎逐行对应），这也说明一个道理：扎实掌握少数几个经典 DP 模型，往往比刷大量表面上不同的题目更有效率。
