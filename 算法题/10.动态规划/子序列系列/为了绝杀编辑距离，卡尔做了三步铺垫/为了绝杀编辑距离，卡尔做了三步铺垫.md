# 为了绝杀编辑距离，卡尔做了三步铺垫

双字符串 DP 的四种目标：

- 392 判断子序列：相等时匹配，不等时跳过长串字符；双指针时间 O(n+m)、空间 O(1)，DP 时间、空间 O(nm)。
- 115 不同子序列：计数相等时“用／不用”两类方案，空目标有 1 种方案；时间、空间 O(nm)。
- 583 删除操作：相等继承左上，不等删除任一侧，取最少；也可求 LCS 后返回 `n+m-2L`。时间、空间 O(nm)。
- 72 编辑距离：允许删除、插入、替换，相等不操作，不等取三种操作最小值：

```
dp[i][j] = min(dp[i-1][j] + 1, dp[i][j-1] + 1, dp[i-1][j-1] + 1)
```

编辑距离边界为 `dp[i][0]=i、dp[0][j]=j`，逐行正序，时间、空间 O(nm)。
