# 1143. 最长公共子序列

**题目描述**

给定两个字符串 `text1` 和 `text2`，求它们的最长公共子序列（Longest Common Subsequence，LCS）的长度。如果不存在公共子序列，返回 0。

这里"子序列"的定义是：可以从原字符串中删除任意个字符（也可以不删除），剩下的字符不改变原有的相对顺序所组成的新字符串。注意子序列不要求连续，这一点和"子数组/子串"完全不同。

```
示例：
输入: text1 = "abcde", text2 = "ace"
输出: 3
解释: 最长公共子序列是 "ace"，它的长度为 3。
```

要求：`text1`、`text2` 由小写英文字母组成，长度范围在 1 到 1000 之间。

## 思路

DP：`dp[i][j]` 为两串前 `i、j` 个字符的最长公共子序列长度，边界为 0。末字符相同取 `dp[i-1][j-1]+1`，不同取 `max(dp[i-1][j],dp[i][j-1])`。

逐行正序，返回 `dp[n][m]`。时间、空间 O(nm)；滚动保存两行可将空间降至 O(m)。

### LeetCode 写法与原有示例

```python
# 依赖说明：len：Python 内置函数：返回容器中元素的数量。；range：Python 内置函数：生成按步长遍历的整数序列。；max：Python 内置函数：返回最大值。

# 依赖说明：len：Python 内置函数：返回容器中元素的数量。；range：Python 内置函数：生成按步长遍历的整数序列。

class Solution:
    # 方法：longestCommonSubsequence；按题目要求处理输入并返回结果，核心算法见方法体。
    def longestCommonSubsequence(self, text1: str, text2: str) -> int:
        n, m = len(text1), len(text2)
        # dp[i][j] 表示 text1 前 i 个字符与 text2 前 j 个字符的最长公共子序列长度
        dp = [[0] * (m + 1) for _ in range(n + 1)]  # 第0行第0列天然为0（空字符串边界）

        for i in range(1, n + 1):
            for j in range(1, m + 1):
                if text1[i - 1] == text2[j - 1]:
                    # 字符匹配：在前i-1、前j-1的基础上加1
                    dp[i][j] = dp[i - 1][j - 1] + 1
                else:
                    # 字符不匹配：继承左、上两个方向中较大的值，而不是清零
                    dp[i][j] = max(dp[i - 1][j], dp[i][j - 1])

        return dp[n][m]  # 最终答案
```

### LeetCode 写法与原有示例

```cpp
// 依赖说明：vector：C++ STL 动态数组。；string：C++ STL 字符串类型。

class Solution {
public:
    // 方法：longestCommonSubsequence；按题目要求处理输入并返回结果，核心算法见方法体。
    int longestCommonSubsequence(string text1, string text2) {
        int n = text1.size(), m = text2.size();
        // dp[i][j] 表示 text1 前 i 个字符与 text2 前 j 个字符的最长公共子序列长度
        vector<vector<int>> dp(n + 1, vector<int>(m + 1, 0)); // 第0行第0列天然初始化为0

        for (int i = 1; i <= n; i++) {
            for (int j = 1; j <= m; j++) {
                if (text1[i - 1] == text2[j - 1]) {
                    // 字符匹配：在前i-1、前j-1的基础上，公共子序列长度加1
                    dp[i][j] = dp[i - 1][j - 1] + 1;
                } else {
                    // 字符不匹配：不清零，而是继承“舍弃text1当前字符”或“舍弃text2当前字符”中较大的结果
                    dp[i][j] = max(dp[i - 1][j], dp[i][j - 1]);
                }
            }
        }
        return dp[n][m]; // 两个字符串全部字符都参与比较后的最终结果
    }
};```

## 总结

- 递推公式的核心分支就在于字符匹不匹配：匹配时 `dp[i][j] = dp[i-1][j-1] + 1`；不匹配时是 `dp[i][j] = max(dp[i-1][j], dp[i][j-1])`——说白了就是**继承左方向和上方向已有的最大值，而不是清零**，这是本题最容易出错、也最关键的一步。
- 为什么不清零呢？因为子序列允许跳过字符、不要求连续，当前这两个字符不匹配，并不会让之前已经找到的公共子序列失效，只是说明当前这一对字符不能同时被选中而已。
- 这正是"连续"（子数组/子串，比如 0718 最长重复子数组）跟"不连续"（子序列，比如本题）这两类双序列 DP 在设计递推公式时的关键分界线：连续型不匹配就得清零重开，不连续型不匹配只是少一种选择，得继承历史最优。
- 下标从 1 开始、用"前 i 个字符"来定义 dp 数组，能让第 0 行、第 0 列的初始化（对应空字符串）变得很自然，这是双序列 DP 里通用的处理技巧。
