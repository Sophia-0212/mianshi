# 718. 最长重复子数组

**题目描述**

给定两个整数数组 `nums1` 和 `nums2`，求两个数组中最长公共**连续**子数组的长度（子数组要求下标连续，不能跳跃）。

```
示例：
输入: nums1 = [1,2,3,2,1], nums2 = [3,2,1,4,7]
输出: 3
解释: 公共的连续子数组是 [3,2,1]，长度为 3
```

## 思路

DP：`dp[i][j]` 为分别以两数组下标 `i-1、j-1` 结尾的最长公共连续段长度。边界为 0；元素相等取 `dp[i-1][j-1]+1`，否则清零。逐行正序，返回全部状态最大值。

时间、空间 O(nm)；一维滚动按 j 倒序，不匹配仍清零，空间 O(m)。

```python
# 依赖说明：len：Python 内置函数：返回容器中元素的数量。；range：Python 内置函数：生成按步长遍历的整数序列。；max：Python 内置函数：返回最大值。

# 依赖说明：len：Python 内置函数：返回容器中元素的数量。；range：Python 内置函数：生成按步长遍历的整数序列。

class Solution:
    # 方法：findLength；按题目要求处理输入并返回结果，核心算法见方法体。
    def findLength(self, nums1: list[int], nums2: list[int]) -> int:
        n, m = len(nums1), len(nums2)
        dp = [[0] * (m + 1) for _ in range(n + 1)]  # dp[i][0]、dp[0][j] 均为0
        result = 0
        for i in range(1, n + 1):
            for j in range(1, m + 1):
                if nums1[i - 1] == nums2[j - 1]:
                    dp[i][j] = dp[i - 1][j - 1] + 1  # 匹配，接续左上方长度+1
                else:
                    dp[i][j] = 0  # 不匹配，连续子数组断开，清零
                result = max(result, dp[i][j])  # 更新全局最大值
        return result
```

```go
func findLength(nums1 []int, nums2 []int) int {
    n, m := len(nums1), len(nums2)
    dp := make([][]int, n+1)
    for i := range dp {
        dp[i] = make([]int, m+1) // 默认初始化为0
    }
    result := 0
    for i := 1; i <= n; i++ {
        for j := 1; j <= m; j++ {
            if nums1[i-1] == nums2[j-1] {
                dp[i][j] = dp[i-1][j-1] + 1 // 匹配，接续左上方长度+1
            } else {
                dp[i][j] = 0 // 不匹配，清零重新开始
            }
            if dp[i][j] > result {
                result = dp[i][j] // 更新全局最大值
            }
        }
    }
    return result
}
```

## 总结

- `dp[i][j]` 表示的是以 `nums1[i-1]`、`nums2[j-1]` 结尾的最长公共连续子数组长度，下标之所以偏移一位，就是为了让 `dp[0][*]`、`dp[*][0]` 能很自然地表示"空数组"这种情况，不用去处理负数索引这种麻烦事。
- 因为题目要求"连续"，所以不匹配的时候必须把 `dp[i][j]` 清零，这一点是这道题递推公式的核心，也是它跟下一题——1143 最长公共子序列（那道题不要求连续，所以不清零）——本质上的区别，这两道题放在一起对比着记会更清楚。
- 还有一点要注意，答案不是直接取 `dp[n][m]`，而是要看整个 dp 表格里的最大值，为什么呢？因为最长公共连续子数组可能在任意位置结束，不一定正好是两个数组都遍历到末尾的那个点。
- 空间复杂度方面，可以用滚动数组把 O(n·m) 优化到 O(m)，但更新顺序上要小心，别把还没用到的上一行数据提前覆盖了。
