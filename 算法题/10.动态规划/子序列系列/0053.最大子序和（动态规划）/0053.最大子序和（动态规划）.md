# 0053. 最大子序和（动态规划）

**题目描述**

给定一个整数数组 `nums`，请找到一个具有最大和的连续子数组（子数组最少包含一个元素），返回其最大和。

```
示例：
输入: nums = [-2,1,-3,4,-1,2,1,-5,4]
输出: 6
解释: 连续子数组 [4,-1,2,1] 的和最大，为 6。
```

这道题在贪心算法分类里已经用贪心解法做过一次了，就是累加和一旦为负就清零重置那个思路。这里咱们换个角度，用动态规划重新推一遍。你可能会觉得这两种解法风格完全不搭——一个就维护两个变量，一个要维护一整个数组——但是往下推你会发现，它们本质上讲的是同一件事，只是表达方式不一样，这也正是这道题放进"子序列系列"里重讲一遍的价值所在。

## 思路

DP：`dp[i]` 为必须以 `i` 结尾的最大子数组和。`dp[0]=nums[0]`，正序更新 `dp[i]=max(nums[i],dp[i-1]+nums[i])`，返回所有状态最大值。

时间 O(n)，空间 O(n)，滚动变量可降为 O(1)。贪心等价写法：累加、更新答案，负和清零；时间 O(n)，空间 O(1)。

### LeetCode 写法与原有示例

```python
# 依赖说明：len：Python 内置函数：返回容器中元素的数量。；range：Python 内置函数：生成按步长遍历的整数序列。；max：Python 内置函数：返回最大值。

# 依赖说明：len：Python 内置函数：返回容器中元素的数量。；range：Python 内置函数：生成按步长遍历的整数序列。

class Solution:
    # 方法：maxSubArray；按题目要求处理输入并返回结果，核心算法见方法体。
    def maxSubArray(self, nums: list[int]) -> int:
        n = len(nums)
        dp = [0] * n
        dp[0] = nums[0]  # 初始化：只有一个元素时，最大和就是它自己
        result = dp[0]   # 记录dp数组中出现过的最大值

        for i in range(1, n):
            # 接着前面走(dp[i-1]+nums[i])，或放弃前面重新开始(nums[i])，取较大值
            dp[i] = max(dp[i - 1] + nums[i], nums[i])
            result = max(result, dp[i])  # 更新全局最大和
        return result
```

```go
// 方法：maxSubArray；按题目要求处理输入并返回结果，核心算法见方法体。
func maxSubArray(nums []int) int {
    n := len(nums)
    dp := make([]int, n)
    dp[0] = nums[0] // 初始化：只有一个元素时，最大和就是它自己
    result := dp[0] // 记录dp数组中出现过的最大值

    for i := 1; i < n; i++ {
        // 接着前面走，或放弃前面重新开始，取较大值
        if dp[i-1]+nums[i] > nums[i] {
            dp[i] = dp[i-1] + nums[i]
        } else {
            dp[i] = nums[i]
        }
        if dp[i] > result {
            result = dp[i] // 更新全局最大和
        }
    }
    return result
```
```cpp
}
```

## 总结

- `dp[i]` 就是"以 `nums[i]` 结尾的连续子数组最大和"，递推公式是 `dp[i] = max(dp[i-1]+nums[i], nums[i])`，最后答案要取整个 `dp` 数组里的最大值，不是 `dp[n-1]`。
- 贪心解法里"累加和为负就清零"这个操作，本质上就是 DP 递推公式里"放弃前面另起一行"这个分支被触发的条件（也就是 `dp[i-1] < 0`），说白了这两个是同一个决策的两种说法。
- 贪心解法其实就是这个 DP 解法的空间优化版本：因为状态转移只依赖上一个状态，所以可以用一个滚动变量代替整个 `dp` 数组，把空间复杂度从 O(n) 降到 O(1)。
- 遇到一个贪心策略想不清楚为什么对的时候，可以先试着写出对应的 DP 状态转移方程，用 DP 严谨的推导反过来验证一下贪心到底对不对。
