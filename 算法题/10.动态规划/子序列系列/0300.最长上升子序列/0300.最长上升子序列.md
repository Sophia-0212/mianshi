# 300. 最长上升子序列

**题目描述**

给定一个整数数组 `nums`，找到其中最长严格递增子序列的长度。

子序列不要求连续，只要求在原数组中保持相对顺序即可。

```
示例：
输入: nums = [10,9,2,5,3,7,101,18]
输出: 4
解释: 最长的上升子序列是 [2,3,7,101]，长度为 4
```

要求：数组长度不超过 2500，元素可以重复但子序列要求严格递增（相等不算递增）。

## 思路

这道题我们可以把它当成"单序列子序列 DP"的入门题来看，其实也是整个子序列系列的一个起点。为什么说它是入门题呢？因为它第一次引入了子序列 DP 里最核心的一个思维方式：**dp 数组表示的不是"前 i 个元素的答案"，而是"以第 i 个元素结尾的答案"**。这个区别乍一看好像没什么大不了，但你别小看它，它其实决定了整个递推逻辑要怎么走，后面几乎所有子序列题目上手前都要先把这一点想明白。

**1. 确定 dp 数组（dp table）以及下标的含义**

`dp[i]` 表示以 `nums[i]` 结尾的最长严格递增子序列的长度。

那这里你可能会问，为什么不能直接定义成"前 i 个元素中最长上升子序列的长度"呢？这里的关键是，如果这样定义，`dp[i]` 和 `dp[i-1]` 之间就没法建立起必然的递推关系了——你想啊，`nums[i]` 到底能不能接到前面的子序列后面，取决于前面那个子序列**最后一个元素**是谁，可是"前 i 个元素的最长上升子序列"这个信息里根本就不包含"最后一个元素是谁"这件事。所以说白了，必须把"结尾元素"给固定下来，才能建立起递推关系，这也是子序列 DP 里最常用的一种定义思路。

**2. 确定递推公式**

那怎么算 `dp[i]` 呢？我们需要枚举所有 `j < i` 的位置，只要 `nums[j] < nums[i]`，就说明 `nums[i]` 可以接在以 `nums[j]` 结尾的那个上升子序列后面，这时候：

```
dp[i] = max(dp[i], dp[j] + 1)   当 nums[j] < nums[i]
```

注意这里为什么要用 `max`，是因为 `j` 有好多个可能的取值，`dp[i]` 得从这些可能性里挑一个最大的出来。这里还有一点要特别说一下：最终答案并不是 `dp[n-1]`，而是整个 `dp` 数组里的最大值，为什么呢？因为最长上升子序列完全可能是在数组中间的某个位置就结束了，不一定非要跑到最后一个元素。

**3. dp 数组如何初始化**

初始化这块其实很直观：每个元素自己都能单独构成一个长度为 1 的子序列（就它自己一个），所以：

```
dp[i] = 1，对所有 i 成立（初始化）
```

这一步千万不能漏，不然的话，递推公式里那个 `dp[j] + 1`，一旦碰到没有更小元素可以接续的情况（比如 `nums[i]` 恰好是当前最小值），就没法算出正确结果了。

**4. 确定遍历顺序**

遍历顺序上，外层 `i` 从 `1` 一直遍历到 `n-1`（`dp[0]` 我们前面已经初始化好了），内层 `j` 从 `0` 遍历到 `i-1`。为什么要这样安排呢？因为算 `dp[i]` 依赖的是前面所有 `j < i` 位置上的 `dp[j]`，所以 `i` 必须按从小到大的顺序来，而且必须保证 `j` 那部分先算完，`i` 才能接着往后推。

**5. 举例推导 dp 数组**

我们拿 `nums = [0,1,0,3,2]` 来举个例子，推一遍看看：

| i | nums[i] | dp[i] | 说明 |
|---|---------|-------|------|
| 0 | 0 | 1 | 自身 |
| 1 | 1 | 2 | 接在 nums[0]=0 后面 |
| 2 | 0 | 1 | 前面没有比 0 小的元素 |
| 3 | 3 | 3 | 接在 nums[1]=1（dp=2）后面 |
| 4 | 2 | 3 | 接在 nums[1]=1（dp=2）后面，nums[3]=3 不满足 |

推到最后 `dp` 数组就是 `[1,2,1,3,3]`，取个最大值是 3，也就是说最长上升子序列的长度是 3（比如 `[0,1,3]` 或者 `[0,1,2]` 都可以）。

**复杂度分析**

- 时间复杂度：这里是双重循环把所有的 `i, j` 对都遍历一遍，所以是 O(n²)。
- 空间复杂度：就一个 `dp` 数组，长度为 n，所以是 O(n)。

**拓展：O(n log n) 的贪心 + 二分优化**

上面这个 O(n²) 的解法，如果数据规模一大就容易超时，这里简单说一下更优的思路：我们维护一个数组 `tails`，`tails[k]` 表示长度为 `k+1` 的上升子序列里，结尾元素能取到的最小值。遍历 `nums` 的时候，对每个元素用二分查找在 `tails` 里找到第一个大于等于它的位置，然后替换掉（如果找不到就直接追加到末尾）。最后 `tails` 的长度就是我们要的答案。这个贪心思路的关键洞察在哪呢？说白了就是：**结尾元素越小，这个子序列后面能接上的元素就越多**，所以我们要贪心地让每个长度对应的结尾尽可能小。这样一优化，内层原来的线性枚举就换成了二分查找，时间复杂度也就降到了 O(n log n)。

## 代码

### C++

```cpp
class Solution {
public:
    int lengthOfLIS(vector<int>& nums) {
        int n = nums.size();
        if (n == 0) return 0;
        vector<int> dp(n, 1);  // dp[i] 初始化为 1，表示只包含自身
        int result = 1;
        for (int i = 1; i < n; i++) {          // i 从 1 开始，dp[0] 已初始化
            for (int j = 0; j < i; j++) {      // 枚举所有 j < i
                if (nums[j] < nums[i]) {       // 只有严格递增才能接续
                    dp[i] = max(dp[i], dp[j] + 1);  // 取所有可能接续中的最大值
                }
            }
            result = max(result, dp[i]);       // 全局答案取 dp 数组最大值
        }
        return result;
    }
};
```

### Java

```java
class Solution {
    public int lengthOfLIS(int[] nums) {
        int n = nums.length;
        if (n == 0) return 0;
        int[] dp = new int[n];
        Arrays.fill(dp, 1);  // dp[i] 初始化为 1
        int result = 1;
        for (int i = 1; i < n; i++) {           // 外层遍历结尾位置 i
            for (int j = 0; j < i; j++) {       // 内层枚举前面所有位置 j
                if (nums[j] < nums[i]) {        // 严格递增才能接续
                    dp[i] = Math.max(dp[i], dp[j] + 1);  // 更新以 i 结尾的最长长度
                }
            }
            result = Math.max(result, dp[i]);   // 更新全局最大值
        }
        return result;
    }
}
```

### Go

```go
func lengthOfLIS(nums []int) int {
    n := len(nums)
    if n == 0 {
        return 0
    }
    dp := make([]int, n)
    for i := range dp {
        dp[i] = 1 // dp[i] 初始化为 1，表示只包含自身
    }
    result := 1
    for i := 1; i < n; i++ { // 外层遍历结尾位置 i
        for j := 0; j < i; j++ { // 内层枚举前面所有位置 j
            if nums[j] < nums[i] { // 严格递增才能接续
                if dp[j]+1 > dp[i] {
                    dp[i] = dp[j] + 1 // 更新以 i 结尾的最长长度
                }
            }
        }
        if dp[i] > result {
            result = dp[i] // 更新全局最大值
        }
    }
    return result
}
```

## 总结

- `dp[i]` 定义为"以 `nums[i]` 结尾的最长上升子序列长度"，是子序列 DP 里最经典的定义方式，后续很多题目都沿用这个思路。
- 递推公式需要枚举所有 `j < i` 找可接续的位置，本质是在"以每个更早元素结尾的子序列"中挑最优的来延伸，这是 O(n²) 的根源。
- 最终答案是 `dp` 数组的最大值而不是 `dp[n-1]`，因为最优解不一定以最后一个元素结尾。
- O(n log n) 的贪心+二分解法通过维护"每个长度对应的最小结尾值"，把内层枚举替换为二分查找，是这道题从入门到进阶的经典优化路径。
