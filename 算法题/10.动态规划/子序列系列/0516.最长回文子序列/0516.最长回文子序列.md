# 516. 最长回文子序列

**题目描述**

给定一个字符串 `s`，求它的最长回文子序列的长度。子序列不要求连续，只要求保持原字符串中字符的相对顺序。

```
示例：
输入: s = "bbbab"
输出: 4
解释: 最长回文子序列是 "bbbb"，长度为 4（取原字符串下标0,1,2,4的字符 b,b,b,b）。
```

## 思路

你看这道题，名字跟前面的 647 题"回文子串"特别像，其实也确实是同一类"回文相关的区间 DP"。但你仔细一想就会发现，它俩有个关键差别：647 题要求"连续"（子串），这道题不要求"连续"（子序列），就这一个差异，直接把递推公式的复杂度给改变了。我建议把这两题放一起对比着讲，这样能更清楚地说明"连续"和"不连续"这条分界线到底是怎么影响 DP 设计的——顺带说一句，这条分界线在 1143 题最长公共子序列和 0718 最长重复子数组这一对题里也出现过一次，说白了这是子序列类 DP 里反复出现的一个核心分歧点。那我们还是按 DP 五部曲来一步步推。

**1. 确定 dp 数组（dp table）的含义**

`dp[i][j]` 表示字符串 `s` 在区间 `[i, j]`（下标 `i` 到 `j`，包含两端）范围内的最长回文子序列长度。

这里要注意一下，这个定义方式跟 647 题不一样：647 题的 `dp[i][j]` 是个布尔值，它只回答一个问题——"是不是回文"；而这道题的 `dp[i][j]` 是个数值，回答的是"这个区间里最长的回文子序列到底有多长"。为什么会有这个区别呢？根源还是在问题本身：647 题要判断"整个子串是不是回文"，这是个是非问题，用布尔值刚好合适；这道题呢，是要在一个区间里"挑"出尽可能长的回文子序列出来（可以跳过区间内任意字符），这本质上是个最优化问题，所以天然就得用数值去记录当前能做到的最优结果。

**2. 确定递推公式**

要求 `dp[i][j]`，我们还是得看两端字符 `s[i]` 和 `s[j]` 是不是相等，但这次不能简单地分"是/否"两条分支就完事了，得更细致地讨论一下：

- 先看如果 `s[i] == s[j]`，也就是两端字符相等的情况：这两个字符是可以同时被选进回文子序列里的（一个放最前面，一个放最后面，天然就对称了），那中间的部分呢，就是区间 `[i+1, j-1]` 里能构成的最长回文子序列。所以公式就是：

```
dp[i][j] = dp[i+1][j-1] + 2
```

  这里跟 647 题的相似之处在于，同样都依赖"去掉两端后的中间区间"，但不一样的地方是，这道题不需要对区间长度做特判——你想啊，即使 `i+1 > j-1`（比如 `i` 和 `j` 正好相邻，中间一个字符都没有），我们也可以约定这时候 `dp[i+1][j-1]` 就当 0（也就是说空区间的最长回文子序列长度是0），加 2 之后正好是"两个相邻且相等的字符构成长度为2的回文"，这跟直觉是吻合的。实现的时候一般通过合理设置遍历范围和初始化，让这种边界情况自然就能算对，不需要像 647 题那样专门写个 `if (j - i <= 1)` 的特判。

- 再看如果 `s[i] != s[j]`，两端字符不相等：这种情况下，这两个字符不可能同时出现在同一个回文子序列的两端（回文要求对称位置的字符必须相等），所以只能放弃其中一个端点。放弃 `s[i]` 的话，问题就变成求区间 `[i+1, j]` 的最长回文子序列，也就是 `dp[i+1][j]`；放弃 `s[j]` 的话，问题就变成求区间 `[i, j-1]` 的最长回文子序列，也就是 `dp[i][j-1]`。这两种放弃方式都是合法的候选答案，那我们当然是取较大的那个：

```
dp[i][j] = max(dp[i+1][j], dp[i][j-1])
```

这一步就是这道题跟 647 题真正分道扬镳的地方了。647 题因为要求"连续"，两端一旦不相等就直接判定整个区间不是回文（`dp[i][j] = false`，一棍子打死，没有中间地带）。但这道题允许"跳过"字符——子序列的定义本来就是可以跳过任意字符——所以两端不相等只是说明"这两个具体的字符不能同时选"，并不代表这个区间里就完全没有回文子序列了，完全可以跳过其中一个端点，在剩下的区间里接着找。这其实跟 1143 题最长公共子序列里"不匹配时继承 `max(左, 上)` 而不是清零"是同一种设计思想的又一次体现：**说白了，只要问题允许"跳过某些元素"，不满足条件的时候就应该继承已有的最优解、取较大值，而不是直接否定归零**。这句话你可以当成一个通用经验，用来判断一类区间/子序列 DP 该往哪个方向想。

**3. 确定初始化**

你想啊，单个字符本身就是长度为 1 的回文——只有一个字符嘛，天然就对称——所以 `dp[i][i] = 1`（对所有合法的 `i` 都是这样）。这一点跟 647 题"单字符天然回文"的初始化思路是一致的，只不过 647 题存的是布尔值 `true`，这道题存的是数值 `1`。

除了对角线 `dp[i][i]=1` 之外，其余格子都初始化为 0（表示还没算，等着后面递推填充）。

**4. 确定遍历顺序（和 647 题一样，这是本题的关键）**

递推公式里 `dp[i][j]` 依赖 `dp[i+1][j-1]`、`dp[i+1][j]`、`dp[i][j-1]` 这三个格子——你把 `i` 当行、`j` 当列来想，这三个格子分别在"左下方"、"下方"、"左方"的位置（`i+1` 意味着往下走，`j-1` 意味着往左走）。那为什么遍历顺序要这么定呢？因为要保证算 `dp[i][j]` 的时候，这三个格子都已经提前算出来了，所以行号 `i` 必须从大到小遍历（这样才能保证第 `i+1` 行先算完），列号 `j` 在同一行内则要从小到大遍历（这样才能保证 `dp[i][j-1]` 在算 `dp[i][j]` 之前已经算好）。这个遍历顺序跟 647 题回文子串完全一样——因为两题的依赖方向（都要用到"左下方"的格子）是相同的，这也说明一个规律：只要是"回文类"区间 DP，涉及"两端往中间收缩"这种递推思路，遍历顺序基本都遵循同一套规律——外层行号从大到小，内层列号从小到大。

**5. 举例推导 dp 数组**

咱们以 `s = "bbbab"`（下标0-4，字符 b,b,b,a,b）为例，按"i从4到0递减，j从i到4递增"的顺序，来推导一下部分关键格子：

- `i=4`：`dp[4][4]=1`（单字符 "b"）。
- `i=3`：`dp[3][3]=1`（单字符 "a"）。`dp[3][4]`：`s[3]='a'`，`s[4]='b'`，不相等，`dp[3][4] = max(dp[4][4], dp[3][3]) = max(1,1) = 1`。
- `i=2`：`dp[2][2]=1`（"b"）。`dp[2][3]`：`s[2]='b'`，`s[3]='a'`，不相等，`dp[2][3] = max(dp[3][3], dp[2][2]) = max(1,1) = 1`。`dp[2][4]`：`s[2]='b'`，`s[4]='b'`，相等，`dp[2][4] = dp[3][3] + 2 = 1 + 2 = 3`（对应回文子序列 "bab"）。
- `i=1`：`dp[1][1]=1`。`dp[1][2]`：`s[1]='b'`，`s[2]='b'`，相等，`dp[1][2] = dp[2][1]+2`，由于 `i+1=2 > j-1=1`（相邻两个相等字符），约定这种情况 `dp[2][1]` 视为0，`dp[1][2]=0+2=2`。`dp[1][3]`：`s[1]='b'`，`s[3]='a'`，不相等，`dp[1][3] = max(dp[2][3], dp[1][2]) = max(1,2) = 2`。`dp[1][4]`：`s[1]='b'`，`s[4]='b'`，相等，`dp[1][4] = dp[2][3] + 2 = 1 + 2 = 3`。
- `i=0`：`dp[0][0]=1`。`dp[0][4]`：`s[0]='b'`，`s[4]='b'`，相等，`dp[0][4] = dp[1][3] + 2 = 2 + 2 = 4`。

最终算出来 `dp[0][4] = 4`，跟预期一致，对应的回文子序列就是 "bbbb"（跳过了下标3的 "a"）。这个推导过程其实也验证了"不相等时继承 max"这一步是必要的：你看 `dp[1][3]=2`，正是从"跳过 `s[3]`，继承 `dp[1][2]=2`"这条分支得来的，如果不相等时直接归零，那后面 `dp[0][4]` 也会跟着算错。

**复杂度分析**

时间复杂度是 O(n²)，因为要填满整个 `[i,j]` 区间的 dp 表；空间复杂度也是 O(n²)。

## 代码

### C++

```cpp
class Solution {
public:
    int longestPalindromeSubseq(string s) {
        int n = s.size();
        vector<vector<int>> dp(n, vector<int>(n, 0));  // 初始化为0
        for (int i = 0; i < n; i++) {
            dp[i][i] = 1;  // 单个字符天然是长度为1的回文
        }
        for (int i = n - 1; i >= 0; i--) {         // 外层i从大到小，保证i+1行先算完
            for (int j = i + 1; j < n; j++) {      // 内层j从i+1到n-1（i本身已初始化）
                if (s[i] == s[j]) {
                    // 两端相等：两端都选入回文，加上中间区间的最长回文子序列长度
                    dp[i][j] = dp[i + 1][j - 1] + 2;
                } else {
                    // 两端不等：放弃左端或放弃右端，取两种舍弃方式中较大的结果（不归零）
                    dp[i][j] = max(dp[i + 1][j], dp[i][j - 1]);
                }
            }
        }
        return dp[0][n - 1];  // 整个字符串区间的最长回文子序列长度
    }
};
```

class Solution {
    public int longestPalindromeSubseq(String s) {
        int n = s.length();
        int[][] dp = new int[n][n];  // 默认初始化为0
        for (int i = 0; i < n; i++) {
            dp[i][i] = 1;  // 单字符天然回文，长度为1
        }
        for (int i = n - 1; i >= 0; i--) {           // 外层i从大到小
            for (int j = i + 1; j < n; j++) {        // 内层j从i+1到n-1
                if (s.charAt(i) == s.charAt(j)) {
                    // 两端相等：两端都选入回文，加上中间区间结果
                    dp[i][j] = dp[i + 1][j - 1] + 2;
                } else {
                    // 两端不等：舍弃左端或右端，取较大值继承
                    dp[i][j] = Math.max(dp[i + 1][j], dp[i][j - 1]);
                }
            }
        }
        return dp[0][n - 1];  // 整体区间的最长回文子序列长度
    }
}

class Solution:

        n = len(s)
        dp = [[0] * n for _ in range(n)]  # 默认初始化为0

### Go

```go
func longestPalindromeSubseq(s string) int {
    n := len(s)
    dp := make([][]int, n)
    for i := range dp {
        dp[i] = make([]int, n) // 初始化为0
    }
    for i := 0; i < n; i++ {
        dp[i][i] = 1 // 单字符天然回文，长度为1
    }

    for i := n - 1; i >= 0; i-- { // 外层i从大到小，保证i+1行先算完
        for j := i + 1; j < n; j++ { // 内层j从i+1到n-1
            if s[i] == s[j] {
                // 两端相等：两端都选入回文，加上中间区间结果
                dp[i][j] = dp[i+1][j-1] + 2
            } else {
                // 两端不等：舍弃左端或右端，取较大值继承（不归零）
                if dp[i+1][j] > dp[i][j-1] {
                    dp[i][j] = dp[i+1][j]
                } else {
                    dp[i][j] = dp[i][j-1]
                }
            }
        }
    }
    return dp[0][n-1] // 整体区间的最长回文子序列长度
}
```

## 总结

- 说白了，`dp[i][j]` 表示的就是区间 `[i,j]` 内最长回文子序列的长度，两端相等时 `dp[i][j] = dp[i+1][j-1] + 2`，两端不等时 `dp[i][j] = max(dp[i+1][j], dp[i][j-1])`——注意这里不匹配时是继承较大值，不是归零，这一点跟 1143 题最长公共子序列的设计思想是一致的：只要问题允许"跳过元素"，不满足条件就应该继承已有的最优解。
- 拿这道题跟 647 题"回文子串"对比一下：两者都是区间 DP，都依赖"左下方"的格子，遍历顺序也都是外层行号从大到小、内层列号从小到大；不一样的地方在于，647 题要求连续，两端不等时就直接判 `false`（没有中间地带），而这道题允许跳过字符，两端不等时得在两种舍弃方式里取最优。
- 遍历顺序是这道题另一个特别容易出错的点：一定要保证 `dp[i+1][...]` 这一整行先算完，然后才能算 `dp[i][...]`，所以外层循环的 `i` 要从字符串末尾往前递减，不能按平时的习惯从头到尾正着遍历。
- 那怎么判断一道题该用"归零"还是"继承 max"呢？这里有个分界线：题目要求"连续"（子串/子数组），就用归零；要求"可以跳过、不要求连续"（子序列），就用继承 max。这个判断标准基本上适用于绝大多数子序列类区间 DP 问题。
