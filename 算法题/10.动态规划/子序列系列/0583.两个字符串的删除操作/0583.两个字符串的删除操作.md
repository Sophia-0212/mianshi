# 583. 两个字符串的删除操作

**题目描述**

给定两个字符串 `word1` 和 `word2`，每次可以删除任意一个字符串中的一个字符，求使 `word1` 和 `word2` 相同所需的最小步数。

```
示例：
输入: word1 = "sea", word2 = "eat"
输出: 2
解释: 第一步将 "sea" 变为 "ea"，第二步将 "eat" 变为 "ea"
```

## 思路

这道题其实是往前铺垫的一环啊：前面 392 题咱们学会了用 DP 判断子序列关系，115 题又学会了用 DP 做方案计数，那这一题呢，要学会把"删除操作"这个动作本身建模到 DP 里去，目的是给最后 72 题的编辑距离（插入、删除、替换三种操作综合起来）做个铺垫。我这里给两种思路，从不同角度切进去讲。

**思路一：转化为最长公共子序列（复用 1143 题）**

你想啊，如果两个字符串要通过删除变得一样，那删完之后剩下的那部分，肯定是两个字符串的一个公共子序列。那要让删除次数最少，就得让剩下的这个公共部分尽可能长——换句话说，剩下的部分应该正好就是两个字符串的**最长公共子序列**（LCS）。

设 `word1` 长度为 `n`，`word2` 长度为 `m`，LCS 长度为 `lcs`，那 `word1` 就要删掉 `n - lcs` 个字符，`word2` 要删掉 `m - lcs` 个字符，加起来总的删除步数就是：

```
result = n + m - 2 * lcs
```

那 `lcs` 怎么求呢？跟 1143 题一模一样：`dp[i][j]` 表示 `word1` 前 `i` 个字符和 `word2` 前 `j` 个字符的最长公共子序列长度，递推公式是字符相等时 `dp[i][j] = dp[i-1][j-1] + 1`，不相等时 `dp[i][j] = max(dp[i-1][j], dp[i][j-1])`。这个思路的价值在于，它展示了"新问题可以转化成已经解决过的经典问题"这种建模能力，但说实话绕了一层弯，不如直接定义 dp 来得直观。

**思路二：直接定义 dp 表示删除步数（更贴近本题语义）**

**1. 确定 dp 数组以及下标的含义**

这里 `dp[i][j]` 表示的是：`word1` 前 `i` 个字符和 `word2` 前 `j` 个字符要变成相同，最少需要删除多少步。

**2. 确定递推公式**

先说第一种情况，如果 `word1[i-1] == word2[j-1]`，这个字符根本不用删，两边都留着就行，那问题就退化成了前一个子问题：

```
dp[i][j] = dp[i-1][j-1]
```

那如果 `word1[i-1] != word2[j-1]` 呢？这时候必须删掉其中一个字符才能继续往下比，这里有两个选择：要么删 `word1[i-1]`（对应 `dp[i-1][j] + 1`），要么删 `word2[j-1]`（对应 `dp[i][j-1] + 1`），咱们取步数少的那一个：

```
dp[i][j] = min(dp[i-1][j] + 1, dp[i][j-1] + 1)
```

你会发现这个递推公式跟 1143 最长公共子序列里"不匹配时取两个方向的最大值"其实是同一种结构，都是从左边、上边这两个已知状态推出当前状态，区别就是本题求的是"删除步数的最小值"，而 1143 求的是"公共长度的最大值"——说白了都是"不匹配的时候，在两个可能的推进方向里挑一个最优的"。

**3. dp 数组如何初始化**

`dp[i][0] = i`：这个好理解，`word2` 是空字符串的话，要把 `word1` 前 `i` 个字符也变成空，那肯定得删 `i` 次。

`dp[0][j] = j`：同理，反过来 `word1` 为空的时候，就得删 `word2` 的 `j` 个字符。

**4. 确定遍历顺序**

这个顺序是从上到下、从左到右，为什么呢？因为 `dp[i][j]` 要依赖左上方、正上方、正左方这三个已经算出来的值，所以得按这个顺序推过去。

**5. 举例推导 dp 数组**

咱们拿 `word1 = "sea"`，`word2 = "eat"` 来举个例子：

| dp | "" | e | a | t |
|----|----|---|---|---|
| "" | 0  | 1 | 2 | 3 |
| s  | 1  | 2 | 3 | 4 |
| e  | 2  | 1 | 2 | 3 |
| a  | 3  | 2 | 1 | 2 |

最终推出来 `dp[3][3] = 2`，跟预期是一致的。这里可以留意一下 `word1[1]='e'` 与 `word2[0]='e'` 相等的那一格：`dp[2][1] = dp[1][0] = 1`，直接从左上角继承过来的。

**复杂度分析**

- 时间复杂度上，两种思路是一样的，都是 O(n·m)。
- 空间复杂度也是 O(n·m)，不过这个可以用滚动数组去优化掉。

## 代码

下面的代码用的是思路二，也就是直接定义删除步数这种写法，这样更能体现出本题作为编辑距离铺垫题的价值。

### C++

```cpp
class Solution {
public:
    int minDistance(string word1, string word2) {
        int n = word1.size(), m = word2.size();
        vector<vector<int>> dp(n + 1, vector<int>(m + 1, 0));
        for (int i = 0; i <= n; i++) dp[i][0] = i;  // word2为空，需删除i次
        for (int j = 0; j <= m; j++) dp[0][j] = j;  // word1为空，需删除j次

        for (int i = 1; i <= n; i++) {
            for (int j = 1; j <= m; j++) {
                if (word1[i - 1] == word2[j - 1]) {
                    dp[i][j] = dp[i - 1][j - 1];  // 字符相等，不用删除，继承左上角
                } else {
                    // 不相等：删word1[i-1]，或删word2[j-1]，取步数更少的
                    dp[i][j] = min(dp[i - 1][j] + 1, dp[i][j - 1] + 1);
                }
            }
        }
        return dp[n][m];
    }
};
```

```java
class Solution {
    public int minDistance(String word1, String word2) {
        int n = word1.length(), m = word2.length();
        int[][] dp = new int[n + 1][m + 1];
        for (int i = 0; i <= n; i++) dp[i][0] = i;  // word2为空，需删除i次
        for (int j = 0; j <= m; j++) dp[0][j] = j;  // word1为空，需删除j次

        for (int i = 1; i <= n; i++) {
            for (int j = 1; j <= m; j++) {
                if (word1.charAt(i - 1) == word2.charAt(j - 1)) {
                    dp[i][j] = dp[i - 1][j - 1];  // 字符相等，继承左上角
                } else {
                    // 不相等：删word1[i-1]，或删word2[j-1]
                    dp[i][j] = Math.min(dp[i - 1][j] + 1, dp[i][j - 1] + 1);
                }
            }
        }
        return dp[n][m];
    }
}
```

### Go

```go
func minDistance(word1 string, word2 string) int {
    n, m := len(word1), len(word2)
    dp := make([][]int, n+1)
    for i := range dp {
        dp[i] = make([]int, m+1)
    }
    for i := 0; i <= n; i++ {
        dp[i][0] = i // word2为空，需删除i次
    }
    for j := 0; j <= m; j++ {
        dp[0][j] = j // word1为空，需删除j次
    }

    for i := 1; i <= n; i++ {
        for j := 1; j <= m; j++ {
            if word1[i-1] == word2[j-1] {
                dp[i][j] = dp[i-1][j-1] // 字符相等，继承左上角
            } else {
                del1 := dp[i-1][j] + 1 // 删word1[i-1]
                del2 := dp[i][j-1] + 1 // 删word2[j-1]
                if del1 < del2 {
                    dp[i][j] = del1
                } else {
                    dp[i][j] = del2
                }
            }
        }
    }
    return dp[n][m]
}
```

## 总结

- 这道题可以转化成"先求最长公共子序列，再用总长度减去 2 倍 LCS 长度"，这个思路展示了问题之间互相转化的能力，不过直接定义删除步数的 dp 其实更贴近题目本身的语义。
- 直接定义的时候，字符不相等那里的递推公式，就是"删 word1 或者删 word2，取比较优的那个"，这是"求最小步数"这类 DP 的典型写法，跟 1143 题"取两个方向最大值"的结构是一样的，只是优化方向反过来了——一个求 min，一个求 max。
- 这一步其实是通往 72 题编辑距离的关键：本题只有"删除"这一种操作，而 72 题会在这个基础上再引入"插入"和"替换"，递推公式也会从两个方向的 min 扩展成三个方向的 min。
