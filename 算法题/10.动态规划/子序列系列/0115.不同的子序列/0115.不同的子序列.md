# 115. 不同的子序列

**题目描述**

给定两个字符串 `s` 和 `t`，求 `s` 的子序列中等于 `t` 的个数（子序列不要求连续，只要求保持相对顺序）。

```
示例：
输入: s = "rabbbit", t = "rabbit"
输出: 3
解释: s 中有 3 种不同的子序列可以匹配出 t = "rabbit"
（分别对应 s 中三个不同的 'b' 被舍弃的方案）
```

结果可能很大，题目保证在 32 位有符号整数范围内。

## 思路

DP：`dp[i][j]` 为 `s` 前 `i` 个字符中组成 `t` 前 `j` 个字符的方案数。`dp[i][0]=1`，其余为 0，逐行正序：

- 末字符相同：`dp[i][j]=dp[i-1][j]+dp[i-1][j-1]`，分别为不用、使用当前字符。
- 不同：`dp[i][j]=dp[i-1][j]`。

返回 `dp[n][m]`。时间、空间 O(nm)；一维滚动须按 j 倒序，空间可降至 O(m)。



## Python

### LeetCode 写法与原有示例

```python
# 依赖说明：len：Python 内置函数：返回容器中元素的数量。；range：Python 内置函数：生成按步长遍历的整数序列。

class Solution:
    # 方法：numDistinct；按题目要求处理输入并返回结果，核心算法见方法体。
    def numDistinct(self, s: str, t: str) -> int:
        n, m = len(s), len(t)
        dp = [[0] * (m + 1) for _ in range(n + 1)]
        for i in range(n + 1):
            dp[i][0] = 1  # t为空时只有一种方案：什么都不选

        for i in range(1, n + 1):
            for j in range(1, m + 1):
                if s[i - 1] == t[j - 1]:
                    # 相等：用当前字符匹配(dp[i-1][j-1]) + 不用当前字符匹配(dp[i-1][j])
                    dp[i][j] = dp[i - 1][j - 1] + dp[i - 1][j]
                else:
                    # 不等：只能跳过s[i-1]，继承dp[i-1][j]
                    dp[i][j] = dp[i - 1][j]
        return dp[n][m]
```

// 依赖说明：vector：C++ STL 动态数组。；string：C++ STL 字符串类型。

class Solution {
public:
    // 方法：numDistinct；按题目要求处理输入并返回结果，核心算法见方法体。
    int numDistinct(string s, string t) {
        int n = s.size(), m = t.size();
        vector<vector<unsigned long long>> dp(n + 1, vector<unsigned long long>(m + 1, 0));
        for (int i = 0; i <= n; i++) dp[i][0] = 1;  // t为空时，只有"什么都不选"这一种方案
        for (int i = 1; i <= n; i++) {
            for (int j = 1; j <= m; j++) {
                if (s[i - 1] == t[j - 1]) {
                    // 字符相等：可以用当前字符匹配(dp[i-1][j-1])，也可以不用(dp[i-1][j])，两种方案相加
                    dp[i][j] = dp[i - 1][j - 1] + dp[i - 1][j];
                } else {
                    // 字符不等：只能跳过s[i-1]，继承dp[i-1][j]
                    dp[i][j] = dp[i - 1][j];
                }
            }
        }
        return (int)dp[n][m];
    }
};```

## 总结

- 你会发现 `dp[i][j]` 从原来"求长度"升级成了"求方案数"，这其实是子序列 DP 从判定类问题过渡到计数类问题的一个关键跨越。
- 字符相等的时候，递推公式用的是"相加"而不是"取最大值"，为什么呢，因为"用当前字符"和"不用当前字符"是两种互斥、但又都合法的方案，必须把所有方案数一个不落地累加起来，这也正是计数类 DP 最核心的思维方式。
- 字符不相等的时候，就只能继承 `dp[i-1][j]`，因为当前字符压根没机会参与匹配，这一分支其实也顺带解释清楚了"相等情况"里面那个 `dp[i-1][j]` 项到底是从哪儿来的。
- 还有一点容易被忽略：`dp[i][0] = 1` 而不是 0，因为空字符串永远都是任何字符串的子序列，而且只有唯一的一种（空）匹配方式，这个初始化条件说白了很多人第一次做的时候都容易漏掉。
