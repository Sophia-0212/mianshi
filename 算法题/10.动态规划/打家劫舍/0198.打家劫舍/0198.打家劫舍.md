# 198. 打家劫舍

**题目描述**

你是一个专业的小偷，计划偷窃一排沿街的房屋。每间房屋都藏有一定的现金，唯一的限制因素是相邻的两间房屋装有相互连通的防盗报警系统，如果两间相邻的房屋在同一晚被偷，系统会自动报警。给定一个非负整数数组 `nums`，`nums[i]` 表示第 `i` 间房屋存放的金额，计算你在不触动报警装置的情况下，一夜之内能够偷窃到的最高金额。

```
示例：
输入: nums = [2,7,9,3,1]
输出: 12
解释: 偷窃 1 号房屋 (金额 = 7)，偷窃 3 号房屋 (金额 = 9)，偷窃 5 号房屋 (金额 = 1)。
     偷窃到的最高金额 = 7 + 9 + 1 = 17？不对，正确组合是偷 0、2、4 号房屋：2+9+1=12。
```

## 思路

这是一道线性结构上的动态规划入门题，我用"DP五部曲"来完整拆解一下。

**1. 确定 dp 数组（含下标）的含义**

我定义 `dp[i]` 表示考虑下标 `0` 到 `i` 这个范围内的所有房屋（你注意，这里不是"必须偷第 i 间"，而是"在前 i+1 间房屋里随意挑选，能偷到的最大金额"）。这个定义很关键：`dp[i]` 是一个"最优值"，而不是"第 i 间偷不偷"的状态标记，所以它天然具备"考虑过前面所有可能性后的最优解"这个性质，方便后面直接取 `dp[n-1]` 作为答案。

**2. 确定递推公式**

对于第 `i` 间房屋，你想啊，只有两种互斥的选择：

- **不偷第 i 间**：那么能拿到的最大金额就是不考虑第 i 间时、前 i 间的最优解，也就是 `dp[i-1]`（因为不偷第 i 间，第 i-1 间偷不偷都不受影响，所以直接沿用 `dp[i-1]` 的结果）。
- **偷第 i 间**：一旦偷了第 i 间，第 i-1 间就绝对不能偷了（不然会触发报警），所以只能在第 i-2 间及之前的最优解基础上，加上第 i 间的金额，即 `dp[i-2] + nums[i]`。

因为这两种选择是互斥且穷尽的（第 i 间不是偷就是不偷，没有第三种情况），取较大值就是 `dp[i]` 的最优解：

```
dp[i] = max(dp[i-1], dp[i-2] + nums[i])
```

这里有一个容易忽略但很重要的点：为什么状态转移只需要往前看两步（`dp[i-1]` 和 `dp[i-2]`），而不需要看 `dp[i-3]`、`dp[i-4]`……呢？原因是 `dp[i-1]` 本身已经"隐式包含"了所有更早的最优选择——它是通过递推得到的全局最优值，不是某个特定的偷窃方案。当我们写 `dp[i-2] + nums[i]` 时，`dp[i-2]` 已经自动排除了"偷第 i-1 间"的可能路径中更优的那个结果，我们不需要关心 `dp[i-2]` 具体是怎么偷出来的，只需要相信它是"前 i-1 间房屋能偷到的最大金额"这一件事就够了。这正是动态规划"最优子结构"的体现：子问题的最优解可以直接复用，不需要还原具体方案。

**3. dp 数组如何初始化**

初始化要覆盖递推公式里最先用到、但没有前置状态可以依赖的那几项：

- `dp[0] = nums[0]`：只有一间房屋时，没有任何相邻限制，直接偷这一间，金额就是 `nums[0]`。
- `dp[1] = max(nums[0], nums[1])`：只有两间房屋时，两间相邻，只能偷其中金额更大的一间。

这两个初始值必须手动给出，因为递推公式里 `dp[i-2]` 在 `i=1` 时会越界（`i-2=-1`），所以 `dp[0]` 和 `dp[1]` 是递推的起点，不能靠公式自动生成。

**4. 确定遍历顺序**

`dp[i]` 依赖 `dp[i-1]` 和 `dp[i-2]`，都是比 `i` 更小的下标，所以必须从前往后遍历（`i` 从 2 递增到 `n-1`），保证计算 `dp[i]` 时它依赖的两个状态都已经计算完毕。

**5. 举例推导 dp 数组**

我拿 `nums = [2,7,9,3,1]` 这个例子来推一下：

- `dp[0] = 2`
- `dp[1] = max(2,7) = 7`
- `dp[2] = max(dp[1], dp[0]+nums[2]) = max(7, 2+9) = 11`
- `dp[3] = max(dp[2], dp[1]+nums[3]) = max(11, 7+3) = 11`
- `dp[4] = max(dp[3], dp[2]+nums[4]) = max(11, 11+1) = 12`

最终 `dp[4] = 12`，对应偷 0、2、4 号房屋（2+9+1=12），跟预期是一致的。

**复杂度分析**

- 时间复杂度：O(n)，只需要遍历数组一次。
- 空间复杂度：O(n)，使用了长度为 n 的 dp 数组；如果只用两个变量滚动保存 `dp[i-1]` 和 `dp[i-2]`，可以将空间复杂度优化到 O(1)。

## 代码

### C++

```cpp
class Solution {
public:
    int rob(vector<int>& nums) {
        int n = nums.size();
        if (n == 0) return 0;              // 边界：没有房屋，偷不到钱
        if (n == 1) return nums[0];        // 边界：只有一间房屋，直接偷
        vector<int> dp(n);                 // dp[i]：前 i+1 间房屋能偷到的最大金额
        dp[0] = nums[0];                   // 初始化：只有第0间时，只能偷它
        dp[1] = max(nums[0], nums[1]);     // 初始化：两间相邻，取金额较大的一间
        for (int i = 2; i < n; i++) {
            // 第i间不偷：延续dp[i-1]；第i间偷：dp[i-2] 加上当前金额，取较优
            dp[i] = max(dp[i - 1], dp[i - 2] + nums[i]);
        }
        return dp[n - 1];                  // 最终答案是考虑全部房屋后的最优解
    }
};
```

### Java

```java
class Solution {
    public int rob(int[] nums) {
        int n = nums.length;
        if (n == 0) return 0;                      // 边界：没有房屋
        if (n == 1) return nums[0];                 // 边界：只有一间房屋
        int[] dp = new int[n];                      // dp[i]：前 i+1 间房屋能偷到的最大金额
        dp[0] = nums[0];                             // 初始化第0间
        dp[1] = Math.max(nums[0], nums[1]);          // 初始化第1间：两间相邻取较大值
        for (int i = 2; i < n; i++) {
            // 不偷第i间沿用dp[i-1]；偷第i间则从dp[i-2]转移，二者取最大
            dp[i] = Math.max(dp[i - 1], dp[i - 2] + nums[i]);
        }
        return dp[n - 1];                            // 返回考虑全部房屋的最优解
    }
}
```

class Solution:

        n = len(nums)
        if n == 0:
            return 0  # 边界：没有房屋
        if n == 1:
            return nums[0]  # 边界：只有一间房屋，直接偷

        dp[1] = max(nums[0], nums[1])  # 初始化第1间：两间相邻取较大值

            # 不偷第i间沿用dp[i-1]；偷第i间从dp[i-2]转移而来，取较大者

```go
func rob(nums []int) int {
    n := len(nums)
    if n == 0 {
        return 0 // 边界：没有房屋
    }
    if n == 1 {
        return nums[0] // 边界：只有一间房屋
    }

    dp := make([]int, n)             // dp[i]：前 i+1 间房屋能偷到的最大金额
    dp[0] = nums[0]                  // 初始化第0间
    dp[1] = max(nums[0], nums[1])    // 初始化第1间：两间相邻取较大值

    for i := 2; i < n; i++ {
        // 不偷第i间沿用dp[i-1]；偷第i间从dp[i-2]转移，取较优
        dp[i] = max(dp[i-1], dp[i-2]+nums[i])
    }

    return dp[n-1] // 返回考虑全部房屋后的最优解
}

func max(a, b int) int {
    if a > b {
        return a
    }
    return b
}
```

## 总结

- 本题的核心是识别出"选或不选"的二元决策结构：每间房屋只有偷/不偷两种状态，且这两种状态的收益分别来自 `dp[i-1]` 和 `dp[i-2]`，取较优就行，不需要枚举所有子集。
- 状态转移只依赖前两个状态，是因为 `dp[i-1]`、`dp[i-2]` 本身已经是"全局最优值"而不是某个具体方案，递推时不需要关心它们是怎么来的，只需要相信其数值正确性——这是"最优子结构"性质的直接体现。
- 初始化容易出错的点在于 `dp[1]` 必须取两间中的较大值，而不是简单地等于 `nums[1]` 或 `dp[0]+nums[1]`（后者是错误的，因为第0、1间相邻不能同时偷）。
- 空间上可以用两个滚动变量代替整个数组，把 O(n) 优化成 O(1)，因为每一步只用到前两个状态，这是线性DP常见的空间优化技巧。
