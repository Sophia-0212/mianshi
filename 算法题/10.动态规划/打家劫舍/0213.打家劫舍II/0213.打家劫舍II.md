# 213. 打家劫舍 II

**题目描述**

在上一题的基础上，所有的房屋不再排成一排，而是围成一个圈，也就是说第一间房屋和最后一间房屋是紧挨着的。其余规则不变：相邻的两间房屋不能在同一晚被偷，否则会触发警报。给定一个非负整数数组 `nums` 表示每间房屋存放的金额，计算在不触动警报的情况下能偷窃到的最高金额。

```
示例：
输入: nums = [2,3,2]
输出: 3
解释: 你不能偷窃 0 号房屋（金额 = 2）然后偷窃 2 号房屋（金额 = 2），
     因为它们是相邻的（0号和2号首尾相连），最优解是只偷1号房屋，金额为3。
```

## 思路

本题在 198 题的基础上多了一个环形约束：`nums[0]` 和 `nums[n-1]` 也算相邻。你想啊，如果直接套用 198 题的一维 dp 递推，会漏掉"首尾不能同时偷"这个限制，所以这里的关键是先做一次问题转化，再复用 198 题的解法，同样按 DP 五部曲来梳理。

**问题转化：环形拆成两个线性子问题**

环形结构的本质困难在于：dp 数组的下标 0 和下标 n-1 之间多了一条"看不见的边"，而线性 DP 只能处理相邻下标之间的约束，处理不了首尾之间的约束。解决思路是分类讨论——考虑最终的最优方案，第一间房屋（下标0）和最后一间房屋（下标n-1）不可能同时被偷（不然就违反环形相邻限制了），所以最优方案必然属于以下两种情况之一：

- **情况一**：不偷最后一间房屋，此时问题退化为对 `nums[0..n-2]`（不包含最后一间）求解线性打家劫舍问题；
- **情况二**：不偷第一间房屋，此时问题退化为对 `nums[1..n-1]`（不包含第一间）求解线性打家劫舍问题；

这两个子问题都不再有首尾相邻的环形约束，可以直接复用 198 题的一维 dp 解法。最终答案取两种情况计算结果的较大值：

```
result = max(rob_linear(nums[0..n-2]), rob_linear(nums[1..n-1]))
```

这里我论证一下为什么这样拆分是正确且完整的（既不漏解，也不引入非法解）：

- **不漏解**：最优方案中，第一间和最后一间不可能同时被偷。所以最优方案一定满足"不偷最后一间"或者"不偷第一间"（或者两者都不偷）。这意味着情况一和情况二这两个区间分别去做线性打家劫舍时，其中至少有一个区间包含了真正的最优方案对应的所有被偷房屋，所以取两者较大值一定能覆盖真正的最优解。
- **不引入非法解**：情况一的搜索范围是 `nums[0..n-2]`，天然不包含最后一间房屋，不会出现"偷了最后一间"的方案；同理情况二不会出现"偷了第一间"的方案。因此两种情况各自求出的线性最优解，都自动满足"首尾不同时被偷"这一环形约束，不会有非法方案混入。

**DP五部曲（应用于子问题 rob_linear）**

1. **dp 数组含义**：`dp[i]` 表示在给定的线性子区间中，考虑到第 `i` 个位置（区间内的相对下标）为止，能偷到的最大金额，跟 198 题完全一致。
2. **递推公式**：`dp[i] = max(dp[i-1], dp[i-2] + nums[i])`，第 i 间偷或不偷取较优，逻辑跟 198 题相同。
3. **初始化**：`dp[0] = nums[0]`（子区间的第一个元素），`dp[1] = max(nums[0], nums[1])`。
4. **遍历顺序**：从前往后遍历子区间，保证计算 `dp[i]` 时 `dp[i-1]`、`dp[i-2]` 已经就位。
5. **举例推导**：我拿 `nums = [2,3,2]` 这个例子来推一下，`n=3`。
   - 情况一（对应 `nums[0..1] = [2,3]`）：`dp[0]=2, dp[1]=max(2,3)=3`，最优为 3。
   - 情况二（对应 `nums[1..2] = [3,2]`）：`dp[0]=3, dp[1]=max(3,2)=3`，最优为 3。
   - 两者取较大值：`max(3,3) = 3`，跟预期输出一致。

**边界情况**

当 `n == 1` 时（只有一间房屋），环形约束不存在意义（一间房屋无法与"自己"相邻），这时候直接返回 `nums[0]` 就行，不需要走拆分逻辑，否则按照上面的拆分方式，两个子区间可能出现空区间或者单元素区间，需要在 `rob_linear` 内部也处理好长度为 0、1 的边界。

**复杂度分析**

- 时间复杂度：O(n)，两次线性 dp 各遍历一次子数组，仍是常数倍的 O(n)。
- 空间复杂度：O(n)（使用数组）或优化为 O(1)（使用滚动变量），与 198 题相同。

## 代码

### C++

```cpp
class Solution {
public:
    // 线性打家劫舍子问题：复用198题的解法
    int robLinear(vector<int>& nums, int start, int end) {
        // start、end 是闭区间下标，先处理区间为空或只有一个元素的边界
        if (start > end) return 0;
        if (start == end) return nums[start];
        int n = end - start + 1;
        vector<int> dp(n);
        dp[0] = nums[start];                        // 区间内第0个元素
        dp[1] = max(nums[start], nums[start + 1]);   // 区间内前两个元素取较大值
        for (int i = 2; i < n; i++) {
            // 第i个位置偷或不偷取较优，nums[start+i] 是区间内第i个元素对应的原数组下标
            dp[i] = max(dp[i - 1], dp[i - 2] + nums[start + i]);
        }
        return dp[n - 1];
    }

    int rob(vector<int>& nums) {
        int n = nums.size();
        if (n == 1) return nums[0];   // 边界：只有一间房屋，没有环形约束
        // 情况一：不偷最后一间，只考虑 [0, n-2]
        int case1 = robLinear(nums, 0, n - 2);
        // 情况二：不偷第一间，只考虑 [1, n-1]
        int case2 = robLinear(nums, 1, n - 1);
        return max(case1, case2);     // 两种情况取较优，即为环形问题的答案
    }
};
```

### Java

```java
class Solution {
    // 线性打家劫舍子问题：复用198题的解法，处理 nums[start..end] 闭区间
    private int robLinear(int[] nums, int start, int end) {
        if (start > end) return 0;               // 区间为空，没有房屋可偷
        if (start == end) return nums[start];    // 区间只有一间房屋
        int n = end - start + 1;
        int[] dp = new int[n];
        dp[0] = nums[start];                              // 初始化区间第0个元素
        dp[1] = Math.max(nums[start], nums[start + 1]);    // 初始化前两个元素取较大值
        for (int i = 2; i < n; i++) {
            // 偷或不偷第i个位置（对应原数组 start+i）取较优
            dp[i] = Math.max(dp[i - 1], dp[i - 2] + nums[start + i]);
        }
        return dp[n - 1];
    }

    public int rob(int[] nums) {
        int n = nums.length;
        if (n == 1) return nums[0];                        // 边界：单间房屋无环形约束
        int case1 = robLinear(nums, 0, n - 2);              // 情况一：不偷最后一间
        int case2 = robLinear(nums, 1, n - 1);              // 情况二：不偷第一间
        return Math.max(case1, case2);                      // 取两种情况的较优解
    }
}
```

### Python

```python
class Solution:
    def rob(self, nums: list[int]) -> int:
        n = len(nums)
        if n == 1:
            return nums[0]  # 边界：只有一间房屋，没有环形约束

        def rob_linear(arr: list[int]) -> int:
            # 线性打家劫舍子问题，复用198题解法
            m = len(arr)
            if m == 0:
                return 0  # 空区间没有房屋
            if m == 1:
                return arr[0]  # 单元素区间直接返回

            dp = [0] * m
            dp[0] = arr[0]                    # 初始化第0个元素
            dp[1] = max(arr[0], arr[1])        # 初始化前两个元素取较大值
            for i in range(2, m):
                # 偷或不偷第i个位置取较优
                dp[i] = max(dp[i - 1], dp[i - 2] + arr[i])
            return dp[m - 1]

        case1 = rob_linear(nums[:-1])   # 情况一：不偷最后一间，切片排除末尾
        case2 = rob_linear(nums[1:])    # 情况二：不偷第一间，切片排除开头
        return max(case1, case2)         # 两种情况取较优解
```

### Go

```go
func robLinear(nums []int) int {
    // 线性打家劫舍子问题，复用198题解法，nums 是已经切好的子数组
    m := len(nums)
    if m == 0 {
        return 0 // 空区间没有房屋
    }
    if m == 1 {
        return nums[0] // 单元素区间直接返回
    }

    dp := make([]int, m)
    dp[0] = nums[0]                 // 初始化第0个元素
    dp[1] = max(nums[0], nums[1])   // 初始化前两个元素取较大值
    for i := 2; i < m; i++ {
        // 偷或不偷第i个位置取较优
        dp[i] = max(dp[i-1], dp[i-2]+nums[i])
    }
    return dp[m-1]
}

func rob(nums []int) int {
    n := len(nums)
    if n == 1 {
        return nums[0] // 边界：只有一间房屋，没有环形约束
    }
    case1 := robLinear(nums[:n-1]) // 情况一：不偷最后一间，切片排除末尾元素
    case2 := robLinear(nums[1:])   // 情况二：不偷第一间，切片排除开头元素
    return max(case1, case2)        // 两种情况取较优解
}

func max(a, b int) int {
    if a > b {
        return a
    }
    return b
}
```

## 总结

- 处理环形约束的核心技巧是"分类讨论 + 降维"：把环形问题拆成两个不含环形约束的线性子问题分别求解，再取较优解，前提是要证明这样拆分既不漏解也不引入非法解。
- 判断依据很直接：最优方案里第一间和最后一间不可能同时被偷，所以"不偷最后一间"和"不偷第一间"这两种情况必然覆盖真正的最优解。
- 容易出错的点是边界条件：当只有 1 间房屋时不能走拆分逻辑（会导致区间为空或者下标越界），必须单独处理；此外子区间求解时要注意下标偏移（区间内的相对下标 vs 原数组下标）。
- 本题体现的是动态规划中常见的"化归"思想——遇到复杂约束时，先尝试把问题转化为已经会解的子问题组合，而不是从零设计新的状态转移方程。
