# 0063. 不同路径 II

**题目描述**

一个机器人位于一个 `m x n` 网格的左上角，机器人每次只能向下或者向右移动一步，机器人试图达到网格的右下角。现在考虑网格中有障碍物，那么从左上角到右下角将会有多少条不同的路径？网格用 `obstacleGrid` 表示，其中 `1` 表示障碍物，`0` 表示空地，机器人不能走进有障碍物的格子。

```
示例：
输入: obstacleGrid = [[0,0,0],[0,1,0],[0,0,0]]
输出: 2
解释: 3x3 网格的中间位置(1,1)有一个障碍物，
从左上角到右下角一共有 2 条不同的路径：
1. 向右 -> 向右 -> 向下 -> 向下
2. 向下 -> 向下 -> 向右 -> 向右
```

如果起点或终点本身就是障碍物，直接返回 0。

## 思路

DP：`dp[i][j]` 表示到达格子的路径数。障碍处为 0，其余为上方与左方之和。首行、首列从起点初始化为 1，遇障碍后保持 0；逐行递推，返回右下角。

时间 O(mn)，空间 O(mn)，滚动数组可降为 O(n)。



## Python

### LeetCode 写法与原有示例

```python
# 依赖说明：len：Python 内置函数：返回容器中元素的数量。；range：Python 内置函数：生成按步长遍历的整数序列。

class Solution:
    # 方法：uniquePathsWithObstacles；按题目要求处理输入并返回结果，核心算法见方法体。
    def uniquePathsWithObstacles(self, obstacleGrid: list[list[int]]) -> int:
        m, n = len(obstacleGrid), len(obstacleGrid[0])
        dp = [[0] * n for _ in range(m)]

        # 初始化第一列，遇到障碍物后停止赋1，后面保持默认的0
        for i in range(m):
            if obstacleGrid[i][0] == 1:
                break
            dp[i][0] = 1

        # 初始化第一行，遇到障碍物后停止赋1
        for j in range(n):
            if obstacleGrid[0][j] == 1:
                break
            dp[0][j] = 1

        for i in range(1, m):
            for j in range(1, n):
                if obstacleGrid[i][j] == 1:
                    dp[i][j] = 0  # 当前是障碍物，路径数为0
                    continue
                # 递推公式：上方路径数+左方路径数；障碍物处的0会自动正确传递
                dp[i][j] = dp[i - 1][j] + dp[i][j - 1]

        return dp[m - 1][n - 1]
```

### LeetCode 写法与原有示例

```cpp
// 依赖说明：vector：C++ STL 动态数组。

class Solution {
public:
    // 方法：uniquePathsWithObstacles；按题目要求处理输入并返回结果，核心算法见方法体。
    int uniquePathsWithObstacles(vector<vector<int>>& obstacleGrid) {
        int m = obstacleGrid.size(), n = obstacleGrid[0].size();
        vector<vector<int>> dp(m, vector<int>(n, 0));

        // 初始化第一列：遇到障碍物后，之后的格子全部保持为0（无法绕过）
        for (int i = 0; i < m && obstacleGrid[i][0] == 0; i++) {
            dp[i][0] = 1;
        }
        // 初始化第一行：遇到障碍物后，之后的格子全部保持为0
        for (int j = 0; j < n && obstacleGrid[0][j] == 0; j++) {
            dp[0][j] = 1;
        }

        for (int i = 1; i < m; i++) {
            for (int j = 1; j < n; j++) {
                if (obstacleGrid[i][j] == 1) {
                    dp[i][j] = 0; // 当前格子是障碍物，机器人无法停留，路径数为0
                    continue;
                }
                // 递推公式：不是障碍物时，路径数=上方路径数+左方路径数
                // 若上方或左方是障碍物，其dp值早已是0，会自动正确地传递
                dp[i][j] = dp[i - 1][j] + dp[i][j - 1];
            }
        }
        return dp[m - 1][n - 1];
    }
};```

## 总结

- 递推公式的核心思路跟"不同路径"这一题完全一致，这道题的难点全都集中在初始化和障碍物判断上，而不在递推逻辑本身。
- 第一行/第一列初始化时一旦碰到障碍物，之后的整行/整列都必须保持为 0，因为沿边缘走一旦被挡住就彻底没法绕路。
- 递推公式内部不需要专门判断上方/左方格子是不是障碍物，因为障碍物格子的 dp 值本来就是 0，会自动正确地往下游传递"此路不通"这个信息。
- 这种"用 0 表示不可达，让 0 在状态转移中自然传播"的技巧，在很多带约束条件的网格 DP 题目里都会用到，是处理约束条件的常见通用手段。
