# 0673. 最长递增子序列的个数

**题目描述**

给定一个未排序的整数数组 `nums`，返回最长递增子序列的个数（子序列不要求连续，但要求严格递增）。

```
示例：
输入: nums = [1,3,5,4,7]
输出: 2
解释: 最长递增子序列的长度是4，有两种方案得到长度为4的递增子序列，分别是 [1,3,4,7] 和 [1,3,5,7]。

输入: nums = [2,2,2,2,2]
输出: 5
解释: 最长递增子序列的长度是1，方案有5种，即选取数组中任意一个单独的元素。
```

## 思路

DP：`dp[i]`、`count[i]` 分别为以 `i` 结尾的最长递增长度及方案数，均初始化为 1。正序枚举 `i`，对满足 `j<i && nums[j]<nums[i]` 的位置：

更长时替换长度和计数：

```
dp[i] = dp[j] + 1
count[i] = count[j]   // 重新赋值，不是累加！
```

等长时累加计数：

```
count[i] += count[j]   // 累加，因为是并列的等长方案
```

最后累加所有 `dp[i]==max(dp)` 的 `count[i]`。

时间 O(n²)，空间 O(n)。

class Solution:
    # 方法：findNumberOfLIS；按题目要求处理输入并返回结果，核心算法见方法体。
    def findNumberOfLIS(self, nums: list[int]) -> int:
        n = len(nums)
        dp = [1] * n     # 每个元素单独成序列，长度1
        count = [1] * n  # 对应方案数1
        for i in range(n):
            for j in range(i):
                if nums[j] < nums[i]:              # 只有严格递增才能转移
                    if dp[j] + 1 > dp[i]:           # 情况一：发现更长路径，刷新记录
                        dp[i] = dp[j] + 1
                        count[i] = count[j]         # 重新赋值，旧方案数作废
                    elif dp[j] + 1 == dp[i]:        # 情况二：追平最长记录，累加方案
                        count[i] += count[j]
        max_len = max(dp)  # 全局最长长度
        return sum(count[i] for i in range(n) if dp[i] == max_len)  # 累加所有达到最长长度的方案数```

func findNumberOfLIS(nums []int) int {
    n := len(nums)
    dp := make([]int, n)
    count := make([]int, n)
    for i := range dp {
        dp[i], count[i] = 1, 1 // 每个元素单独成序列，长度1，方案数1
    }
    for i := 0; i < n; i++ {
        for j := 0; j < i; j++ {
            if nums[j] < nums[i] { // 只有严格递增才能转移
                if dp[j]+1 > dp[i] { // 情况一：发现更长路径，刷新记录
                    dp[i] = dp[j] + 1
                    count[i] = count[j] // 重新赋值，旧方案数作废
                } else if dp[j]+1 == dp[i] { // 情况二：追平最长记录，累加方案
                    count[i] += count[j]
                }
            }
        }
    }
    maxLen := 0
    for _, v := range dp {
        if v > maxLen {
            maxLen = v // 全局最长长度
        }
    }
    result := 0
    for i := 0; i < n; i++ {
        if dp[i] == maxLen {
            result += count[i] // 累加所有达到最长长度的方案数
        }
    }
    return result

```cpp
class Solution {
public:
    // 方法：findNumberOfLIS；按题目要求处理输入并返回结果，核心算法见方法体。
    int findNumberOfLIS(vector<int>& nums) {
        int n = nums.size();
        vector<int> dp(n, 1), count(n, 1); // 每个元素单独成序列，长度1，方案数1
        for (int i = 0; i < n; i++) {
            for (int j = 0; j < i; j++) {
                if (nums[j] < nums[i]) {           // 只有严格递增才能转移
                    if (dp[j] + 1 > dp[i]) {        // 情况一：发现更长路径，刷新记录
                        dp[i] = dp[j] + 1;
                        count[i] = count[j];        // 重新赋值，旧方案数作废
                    } else if (dp[j] + 1 == dp[i]) { // 情况二：追平最长记录，累加方案
                        count[i] += count[j];
                    }
                }
            }
        }
        int maxLen = *max_element(dp.begin(), dp.end()); // 全局最长长度
        int result = 0;
        for (int i = 0; i < n; i++) {
            if (dp[i] == maxLen) {
                result += count[i];  // 累加所有达到最长长度的方案数
            }
        }
        return result;
    }
};
```

## 总结

- 这道题的核心是"双重DP"：`dp[i]` 沿用300题的定义记录长度，`count[i]` 是新增的、专门记录方案数的数组，两者必须同步更新，且更新逻辑不同——这是"在已有DP基础上扩展统计维度"的典型技巧，遇到"不仅要求最优值、还要求方案数"的题目都可以借鉴这个模式。
- 最容易出错的地方是 `dp[j]+1 > dp[i]` 与 `dp[j]+1 == dp[i]` 这两种情况的区分：前者是发现更优解，必须清空重新赋值；后者是发现同样优的并列解，需要累加。混淆两者会导致方案数统计错误（多算或少算）。
- 最终答案要遍历所有 `dp[i] == maxLen` 的位置并累加对应 `count[i]`，因为最长递增子序列可能在数组中以多个不同的位置结尾，不能只看某一个位置的 `count`。
- 这道题和300题的关系类似"求最优值"与"求最优方案数"的一般性扩展关系，做完300题后再做这道题，可以体会同一个状态定义如何被复用并附加统计信息，这也是动态规划题型训练中常见的递进式练习方式。
