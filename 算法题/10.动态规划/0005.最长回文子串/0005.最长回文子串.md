# 0005. 最长回文子串

**题目描述**

给定一个字符串 `s`，找到 `s` 中最长的回文子串，并返回这个子串本身（不是长度）。回文串是指正着读和反着读都一样的字符串，子串要求是连续的一段字符。

```
示例：
输入: s = "babad"
输出: "bab"
解释: "aba" 同样是符合题意的答案（存在多个最长回文子串时，返回任意一个即可）。

输入: s = "cbbd"
输出: "bb"
```

## 思路

这道题你可以先想一想，它和 647 题「回文子串」其实是同一个内核，区别就在于 647 题是要统计所有回文子串一共有多少个，而这道题是要找出最长的那一个，还得把具体的子串内容给还原出来。既然底层逻辑是一样的，那就直接沿用区间DP那套思路，只不过要多维护两个变量来记录答案。

**状态定义是什么呢**：我们设 `dp[i][j]` 表示字符串 `s` 在闭区间 `[i, j]` 这一段（也就是 `s[i..j]`，两端都算进去）是不是一个回文串，是个布尔值。这个定义跟647题完全一样，为什么呢？因为要解决的子问题本质上是同一件事——判断某一段区间是不是回文。

**那递推公式怎么推呢**：这里要分两种情况讨论。如果 `s[i] != s[j]`，两端的字符都不相等，那整体肯定不是回文，直接 `dp[i][j] = false`。如果 `s[i] == s[j]` 呢，这时候就得看区间长度了：长度是1（也就是 `i == j`，其实就是单个字符）或者长度是2（`j - i == 1`）的时候，两端相等就够了，不需要再看中间；但长度大于等于3（`j - i >= 2`）的时候，还得看去掉两端之后剩下的中间那一段 `[i+1, j-1]` 是不是回文。把这些情况合并起来写成一个式子：

```
dp[i][j] = (s[i] == s[j]) && (j - i < 2 || dp[i+1][j-1])
```

这里的 `j - i < 2` 和647题里写的 `j - i <= 1` 其实是一回事，只是写法不一样，说白了都是在覆盖长度1、2这两种不用看中间结果就能判断的情况。

**初始化怎么做**：`dp` 数组一开始全部设成 `false`。同时我们还要额外准备两个变量：一个叫 `maxLen`，用来记录目前发现的最长回文子串的长度（初始可以设成0或者1）；另一个叫 `start`，记录这个最长回文子串是从哪个下标开始的（初始为0）。你想啊，单个字符肯定是回文，所以初始化的时候直接把 `maxLen` 设成1、`start` 设成0，这样至少能保证有一个字符的答案，避免空字符串之类的边界问题（题目已经保证 `s` 长度至少是1）。

**遍历顺序要注意什么**：这一点是这道题和647题共同最容易踩坑的地方。因为 `dp[i][j]` 要依赖左下方的 `dp[i+1][j-1]`（也就是行号更大、列号更小的那个位置），所以必须保证第 `i+1` 行先算完，才能开始算第 `i` 行。也就是说外层循环的 `i` 得从大到小遍历，从字符串最后一个下标一直减到0，内层循环的 `j` 从 `i` 往后递增到末尾就行。要是习惯性地写成 `i` 从小到大遍历，就会出现还没算出 `dp[i+1][...]` 就去读它的情况，读到的只是初始值 `false`，整个判断就全错了。

**怎么把具体的子串还原出来呢**：在递推的过程中，每当算出 `dp[i][j] == true`，就顺手检查一下这个区间的长度 `j - i + 1` 有没有比当前记录的 `maxLen` 更大，如果更大就更新 `maxLen = j - i + 1`，同时 `start = i`。等全部遍历结束之后，用 `s.substr(start, maxLen)`（或者对应语言的切片写法）就能截取出答案了。因为外层 `i` 是从大到小遍历的，第一次遇到某个长度的回文时就会被记下来，后面再遇到同样长度的回文也不会覆盖它（除非长度更大才会覆盖），所以最终返回的其实是按遍历顺序找到的第一个最长回文，这正好满足题目里"存在多个答案返回任意一个"的要求。

**复杂度说一下**：两层循环把所有区间组合都遍历一遍，时间复杂度是 O(n²)；用了一个 n×n 的二维数组来保存判断结果，空间复杂度也是 O(n²)。

**再对比一下中心扩展法**：中心扩展法是另一个很经典的解法，思路是枚举每一个可能作为回文中心的位置，然后往两边扩展。你想啊，回文中心其实有两类——一类是单字符中心（比如"aba"就是以中间的'b'为中心），另一类是双字符中心（比如"abba"是以中间两个'b'之间的那个空隙为中心）。所以对每个下标 `i`，得分别以 `(i, i)` 和 `(i, i+1)` 作为起点向外扩展，只要左右字符相等就继续往外扩大范围，直到不相等或者越界为止，扩展过程中记录出现过的最长回文。中心扩展法的时间复杂度同样是 O(n²)（n个中心，每个中心最多扩展O(n)次），但好处是空间复杂度只需要 O(1)，不需要额外开一个二维数组，算是既省时间又省空间的一种优化写法。这两种方法思路不同，但复杂度量级差不多，DP的优势是可以顺带解决647题这种"统计所有回文子串数量"的问题，中心扩展法则更省内存、代码也更短。实际面试里如果只要求"找最长回文子串"，面试官往往更希望看到中心扩展法的写法，但理解DP解法对建立区间DP的通用思维还是很有帮助的。

## 代码

### C++

```cpp
class Solution {
public:
    string longestPalindrome(string s) {
        int n = s.size();
        vector<vector<bool>> dp(n, vector<bool>(n, false)); // dp[i][j]初始化为false
        int maxLen = 1, start = 0;   // 至少单字符是回文，先占位
        for (int i = n - 1; i >= 0; i--) {        // 外层i从大到小，保证i+1行先算完
            for (int j = i; j < n; j++) {         // 内层j从i到n-1，保证区间[i,j]合法
                if (s[i] == s[j] && (j - i < 2 || dp[i + 1][j - 1])) {
                    dp[i][j] = true;              // 两端相等且中间也回文（或长度<=2）
                    if (j - i + 1 > maxLen) {      // 发现更长的回文，更新答案
                        maxLen = j - i + 1;
                        start = i;
                    }
                }
            }
        }
        return s.substr(start, maxLen); // 截取最长回文子串
    }
};
```

## 总结

- 说白了，本题的状态定义和转移方程跟647题「回文子串」是完全一致的，唯一的区别就是这道题需要额外维护 `maxLen` 和 `start` 这两个变量，在递推的同时把最优解的位置也记下来。这其实是一种很常见的套路——"DP判断 + 顺带记录答案"，以后遇到"求具体方案"而不是"求数量或布尔值"的题目，都可以借鉴这个思路。
- 遍历顺序还是这道题最容易出错的地方：外层的 `i` 一定要从大到小遍历，这样才能保证算 `dp[i][j]` 的时候，它依赖的 `dp[i+1][j-1]` 已经提前算好了，这是所有区间DP都通用的规律。
- 中心扩展法是空间复杂度更优的一个替代方案，只需要 O(1) 的额外空间，关键是要枚举两类中心（单字符中心和双字符中心）才能把奇数长度和偶数长度的回文都覆盖到，实际面试中面试官更希望你能写出这个解法。
- 还有一点要提一下，"回文子串"（要求连续）和"回文子序列"（可以跳着选字符）是两个完全不同的概念，它们的DP定义和解法也完全不一样，做题的时候题目描述里的"子串"这个词一定要看清楚，别搞混了。
