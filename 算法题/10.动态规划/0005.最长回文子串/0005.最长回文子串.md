# 0005. 最长回文子串

**题目描述**

给定一个字符串 `s`，找到 `s` 中最长的回文子串，并返回这个子串本身（不是长度）。回文串是指正着读和反着读都一样的字符串，子串要求是连续的一段字符。

```
示例：
输入: s = "babad"
输出: "bab"
解释: "aba" 同样是符合题意的答案（存在多个最长回文子串时，返回任意一个即可）。

输入: s = "cbbd"
输出: "bb"
```

## 思路

- 区间 DP：`dp[i][j]` 表示 `s[i..j]` 是否回文，初值为假；当两端相等且（长度≤2 或内部回文）时为真。`i` 倒序、`j` 正序，记录最长区间。时间、空间 O(n²)。
- 中心扩展：枚举单字符、双字符中心，向两侧扩展相等字符，记录最长区间。时间 O(n²)，辅助空间 O(1)，返回子串需 O(n) 空间。

### LeetCode 写法与原有示例

```python
# 依赖说明：len：Python 内置函数：返回容器中元素的数量。；range：Python 内置函数：生成按步长遍历的整数序列。

class Solution:
    # 方法：longestPalindrome；按题目要求处理输入并返回结果，核心算法见方法体。
    def longestPalindrome(self, s: str) -> str:
        n = len(s)
        dp = [[False] * n for _ in range(n)]  # dp[i][j]初始化为False
        max_len, start = 1, 0                 # 至少单字符是回文，先占位
        for i in range(n - 1, -1, -1):        # 外层i从大到小，保证i+1行先算完
            for j in range(i, n):             # 内层j从i到n-1，保证区间[i,j]合法
                if s[i] == s[j] and (j - i < 2 or dp[i + 1][j - 1]):
                    dp[i][j] = True            # 两端相等且中间也回文（或长度<=2）
                    if j - i + 1 > max_len:    # 发现更长的回文，更新答案
                        max_len = j - i + 1
                        start = i
        return s[start:start + max_len]       # 截取最长回文子串```

## 总结

- 说白了，本题的状态定义和转移方程跟647题「回文子串」是完全一致的，唯一的区别就是这道题需要额外维护 `maxLen` 和 `start` 这两个变量，在递推的同时把最优解的位置也记下来。这其实是一种很常见的套路——"DP判断 + 顺带记录答案"，以后遇到"求具体方案"而不是"求数量或布尔值"的题目，都可以借鉴这个思路。
- 遍历顺序还是这道题最容易出错的地方：外层的 `i` 一定要从大到小遍历，这样才能保证算 `dp[i][j]` 的时候，它依赖的 `dp[i+1][j-1]` 已经提前算好了，这是所有区间DP都通用的规律。
- 中心扩展法是空间复杂度更优的一个替代方案，只需要 O(1) 的额外空间，关键是要枚举两类中心（单字符中心和双字符中心）才能把奇数长度和偶数长度的回文都覆盖到，实际面试中面试官更希望你能写出这个解法。
- 还有一点要提一下，"回文子串"（要求连续）和"回文子序列"（可以跳着选字符）是两个完全不同的概念，它们的DP定义和解法也完全不一样，做题的时候题目描述里的"子串"这个词一定要看清楚，别搞混了。
