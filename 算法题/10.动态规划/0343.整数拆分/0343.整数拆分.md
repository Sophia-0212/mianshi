# 0343. 整数拆分

**题目描述**

给定一个正整数 `n`，将其拆分为至少两个正整数的和，并使这些整数的乘积最大化。返回你可以获得的最大乘积。

```
示例：
输入: n = 10
输出: 36
解释: 10 = 3 + 3 + 4，3 x 3 x 4 = 36 为拆分后能得到的最大乘积。
另一个例子：
输入: n = 2
输出: 1
解释: 2 = 1 + 1，1 x 1 = 1
```

题目要求拆分成的正整数个数至少为 2 个，且每个数都必须是正整数。

## 思路

这道题和前两题"网格路径类"DP有本质的不同：网格题的状态是由固定的两个相邻方向（上、左）转移过来的，而这道题需要**枚举一个拆分点**，把一个大问题拆成两个子问题来组合，这是一种更通用的DP设计技巧，后面的"不同的二叉搜索树"也会用到类似的思路。下面按DP五部曲展开。

**第一步，先确定dp数组（下标）的含义**

我定义 `dp[i]` 表示把正整数 `i` 拆分成至少两个正整数之和之后，这些正整数乘积能达到的最大值。注意 `dp[i]` 的定义里已经隐含了"必须拆分"这个前提，所以 `dp[i]` 不等于 `i` 本身（除非拆分后碰巧乘积仍等于i，但一般不会）。

**第二步，确定递推公式**

要算 `dp[i]`，我们可以枚举把 `i` 拆分出来的第一个数 `j`（`1 <= j < i`），那剩下的部分就是 `i - j`。对于剩下的这部分 `i - j`，有两种处理方式：

- **不再继续拆分**：直接把 `i - j` 当作一个独立的正整数，这次拆分方案贡献的乘积是 `j * (i - j)`；
- **继续往下拆分**：把 `i - j` 也拆成若干正整数之和，这时候可以复用已经算好的 `dp[i - j]`（也就是 `i - j` 继续拆分后能拿到的最大乘积），这次拆分方案贡献的乘积是 `j * dp[i - j]`。

因为我们不知道对每个 `j` 来说，"拆"和"不拆"剩下的部分哪一种更优，所以两者都要考虑，取较大的那个；同时还要把所有可能的 `j` 都试一遍，取全局最大值。于是递推公式是：

```
dp[i] = max(dp[i], max(j * (i - j), j * dp[i - j]))   对所有 1 <= j < i
```

这里最容易让人困惑、也必须讲清楚的一点是：**为什么不能直接统一用 `j * dp[i - j]`，而必须同时比较 `j * (i - j)` 呢？** 你想啊，`dp[i-j]` 的定义是"`i-j` **继续拆分成至少两个数**之后的最大乘积"，但"继续拆分"并不总是让乘积变大。举个具体例子，当 `i - j` 等于2的时候，如果不拆分，它就是2；但如果按定义强行拆成两个正整数之和（比如拆成1+1），乘积反而变成1，比不拆分的2还小。也就是说，`dp[1]` 和 `dp[2]` 这种"拆分后反而更小"的值，要是直接被套用到递推里，就会让结果变得比实际最优解更差。所以必须显式地保留"不拆，直接用 `j * (i - j)`"这一种可能性，跟"拆，用 `j * dp[i-j]`"做比较，两者取大的那个，才能保证递推公式覆盖到所有真实可能的拆分方式。

**第三步，dp数组怎么初始化**

`dp[0]` 和 `dp[1]` 在这道题里没有实际意义（0和1都不能拆分成两个正整数之和），一般不用它们参与递推，可以不赋值或者随意赋值为0，只要保证遍历时不会用到它们就行。真正有意义的初始值是 `dp[2]`：2只能拆分成 `1 + 1`，乘积是 `1 * 1 = 1`，所以 `dp[2] = 1`。遍历一般从 `i = 3` 开始（或者从2开始但对 `dp[2]` 单独处理），因为 `dp[2]` 已经是最终结果，不需要再用递推公式去"推导"它（如果非要套用递推公式对 `i=2` 枚举 `j=1`，得到的也是 `max(1*(2-1), 1*dp[1])`，由于 `dp[1]` 没有意义，这一步很容易出错，所以直接初始化 `dp[2]=1` 更清晰安全）。

**第四步，确定遍历顺序**

外层循环 `i` 从3遍历到 `n`（表示当前要算的拆分对象规模从小到大）；内层循环 `j` 从1遍历到 `i - 1`（表示尝试所有可能的拆分点）。因为算 `dp[i]` 依赖比 `i` 更小的 `dp[i-j]`，所以必须保证外层 `i` 从小到大递增，这样算到 `dp[i]` 的时候，所有 `dp[i-j]`（`i-j < i`）都已经在之前的外层循环里算完了。

**第五步，举例推导一下dp数组，验证一下**

先约定 `dp[2] = 1`（初始化）。接下来我们逐个推导 `dp[3]` 到 `dp[10]`：

- `dp[3]`：枚举 `j=1`：`max(1*2, 1*dp[2]) = max(2, 1) = 2`；枚举 `j=2`：`max(2*1, 2*dp[1])`，`dp[1]`没有意义忽略掉，取 `2*1=2`。综合最大值 `dp[3] = 2`（对应拆分1+2）。
- `dp[4]`：枚举 `j=1`：`max(1*3, 1*dp[3]) = max(3,2) = 3`；枚举 `j=2`：`max(2*2, 2*dp[2]) = max(4,2) = 4`；枚举 `j=3`：`max(3*1, 3*dp[1])` 忽略无意义项取 `3`。最大值 `dp[4] = 4`（对应拆分2+2）。
- `dp[5]`：枚举到 `j=2`：`max(2*3, 2*dp[3]) = max(6,4) = 6`；其他 `j` 都不超过6。`dp[5] = 6`（对应拆分2+3）。
- `dp[6]`：枚举 `j=3`：`max(3*3, 3*dp[3]) = max(9,6) = 9`。`dp[6] = 9`（对应拆分3+3）。
- `dp[7]`：枚举 `j=3`：`max(3*4, 3*dp[4]) = max(12,12) = 12`。`dp[7] = 12`（对应拆分3+4）。
- `dp[8]`：枚举 `j=3`：`max(3*5, 3*dp[5]) = max(15,18) = 18`。`dp[8] = 18`（对应拆分3+dp[5]，也就是3+2+3）。
- `dp[9]`：枚举 `j=3`：`max(3*6, 3*dp[6]) = max(18,27) = 27`。`dp[9] = 27`（对应3+3+3）。
- `dp[10]`：枚举 `j=3`：`max(3*7, 3*dp[7]) = max(21,36) = 36`；枚举 `j=4`：`max(4*6, 4*dp[6]) = max(24,36) = 36`。`dp[10] = 36`（对应3+dp[7]即3+3+4，或4+dp[6]即4+3+3，两者结果一致）。

最终 `dp[10] = 36`，跟题目给出的示例答案完全一致，说明我们这个递推过程是对的。

**复杂度说一下**

时间复杂度：外层循环 `i` 从3到 `n`，内层循环 `j` 从1到 `i-1`，是双层嵌套循环，总时间复杂度是O(n²)。

空间复杂度：用一个长度为 `n+1` 的一维数组存所有 `dp[i]`，空间复杂度是O(n)。

## 代码

### C++

```cpp
class Solution {
public:
    int integerBreak(int n) {
        vector<int> dp(n + 1, 0); // dp[i]：i拆分成至少两个正整数之和后的最大乘积
        dp[2] = 1; // 2只能拆成1+1，乘积为1，作为递推起点
        for (int i = 3; i <= n; i++) {
            for (int j = 1; j < i; j++) {
                // 递推：枚举拆分点j，i-j部分"不拆"贡献j*(i-j)，"继续拆"贡献j*dp[i-j]，取更大的
                dp[i] = max(dp[i], max(j * (i - j), j * dp[i - j]));
            }
        }
        return dp[n];
    }
};
```

class Solution {
    public int integerBreak(int n) {
        int[] dp = new int[n + 1]; // dp[i]：i拆分后能得到的最大乘积

            }
        }
        return dp[n];
    }
}

### Go

```go
func integerBreak(n int) int {
    dp := make([]int, n+1) // dp[i]：i拆分后能得到的最大乘积
    dp[2] = 1              // 初始化：2只能拆成1+1，乘积为1

    for i := 3; i <= n; i++ {
        for j := 1; j < i; j++ {
            // 递推：j*(i-j)对应剩余部分不拆分，j*dp[i-j]对应剩余部分继续拆分，取较大值
            noSplit := j * (i - j)
            keepSplit := j * dp[i-j]
            best := noSplit
            if keepSplit > best {
                best = keepSplit
            }
            if best > dp[i] {
                dp[i] = best
            }
        }
    }

    return dp[n]
}
```

## 总结

- 这道题的核心技巧是"枚举拆分点 j"，把大问题 `i` 拆成 `j` 和 `i-j` 两部分，这跟网格路径DP完全是不同的一种递推设计范式。
- 递推公式必须同时比较"剩余部分不再拆分（`j*(i-j)`）"和"剩余部分继续拆分（`j*dp[i-j]`）"这两种情况，因为 `dp[i-j]` 在 `i-j` 较小的时候（比如等于1或2）并不一定比不拆分更优。
- `dp[2] = 1` 是唯一需要手动初始化的有意义的起点，`dp[0]`、`dp[1]` 在这道题的定义下没有意义，不参与递推。
- 这种"枚举分割点，把问题拆成两个独立子问题再组合"的思路，是很多区间型、组合型DP问题的通用套路，以后遇到类似结构的题目可以直接拿来借鉴这个模式。
