# 0062. 不同路径

**题目描述**

一个机器人位于一个 `m x n` 网格的左上角（起点，图中标记为 "Start"）。机器人每次只能向下或者向右移动一步，机器人试图达到网格的右下角（终点，图中标记为 "Finish"）。问总共有多少条不同的路径？

```
示例：
输入: m = 3, n = 2
输出: 3
解释: 从左上角开始，总共有 3 条路径可以到达右下角：
1. 向右 -> 向下 -> 向下
2. 向下 -> 向下 -> 向右
3. 向下 -> 向右 -> 向下
```

再比如 `m = 3, n = 7` 时，输出为 28。数据范围保证答案在 32 位整数范围内。

## 思路

这道题是很经典的二维 DP 入门题，你想啊，机器人当前所在的位置只能从"上方格子往下走一步"或者"左方格子往右走一步"这两种方式到达，天然就满足动态规划的最优子结构和无后效性，下面按照 DP 五部曲一步步来分析。

**1. 确定 dp 数组（下标）的含义**

我定义 `dp[i][j]` 表示从起点 `(0, 0)` 出发，走到网格中坐标为 `(i, j)` 的格子时，总共有多少种不同的走法（路径数）。这里 `i` 表示行下标，范围是 `0` 到 `m-1`；`j` 表示列下标，范围是 `0` 到 `n-1`。最终答案就是 `dp[m-1][n-1]`，也就是走到右下角终点的路径数。

**2. 确定递推公式**

因为机器人每一步只能向右或者向下移动，所以要到达格子 `(i, j)`，只有两种可能的"上一步"来源：

- 从它正上方的格子 `(i-1, j)` 向下走一步过来；
- 从它正左方的格子 `(i, j-1)` 向右走一步过来。

这两种来源互斥、又完全穷尽了所有情况（除了边界格子），所以到达 `(i, j)` 的总路径数，就是这两个来源各自路径数加起来：

```
dp[i][j] = dp[i-1][j] + dp[i][j-1]
```

这里要特别说一下，为什么是"相加"而不是"取最大值"或者"相乘"呢？说白了就是我们要统计的是路径的**总数**，从上边来的每一种走法和从左边来的每一种走法，都是一条独立且不同的完整路径，所以直接做加法就行，这也是这道题和后面"整数拆分""不同的二叉搜索树"两题（那两题是枚举分割点、用乘法组合子问题）在递推结构上的本质区别。

**3. dp 数组如何初始化**

第一行（`i = 0`）的所有格子 `dp[0][j]`，只能从最左边一路向右走过来，途中没有任何"向下"的选择，所以只有唯一一种走法，应该初始化为 `dp[0][j] = 1`（对所有 `j`）。

同理，第一列（`j = 0`）的所有格子 `dp[i][0]`，只能从最上边一路向下走过来，也只有唯一一种走法，初始化为 `dp[i][0] = 1`（对所有 `i`）。

这里初始化的道理是：第一行/第一列的格子只有一个方向的邻居是"合法来源"（第一行只能从左边来，因为它上面已经越界了；第一列只能从上边来，因为它左边已经越界了），所以递推公式在这些边界位置天然就退化成了"只有一种走法"。

**4. 确定遍历顺序**

由于 `dp[i][j]` 依赖 `dp[i-1][j]`（上方）和 `dp[i][j-1]`（左方），必须保证在算当前格子之前，它上方和左方的格子都已经算完了。所以遍历顺序是：外层从上到下遍历行（`i` 从 0 到 `m-1`），内层从左到右遍历列（`j` 从 0 到 `n-1`）。这种顺序能保证 `dp[i-1][j]` 一定在上一轮外层循环中已经算好，`dp[i][j-1]` 一定在本轮内层循环的前一步已经算好。

**5. 举例推导 dp 数组验证**

拿 `m = 3, n = 3` 来举例（3 行 3 列），手动推导整张 dp 表：

第一行和第一列先按初始化规则填 1：

```
dp[0][0]=1  dp[0][1]=1  dp[0][2]=1
dp[1][0]=1
dp[2][0]=1
```

然后按遍历顺序逐格算剩下的部分：

- `dp[1][1] = dp[0][1] + dp[1][0] = 1 + 1 = 2`
- `dp[1][2] = dp[0][2] + dp[1][1] = 1 + 2 = 3`
- `dp[2][1] = dp[1][1] + dp[2][0] = 2 + 1 = 3`
- `dp[2][2] = dp[1][2] + dp[2][1] = 3 + 3 = 6`

最终完整的 dp 表如下：

```
1  1  1
1  2  3
1  3  6
```

答案 `dp[2][2] = 6`，也就是说 3x3 网格从左上到右下一共有 6 种不同路径，这也符合直观上的组合数验证（等价于从 `m+n-2` 步中选 `m-1` 步向下，即 `C(4,2) = 6`）。再验证一下题目给的 `m=3, n=2` 那个例子：dp 表是 `[[1,1],[1,2],[1,3]]`，`dp[2][1] = 3`，跟题目描述的 3 条路径完全对得上。

**复杂度分析**

时间复杂度：需要填满整张 `m x n` 的 dp 表，每个格子的计算是 O(1)，所以总时间复杂度是 O(m × n)。

空间复杂度：这里用了一张完整的二维数组存 dp 状态，空间复杂度是 O(m × n)。这里可以顺带提一句常见的空间优化思路：因为算 `dp[i][j]` 时只依赖上一行和本行左侧的值，完全可以用一个长度为 `n` 的一维数组滚动更新（`dp[j] = dp[j] + dp[j-1]`），把空间复杂度优化到 O(n)，这里就不展开具体代码实现了，重点还是先把二维 DP 的基本思路吃透。

## 代码

### C++

```cpp
class Solution {
public:
    int uniquePaths(int m, int n) {
        vector<vector<int>> dp(m, vector<int>(n, 0)); // dp[i][j]：到达(i,j)的路径数
        for (int i = 0; i < m; i++) {
            dp[i][0] = 1; // 第一列只能一直向下走，唯一一种走法
        }
        for (int j = 0; j < n; j++) {
            dp[0][j] = 1; // 第一行只能一直向右走，唯一一种走法
        }
        for (int i = 1; i < m; i++) {
            for (int j = 1; j < n; j++) {
                // 递推公式：到达(i,j)的路径数 = 从上方格子来的路径数 + 从左方格子来的路径数
                dp[i][j] = dp[i - 1][j] + dp[i][j - 1];
            }
        }
        return dp[m - 1][n - 1]; // 右下角即为最终答案
    }
};
```

### Java

```java
class Solution {
    public int uniquePaths(int m, int n) {
        int[][] dp = new int[m][n]; // dp[i][j]：到达(i,j)的路径数
        for (int i = 0; i < m; i++) {
            dp[i][0] = 1; // 第一列初始化为1，只有一条纵向路径能到达
        }
        for (int j = 0; j < n; j++) {
            dp[0][j] = 1; // 第一行初始化为1，只有一条横向路径能到达
        }
        for (int i = 1; i < m; i++) {
            for (int j = 1; j < n; j++) {
                // 核心递推：当前格子路径数 = 上方格子路径数 + 左方格子路径数
                dp[i][j] = dp[i - 1][j] + dp[i][j - 1];
            }
        }
        return dp[m - 1][n - 1]; // 返回终点的路径总数
    }
}
```

### Python

```python
class Solution:
    def uniquePaths(self, m: int, n: int) -> int:
        dp = [[0] * n for _ in range(m)]  # dp[i][j]：到达(i,j)的路径数
        for i in range(m):
            dp[i][0] = 1  # 第一列，只能一直向下走到达，路径数为1
        for j in range(n):
            dp[0][j] = 1  # 第一行，只能一直向右走到达，路径数为1

        for i in range(1, m):
            for j in range(1, n):
                # 递推公式：当前格子的路径数等于上方格子和左方格子路径数之和
                dp[i][j] = dp[i - 1][j] + dp[i][j - 1]

        return dp[m - 1][n - 1]  # 终点格子的值即为答案
```

func uniquePaths(m int, n int) int {

        }

## 总结

- 这道题是二维 DP 的入门范例，dp 状态由"上方"和"左方"两个相邻方向转移而来，递推公式用加法组合，因为求的是路径**总数**而不是最优值。
- 初始化的关键在于理解第一行/第一列的格子只有单一方向的合法来源，因而只能有一种走法，这一点是很多二维网格类 DP 题目通用的初始化思路。
- 遍历顺序必须保证依赖的状态先被算出来，这道题采用从上到下、从左到右的顺序，自然就能满足这一要求。
- 二维数组可以用一维滚动数组优化空间到 O(n)，这是网格类 DP 常见的空间优化手段，说白了就是利用了"只依赖上一行"这个特性。
