# 0062. 不同路径

**题目描述**

一个机器人位于一个 `m x n` 网格的左上角（起点，图中标记为 "Start"）。机器人每次只能向下或者向右移动一步，机器人试图达到网格的右下角（终点，图中标记为 "Finish"）。问总共有多少条不同的路径？

```
示例：
输入: m = 3, n = 2
输出: 3
解释: 从左上角开始，总共有 3 条路径可以到达右下角：
1. 向右 -> 向下 -> 向下
2. 向下 -> 向下 -> 向右
3. 向下 -> 向右 -> 向下
```

再比如 `m = 3, n = 7` 时，输出为 28。数据范围保证答案在 32 位整数范围内。

## 思路

DP：`dp[i][j]` 表示到达格子的路径数，等于上方与左方路径数之和。首行、首列初始化为 1，从上到下、从左到右递推，返回右下角。

时间 O(mn)，空间 O(mn)，滚动数组可降为 O(n)。



## Python

### LeetCode 写法与原有示例

```python
# 依赖说明：range：Python 内置函数：生成按步长遍历的整数序列。

class Solution:
    # 方法：uniquePaths；按题目要求处理输入并返回结果，核心算法见方法体。
    def uniquePaths(self, m: int, n: int) -> int:
        dp = [[0] * n for _ in range(m)]  # dp[i][j]：到达(i,j)的路径数
        for i in range(m):
            dp[i][0] = 1  # 第一列，只能一直向下走到达，路径数为1
        for j in range(n):
            dp[0][j] = 1  # 第一行，只能一直向右走到达，路径数为1

        for i in range(1, m):
            for j in range(1, n):
                # 递推公式：当前格子的路径数等于上方格子和左方格子路径数之和
                dp[i][j] = dp[i - 1][j] + dp[i][j - 1]

        return dp[m - 1][n - 1]  # 终点格子的值即为答案```

// 方法：uniquePaths；按题目要求处理输入并返回结果，核心算法见方法体。
func uniquePaths(m int, n int) int {
    dp := make([][]int, m) // dp[i][j]：到达(i,j)的路径数
    for i := range dp {
        dp[i] = make([]int, n)
        dp[i][0] = 1 // 第一列初始化为1，只有唯一走法
    }
    for j := 0; j < n; j++ {
        dp[0][j] = 1 // 第一行初始化为1，只有唯一走法
    }

    for i := 1; i < m; i++ {
        for j := 1; j < n; j++ {
            // 递推：当前格子路径数 = 上方格子路径数 + 左方格子路径数
            dp[i][j] = dp[i-1][j] + dp[i][j-1]
        }
    }

    return dp[m-1][n-1] // 右下角终点即为最终答案
}
```

## 总结

- 这道题是二维 DP 的入门范例，dp 状态由"上方"和"左方"两个相邻方向转移而来，递推公式用加法组合，因为求的是路径**总数**而不是最优值。
- 初始化的关键在于理解第一行/第一列的格子只有单一方向的合法来源，因而只能有一种走法，这一点是很多二维网格类 DP 题目通用的初始化思路。
- 遍历顺序必须保证依赖的状态先被算出来，这道题采用从上到下、从左到右的顺序，自然就能满足这一要求。
- 二维数组可以用一维滚动数组优化空间到 O(n)，这是网格类 DP 常见的空间优化手段，说白了就是利用了"只依赖上一行"这个特性。
