# 0416. 分割等和子集

**题目描述**

给你一个只包含正整数的非空数组 `nums`，请判断是否可以将这个数组分割成两个子集，使得两个子集的元素和相等。

```
示例 1：
输入：nums = [1,5,11,5]
输出：true
解释：数组可以分割成 [1,5,5] 和 [11]，两个子集的和都是11。

示例 2：
输入：nums = [1,2,3,5]
输出：false
解释：数组不能分割成两个和相等的子集。
```

## 思路

总和为奇数则失败，否则令 `T=sum/2`，转为 01 背包。`dp[j]` 为不超过 `j` 的最大子集和，初值 0。外层元素、内层容量倒序，保证每数只用一次；判断 `dp[T]==T`。

```
for i in 0..n-1:                      # 外层遍历每个数字
    for j in target downto nums[i]:   # 内层容量倒序遍历
        dp[j] = max(dp[j], dp[j-nums[i]] + nums[i])
```

时间 O(nT)，空间 O(T)。

func canPartition(nums []int) bool {
    sum := 0
    for _, num := range nums {
        sum += num // 先求数组总和
    }
    if sum%2 != 0 {
        return false // 总和为奇数，不可能平分
    }
    target := sum / 2 // 背包容量：目标子集和

    dp := make([]int, target+1) // dp[j]：容量为j时能凑出的最大价值
    for _, num := range nums {  // 外层：遍历每个数字（物品）
        for j := target; j >= num; j-- { // 内层：容量倒序遍历，01背包关键
            if dp[j-num]+num > dp[j] {
                dp[j] = dp[j-num] + num // 核心递推：选或不选num，取更大价值
            }
        }
    }
    return dp[target] == target // 若能恰好凑满target，说明可以平分
}

## 总结

- 本题的关键是"问题转化"：把"能否分成两个和相等的子集"转化为"能否从数组中选出若干数，凑出总和一半的目标值"，这是01背包思想在判定类问题上的典型应用。
- 一维dp数组下，`weight[i]` 和 `value[i]` 都等于 `nums[i]`，判断条件是 `dp[target] == target`（恰好装满），而不是简单地判断dp[target]是否非零。
- 内层容量必须倒序遍历，这是01背包一维写法的铁律，本题不例外。
- 这种"总和减半作为背包容量"的转化思路，在后续类似"分成两部分使某种指标相等或接近"的题目中会反复出现，值得作为一种固定套路记住。
