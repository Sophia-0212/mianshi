# 0474. 一和零

**题目描述**

给定一个二进制字符串数组 `strs`（每个字符串只由 `'0'` 和 `'1'` 组成），以及两个整数 `m` 和 `n`。请从 `strs` 中选出最多数量的字符串，使得所选出的这些字符串中，`'0'` 的总个数不超过 `m`，`'1'` 的总个数不超过 `n`。返回可以选出的字符串的最大数量。

```
示例：
输入: strs = ["10","0001","111001","1","0"], m = 5, n = 3
输出: 4
解释: 最多可以选择 4 个字符串：
"10" 消耗 1 个 0 和 1 个 1
"0" 消耗 1 个 0
"1" 消耗 1 个 1
"0" 不能再选（strs 里只有一个 "0"，已用过）
实际选法之一是 {"10", "0001", "1", "0"}，消耗 0 的个数为 1+3+0+1=5，1 的个数为 1+1+1+0=3，均不超过限制，共选出 4 个字符串。
```

数组长度不超过 600，字符串长度不超过 100，m、n 范围 0 到 100。

## 思路

二维 01 背包：`dp[i][j]` 为最多用 `i` 个 0、`j` 个 1 可选的字符串数，初值 0。

每个串统计 `a` 个 0、`b` 个 1，两容量均倒序更新：`dp[i][j]=max(dp[i][j],dp[i-a][j-b]+1)`，避免重复选串。返回 `dp[m][n]`。

时间 O(L+k(m+1)(n+1))，空间 O((m+1)(n+1))，L 为总字符数，k 为字符串数。

# 依赖说明：range：Python 内置函数：生成按步长遍历的整数序列。；max：Python 内置函数：返回最大值。

# 依赖说明：range：Python 内置函数：生成按步长遍历的整数序列。

class Solution:
    # 方法：findMaxForm；按题目要求处理输入并返回结果，核心算法见方法体。
    def findMaxForm(self, strs: list[str], m: int, n: int) -> int:
        dp = [[0] * (n + 1) for _ in range(m + 1)]  # dp[i][j]: 0的容量i、1的容量j时最多选几个字符串

        for s in strs:                     # 外层：遍历每个字符串（物品）
            zeros = s.count('0')
            ones = s.count('1')
            for i in range(m, zeros - 1, -1):        # 内层1：0的容量倒序遍历
                for j in range(n, ones - 1, -1):      # 内层2：1的容量倒序遍历
                    # 递推：不选当前字符串 vs 选当前字符串(需先扣除zeros/ones容量)后数量+1，取较大值
                    dp[i][j] = max(dp[i][j], dp[i - zeros][j - ones] + 1)
        return dp[m][n]
```

## Go

### LeetCode 写法与原有示例

```go
// 方法：findMaxForm；按题目要求处理输入并返回结果，核心算法见方法体。
func findMaxForm(strs []string, m int, n int) int {
    dp := make([][]int, m+1) // dp[i][j]: 0的容量i、1的容量j时最多选几个字符串
    for i := range dp {
        dp[i] = make([]int, n+1)
    }

    for _, s := range strs { // 外层：遍历每个字符串（物品）
        zeros, ones := 0, 0
        for _, c := range s {
            if c == '0' {
                zeros++
            } else {
                ones++
            }
        }
        for i := m; i >= zeros; i-- { // 内层1：0的容量倒序遍历
            for j := n; j >= ones; j-- { // 内层2：1的容量倒序遍历
                // 递推：不选当前字符串 vs 选当前字符串(需先扣除zeros/ones容量)后数量+1，取较大值
                if dp[i-zeros][j-ones]+1 > dp[i][j] {
                    dp[i][j] = dp[i-zeros][j-ones] + 1
                }
            }
        }
    }
    return dp[m][n]
}
```

## C++

### LeetCode 写法与原有示例

```cpp
// 依赖说明：vector：C++ STL 动态数组。；string：C++ STL 字符串类型。

class Solution {
public:
    // 方法：findMaxForm；按题目要求处理输入并返回结果，核心算法见方法体。
    int findMaxForm(vector<string>& strs, int m, int n) {
        vector<vector<int>> dp(m + 1, vector<int>(n + 1, 0));  // dp[i][j]: 0的容量i、1的容量j时最多选几个字符串

        for (const string& s : strs) {          // 外层：遍历每个字符串（物品）
            int zeros = 0, ones = 0;
            for (char c : s) {
                if (c == '0') zeros++;
                else ones++;
            }
            for (int i = m; i >= zeros; i--) {        // 内层1：0的容量倒序遍历
                for (int j = n; j >= ones; j--) {      // 内层2：1的容量倒序遍历
                    // 递推：不选当前字符串 vs 选当前字符串(需先扣除zeros/ones容量)后数量+1，取较大值
                    dp[i][j] = max(dp[i][j], dp[i - zeros][j - ones] + 1);
                }
            }
        }
        return dp[m][n];
    }
};```

## 总结

- 本题是 01 背包在"费用"维度上的扩展：原本一个物品只有一个重量，现在变成一个物品同时消耗两种资源（0 的个数、1 的个数），dp 数组也从一维变成二维 `dp[i][j]`。
- 递推公式的本质没有变化，依然是"选或不选，取较优值"，只是把重量和容量都换成了二维形式：`dp[i][j] = max(dp[i][j], dp[i-zeros][j-ones] + 1)`。
- 遍历顺序仍然遵循 01 背包"倒序遍历容量"的规则，只是这里有两个容量维度，i 和 j 都必须倒序，缺一不可，否则会退化成允许重复选取的完全背包语义。
- 每个字符串在处理前先统计出 zeros 和 ones 两个统计量，是把原始输入转化为背包模型里的"物品重量"的关键一步，这一步做完之后，剩下的就是标准的二维费用 01 背包套路。
