# 0070. 爬楼梯（完全背包版本）

**题目描述**

爬楼梯的推广版本：一共有 `n` 阶楼梯，每次可以向上爬 `1` 到 `m` 阶中的任意数量（`m` 是给定的一个正整数上限），每种爬法内部的顺序不同视为不同的方案，求爬到楼顶一共有多少种不同的方法。

```
示例：
输入: n = 3, m = 3
输出: 4
解释: 爬到第 3 阶楼梯，一共有 4 种方法：
[1,1,1]
[1,2]
[2,1]
[3]
```

当 `m = 2` 时，这道题就退化为最初的爬楼梯问题（每次只能爬 1 阶或 2 阶）。

## 思路

完全背包求排列数：`dp[j]` 为到第 `j` 阶的方法数，`dp[0]=1`，其余为 0。外层递增阶数，内层枚举最后一步 1～m，累加 `dp[j-i]`，返回 `dp[n]`。

```
for j in range(1, n + 1):        # 外层：容量（当前要爬到的阶数）
    for i in range(1, m + 1):    # 内层：物品（每次可以爬的步数）
        if j >= i:
            dp[j] += dp[j - i]
```

阶数在外，区分步数顺序。时间 O(nm)，空间 O(n)。

## 总结

- 把"每次可爬的阶数"抽象为可重复使用的物品，"总阶数 n"抽象为容量，爬楼梯的推广版本就是一道标准的完全背包"求排列数"问题，递推公式为 `dp[j] += dp[j-i]`。
- 因为爬楼梯每一步的先后顺序不同算不同的方法，遍历顺序沿用 377 题的搭配：外层容量、内层物品，这样才能让每一步的跨度都有机会作为"最后一步"被单独统计。
- 原始的 70 题（每次只能爬 1 或 2 阶）只是这里 `m = 2` 时的特例，此时递推公式退化为熟悉的 `dp[j] = dp[j-1] + dp[j-2]`，说明抽象出背包模型后，同一套框架可以自然覆盖任意 `m` 的情况。
- 三道题（518、377、本题）放在一起对比，能清楚看到"完全背包求组合数"和"求排列数"只在遍历顺序上有差别，状态转移方程的核心形式始终是 `dp[j] += dp[j-x]`。
