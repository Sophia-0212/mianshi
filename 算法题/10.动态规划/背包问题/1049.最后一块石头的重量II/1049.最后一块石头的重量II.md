# 1049. 最后一块石头的重量 II

**题目描述**

有一堆石头，用整数数组 `stones` 表示，其中 `stones[i]` 表示第 `i` 块石头的重量。每一回合，可以从中选出任意两块石头，然后将它们一起粉碎。假设石头的重量分别为 `x` 和 `y`，且 `x <= y`，那么粉碎的可能结果如下：

- 如果 `x == y`，那么两块石头都会被完全粉碎；
- 如果 `x != y`，那么重量为 `x` 的石头将会完全粉碎，而重量为 `y` 的石头新重量为 `y - x`。

最后，最多只会剩下一块石头。返回此石头的最小可能重量。如果没有石头剩下，返回0。

```
示例：
输入：stones = [2,7,4,1,8,1]
输出：1
解释：
组合 2 和 4，得到 2，故数组转化为 [2,7,1,8,1]，
组合 7 和 8，得到 1，故数组转化为 [2,1,1,1]，
组合 2 和 1，得到 1，故数组转化为 [1,1,1]，
组合 1 和 1，得到 0，故数组转化为 [1]，
此时数组中只剩下一块石头的重量为1，这就是最小可能的重量。
```

## 思路

把石头分为两堆，使重量差最小。总重 S，令 `T=⌊S/2⌋`，用 01 背包求不超过 T 的最大子集和。

`dp[j]` 为容量 j 可凑出的最大重量，初值 0；外层石头、内层容量倒序。答案 `S-2*dp[T]`。

```
for i in 0..n-1:                          # 外层遍历每块石头
    for j in target downto stones[i]:     # 内层容量倒序遍历
        dp[j] = max(dp[j], dp[j-stones[i]] + stones[i])
```

时间 O(nT)，空间 O(T)。

### LeetCode 写法与原有示例

```go
// 方法：lastStoneWeightII；按题目要求处理输入并返回结果，核心算法见方法体。
func lastStoneWeightII(stones []int) int {
    sum := 0
    for _, s := range stones {
        sum += s // 求石头总重量
    }
    target := sum / 2 // 背包容量：较小堆的理论上限

    dp := make([]int, target+1) // dp[j]：容量j下能凑出的最大重量
    for _, stone := range stones { // 外层：遍历每块石头
        for j := target; j >= stone; j-- { // 内层：容量倒序遍历，01背包关键
            if dp[j-stone]+stone > dp[j] {
                dp[j] = dp[j-stone] + stone // 核心递推：该石头分不分入较小堆
            }
        }
    }
    return sum - 2*dp[target] // 两堆之差
}
```

## C++

### LeetCode 写法与原有示例

```cpp
class Solution {
public:
    // 方法：lastStoneWeightII；按题目要求处理输入并返回结果，核心算法见方法体。
    int lastStoneWeightII(vector<int>& stones) {
        int sum = 0;
        for (int s : stones) sum += s;              // 求石头总重量
        int target = sum / 2;                        // 背包容量：较小堆的理论上限

        vector<int> dp(target + 1, 0);               // dp[j]：容量j下能凑出的最大重量
        for (int i = 0; i < stones.size(); i++) {    // 外层：遍历每块石头
            for (int j = target; j >= stones[i]; j--) { // 内层：容量倒序遍历，01背包关键
                dp[j] = max(dp[j], dp[j - stones[i]] + stones[i]); // 核心递推：该石头分不分入较小堆
            }
        }
        return sum - 2 * dp[target]; // 两堆之差：较大堆(sum-dp[target]) - 较小堆(dp[target])
    }
};
```

## 总结

- 本题的转化思路是"两两撞击"等价于"分成两堆求重量差的绝对值"，这一步转化想清楚之后，问题就退化成了标准的01背包：让较小的一堆尽可能接近sum的一半。
- `target = sum / 2` 是较小堆重量的理论上限，`dp[target]` 求出的就是较小堆能达到的最大重量，答案公式为 `sum - 2*dp[target]`。
- 和分割等和子集一题的区别在于：本题不要求恰好装满（不用判断dp[target]是否等于target），只需要dp[target]本身尽可能大即可，因为最终答案是用总量减去两倍的dp[target]。
- 两题都属于"给定总量，把物品分成两部分，使某个指标相等或尽量接近"的题型，套路都是取总量的一半作为背包容量去做01背包。
