# 背包问题理论基础 多重背包

多重背包：第 i 种物品最多选 `count[i]` 次，在容量 C 内求最大价值。

- 直接展开：拆成 `count[i]` 个独立物品，按 01 背包容量倒序更新。时间 O(CΣcount)，空间 O(C+Σcount)。
- 二进制分组：按 1、2、4……及余数组成若干组，组重量／价值同步乘数量，再做 01 背包。时间 O(CΣlog(count+1))，空间 O(C+Σlog(count+1))。

### LeetCode 写法与原有示例

```python
# 依赖说明：len：Python 内置函数：返回容器中元素的数量。；range：Python 内置函数：生成按步长遍历的整数序列。；zip：Python 内置函数：按位置把多个可迭代对象组合成元组序列。；max：Python 内置函数：返回最大值。

# 依赖说明：len：Python 内置函数：返回容器中元素的数量。；range：Python 内置函数：生成按步长遍历的整数序列。

# 方法：multi_pack_via_01；按题目要求处理输入并返回结果，核心算法见方法体。
def multi_pack_via_01(weights, values, counts, capacity):
    # 第一步：展开——把每种"数量有限"的物品，按 count 展开成多个独立的 01 背包物品
    expanded_weights = []
    expanded_values = []
    for w, v, c in zip(weights, values, counts):
        for _ in range(c):          # 按数量上限 c，展开成 c 个重量、价值都相同的独立物品
            expanded_weights.append(w)
            expanded_values.append(v)

    # 第二步：01 背包求解——对展开后的物品列表，套用标准 01 背包模板
    dp = [0] * (capacity + 1)       # dp[j]：容量为 j 时能装下的最大价值
    for i in range(len(expanded_weights)):        # 外层遍历每一个展开后的独立物品
        for j in range(capacity, expanded_weights[i] - 1, -1):  # 内层倒序遍历容量（01 背包标准写法）
            dp[j] = max(dp[j], dp[j - expanded_weights[i]] + expanded_values[i])  # 选或不选这个物品，取较大价值
    return dp[capacity]```
