# 0494. 目标和

**题目描述**

给定一个非负整数数组 `nums` 和一个整数 `target`。数组中每个数字前面都要添加 `'+'` 或 `'-'`，然后把所有整数连接起来可以构造一个表达式，求该表达式计算结果等于 `target` 的不同添加符号的方法数。

```
示例：
输入: nums = [1,1,1,1,1], target = 3
输出: 5
解释: 一共有 5 种添加符号的方法使得表达式的结果为 3。
-1+1+1+1+1 = 3
+1-1+1+1+1 = 3
+1+1-1+1+1 = 3
+1+1+1-1+1 = 3
+1+1+1+1-1 = 3
```

数组长度范围 1 到 20，元素值范围 0 到 1000，`target` 的绝对值不超过 1000。

## 思路

设总和 S，正号子集和须为 `P=(S+target)/2`。若 `|target|>S` 或 `S+target` 为奇数，返回 0。

01 背包计数：`dp[j]` 为凑成 `j` 的子集数，`dp[0]=1`，其余为 0。外层元素，容量从 P 倒序到 num，更新 `dp[j]+=dp[j-num]`，返回 `dp[P]`；0 也须处理，会使方案数翻倍。

时间 O(n(P+1))，空间 O(P+1)。暴力枚举正负号：时间 O(2ⁿ)，栈空间 O(n)。

# 依赖说明：range：Python 内置函数：生成按步长遍历的整数序列。；sum：Python 内置函数：计算可迭代对象元素的总和。；abs：Python 内置函数：返回数值的绝对值。

# 依赖说明：range：Python 内置函数：生成按步长遍历的整数序列。

class Solution:
    # 方法：findTargetSumWays；按题目要求处理输入并返回结果，核心算法见方法体。
    def findTargetSumWays(self, nums: list[int], target: int) -> int:
        total = sum(nums)  # 先求数组总和

        # (target + total) 必须是非负偶数，否则无法凑出整数容量 x
        if (target + total) % 2 != 0 or abs(target) > total:
            return 0

        x = (target + total) // 2  # 转化为：选子集凑出和为 x 的方案数
        dp = [0] * (x + 1)
        dp[0] = 1  # 什么都不选，凑出和为 0，唯一方案

        for num in nums:                      # 外层：遍历物品
            for j in range(x, num - 1, -1):   # 内层：容量倒序，保证每个数只用一次
                dp[j] += dp[j - num]          # 累加"选"与"不选"两种方案数，而非取max/min
        return dp[x]```

## C++

### LeetCode 写法与原有示例

```cpp
class Solution {
public:
    // 方法：findTargetSumWays；按题目要求处理输入并返回结果，核心算法见方法体。
    int findTargetSumWays(vector<int>& nums, int target) {
        int sum = 0;
        for (int num : nums) sum += num;  // 先求数组总和

        // (target + sum) 必须是非负偶数，否则无法凑出整数容量 x
        if ((target + sum) % 2 != 0 || abs(target) > sum) {
            return 0;
        }

        int x = (target + sum) / 2;  // 转化为：选子集凑出和为 x 的方案数
        vector<int> dp(x + 1, 0);
        dp[0] = 1;  // 什么都不选，凑出和为 0，唯一方案

        for (int i = 0; i < nums.size(); i++) {       // 外层：遍历物品
            for (int j = x; j >= nums[i]; j--) {      // 内层：容量倒序，保证每个数只用一次
                dp[j] += dp[j - nums[i]];             // 累加"选"与"不选"两种方案数，而非取max/min
            }
        }
        return dp[x];
    }
};
```

## 总结

- 这道题最核心的一步，其实不是背包本身，而是"填符号"到"选子集使和为 x"这个数学转化：`x = (target + sum) / 2`。这一步要是想不到，后面的背包模型根本无从下手，所以说这才是真正的难点。
- dp 数组的含义从"最大价值"变成了"方案数"，递推公式也从 max/min 变成了累加 `dp[j] += dp[j-nums[i]]`，这是计数类背包问题的通用写法，一定要跟最优化类背包问题区分开，别搞混了。
- 遍历顺序依然遵循 01 背包的老结论：容量维度倒序遍历，这样才能防止同一个数字在同一轮被选用两次。
- 提前处理好奇偶性和绝对值越界这两种边界情况，能避免数组开出负数长度，或者做一堆没意义的计算。
