# 背包理论基础 01背包（一）

## 什么是01背包

背包问题是动态规划里最经典的一类题型，几乎所有讲DP的教程都会把它作为入门案例，为什么呢？因为它的状态转移逻辑非常规整，能很好地体现"选或不选"这种决策型DP的通用套路。而01背包，是所有背包问题中最基础的一种，后面要学的完全背包、多重背包，本质上都是在01背包的框架上做变体。

先说清楚模型：假设有 n 个物品，编号从 0 到 n-1，第 i 个物品有两个属性——重量 `weight[i]` 和价值 `value[i]`。同时有一个容量为 `bagWeight` 的背包。现在要往背包里装物品，每个物品**最多只能选一次**（可以选0次，也可以选1次，不能选多次），在不超过背包容量的前提下，希望背包里物品的总价值尽可能大。

"01"这两个字就是从"选0次或选1次"这个约束来的，这也是它和完全背包（每个物品可以选无限次）最本质的区别。这一点理解清楚非常重要，因为它直接决定了后面代码实现中遍历顺序的选择——这是很多人在01背包这里踩坑的地方，下一篇会专门展开讲。

## 二维dp数组的定义

做背包问题，第一步永远是想清楚dp数组的含义，这是DP五部曲里最关键的一步，含义想不清楚，后面递推公式怎么推都是在瞎猜。

对01背包，最直观、最容易想到的定义方式是二维数组：

`dp[i][j]` 表示：**从下标为 [0, i] 的物品中任意选取（每个物品最多选一次），放进容量为 j 的背包，所能得到的最大价值。**

这里要注意两个下标各自的含义：第一个维度 i 限定了"能选的物品范围"（只能从前 i+1 个物品里选，也就是下标0到i），第二个维度 j 限定了"当前背包的容量"。dp数组的每一个格子，都是在这两个约束下求出的一个最优解（最大价值）。

理解这个定义，最好在脑子里画一张二维表格：行代表物品（从物品0到物品n-1逐行往下），列代表容量（从0到bagWeight逐列往右）。表格填满之后，右下角 `dp[n-1][bagWeight]` 就是最终答案——用全部n个物品、容量为bagWeight时能得到的最大价值。

## 递推公式的推导

有了dp数组的定义，接下来推递推公式，其实就是在问："`dp[i][j]` 是怎么从更小规模的子问题算出来的？"

考虑第 i 个物品，此时只有两种可能的决策：

**情况一：不放物品 i 进背包。**

如果不放物品i，那么容量为j的背包里装的东西，其实就等价于"只从前i-1个物品里选，放进容量为j的背包"，也就是：

```
dp[i][j] = dp[i-1][j]
```

**情况二：放物品 i 进背包。**

放的前提是背包容量得够，即 `j >= weight[i]`。放了物品i之后，背包剩余的容量是 `j - weight[i]`，这部分剩余容量要去承载前i-1个物品能提供的最大价值，加上物品i自身的价值 `value[i]`，即：

```
dp[i][j] = dp[i-1][j - weight[i]] + value[i]
```

物品i到底放不放，取决于哪种情况能得到更大的价值，所以两者取较大值：

```
dp[i][j] = max(dp[i-1][j], dp[i-1][j - weight[i]] + value[i])
```

这一行就是01背包最核心的递推公式，务必理解每一项的来源：`dp[i-1][j]` 是"放弃物品i"这条路径的最优解；`dp[i-1][j-weight[i]] + value[i]` 是"拿下物品i"这条路径的最优解，其中 `dp[i-1][j-weight[i]]` 描述的是"给物品i腾出空间之后，剩下的容量能装出的最大价值"。

特别要注意，当 `j < weight[i]` 时，物品i根本装不进去，只能取情况一，即 `dp[i][j] = dp[i-1][j]`。实际写代码时通常会在遍历容量j时加一个条件判断来处理这种情况。

## dp数组的初始化

递推公式确定后，需要确定初始值，也就是dp表格的第一行和第一列。

**第一列（j=0，背包容量为0）**：容量为0的背包无论怎么选都装不进任何东西，所以对所有的i，都有：

```
dp[i][0] = 0
```

**第一行（i=0，只考虑物品0）**：这一行要单独算，为什么呢？因为它是递推链条的起点，没有"上一行"可以依赖。当容量 j 能装下物品0（即 `j >= weight[0]`）时，能选的方案只有"选物品0"这一种（选了价值更高，因为不选价值是0），所以：

```
dp[0][j] = value[0]   若 j >= weight[0]
dp[0][j] = 0           若 j <  weight[0]
```

除了第一行和第一列，dp数组其余位置的初始值理论上可以随便填（比如全部初始化成0），因为它们最终都会被递推公式重新计算覆盖。但实践中一般还是统一初始化为0，避免遗漏边界导致脏数据。

## 遍历顺序

二维dp数组的01背包，先遍历物品再遍历容量，或者先遍历容量再遍历物品，**结果都是对的**。为什么呢？原因很直观：`dp[i][j]` 只依赖"上一行"（i-1那一行）的数据，和"本行内先算哪一列、后算哪一列"没有关系，所以两层for循环谁在外谁在内都不影响正确性。

但这里要埋一个钩子：这个"顺序随意"的结论，只在二维dp数组下成立。等到下一篇引入一维滚动数组优化之后，情况会发生本质变化——内层容量的遍历顺序会变得**极其敏感**，正序遍历和倒序遍历会得到完全不同（且倒序才是正确）的结果。这也是初学者最容易在01背包上翻车的地方，下一篇会用具体数字例子把这个坑讲清楚。

## 复杂度分析

设物品数量为 n，背包容量为 bagWeight。二维dp数组需要填满一张 n 行、bagWeight+1 列的表格，每个格子的计算是O(1)，所以：

- 时间复杂度：O(n × bagWeight)
- 空间复杂度：O(n × bagWeight)，因为要开一个二维数组

空间复杂度这一点，也是引出下一篇一维滚动数组优化的直接动机——当物品数量和背包容量都很大时，二维数组的空间开销会成为瓶颈，而通过滚动数组可以把空间复杂度降到O(bagWeight)。

## 代码模板（二维dp，C++）

下面给出一份二维dp的完整代码模板，这里只是演示模型本身，不针对某道具体题目，所以直接手动构造一组物品数据来验证。

```cpp
#include <vector>
#include <iostream>
using namespace std;

int main() {
    // 物品的重量和价值，下标一一对应
    vector<int> weight = {1, 3, 4};   // 3个物品的重量
    vector<int> value = {15, 20, 30}; // 3个物品对应的价值
    int bagWeight = 4;                // 背包容量

    int n = weight.size();
    // dp[i][j]：从下标[0,i]的物品中任选（每个最多选一次），放入容量为j的背包，能得到的最大价值
    vector<vector<int>> dp(n, vector<int>(bagWeight + 1, 0));

    // 初始化第一行：只考虑物品0时，容量j能不能装下物品0
    for (int j = weight[0]; j <= bagWeight; j++) {
        dp[0][j] = value[0]; // 装得下就选它，价值为value[0]
    }
    // dp[i][0] = 0 已经在数组初始化时默认满足，不需要额外处理

    // 先遍历物品，再遍历容量（二维dp下这个顺序可以互换，结果不变）
    for (int i = 1; i < n; i++) {           // 从物品1开始递推（物品0已经初始化）
        for (int j = 0; j <= bagWeight; j++) {
            if (j < weight[i]) {
                dp[i][j] = dp[i - 1][j];      // 容量装不下物品i，只能不选
            } else {
                // 核心递推公式：不选物品i vs 选物品i，取较大值
                dp[i][j] = max(dp[i - 1][j], dp[i - 1][j - weight[i]] + value[i]);
            }
        }
    }

    cout << dp[n - 1][bagWeight] << endl; // 输出：用全部物品、容量为bagWeight时的最大价值
    return 0;
}
```

用人脑简单验算一下：物品0(w=1,v=15)、物品1(w=3,v=20)、物品2(w=4,v=30)，背包容量4。最优方案是选物品0和物品1（重量1+3=4，正好装满，价值15+20=35），比单独选物品2（价值30）更优，所以最终答案应为35，跟代码逻辑是吻合的。

## 小结

- 01背包的模型是"n个物品每个最多选一次，背包容量有限，求能装下的最大价值"，核心矛盾在于"选或不选"每个物品。
- 二维dp数组 `dp[i][j]` 的含义是理解一切后续推导的基础：前i个物品、容量j的背包下的最大价值。
- 递推公式 `dp[i][j] = max(dp[i-1][j], dp[i-1][j-weight[i]] + value[i])` 本质上是在"要不要拿这个物品"两种决策里选更优的一个。
- 二维dp下物品和容量两层遍历顺序可以随意交换，但这个便利性在后续一维数组优化后就会消失，需要格外小心。
