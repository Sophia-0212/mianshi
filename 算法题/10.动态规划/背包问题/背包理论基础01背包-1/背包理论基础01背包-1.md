# 背包理论基础 01背包（一）

01 背包：每个物品最多选一次，在容量 C 内求最大价值。`dp[i][j]` 为使用物品 `[0,i]`、容量 j 的最大价值。

不选物品 i：

```
dp[i][j] = dp[i-1][j]
```

容量足够时选物品 i：

```
dp[i][j] = dp[i-1][j - weight[i]] + value[i]
```

两种选择取最大：

```
dp[i][j] = max(dp[i-1][j], dp[i-1][j - weight[i]] + value[i])
```

容量不足只能不选。正重量、非负价值时初始化：

```
dp[i][0] = 0
```

```
dp[0][j] = value[0]   若 j >= weight[0]
dp[0][j] = 0           若 j <  weight[0]
```

逐行计算，每个状态只依赖上一行；时间、空间 O(nC)，返回 `dp[n-1][C]`。

## 代码模板（二维dp，C++）

## C++

### LeetCode 写法与原有示例

```cpp
#include <vector>
#include <iostream>
// 依赖说明：C++ STL vector：动态数组。；C++ 标准库 iostream：控制台输入输出。

using namespace std;

// 方法：main；按题目要求处理输入并返回结果，核心算法见方法体。
int main() {
    // 物品的重量和价值，下标一一对应
    vector<int> weight = {1, 3, 4};   // 3个物品的重量
    vector<int> value = {15, 20, 30}; // 3个物品对应的价值
    int bagWeight = 4;                // 背包容量

    int n = weight.size();
    // dp[i][j]：从下标[0,i]的物品中任选（每个最多选一次），放入容量为j的背包，能得到的最大价值
    vector<vector<int>> dp(n, vector<int>(bagWeight + 1, 0));

    // 初始化第一行：只考虑物品0时，容量j能不能装下物品0
    for (int j = weight[0]; j <= bagWeight; j++) {
        dp[0][j] = value[0]; // 装得下就选它，价值为value[0]
    }
    // dp[i][0] = 0 已经在数组初始化时默认满足，不需要额外处理

    // 先遍历物品，再遍历容量（二维dp下这个顺序可以互换，结果不变）
    for (int i = 1; i < n; i++) {           // 从物品1开始递推（物品0已经初始化）
        for (int j = 0; j <= bagWeight; j++) {
            if (j < weight[i]) {
                dp[i][j] = dp[i - 1][j];      // 容量装不下物品i，只能不选
            } else {
                // 核心递推公式：不选物品i vs 选物品i，取较大值
                dp[i][j] = max(dp[i - 1][j], dp[i - 1][j - weight[i]] + value[i]);
            }
        }
    }

    cout << dp[n - 1][bagWeight] << endl; // 输出：用全部物品、容量为bagWeight时的最大价值
    return 0;
}
```

namespace interview {

// 普通函数与辅助函数声明。
int zeroOneBackpack(vector<int> weights, vector<int> values, int capacity);

int zeroOneBackpack(vector<int> weights, vector<int> values, int capacity) {
    // 每件物品最多选一次，容量倒序更新，避免重复使用当前物品。
    vector<int> dp(capacity+1,0);
    for(int i=0;i<weights.size();++i)
        for(int c=capacity;c>=weights[i];--c)
            dp[c]=max(dp[c],dp[c-weights[i]]+values[i]);
    return dp[capacity];
}
