# 0279. 完全平方数

**题目描述**

给定一个正整数 `n`，求最少需要多少个**完全平方数**（即 `1, 4, 9, 16, 25, ...`，也就是 `1², 2², 3², 4², 5², ...`）相加，使它们的和等于 `n`。同一个完全平方数可以被重复使用多次。

```
示例：
输入: n = 13
输出: 2
解释: 13 = 4 + 9，用了 2 个完全平方数
```

这道题和上一篇 0322 零钱兑换是**同一个模型**：只要把"完全平方数"看成硬币的面值，把 `n` 看成要凑出的目标金额，问题就变成了"最少用多少个硬币（面值是 `1, 4, 9, 16, ...`）能凑出金额 `n`"——和 322 题一字不差地对应。区别只在于硬币面值列表（`coins` 数组）的来源不同：322 题是题目直接给出的数组，本题需要自己先枚举出所有不超过 `n` 的完全平方数，作为隐式的 `coins` 数组。

## 思路

完全背包：`dp[j]` 为凑成 `j` 的最少平方数个数，`dp[0]=0`，其余设为不可达。枚举平方数，金额正序，允许重复选取，返回 `dp[n]`。

```
for i in 1 .. sqrt(n):
    for j in i*i .. n:
        dp[j] = min(dp[j], dp[j - i*i] + 1)
```

时间 O(n√n)，空间 O(n)。

        while i * i <= n:           # 外层遍历每一个完全平方数（底数 i）

            for j in range(square, n + 1):  # 内层正序遍历容量（完全背包：可重复使用）

            i += 1
        return dp[n]

// 方法：numSquares；按题目要求处理输入并返回结果，核心算法见方法体。
func numSquares(n int) int {
    dp := make([]int, n+1)
    for j := range dp {
        dp[j] = n + 1 // 初始化为足够大的数，代表"暂不可达"
    }
    dp[0] = 0 // 凑出数字 0 需要 0 个完全平方数

    for i := 1; i*i <= n; i++ { // 外层遍历每一个完全平方数（底数 i）
        square := i * i
        for j := square; j <= n; j++ { // 内层正序遍历容量（完全背包写法）
            if dp[j-square]+1 < dp[j] {
                dp[j] = dp[j-square] + 1 // 状态转移：min(不用这个平方数, 用它多凑一次)
            }
        }
    }
    return dp[n]
}
```

### LeetCode 写法与原有示例

```cpp
// 依赖说明：vector：C++ STL 动态数组。

class Solution {
public:
    // 方法：numSquares；按题目要求处理输入并返回结果，核心算法见方法体。
    int numSquares(int n) {
        vector<int> dp(n + 1, n + 1);  // 初始化为足够大的数，代表"暂不可达"
        dp[0] = 0;                      // 凑出数字 0 需要 0 个完全平方数
        for (int i = 1; i * i <= n; i++) {       // 外层遍历每一个完全平方数"物品"（底数 i）
            for (int j = i * i; j <= n; j++) {   // 内层正序遍历容量（完全背包：可重复使用同一个完全平方数）
                dp[j] = min(dp[j], dp[j - i * i] + 1);  // 状态转移：min(不用 i*i, 用 i*i 多凑一次)
            }
        }
        return dp[n];  // n 一定有解（用 n 个 1 兜底），不需要判断 -1
    }
};```

## 总结

- 本题与 322 题零钱兑换是同一个"完全背包求最优解"模型，递推公式 `dp[j] = min(dp[j], dp[j-物品]+1)` 完全一致，唯一区别是物品集合的来源：322 是题目直接给出的 `coins` 数组，本题需要先枚举 `1` 到 `sqrt(n)` 生成隐式的"完全平方数数组"。
- 识别出"这是同一个模型的变形"比记住递推公式本身更重要——遇到新题时，先想"能不能把某种东西看成硬币，把目标值看成金额"，往往就能直接套用已经掌握的完全背包求最优解套路。
- 初始化同样要用"足够大的数"表示不可达，且本题保证一定有解（`1` 的平方兜底），所以不需要像 322 题那样处理返回 `-1` 的情况。
- 遍历顺序上，外层是"物品（底数 i）"、内层是"容量 j"且内层正序，这是完全背包的标准写法；由于是求最优解而非计数，外内层顺序对正确性并不敏感。
