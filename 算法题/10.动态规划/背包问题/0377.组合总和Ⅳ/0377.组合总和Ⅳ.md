# 0377. 组合总和 Ⅳ

**题目描述**

给定一个由不同正整数组成的数组 `nums` 和一个目标整数 `target`，从 `nums` 中选取数字（每个数字可以被重复使用任意次），求恰好组成 `target` 的排列数。这里"排列"意味着选取数字的顺序不同则视为不同的方案。

```
示例：
输入: nums = [1, 2, 3], target = 4
输出: 7
解释: 所有可能的组合为：
(1, 1, 1, 1)
(1, 1, 2)
(1, 2, 1)
(1, 3)
(2, 1, 1)
(2, 2)
(3, 1)
```

数据保证答案符合 32 位整数范围，`nums` 中不含 0。

## 思路

完全背包求排列数：`dp[j]` 为总和 `j` 的有序方案数，`dp[0]=1`，其余为 0。外层目标和递增，内层枚举最后一个数，累加剩余和的方案，返回 `dp[target]`。

```
for j in range(1, target + 1):      # 外层：容量（目标和）
    for num in nums:                # 内层：物品
        if j >= num:
            dp[j] += dp[j - num]
```

容量在外，区分不同排列。时间 O(nT)，空间 O(T)，T 为目标和。

class Solution:
    # 方法：combinationSum4；按题目要求处理输入并返回结果，核心算法见方法体。
    def combinationSum4(self, nums: list[int], target: int) -> int:
        dp = [0] * (target + 1)  # dp[j]：凑成总和 j 的排列数
        dp[0] = 1  # 递推种子：凑成 0 只有一种方案（什么都不选）
        for j in range(1, target + 1):     # 外层遍历容量（目标和），外层容量是求排列数的标志
            for num in nums:                # 内层遍历物品，让每个数字轮流作为"最后一步"
                if j >= num:
                    dp[j] += dp[j - num]  # 递推公式：累加以 num 结尾时前面部分的排列数
        return dp[target]```

```go
func combinationSum4(nums []int, target int) int {
    dp := make([]int, target+1) // dp[j]：凑成总和 j 的排列数
    dp[0] = 1                   // 递推种子：凑成 0 只有一种方案
    for j := 1; j <= target; j++ { // 外层遍历容量：外层是容量才能区分排列的先后顺序
        for _, num := range nums { // 内层遍历物品：每个数字都有机会作为排列的最后一位
            if j >= num {
                dp[j] += dp[j-num] // 核心递推：累加以 num 结尾、前面凑出 j-num 的排列数
            }
        }
    }
    return dp[target]
}
```

## 总结

- 本题与 518 题（零钱兑换 II）的状态转移方程形式完全相同（`dp[j] += dp[j-x]`），唯一的区别是遍历顺序：本题外层容量、内层物品，得到排列数；518 题外层物品、内层容量，得到组合数。
- 外层容量在外，意味着对每一个目标和都会让所有物品轮流尝试作为"最后一步"，从而把同一组合的不同排列顺序分别统计出来。
- `dp[0] = 1` 是这一类"累加型"计数 dp 通用的初始化方式，代表"凑成 0 的方案数为 1（不选任何元素）"，是后续所有累加的起点。
- 判断一道计数类背包题该用哪种遍历顺序，先确认题目是否区分选取顺序：不区分选组合数写法（先物后容），区分就选排列数写法（先容后物）。
