# 背包问题理论基础 完全背包

完全背包每种物品可重复选，01 背包最多一次。

01 背包选当前物品时读取上一行：

```
dp[i][j] = max(dp[i-1][j], dp[i-1][j - weight[i]] + value[i])
```

完全背包读取本行较小容量，允许再次选择：

```
dp[i][j] = max(dp[i-1][j], dp[i][j - weight[i]] + value[i])
```

压缩为一维：

```
dp[j] = max(dp[j], dp[j - weight[i]] + value[i])
```

物品在外，容量从重量递增到上限。允许不装满、价值非负时初值为 0；时间 O(nC)，空间 O(C)。

## C++

### LeetCode 写法与原有示例

```cpp
#include <vector>
#include <algorithm>
// 依赖说明：C++ STL vector：动态数组。；C++ STL algorithm：sort、max、min 等通用算法。

using namespace std;

// 方法：completeBackpack；按题目要求处理输入并返回结果，核心算法见方法体。
int completeBackpack(vector<int>& weight, vector<int>& value, int bagWeight) {
    // dp[j] 表示容量为 j 的背包，在"每种物品可选无限次"的前提下能装下的最大价值
    vector<int> dp(bagWeight + 1, 0);  // 初始化：容量为0时无论怎么选价值都是0

    for (int i = 0; i < weight.size(); i++) {      // 外层遍历每一种物品
        for (int j = weight[i]; j <= bagWeight; j++) {
            // 内层容量正序遍历（与01背包相反）：
            // dp[j - weight[i]] 可能已经是本轮更新过的新值，
            // 这正是我们需要的效果——让物品i可以被连续多次叠加选取
            dp[j] = max(dp[j], dp[j - weight[i]] + value[i]);
        }
    }
    return dp[bagWeight];  // 容量恰好为bagWeight时能达到的最大价值
}```
