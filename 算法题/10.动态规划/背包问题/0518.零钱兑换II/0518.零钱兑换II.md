# 0518. 零钱兑换 II

**题目描述**

给定不同面额的硬币数组 `coins` 和一个总金额 `amount`，每种硬币的数量不限（可以重复使用任意次），计算可以凑成总金额的硬币组合数。这里的"组合"不考虑硬币的使用顺序，即 `{1,2,2}` 和 `{2,1,2}` 被视为同一种方案，只统计一次。

```
示例：
输入: amount = 5, coins = [1, 2, 5]
输出: 4
解释: 凑成 5 的组合一共有 4 种：
5 = 5
5 = 2+2+1
5 = 2+1+1+1
5 = 1+1+1+1+1
```

如果 `coins` 中的硬币无法凑出 `amount`，返回 0。

## 思路

完全背包求组合数：`dp[j]` 为金额 `j` 的组合数，`dp[0]=1`，其余为 0。外层硬币避免重复排列，内层金额递增允许重复选取，返回 `dp[amount]`。

```
for coin in coins:          # 外层：物品
    for j in range(coin, amount + 1):   # 内层：容量，正序
        dp[j] += dp[j - coin]
```

时间 O(kA)，空间 O(A)，k 为硬币种数，A 为目标金额。

### LeetCode 写法与原有示例

# 依赖说明：range：Python 内置函数：生成按步长遍历的整数序列。

class Solution:
    # 方法：change；按题目要求处理输入并返回结果，核心算法见方法体。
    def change(self, amount: int, coins: list[int]) -> int:
        dp = [0] * (amount + 1)  # dp[j]：凑成金额 j 的组合数
        dp[0] = 1  # 递推种子：凑成 0 元有且只有一种方案（不选任何硬币）
        for coin in coins:                       # 外层遍历物品（硬币），决定统计的是组合数
            for j in range(coin, amount + 1):    # 内层正序遍历容量，完全背包允许重复选取
                dp[j] += dp[j - coin]  # 递推公式：累加去掉一枚 coin 后剩余金额的组合数
        return dp[amount]
```

func change(amount int, coins []int) int {
    dp := make([]int, amount+1) // dp[j]：凑成金额 j 的组合数
    dp[0] = 1                   // 递推种子：凑成 0 元只有一种方案
    for _, coin := range coins {          // 外层遍历硬币：保证同一组合不因硬币顺序不同被重复统计

            dp[j] += dp[j-coin] // 核心递推：累加引入这枚硬币后新增的组合方式
        }
    }
    return dp[amount]
}

### LeetCode 写法与原有示例

```cpp

class Solution {
public:
    // 方法：change；按题目要求处理输入并返回结果，核心算法见方法体。
    int change(int amount, vector<int>& coins) {
        vector<int> dp(amount + 1, 0); // dp[j]：凑成金额 j 的组合数
        dp[0] = 1; // 凑成金额 0 只有"什么都不选"这一种方案，是递推的种子
        for (int coin : coins) {           // 外层遍历物品（硬币）：保证组合数不重复统计
            for (int j = coin; j <= amount; j++) { // 内层正序遍历容量（完全背包可重复使用同一硬币）
                dp[j] += dp[j - coin]; // 核心递推：引入 coin 后，凑成 j 的方案数累加上凑成 j-coin 的方案数
            }
        }
        return dp[amount];
    }
};```

## 总结

- 本题是完全背包"求组合数"的模板题：状态转移用 `dp[j] += dp[j-coins[i]]`，初始化 `dp[0] = 1` 作为递推种子。
- 最关键的考点是遍历顺序：**外层物品、内层容量** 得到组合数（硬币的相对引入顺序固定，不重复统计排列）；若反过来外层容量、内层物品，则会把同一组合的不同排列都分别计数，变成排列数（对应 377 题）。
- 完全背包的一维数组内层容量要**正序**遍历（区别于 0-1 背包的倒序），因为需要允许同一件物品在同一轮里被多次叠加使用。
- 遇到"不考虑顺序的组合数"类问题，先想到"外层物品、内层容量"这一固定搭配，能省去不少调试时间。
