# 0322. 零钱兑换

**题目描述**

给定不同面额的硬币数组 `coins`（每种面额的硬币数量不限）和一个总金额 `amount`，计算凑成总金额所需的**最少硬币个数**。如果任何组合方式都无法凑出该金额，返回 `-1`。

```
示例：
输入: coins = [1, 2, 5], amount = 11
输出: 3
解释: 11 = 5 + 5 + 1，用了 3 枚硬币，是最少的凑法
```

每种硬币可以使用任意多次（数量不限），你想啊，这就意味着这是一个**完全背包**问题——但和常见的完全背包"求组合数/排列数"不同，这里问的是"最少要用多少个物品"，属于完全背包的另一个分支：**求最优解**。

## 思路

完全背包：`dp[j]` 为凑成金额 `j` 的最少硬币数，`dp[0]=0`，其余设为不可达。外层硬币，内层金额递增，更新 `dp[j]=min(dp[j],dp[j-coin]+1)`；目标仍不可达返回 -1。

```
for i in coins:
    for j in coins[i] .. amount:
        dp[j] = min(dp[j], dp[j - coins[i]] + 1)
```

时间 O(kA)，空间 O(A)，k 为硬币种数，A 为目标金额。

// 方法：coinChange；按题目要求处理输入并返回结果，核心算法见方法体。
func coinChange(coins []int, amount int) int {
    dp := make([]int, amount+1)
    for j := range dp {
        dp[j] = amount + 1 // 初始化为足够大的数，代表"暂不可达"
    }
    dp[0] = 0 // 凑出金额 0 需要 0 枚硬币

    for _, coin := range coins { // 外层遍历每一种硬币
        for j := coin; j <= amount; j++ { // 内层正序遍历容量（完全背包写法）
            if dp[j-coin]+1 < dp[j] {
                dp[j] = dp[j-coin] + 1 // 状态转移：min(不用这枚硬币, 用这枚硬币多凑一次)
            }
        }
    }

    if dp[amount] > amount {
        return -1 // 未被有效更新，说明凑不出该金额
    }
    return dp[amount]
}

## 总结

- 本题的核心是完全背包"求最优解"模型：递推公式用 `min(dp[j], dp[j-coins[i]]+1)`，比较的是"代价"，而不是像 518/377 那样用 `+=` 累加"方案条数"——同样是完全背包外壳，问题目标不同导致递推公式的组合方式完全不同。
- 初始化必须用一个"足够大"的数表示"暂不可达"，不能是 0，否则 `min` 操作会直接锁死在错误的初始值上。
- 由于是求最优解而非计数，外层遍历硬币、内层遍历容量的顺序在正确性上并不敏感，但为了统一写法仍按标准完全背包模板书写（内层正序，允许硬币重复使用）。
- 最终通过检查 `dp[amount]` 是否仍停留在初始大数来判断"是否存在可行凑法"，这是"用不可达标记 + 事后检查"处理无解情况的通用套路。
