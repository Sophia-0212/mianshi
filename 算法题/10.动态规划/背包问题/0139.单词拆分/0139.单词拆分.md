# 0139. 单词拆分

**题目描述**

给定一个字符串 `s` 和一个字符串列表 `wordDict`（字典），判断 `s` 是否可以被拆分为一个或多个字典中出现的单词的拼接。字典中的单词可以被重复使用多次。

```
示例：
输入: s = "leetcode", wordDict = ["leet", "code"]
输出: true
解释: 可以拆分成 "leet" + "code"
```

字典里的每个单词都可以被重复使用，你想啊，这就意味着可以把字典中的单词看成"物品"，且是可以重复选取的完全背包物品；把字符串 `s` 的长度看成背包的"容量"。这样问题就转化为了："能否用字典里的单词（可重复使用）恰好拼出长度为 `len(s)` 且内容与 `s` 完全一致的字符串"。这其实是完全背包的第三种典型问题类型——**判定性问题（能否装满）**，和"求最优解"（min/max）、"求方案数"（累加）都不一样。

## 思路

DP：`dp[j]` 表示前 `j` 个字符可拆分，`dp[0]=true`。正序枚举前缀；存在字典单词作为后缀且剩余前缀可拆分，就设为真。返回 `dp[n]`。

```
for j in 1 .. len(s):
    for word in wordDict:
        if j >= len(word) and dp[j - len(word)] and s[j-len(word):j] == word:
            dp[j] = true
            break  // 已经确定 dp[j] = true，不需要再看其他单词
```

枚举字典单词：时间 O(nkL)，k 为单词数，L 为最长词长。当前枚举子串长度并复制／哈希的实现最坏 O(n³)；空间 O(n+D)，D 为字典存储量。



## Python

### LeetCode 写法与原有示例

```python
# 依赖说明：len：Python 内置函数：返回容器中元素的数量。；range：Python 内置函数：生成按步长遍历的整数序列。

class Solution:
    # 方法：wordBreak；按题目要求处理输入并返回结果，核心算法见方法体。
    def wordBreak(self, s: str, wordDict: list[str]) -> bool:
        word_set = set(wordDict)  # 哈希集合加速单词查找
        n = len(s)
        dp = [False] * (n + 1)   # dp[j]：s 的前 j 个字符能否被拼接成功
        dp[0] = True              # 空字符串天然合法，递推起点
        for j in range(1, n + 1):        # 外层按前缀长度递增遍历容量 j
            for length in range(1, j + 1):  # 内层枚举结尾单词的长度
                word = s[j - length:j]      # 取出 s 中从 j-length 到 j 的子串
                if dp[j - length] and word in word_set:  # 前缀合法 且 结尾恰好是字典单词
                    dp[j] = True  # 逻辑或：只要有一种拼法成立就为 true
                    break
        return dp[n]
```

// 方法：wordBreak；按题目要求处理输入并返回结果，核心算法见方法体。
func wordBreak(s string, wordDict []string) bool {
    wordSet := make(map[string]bool)
    for _, w := range wordDict {
        wordSet[w] = true // 哈希集合加速单词查找
    }
    n := len(s)
    dp := make([]bool, n+1) // dp[j]：s 的前 j 个字符能否被拼接成功
    dp[0] = true            // 空字符串天然合法，递推起点

    for j := 1; j <= n; j++ { // 外层按前缀长度递增遍历容量 j
        for length := 1; length <= j; length++ { // 内层枚举结尾单词的长度
            word := s[j-length : j] // 取出 s 中从 j-length 到 j 的子串
            if dp[j-length] && wordSet[word] {
                dp[j] = true // 逻辑或：只要有一种拼法成立，dp[j] 就是 true
                break
            }
        }
    }
    return dp[n]
}
```

## C++

### LeetCode 写法与原有示例

```cpp
// 依赖说明：vector：C++ STL 动态数组。；unordered_set：C++ STL 哈希集合。；string：C++ STL 字符串类型。

class Solution {
public:
    // 方法：wordBreak；按题目要求处理输入并返回结果，核心算法见方法体。
    bool wordBreak(string s, vector<string>& wordDict) {
        unordered_set<string> wordSet(wordDict.begin(), wordDict.end());  // 用哈希集合加速单词查找
        int n = s.size();
        vector<bool> dp(n + 1, false);  // dp[j]：s 的前 j 个字符能否被拼接成功
        dp[0] = true;                    // 空字符串天然合法，是递推的起点
        for (int j = 1; j <= n; j++) {          // 外层按前缀长度递增遍历容量 j
            for (int len = 1; len <= j; len++) { // 内层枚举当前这一段"结尾单词"的长度
                string word = s.substr(j - len, len);  // 取出 s 中从 j-len 到 j 的子串
                if (dp[j - len] && wordSet.count(word)) {  // 前缀合法 且 结尾子串恰好是字典中的单词
                    dp[j] = true;  // 逻辑或：只要有一种拼法成立，dp[j] 就是 true
                    break;         // 已确定为 true，无需再尝试其他长度
                }
            }
        }
        return dp[n];  // 前 n 个字符（即整个字符串）是否能被成功拼接
    }
};```

## 总结

- 这道题是完全背包"能否装满"这一判定性问题的典型代表：把字典单词看作可重复使用的物品，把 `len(s)` 看作容量，递推公式的合并方式是逻辑或（or），只要有任意一种拼法能成立，`dp[j]` 就是 `true`。
- 这也补上了完全背包递推公式合并方式的第三种类型：`min`/`max` 求最优解、`+=` 求方案数、`or` 求"是否可行"，三者分别对应优化、计数、判定这三种不同性质的问题目标。
- 初始化 `dp[0] = true` 是整个递推能够启动的关键，代表"空字符串"天然合法，这一点一定要记住。
- 遍历顺序上，外层必须按 `s` 的前缀长度 `j` 递增处理（因为 `dp[j]` 依赖更短前缀的 `dp` 值），内层枚举可能的结尾单词长度并做子串匹配，这一点和纯数值型完全背包"讨论组合数/排列数"的遍历顺序考量不同，本题的约束来自"字符串前缀依赖关系"本身。
