# 0132. 分割回文串 II

**题目描述**

给定一个字符串 `s`，将其分割成若干个子串，使每个子串都是回文串，求最少的分割次数。

```
示例：
输入: s = "aab"
输出: 1
解释: 只需要分割一次，分成 "aa" 和 "b" 两个回文子串，切一刀对应1次分割。

输入: s = "a"
输出: 0
解释: 整个字符串本身就是回文串，不需要分割。
```

## 思路

两阶段 DP：

1. 预处理回文：`pal[i][j] = s[i]==s[j] && (j-i<2 || pal[i+1][j-1])`，`i` 倒序、`j` 正序。
2. `dp[i]` 为前 `i` 个字符的最少切割数。初值 `dp[0]=-1`、`dp[i]=i-1`；正序枚举 `i`，对每个回文后缀 `s[j..i-1]`，更新 `dp[i]=min(dp[i],dp[j]+1)`。返回 `dp[n]`。

`dp[0]=-1` 使整体回文时无需切割。时间、空间 O(n²)；逐次现场检查回文会使时间升至 O(n³)。

```python
# 依赖说明：len：Python 内置函数：返回容器中元素的数量。；range：Python 内置函数：生成按步长遍历的整数序列。

class Solution:
    # 方法：minCut；按题目要求处理输入并返回结果，核心算法见方法体。
    def minCut(self, s: str) -> int:
        n = len(s)
        # 第一阶段：预处理区间是否回文
        is_palindrome = [[False] * n for _ in range(n)]
        for i in range(n - 1, -1, -1):        # 外层i从大到小，保证i+1行先算完
            for j in range(i, n):             # 内层j从i到n-1
                if s[i] == s[j] and (j - i < 2 or is_palindrome[i + 1][j - 1]):
                    is_palindrome[i][j] = True
        # 第二阶段：主DP求最少分割次数
        dp = [0] * (n + 1)
        dp[0] = -1  # 空前缀补偿项，保证整体回文时dp[i]=0
        for i in range(1, n + 1):
            dp[i] = i - 1  # 初始上界：最坏情况每个字符单独成段
            for j in range(i):                     # 枚举最后一段的起点j
                if is_palindrome[j][i - 1]:         # s[j..i-1]是回文，才能作为最后一段
                    dp[i] = min(dp[i], dp[j] + 1)   # 前j个字符的代价 + 新增一次分割
        return dp[n]
```

```go
func minCut(s string) int {
    n := len(s)
    // 第一阶段：预处理区间是否回文
    isPalindrome := make([][]bool, n)
    for i := range isPalindrome {
        isPalindrome[i] = make([]bool, n)
    }
    for i := n - 1; i >= 0; i-- {          // 外层i从大到小，保证i+1行先算完
        for j := i; j < n; j++ {          // 内层j从i到n-1
            if s[i] == s[j] && (j-i < 2 || isPalindrome[i+1][j-1]) {
                isPalindrome[i][j] = true
            }
        }
    }
    // 第二阶段：主DP求最少分割次数
    dp := make([]int, n+1)
    dp[0] = -1 // 空前缀补偿项，保证整体回文时dp[i]=0
    for i := 1; i <= n; i++ {
        dp[i] = i - 1 // 初始上界：最坏情况每个字符单独成段
        for j := 0; j < i; j++ { // 枚举最后一段的起点j

                    dp[i] = dp[j] + 1 // 前j个字符的代价 + 新增一次分割
                }
            }
        }
    }
    return dp[n]
}
```

class Solution {
public:
    // 方法：minCut；按题目要求处理输入并返回结果，核心算法见方法体。
    int minCut(string s) {
        int n = s.size();
        // 第一阶段：预处理区间是否回文
        vector<vector<bool>> isPalindrome(n, vector<bool>(n, false));
        for (int i = n - 1; i >= 0; i--) {          // 外层i从大到小，保证i+1行先算完
            for (int j = i; j < n; j++) {           // 内层j从i到n-1
                if (s[i] == s[j] && (j - i < 2 || isPalindrome[i + 1][j - 1])) {
                    isPalindrome[i][j] = true;
                }
            }
        }
        // 第二阶段：主DP求最少分割次数
        vector<int> dp(n + 1);
        dp[0] = -1; // 空前缀补偿项，保证整体回文时dp[i]=0
        for (int i = 1; i <= n; i++) {
            dp[i] = i - 1; // 初始上界：最坏情况每个字符单独成段
            for (int j = 0; j < i; j++) {           // 枚举最后一段的起点j
                if (isPalindrome[j][i - 1]) {       // s[j..i-1]是回文，才能作为最后一段
                    dp[i] = min(dp[i], dp[j] + 1);  // 前j个字符的代价 + 新增一次分割
                }
            }
        }
        return dp[n];
    }
};```

## 总结

- 这道题最核心的思路就是"预处理DP + 主DP"的两阶段组合：先用647题的区间DP方法一次性算出所有区间是不是回文（O(n²)），再在主DP的状态转移里直接查表判断，这样就避免了现场判断回文带来的额外O(n)开销，把整体复杂度从可能的O(n³)压到O(n²)。
- `dp[i]` 采用"前i个字符"的下标定义（而不是"下标i处"），是为了让 `dp[0]` 能自然表示空前缀这个状态，从而设置 `dp[0]=-1` 来补偿"整体回文时不应该多算一刀"的这种情况，这个初始化的直觉理解是关键。
- 状态转移 `dp[i] = min(dp[j]+1)` 的本质，是在枚举"最后一段回文子串"的起点，把大问题拆成"前面已经处理好的部分"加"最后一段"，这是区间类DP里常见的"枚举最后一步"的思考模式。
- 这道题还有个"进阶版"——如果不只是要求分割成回文串且求最少次数，还要求分割成回文串且要恰好满足某些性质（比如每段长度相等），思路框架是类似的，但状态定义会需要额外维度，做题时要先想清楚状态定义能不能覆盖题目所有约束。
