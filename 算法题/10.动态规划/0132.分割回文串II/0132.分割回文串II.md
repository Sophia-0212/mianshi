# 0132. 分割回文串 II

**题目描述**

给定一个字符串 `s`，将其分割成若干个子串，使每个子串都是回文串，求最少的分割次数。

```
示例：
输入: s = "aab"
输出: 1
解释: 只需要分割一次，分成 "aa" 和 "b" 两个回文子串，切一刀对应1次分割。

输入: s = "a"
输出: 0
解释: 整个字符串本身就是回文串，不需要分割。
```

## 思路

这道题表面上看是个"分割最优化"问题，但要正确解决它，关键是要意识到它其实是**两个DP问题的组合**：第一层DP负责判断"任意区间是不是回文串"（这正是647题的核心内容），第二层DP才是真正针对"分割"这件事本身来建模。这种"预处理DP + 主DP"的两阶段套路在很多题目里都会出现，值得专门讲清楚为什么要拆成两步、以及拆开之后到底能带来多大的复杂度收益。

**先说为什么要做预处理**：你想啊，如果不预处理，直接在主DP的状态转移里去判断某个子串是不是回文，每次判断都要花 O(n) 的时间去遍历比较两端字符、逐步向中间收缩。而主DP本身在最坏情况下有 O(n²) 个状态转移要做（对每个位置 `i`，要枚举所有可能的分割点 `j`），如果每次转移都额外花 O(n) 去判断回文，总时间复杂度就会退化到 O(n³)。但事实上，"字符串 s 的所有子区间是不是回文"这件事，是完全可以用一次 O(n²) 的区间DP提前算好、缓存起来的（就是647题里 `dp[i][j]` 的判断），之后主DP里任何时候需要查询某个区间是不是回文，都只需要 O(1) 查表就行。所以说白了，预处理的本质就是用一次性的 O(n²) 计算，换掉后续可能重复发生的 O(n) 查询，把总复杂度从 O(n³) 优化到 O(n²)。这正是动态规划里"空间换时间"思想的一个典型体现。

**第一阶段，预处理回文信息**

沿用647题的定义：`isPalindrome[i][j]` 表示 `s[i..j]`（闭区间）是不是回文串。转移方程和647题完全一致：

```
isPalindrome[i][j] = (s[i] == s[j]) && (j - i < 2 || isPalindrome[i+1][j-1])
```

遍历顺序同样要注意：因为依赖左下方的 `isPalindrome[i+1][j-1]`，外层 `i` 必须从大到小遍历，内层 `j` 从 `i` 到末尾递增，才能保证用到 `isPalindrome[i+1][j-1]` 时它已经被正确计算过。这一步跑完之后，任意区间是不是回文的信息就全部缓存好了，后续查询都是 O(1)。

**第二阶段：主DP求最少分割次数**

这里的状态定义选择是这道题另一个需要讲清楚的关键点。我采用的下标定义是：`dp[i]` 表示字符串 `s` 的前 `i` 个字符（即 `s[0..i-1]`，长度为 `i` 的前缀）最少需要分割多少次才能让每一段都是回文串。注意这里 `dp[i]` 描述的是"前i个字符"而不是"下标i处"，这样定义的好处是可以自然地表示"空前缀"这个状态（`i=0` 时代表一个字符都没有），方便处理初始化。

**状态转移方程**：对于 `dp[i]`（前i个字符的最少分割次数），枚举最后一段回文子串的起始下标 `j`（`0 <= j < i`），如果 `s[j..i-1]`（对应预处理里的 `isPalindrome[j][i-1]`）是回文串，说明可以把前i个字符分成"前j个字符（已经处理好，代价是dp[j]）"加上"最后一段 `s[j..i-1]`（这一段本身已经是回文，不需要再分割，但从"前j个字符"过渡到"前i个字符"这一刀本身算一次分割）"，所以有转移：

```
dp[i] = min(dp[j] + 1)，对所有满足 isPalindrome[j][i-1] == true 的 j（0 <= j < i）取最小值
```

这里"+1"对应的是新增的这一次分割动作：把长度为j的前缀和新的一段 `s[j..i-1]` 分开，这一刀就是一次分割。

**初始化的关键**：`dp[0] = -1`。这个初始化看起来有点反直觉——次数怎么会是负数？但这恰恰是这套下标定义下最合理的设定，为什么呢？原因是：当整个字符串 `s[0..i-1]` 本身就是一个完整的回文串时（即 `j=0` 且 `isPalindrome[0][i-1]=true`），此时不需要任何分割，`dp[i]` 应该等于0，而不是1。按转移方程算，这种情况下 `dp[i] = dp[0] + 1`，如果要让结果是0，就必须让 `dp[0] = -1`。可以这样理解：`dp[0]` 代表"空前缀"的分割次数，把它设为-1相当于一个数学上的补偿项，抵消掉"把整个字符串当作从空前缀之后接上的第一段"时多算的那一刀。除了 `dp[0]=-1` 之外，其余 `dp[i]`（`i>=1`）初始化为一个足够大的数（如 `i-1` 或者直接用无穷大），保证后续用 `min` 时能被正确的更小值替换——用 `i-1` 作为初始上界也有实际意义，因为最坏情况下每个字符单独成一段回文串，需要切 `i-1` 刀。

**遍历顺序**：主DP的外层遍历 `i` 从1到字符串长度 `n`（`dp[i]` 依赖的是更小的 `dp[j]`，`j<i`），内层遍历 `j` 从0到 `i-1`，这个顺序是自然的从小到大递推，不像预处理阶段那样需要反向遍历，因为这里 `dp[i]` 只依赖比它下标更小的 `dp[j]`，正常递增遍历就能保证依赖项先算好。

**复杂度分析**：预处理阶段是标准区间DP，时间和空间复杂度都是 O(n²)；主DP阶段外层 `n` 次、内层最多 `n` 次，时间复杂度也是 O(n²)，空间上 `dp` 数组是 O(n)。两阶段相加，总时间复杂度 O(n²)，总空间复杂度 O(n²)（由预处理阶段的二维数组主导）。相比不做预处理直接在主DP里现场判断回文的 O(n³) 写法，这是一个数量级的优化。

**第一阶段，预处理回文信息**

沿用647题的定义：`isPalindrome[i][j]` 表示 `s[i..j]`（闭区间）是否是回文串。转移方程和647题完全一致：


## 代码

### C++

```cpp
class Solution {
public:
    int minCut(string s) {
        int n = s.size();
        // 第一阶段：预处理区间是否回文
        vector<vector<bool>> isPalindrome(n, vector<bool>(n, false));
        for (int i = n - 1; i >= 0; i--) {          // 外层i从大到小，保证i+1行先算完
            for (int j = i; j < n; j++) {           // 内层j从i到n-1
                if (s[i] == s[j] && (j - i < 2 || isPalindrome[i + 1][j - 1])) {
                    isPalindrome[i][j] = true;
                }
            }
        }
        // 第二阶段：主DP求最少分割次数
        vector<int> dp(n + 1);
        dp[0] = -1; // 空前缀补偿项，保证整体回文时dp[i]=0
        for (int i = 1; i <= n; i++) {
            dp[i] = i - 1; // 初始上界：最坏情况每个字符单独成段
            for (int j = 0; j < i; j++) {           // 枚举最后一段的起点j
                if (isPalindrome[j][i - 1]) {       // s[j..i-1]是回文，才能作为最后一段
                    dp[i] = min(dp[i], dp[j] + 1);  // 前j个字符的代价 + 新增一次分割
                }
            }
        }
        return dp[n];
    }
};
```

```python
class Solution:
    def minCut(self, s: str) -> int:
        n = len(s)
        # 第一阶段：预处理区间是否回文
        is_palindrome = [[False] * n for _ in range(n)]
        for i in range(n - 1, -1, -1):        # 外层i从大到小，保证i+1行先算完
            for j in range(i, n):             # 内层j从i到n-1
                if s[i] == s[j] and (j - i < 2 or is_palindrome[i + 1][j - 1]):
                    is_palindrome[i][j] = True
        # 第二阶段：主DP求最少分割次数
        dp = [0] * (n + 1)
        dp[0] = -1  # 空前缀补偿项，保证整体回文时dp[i]=0
        for i in range(1, n + 1):
            dp[i] = i - 1  # 初始上界：最坏情况每个字符单独成段
            for j in range(i):                     # 枚举最后一段的起点j
```

### Go

```go
func minCut(s string) int {
    n := len(s)
    // 第一阶段：预处理区间是否回文
    isPalindrome := make([][]bool, n)
    for i := range isPalindrome {
        isPalindrome[i] = make([]bool, n)
    }
    for i := n - 1; i >= 0; i-- {          // 外层i从大到小，保证i+1行先算完
        for j := i; j < n; j++ {          // 内层j从i到n-1
            if s[i] == s[j] && (j-i < 2 || isPalindrome[i+1][j-1]) {
                isPalindrome[i][j] = true
            }
        }
    }
    // 第二阶段：主DP求最少分割次数
    dp := make([]int, n+1)
    dp[0] = -1 // 空前缀补偿项，保证整体回文时dp[i]=0
    for i := 1; i <= n; i++ {
        dp[i] = i - 1 // 初始上界：最坏情况每个字符单独成段
        for j := 0; j < i; j++ { // 枚举最后一段的起点j
            if isPalindrome[j][i-1] { // s[j..i-1]是回文，才能作为最后一段
                if dp[j]+1 < dp[i] {
                    dp[i] = dp[j] + 1 // 前j个字符的代价 + 新增一次分割
                }
            }
        }
    }
    return dp[n]
}
```

## 总结

- 这道题最核心的思路就是"预处理DP + 主DP"的两阶段组合：先用647题的区间DP方法一次性算出所有区间是不是回文（O(n²)），再在主DP的状态转移里直接查表判断，这样就避免了现场判断回文带来的额外O(n)开销，把整体复杂度从可能的O(n³)压到O(n²)。
- `dp[i]` 采用"前i个字符"的下标定义（而不是"下标i处"），是为了让 `dp[0]` 能自然表示空前缀这个状态，从而设置 `dp[0]=-1` 来补偿"整体回文时不应该多算一刀"的这种情况，这个初始化的直觉理解是关键。
- 状态转移 `dp[i] = min(dp[j]+1)` 的本质，是在枚举"最后一段回文子串"的起点，把大问题拆成"前面已经处理好的部分"加"最后一段"，这是区间类DP里常见的"枚举最后一步"的思考模式。
- 这道题还有个"进阶版"——如果不只是要求分割成回文串且求最少次数，还要求分割成回文串且要恰好满足某些性质（比如每段长度相等），思路框架是类似的，但状态定义会需要额外维度，做题时要先想清楚状态定义能不能覆盖题目所有约束。
