# 0509. 斐波那契数

**题目描述**

斐波那契数列由 0 和 1 开始，之后的每一项都等于前两项之和。也就是说，F(0) = 0，F(1) = 1，当 n > 1 时，F(n) = F(n - 1) + F(n - 2)。给定 n，求 F(n) 的值。

```
示例：
输入: n = 2
输出: 1
解释: F(2) = F(1) + F(0) = 1 + 0 = 1
```

n 的取值范围较小（通常 0 <= n <= 30），不需要考虑大数溢出问题，但这道题的价值不在于结果本身，而在于它是理解动态规划最合适的起点。

## 思路

递推：`F(0)=0、F(1)=1`，`F(i)=F(i-1)+F(i-2)`。从小到大计算，只保存前两项并滚动更新。

时间 O(n)，滚动变量空间 O(1)；保存完整数组需 O(n) 空间。

### LeetCode 写法与原有示例

```python
# 依赖说明：range：Python 内置函数：生成按步长遍历的整数序列。

class Solution:
    # 方法：fib；按题目要求处理输入并返回结果，核心算法见方法体。
    def fib(self, n: int) -> int:
        if n < 2:
            return n  # n=0 返回0，n=1 返回1，对应初始化
        prev2, prev1 = 0, 1  # prev2=dp[i-2]，prev1=dp[i-1]
        curr = 0
        for i in range(2, n + 1):
            curr = prev1 + prev2  # 核心递推：dp[i] = dp[i-1] + dp[i-2]
            prev2, prev1 = prev1, curr  # 同时滚动更新两个变量，避免中间状态被覆盖
        return curr```

// 方法：fib；按题目要求处理输入并返回结果，核心算法见方法体。
func fib(n int) int {
    if n < 2 {
        return n // n=0 返回0，n=1 返回1，对应初始化
    }
    prev2, prev1 := 0, 1 // prev2=dp[i-2], prev1=dp[i-1]
    curr := 0
    for i := 2; i <= n; i++ {
        curr = prev1 + prev2 // 核心递推：dp[i] = dp[i-1] + dp[i-2]
        prev2 = prev1        // 滚动更新 dp[i-2]
        prev1 = curr         // 滚动更新 dp[i-1]
    }
    return curr
}
```

## C++

### LeetCode 写法与原有示例

```cpp
class Solution {
public:
    // 方法：fib；按题目要求处理输入并返回结果，核心算法见方法体。
    int fib(int n) {
        if (n < 2) return n;  // n=0 返回0，n=1 返回1，对应初始化
        int prev2 = 0, prev1 = 1;  // prev2=dp[i-2], prev1=dp[i-1]，滚动变量代替数组
        int curr = 0;
        for (int i = 2; i <= n; i++) {
            curr = prev1 + prev2;  // 核心递推：dp[i] = dp[i-1] + dp[i-2]
            prev2 = prev1;         // 滚动：旧的 dp[i-1] 变成新一轮的 dp[i-2]
            prev1 = curr;          // 滚动：新算出的 dp[i] 变成新一轮的 dp[i-1]
        }
        return curr;
    }
};
```

## 总结

- 斐波那契数列是练"DP五部曲"最干净的例子，因为递推公式是题目直接给的，不需要你额外分析业务逻辑，可以把全部注意力放在这五个步骤各自的作用上。
- 初始化和遍历顺序看起来简单，但它们分别解决的是"递推公式够不到的边界"和"依赖关系决定的计算方向"这两个问题，这在更复杂的DP里恰恰是最容易翻车的地方。
- 当状态转移只依赖有限几个最近的历史状态时（这题就只依赖前两项），可以拿滚动变量代替完整数组，把空间复杂度从O(n)优化到O(1)。
- 举例手动推导dp数组是验证思路对不对的有效手段，应该在写代码之前就做完，而不是靠运行结果跑出来再反向排查错误。
