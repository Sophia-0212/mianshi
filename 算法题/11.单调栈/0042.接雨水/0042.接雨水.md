# 0042. 接雨水

**题目描述**

给定 `n` 个非负整数表示每个宽度为 1 的柱子的高度图，计算按此排列的柱子，下雨之后能接多少雨水。

```
示例：
输入: height = [0,1,0,2,1,0,1,3,2,1,2,1]
输出: 6
解释：上面是由数组 [0,1,0,2,1,0,1,3,2,1,2,1] 表示的高度图，
在这种情况下，可以接 6 个单位的雨水。
```

## 思路

- 前后缀最大值：每列水量为 `min(左最大,右最大)-当前高度`，累加。时间 O(n)，空间 O(n)。
- 双指针：维护左右已扫描最大高度，每次结算较小最大值所在侧并内移。时间 O(n)，空间 O(1)。
- 单调栈：存下标，高度从栈底到栈顶非递增。遇更高柱弹出槽底，若仍有左边界，累加 `(min(左右高度)-槽底高度)×间距`。时间 O(n)，空间 O(n)。

# 依赖说明：len：Python 内置函数：返回容器中元素的数量。；max：Python 内置函数：返回最大值。

# 依赖说明：len：Python 内置函数：返回容器中元素的数量。

# 方法一：双指针
class Solution:
    # 方法：trap；按题目要求处理输入并返回结果，核心算法见方法体。
    def trap(self, height: list[int]) -> int:
        left, right = 0, len(height) - 1
        left_max, right_max = 0, 0  # 分别记录左右指针扫过范围内的最大高度
        water = 0
        while left < right:
            left_max = max(left_max, height[left])
            right_max = max(right_max, height[right])
            if left_max < right_max:
                water += left_max - height[left]  # 左边屏障更矮，决定当前水位
                left += 1
            else:
                water += right_max - height[right]  # 右边屏障更矮或相等
                right -= 1
        return water
```

# 依赖说明：enumerate：Python 内置函数：遍历序列时同时得到下标和值。

# 方法二：单调栈
class Solution:
    # 方法：trap；按题目要求处理输入并返回结果，核心算法见方法体。
    def trap(self, height: list[int]) -> int:
        stack = []   # 栈中存下标，高度从栈底到栈顶递减
        water = 0
        for i, h in enumerate(height):
            while stack and h > height[stack[-1]]:
                mid = stack.pop()          # 槽底
                if not stack:
                    break                   # 左边没有屏障，无法蓄水
                left = stack[-1]            # 左边界
                width = i - left - 1        # 凹槽宽度
                depth = min(height[left], h) - height[mid]  # 这一层高度
                water += width * depth
            stack.append(i)
        return water
```

func trap(height []int) int {
    left, right := 0, len(height)-1
    leftMax, rightMax := 0, 0
    water := 0
    for left < right {
        if height[left] > leftMax {
            leftMax = height[left]
        }
        if height[right] > rightMax {
            rightMax = height[right]
        }
        if leftMax < rightMax {
            water += leftMax - height[left] // 左边屏障更矮，决定水位
            left++
        } else {
            water += rightMax - height[right] // 右边屏障更矮或相等
            right--
        }
    }
    return water
}

// 方法二：单调栈
// 方法：trapStack；按题目要求处理输入并返回结果，核心算法见方法体。
func trapStack(height []int) int {
    stack := make([]int, 0, len(height)) // 栈中存下标，高度递减
    water := 0
    for i, h := range height {
        for len(stack) > 0 && h > height[stack[len(stack)-1]] {
            mid := stack[len(stack)-1]
            stack = stack[:len(stack)-1] // 槽底出栈
            if len(stack) == 0 {
                break // 左边没有屏障
            }
            left := stack[len(stack)-1]      // 左边界
            width := i - left - 1             // 凹槽宽度
            depth := min(height[left], h) - height[mid] // 这一层高度
            water += width * depth
        }
        stack = append(stack, i)
    }
    return water
}

### LeetCode 写法与原有示例

// 依赖说明：vector：C++ STL 动态数组。

// 方法一：双指针，O(n) 时间 O(1) 空间
class Solution {
public:
    // 方法：trap；按题目要求处理输入并返回结果，核心算法见方法体。
    int trap(vector<int>& height) {
        int left = 0, right = height.size() - 1;
        int leftMax = 0, rightMax = 0; // 分别记录左右指针扫过范围内的最大高度
        int water = 0;
        while (left < right) {
            leftMax = max(leftMax, height[left]);
            rightMax = max(rightMax, height[right]);
            if (leftMax < rightMax) {
                // 左边屏障更矮，当前列的水位由leftMax决定
                water += leftMax - height[left];
                left++;
            } else {
                // 右边屏障更矮（或相等），当前列的水位由rightMax决定
                water += rightMax - height[right];
                right--;
            }
        }
        return water;
    }
};```


```cpp
// 依赖说明：vector：C++ STL 动态数组。；stack：C++ STL 栈容器。

// 方法二：单调栈，按凹槽逐层结算
class Solution {
public:
    // 方法：trap；按题目要求处理输入并返回结果，核心算法见方法体。
    int trap(vector<int>& height) {
        stack<int> st;   // 栈中存下标，高度从栈底到栈顶递减
        int water = 0;
        for (int i = 0; i < (int)height.size(); i++) {
            // 当前柱子比栈顶柱子高，说明形成了凹槽的右边界
            while (!st.empty() && height[i] > height[st.top()]) {
                int mid = st.top(); st.pop(); // 槽底
                if (st.empty()) break;        // 左边没有屏障，无法蓄水
                int left = st.top();          // 凹槽左边界
                int width = i - left - 1;                          // 凹槽宽度
                int h = min(height[left], height[i]) - height[mid]; // 凹槽这一层的高度
                water += width * h;
            }
            st.push(i); // 当前下标入栈，作为新的潜在槽底
        }
        return water;
    }
};```

## 总结

- 接雨水这道题的核心公式就是"每一列的积水量 = min(左边最高, 右边最高) - 自身高度"，双指针法靠维护左右两个指针扫过的历史最大值，在不知道对面精确最大值的情况下，也能确定当前列的水位归属到底是谁，这样就把空间优化到了 O(1)。
- 单调栈法换了个视角来看这道题：不是一列一列地算，而是直接定位"凹槽"——左边界、槛底、右边界，一次弹栈就能同时确定凹槽的宽和高，说白了本质是"按层"累加雨水，而双指针/DP 是"按列"累加雨水，两种思路殊途同归，最后结果是一样的。
- 单调栈法里有个容易漏掉的边界条件：一旦弹出槛底之后栈变空了，说明左边根本没有更高的屏障能把水围住，这时候一定要记得 `break` 跳出内层循环。
- 双指针能简化到 O(1) 空间，关键的判断依据就是：只要 `leftMax < rightMax`，就能确定右边一定存在能挡住水的屏障（哪怕还没扫到它具体在哪），所以当前列的水位必然是由 `leftMax` 决定的。这其实是一种"提前确定归属、不用知道精确对手值"的技巧，在双指针这类问题里还挺常见的。
