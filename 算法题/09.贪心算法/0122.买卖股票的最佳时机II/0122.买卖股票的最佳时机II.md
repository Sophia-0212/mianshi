# 0122. 买卖股票的最佳时机II

**题目描述**

给定一个数组 `prices`，其中 `prices[i]` 表示某支股票第 `i` 天的价格。你可以尽可能多地完成交易（多次买入卖出一支股票），但不能同时参与多笔交易（也就是说，必须先卖出手中持有的股票，才能再次购买）。返回你能获得的最大利润。

```
示例：
输入: prices = [7,1,5,3,6,4]
输出: 7
解释: 第2天（股价=1）买入，第3天（股价=5）卖出，这笔交易利润 = 5-1 = 4。
      第4天（股价=3）买入，第5天（股价=6）卖出，这笔交易利润 = 6-3 = 3。
      总利润为 4+3 = 7。
```

## 思路

贪心累加所有正的相邻价差：`sum(max(0,prices[i]-prices[i-1]))`。一段上涨的总利润等于其中每日涨幅之和。

时间 O(n)，空间 O(1)。



## Python

### LeetCode 写法与原有示例

```python
# 依赖说明：len：Python 内置函数：返回容器中元素的数量。；range：Python 内置函数：生成按步长遍历的整数序列。

class Solution:
    # 方法：maxProfit；按题目要求处理输入并返回结果，核心算法见方法体。
    def maxProfit(self, prices: list[int]) -> int:
        result = 0  # 累加所有正的价格差
        for i in range(1, len(prices)):
            diff = prices[i] - prices[i - 1]  # 今天相对昨天的涨跌幅
            if diff > 0:
                result += diff  # 涨了就吃下这部分利润
            # 跌了直接跳过，不进行这次交易
        return result
```

class Solution {
public:
    // 方法：maxProfit；按题目要求处理输入并返回结果，核心算法见方法体。
    int maxProfit(vector<int>& prices) {
        int result = 0;  // 累加所有正的价格差

            }

        }
        return result;
    }
};```

## 总结

- 贪心策略就是把整体买卖利润拆解成逐日价差之和，只累加正的价差，负的价差直接跳过。
- 正确性的关键在于一个恒等式：任意一段持有区间的整体利润，等于区间内每天价差的累加和（中间项两两抵消），这跟实际股价走势没关系，是纯代数事实。
- 因为允许多次买卖且没有次数限制，逐日贪心不仅能完整捕获所有上升行情的收益，还能自动规避掉下跌段造成的损失，等价于全局最优解。
- 本题跟"最大子序和"（0053）都用到了"逐步累加、按正负筛选"的思路，但本题的贪心证明依赖的是"利润拆解成逐日差值之和"这一恒等式，而不是"负前缀不可能贡献最优解"的论证方式，两者的贪心角度是不一样的。
