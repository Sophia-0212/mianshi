# 0122. 买卖股票的最佳时机II

**题目描述**

给定一个数组 `prices`，其中 `prices[i]` 表示某支股票第 `i` 天的价格。你可以尽可能多地完成交易（多次买入卖出一支股票），但不能同时参与多笔交易（也就是说，必须先卖出手中持有的股票，才能再次购买）。返回你能获得的最大利润。

```
示例：
输入: prices = [7,1,5,3,6,4]
输出: 7
解释: 第2天（股价=1）买入，第3天（股价=5）卖出，这笔交易利润 = 5-1 = 4。
      第4天（股价=3）买入，第5天（股价=6）卖出，这笔交易利润 = 6-3 = 3。
      总利润为 4+3 = 7。
```

## 思路

**贪心策略是什么**

我把整个买卖过程拆解成"每天的价格差"：`profit[i] = prices[i] - prices[i-1]`，从第二天开始遍历数组，只累加所有正的价格差，负的价格差直接忽略（不参与累加）。最终累加的结果就是最大利润。

**为什么"只累加正的价格差"等价于原问题的最优解**

这里最关键的一步是一个数学上的恒等式变形。你想啊，假设我们选定了一段区间，在第 `i` 天买入、第 `j` 天卖出（`i < j`），那这一段交易的利润就是 `prices[j] - prices[i]`。这个差值可以拆解成逐日差值的累加和：

```
prices[j] - prices[i]
= (prices[i+1] - prices[i]) + (prices[i+2] - prices[i+1]) + ... + (prices[j] - prices[j-1])
```

这是纯粹的代数恒等式——你把中间项两两写出来，会发现除了首尾的 `prices[i]` 和 `prices[j]`，中间所有的项都会两两抵消（比如 `-prices[i+1]` 和 `+prices[i+1]` 抵消），所以等式左右两边是完全相等的，跟股价的实际走势没关系，对任意数列都成立。

这个恒等式说明了什么呢？说明不管你把一段持有区间划分成多长，这段区间的整体利润，永远等于这段区间内每一天相对前一天的涨跌幅之和。既然这样，要最大化整体利润，就根本不需要纠结"应该在哪天买、哪天卖"这种全局决策了，而是可以把问题彻底简化成一个逐日的独立判断：今天相对昨天涨了，就把这部分涨幅"吃下来"（相当于昨天买入、今天卖出）；今天相对昨天跌了，就跳过（相当于不进行这次交易，避免产生这笔亏损）。

因为本题允许多次买卖且没有次数限制，也不要求"必须连续持有"，所以这种逐日拆解得到的一笔一笔"隔夜交易"，可以完整拼出所有原本连续上升区间的整体收益。你想，假设某一段是连续上升的（比如从第2天的1一直涨到第3天的5），那把这段拆成每天一笔小交易（1→2→3→4→5，如果中间没有波动的话），累加起来的总利润和"第2天买入、第5天直接卖出"是完全相等的，因为中间不存在下跌，每一天的价差都是正的，全部都会被累加进去。而如果中间出现了短暂的下跌，比如先涨后跌再涨，那逐日判断"是正就吃、是负就跳过"的策略，相当于自动地在下跌前卖出、下跌后再买入，这样反而能规避掉这段下跌造成的损失，得到比"傻乎乎地捂着不动"更高的利润。

所以说，逐日判断、只累加正收益的贪心策略，不仅不会漏掉任何一段真实存在的上升行情的收益，还能在允许多次交易的前提下，自动规避掉所有的下跌段——这正是全局最优解所要求的效果，所以该贪心策略与原问题的最优解是完全等价的。

**复杂度分析**

只需要遍历一次数组，比较每天与前一天的价格差，时间复杂度 O(n)。只需要一个变量记录累加的利润，空间复杂度 O(1)。

## 代码

### C++

```cpp
class Solution {
public:
    int maxProfit(vector<int>& prices) {
        int result = 0;  // 累加所有正的价格差
        for (int i = 1; i < prices.size(); i++) {
            int diff = prices[i] - prices[i - 1];  // 今天相对昨天的涨跌幅
            if (diff > 0) {
                result += diff;  // 涨了就吃下这部分利润（相当于昨买今卖）
            }
            // 跌了（diff<=0）直接跳过，不进行这次交易，避免产生亏损
        }
        return result;
    }
};
```

## 总结

- 贪心策略就是把整体买卖利润拆解成逐日价差之和，只累加正的价差，负的价差直接跳过。
- 正确性的关键在于一个恒等式：任意一段持有区间的整体利润，等于区间内每天价差的累加和（中间项两两抵消），这跟实际股价走势没关系，是纯代数事实。
- 因为允许多次买卖且没有次数限制，逐日贪心不仅能完整捕获所有上升行情的收益，还能自动规避掉下跌段造成的损失，等价于全局最优解。
- 本题跟"最大子序和"（0053）都用到了"逐步累加、按正负筛选"的思路，但本题的贪心证明依赖的是"利润拆解成逐日差值之和"这一恒等式，而不是"负前缀不可能贡献最优解"的论证方式，两者的贪心角度是不一样的。
