# 0435. 无重叠区间

**题目描述**

给定一个区间的数组 `intervals`，其中 `intervals[i] = [starti, endi]`，返回需要移除区间的最小数量，使剩余区间互不重叠（区间的边界重合不算重叠，例如 `[1,2]` 和 `[2,3]` 视为不重叠）。

```
示例：
输入: intervals = [[1,2],[2,3],[3,4],[1,3]]
输出: 1
解释: 移除 [1,3] 后，剩下的区间 [[1,2],[2,3],[3,4]] 互不重叠。
```

## 思路

按右端点升序，优先保留结束最早的区间，为后续留出空间。左端点小于已保留右端点则删除，否则保留并更新右端点；端点相等不算重叠。

时间 O(n log n)，扫描辅助空间 O(1)；计入排序时 C++ 常见 O(log n)、Python O(n)。也可按左端点排序，重叠时保留右端点较小者。

# 依赖说明：len：Python 内置函数：返回容器中元素的数量。；range：Python 内置函数：生成按步长遍历的整数序列。

class Solution:
    # 方法：eraseOverlapIntervals；按题目要求处理输入并返回结果，核心算法见方法体。
    def eraseOverlapIntervals(self, intervals: list[list[int]]) -> int:
        if not intervals:
            return 0
        intervals.sort(key=lambda x: x[1])  # 按右边界从小到大排序
        count = 0                             # 需要移除的区间数
        end = intervals[0][1]                 # 当前保留区间的右边界
        for i in range(1, len(intervals)):
            if intervals[i][0] < end:
                # 左边界小于当前保留区间右边界，发生重叠，移除当前这个
                count += 1
            else:
                # 不重叠，保留并更新右边界
                end = intervals[i][1]
        return count```

// 依赖说明：Go 标准库 sort：排序切片。
import "sort"

// 方法：eraseOverlapIntervals；按题目要求处理输入并返回结果，核心算法见方法体。
func eraseOverlapIntervals(intervals [][]int) int {
    if len(intervals) == 0 {
        return 0
    }
    // 按右边界从小到大排序
    sort.Slice(intervals, func(i, j int) bool {
        return intervals[i][1] < intervals[j][1]
    })
    count := 0                    // 需要移除的区间数
    end := intervals[0][1]        // 当前保留区间的右边界
    for i := 1; i < len(intervals); i++ {
        if intervals[i][0] < end {
            // 左边界小于当前保留区间右边界，发生重叠，移除当前这个
            count++
        } else {
            // 不重叠，保留并更新右边界
            end = intervals[i][1]
        }
    }
    return count
}```

## C++

### LeetCode 写法与原有示例

```cpp
class Solution {
public:
    static bool cmp(const vector<int>& a, const vector<int>& b) {
        return a[1] < b[1];  // 按右边界从小到大排序
    }

    // 方法：eraseOverlapIntervals；按题目要求处理输入并返回结果，核心算法见方法体。
    int eraseOverlapIntervals(vector<vector<int>>& intervals) {
        if (intervals.empty()) return 0;
        sort(intervals.begin(), intervals.end(), cmp);  // 按右边界排序
        int count = 0;                 // 需要移除的区间数
        int end = intervals[0][1];     // 当前保留区间的右边界
        for (int i = 1; i < intervals.size(); i++) {
            if (intervals[i][0] < end) {
                // 左边界小于当前保留区间右边界，发生重叠（边界重合不算重叠，用严格小于）
                // 排序后右边界非递减，当前区间右边界必然>=end，故移除当前区间，end不更新
                count++;
            } else {
                // 不重叠，保留这个区间，更新右边界
                end = intervals[i][1];
            }
        }
        return count;
    }
};
```

## 总结

- 跟 452 题共享同一套"排序 + 维护边界变量"的贪心模板，区别在于统计目标（箭数 vs 移除数）和边界重合的语义（`<=` vs `<`）。
- 重叠时保留右边界更小的区间是关键贪心选择，用交换论证可以证明：保留右边界小的区间不会让后续判断变严格，所以不劣于保留右边界大的区间。
- 452 题统计"分组数"就是答案，435 题需要用"总数 - 分组数"才能得到移除数，二者本质上是同一个分组过程的不同读数方式。
- 区间重叠类问题写代码时要特别注意边界符号（`<` 还是 `<=`），这取决于题目对"边界重合是否算重叠"的具体定义。
