# 0455. 分发饼干

**题目描述**

给定两个数组：`g` 表示每个孩子的胃口值，`s` 表示每块饼干的尺寸。只有当饼干尺寸大于或等于孩子的胃口值时，这块饼干才能满足这个孩子。每个孩子最多只能分到一块饼干，每块饼干也最多只能分给一个孩子。求最多能满足多少个孩子。

```
示例：
输入: g = [1,2,3], s = [1,1]
输出: 1
解释: 你有三个孩子和两块小饼干，3个孩子的胃口值分别是1,2,3。
但是你只有两块饼干，如果只满足胃口值最小的孩子，你可以让胃口值为1的孩子得到满足，
输出1。
```

## 思路

排序＋双指针：孩子胃口和饼干尺寸均升序，用能满足当前最小胃口的最小饼干；太小的饼干直接跳过，保留大饼干给更大胃口。

时间 O(n log n+m log m)，扫描辅助空间 O(1)；排序空间 C++ 常见 O(log n+log m)、Python O(n+m)。



## Python

### LeetCode 写法与原有示例

```python
# 依赖说明：len：Python 内置函数：返回容器中元素的数量。

class Solution:
    # 方法：findContentChildren；按题目要求处理输入并返回结果，核心算法见方法体。
    def findContentChildren(self, g: list[int], s: list[int]) -> int:
        g.sort()  # 胃口从小到大排序
        s.sort()  # 饼干尺寸从小到大排序
        child = 0   # 指向当前待满足的孩子
        cookie = 0  # 指向当前待分配的饼干
        while child < len(g) and cookie < len(s):
            if s[cookie] >= g[child]:  # 当前饼干够满足当前孩子
                child += 1              # 满足一个孩子
            cookie += 1  # 这块饼干处理完毕
        return child
```

## C++

### LeetCode 写法与原有示例

```cpp
// 依赖说明：vector：C++ STL 动态数组。；sort：C++ STL algorithm 提供的排序函数。

class Solution {
public:
    // 方法：findContentChildren；按题目要求处理输入并返回结果，核心算法见方法体。
    int findContentChildren(vector<int>& g, vector<int>& s) {
        sort(g.begin(), g.end());  // 胃口从小到大排序
        sort(s.begin(), s.end());  // 饼干尺寸从小到大排序
        int child = 0;             // 指向当前待满足的孩子
        int cookie = 0;            // 指向当前待分配的饼干
        while (child < g.size() && cookie < s.size()) {
            if (s[cookie] >= g[child]) {  // 当前饼干够满足当前孩子
                child++;                  // 满足一个孩子，孩子指针后移
            }
            cookie++;  // 无论是否满足，这块饼干都已经用过（用掉或判定为废饼干），指针后移
        }
        return child;  // child 的值即为满足的孩子数
    }
};```

## 总结

- 这题是"排序后贪心"这一大类问题的入门代表：先把两个数组都排好序，再用双指针从一端开始贪心匹配。
- 贪心策略的正确性可以用交换论证来证明：如果小饼干分给了不该分的大胃口孩子，交换一下发现结果不会变差，这就说明"小饼干优先满足小胃口"这个策略不会比其他方案差。
- 如果最小的饼干连最小胃口都满足不了，直接丢弃这块饼干就是唯一合理的选择，因为它对任何孩子都没用了。
- 以后遇到"两个数组做匹配、追求满足数量最大化"这类题目，可以先考虑一下排序后贪心是否可行，这往往是个挺高效的突破口。
