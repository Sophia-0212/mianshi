# 0053. 最大子序和

**题目描述**

给定一个整数数组 `nums`，请找到一个具有最大和的连续子数组（子数组最少包含一个元素），返回其最大和。

```
示例：
输入: nums = [-2,1,-3,4,-1,2,1,-5,4]
输出: 6
解释: 连续子数组 [4,-1,2,1] 的和最大，为 6。
```

## 思路

- 贪心：累加当前段，先更新最大和；若累计和为负则清零，负前缀只会拖累后续。答案初始化为数组首值，处理全负数。时间 O(n)，空间 O(1)。
- DP：以 `i` 结尾的最大和为 `dp[i]=max(nums[i],dp[i-1]+nums[i])`，取全局最大值。时间 O(n)，数组空间 O(n)，滚动变量 O(1)。

### LeetCode 写法与原有示例

```python
class Solution:
    # 方法：maxSubArray；按题目要求处理输入并返回结果，核心算法见方法体。
    def maxSubArray(self, nums: list[int]) -> int:
        result = float('-inf')  # 记录出现过的最大和
        count = 0                # 当前累加和
        for num in nums:
            count += num  # 累加当前元素
            if count > result:
                result = count  # 更新历史最大值
            if count < 0:
                count = 0  # 累加和为负，丢弃这段前缀，重新从0开始累加
        return result
```

    // 方法：maxSubArray；按题目要求处理输入并返回结果，核心算法见方法体。
    int maxSubArray(vector<int>& nums) {

        int count = 0;         // 当前累加和
        for (int i = 0; i < nums.size(); i++) {

            }
            if (count < 0) {
                count = 0;  // 累加和为负，说明这段前缀只会拖累后面，重置为0重新开始
            }
        }
        return result;
    }
};```

## 总结

- 贪心策略的核心就是"累加和一旦为负就清零重新计数"，因为带着负的前缀往后走只会拖累后面的和，永远不会比丢弃它更好。
- 正确性可以用反证法来说明：如果最优子数组的某段前缀和为负，那去掉这段前缀后剩余部分的和会更大，这就跟"该子数组是全局最优"矛盾了，所以最优解永远不会以负的前缀开头。
- `result` 要在每一步累加后立即更新，不能只在清零时才更新，不然会漏掉最大值恰好出现在清零之前的情况。
- 贪心解法本质上是 DP 解法 `dp[i] = max(dp[i-1] + nums[i], nums[i])` 的空间优化版本，因为状态转移只依赖前一个状态，用一个滚动变量就能代替整个 dp 数组。
