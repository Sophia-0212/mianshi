# 0056. 合并区间

**题目描述**

给定一个区间的集合 `intervals`，其中 `intervals[i] = [starti, endi]`，请合并所有重叠的区间，并返回一个不重叠的区间数组，该数组需恰好覆盖输入中的所有区间。

```
示例：
输入: intervals = [[1,3],[2,6],[8,10],[15,18]]
输出: [[1,6],[8,10],[15,18]]
解释: 区间 [1,3] 和 [2,6] 重叠，将它们合并为 [1,6]。
```

## 思路

**贪心策略是什么**

先把所有区间按左边界从小到大排个序。排完序之后遍历这些区间，维护一个结果列表 `result`。对每个遍历到的区间，判断一下它的左边界是不是小于或等于 `result` 里最后一个区间的右边界：

- 如果是，那就说明发生重叠了，需要合并——把 `result` 最后一个区间的右边界更新成它自身右边界和当前区间右边界里较大的那个（为什么要取较大的？因为合并后的区间要覆盖两个原区间的全部范围，所以右边界必须扩展到能盖住两者的最大值）。
- 如果不是，那说明这个区间跟之前所有区间都不重叠，直接把它当成一个新区间加进 `result` 就行。

**为什么排序后只需要和"结果集最后一个区间"比较**

这里有个容易被忽略、但值得说清楚的技巧点：为什么不用拿当前区间跟 `result` 里更早的每一个区间都比一遍，只比最后一个就够了？

你想啊，原因就在于排序和合并这个过程一起维护了一个隐含的性质：`result` 里的区间本身一直都是按左边界递增、而且互不重叠排列的，同时它们的右边界也是非递减的——为什么呢？因为每次合并只会让右边界变大，而新加入的独立区间左边界又不小于之前所有区间的左边界，这样一来右边界的位置关系自然也就保持有序了。基于这个性质，一旦当前遍历到的区间跟 `result` 最后一个区间不重叠（也就是左边界严格大于最后一个区间的右边界），那它也绝不可能跟 `result` 里更早的任何区间重叠——为什么？因为更早的区间的右边界都小于或等于最后一个区间的右边界，当前区间的左边界已经比这个"最大的右边界"都大了，那自然也大于所有更小的右边界。所以只需要检查跟最后一个区间的关系就够了，不用把整个结果集都遍历一遍去逐一比较。这其实是一种通过排序，把"任意区间对之间的关系"简化成"只需要看相邻/最新一个区间"的典型贪心加双指针技巧。

**为什么合并时要取两者右边界的较大值**

这一点是保证结果正确性的必要条件：题目要求最终返回的区间数组要"恰好覆盖输入中所有区间"，也就是说，合并后的区间必须完整地包含两个原始区间各自的全部范围。你想，如果合并后的右边界只取其中一个区间的右边界，而不是两者中较大的那个，就会导致右边界更大的那个原始区间的一部分范围被"丢弃"在合并结果之外，不满足"恰好覆盖所有输入区间"的要求。所以取较大值扩展右边界是唯一能保证覆盖完整性的做法，这一步没有别的选择空间，是这道题贪心逻辑里"正确性上唯一确定"的部分。

**区间类问题的通用处理范式**

这道题很适合拿来总结一个更普遍的规律：几乎所有涉及区间重叠、区间合并、区间统计的问题，第一步几乎都是"按左边界（或右边界）排序"。排序的作用是什么呢？就是把一个原本需要两两比较所有区间对关系的问题（如果不排序，任意两个区间之间的重叠关系是无序、无规律的，需要 O(n²) 甚至更复杂的比较才能确认所有重叠关系），转化成一次线性遍历（O(n)）就能完成的问题。排序把"任意顺序下复杂的区间关系"转化成了"局部相邻区间之间简单的顺序关系"（只需要比较当前区间和前一个已处理区间的关系），这正是贪心算法处理区间类问题时反复出现的核心技巧，本题、452 题（用最少数量的箭引爆气球）、435 题（无重叠区间）都遵循这一范式。

**复杂度分析**

排序的时间复杂度为 O(n log n)，遍历合并的时间复杂度为 O(n)，总时间复杂度 O(n log n)；空间复杂度 O(n)（用于存储结果数组，不考虑排序本身可能用到的辅助空间）。

## 代码

### C++

```cpp
class Solution {
public:
    vector<vector<int>> merge(vector<vector<int>>& intervals) {
        if (intervals.empty()) return {};
        // 按左边界从小到大排序
        sort(intervals.begin(), intervals.end(),
             [](const vector<int>& a, const vector<int>& b) { return a[0] < b[0]; });

        vector<vector<int>> result;
        result.push_back(intervals[0]);  // 第一个区间直接作为结果集的起点

        for (int i = 1; i < intervals.size(); i++) {
            if (intervals[i][0] <= result.back()[1]) {
                // 左边界不超过结果集最后一个区间的右边界，发生重叠，需要合并
                result.back()[1] = max(result.back()[1], intervals[i][1]);  // 取较大右边界
            } else {
                // 不重叠，作为新区间加入结果集
                result.push_back(intervals[i]);
            }
        }
        return result;
    }
};
```

### Java

```java
class Solution {
    public int[][] merge(int[][] intervals) {
        if (intervals.length == 0) return new int[0][];
        // 按左边界从小到大排序
        Arrays.sort(intervals, (a, b) -> Integer.compare(a[0], b[0]));

        List<int[]> result = new ArrayList<>();
        result.add(intervals[0]);  // 第一个区间直接作为结果集的起点

        for (int i = 1; i < intervals.length; i++) {
            int[] last = result.get(result.size() - 1);
            if (intervals[i][0] <= last[1]) {
                // 左边界不超过结果集最后一个区间的右边界，发生重叠，合并（取较大右边界）
                last[1] = Math.max(last[1], intervals[i][1]);
            } else {
                // 不重叠，作为新区间加入结果集
                result.add(intervals[i]);
            }
        }
        return result.toArray(new int[result.size()][]);
    }
}
```

class Solution:
    def merge(self, intervals: list[list[int]]) -> list[list[int]]:
        if not intervals:
            return []
        intervals.sort(key=lambda x: x[0])  # 按左边界从小到大排序

        for i in range(1, len(intervals)):
            if intervals[i][0] <= result[-1][1]:

            else:
                # 不重叠，作为新区间加入结果集
                result.append(intervals[i])
        return result

### Go

```go
import "sort"

func merge(intervals [][]int) [][]int {
    if len(intervals) == 0 {
        return [][]int{}
    }
    // 按左边界从小到大排序
    sort.Slice(intervals, func(i, j int) bool {
        return intervals[i][0] < intervals[j][0]
    })

    result := [][]int{intervals[0]} // 第一个区间直接作为结果集的起点
    for i := 1; i < len(intervals); i++ {
        last := result[len(result)-1]
        if intervals[i][0] <= last[1] {
            // 左边界不超过结果集最后一个区间的右边界，发生重叠，合并（取较大右边界）
            if intervals[i][1] > last[1] {
                last[1] = intervals[i][1]
            }
        } else {
            // 不重叠，作为新区间加入结果集
            result = append(result, intervals[i])
        }
    }
    return result
}
```

## 总结

- 按左边界排序之后，只需要拿当前区间和结果集最后一个区间比较就能判断重叠，为什么呢？因为排序和合并这个过程一起保证了结果集内部右边界非递减，不可能跟更早的区间产生"漏判"的重叠。
- 合并的时候取两者右边界的较大值，是保证"恰好覆盖所有输入区间"这个要求的必要操作，少取了就会丢失部分原始区间的范围。
- "排序后线性遍历"是区间类问题的通用处理范式，把原本复杂的两两比较关系转化成局部相邻区间的顺序关系，这是贪心算法处理区间问题的核心技巧。
- 这道题跟 452、435 题共享同一套处理框架，差异主要体现在最终要产出的结果形式上——这里是返回合并后的区间列表，而不是统计数量。
