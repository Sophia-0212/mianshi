# 0649. Dota2参议院

**题目描述**

Dota2 的世界里有两个阵营：Radiant（天辉）和 Dire（夜魔）。Dota2 参议院由来自两派的参议员组成，现在参议院希望对某一 Dota2 游戏里的改变作出决定，他们以投票的形式决定。这个投票过程按照以下规则进行：

给定一个字符串 `senate` 代表每个参议员的阵营，`senate[i]` 为 `'R'` 或 `'D'`，字符所在位置代表投票次序。参议员按照排列顺序，轮流行使两项权利中的一项：
- **禁止一名参议员的权利**：参议员可以让另一位参议员在这一轮和随后的几轮中丧失所有权利。
- **宣布胜利**：如果参议员发现所有的参议员都是同一个阵营的，他可以宣布胜利并决定在游戏中的有关变化。

给定一个字符串代表每个参议员的阵营，请预测哪一个阵营最终会宣布胜利并在 Dota2 游戏中决定改变。输出应该是 `Radiant` 或 `Dire`。

```
示例：
输入：senate = "RD"
输出："Radiant"
解释：第 1 个参议员来自 Radiant 阵营，他可以使用第一项权利让第 2 个参议员失去权力。
剩下所有的参议员都是 Radiant 阵营的，所以宣布胜利。

输入：senate = "RDD"
输出："Dire"
解释：
第 1 个参议员来自 Radiant 阵营，他可以使用第一项权利禁止第 2 个参议员的权利。
第 2 个参议员被禁止了所有的权利。
第 3 个参议员来自 Dire 阵营，他可以使用他的权利禁止第 1 个参议员的权利。
因为参议院中只剩下第 3 个参议员，所以他可以宣布胜利。
```

## 思路

双队列保存两阵营的下标。每次取双方队头，下标小者先行动，淘汰对方并将自身下标加 `n` 后入队。某队为空时另一方获胜；优先淘汰最早能行动的对手。

每次对抗淘汰一人，时间 O(n)，空间 O(n)。

                # R 更早行动，禁掉 D；R 存活，下标+n 表示进入下一轮
                radiant.append(r + n)
            else:
                dire.append(d + n)

        return "Radiant" if radiant else "Dire"  # 非空的队列即为胜者```

```go
// 方法：predictPartyVictory；按题目要求处理输入并返回结果，核心算法见方法体。
func predictPartyVictory(senate string) string {
    n := len(senate)
    radiant := make([]int, 0, n)
    dire := make([]int, 0, n)
    for i, c := range senate {
        if c == 'R' {
            radiant = append(radiant, i)
        } else {
            dire = append(dire, i)
        }
    }

    for len(radiant) > 0 && len(dire) > 0 {
        r, d := radiant[0], dire[0]
        radiant, dire = radiant[1:], dire[1:] // 弹出两队队首
        if r < d {
            radiant = append(radiant, r+n) // R 先行动，禁掉 D，自己进入下一轮
        } else {
            dire = append(dire, d+n) // D 先行动，禁掉 R，自己进入下一轮
        }
    }

    if len(radiant) > 0 {
        return "Radiant"
    }
    return "Dire"
}
```

## C++

### LeetCode 写法与原有示例

```cpp
class Solution {
public:
    // 方法：predictPartyVictory；按题目要求处理输入并返回结果，核心算法见方法体。
    string predictPartyVictory(string senate) {
        int n = senate.size();
        queue<int> radiant, dire;  // 分别存放 R、D 阵营参议员的下标
        for (int i = 0; i < n; i++) {
            if (senate[i] == 'R') radiant.push(i);
            else dire.push(i);
        }
        while (!radiant.empty() && !dire.empty()) {
            int r = radiant.front(); radiant.pop();  // R 阵营下一个行动的人
            int d = dire.front(); dire.pop();        // D 阵营下一个行动的人
            if (r < d) {
                // R 先行动，禁掉 D，R 存活并进入下一轮（下标+n 表示时间顺序后移）
                radiant.push(r + n);
            } else {
                dire.push(d + n);
            }
        }
        return radiant.empty() ? "Dire" : "Radiant";  // 哪个队列还有剩余就是赢家
    }
};
```

## 总结

- 核心贪心策略是"谁先行动谁就优先消灭对方下一个即将行动的人"，本质上是在争夺行动的先手权，这类"轮流行动、互相消耗"的博弈模拟题经常可以转化为贪心+队列模型。
- 给重新入队的下标加上 `n` 是本题最关键的技巧：它把"轮次信息"编码进了下标数值本身，让两个独立队列之间依然可以通过简单的数值比较还原出全局的真实时间顺序，避免了显式模拟每一轮、每一个位置的复杂操作。
- 时间复杂度做到了 O(n)，因为每一轮必定有一个参议员永久出局，循环次数不会超过参议员总数。
- 容易犯的错误是直接用两个指针在原字符串上模拟轮转，忘了被禁止的参议员是永久出局的，还试图给"存活"和"出局"分别加复杂的标记数组——队列模型天然免除了这个麻烦，因为出队的人默认不会再出现，除非显式重新入队。
