# 1221. 分割平衡字符串

**题目描述**

在一个「平衡字符串」中，`'L'` 和 `'R'` 字符的数量是相同的。

给你一个平衡字符串 `s`，请你将它分割成尽可能多的平衡字符串。注意：分割得到的每个字符串都必须是平衡字符串（要求分割后每一部分单独看，L 和 R 数量相等），且必须使用原字符串的全部字符（不能省略任何字符）。

返回可以通过分割得到的平衡字符串的最大数量。

```
示例：
输入：s = "RLRRLLRLRL"
输出：4
解释：s 可以分割为 "RL"、"RRLL"、"RL"、"RL"，每个子字符串中都包含相同数量的 'L' 和 'R'。

输入：s = "RLLLLRRRLR"
输出：3
解释：s 可以分割为 "RL"、"LLLRRR"、"LR"，每个子字符串中都包含相同数量的 'L' 和 'R'。
```

## 思路

贪心计数：`L` 加一，`R` 减一；计数归零立即切分并累加段数。每段尽早结束，为后续保留最多切分机会。

时间 O(n)，空间 O(1)。



## Python

### LeetCode 写法与原有示例

本题逻辑非常简单，标准库没有直接对应的一行解法，直接给出手写实现：

```python
class Solution:
    # 方法：balancedStringSplit；按题目要求处理输入并返回结果，核心算法见方法体。
    def balancedStringSplit(self, s: str) -> int:
        balance = 0  # L 记 +1，R 记 -1，归零说明当前段落已经平衡
        count = 0    # 切分出的平衡子串数量
        for c in s:
            balance += 1 if c == 'L' else -1  # 累加当前字符对平衡度的贡献
            if balance == 0:
                count += 1  # 归零，贪心地立刻切一刀
        return count
```

## Go

### LeetCode 写法与原有示例

```go
// 方法：balancedStringSplit；按题目要求处理输入并返回结果，核心算法见方法体。
func balancedStringSplit(s string) int {
    balance := 0 // L 记 +1，R 记 -1
    count := 0   // 切分出的平衡子串数量
    for _, c := range s {
        if c == 'L' {
            balance++ // L 对平衡度贡献 +1
        } else {
            balance-- // R 对平衡度贡献 -1
        }
        if balance == 0 {
            count++ // 归零，说明当前段落已平衡，贪心切一刀
        }
    }
    return count
}
```

### LeetCode 写法与原有示例

class Solution {
public:
    // 方法：balancedStringSplit；按题目要求处理输入并返回结果，核心算法见方法体。
    int balancedStringSplit(string s) {
        int balance = 0;  // L 记 +1，R 记 -1，归零说明当前段落平衡
        int count = 0;    // 记录切分出的平衡子串数量

                count++;      // 归零，说明可以在此处切一刀
            }
        }
        return count;
    }
};```

## 总结

- 这题贪心为什么成立呢？说白了就是"越早切分，总段数不会变少"这个单调性——只要计数器归零就立刻切，既不会影响整体的平衡性，又能保证段数最多。
- "遇到某类字符+1、遇到另一类字符-1、计数器归零就算成立"，这是处理成对匹配、平衡类问题的一个通用范式，同样的思路你在有效括号匹配、判断字符串能否被特定模式整除这些题目里也能看到。
- 不用真的对字符串做切割操作，只要用一个整型变量去模拟"当前段落是不是平衡的"就行，这是用O(1)额外空间代替显式数据结构操作的一个典型例子。
- 容易搞混的一点是，这里统计的是"能切出多少段"，不是"每段具体是什么内容"，所以归零那一瞬间给计数器加一就够了，完全不需要记录子串的起止下标或者具体字符。
