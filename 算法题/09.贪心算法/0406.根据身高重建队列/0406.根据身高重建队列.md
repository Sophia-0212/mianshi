# 0406. 根据身高重建队列

**题目描述**

假设有打乱顺序的一群人站成一个队列，每个人由一个整数对 `(h, k)` 描述，其中 `h` 是这个人的身高，`k` 是排在这个人前面且身高大于或等于 `h` 的人数。请你重新构造并返回输入数组 `people` 所表示的队列。返回的队列应该形如 `[[h1,k1],[h2,k2],...]`，其中 `[hi, ki]` 是队列中第 `i` 个人的属性。

```
示例：
输入: people = [[7,0],[4,4],[7,1],[5,0],[6,1],[5,2]]
输出: [[5,0],[7,0],[5,2],[6,1],[4,4],[7,1]]
解释:
编号为 0 的人身高为 5，前面没有身高大于等于 5 的人，所以他必须排在最前面。
编号为 1 的人身高为 7，前面也没有身高大于等于 7 的人，所以他排在第二位。
编号为 2 的人身高为 5，前面有 2 个身高大于等于 5 的人，那就是编号为 0 和 1 的人。
...（以此类推）
```

## 思路

- 贪心插入：按身高降序、同高按 `k` 升序排序，再依次插入下标 `k`。已插入者均不矮于当前人，矮者后续插入不影响其计数。时间 O(n²)，空间 O(n)。
- 树状数组／线段树：按身高升序、同高 `k` 降序，将人放入第 `k+1` 个空位。时间 O(n log n)，空间 O(n)。

class Solution:
    # 方法：reconstructQueue；按题目要求处理输入并返回结果，核心算法见方法体。
    def reconstructQueue(self, people: list[list[int]]) -> list[list[int]]:
        # 身高降序；身高相同时 k 升序
        people.sort(key=lambda p: (-p[0], p[1]))

        result = []
        for p in people:
            result.insert(p[1], p)  # 插入到下标为 k 的位置
        return result
```

// 方法：reconstructQueue；按题目要求处理输入并返回结果，核心算法见方法体。
func reconstructQueue(people [][]int) [][]int {
    // 身高降序；身高相同时 k 升序
    sort.Slice(people, func(i, j int) bool {
        if people[i][0] == people[j][0] {
            return people[i][1] < people[j][1]
        }
        return people[i][0] > people[j][0]
    })

    result := make([][]int, 0, len(people))
    for _, p := range people {
        k := p[1]
        result = append(result, nil)
        copy(result[k+1:], result[k:]) // 后面元素整体后移一位
        result[k] = p                  // 插入到下标为 k 的位置
    }
    return result
}
```

## C++

### LeetCode 写法与原有示例

```cpp
// 依赖说明：vector：C++ STL 动态数组。；sort：C++ STL algorithm 提供的排序函数。

class Solution {
public:
    vector<vector<int>> reconstructQueue(vector<vector<int>>& people) {
        // 身高降序；身高相同时 k 升序
        sort(people.begin(), people.end(), [](const vector<int>& a, const vector<int>& b) {
            if (a[0] == b[0]) return a[1] < b[1];
            return a[0] > b[0];
        });

        vector<vector<int>> result;
        for (auto& p : people) {
            result.insert(result.begin() + p[1], p); // 插入到下标为 k 的位置
        }
        return result;
    }
};```

## 总结

- 遇到"每个元素受两个维度约束"的问题时，可以尝试先固定一个维度的处理顺序，把二维问题降成一维问题，这是一种通用的贪心降维技巧。
- 本题按身高降序处理的本质原因是：先确定的人身高更高，后续插入的人不会影响已确定的人的"前面身高≥自己的人数"这一约束，从而保证每一步插入都不会被后续操作破坏。
- 身高相同时按 k 升序排列，是为了让同身高的人之间的相对顺序跟插入顺序保持一致。
- 直接用数组插入的实现方式简单直观但是 O(n²)，如果对性能有更高要求，可以考虑链表或树状结构优化插入操作。
