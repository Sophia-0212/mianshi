# 0376. 摆动序列

**题目描述**

如果一个序列中，相邻两个元素的差严格地在正负之间交替（即差值符号交替变化），那么这个序列被称为摆动序列。给定一个整数数组 `nums`，求其中最长摆动子序列的长度（子序列可以不连续，但要保持原数组中的相对顺序）。

```
示例：
输入: nums = [1,7,4,9,2,5]
输出: 6
解释: 整个数组就是一个摆动序列，差值为 (6,-3,5,-7,3)，符号严格交替。

输入: nums = [1,17,5,10,13,15,10,5,16,8]
输出: 7
解释: 存在多种最长摆动子序列，一个例子是 [1,17,10,13,10,16,8]，差值为 (16,-7,3,-3,6,-8)。
```

## 思路

贪心只保留峰谷：统计相邻差值的正负交替次数，初始长度为 1。零差跳过；仅符号反转时更新前差和长度。

时间 O(n)，空间 O(1)。



## Python

### LeetCode 写法与原有示例

```python
# 依赖说明：len：Python 内置函数：返回容器中元素的数量。；range：Python 内置函数：生成按步长遍历的整数序列。

class Solution:
    # 方法：wiggleMaxLength；按题目要求处理输入并返回结果，核心算法见方法体。
    def wiggleMaxLength(self, nums: list[int]) -> int:
        if len(nums) <= 1:
            return len(nums)  # 长度 0 或 1 时本身就是摆动序列
        result = 1     # 第一个元素默认算作起点
        prediff = 0    # 上一次真正发生摆动的差值方向，初始为0
        for i in range(1, len(nums)):
            curdiff = nums[i] - nums[i - 1]  # 当前相邻差值
            # 谷底转峰顶 或 峰顶转谷底 时才计数
            if (prediff <= 0 and curdiff > 0) or (prediff >= 0 and curdiff < 0):
                result += 1        # 出现新的峰值/谷值
                prediff = curdiff  # 更新方向，平坡（curdiff==0）不更新
        return result
```

## C++

### LeetCode 写法与原有示例

```cpp
// 依赖说明：vector：C++ STL 动态数组。

class Solution {
public:
    // 方法：wiggleMaxLength；按题目要求处理输入并返回结果，核心算法见方法体。
    int wiggleMaxLength(vector<int>& nums) {
        if (nums.size() <= 1) return nums.size();  // 长度 0 或 1 时本身就是摆动序列
        int result = 1;    // 默认第一个元素算作序列的起点，长度至少为1
        int prediff = 0;   // 记录上一次真正发生摆动的差值符号（初始为0表示尚未摆动）
        for (int i = 1; i < nums.size(); i++) {
            int curdiff = nums[i] - nums[i - 1];  // 当前相邻元素的差值
            // 谷底转峰顶（prediff<=0 说明之前是下降或平坡，curdiff>0 说明现在上升）
            // 或者峰顶转谷底（prediff>=0 说明之前是上升或平坡，curdiff<0 说明现在下降）
            if ((prediff <= 0 && curdiff > 0) || (prediff >= 0 && curdiff < 0)) {
                result++;        // 出现一次新的摆动，长度加一
                prediff = curdiff;  // 更新为最近一次真正的摆动方向，供下次比较
            }
            // curdiff == 0（平坡）或方向未变化时，不更新prediff，跳过不计数
        }
        return result;
    }
};```

## 总结

- 贪心策略就是只统计"局部峰值"（相邻差值符号发生变化的位置），说白了本质上就是删掉单调区间内部的所有中间元素，只留区间端点。
- 正确性证明的关键在哪儿呢？就在于单调区间内的中间元素不管留多少个都没法增加摆动次数（因为符号不会交替），而用峰值点去代替任意一个非峰值点，不会让摆动长度变差，所以贪心选峰值不会比任何其他方案差。
- 差值为0（平坡）的情况不能更新 prediff，不然会导致漏判或者重复计数，这是这题最容易出错的边界，得留意。
- 这题跟"最大子序和"（0053）都体现了"用一个方向标志/累加变量做单次遍历决策"的贪心手法，但摆动序列关注的是符号变化次数，最大子序和关注的是累加值的正负，这一点要分清楚，别搞混了。
