# 贪心算法总结

贪心每步选择需能扩展为全局最优；用交换论证、归纳或反例检验，排序本身不保证正确。

| 模式 | 关键选择 | 示例 |
|---|---|---|
| 排序匹配 | 最小可用资源满足最小需求 | 分发饼干 |
| 峰谷统计 | 舍弃单调段内部元素 | 摆动序列 |
| 利润分解 | 累加正增量 | 股票 II |
| 边界维护 | 合并可达范围 | 跳跃游戏 |
| 负值重置 | 丢弃负贡献前缀 | 最大子序和、加油站 |
| 两次遍历 | 分别满足左右约束 | 分发糖果 |
| 区间排序 | 尽早结束／更新交集或并集 | 无重叠区间、气球、合并区间 |

扫描类常为时间 O(n)、空间 O(1)；排序类常为 O(n log n)，空间依排序及状态。若决策依赖多个不可舍弃的历史状态，考虑 DP。
