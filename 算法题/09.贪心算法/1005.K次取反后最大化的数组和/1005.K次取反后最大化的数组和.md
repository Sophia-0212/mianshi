# 1005. K次取反后最大化的数组和

**题目描述**

给定一个整数数组 `nums` 和一个整数 `K`，可以对数组中的元素多次执行"取反"操作（同一个下标的元素可以被多次取反），但必须恰好执行 `K` 次取反（不能多也不能少）。求操作后数组所有元素的最大可能和。

```
示例：
输入: nums = [4,2,3], K = 1
输出: 5
解释: 选择将 2 变为 -2，数组变为 [4,-2,3]，其和为 5。

输入: nums = [3,-1,0,2], K = 3
输出: 6
```

## 思路

**贪心策略是什么**

这是一道需要两步贪心才能完整解决的题目。

第一步：把数组按绝对值从大到小排序，从头开始遍历。遍历过程中，只要遇到负数，就把它取反变成正数，同时把 `K` 减一，直到 `K` 用完或者数组中已经没有负数为止。这一步的局部最优选择是什么呢？就是优先把绝对值大的负数取反变正，因为绝对值越大的负数，取反后对总和的提升幅度也越大。

第二步：处理完所有负数后，如果 `K` 还有剩余，分两种情况讨论：
- 如果剩余的 `K` 是偶数，直接结束，不需要再做任何操作。为什么呢？因为对同一个数字取反两次等于没有取反（正正得正），偶数次取反最终效果和不取反完全一样，不会改变数组的和。
- 如果剩余的 `K` 是奇数，就必须再取反一次。这时候应该找出数组中绝对值最小的那个元素，把它取反（哪怕它原本已经是正数也要取反），为什么这样做呢？因为这一次"多余"的取反无法避免，让绝对值最小的元素来承担这次取反造成的损失，才能让总和的损失降到最小。

**为什么按绝对值从大到小排序、优先处理负数是最优的**

假设数组中存在两个负数 `a` 和 `b`，且 `|a| > |b|`。如果当前 `K` 只够取反一个数，应该选择取反 `a` 还是 `b` 呢？取反 `a` 能让总和增加 `2|a|`（从 `a` 变成 `-a`，增量是 `-a - a = -2a = 2|a|`，因为 `a` 是负数），取反 `b` 只能让总和增加 `2|b|`。由于 `|a| > |b|`，显然 `2|a| > 2|b|`，所以优先取反绝对值更大的负数，能获得更大的总和提升，这就是局部最优选择最直接的体现。

把这个两两比较的结论推广到整个数组：只要数组中还存在负数，每一步都应该在当前剩余的负数里，选择绝对值最大的那个来取反，这样才能保证每一次取反操作带来的总和增量都是当前状态下能获得的最大增量。按绝对值从大到小排序后从头遍历，恰好保证了每一步遇到的负数都是当前剩余负数中绝对值最大的（因为已经排好序，前面处理过的都是比它更大的），所以这个遍历顺序天然实现了"每一步都选增益最大的负数取反"这个贪心过程，这是标准的贪心排序思路。

**为什么"剩余K为奇数时，取反绝对值最小的元素"是对的**

因为题目要求 `K` 必须被恰好用完，一次不多一次不少。如果处理完所有负数后 `K` 还有剩余，且剩余的次数是奇数，那么无论怎么安排，必然有某一个元素最终被"多取反了一次"（因为偶数次取反可以互相抵消，但奇数次不行，总会有一次落单）。这次落单的取反会让某个元素从正变负（如果这时候已经没有负数了，只能拿正数开刀），造成的总和损失是"该元素绝对值的两倍"（因为从 `x` 变成 `-x`，总和的变化量是 `-x - x = -2x`，即损失了 `2x`，也就是 `2|x|`）。

既然这次损失无法避免，要让损失最小化，自然应该选择数组中绝对值最小的那个元素来承担这次取反，因为绝对值越小，`2×|该元素|` 这个损失值也越小。这样选出来的方案，是所有可能选择里损失最小的一种，因此总和是在"恰好用完K次取反"这个约束下能达到的最大值。

需要注意的是，这里"绝对值最小的元素"指的是经过第一步处理后（所有能取反的负数都已经取反变正）整个数组里绝对值最小的元素，它可能是原数组中的正数，也可能是刚被取反过的、原本是负数但现在变成正数的元素，甚至可能是数值 0（如果数组中有 0，取反它总和不会有任何损失，因为 `0` 和 `-0` 相等，损失为 `2×0=0`，是最优的选择）。

**复杂度分析**

排序的时间复杂度是 O(n log n)，之后两次遍历数组（一次处理负数，一次找绝对值最小值）都是 O(n)，所以总时间复杂度为 O(n log n)。空间复杂度 O(1)（不考虑排序过程可能用到的辅助空间）。

## 代码

### C++

```cpp
class Solution {
public:
    int largestSumAfterKNegations(vector<int>& nums, int K) {
        // 按绝对值从大到小排序，保证优先处理绝对值大的负数
        sort(nums.begin(), nums.end(), [](int a, int b) {
            return abs(a) > abs(b);
        });
        for (int i = 0; i < nums.size(); i++) {
            // 只要还有K的次数，且当前是负数，就取反（绝对值越大的负数优先处理，收益最大）
            if (nums[i] < 0 && K > 0) {
                nums[i] = -nums[i];
                K--;
            }
        }
        // 遍历完负数后，若K还有剩余且为奇数，必须再取反一次
        // 数组已按绝对值降序排列，此时最后一个元素就是绝对值最小的，取反它损失最小
        if (K % 2 == 1) {
            nums[nums.size() - 1] = -nums[nums.size() - 1];
        }
        int result = 0;
        for (int num : nums) {
            result += num;  // 累加最终数组的和
        }
        return result;
    }
};
```

class Solution {
    public int largestSumAfterKNegations(int[] nums, int K) {
        // 按绝对值从大到小排序
        Integer[] boxed = new Integer[nums.length];
        for (int i = 0; i < nums.length; i++) boxed[i] = nums[i];
        Arrays.sort(boxed, (a, b) -> Math.abs(b) - Math.abs(a));
        for (int i = 0; i < boxed.length; i++) boxed[i] = boxed[i];

        for (int i = 0; i < boxed.length; i++) {
            // 优先取反绝对值大的负数，收益最大
            if (boxed[i] < 0 && K > 0) {
                boxed[i] = -boxed[i];
                K--;
            }
        }
        // K剩余为奇数时，取反绝对值最小的元素（数组末尾），使损失最小
        if (K % 2 == 1) {
            boxed[boxed.length - 1] = -boxed[boxed.length - 1];
        }
        int result = 0;
        for (int num : boxed) {
            result += num;
        }
        return result;
    }
}

class Solution:
    def largestSumAfterKNegations(self, nums: list[int], K: int) -> int:
        # 按绝对值从大到小排序，优先让绝对值大的负数被取反
        nums.sort(key=lambda x: abs(x), reverse=True)
        for i in range(len(nums)):
            # 只要还有K的次数，且当前是负数，就取反（局部最优：绝对值大的负数优先处理）
            if nums[i] < 0 and K > 0:
                nums[i] = -nums[i]
                K -= 1
        # 剩余K为奇数时，必须再取反一次，选绝对值最小的元素（此时在数组末尾）损失最小
        if K % 2 == 1:
            nums[-1] = -nums[-1]
        return sum(nums)

    if x < 0 {
        return -x
    }

## 总结

- 本题是两步贪心的组合：第一步按绝对值从大到小优先取反负数（局部最优：绝对值大的负数取反收益最大），第二步处理K剩余为奇数时取反绝对值最小的元素（局部最优：损失最小）。
- 第一步的正确性可以用两两比较证明：取反绝对值更大的负数带来的总和增量 `2|a|` 一定大于取反绝对值更小的负数的增量 `2|b|`，排序后遍历天然实现了"每步选增益最大"的贪心过程。
- 第二步的正确性在于：K必须恰好用完，多余的一次取反造成的损失是`2×|该元素|`，无法避免，只能通过选择绝对值最小的元素来把这个损失降到最低。
- 偶数次取反等于不取反（可以互相抵消），所以只有K剩余为奇数时才需要额外处理，这是本题容易被忽略的边界条件。
