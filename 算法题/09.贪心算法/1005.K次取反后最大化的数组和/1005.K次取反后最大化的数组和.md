# 1005. K次取反后最大化的数组和

**题目描述**

给定一个整数数组 `nums` 和一个整数 `K`，可以对数组中的元素多次执行"取反"操作（同一个下标的元素可以被多次取反），但必须恰好执行 `K` 次取反（不能多也不能少）。求操作后数组所有元素的最大可能和。

```
示例：
输入: nums = [4,2,3], K = 1
输出: 5
解释: 选择将 2 变为 -2，数组变为 [4,-2,3]，其和为 5。

输入: nums = [3,-1,0,2], K = 3
输出: 6
```

## 思路

按绝对值降序，优先把负数取反，收益最大。负数处理完后，若剩余 `k` 为奇数，再取反绝对值最小的元素；偶数次可相互抵消。

时间 O(n log n)，扫描辅助空间 O(1)；计入排序时 C++ 常见 O(log n)、Python O(n)。

class Solution:
    # 方法：largestSumAfterKNegations；按题目要求处理输入并返回结果，核心算法见方法体。
    def largestSumAfterKNegations(self, nums: list[int], K: int) -> int:
        # 按绝对值从大到小排序，优先让绝对值大的负数被取反
        nums.sort(key=lambda x: abs(x), reverse=True)
        for i in range(len(nums)):
            # 只要还有K的次数，且当前是负数，就取反（局部最优：绝对值大的负数优先处理）
            if nums[i] < 0 and K > 0:
                nums[i] = -nums[i]
                K -= 1
        # 剩余K为奇数时，必须再取反一次，选绝对值最小的元素（此时在数组末尾）损失最小
        if K % 2 == 1:
            nums[-1] = -nums[-1]
        return sum(nums)
```

func largestSumAfterKNegations(nums []int, K int) int {
    // 按绝对值从大到小排序
    sort.Slice(nums, func(i, j int) bool {
        return abs(nums[i]) > abs(nums[j])
    })
    for i := 0; i < len(nums); i++ {
        // 优先取反绝对值大的负数，收益最大
        if nums[i] < 0 && K > 0 {
            nums[i] = -nums[i]
            K--
        }
    }

    }
    result := 0
    for _, num := range nums {
        result += num // 累加最终数组的和
    }
    return result
}

## C++

### LeetCode 写法与原有示例

```cpp
// 依赖说明：vector：C++ STL 动态数组。；sort：C++ STL algorithm 提供的排序函数。

class Solution {
public:
    // 方法：largestSumAfterKNegations；按题目要求处理输入并返回结果，核心算法见方法体。
    int largestSumAfterKNegations(vector<int>& nums, int K) {
        // 按绝对值从大到小排序，保证优先处理绝对值大的负数
        sort(nums.begin(), nums.end(), [](int a, int b) {
            return abs(a) > abs(b);
        });
        for (int i = 0; i < nums.size(); i++) {
            // 只要还有K的次数，且当前是负数，就取反（绝对值越大的负数优先处理，收益最大）
            if (nums[i] < 0 && K > 0) {
                nums[i] = -nums[i];
                K--;
            }
        }
        // 遍历完负数后，若K还有剩余且为奇数，必须再取反一次
        // 数组已按绝对值降序排列，此时最后一个元素就是绝对值最小的，取反它损失最小
        if (K % 2 == 1) {
            nums[nums.size() - 1] = -nums[nums.size() - 1];
        }
        int result = 0;
        for (int num : nums) {
            result += num;  // 累加最终数组的和
        }
        return result;
    }
};```

## 总结

- 本题是两步贪心的组合：第一步按绝对值从大到小优先取反负数（局部最优：绝对值大的负数取反收益最大），第二步处理K剩余为奇数时取反绝对值最小的元素（局部最优：损失最小）。
- 第一步的正确性可以用两两比较证明：取反绝对值更大的负数带来的总和增量 `2|a|` 一定大于取反绝对值更小的负数的增量 `2|b|`，排序后遍历天然实现了"每步选增益最大"的贪心过程。
- 第二步的正确性在于：K必须恰好用完，多余的一次取反造成的损失是`2×|该元素|`，无法避免，只能通过选择绝对值最小的元素来把这个损失降到最低。
- 偶数次取反等于不取反（可以互相抵消），所以只有K剩余为奇数时才需要额外处理，这是本题容易被忽略的边界条件。
