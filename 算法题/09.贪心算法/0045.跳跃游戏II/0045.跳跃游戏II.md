# 0045. 跳跃游戏II

**题目描述**

给定一个非负整数数组 `nums`，数组中的每个元素代表你在该位置可以跳跃的最大长度。你的目标是使用最少的跳跃次数到达数组的最后一个位置。假设你总能到达数组的最后一个位置。

```
示例：
输入: nums = [2,3,1,1,4]
输出: 2
解释: 跳到下标1（跳1步），然后跳3步到达最后一个位置（下标4）。
```

## 思路

贪心维护本次跳跃边界 `curEnd` 和下一次最远边界 `nextEnd`。遍历可达位置更新 `nextEnd=max(nextEnd,i+nums[i])`；到达 `curEnd` 时跳数加一，并更新边界。

只遍历到倒数第二个位置，避免到终点后多算一次。题目保证可达；时间 O(n)，空间 O(1)。

```python
    # 方法：jump；按题目要求处理输入并返回结果，核心算法见方法体。
    def jump(self, nums: list[int]) -> int:
        if len(nums) == 1:
            return 0  # 起点即终点，不需要跳跃
        cur_distance = 0   # 当前这一跳能到达的最远距离
        next_distance = 0  # 下一跳能到达的最远距离
        result = 0         # 跳跃次数
        for i in range(len(nums) - 1):  # 不遍历最后一个下标，避免多算一次跳跃
            next_distance = max(next_distance, i + nums[i])  # 合并下一跳的最大覆盖范围

                cur_distance = next_distance  # 扩展到下一层
                result += 1                    # 跳跃次数加一
        return result
```

```go
func jump(nums []int) int {
    if len(nums) == 1 {
        return 0 // 起点即终点，不需要跳跃
    }
    curDistance, nextDistance, result := 0, 0, 0
    for i := 0; i < len(nums)-1; i++ { // 不遍历最后一个下标，避免多算一次
        if i+nums[i] > nextDistance {
            nextDistance = i + nums[i] // 合并下一跳能到达的最大范围
        }
        if i == curDistance { // 当前范围走到尽头，必须再跳一次
            curDistance = nextDistance // 扩展到下一层覆盖范围
            result++                   // 跳跃次数加一
        }
    }
    return result
}
```

class Solution {
public:
    // 方法：jump；按题目要求处理输入并返回结果，核心算法见方法体。
    int jump(vector<int>& nums) {
        if (nums.size() == 1) return 0;  // 起点即终点，不需要跳跃
        int curDistance = 0;   // 当前这一跳能到达的最远距离
        int nextDistance = 0;  // 再多跳一步能到达的最远距离
        int result = 0;        // 跳跃次数
        for (int i = 0; i < nums.size() - 1; i++) {  // 不遍历最后一个下标，避免多算一次
            nextDistance = max(nextDistance, i + nums[i]);  // 持续合并下一跳能到达的最大范围
            if (i == curDistance) {  // 当前跳跃的覆盖范围已经走到尽头，必须再跳一次
                curDistance = nextDistance;  // 扩展到下一层覆盖范围
                result++;                    // 跳跃次数加一
            }
        }
        return result;
    }
};```

## 总结

- 贪心策略就是维护两个边界，`curDistance`（当前跳的覆盖范围）和 `nextDistance`（下一跳的覆盖范围），等遍历走到当前边界了才扩展到下一层，本质上就是 BFS 按层扩展求最短路径层数的思路。
- 正确性的关键在哪儿呢？就在于遍历完当前范围内所有位置后拿到的最大 `nextDistance`，正是这个范围内能提供的最大跳跃能力，不会再有更优的选择了，所以按层扩展得到的次数就是理论最小值。
- 如果提前跳跃、没把当前范围内所有位置遍历完，就可能错过范围里某个位置更大的跳跃能力，导致后面得多跳几次。
- 实现的时候循环范围要写成 `i < nums.size() - 1`，这样才能避免在已经到达终点的情况下还多算一次不必要的跳跃。
