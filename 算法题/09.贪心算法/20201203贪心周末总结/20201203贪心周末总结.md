# 贪心算法周末总结（2020.12.03）

**股票 II**：累加正的相邻价差，等价于收集所有上涨利润。时间 O(n)，空间 O(1)。

```
// 伪代码示意
profit = 0
for i in 1..n-1:
    if prices[i] > prices[i-1]:
        profit += prices[i] - prices[i-1]
return profit
```

**跳跃游戏**：只从可达位置更新最远边界，覆盖终点即成功；最少跳数再维护当前层、下一层边界，到当前边界时跳数加一。时间 O(n)，空间 O(1)。

**K 次取反**：优先翻转绝对值最大的负数；剩余次数为奇数时翻转绝对值最小项。时间 O(n log n)，扫描辅助空间 O(1)，排序另计。

```
// 伪代码示意
sort array by absolute value descending
for each num in array (from largest abs to smallest):
    if num < 0 and K > 0:
        num = -num
        K -= 1
if K is odd:
    find element with smallest absolute value, negate it once
return sum(array)
```
