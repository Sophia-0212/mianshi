# 968. 监控二叉树

**题目描述**

给定一个二叉树，我们需要在树的节点上安装摄像头。节点上的每个摄像头都可以监视其父对象、自身及其直接子对象。计算监控树的所有节点所需的最少摄像头数量。

```
示例：
输入: root = [0,0,null,0,0]
      对应二叉树：
              0
             /
            0
           / \
          0   0
输出: 1
解释: 如图所示，一台摄像头足以监控所有节点（安装在第二层的节点上）。
```

要求：树节点值均为 0（题目本身值无实际意义，只关心结构），返回最少摄像头数。

## 思路

后序贪心，状态为“未覆盖／有摄像头／已覆盖”，空节点视为已覆盖：

- 孩子有未覆盖：当前装摄像头。
- 否则孩子有摄像头：当前已覆盖。
- 否则当前未覆盖，交给父节点处理。

根若仍未覆盖，补一个摄像头。优先在未覆盖孩子的父节点安装，扩大覆盖范围。

时间 O(n)，空间 O(h)，h 为树高。

    # 方法：minCameraCover；按题目要求处理输入并返回结果，核心算法见方法体。
    def minCameraCover(self, root: "TreeNode") -> int:
        # 用长度为 1 的列表模拟"引用传递"的计数器，
        # 因为 Python 中整数是不可变对象，闭包内直接赋值不会影响外层变量
        result = [0]

        # 方法：traverse；按题目要求处理输入并返回结果，核心算法见方法体。

            # 三种状态：0 = 无覆盖，1 = 有摄像头，2 = 有覆盖无摄像头
            if node is None:
                return 2  # 空节点定义为"有覆盖"，保证叶子节点的判断逻辑正确

            left = traverse(node.left)    # 后序遍历：先处理左子树
            right = traverse(node.right)  # 再处理右子树

            if left == 0 or right == 0:
                # 有孩子无覆盖，当前节点必须装摄像头
                result[0] += 1
                return 1

            if left == 1 or right == 1:
                # 有孩子已装摄像头，当前节点被覆盖
                return 2

            # 两个孩子都无摄像头但都有覆盖，当前节点无覆盖，交给父节点
            return 0

        if traverse(root) == 0:
            # 根节点没有父节点兜底，需要额外装一台
            result[0] += 1

        return result[0]

class Solution {
public:
    int result = 0; // 摄像头计数器

    // 三种状态：0 = 无覆盖，1 = 有摄像头，2 = 有覆盖无摄像头
    // 方法：traverse；按题目要求处理输入并返回结果，核心算法见方法体。
    int traverse(TreeNode* node) {
        if (node == nullptr) {
            return 2; // 空节点定义为"有覆盖"，避免叶子节点被误判为需要装摄像头
        }

        int left = traverse(node->left);   // 后序遍历：先处理左子树
        int right = traverse(node->right); // 再处理右子树

        if (left == 0 || right == 0) {
            // 只要有一个孩子无覆盖，当前节点必须装摄像头兜底
            result++;
            return 1;
        }

        if (left == 1 || right == 1) {
            // 有孩子已经装了摄像头，当前节点被覆盖到
            return 2;
        }

        // 两个孩子都是"有覆盖无摄像头"，当前节点得不到覆盖，交给父节点处理
        return 0;
    }

    // 方法：minCameraCover；按题目要求处理输入并返回结果，核心算法见方法体。
    int minCameraCover(TreeNode* root) {
        if (traverse(root) == 0) {
            // 根节点没有父节点兜底，若根节点仍无覆盖，必须单独装一台
            result++;
        }
        return result;
    }
};

        return 0;

            result++;

## 总结

- 本题必须自底向上（后序遍历）处理，因为判断当前节点是否需要装摄像头依赖于孩子节点的覆盖状态，而这个状态只有在孩子及其子树递归完成后才能确定。
- 三种状态（无覆盖 / 有摄像头 / 有覆盖无摄像头）是解题的核心设计，其中空节点被定义为"有覆盖"是让叶子节点逻辑自动正确工作的关键技巧，不需要为叶子写特殊分支。
- 贪心的本质是让摄像头尽量装在叶子节点的父节点而不是叶子节点本身，因为这样能同时利用摄像头"向上覆盖父节点、向下覆盖孩子"的两格监控能力，覆盖范围更大，摄像头利用率最高。
- 状态转移要按"存在无覆盖孩子 → 存在有摄像头孩子 → 否则无覆盖"的优先级顺序判断，遍历结束后还需单独检查根节点是否为无覆盖状态并补装一台摄像头。
