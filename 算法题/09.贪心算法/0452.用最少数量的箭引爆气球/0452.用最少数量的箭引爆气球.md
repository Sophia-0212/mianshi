# 0452. 用最少数量的箭引爆气球

**题目描述**

给定一个二维数组 `points`，其中 `points[i] = [xstart, xend]` 表示第 i 个气球在 x 轴上的直径区间。气球被完全填充在 x 轴上方，一支箭可以从 x 轴上任意一点垂直射出，如果一支箭的射出点在气球的直径区间内（包括边界），那么该气球会被引爆。求引爆所有气球所需的最少弓箭数。

```
示例：
输入: points = [[10,16],[2,8],[1,6],[7,12]]
输出: 2
解释: 在 x=6 处射出一支箭，可以射爆气球 [2,8] 和 [1,6]；
在 x=11 处射出一支箭，射爆气球 [10,16] 和 [7,12]。
```

## 思路

- 按左端点排序：维护当前组公共交集的右端点，重叠时取较小右端点；下一左端点超过它时新增一箭。
- 按右端点排序：箭射最早结束处，跳过已覆盖气球，遇到未覆盖者再射。

端点相等可共用一箭。时间 O(n log n)，扫描辅助空间 O(1)；计入排序时 C++ 常见 O(log n)、Python O(n)。

# 依赖说明：len：Python 内置函数：返回容器中元素的数量。；range：Python 内置函数：生成按步长遍历的整数序列。；min：Python 内置函数：返回最小值。

class Solution:
    # 方法：findMinArrowShots；按题目要求处理输入并返回结果，核心算法见方法体。
    def findMinArrowShots(self, points: list[list[int]]) -> int:
        if not points:
            return 0
        points.sort(key=lambda p: p[0])  # 按左边界从小到大排序
        count = 1                          # 至少需要一支箭
        arrow_pos = points[0][1]           # 第一支箭覆盖到第一个气球的右边界

                # 左边界超出覆盖范围，没有重叠，新增一支箭
                count += 1
                arrow_pos = points[i][1]
            else:
                # 有重叠，收缩覆盖范围为交集右边界（取较小值）
                arrow_pos = min(arrow_pos, points[i][1])
        return count

            }
        }
    }

## C++

### LeetCode 写法与原有示例

```cpp
// 依赖说明：vector：C++ STL 动态数组。；sort：C++ STL algorithm 提供的排序函数。

class Solution {
public:
    static bool cmp(const vector<int>& a, const vector<int>& b) {
        return a[0] < b[0];  // 按左边界从小到大排序
    }

    // 方法：findMinArrowShots；按题目要求处理输入并返回结果，核心算法见方法体。
    int findMinArrowShots(vector<vector<int>>& points) {
        if (points.empty()) return 0;
        sort(points.begin(), points.end(), cmp);  // 按左边界排序
        int count = 1;                             // 至少需要一支箭
        int arrowPos = points[0][1];                // 第一支箭初始覆盖到第一个气球的右边界
        for (int i = 1; i < points.size(); i++) {
            if (points[i][0] > arrowPos) {
                // 左边界超出当前箭覆盖范围，说明没有重叠，必须新增一支箭
                count++;
                arrowPos = points[i][1];  // 新箭的覆盖右边界初始化为当前气球右边界
            } else {
                // 左边界在覆盖范围内，可以用同一支箭，收缩覆盖范围为交集右边界（取较小值）
                arrowPos = min(arrowPos, points[i][1]);
            }
        }
        return count;
    }
};```

## 总结

- 按左边界排序是为了让遍历过程单调有序，这样只需要维护一个"当前箭覆盖范围"变量就能正确判断重叠关系，不用去处理乱序区间的复杂关系。
- 重叠的时候更新覆盖范围为两者右边界的较小值，说白了本质上就是维护"覆盖范围=已合并气球的真实交集"这一不变量，取较大值或者不更新都会导致后面判断出现误判。
- 边界重合（左边界恰好等于arrowPos）算作可以引爆，因为箭可以射在边界点上，所以判断条件用的是"严格大于才新增箭"，等号情况归入可合并这一类。
- 这题跟435（无重叠区间）思路高度相似，都是"排序+维护右边界"的区间处理范式，区别就在于边界重合的语义和最终统计目标不一样。
