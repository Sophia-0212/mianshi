# 0763. 划分字母区间

**题目描述**

给定一个字符串 `s`，需要把这个字符串划分为尽可能多的片段，同一字母最多出现在一个片段中，返回一个表示每个字符串片段长度的列表。

```
示例：
输入: s = "ababcbacadefegdehijhklij"
输出: [9,7,8]
解释: 划分结果为 "ababcbaca", "defegde", "hijhklij"，
每个片段中的字母都不会出现在其他片段中。
```

## 思路

**贪心策略是什么**

我先说下大致的两步走法。第一步，先把字符串遍历一遍，记录每个字母最后一次出现的下标，用一个大小为 26 的数组 `lastIndex` 存下来（`lastIndex[字符 - 'a'] = 该字符最后出现的下标`）。这一步没什么好说的，就是个预处理。

第二步是核心，再遍历一次字符串，维护一个变量 `right`，表示"当前这个片段的右边界能撑到哪儿"，初始是 0。每碰到一个字符 `s[i]`，我就拿这个字符最后出现的位置去更新 `right`，取较大值：`right = max(right, lastIndex[s[i] - 'a'])`。那什么时候能切一刀呢？当遍历下标 `i` 恰好追上 `right` 的时候。这说明什么呢？说明从当前片段起点到 `i` 这一段里，所有出现过的字母，它们最后一次出现的位置都没有超过 `i`——换句话说这个片段"消化"完了，可以在这里切。这时候就记录片段长度（`i - start + 1`），再把下一个片段的起点 `start` 设成 `i + 1`，继续往后走。

**为什么"遍历到 right 位置时切分"是正确的贪心策略**

这题说白了就是"区间合并"思想搬到了字符串上。你可以这么想：每个字母从"第一次出现"到"最后一次出现"，其实就圈出了一个区间（比如字母 `a` 第一次在下标 0 出现，最后一次在下标 8，那它对应的区间就是 `[0, 8]`）。题目要求"同一字母只能出现在一个片段里"，这其实就等价于说：任何一个字母的区间，必须完整地待在某一个片段内部，不能一半在这个片段、一半跑到下一个片段去。这么一转化，问题就变成了：把这些字母区间合并成尽可能多的、互不重叠的连续区间组，看最多能分出多少组。

那维护 `right` 这个变量在做什么呢？它其实就是在实时合并当前片段里已经出现过的所有字母对应的区间。你想啊，只要当前片段里还有某个字母，它的最后出现位置比 `right` 更靠后，就说明这个片段还没把这个字母的区间完整装进来——这时候如果贸然切一刀，这个字母就会被切到下一个片段去，直接破坏了"同一字母只能待一个片段"的要求。所以必须继续把 `right` 往后推，一直推到 `right` 不再增长、并且遍历下标 `i` 正好追上了它，这时候才能确认：这个片段里出现过的所有字母，它们的区间都已经完整地被 `[start, right]` 这个范围罩住了，不会再有哪个字母的后续出现溜到下一个片段里。这一刻切下去是安全的，不会被任何字母的区间"跨栏"。

那为什么这样切出来的片段数一定是最多的呢？关键是 `right` 在任意时刻代表的都是"当前所有已知字母区间能撑到的最远边界"，这个边界是数据本身决定的，不是我随便挑的。你想，如果在追上 `right` 之前就提前切了，肯定会把某个字母的区间切断（因为它最后出现的位置还没到），这就是非法划分了；反过来，如果追上 `right` 了却不切，继续往后走，那就是把本来可以独立成一段的内容硬生生跟后面的合并在一起，片段数只会变少不会变多。所以说白了，"下标追上 right 就立刻切"既是能合法切分的最早时机，也是能拿到最多片段数的时机，不可能有更优的切法。

**复杂度分析**

两次遍历字符串，时间复杂度 O(n)（n 是字符串长度，字符集大小是常数 26，可以忽略不看），空间复杂度 O(1)（辅助数组大小固定是 26，不会随输入规模变大）。

## 代码

### C++

```cpp
class Solution {
public:
    vector<int> partitionLabels(string s) {
        int lastIndex[26] = {0};  // 记录每个字母最后一次出现的下标
        for (int i = 0; i < s.size(); i++) {
            lastIndex[s[i] - 'a'] = i;  // 不断更新，最终保留最后一次出现的位置
        }
        vector<int> result;
        int start = 0, right = 0;  // start:当前片段起点，right:当前片段右边界
        for (int i = 0; i < s.size(); i++) {
            right = max(right, lastIndex[s[i] - 'a']);  // 扩展右边界，纳入当前字符的完整区间
            if (i == right) {
                // 遍历下标追上右边界，说明当前片段内所有字母的区间都已完整纳入，可以切分
                result.push_back(right - start + 1);
                start = i + 1;  // 下一个片段起点
            }
        }
        return result;
    }
};
```

## 总结

- 这题的核心思路，说白了就是把"字母不能跨片段出现"这个要求，转化成了"字母对应的区间不能跨片段"，然后用区间合并的思路一次遍历搞定划分，本质上是区间合并思想在字符串上的一个变体。
- `right` 变量代表的是"当前片段已经合并的所有字母区间能撑到的最远边界"，只有遍历下标追上了 `right`，才能保证这个片段里的所有字母都不会跑到外面去。
- 这个贪心策略切出来的，既是能合法切分的最早时机，也是数量最多的划分方式——提前切会把字母区间切断变成非法划分，拖后切又会白白减少片段数量。
- 用一个长度为 26 的数组代替哈希表来记录最后出现位置，这是字符集有限场景下很常见的优化技巧，能省掉哈希表那部分额外开销。
