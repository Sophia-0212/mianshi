# 0763. 划分字母区间

**题目描述**

给定一个字符串 `s`，需要把这个字符串划分为尽可能多的片段，同一字母最多出现在一个片段中，返回一个表示每个字符串片段长度的列表。

```
示例：
输入: s = "ababcbacadefegdehijhklij"
输出: [9,7,8]
解释: 划分结果为 "ababcbaca", "defegde", "hijhklij"，
每个片段中的字母都不会出现在其他片段中。
```

## 思路

记录每个字符最后出现的位置。扫描时更新本段最远终点 `end=max(end,last[s[i]])`；到达 `end` 即切分，此时段内字符都不会出现在后面。

时间 O(n)，辅助空间 O(1)（26 个字母），结果最多 26 段。

### LeetCode 写法与原有示例

# 依赖说明：enumerate：Python 内置函数：遍历序列时同时得到下标和值。；max：Python 内置函数：返回最大值。

# 依赖说明：enumerate：Python 内置函数：遍历序列时同时得到下标和值。

class Solution:
    # 方法：partitionLabels；按题目要求处理输入并返回结果，核心算法见方法体。
    def partitionLabels(self, s: str) -> list[int]:
        last_index = {}  # 记录每个字母最后一次出现的下标
        for i, ch in enumerate(s):
            last_index[ch] = i  # 不断覆盖，最终保留最后一次出现的位置

        result = []
        start, right = 0, 0  # start:片段起点，right:片段右边界
        for i, ch in enumerate(s):
            right = max(right, last_index[ch])  # 扩展右边界，纳入当前字符完整区间
            if i == right:
                # 下标追上右边界，当前片段可以安全切分
                result.append(right - start + 1)
                start = i + 1
        return result```

### LeetCode 写法与原有示例

```go
// 方法：partitionLabels；按题目要求处理输入并返回结果，核心算法见方法体。
func partitionLabels(s string) []int {
    var lastIndex [26]int // 记录每个字母最后一次出现的下标
    for i := 0; i < len(s); i++ {
        lastIndex[s[i]-'a'] = i // 更新为最后一次出现的位置
    }

    var result []int
    start, right := 0, 0 // start:片段起点，right:片段右边界
    for i := 0; i < len(s); i++ {
        if lastIndex[s[i]-'a'] > right {
            right = lastIndex[s[i]-'a'] // 扩展右边界，纳入当前字符完整区间
        }
        if i == right {
            // 下标追上右边界，当前片段可以安全切分
            result = append(result, right-start+1)
            start = i + 1
        }
    }
    return result
}
```

## C++

### LeetCode 写法与原有示例

```cpp
class Solution {
public:
    // 方法：partitionLabels；按题目要求处理输入并返回结果，核心算法见方法体。
    vector<int> partitionLabels(string s) {
        int lastIndex[26] = {0};  // 记录每个字母最后一次出现的下标
        for (int i = 0; i < s.size(); i++) {
            lastIndex[s[i] - 'a'] = i;  // 不断更新，最终保留最后一次出现的位置
        }
        vector<int> result;
        int start = 0, right = 0;  // start:当前片段起点，right:当前片段右边界
        for (int i = 0; i < s.size(); i++) {
            right = max(right, lastIndex[s[i] - 'a']);  // 扩展右边界，纳入当前字符的完整区间
            if (i == right) {
                // 遍历下标追上右边界，说明当前片段内所有字母的区间都已完整纳入，可以切分
                result.push_back(right - start + 1);
                start = i + 1;  // 下一个片段起点
            }
        }
        return result;
    }
};
```

## 总结

- 这题的核心思路，说白了就是把"字母不能跨片段出现"这个要求，转化成了"字母对应的区间不能跨片段"，然后用区间合并的思路一次遍历搞定划分，本质上是区间合并思想在字符串上的一个变体。
- `right` 变量代表的是"当前片段已经合并的所有字母区间能撑到的最远边界"，只有遍历下标追上了 `right`，才能保证这个片段里的所有字母都不会跑到外面去。
- 这个贪心策略切出来的，既是能合法切分的最早时机，也是数量最多的划分方式——提前切会把字母区间切断变成非法划分，拖后切又会白白减少片段数量。
- 用一个长度为 26 的数组代替哈希表来记录最后出现位置，这是字符集有限场景下很常见的优化技巧，能省掉哈希表那部分额外开销。
