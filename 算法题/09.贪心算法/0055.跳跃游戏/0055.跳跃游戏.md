# 0055. 跳跃游戏

**题目描述**

给定一个非负整数数组 `nums`，你最初位于数组的第一个下标。数组中的每个元素代表你在该位置可以跳跃的最大长度。判断你是否能够到达最后一个下标。

```
示例：
输入: nums = [2,3,1,1,4]
输出: true
解释: 可以先跳1步，从下标0到达下标1，然后再从下标1跳3步到达最后一个下标。

输入: nums = [3,2,1,0,4]
输出: false
解释: 无论怎样，总会到达下标3。但该下标的最大跳跃长度是0，
      所以永远不可能到达最后一个下标。
```

## 思路

贪心维护最远可达下标 `cover=0`。若 `i>cover` 则不可达，否则更新 `cover=max(cover,i+nums[i])`；覆盖末尾即成功。

时间 O(n)，空间 O(1)。

class Solution:
    # 方法：canJump；按题目要求处理输入并返回结果，核心算法见方法体。
    def canJump(self, nums: list[int]) -> bool:
        cover = 0  # 当前能到达的最远下标
        for i in range(len(nums)):
            if i > cover:
                return False  # 当前下标不可达，起跳点本身够不到
            cover = max(cover, i + nums[i])  # 更新最远覆盖范围
        return True```

```go
// 方法：canJump；按题目要求处理输入并返回结果，核心算法见方法体。
func canJump(nums []int) bool {
    cover := 0 // 当前能到达的最远下标
    for i := 0; i < len(nums); i++ {
        if i > cover {
            return false // 当前下标不可达，直接判定失败
        }
        if i+nums[i] > cover {
            cover = i + nums[i] // 用当前可达位置更新最远覆盖范围
        }
    }
    return true
}
```

    }

## 总结

- 贪心策略就是维护一个"最远可达覆盖范围" `cover`，遍历过程中不断用每个可达位置能提供的跳跃范围去更新它，根本不需要模拟具体的跳跃路径。
- 正确性的关键在于：一个位置能跳多远，是它自带的属性（由 `nums[i]` 决定），跟到达它的路径没关系，所以把所有可达位置的覆盖范围合并起来，就等价于穷举了所有路径组合的能力上限。
- 一旦发现某个下标超过了当前覆盖范围，说明这个位置本身就到不了，可以直接判定失败并提前返回，不用继续遍历。
- 这道题只关心"能不能到达"，跟45题"最少跳跃次数"是相关但不同的问题，本题的 `cover` 只需要合并更新，不用额外统计跳跃次数。
