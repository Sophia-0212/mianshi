# 面试题 02.07. 链表相交

**题目描述**

给定两个单链表的头节点 `headA` 和 `headB`，判断两个链表是否相交，如果相交，返回相交的起始节点；如果不相交，返回 `null`。

需要注意：这里的"相交"指的是两个链表从某个节点开始，后续所有节点（包括该节点本身）在内存中是完全同一批节点，即节点的引用/地址相同，而不是节点的值恰好相等。

```
示例：
链表 A: 4 -> 1 -> 8 -> 4 -> 5
链表 B:      5 -> 6 -> 1 -> 8 -> 4 -> 5
（A 和 B 从值为 8 的节点开始是同一批节点，即地址相同）
输出: 相交起始节点，值为 8
解释: 从这个节点开始，A 和 B 之后的部分完全共享（同一段内存）
```

## 思路

先求两链表长度，让较长链表先走长度差，再同步前进。首次指向同一节点即相交点；同时到空则不相交。比较节点身份，不能只比较值。

时间 O(m+n)，空间 O(1)。

# 依赖说明：range：Python 内置函数：生成按步长遍历的整数序列。

class ListNode:
    # 方法：__init__；按题目要求处理输入并返回结果，核心算法见方法体。
    def __init__(self, val=0, next=None):
        self.val = val
        self.next = next


class Solution:
    # 方法：getIntersectionNode；按题目要求处理输入并返回结果，核心算法见方法体。
    def getIntersectionNode(self, headA: ListNode, headB: ListNode) -> ListNode:
        # 方法：get_length；按题目要求处理输入并返回结果，核心算法见方法体。
        def get_length(head):
            length = 0
            while head is not None:
                length += 1
                head = head.next
            return length

        len_a, len_b = get_length(headA), get_length(headB)
        cur_a, cur_b = headA, headB

        # 让较长链表先走长度差步，对齐剩余距离
        if len_a > len_b:
            for _ in range(len_a - len_b):
                cur_a = cur_a.next
        else:
            for _ in range(len_b - len_a):
                cur_b = cur_b.next

        # 同步前进，用 is 比较节点身份（地址），不是值相等
        while cur_a is not cur_b:
            cur_a = cur_a.next
            cur_b = cur_b.next
        return cur_a  # 相交返回交点；不相交时两者同时变为 None```

class Solution {
public:
    ListNode* getIntersectionNode(ListNode* headA, ListNode* headB) {
        int lenA = getLength(headA);
        int lenB = getLength(headB);
        ListNode* curA = headA;
        ListNode* curB = headB;

        // 让较长的链表先走长度差步，对齐两指针到终点的剩余距离
        if (lenA > lenB) {
            for (int i = 0; i < lenA - lenB; i++) curA = curA->next;
        } else {
            for (int i = 0; i < lenB - lenA; i++) curB = curB->next;
        }

        // 同步前进，比较的是节点地址（指针本身）是否相同，不是值
        while (curA != curB) {
            curA = curA->next;
            curB = curB->next;
        }
        return curA;  // 相交则返回交点；不相交时 curA、curB 都会同时变为 nullptr
    }

private:
    // 方法：getLength；按题目要求处理输入并返回结果，核心算法见方法体。
    int getLength(ListNode* head) {
        int len = 0;
        while (head != nullptr) {
            len++;
            head = head->next;
        }
        return len;
    }
};

## 总结

- 这道题最容易犯的错误就是用节点的**值**来判断是否相交，正确做法应该是比较节点的**引用/地址**，因为不同链表完全可以有值相同但是不同对象的节点，这一点一定要说清楚。
- 核心技巧就是"先消化长度差，再同步遍历"：让较长链表先走 `|lenA - lenB|` 步，之后两指针每一步都保持"到链表末尾距离相等"，如果存在交点，就必然会同步到达。
- 不相交其实是这个算法的自然退化情况：两指针会同步走到各自链表末尾（都变成 `null`/`None`/`nil`），这时候它们是相等的，直接拿这个当统一的返回值就行，不需要单独判断"不相交"这个分支。
- 跟"环形链表判环"里的快慢指针不一样，这道题的两个指针速度始终是一样的（都是一步一步走），差异只体现在起跑时间上（通过提前走长度差步来实现），这是双指针技巧里"对齐后同步"这个子模式的典型代表。
