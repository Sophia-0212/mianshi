# 0203. 移除链表元素

**题目描述**

给定一个链表的头节点 `head` 和一个整数 `val`，删除链表中所有满足 `Node.val == val` 的节点，返回新的头节点。

```
示例：
输入: head = [1,2,6,3,4,5,6], val = 6
输出: [1,2,3,4,5]
解释: 链表中值为 6 的节点（第 3 个和最后一个）被删除，其余节点保持原有相对顺序
```

## 思路

虚拟头节点统一删除逻辑。检查 `cur.next`：值等于 `val` 就跳过该节点，否则 `cur` 前进。删除后不前进，避免漏掉连续目标值。

时间 O(n)，空间 O(1)。

```python
class ListNode:
    # 方法：__init__；按题目要求处理输入并返回结果，核心算法见方法体。
    def __init__(self, val=0, next=None):
        self.val = val
        self.next = next


class Solution:
    # 方法：removeElements；按题目要求处理输入并返回结果，核心算法见方法体。
    def removeElements(self, head: ListNode, val: int) -> ListNode:
        dummy = ListNode(0)      # 虚拟头节点
        dummy.next = head
        cur = dummy              # cur 指向已确认保留的最后一个节点
        while cur.next is not None:
            if cur.next.val == val:
                cur.next = cur.next.next  # 跳过待删除节点
            else:
                cur = cur.next             # 保留当前节点，指针后移
        return dummy.next
```

## C++

### LeetCode 写法与原有示例

```cpp
struct ListNode {
    int val;
    ListNode *next;
    ListNode(int x) : val(x), next(NULL) {}
};
```

```cpp
class Solution {
public:
    ListNode* removeElements(ListNode* head, int val) {
        ListNode* dummy = new ListNode(0);  // 虚拟头节点，统一头部与中间节点的删除逻辑
        dummy->next = head;
        ListNode* cur = dummy;  // cur 始终指向"已确认保留"的最后一个节点
        while (cur->next != nullptr) {
            if (cur->next->val == val) {
                ListNode* toDelete = cur->next;
                cur->next = cur->next->next;  // 跳过待删除节点，重新连接
                delete toDelete;               // 释放内存，避免泄漏
            } else {
                cur = cur->next;  // 当前节点保留，指针后移
            }
        }
        ListNode* newHead = dummy->next;  // 真正的新头节点
        delete dummy;
        return newHead;
    }
};
```

## 总结

- 这题其实是虚拟头节点技巧最经典的入门场景。核心就是头节点也可能被删掉，导致你不能直接用原来的 `head` 变量去返回，所以必须引入一个 `dummy` 节点来统一处理。
- 最容易犯错的地方是判断条件写在 `cur` 还是 `cur->next` 上。一定要记住，检查和删除的对象是 `cur->next`，`cur` 本身永远是已经确认保留、安全的节点，因为删除操作得靠前驱指针才能完成"跳过"这个动作。
- 循环条件那里也要注意，是 `cur->next != nullptr`，不是 `cur != nullptr`。因为每一步我们看的都是"下一个节点"要不要删，如果 `cur->next` 为空了，说明已经走到链表末尾了。
- 这道题算是个基础题，后面像"两两交换节点""删除倒数第N个节点"这些题，用的都是虚拟头节点加前驱指针操作这个套路，把这题吃透了，后面套路都差不多。
