# 0707. 设计链表

**题目描述**

设计实现一个链表，支持以下操作：

- `get(index)`：获取链表中第 `index` 个节点的值（从 0 开始），若 `index` 无效返回 -1
- `addAtHead(val)`：在链表头部插入一个值为 `val` 的节点
- `addAtTail(val)`：在链表尾部插入一个值为 `val` 的节点
- `addAtIndex(index, val)`：在第 `index` 个节点之前插入值为 `val` 的节点。若 `index` 等于链表长度，则插入到末尾；若 `index` 大于链表长度，则不插入；若 `index` 小于 0，视为在头部插入
- `deleteAtIndex(index)`：删除第 `index` 个节点，若 `index` 无效则不操作

```
示例：
MyLinkedList list = new MyLinkedList();
list.addAtHead(1);        // 链表: 1
list.addAtTail(3);        // 链表: 1 -> 3
list.addAtIndex(1, 2);    // 链表: 1 -> 2 -> 3
list.get(1);               // 返回 2
list.deleteAtIndex(1);     // 链表: 1 -> 3
list.get(1);               // 返回 3
```

## 思路

这道题其实没什么算法技巧，核心考察的是**链表基本操作的完整、严谨实现**，尤其是边界条件处理得干不干净。实现方式我还是用带虚拟头节点这个套路，理由跟前面讲过的一样：省得对"操作头节点"单独写一套特殊判断逻辑。

那设计上有几个要点，我说一下：

第一个，我会维护一个 `size` 字段，专门记录当前链表长度。为什么要这个呢？因为这样一来，所有涉及 `index` 合法性的判断都能在 O(1) 时间内完成，不用每次操作都额外遍历一遍链表去统计长度。

第二个，我统一用"找到第 `index` 个节点的前驱"这个思路去实现插入和删除。具体说：`get(index)` 就是从 `dummy->next` 开始走 `index` 步，也就等价于从 dummy 走 `index + 1` 步；`addAtIndex(index, val)` 呢，先把边界修正一下（`index` 小于 0 就当成 0，`index` 大于 size 就直接不插入），然后找到第 `index` 个节点的前驱 `prev`（从 dummy 走 `index` 步），插入新节点的逻辑就是 `newNode->next = prev->next; prev->next = newNode;`；`deleteAtIndex(index)` 也一样，找到前驱 `prev`，让 `prev->next = prev->next->next` 就完事了。你会发现 `addAtHead` 和 `addAtTail` 其实可以直接复用 `addAtIndex(0, val)` 和 `addAtIndex(size, val)`，这样能省不少重复代码。

第三个，也是这题最大的坑：边界条件。`index` 越界的时候（负数、超出范围、大于等于或大于 size），这几个方法的行为是不一样的，得严格按题意来区分——`get`/`deleteAtIndex` 要求的是 `0 <= index < size`，但 `addAtIndex` 是允许 `index == size` 的，意思就是插到尾部去。另外空链表的情况也得考虑到，`get`、`deleteAtIndex` 碰到空链表都得能安全返回，不能崩掉。

复杂度这块，`get`、`addAtIndex`、`deleteAtIndex` 都是 O(index)，最坏情况就是 O(n)；`addAtHead` 是 O(1)；`addAtTail` 是 O(n)，因为得一直走到链表末尾——如果你额外维护一个尾指针的话，是能优化到 O(1) 的，但这里为了实现简洁，我就没做这个优化。空间复杂度是 O(n)，因为要存 n 个节点。

## 代码

链表节点定义：

```cpp
struct ListNode {
    int val;
    ListNode *next;
    ListNode(int x) : val(x), next(NULL) {}
};
```

### C++

```cpp
class MyLinkedList {
private:
    ListNode* dummy;  // 虚拟头节点，dummy->next 才是真正的第 0 个节点
    int size;          // 维护链表长度，O(1) 判断边界

public:
    MyLinkedList() {
        dummy = new ListNode(0);
        size = 0;
    }

    int get(int index) {
        if (index < 0 || index >= size) return -1;  // 越界直接返回 -1
        ListNode* cur = dummy->next;
        while (index--) cur = cur->next;  // 走 index 步到达目标节点
        return cur->val;
    }

    void addAtHead(int val) {
        addAtIndex(0, val);  // 复用统一插入逻辑
    }

    void addAtTail(int val) {
        addAtIndex(size, val);  // index == size 表示插入到末尾
    }

    void addAtIndex(int index, int val) {
        if (index > size) return;      // 超出长度，不插入
        if (index < 0) index = 0;      // 负数视为插入头部
        ListNode* prev = dummy;
        while (index--) prev = prev->next;  // 找到插入位置的前驱节点
        ListNode* newNode = new ListNode(val);
        newNode->next = prev->next;  // 新节点指向原本的后继
        prev->next = newNode;         // 前驱指向新节点，完成插入
        size++;
    }

    void deleteAtIndex(int index) {
        if (index < 0 || index >= size) return;  // 越界不操作
        ListNode* prev = dummy;
        while (index--) prev = prev->next;  // 找到待删除节点的前驱
        ListNode* toDelete = prev->next;
        prev->next = toDelete->next;          // 跳过待删除节点
        delete toDelete;
        size--;
    }
};
```

### Python

这道题是链表结构本身的实现题，Python 没有内置链表类型，标准库也没有对应的一行解，只能手写实现：

```python
class ListNode:
    def __init__(self, val=0, next=None):
        self.val = val
        self.next = next


class MyLinkedList:
    def __init__(self):
        self.dummy = ListNode(0)  # 虚拟头节点
        self.size = 0               # 链表长度

    def get(self, index: int) -> int:
        if index < 0 or index >= self.size:  # 越界返回 -1
            return -1
        cur = self.dummy.next
        for _ in range(index):  # 走 index 步到达目标节点
            cur = cur.next
        return cur.val

    def addAtHead(self, val: int) -> None:
        self.addAtIndex(0, val)

    def addAtTail(self, val: int) -> None:
        self.addAtIndex(self.size, val)

    def addAtIndex(self, index: int, val: int) -> None:
        if index > self.size:  # 超出长度不插入
            return
        if index < 0:           # 负数视为头部插入
            index = 0
        prev = self.dummy
        for _ in range(index):  # 找到插入位置的前驱
            prev = prev.next
        new_node = ListNode(val)
        new_node.next = prev.next  # 新节点指向原后继
        prev.next = new_node        # 前驱指向新节点
        self.size += 1

    def deleteAtIndex(self, index: int) -> None:
        if index < 0 or index >= self.size:  # 越界不操作
            return
        prev = self.dummy
        for _ in range(index):  # 找到待删除节点的前驱
            prev = prev.next
        prev.next = prev.next.next  # 跳过待删除节点
        self.size -= 1
```

### Go

```go
type ListNode struct {
    Val  int
    Next *ListNode
}

type MyLinkedList struct {
    dummy *ListNode // 虚拟头节点
    size  int        // 链表长度
}

func Constructor() MyLinkedList {
    return MyLinkedList{dummy: &ListNode{}, size: 0}
}

func (l *MyLinkedList) Get(index int) int {
    if index < 0 || index >= l.size { // 越界返回 -1
        return -1
    }
    cur := l.dummy.Next
    for i := 0; i < index; i++ { // 走到目标节点
        cur = cur.Next
    }
    return cur.Val
}

func (l *MyLinkedList) AddAtHead(val int) {
    l.AddAtIndex(0, val)
}

func (l *MyLinkedList) AddAtTail(val int) {
    l.AddAtIndex(l.size, val)
}

func (l *MyLinkedList) AddAtIndex(index int, val int) {
    if index > l.size { // 超出长度不插入
        return
    }
    if index < 0 { // 负数视为头部插入
        index = 0
    }
    prev := l.dummy
    for i := 0; i < index; i++ { // 找到插入位置前驱
        prev = prev.Next
    }
    newNode := &ListNode{Val: val, Next: prev.Next} // 新节点接上原后继
    prev.Next = newNode                               // 前驱接上新节点
    l.size++
}

func (l *MyLinkedList) DeleteAtIndex(index int) {
    if index < 0 || index >= l.size { // 越界不操作
        return
    }
    prev := l.dummy
    for i := 0; i < index; i++ { // 找到待删除节点前驱
        prev = prev.Next
    }
    prev.Next = prev.Next.Next // 跳过待删除节点
    l.size--
}
```

## 总结

- 这道题考的不是算法思维，而是工程实现够不够严谨。核心就是所有操作前都得先想清楚 `index` 的合法范围在哪，`get`/`deleteAtIndex` 要求 `0 <= index < size`，`addAtIndex` 却允许 `index == size`（也就是插到尾部）。
- 维护一个 `size` 字段去记长度，这样就不用每次操作都遍历一遍链表去判断边界，这其实是个很常见的工程优化思路，面试的时候可以主动提一下。
- 用虚拟头节点加上"统一定位到前驱节点"这个套路去实现插入删除，好处是能把 `addAtHead`/`addAtTail` 都归约成 `addAtIndex` 的特殊情况，代码量能省不少。
- 这道题跟前面"移除链表元素"其实是一脉相承的，本质上链表的插入删除操作说白了都是"找到前驱节点，改它的 `next` 指针"，虚拟头节点就是让这个操作在头部和中间节点上保持一致，不用写两套逻辑。
