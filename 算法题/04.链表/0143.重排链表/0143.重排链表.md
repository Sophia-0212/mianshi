# 0143. 重排链表

**题目描述**

给定一个单链表 `L` 的头节点 `head`，链表的节点顺序为 `L0 → L1 → … → Ln-1 → Ln`，要求将其重新排列为：

```
L0 → Ln → L1 → Ln-1 → L2 → Ln-2 → …
```

不能修改节点内部的值，只能通过改变节点之间的连接关系来重排。

```
示例：
输入: head = [1,2,3,4]
输出: [1,4,2,3]

输入: head = [1,2,3,4,5]
输出: [1,5,2,4,3]
```

## 思路

咱们先分析一下重排后有什么规律：新链表其实就是"头一个、尾一个、头二个、尾二个……"这样交替排下去的。你想啊，如果把原链表从中点断开，分成前半部分 `L0…Lk` 和后半部分 `Lk+1…Ln`，会发现后半部分得先**反转**一下，才能和前半部分按"一个前、一个后"的顺序交替连起来——反转半部分正好把 `Ln` 变成新后半段的头，`Lk+1` 变成新后半段的尾，这样两条链表从头开始交替合并，就恰好拼出 `L0, Ln, L1, Ln-1, …` 这个顺序了。

这么一分析，就能把整道题拆成三个咱们都很熟悉的子问题：

**第一步，用快慢指针找到链表中点，把链表切成两半。** 这一步和"回文链表""环形链表"用的是同一套快慢指针模板：快指针一次走两步，慢指针一次走一步，快指针到达末尾的时候，慢指针刚好停在中点。这里要注意，找到中点之后一定要显式地把前半部分的 `next` 断开（`slow.next = null` 之类的操作），不然前半部分链表会一直连着后半部分，导致后面反转或者合并的时候出现环或者错误连接，这个坑一定要避开。

**第二步，反转后半部分链表。** 就是标准的链表反转：维护一个 `prev` 指针，遍历过程中不停地把当前节点的 `next` 指向 `prev`，一直到把后半部分遍历完。反转完之后，后半部分链表就变成从 `Ln` 到 `Lk+1` 的顺序了，正好就是咱们需要拼接的顺序。

**第三步，交替合并两条链表。** 用两个指针分别指向前半部分链表头 `p1` 和反转后的后半部分链表头 `p2`，每次循环里先记下 `p1` 和 `p2` 各自的下一个节点（为什么呢？因为马上要改写 `next` 指针了，提前保存好才不会把链表丢了），然后让 `p1.next = p2`，`p2.next` 指向原来 `p1` 保存的那个下一个节点，接着 `p1` 和 `p2` 都移动到各自保存的下一个位置，继续循环。循环什么时候停呢？以 `p2` 走到空为终止条件（因为后半部分长度肯定小于等于前半部分长度，`p2` 会先耗尽）。

**边界条件怎么处理：** 当链表长度是奇数的时候，前半部分会比后半部分多一个节点（多出来的正是原链表的中间节点），这个节点在合并的时候会是前半部分最后一个被处理的节点，它的 `next` 会在循环结束后自然指向 `null`（因为后半部分已经耗尽了，不会再有新节点接到它后面），所以不需要额外特殊处理，只要合并循环的终止条件写对（以较短的那条链表耗尽为准），奇偶长度都能正确处理。另外还要注意，当链表节点数小于等于 2 时（0、1、2 个节点），重排后顺序是不变的，可以直接在函数开头判断一下然后提前返回，避免快慢指针在特别短的链表上出现边界错误。

**复杂度分析：** 找中点、反转、合并这三步都只需要遍历链表常数次，所以时间复杂度是 O(n)。整个过程只用了若干个指针变量，没有额外的线性存储（不像用数组或者栈暂存节点值的方法需要 O(n) 空间），所以空间复杂度是 O(1)。

## 代码

### C++

```cpp
/**
 * struct ListNode {
 *     int val;
 *     ListNode *next;
 *     ListNode(int x) : val(x), next(nullptr) {}
 * };
 */
class Solution {
public:
    void reorderList(ListNode* head) {
        if (head == nullptr || head->next == nullptr || head->next->next == nullptr) {
            return; // 0、1、2 个节点时顺序不变，无需重排
        }

        // 第一步：快慢指针找中点，同时断开前半部分
        ListNode *slow = head, *fast = head;
        while (fast->next != nullptr && fast->next->next != nullptr) {
            slow = slow->next;
            fast = fast->next->next;
        }
        ListNode* secondHead = slow->next; // 后半部分头节点
        slow->next = nullptr;              // 断开前半部分，避免和后半部分连在一起

        // 第二步：反转后半部分
        ListNode* prev = nullptr;
        ListNode* cur = secondHead;
        while (cur != nullptr) {
            ListNode* next = cur->next; // 暂存下一节点
            cur->next = prev;           // 反转指向
            prev = cur;
            cur = next;
        }
        secondHead = prev; // 反转后的新头节点

        // 第三步：交替合并前半部分与反转后的后半部分
        ListNode *p1 = head, *p2 = secondHead;
        while (p2 != nullptr) { // 后半部分较短或相等，以它耗尽为终止条件
            ListNode* p1Next = p1->next; // 提前保存，防止改写后丢失
            ListNode* p2Next = p2->next;
            p1->next = p2;                // 前半部分当前节点接到后半部分当前节点
            if (p1Next != nullptr) {
                p2->next = p1Next;        // 后半部分当前节点接回前半部分的下一个节点
            }
            p1 = p1Next;
            p2 = p2Next;
        }
    }
};
```

### Python

标准库思路说明：Python 没有直接实现"链表交替重排"的库函数，因为这是纯链表指针操作，没有通用容器函数能替代它的核心逻辑，所以这道题只给手写实现。

手写实现（这是面试的考察点，快慢指针找中点 + 反转 + 交替合并三步组合）：

```python
class ListNode:
    def __init__(self, val=0, next=None):
        self.val = val
        self.next = next

class Solution:
    def reorderList(self, head: 'Optional[ListNode]') -> None:
        if not head or not head.next or not head.next.next:
            return  # 0、1、2 个节点时顺序不变

        # 第一步：快慢指针找中点，同时断开前半部分
        slow, fast = head, head
        while fast.next and fast.next.next:
            slow = slow.next
            fast = fast.next.next
        second_head = slow.next  # 后半部分头节点
        slow.next = None         # 断开前半部分

        # 第二步：反转后半部分
        prev, cur = None, second_head
        while cur:
            nxt = cur.next   # 暂存下一节点
            cur.next = prev  # 反转指向
            prev = cur
            cur = nxt
        second_head = prev  # 反转后的新头节点

        # 第三步：交替合并前半部分与反转后的后半部分
        p1, p2 = head, second_head
        while p2:  # 以后半部分耗尽为终止条件
            p1_next = p1.next  # 提前保存，防止改写后丢失
            p2_next = p2.next
            p1.next = p2       # 接入后半部分当前节点
            if p1_next:
                p2.next = p1_next  # 接回前半部分下一节点
            p1 = p1_next
            p2 = p2_next
```

## 总结

- 这道题说白了就是"找中点 + 反转链表 + 合并链表"三个基础操作的组合题，拆开来看每一步都是独立的经典考点。遇到复杂链表题的时候，先试着往这些基本操作上拆解，是个很通用的解题思路。
- 交替合并的时候，一定要提前把双方的 `next` 指针存好，再去修改连接关系，不然改了 `p1.next` 之后，原来 `p1` 指向的后续节点就丢了，这是链表题里最常见的出错点。
- 合并循环以后半部分（较短的那条）耗尽为终止条件，这样天然就能处理奇数长度时前半部分多出一个节点的情况，不需要额外写分支判断奇偶。
- 找到中点之后一定要显式断开前半部分的 `next`，不然后面反转或者合并的时候，链表结构会互相干扰，产生错误连接甚至死循环。
