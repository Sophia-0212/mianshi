# 0141. 环形链表

**题目描述**

给定一个链表的头节点 `head`，判断链表中是否存在环。链表中的环是指：链表某个节点的 `next` 指针指向了链表中靠前的某个节点，形成一个循环，导致从这个节点出发沿着 `next` 一直走会无限循环下去，而不会到达 `null`。

本题只需要返回是否存在环（布尔值），不需要找出环的入口位置（找入口是进阶版 142 题的要求）。

```
示例：
输入: head = [3,2,0,-4]，其中最后一个节点的 next 指向下标为 1 的节点（形成环）
输出: true

输入: head = [1,2]，不存在环
输出: false
```

## 思路

- Floyd 快慢指针：慢走一步、快走两步；相遇有环，快指针到空则无环。时间 O(n)，空间 O(1)。
- 哈希集合：记录访问过的节点，重复访问即有环。平均时间 O(n)，空间 O(n)。

### LeetCode 写法与原有示例

标准库思路说明：Python 没有针对"链表判圈"这种场景的现成库函数，因为这属于自定义数据结构上的指针操作，没有通用容器能直接调用。这里先给一个更直观但空间不是最优的哈希集合写法作为对照，再给出面试真正考察的手写快慢指针版本。

哈希集合写法（空间 O(n)，用于对照理解，不是本题推荐解法）：

```python
class Solution:
    # 方法：hasCycle；按题目要求处理输入并返回结果，核心算法见方法体。
    def hasCycle(self, head: 'Optional[ListNode]') -> bool:
        visited = set()          # 记录访问过的节点地址
        node = head
        while node:
            if node in visited:  # 该节点已经访问过，说明存在环
                return True
            visited.add(node)
            node = node.next
        return False              # 遍历到 null，说明无环
```


手写实现（面试考察点，Floyd 判圈算法，O(1) 空间）：

```python
class ListNode:
    # 方法：__init__；按题目要求处理输入并返回结果，核心算法见方法体。
    def __init__(self, val=0, next=None):
        self.val = val
        self.next = next

class Solution:
    # 方法：hasCycle；按题目要求处理输入并返回结果，核心算法见方法体。
    def hasCycle(self, head: 'Optional[ListNode]') -> bool:
        slow, fast = head, head  # 两个指针都从头节点出发
        while fast and fast.next:
            slow = slow.next        # 慢指针走一步
            fast = fast.next.next   # 快指针走两步
            if slow == fast:        # 移动之后判断是否相遇
                return True          # 相遇说明存在环
        return False  # fast 提前到达链表末尾，说明无环
```

 * struct ListNode {
 *     int val;

## 总结

- Floyd 判圈算法的正确性，说白了就是建立在"恒定相对速度差在有限环上必然导致追及"这个朴素的物理直觉上：快慢指针速度差是 1，环的周长又是有限的，所以追赶所需的轮数肯定是有限的，不会无限循环下去。
- 循环终止条件一定要同时判断 `fast` 和 `fast.next` 非空，因为快指针一次要跨两步，少判断一个的话，链表比较短的时候就会访问越界指针。
- 相遇判断要放在指针移动之后，不能放在移动之前，不然会因为起点相同，导致循环刚开始就被误判成有环了。
- 这道题其实是 142 题（环形链表 II）的简化版：141 题只要判断相遇就能返回结果，142 题在相遇之后还得利用等距性质重新定位入环点。理解清楚这两题的递进关系，能帮你更系统地掌握 Floyd 判圈算法的完整应用。
