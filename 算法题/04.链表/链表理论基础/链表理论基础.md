# 链表理论基础

链表节点通过指针连接，无需连续存储。按下标访问 O(n)；已知前驱时插入、删除 O(1)，否则需先 O(n) 定位。存储 O(n)。

- 单链表：仅后继，单向遍历。
- 双链表：前驱＋后继，可双向遍历，已知节点即可 O(1) 删除。
- 循环链表：尾部连接头部，遍历需明确终止条件。

数组随机访问 O(1)、中间增删 O(n)；链表节点另有指针开销。

struct ListNode {
    int val;
    ListNode* next;
    ListNode(int value = 0, ListNode* n = nullptr) : val(value), next(n) {}
};
// 自己构造链表，不依赖平台提供节点。
ListNode* buildList(const vector<int>& values) {
    ListNode dummy; auto* tail = &dummy;
    for (int v : values) { tail->next = new ListNode(v); tail = tail->next; }
    return dummy.next;
}
vector<int> listValues(ListNode* head) {
    vector<int> result;
    for (; head; head = head->next) result.push_back(head->val);
    return result;
}
ListNode* buildCycle(const vector<int>& values, int pos) {
    auto* head = buildList(values);
    vector<ListNode*> nodes;
    for (auto* n = head; n; n = n->next) nodes.push_back(n);
    if (!nodes.empty() && pos >= 0) nodes.back()->next = nodes[pos];
    return head;
}
ListNode* attach(const vector<int>& prefix, ListNode* shared) {
    auto* head = buildList(prefix);
    if (!head) return shared;
    auto* tail = head;
    while (tail->next) tail = tail->next;
    tail->next = shared;
    return head;
}
void show(ListNode* head) { show(listValues(head)); }
