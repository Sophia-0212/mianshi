# 链表理论基础

**链表的定义**

链表是一种通过指针（引用）把一系列节点串起来的线性数据结构。每个节点通常包含两部分：存储的数据（`val`）和指向下一个节点的指针（`next`）。这里跟数组不一样的地方在于，链表里的元素在内存中不是连续存放的，节点的物理位置是分散的，全靠指针来维系逻辑上的先后顺序。

一个单链表节点的典型定义（以 C++ 为例）：

```cpp
struct ListNode {
    int val;
    ListNode *next;
    ListNode(int x) : val(x), next(NULL) {}
};
```

**单链表、双链表、循环链表的区别**

- **单链表**：每个节点只有一个 `next` 指针，指向下一个节点，只能从头到尾单向遍历。最后一个节点的 `next` 指向 `null`，标志着链表结束。
- **双链表**：每个节点除了 `next` 还多了一个 `prev` 指针，指向前一个节点。双向链表可以双向遍历，删除某个节点的时候也不需要额外维护前驱指针（因为节点自己就存着前驱），但每个节点多了一个指针字段，内存开销更大，插入删除的时候要同时维护两个方向的指针，逻辑也更复杂一些。
- **循环链表**：链表首尾相连，最后一个节点的 `next` 不指向 `null`，而是指向头节点，这样就形成了一个环。循环链表适合表达环形结构的场景，比如约瑟夫环问题、轮询调度这些。需要额外小心遍历时的终止条件，不然很容易死循环。

这三者的选择本质上就是在”遍历灵活性”和”额外内存/维护成本”之间做权衡：单链表最省内存、逻辑最简单；双链表遍历方向灵活、删除操作更直接；循环链表适合天然具有环状语义的问题。

**链表与数组的对比**

链表和数组是两种最基础、也是最常被拿来对比的线性结构，理解它们之间的差异是做算法选择的第一步。

1. **内存分布**：数组在内存中是一段连续的空间，很多语言里声明的时候就需要预先确定大小；链表的节点是分散在堆内存里的，通过指针串联起来，不要求连续存储，所以对内存空间的利用更灵活，尤其适合大小不确定或者频繁变化的场景。

2. **插入和删除的复杂度**：这是链表相对数组最大的优势。你想啊，数组要在中间插入或删除一个元素，得把该位置之后的所有元素都搬一遍，时间复杂度是 O(n)；而链表只需要改一下相邻节点的指针指向，时间复杂度是 O(1)（前提是已经定位到了要操作的位置，定位本身要是从头遍历还是 O(n)，但操作动作本身是常数级的）。这也是为什么频繁增删、而且增删位置不固定在末尾的场景，链表往往比数组更合适。

3. **随机访问能力**：数组支持随机访问，通过下标就能在 O(1) 时间内直接定位到任意元素，因为内存是连续的，地址可以通过下标直接算出来。链表就不支持随机访问了，要访问第 k 个节点必须从头节点开始一个一个遍历 `next`，时间复杂度是 O(n)。这意味着如果算法里大量依赖”按下标访问”，那数组是更好的选择；要是算法的主要操作是插入删除、访问模式又是顺序遍历，链表就更合适。

简单总结一下：数组是”查询快，增删慢”；链表是”增删快（定位到位置之后），查询慢”。

**虚拟头节点（dummy head）技巧**

处理链表删除、插入这类操作的时候，一个常见的痛点是：头节点的处理逻辑往往跟中间节点不一致。比如说要删除链表中所有等于某个值的节点，如果头节点恰好也等于这个值，删除头节点就需要单独更新”头指针本身”，而删除中间节点只需要改前一个节点的 `next` 指向——这其实是两套不同的逻辑，代码里就会出现一堆特判（类似 `if (head != nullptr && head->val == val) { ... }` 这种）。

虚拟头节点的做法是这样的：在真正的头节点之前，额外创建一个不存储有效数据的节点 `dummy`，让 `dummy->next` 指向原来的头节点。这样一来，原链表的头节点也就变成了一个”有前驱节点”的普通节点，所有的删除、插入操作都可以统一用”修改某个节点的 `next` 指针”这一套逻辑来处理，不用再区分头节点和中间节点了。

```cpp
ListNode* dummy = new ListNode(0);
dummy->next = head;
ListNode* cur = dummy;
// 后续所有操作都基于 cur->next 进行，不再需要对 head 单独判断
```

最后返回结果的时候，返回 `dummy->next` 就行了（因为真正的头节点可能已经变了，比如头节点被删除了）。这个技巧在链表相关的题目里出现的频率非常高，本质上就是用”增加一层抽象”把边界情况统一成了普通情况，是简化链表代码逻辑的一个重要思维方式，后面在具体题目（比如移除链表元素、两两交换节点等）里还会反复用到。
