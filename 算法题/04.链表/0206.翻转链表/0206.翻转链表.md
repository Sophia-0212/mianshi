# 0206. 翻转链表

**题目描述**

给定单链表的头节点 `head`，反转链表并返回反转后的头节点。

```
示例：
输入: head = [1,2,3,4,5]
输出: [5,4,3,2,1]
解释: 原链表从头到尾遍历顺序 1->2->3->4->5，反转后变为 5->4->3->2->1
```

## 思路

反转链表这件事本质上就是把每个节点的 `next` 指针方向全部倒过来。原来是 `A -> B -> C -> null`，反转之后要变成 `null <- A <- B <- C`，也就是 `C -> B -> A -> null`。

这里有两种主流写法，思路完全不一样，值得拿出来对比着理解一下。

**双指针迭代法**：维护两个指针 `pre` 和 `cur`，`pre` 一开始是 `null`（代表新链表当前的末尾，一开始还没有节点呢），`cur` 一开始是 `head`。每一步要做三件事：

1. 用 `next` 这个临时变量先把 `cur->next` 存起来（为什么呢？因为马上就要改 `cur->next` 了，如果不提前存好，后面的节点引用就丢了，没法继续遍历）
2. 把 `cur->next` 指向 `pre`（这一步就完成了当前节点的指针反转）
3. `pre` 和 `cur` 一起往前挪一步：`pre = cur; cur = next;`

这样循环下去，直到 `cur` 变成 `null`，这时候 `pre` 就是反转后的新头节点了。你可以这么理解这个过程：从原链表头部开始，一个一个地把节点"摘下来接到新链表的头部"，新链表就在 `pre` 这个位置不断往前长。

时间复杂度是 O(n)，就遍历一次；空间复杂度是 O(1)，只用了几个指针变量。

**递归法**：递归的思路是这样的——假设从 `head->next` 开始的那段子链表已经反转好了，那原问题就变成了：把 `head` 接到这个已经反转好的子链表的尾部。

具体来说，设 `reverse(head)` 返回反转后子链表的头节点 `newHead`。递归到最深处，子链表反转完成之后，子链表原来的尾节点就变成了新头节点，而 `head` 本身这时候的 `next` 还指向原来的下一个节点（还没改呢）。因为子链表已经反转了，`head->next`（也就是反转前的下一个节点，反转后成了子链表的尾节点）的 `next` 应该要指向 `head`，所以令 `head->next->next = head`，然后再把 `head->next` 置为 `null`（因为 `head` 现在变成了新链表的尾节点），最后返回 `newHead` 就行了。

递归写法更符合"分治"的思考方式：先解决子问题（把后面的部分反转好），再拿子问题的解来解决当前层的问题（把当前节点接到反转结果的尾部）。不过递归有额外的调用栈开销，空间复杂度是 O(n)（递归深度就等于链表长度），而迭代法是严格的 O(1) 空间。链表很长的时候，递归还可能有栈溢出的风险，所以工程实践里更常用迭代法，递归法主要是用来理解链表反转的本质，以及在面试中展示两种思路的能力。

## 代码

链表节点定义：

```cpp
struct ListNode {
    int val;
    ListNode *next;
    ListNode(int x) : val(x), next(NULL) {}
};
```

### C++

```cpp
// 迭代法
class Solution {
public:
    ListNode* reverseList(ListNode* head) {
        ListNode* pre = nullptr;  // pre 表示新链表当前的头部，初始为空
        ListNode* cur = head;
        while (cur != nullptr) {
            ListNode* next = cur->next;  // 提前保存后继，防止修改 next 后丢失
            cur->next = pre;              // 反转当前节点的指向
            pre = cur;                     // pre 前移，成为新的"新链表头"
            cur = next;                    // cur 前移，处理原链表下一个节点
        }
        return pre;  // cur 为空时，pre 正是反转后的新头节点
    }
};

// 递归法
class SolutionRecursive {
public:
    ListNode* reverseList(ListNode* head) {
        if (head == nullptr || head->next == nullptr) {
            return head;  // 递归基：空链表或只有一个节点，反转后不变
        }
        ListNode* newHead = reverseList(head->next);  // 假设后面的子链表已反转完毕
        head->next->next = head;  // 子链表的尾节点（原 head->next）指回 head
        head->next = nullptr;      // head 变为新链表的尾节点，next 置空
        return newHead;             // newHead 始终是最终的新头节点
    }
};
```

### Python

链表反转是结构性的指针操作，没有对应的标准库一行解，这里只给手写实现（迭代和递归两个版本都写一下）：

```python
class ListNode:
    def __init__(self, val=0, next=None):
        self.val = val
        self.next = next


class Solution:
    def reverseList(self, head: ListNode) -> ListNode:
        pre = None       # 新链表当前头部，初始为空
        cur = head
        while cur is not None:
            nxt = cur.next   # 提前保存后继节点
            cur.next = pre     # 反转当前节点指向
            pre = cur           # pre 前移
            cur = nxt            # cur 前移
        return pre  # 反转后的新头节点


class SolutionRecursive:
    def reverseList(self, head: ListNode) -> ListNode:
        if head is None or head.next is None:
            return head  # 递归基：空链表或单节点，反转后不变
        new_head = self.reverseList(head.next)  # 假设后面子链表已反转完毕
        head.next.next = head  # 子链表尾节点指回 head
        head.next = None         # head 变为新尾节点
        return new_head
```

### Go

```go
type ListNode struct {
    Val  int
    Next *ListNode
}

// 迭代法
func reverseList(head *ListNode) *ListNode {
    var pre *ListNode = nil // 新链表当前头部，初始为空
    cur := head
    for cur != nil {
        next := cur.Next // 提前保存后继节点
        cur.Next = pre    // 反转当前节点指向
        pre = cur          // pre 前移
        cur = next          // cur 前移
    }
    return pre // 反转后的新头节点
}

// 递归法
func reverseListRecursive(head *ListNode) *ListNode {
    if head == nil || head.Next == nil {
        return head // 递归基
    }
    newHead := reverseListRecursive(head.Next) // 子链表已反转
    head.Next.Next = head                        // 子链表尾节点指回 head
    head.Next = nil                                // head 变为新尾节点
    return newHead
}
```

## 总结

- 迭代法的核心就是三步走：保存后继、反转指向、双指针前移，这个顺序不能乱——一定要先保存 `cur->next`，不然一改 `cur->next = pre`，原来的后继引用就永久没了。
- 递归法的核心是"信任递归"：假设 `reverse(head->next)` 已经正确处理好了，当前层只要处理好 `head` 和这个已反转子链表之间的连接关系就行（`head->next->next = head` 加上 `head->next = nullptr`）。
- 递归法的空间复杂度是 O(n)（调用栈开销），迭代法是 O(1)，链表比较长的时候，优先用迭代法，能避免栈溢出。
- 反转链表其实是很多复杂链表题目的子过程，比如"回文链表判断""按组反转链表"这些题都可能复用反转的逻辑，所以这个迭代写法一定要练到手写不出错才行。
