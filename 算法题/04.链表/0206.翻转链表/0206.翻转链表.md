# 0206. 翻转链表

**题目描述**

给定单链表的头节点 `head`，反转链表并返回反转后的头节点。

```
示例：
输入: head = [1,2,3,4,5]
输出: [5,4,3,2,1]
解释: 原链表从头到尾遍历顺序 1->2->3->4->5，反转后变为 5->4->3->2->1
```

## 思路

- 迭代：保存 `cur.next`，令 `cur.next=pre`，再推进 `pre、cur`；结束返回 `pre`。时间 O(n)，空间 O(1)。
- 递归：先反转后续链表，再令 `head.next.next=head`、`head.next=null`，返回新头。时间 O(n)，栈空间 O(n)。

```python
class ListNode:
    # 方法：__init__；按题目要求处理输入并返回结果，核心算法见方法体。
    def __init__(self, val=0, next=None):
        self.val = val
        self.next = next


class Solution:
    # 方法：reverseList；按题目要求处理输入并返回结果，核心算法见方法体。
    def reverseList(self, head: ListNode) -> ListNode:
        pre = None       # 新链表当前头部，初始为空
        cur = head
        while cur is not None:
            nxt = cur.next   # 提前保存后继节点
            cur.next = pre     # 反转当前节点指向
            pre = cur           # pre 前移
            cur = nxt            # cur 前移
        return pre  # 反转后的新头节点


class SolutionRecursive:
    # 方法：reverseList；按题目要求处理输入并返回结果，核心算法见方法体。
    def reverseList(self, head: ListNode) -> ListNode:
        if head is None or head.next is None:
            return head  # 递归基：空链表或单节点，反转后不变
        new_head = self.reverseList(head.next)  # 假设后面子链表已反转完毕
        head.next.next = head  # 子链表尾节点指回 head
        head.next = None         # head 变为新尾节点
        return new_head
```

```cpp
// 迭代法
class Solution {
public:
    ListNode* reverseList(ListNode* head) {
        ListNode* pre = nullptr;  // pre 表示新链表当前的头部，初始为空
        ListNode* cur = head;
        while (cur != nullptr) {
            ListNode* next = cur->next;  // 提前保存后继，防止修改 next 后丢失
            cur->next = pre;              // 反转当前节点的指向
            pre = cur;                     // pre 前移，成为新的"新链表头"
            cur = next;                    // cur 前移，处理原链表下一个节点
        }
        return pre;  // cur 为空时，pre 正是反转后的新头节点
    }
};

// 递归法
class SolutionRecursive {
public:
    ListNode* reverseList(ListNode* head) {
        if (head == nullptr || head->next == nullptr) {
            return head;  // 递归基：空链表或只有一个节点，反转后不变
        }
        ListNode* newHead = reverseList(head->next);  // 假设后面的子链表已反转完毕
        head->next->next = head;  // 子链表的尾节点（原 head->next）指回 head
        head->next = nullptr;      // head 变为新链表的尾节点，next 置空
        return newHead;             // newHead 始终是最终的新头节点
    }
};
```

## 总结

- 迭代法的核心就是三步走：保存后继、反转指向、双指针前移，这个顺序不能乱——一定要先保存 `cur->next`，不然一改 `cur->next = pre`，原来的后继引用就永久没了。
- 递归法的核心是"信任递归"：假设 `reverse(head->next)` 已经正确处理好了，当前层只要处理好 `head` 和这个已反转子链表之间的连接关系就行（`head->next->next = head` 加上 `head->next = nullptr`）。
- 递归法的空间复杂度是 O(n)（调用栈开销），迭代法是 O(1)，链表比较长的时候，优先用迭代法，能避免栈溢出。
- 反转链表其实是很多复杂链表题目的子过程，比如"回文链表判断""按组反转链表"这些题都可能复用反转的逻辑，所以这个迭代写法一定要练到手写不出错才行。
