# 0019. 删除链表的倒数第N个节点

**题目描述**

给定一个链表的头节点 `head`，删除链表的倒数第 `n` 个节点，并返回链表的头节点。题目保证 `n` 是合法的（不超过链表长度）。

```
示例：
输入: head = [1,2,3,4,5], n = 2
输出: [1,2,3,5]
解释: 倒数第 2 个节点是值为 4 的节点，删除后链表变为 1->2->3->5
```

## 思路

- 快慢指针：从虚拟头节点出发，快指针先走 `n+1` 步，再同步前进。快指针为空时，慢指针位于待删节点前，令 `slow.next=slow.next.next`。
- 两次遍历：先求长度 `L`，再找到第 `L-n+1` 个节点的前驱并删除。

两种方法均为时间 O(L)，空间 O(1)。

class ListNode:
    # 方法：__init__；按题目要求处理输入并返回结果，核心算法见方法体。
    def __init__(self, val=0, next=None):
        self.val = val
        self.next = next


class Solution:
    # 方法：removeNthFromEnd；按题目要求处理输入并返回结果，核心算法见方法体。
    def removeNthFromEnd(self, head: ListNode, n: int) -> ListNode:
        dummy = ListNode(0)  # 虚拟头节点
        dummy.next = head
        fast = dummy
        slow = dummy

        for _ in range(n):
            fast = fast.next  # fast 先走 n 步，制造间距

        while fast.next is not None:  # fast 走到最后一个节点
            fast = fast.next
            slow = slow.next            # 同步前进保持间距

        slow.next = slow.next.next  # slow 是待删除节点的前驱
        return dummy.next

## C++

### LeetCode 写法与原有示例

```cpp
struct ListNode {
    int val;
    ListNode *next;
    ListNode(int x) : val(x), next(NULL) {}
};
```

```cpp
class Solution {
public:
    ListNode* removeNthFromEnd(ListNode* head, int n) {
        ListNode* dummy = new ListNode(0);  // 虚拟头节点，涵盖"删除原头节点"的边界情况
        dummy->next = head;
        ListNode* fast = dummy;
        ListNode* slow = dummy;

        for (int i = 0; i < n; i++) {
            fast = fast->next;  // fast 先走 n 步，制造 n 个节点的间距
        }

        while (fast->next != nullptr) {  // fast 走到最后一个节点为止（不是走到 null）
            fast = fast->next;
            slow = slow->next;  // 保持间距同步前进
        }

        slow->next = slow->next->next;  // slow 现在正好是待删除节点的前驱，跳过它
        ListNode* newHead = dummy->next;
        delete dummy;
        return newHead;
    }
};
```

## 总结

- 这道题的核心就是快慢指针的间距设计：让 `fast` 先走 `n` 步，制造出固定间距，之后两个指针同步往前挪，`fast` 走到末尾的时候，`slow` 必然会落在倒数第 `n+1` 个节点上，也就是待删除节点的前驱。
- 有个特别容易踩坑的地方，就是循环终止条件：一定要判断 `fast->next == nullptr`（走到最后一个节点），而不是 `fast == nullptr`（走到 `null`）。为什么呢？因为少走一步才能让 `slow` 精确停在"前驱"上，而不是停在"待删除节点本身"。
- 虚拟头节点在这里解决的是这样一个边界情况：当 `n` 正好等于链表长度时，要删除的其实是原头节点，它的前驱就是 `dummy`。用了虚拟头节点之后，这种特殊情况和普通情况就完全统一了，不用再额外写判断。
- 这道题和"环形链表判环"其实都属于快慢指针的应用，但目的不太一样：这里是用间距差去找位置，环形链表那道题是用速度差去判断是否存在环。搞清楚这两者的差异，才能真正灵活地用好双指针这个技巧。
