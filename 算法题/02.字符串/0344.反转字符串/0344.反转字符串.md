# 0344. 反转字符串

**题目描述**

编写一个函数，其作用是将输入的字符数组原地反转。不要使用额外的数组空间，必须原地修改输入数组、使用 O(1) 的额外空间解决这一问题。

```
示例：
输入: s = ['h','e','l','l','o']
输出: ['o','l','l','e','h']

输入: s = ['H','a','n','n','a','h']
输出: ['h','a','n','n','a','H']
```

## 思路

双指针从两端向中间交换，直到相遇或交错。时间 O(n)，空间 O(1)。

切片反转后赋回原数组也可实现；时间 O(n)，空间 O(n)。



## Python

### LeetCode 写法与原有示例

标准库一行解（切片反转，`s[::-1]` 会生成一个新的反转后的序列）：

```python
class Solution:
    # 方法：reverseString；按题目要求处理输入并返回结果，核心算法见方法体。
    def reverseString(self, s: list[str]) -> None:
        s[:] = s[::-1]  # 切片赋值给 s[:]，保持原地修改语义（而非重新绑定变量）
```


手写实现（面试考察点：还原双指针交换过程）：

```python
# 依赖说明：len：Python 内置函数：返回容器中元素的数量。

class Solution:
    # 方法：reverseString；按题目要求处理输入并返回结果，核心算法见方法体。
    def reverseString(self, s: list[str]) -> None:
        left, right = 0, len(s) - 1  # 双指针分别指向首尾
        while left < right:  # 两指针未相遇/未交错时继续
            s[left], s[right] = s[right], s[left]  # Python 支持多重赋值一步交换
            left += 1   # 左指针右移
            right -= 1  # 右指针左移```

## Go

// 方法：reverseString；按题目要求处理输入并返回结果，核心算法见方法体。
func reverseString(s []byte) {
    left, right := 0, len(s)-1 // 双指针分别指向首尾
    for left < right {         // 两指针未相遇/未交错时继续
        s[left], s[right] = s[right], s[left] // Go 支持多重赋值一步交换
        left++   // 左指针右移
        right--  // 右指针左移
    }
}
```

## C++

### LeetCode 写法与原有示例

```cpp
class Solution {
public:
    // 方法：reverseString；按题目要求处理输入并返回结果，核心算法见方法体。
    void reverseString(vector<char>& s) {
        int left = 0, right = s.size() - 1;  // 双指针分别指向首尾
        while (left < right) {  // 两指针未相遇/未交错时继续
            swap(s[left], s[right]);  // 交换首尾字符
            left++;   // 左指针右移
            right--;  // 右指针左移
        }
    }
};
```

## 总结

- 双指针从两端向中间逼近、原地交换，这是字符串/数组反转类问题里最基础的模板，后面很多题（比如 541、151、55）都是在这个模板上叠加逻辑玩出来的。
- 循环条件要用 `left < right`（不是 `<=`），这样可以省去中间字符的无意义自交换，顺便还天然兼容了奇偶长度。
- 面试中即使语言自带反转的库函数（比如 Python 的切片），也建议先说一下库解，再手写一版双指针，这样能体现出你对底层原理的掌握。
- 这个技巧的空间复杂度是 O(1)，是"原地反转"类问题的标准解法，跟需要额外数组的反转方式是有本质区别的。
