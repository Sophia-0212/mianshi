# 0344. 反转字符串

**题目描述**

编写一个函数，其作用是将输入的字符数组原地反转。不要使用额外的数组空间，必须原地修改输入数组、使用 O(1) 的额外空间解决这一问题。

```
示例：
输入: s = ['h','e','l','l','o']
输出: ['o','l','l','e','h']

输入: s = ['H','a','n','n','a','h']
输出: ['h','a','n','n','a','H']
```

## 思路

这题是字符串（字符数组）操作里最基础的一道题了，核心考点就是**双指针从两端向中间交换**。

思路其实很直白：设置两个指针，`left` 指向数组头，`right` 指向数组尾，每次交换 `s[left]` 和 `s[right]`，然后 `left` 右移、`right` 左移，一直做到两个指针相遇或者交错为止。你想啊，因为每一步交换的都是"确定位置"的元素——一旦交换完，这两个位置就再也不会被后面的操作影响了——所以根本不需要额外空间去记录中间状态。

关键决策点在哪呢？在循环终止条件上：要用 `left < right`，而不是 `left <= right`。为什么呢？当数组长度是偶数的时候，两个指针最终会错开一位；当长度是奇数的时候，会在中间位置碰头（`left == right`），这个中间字符自己跟自己交换其实没啥意义，所以用 `<` 就能少做一次无意义的交换，逻辑也更清晰——说白了就是，只要两个指针还没碰头，就说明还有需要交换的对。

还有一点要注意，题目要求是**原地修改**，所以不能写成 `return s[::-1]` 这种返回新对象的写法（虽然 Python 的切片语法确实能一步得到反转结果，但这属于"抄近路"的库函数用法，面试里真正考察的是你是不是理解并能手写出双指针交换的过程）。

复杂度这块：数组长度为 `n`，双指针总共移动 `n/2` 次，每次做一次常数时间的交换，所以时间复杂度是 O(n)；除了输入数组本身，只用了两个指针变量，空间复杂度是 O(1)。

## 代码

### C++

```cpp
class Solution {
public:
    void reverseString(vector<char>& s) {
        int left = 0, right = s.size() - 1;  // 双指针分别指向首尾
        while (left < right) {  // 两指针未相遇/未交错时继续
            swap(s[left], s[right]);  // 交换首尾字符
            left++;   // 左指针右移
            right--;  // 右指针左移
        }
    }
};
```

### Java

```java
class Solution {
    public void reverseString(char[] s) {
        int left = 0, right = s.length - 1;  // 双指针分别指向首尾
        while (left < right) {  // 两指针未相遇/未交错时继续
            char tmp = s[left];   // 借助临时变量交换（Java 没有内置 swap）
            s[left] = s[right];
            s[right] = tmp;
            left++;   // 左指针右移
            right--;  // 右指针左移
        }
    }
}
```

### Python

标准库一行解（切片反转，`s[::-1]` 会生成一个新的反转后的序列）：

```python
class Solution:
    def reverseString(self, s: list[str]) -> None:
        s[:] = s[::-1]  # 切片赋值给 s[:]，保持原地修改语义（而非重新绑定变量）
```

手写实现（面试考察点：还原双指针交换过程）：

```python
class Solution:
    def reverseString(self, s: list[str]) -> None:
        left, right = 0, len(s) - 1  # 双指针分别指向首尾
        while left < right:  # 两指针未相遇/未交错时继续
            s[left], s[right] = s[right], s[left]  # Python 支持多重赋值一步交换
            left += 1   # 左指针右移
            right -= 1  # 右指针左移
```

### Go

```go
func reverseString(s []byte) {
    left, right := 0, len(s)-1 // 双指针分别指向首尾
    for left < right {         // 两指针未相遇/未交错时继续
        s[left], s[right] = s[right], s[left] // Go 支持多重赋值一步交换
        left++   // 左指针右移
        right--  // 右指针左移
    }
}
```

## 总结

- 双指针从两端向中间逼近、原地交换，这是字符串/数组反转类问题里最基础的模板，后面很多题（比如 541、151、55）都是在这个模板上叠加逻辑玩出来的。
- 循环条件要用 `left < right`（不是 `<=`），这样可以省去中间字符的无意义自交换，顺便还天然兼容了奇偶长度。
- 面试中即使语言自带反转的库函数（比如 Python 的切片），也建议先说一下库解，再手写一版双指针，这样能体现出你对底层原理的掌握。
- 这个技巧的空间复杂度是 O(1)，是"原地反转"类问题的标准解法，跟需要额外数组的反转方式是有本质区别的。
