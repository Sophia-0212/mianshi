# 0028. 实现strStr

**题目描述**

给定两个字符串 `haystack` 和 `needle`，在 `haystack` 字符串中找出 `needle` 字符串第一次出现的位置（下标从 0 开始）。如果不存在，返回 -1。

```
示例：
输入: haystack = "hello", needle = "ll"
输出: 2

输入: haystack = "aaaaa", needle = "bba"
输出: -1
```

## 思路

先说说最直观的想法：对 `haystack` 里每个起始位置，都去跟 `needle` 逐字符比一遍，不匹配就挪到下一个起始位置重新比，这个暴力解法时间复杂度是 O(n*m)。但这题真正想考的其实不是这个，而是**KMP 算法**——你想啊，字符串匹配类题目里最难也最经典的就是它了，核心思想说白了就是一句话："利用已经匹配过的信息，别每次失配了就傻乎乎地退回起点重新扫"。

### 为什么需要 KMP

暴力解法问题在哪呢？就是每次从 `haystack` 的新起点跟 `needle` 从头比的时候，完全没有利用上一轮已经匹配上的那部分信息，等于白白浪费了。举个例子，比如 `needle = "aabaaf"`，如果匹配到第 5 个字符才失败，这时候我们其实已经知道前面匹配上的 `"aabaa"` 这一段内部长什么样了——如果 `needle` 的某个前缀恰好跟某个后缀长得一样，那下次失配了直接跳到这个前缀后面继续比就行，根本不用把指针退回起点重新扫一遍。KMP 算法预处理出来的这个**next 数组**，干的就是这个事：记录这种"最长相等前后缀"的信息。

### next 数组的含义：最长相等前后缀

这里的关键是搞懂 `next[i]` 到底在说什么：它表示 `needle` 的子串 `needle[0..i]`（包含第 i 个字符）里，最长的"相等前后缀"能有多长。

那什么是"前后缀"呢？对于字符串 `needle[0..i]`，前缀就是从下标 0 开始数的子串（但不能是整个串本身），后缀就是以下标 i 结尾的子串（同样不能是整个串本身）。"最长相等前后缀"说白了就是：找一个尽可能长的长度 `len`，让前 `len` 个字符拼成的前缀，跟最后 `len` 个字符拼成的后缀，内容完全一样。

拿 `needle = "aabaaf"` 举例子过一遍：
- `next[0]`：子串就是 `"a"`，只有一个字符，谈不上什么非本身的前后缀，所以 `next[0] = 0`
- `next[1]`：子串 `"aa"`，前缀候选是 `"a"`，后缀候选也是 `"a"`，正好相等，长度为 1，所以 `next[1] = 1`
- `next[2]`：子串 `"aab"`，先看长度2的 `"aa"` vs `"ab"`，不等；再看长度1的 `"a"` vs `"b"`，也不等，所以 `next[2] = 0`
- `next[3]`：子串 `"aaba"`，长度3 `"aab"` vs `"aba"` 不等；长度2 `"aa"` vs `"ba"` 不等；长度1 `"a"` vs `"a"` 相等，所以 `next[3] = 1`
- `next[4]`：子串 `"aabaa"`，长度4 `"aaba"` vs `"abaa"` 不等；长度3 `"aab"` vs `"baa"` 不等；长度2 `"aa"` vs `"aa"` 相等，所以 `next[4] = 2`
- `next[5]`：子串 `"aabaaf"`，末尾字符是 f，前面根本没出现过 f，最长相等前后缀只能是 0，所以 `next[5] = 0`

这样一算，就得到 `next = [0, 1, 0, 1, 2, 0]`。

### next 数组的构建过程

构建 next 数组用的其实是**动态规划**的思路：用 `j` 表示当前已经确定的最长相等前后缀长度（一开始是 0），然后遍历 `i` 从 1 到 `needle.length-1`：

- 如果 `needle[i] == needle[j]`，说明可以在原来长度为 `j` 的相等前后缀基础上，两边各延伸一个字符，那就 `j++`，然后 `next[i] = j`。
- 如果 `needle[i] != needle[j]` 而且 `j > 0`，说明当前长度的前后缀撑不住了，这时候要把 `j` 回退到 `next[j-1]`——也就是退到"次长的相等前后缀长度"，再重新试一次比较（有可能要连续回退好几次，所以这里用的是 `while` 循环）。
- 要是回退到 `j == 0` 了还是不匹配，那就说明这个位置压根没有相等前后缀，`next[i] = 0`。

为什么说这是动态规划呢？你想，`next[i]` 的计算依赖的是 `next[0..i-1]` 已经算出来的结果——匹配失败的时候，需要去查"更短的相等前后缀"这个子问题的答案，这正是 DP 那种"拿子问题的答案去推出当前问题答案"的味儿。

### 匹配过程如何利用 next 数组跳过比较

到主匹配阶段了：用指针 `i` 遍历 `haystack`，指针 `j` 遍历 `needle`（`j` 同时也代表"目前已经匹配上的字符个数"）：

- 如果 `haystack[i] == needle[j]`，两个指针都往前走一位，接着比下一个字符。
- 如果不匹配，而且 `j > 0`，这里的关键是——`j` 不是退回 0 从头再来，而是回退到 `next[j-1]`。为什么呢？因为 `next[j-1]` 记录的正是"当前已经匹配上的这一段字符串"里最长相等前后缀的长度，这意味着 `needle` 里这个更短的前缀，其实已经天然跟 `haystack` 当前位置前面的那一段字符对齐了，不需要再重新比一遍，直接从这个位置接着比 `haystack[i]` 和 `needle[j]` 就行。
- 如果 `j` 一直涨到 `needle.length`，说明完全匹配成功了，这时候 `i - needle.length` 就是匹配的起始下标。

这就是 KMP 比暴力解法厉害的地方：`haystack` 的指针 `i` 从头到尾都不回退，只有 `needle` 的指针 `j` 靠着 next 数组智能地往回跳，整体时间复杂度就降到了 O(n+m)（构建 next 数组花 O(m)，主匹配过程花 O(n)）。

复杂度这块，时间复杂度是 O(n+m)，`n` 是 `haystack` 长度，`m` 是 `needle` 长度；空间复杂度是 O(m)，用来存 next 数组。

## 代码

### C++

```cpp
class Solution {
public:
    int strStr(string haystack, string needle) {
        int m = needle.size();
        if (m == 0) return 0;
        vector<int> next(m, 0);
        getNext(next, needle);  // 构建next数组（最长相等前后缀）

        int j = 0;  // j 表示 needle 中已匹配上的字符个数
        for (int i = 0; i < haystack.size(); i++) {
            // 不匹配且 j>0 时，回退到 next[j-1]，跳过不必要的比较
            while (j > 0 && haystack[i] != needle[j]) {
                j = next[j - 1];
            }
            if (haystack[i] == needle[j]) {
                j++;  // 匹配成功，j 前进
            }
            if (j == m) {
                return i - m + 1;  // 完全匹配，返回起始下标
            }
        }
        return -1;
    }

private:
    void getNext(vector<int>& next, const string& needle) {
        int j = 0;  // j 表示当前最长相等前后缀的长度
        next[0] = 0;
        for (int i = 1; i < needle.size(); i++) {
            // 不匹配时回退 j 到更短的相等前后缀长度（可能回退多次）
            while (j > 0 && needle[i] != needle[j]) {
                j = next[j - 1];
            }
            if (needle[i] == needle[j]) {
                j++;  // 可以在原前后缀基础上各延伸一位
            }
            next[i] = j;
        }
    }
};
```

class Solution {
    public int strStr(String haystack, String needle) {
        int m = needle.length();
        if (m == 0) return 0;
        int[] next = getNext(needle);  // 构建next数组

        int j = 0;  // j 表示 needle 中已匹配上的字符个数
        for (int i = 0; i < haystack.length(); i++) {
            while (j > 0 && haystack.charAt(i) != needle.charAt(j)) {
                j = next[j - 1];  // 回退到更短的相等前后缀长度
            }
            if (haystack.charAt(i) == needle.charAt(j)) {
                j++;  // 匹配成功，j 前进
            }
            if (j == m) {
                return i - m + 1;  // 完全匹配，返回起始下标
            }
        }
        return -1;
    }

    private int[] getNext(String needle) {
        int[] next = new int[needle.length()];
        int j = 0;  // 当前最长相等前后缀的长度
        next[0] = 0;
        for (int i = 1; i < needle.length(); i++) {
            while (j > 0 && needle.charAt(i) != needle.charAt(j)) {
                j = next[j - 1];  // 回退（可能回退多次）
            }
            if (needle.charAt(i) == needle.charAt(j)) {
                j++;
            }
            next[i] = j;
        }
        return next;
    }
}

手写实现（面试考察点：还原KMP算法，包括next数组构建和主匹配过程，这是字符串类最难的算法考点）：

```python
class Solution:
    def strStr(self, haystack: str, needle: str) -> int:
        m = len(needle)
        if m == 0:
            return 0
        nxt = self._get_next(needle)  # 构建next数组（最长相等前后缀）

        j = 0  # j 表示 needle 中已匹配上的字符个数
        for i in range(len(haystack)):
            # 不匹配且j>0时，回退到next[j-1]，跳过不必要的比较
            while j > 0 and haystack[i] != needle[j]:
                j = nxt[j - 1]
            if haystack[i] == needle[j]:
                j += 1  # 匹配成功，j前进
            if j == m:
                return i - m + 1  # 完全匹配，返回起始下标
        return -1

    def _get_next(self, needle: str) -> list[int]:
        m = len(needle)
        nxt = [0] * m
        j = 0  # 当前最长相等前后缀的长度
        for i in range(1, m):
            # 不匹配时回退j到更短的相等前后缀长度（DP思想：依赖已算出的next[j-1]）
            while j > 0 and needle[i] != needle[j]:
                j = nxt[j - 1]
            if needle[i] == needle[j]:
                j += 1  # 可以在原前后缀基础上各延伸一位
            nxt[i] = j
        return nxt
```

## 总结

- 说白了，KMP 算法的核心就是 next 数组，`next[i]` 表示 `needle[0..i]` 这个子串的"最长相等前后缀长度"，本质上记录的是字符串自身的重复结构信息。
- next 数组的构建过程本身也是一次字符串自己跟自己匹配，用的是 DP 思想：当前位置匹配失败了，就回退到 `next[j-1]`（也就是更短的相等前后缀长度）继续试，而不是一股脑退回 0。
- 主匹配阶段用 next 数组的方式跟构建阶段其实一模一样：不匹配时 `j` 回退到 `next[j-1]`，`haystack` 的指针 `i` 从头到尾都不回退，这样整体时间复杂度就从暴力法的 O(n*m) 降到了 O(n+m)。
- KMP 是字符串类题目里最难啃、但也最重要的算法之一，你想真正掌握它，关键突破口就是理解"最长相等前后缀"到底是什么意思，以及"失配的时候为什么能跳过一段直接接着比"，后面 459 题里用 next 数组判断周期性，也是建立在这个核心概念上的。
