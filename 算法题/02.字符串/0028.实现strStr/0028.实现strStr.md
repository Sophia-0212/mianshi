# 0028. 实现strStr

**题目描述**

给定两个字符串 `haystack` 和 `needle`，在 `haystack` 字符串中找出 `needle` 字符串第一次出现的位置（下标从 0 开始）。如果不存在，返回 -1。

```
示例：
输入: haystack = "hello", needle = "ll"
输出: 2

输入: haystack = "aaaaa", needle = "bba"
输出: -1
```

## 思路

- KMP：`next[i]` 为模式串 `needle[0..i]` 的最长相等真前后缀长度。构建和匹配时，失配令 `j=next[j-1]`；主串指针不回退。时间 O(n+m)，空间 O(m)。
- 暴力匹配：枚举起点，逐字符比较。时间 O(nm)，空间 O(1)。`str.find` 可直接调用，复杂度取决于库实现。

n、m 分别为主串、模式串长度。

```python
# 依赖说明：len：Python 内置函数：返回容器中元素的数量。；range：Python 内置函数：生成按步长遍历的整数序列。

class Solution:
    # 方法：strStr；按题目要求处理输入并返回结果，核心算法见方法体。
    def strStr(self, haystack: str, needle: str) -> int:
        m = len(needle)
        if m == 0:
            return 0
        nxt = self._get_next(needle)  # 构建next数组（最长相等前后缀）

        j = 0  # j 表示 needle 中已匹配上的字符个数
        for i in range(len(haystack)):
            # 不匹配且j>0时，回退到next[j-1]，跳过不必要的比较
            while j > 0 and haystack[i] != needle[j]:
                j = nxt[j - 1]
            if haystack[i] == needle[j]:
                j += 1  # 匹配成功，j前进
            if j == m:
                return i - m + 1  # 完全匹配，返回起始下标
        return -1

    # 方法：_get_next；按题目要求处理输入并返回结果，核心算法见方法体。
    def _get_next(self, needle: str) -> list[int]:
        m = len(needle)
        nxt = [0] * m
        j = 0  # 当前最长相等前后缀的长度
        for i in range(1, m):
            # 不匹配时回退j到更短的相等前后缀长度（DP思想：依赖已算出的next[j-1]）
            while j > 0 and needle[i] != needle[j]:
                j = nxt[j - 1]
            if needle[i] == needle[j]:
                j += 1  # 可以在原前后缀基础上各延伸一位
            nxt[i] = j
        return nxt```

    m := len(needle)
    if m == 0 {
        return 0
    }
    next := getNext(needle) // 构建next数组

    j := 0 // j 表示 needle 中已匹配上的字符个数
    for i := 0; i < len(haystack); i++ {
        for j > 0 && haystack[i] != needle[j] {
            j = next[j-1] // 回退到更短的相等前后缀长度
        }
        if haystack[i] == needle[j] {
            j++ // 匹配成功，j 前进
        }
        if j == m {
            return i - m + 1 // 完全匹配，返回起始下标
        }
    }
    return -1
}

// 方法：getNext；按题目要求处理输入并返回结果，核心算法见方法体。
func getNext(needle string) []int {
    m := len(needle)
    next := make([]int, m)
    j := 0 // 当前最长相等前后缀的长度
    for i := 1; i < m; i++ {
        for j > 0 && needle[i] != needle[j] {
            j = next[j-1] // 回退（可能回退多次）
        }
        if needle[i] == needle[j] {
            j++
        }
        next[i] = j
    }
    return next
}

class Solution {
public:
    // 方法：strStr；按题目要求处理输入并返回结果，核心算法见方法体。
    int strStr(string haystack, string needle) {
        int m = needle.size();
        if (m == 0) return 0;
        vector<int> next(m, 0);
        getNext(next, needle);  // 构建next数组（最长相等前后缀）

        int j = 0;  // j 表示 needle 中已匹配上的字符个数
        for (int i = 0; i < haystack.size(); i++) {
            // 不匹配且 j>0 时，回退到 next[j-1]，跳过不必要的比较

                j = next[j - 1];
            }
            if (haystack[i] == needle[j]) {
                j++;  // 匹配成功，j 前进
            }
            if (j == m) {

            }
        }
        return -1;
    }

## 总结

- 说白了，KMP 算法的核心就是 next 数组，`next[i]` 表示 `needle[0..i]` 这个子串的"最长相等前后缀长度"，本质上记录的是字符串自身的重复结构信息。
- next 数组的构建过程本身也是一次字符串自己跟自己匹配，用的是 DP 思想：当前位置匹配失败了，就回退到 `next[j-1]`（也就是更短的相等前后缀长度）继续试，而不是一股脑退回 0。
- 主匹配阶段用 next 数组的方式跟构建阶段其实一模一样：不匹配时 `j` 回退到 `next[j-1]`，`haystack` 的指针 `i` 从头到尾都不回退，这样整体时间复杂度就从暴力法的 O(n*m) 降到了 O(n+m)。
- KMP 是字符串类题目里最难啃、但也最重要的算法之一，你想真正掌握它，关键突破口就是理解"最长相等前后缀"到底是什么意思，以及"失配的时候为什么能跳过一段直接接着比"，后面 459 题里用 next 数组判断周期性，也是建立在这个核心概念上的。
