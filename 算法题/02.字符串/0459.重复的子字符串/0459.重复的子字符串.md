# 0459. 重复的子字符串

**题目描述**

给定一个非空字符串 `s`，判断它是否可以由它的一个子串重复多次构成。

```
示例：
输入: s = "abab"
输出: true
解释: 可由子串 "ab" 重复两次构成。

输入: s = "aba"
输出: false

输入: s = "abcabcabcabc"
输出: true
解释: 可由子串 "abc" 重复四次构成，也可由子串 "abcabc" 重复两次构成。
```

## 思路

这题有两种经典思路可以讲：**移动匹配法**和**KMP 的 next 数组法**，你想啊，它们其实是从不同角度利用了"周期性字符串"这个性质，两个都值得掌握。

### 思路一：移动匹配法

先说这个：如果字符串 `s` 是由某个子串重复多次构成的（也就是说 `s` 具有周期性），那把两个 `s` 拼起来（`s+s`），再把拼接结果的第一个字符和最后一个字符去掉（也就是掐头去尾），你会发现新字符串里一定还能找到一个完整的 `s`。反过来想，如果找不到，那就说明 `s` 不具有周期性。

这个结论怎么直觉理解呢？假设 `s = "abcabc"`（重复单元是 `"abc"`，重复了2次）。`s+s = "abcabcabcabc"`，掐头去尾后就是 `"bcabcabcab"`。在这段字符串里找 `"abcabc"`：实际验证一下，从下标2开始 `"abcabc"` 正好能对上。那为什么掐头去尾之后还能找到完整的 `s` 呢？本质原因是——如果 `s` 真的有周期性，那 `s` 往左"错位"一个周期长度之后，跟自己重叠的部分依然是相同的，这种自相似性就保证了在 `s+s` 去掉首尾字符后的中间地带，一定能重新拼出一个完整的 `s`。反过来，如果 `s` 不具备周期性，`s+s` 中除了开头和结尾那两个位置，中间不会再冒出完整的 `s`，掐头去尾后自然就找不到了。

用代码实现其实就一行核心逻辑：判断 `(s+s)` 去掉首尾字符后的字符串里，是不是包含 `s`。

### 思路二：KMP 的 next 数组法

这个思路说白了就是 0028 题 KMP 算法的直接应用，核心利用的性质是：**next 数组的最后一位记录了整个字符串的最长相等前后缀长度，而这个信息可以直接推导出字符串是否具有周期性**。

设字符串长度为 `n`，`next[n-1]` 表示整个字符串的最长相等前后缀长度（回顾一下 0028 题的定义）。如果 `next[n-1] != 0`，说明字符串存在长度为 `next[n-1]` 的相等前后缀，那"最小重复单元长度"就是 `n - next[n-1]`——为什么呢？因为如果前缀和后缀能重叠这么长，就等于说字符串错位 `n - next[n-1]` 个位置后能跟自己对齐，这不就正是"周期"的定义嘛。

那怎么判断字符串是不是真的具有周期性呢？还需要验证 `n` 能不能被这个候选的最小周期长度 `n - next[n-1]` 整除：能整除，就说明整个字符串恰好可以被这个长度的子串填满整数次，是重复子串构成的；不能整除呢，就说明只是"部分重叠"但凑不满整数个周期，不满足题意（比如 `"aabaaba"`，虽然有相等前后缀，但整除不了，就不是重复子串构成的）。

拿个具体例子演示一下：`s = "abab"`，`next` 数组构建过程是这样的：
- `next[0] = 0`
- `next[1]`：子串 `"ab"`，没有相等前后缀，`next[1] = 0`
- `next[2]`：子串 `"aba"`，长度1的前后缀 `"a"` vs `"a"` 相等，`next[2] = 1`
- `next[3]`：子串 `"abab"`，在 `next[2]=1` 的基础上，`s[3]='b'` 跟 `s[1]='b'` 相等，`next[3] = 2`

`n = 4`，`next[n-1] = 2`，候选最小周期长度就是 `4 - 2 = 2`。`4 % 2 == 0`，能整除，所以 `"abab"` 就是由长度为 2 的子串 `"ab"` 重复 2 次构成的，判断为 `true`，跟预期一致。

### 两种方法对比

移动匹配法思路直观、代码也极简，但它依赖字符串查找操作（要是自己手写查找，退化到暴力查找就是 O(n²)，用高效字符串匹配算法可以做到 O(n)）；KMP 法本身就是严格 O(n) 的线性算法，而且更能体现你对 next 数组本质含义的理解，所以在面试中更受青睐。

复杂度这块：移动匹配法如果用语言内置的高效查找，时间复杂度接近 O(n)，空间复杂度 O(n)（因为要拼接字符串）；KMP 法时间复杂度严格是 O(n)（构建 next 数组），空间复杂度 O(n)（存 next 数组）。

## 代码

### C++

```cpp
class Solution {
public:
    // 思路一：移动匹配法
    bool repeatedSubstringPattern(string s) {
        string doubled = s + s;
        doubled.erase(doubled.begin());       // 去掉第一个字符
        doubled.erase(doubled.end() - 1);     // 去掉最后一个字符
        return doubled.find(s) != string::npos;  // 掐头去尾后能找到完整s，说明有周期性
    }

    // 思路二：KMP next数组法
    bool repeatedSubstringPatternKMP(string s) {
        int n = s.size();
        vector<int> next(n, 0);
        int j = 0;
        for (int i = 1; i < n; i++) {
            while (j > 0 && s[i] != s[j]) {
                j = next[j - 1];
            }
            if (s[i] == s[j]) j++;
            next[i] = j;
        }
        int len = next[n - 1];  // 整个字符串的最长相等前后缀长度
        // len!=0 说明有候选周期；n%(n-len)==0 说明能被最小周期长度整除
        return len != 0 && n % (n - len) == 0;
    }
};
```

### Java

```java
class Solution {
    // 思路一：移动匹配法
    public boolean repeatedSubstringPattern(String s) {
        String doubled = (s + s).substring(1, 2 * s.length() - 1);  // 拼接后掐头去尾
        return doubled.contains(s);  // 能找到完整s，说明有周期性
    }

    // 思路二：KMP next数组法
    public boolean repeatedSubstringPatternKMP(String s) {
        int n = s.length();
        int[] next = new int[n];
        int j = 0;
        for (int i = 1; i < n; i++) {
            while (j > 0 && s.charAt(i) != s.charAt(j)) {
                j = next[j - 1];
            }
            if (s.charAt(i) == s.charAt(j)) j++;
            next[i] = j;
        }
        int len = next[n - 1];  // 最长相等前后缀长度
        return len != 0 && n % (n - len) == 0;  // 能整除说明可被完整周期填满
    }
}
```

### Python

标准库/简化写法（移动匹配法可以用一行 `in` 运算符判断子串包含）：

```python
class Solution:
    def repeatedSubstringPattern(self, s: str) -> bool:
        doubled = (s + s)[1:-1]  # 拼接后掐头去尾
        return s in doubled  # in 运算符判断是否包含完整的 s
```

手写实现（面试考察点：KMP的next数组法，还原"最长相等前后缀长度推导最小周期"的核心原理）：

```python
class Solution:
    def repeatedSubstringPattern(self, s: str) -> bool:
        n = len(s)
        nxt = [0] * n
        j = 0  # 当前最长相等前后缀的长度
        for i in range(1, n):
            while j > 0 and s[i] != s[j]:
                j = nxt[j - 1]  # 回退到更短的相等前后缀（0028题KMP构建逻辑）
            if s[i] == s[j]:
                j += 1
            nxt[i] = j

        min_period_len = n - nxt[n - 1]  # 候选最小重复单元长度
        # nxt[n-1] != 0 说明存在相等前后缀；n能被候选周期长度整除说明能填满整数个周期
        return nxt[n - 1] != 0 and n % min_period_len == 0
```

## 总结

- 移动匹配法的核心洞察是：字符串具有周期性，等价于 `s+s` 掐头去尾后仍能找到完整的 `s`，说白了就是利用了周期性字符串错位重叠后依然自相似的性质。
- KMP 的 next 数组法核心洞察是：整个字符串的最长相等前后缀长度 `next[n-1]`，直接就能给出候选的最小重复单元长度 `n - next[n-1]`；再验证总长度能不能被这个候选长度整除，就能确定是不是真的构成完整周期。
- 这两种方法本质上都是从不同角度刻画"周期性"：移动匹配法是从"整体自重叠"的角度看，KMP法是从"前后缀相等长度"的角度看，殊途同归。
- 这题说到底是对 0028 题 KMP 算法 next 数组含义的一次深化考察——不只是要会用 next 数组做字符串匹配，还得理解 next 数组本身携带的"字符串内部周期结构"信息，这算是 KMP 算法思想的一个重要拓展应用。
