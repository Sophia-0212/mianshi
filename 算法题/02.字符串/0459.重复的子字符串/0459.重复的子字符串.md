# 0459. 重复的子字符串

**题目描述**

给定一个非空字符串 `s`，判断它是否可以由它的一个子串重复多次构成。

```
示例：
输入: s = "abab"
输出: true
解释: 可由子串 "ab" 重复两次构成。

输入: s = "aba"
输出: false

输入: s = "abcabcabcabc"
输出: true
解释: 可由子串 "abc" 重复四次构成，也可由子串 "abcabc" 重复两次构成。
```

## 思路

- 移动匹配：判断 `(s+s)[1:-1]` 是否包含 `s`。时间取决于子串查找实现：朴素匹配 O(n²)，线性匹配 O(n)；空间 O(n)。
- KMP：设 `L=next[n-1]`，候选周期为 `n-L`。满足 `L>0` 且 `n%(n-L)==0` 即可。时间 O(n)，空间 O(n)。



## Python

### LeetCode 写法与原有示例

标准库/简化写法（移动匹配法可以用一行 `in` 运算符判断子串包含）：

```python
class Solution:
    # 方法：repeatedSubstringPattern；按题目要求处理输入并返回结果，核心算法见方法体。
    def repeatedSubstringPattern(self, s: str) -> bool:
        doubled = (s + s)[1:-1]  # 拼接后掐头去尾
        return s in doubled  # in 运算符判断是否包含完整的 s
```


手写实现（面试考察点：KMP的next数组法，还原"最长相等前后缀长度推导最小周期"的核心原理）：

```python
# 依赖说明：len：Python 内置函数：返回容器中元素的数量。；range：Python 内置函数：生成按步长遍历的整数序列。

class Solution:
    # 方法：repeatedSubstringPattern；按题目要求处理输入并返回结果，核心算法见方法体。
    def repeatedSubstringPattern(self, s: str) -> bool:
        n = len(s)
        nxt = [0] * n
        j = 0  # 当前最长相等前后缀的长度
        for i in range(1, n):
            while j > 0 and s[i] != s[j]:
                j = nxt[j - 1]  # 回退到更短的相等前后缀（0028题KMP构建逻辑）
            if s[i] == s[j]:
                j += 1
            nxt[i] = j

        min_period_len = n - nxt[n - 1]  # 候选最小重复单元长度
        # nxt[n-1] != 0 说明存在相等前后缀；n能被候选周期长度整除说明能填满整数个周期
        return nxt[n - 1] != 0 and n % min_period_len == 0
```

// 方法：repeatedSubstringPattern；按题目要求处理输入并返回结果，核心算法见方法体。
func repeatedSubstringPattern(s string) bool {
    doubled := (s + s)[1 : 2*len(s)-1] // 拼接后掐头去尾
    return strings.Contains(doubled, s) // 能找到完整s，说明有周期性
}

// 思路二：KMP next数组法
// 方法：repeatedSubstringPatternKMP；按题目要求处理输入并返回结果，核心算法见方法体。
func repeatedSubstringPatternKMP(s string) bool {
    n := len(s)
    next := make([]int, n)
    j := 0
    for i := 1; i < n; i++ {
        for j > 0 && s[i] != s[j] {
            j = next[j-1] // 回退到更短的相等前后缀
        }
        if s[i] == s[j] {
            j++
        }
        next[i] = j
    }
    length := next[n-1] // 最长相等前后缀长度
    return length != 0 && n%(n-length) == 0 // 能整除说明可被完整周期填满
}

## C++

### LeetCode 写法与原有示例

```cpp
// 依赖说明：vector：C++ STL 动态数组。；string：C++ STL 字符串类型。

class Solution {
public:
    // 思路一：移动匹配法
    // 方法：repeatedSubstringPattern；按题目要求处理输入并返回结果，核心算法见方法体。
    bool repeatedSubstringPattern(string s) {
        string doubled = s + s;
        doubled.erase(doubled.begin());       // 去掉第一个字符
        doubled.erase(doubled.end() - 1);     // 去掉最后一个字符
        return doubled.find(s) != string::npos;  // 掐头去尾后能找到完整s，说明有周期性
    }

    // 思路二：KMP next数组法
    // 方法：repeatedSubstringPatternKMP；按题目要求处理输入并返回结果，核心算法见方法体。
    bool repeatedSubstringPatternKMP(string s) {
        int n = s.size();
        vector<int> next(n, 0);
        int j = 0;
        for (int i = 1; i < n; i++) {
            while (j > 0 && s[i] != s[j]) {
                j = next[j - 1];
            }
            if (s[i] == s[j]) j++;
            next[i] = j;
        }
        int len = next[n - 1];  // 整个字符串的最长相等前后缀长度
        // len!=0 说明有候选周期；n%(n-len)==0 说明能被最小周期长度整除
        return len != 0 && n % (n - len) == 0;
    }
};```

## 总结

- 移动匹配法的核心洞察是：字符串具有周期性，等价于 `s+s` 掐头去尾后仍能找到完整的 `s`，说白了就是利用了周期性字符串错位重叠后依然自相似的性质。
- KMP 的 next 数组法核心洞察是：整个字符串的最长相等前后缀长度 `next[n-1]`，直接就能给出候选的最小重复单元长度 `n - next[n-1]`；再验证总长度能不能被这个候选长度整除，就能确定是不是真的构成完整周期。
- 这两种方法本质上都是从不同角度刻画"周期性"：移动匹配法是从"整体自重叠"的角度看，KMP法是从"前后缀相等长度"的角度看，殊途同归。
- 这题说到底是对 0028 题 KMP 算法 next 数组含义的一次深化考察——不只是要会用 next 数组做字符串匹配，还得理解 next 数组本身携带的"字符串内部周期结构"信息，这算是 KMP 算法思想的一个重要拓展应用。
