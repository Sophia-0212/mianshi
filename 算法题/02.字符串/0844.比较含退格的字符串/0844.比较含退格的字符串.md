# 0844. 比较含退格的字符串

**题目描述**

给定 `s` 和 `t` 两个字符串，当它们分别被输入到空白的文本编辑器后，判断二者是否相等，并返回结果。`#` 代表退格字符。

注意：如果对空文本输入退格字符，文本继续为空。

```
示例 1：
输入: s = "ab#c", t = "ad#c"
输出: true
解释: s 和 t 都会变成 "ac"

示例 2：
输入: s = "ab##", t = "c#d#"
输出: true
解释: s 和 t 都会变成 ""

示例 3：
输入: s = "a#c", t = "b"
输出: false
解释: s 会变成 "c"，但 t 仍然是 "b"
```

## 思路

- 逆向双指针：计数 `#`，跳过被删除字符，再比较两边有效字符；必须同时耗尽。时间 O(n+m)，空间 O(1)。
- 栈模拟：普通字符入栈，`#` 弹栈，最后比较结果。时间 O(n+m)，空间 O(n+m)。



## Python

### LeetCode 写法与原有示例

标准库一行解：Python 没有直接对应"退格语义"的库函数，但可以借助字符串处理技巧，用一个辅助函数模拟栈的过程，再用 `==` 比较两个还原结果，这本质上还是模拟法，不是严格意义上的"库函数捷径"，这里作为对比展示。

```python
class Solution:
    # 方法：backspaceCompare；按题目要求处理输入并返回结果，核心算法见方法体。
    def backspaceCompare(self, s: str, t: str) -> bool:
        # 用列表当栈，reduce 风格地处理每个字符：
        # 遇到普通字符 push，遇到 '#' 且栈非空则 pop
        # 方法：build；按题目要求处理输入并返回结果，核心算法见方法体。
        def build(string: str) -> str:
            stack = []
            for c in string:
                if c != '#':
                    stack.append(c)
                elif stack:
                    stack.pop()
            return ''.join(stack)
        return build(s) == build(t)
```


原理说明：这段代码把栈模拟封装成一个辅助函数，分别处理 `s` 和 `t` 还原出真实文本后再比较，思路简单但用了 O(n + m) 的额外空间来存放两个栈。它更适合用来快速验证正确性或者面试中作为"先给一个直观解法"的开场，但不是本题真正想考察的最优解。

手写实现（面试考察点：从后往前的双指针 + 计数变量消解退格，空间复杂度优化到 O(1) 是这道题的核心亮点）：

```python
# 依赖说明：len：Python 内置函数：返回容器中元素的数量。

class Solution:
    # 方法：backspaceCompare；按题目要求处理输入并返回结果，核心算法见方法体。
    def backspaceCompare(self, s: str, t: str) -> bool:
        # 方法：next_valid_index；按题目要求处理输入并返回结果，核心算法见方法体。
        def next_valid_index(string: str, index: int) -> int:
            # 从 index 开始往前找，返回下一个"真正保留"的字符下标，越界返回 -1
            skip = 0
            while index >= 0:
                if string[index] == '#':
                    skip += 1
                    index -= 1
                elif skip > 0:
                    skip -= 1
                    index -= 1
                else:
                    break
            return index

        i, j = len(s) - 1, len(t) - 1
        while i >= 0 or j >= 0:
            i = next_valid_index(s, i)  # 跳过被退格抵消的字符
            j = next_valid_index(t, j)
            if i >= 0 and j >= 0:
                if s[i] != t[j]:
                    return False  # 字符不同，失败
            elif i >= 0 or j >= 0:
                return False  # 只有一边还有字符，长度不一致
            i -= 1
            j -= 1
        return True
```

func backspaceCompare(s string, t string) bool {
    i, j := len(s)-1, len(t)-1
    skipS, skipT := 0, 0
    for i >= 0 || j >= 0 {
        for i >= 0 {
            if s[i] == '#' {
                skipS++
                i--
            } else if skipS > 0 {
                skipS--
                i--
            } else {
                break
            }
        }
        for j >= 0 {
            if t[j] == '#' {
                skipT++
                j--
            } else if skipT > 0 {
                skipT--
                j--
            } else {
                break
            }
        }

            if s[i] != t[j] {
                return false // 字符不同
            }
        } else if i >= 0 || j >= 0 {
            return false // 长度不一致
        }
        i--
        j--
    }
    return true
}

## C++

### LeetCode 写法与原有示例

```cpp
// 依赖说明：string：C++ STL 字符串类型。

class Solution {
public:
    // 方法：backspaceCompare；按题目要求处理输入并返回结果，核心算法见方法体。
    bool backspaceCompare(string s, string t) {
        int i = s.size() - 1, j = t.size() - 1;
        int skipS = 0, skipT = 0;
        while (i >= 0 || j >= 0) {
            // 跳过 s 中被退格抵消的字符，找到下一个真正保留的字符
            while (i >= 0) {
                if (s[i] == '#') { skipS++; i--; }
                // 方法：if；按题目要求处理输入并返回结果，核心算法见方法体。
                else if (skipS > 0) { skipS--; i--; }
                else break;
            }
            // 跳过 t 中被退格抵消的字符
            while (j >= 0) {
                if (t[j] == '#') { skipT++; j--; }
                // 方法：if；按题目要求处理输入并返回结果，核心算法见方法体。
                else if (skipT > 0) { skipT--; j--; }
                else break;
            }
            if (i >= 0 && j >= 0) {
                if (s[i] != t[j]) return false; // 当前保留字符不同，直接失败
            } else if (i >= 0 || j >= 0) {
                return false; // 一个还有剩余字符，另一个已经处理完，长度不一致
            }
            i--; j--; // 两边都匹配上了，继续往前比较
        }
        return true; // 全程比对完毕，未发现不一致
    }
};```

## 总结

- 这题的核心突破点是发现"退格只影响它前面的字符"这个单向性质，从后往前扫描就能立刻确定每个 `#` 抵消的对象，不需要像正向扫描那样非得靠栈来"记住"之前的字符再回头处理。
- 用栈模拟是更容易想到的直觉解法，时间复杂度同样是 O(n+m)，但要额外花 O(n+m) 的空间来存处理后的字符序列；双指针解法把这部分空间优化到了 O(1)，是"用两个计数变量代替一个数据结构"的典型空间优化范例。
- 双指针内层的 while 循环容易让人误以为整体复杂度会变成 O(n²)，但你想啊，因为每个字符在整个过程中只会被访问常数次（被判定为跳过，或者被判定为保留字符），所以均摊下来总时间复杂度还是线性的 O(n+m)。
- 比较两个指针的时候要注意三种情况得全覆盖：两边都有剩余字符且字符相同（继续比较）、字符不同（直接失败）、只有一边有剩余字符（说明退格处理后长度不同，失败），漏掉任何一种情况都可能导致边界出错。
