# 0844. 比较含退格的字符串

**题目描述**

给定 `s` 和 `t` 两个字符串，当它们分别被输入到空白的文本编辑器后，判断二者是否相等，并返回结果。`#` 代表退格字符。

注意：如果对空文本输入退格字符，文本继续为空。

```
示例 1：
输入: s = "ab#c", t = "ad#c"
输出: true
解释: s 和 t 都会变成 "ac"

示例 2：
输入: s = "ab##", t = "c#d#"
输出: true
解释: s 和 t 都会变成 ""

示例 3：
输入: s = "a#c", t = "b"
输出: false
解释: s 会变成 "c"，但 t 仍然是 "b"
```

## 思路

这题最直接的想法是"模拟"：用一个栈从前往后扫描字符串，遇到普通字符就入栈，遇到 `#` 就弹出栈顶（如果栈不为空）。扫描完之后，栈里剩下的内容就是这个字符串退格处理后的最终结果。对 `s` 和 `t` 分别做一遍这个模拟，再比较两个栈（或者还原出的字符串）是不是相等就行了。这个做法很直观，时间复杂度 O(n)，但需要额外 O(n) 的空间来放栈。

那有没有办法不用额外的栈空间呢？这里的关键观察是：**`#` 只会影响它前面的字符，不会影响它后面的字符**。也就是说，如果咱们从字符串末尾往前扫描，就能立刻知道当前遇到的 `#` 要抵消前面几个字符，不需要等扫描完全部字符后再回头处理。这正是"从后往前双指针"的核心思路。

具体来说，维护两个指针 `i`、`j` 分别指向 `s` 和 `t` 的末尾，同时维护两个"待跳过计数" `skipS`、`skipT`。每一轮，从后往前处理一个字符串的指针时：

1. 不断向前移动指针：如果当前字符是 `#`，说明它要抵消掉前面一个字符，`skip` 计数加一，指针左移；如果当前 `skip > 0`（说明前面还欠着退格的账），说明当前字符会被后面某个 `#` 抵消掉，`skip` 减一，指针左移，跳过这个字符；否则的话（当前字符是普通字符且 `skip == 0`），说明这个字符是真正会被保留下来的字符，停止移动，指针就停在这个位置。
2. 对 `s` 和 `t` 都做完上面这个"跳过退格影响"的处理后，比较两个指针当前指向的字符：如果两者都已经越过字符串开头（都变成 -1，说明两个字符串都处理完了），说明目前为止完全匹配，继续下一轮；如果一个越界另一个没有，说明长度不一致，返回 false；如果两者都还在字符串内但字符不同，也返回 false。
3. 如果字符相同，两个指针都左移一位，继续下一轮比较，一直做到某一方或两方都处理完。

拿个具体例子过一遍：`s = "a#c"`，`t = "b"`。`i` 从末尾开始指向 `c`（下标 2），`skipS = 0`，`c` 是普通字符且 `skip==0`，停在这里；`j` 从末尾指向 `b`（下标 0），`skipT = 0`，停在这里。比较 `s[i]='c'` 和 `t[j]='b'`，不相等，返回 false。这跟直接模拟得到的结果 `"c"` vs `"b"` 是一致的。

再看一个带退格连续消解的例子：`s = "ab##"`。从后往前看：下标 3 是 `#`，`skipS` 从 0 变 1，指针左移到下标 2；下标 2 也是 `#`，`skipS` 从 1 变 2，指针左移到下标 1；下标 1 是 `b`，这时候 `skipS=2>0`，说明这个 `b` 要被消掉，`skipS` 减到 1，指针左移到下标 0；下标 0 是 `a`，`skipS=1>0`，`a` 也被消掉，`skipS` 减到 0，指针左移到 -1，越界。最终 `i=-1`，代表 `s` 处理后是空字符串，跟直接模拟的结果一致。

时间复杂度这块，虽然每一轮比较里都有一个内层的 while 循环在跳字符，但你想啊，每个字符最多只会被访问一次（要么是普通字符被访问一次然后跳过，要么是 `#` 被访问一次），所以总的时间复杂度仍然是 O(n + m)，跟用栈模拟的复杂度一样，但空间复杂度从 O(n + m) 降到了 O(1)（只用了几个指针和计数变量，没有额外数组或栈）。这就是双指针解法相对于栈模拟解法的核心优势：**同样的时间复杂度下，用常数空间替代了线性空间**，是个典型的空间优化案例。

## 代码

### C++

```cpp
class Solution {
public:
    bool backspaceCompare(string s, string t) {
        int i = s.size() - 1, j = t.size() - 1;
        int skipS = 0, skipT = 0;
        while (i >= 0 || j >= 0) {
            // 跳过 s 中被退格抵消的字符，找到下一个真正保留的字符
            while (i >= 0) {
                if (s[i] == '#') { skipS++; i--; }
                else if (skipS > 0) { skipS--; i--; }
                else break;
            }
            // 跳过 t 中被退格抵消的字符
            while (j >= 0) {
                if (t[j] == '#') { skipT++; j--; }
                else if (skipT > 0) { skipT--; j--; }
                else break;
            }
            if (i >= 0 && j >= 0) {
                if (s[i] != t[j]) return false; // 当前保留字符不同，直接失败
            } else if (i >= 0 || j >= 0) {
                return false; // 一个还有剩余字符，另一个已经处理完，长度不一致
            }
            i--; j--; // 两边都匹配上了，继续往前比较
        }
        return true; // 全程比对完毕，未发现不一致
    }
};
```

### Java

```java
class Solution {
    public boolean backspaceCompare(String s, String t) {
        int i = s.length() - 1, j = t.length() - 1;
        int skipS = 0, skipT = 0;
        while (i >= 0 || j >= 0) {
            while (i >= 0) {
                if (s.charAt(i) == '#') { skipS++; i--; }
                else if (skipS > 0) { skipS--; i--; }
                else break;
            }
            while (j >= 0) {
                if (t.charAt(j) == '#') { skipT++; j--; }
                else if (skipT > 0) { skipT--; j--; }
                else break;
            }
            if (i >= 0 && j >= 0) {
                if (s.charAt(i) != t.charAt(j)) return false;
            } else if (i >= 0 || j >= 0) {
                return false; // 长度不一致
            }
            i--; j--;
        }
        return true;
    }
}
```

### Python

标准库一行解：Python 没有直接对应"退格语义"的库函数，但可以借助字符串处理技巧，用一个辅助函数模拟栈的过程，再用 `==` 比较两个还原结果，这本质上还是模拟法，不是严格意义上的"库函数捷径"，这里作为对比展示。

```python
class Solution:
    def backspaceCompare(self, s: str, t: str) -> bool:
        # 用列表当栈，reduce 风格地处理每个字符：
        # 遇到普通字符 push，遇到 '#' 且栈非空则 pop
        def build(string: str) -> str:
            stack = []
            for c in string:
                if c != '#':
                    stack.append(c)
                elif stack:
                    stack.pop()
            return ''.join(stack)
        return build(s) == build(t)
```

原理说明：这段代码把栈模拟封装成一个辅助函数，分别处理 `s` 和 `t` 还原出真实文本后再比较，思路简单但用了 O(n + m) 的额外空间来存放两个栈。它更适合用来快速验证正确性或者面试中作为"先给一个直观解法"的开场，但不是本题真正想考察的最优解。

手写实现（面试考察点：从后往前的双指针 + 计数变量消解退格，空间复杂度优化到 O(1) 是这道题的核心亮点）：

```python
class Solution:
    def backspaceCompare(self, s: str, t: str) -> bool:
        def next_valid_index(string: str, index: int) -> int:
            # 从 index 开始往前找，返回下一个"真正保留"的字符下标，越界返回 -1
            skip = 0
            while index >= 0:
                if string[index] == '#':
                    skip += 1
                    index -= 1
                elif skip > 0:
                    skip -= 1
                    index -= 1
                else:
                    break
            return index

        i, j = len(s) - 1, len(t) - 1
        while i >= 0 or j >= 0:
            i = next_valid_index(s, i)  # 跳过被退格抵消的字符
            j = next_valid_index(t, j)
            if i >= 0 and j >= 0:
                if s[i] != t[j]:
                    return False  # 字符不同，失败
            elif i >= 0 or j >= 0:
                return False  # 只有一边还有字符，长度不一致
            i -= 1
            j -= 1
        return True
```

## 总结

- 这题的核心突破点是发现"退格只影响它前面的字符"这个单向性质，从后往前扫描就能立刻确定每个 `#` 抵消的对象，不需要像正向扫描那样非得靠栈来"记住"之前的字符再回头处理。
- 用栈模拟是更容易想到的直觉解法，时间复杂度同样是 O(n+m)，但要额外花 O(n+m) 的空间来存处理后的字符序列；双指针解法把这部分空间优化到了 O(1)，是"用两个计数变量代替一个数据结构"的典型空间优化范例。
- 双指针内层的 while 循环容易让人误以为整体复杂度会变成 O(n²)，但你想啊，因为每个字符在整个过程中只会被访问常数次（被判定为跳过，或者被判定为保留字符），所以均摊下来总时间复杂度还是线性的 O(n+m)。
- 比较两个指针的时候要注意三种情况得全覆盖：两边都有剩余字符且字符相同（继续比较）、字符不同（直接失败）、只有一边有剩余字符（说明退格处理后长度不同，失败），漏掉任何一种情况都可能导致边界出错。
