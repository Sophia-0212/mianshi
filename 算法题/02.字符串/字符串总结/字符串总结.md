# 字符串总结

| 方法 | 核心操作 | 时间 | 辅助空间 |
|---|---|---|---|
| 双指针反转 | 两端交换并内移 | O(n) | O(1) |
| 分段反转 | 每隔 2k 反转前 k 位 | O(n) | O(1) |
| 三步反转 | 整体反转，再反转各段，改变段序而保持段内顺序 | O(n) | O(1) |
| 扩容填充 | 先算新长度，从后往前写，避免覆盖 | O(n) | O(1)，不计结果存储 |
| KMP | 构建前缀函数，失配回退，主串不回退 | O(n+m) | O(m) |

原地空间结论针对可变字符数组；转数组、切片或拼接通常需 O(n) 空间。

- 翻转单词：去多余空格→整体反转→逐词反转。
- 右旋 k 位：`k%=n`，整体反转→前 k 位反转→余段反转。
- 重复子串：设 `L=pi[n-1]`，满足 `L>0 && n%(n-L)==0`；也可判断 `(s+s)[1:-1]` 是否包含 s。
