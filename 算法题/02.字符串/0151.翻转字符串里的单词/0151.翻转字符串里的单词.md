# 0151. 翻转字符串里的单词

**题目描述**

给定一个字符串 `s`，反转字符串中单词的顺序。单词之间用一个或多个空格分隔，字符串前后可能有多余的空格。要求返回的结果中，单词之间只保留一个空格，且首尾不能有空格。

```
示例：
输入: s = "  hello   world  "
输出: "world hello"

输入: s = "a good   example"
输出: "example good a"
```

## 思路

这题最直接的做法是"按空格切分成单词列表，反转列表，再拼接"，但你想啊，如果面试官要求 O(1) 额外空间（也就是不能用 split 这种会产生额外数组的操作），那就得用**三步反转法**了，这也是这题的核心考点。

三步反转法的思路是这样的：
1. **去除多余空格**：把字符串中每个单词之间的多个空格压缩成一个，同时去掉首尾空格。
2. **整体反转**：把去除多余空格后的整个字符串反转一次。比如 `"hello world"` 整体反转变成 `"dlrow olleh"`——这时候单词顺序是对了（world 在前，hello 在后），但每个单词内部的字符顺序反了。
3. **单词内反转**：再遍历一次字符串，把每个单词（以空格为分界）内部的字符再反转一次，恢复正常的单词拼写。比如 `"dlrow olleh"` 里的 `"dlrow"` 反转回 `"world"`，`"olleh"` 反转回 `"hello"`，最终就得到 `"world hello"`。

这里的关键决策点是**为什么整体反转+局部反转能等价于"反转单词顺序"**：你想，整体反转会把"单词顺序"和"单词内字符顺序"同时反转，但我们只想反转单词顺序、不想动单词内部的字符顺序，所以得再对每个单词做一次局部反转，把内部字符顺序"反回来"——两次反转叠加的效果正好抵消了内部顺序的错误，只留下了单词顺序的反转。说白了这和 0541 题、kama55 题用的是同一个"三步反转法"框架，只是应用场景不一样。

去除多余空格这一步，同样可以用**双指针原地移除**的技巧（跟移除元素类问题很像）：用一个慢指针 `slow` 记录写入位置，快指针 `fast` 遍历原字符串，只有在"当前字符不是空格"或者"当前字符是空格但前一个已写入的字符不是空格（也就是单词与单词的分界处保留一个空格）"这两种情况下，才把字符写入 `slow` 位置。

复杂度分析：去空格、整体反转、单词内反转都是线性扫描，时间复杂度 O(n)；C++/Java（转成 char 数组）/Go 可以做到真正的 O(1) 额外空间原地操作，但 Python 字符串不可变，标准库解法或者转 list 操作都会引入 O(n) 空间。

## 代码

### C++

```cpp
class Solution {
public:
    string reverseWords(string s) {
        removeExtraSpaces(s);           // 第一步：去除多余空格
        reverse(s.begin(), s.end());    // 第二步：整体反转
        reverseEachWord(s);             // 第三步：单词内部再反转一次
        return s;
    }

private:
    // 双指针原地去除多余空格：压缩连续空格为一个，去除首尾空格
    void removeExtraSpaces(string& s) {
        int slow = 0;
        for (int fast = 0; fast < s.size(); fast++) {
            if (s[fast] != ' ') {  // 遇到非空格字符，直接写入
                if (slow != 0) s[slow++] = ' ';  // 单词间补一个分隔空格（非首个单词）
                while (fast < s.size() && s[fast] != ' ') {
                    s[slow++] = s[fast++];  // 整个单词依次写入
                }
            }
        }
        s.resize(slow);  // 截断到有效长度
    }

    // 对每个单词（以空格分界）做局部反转，恢复单词内部字符顺序
    void reverseEachWord(string& s) {
        int start = 0;
        for (int i = 0; i <= s.size(); i++) {
            if (i == s.size() || s[i] == ' ') {
                reverse(s.begin() + start, s.begin() + i);  // 反转 [start, i) 这个单词
                start = i + 1;
            }
        }
    }
};
```

### Java

```java
class Solution {
    public String reverseWords(String s) {
        StringBuilder sb = removeExtraSpaces(s);  // 第一步：去除多余空格
        reverse(sb, 0, sb.length() - 1);          // 第二步：整体反转
        reverseEachWord(sb);                       // 第三步：单词内部再反转
        return sb.toString();
    }

    // 去除多余空格，返回压缩后的 StringBuilder
    private StringBuilder removeExtraSpaces(String s) {
        int left = 0, right = s.length() - 1;
        while (left <= right && s.charAt(left) == ' ') left++;   // 跳过前导空格
        while (left <= right && s.charAt(right) == ' ') right--; // 跳过尾部空格
        StringBuilder sb = new StringBuilder();
        while (left <= right) {
            char c = s.charAt(left);
            if (c != ' ' || sb.charAt(sb.length() - 1) != ' ') {  // 非空格，或空格但前一个不是空格才保留
                sb.append(c);
            }
            left++;
        }
        return sb;
    }

    // 反转 [start, end] 区间字符（344题双指针反转模板）
    private void reverse(StringBuilder sb, int start, int end) {
        while (start < end) {
            char tmp = sb.charAt(start);
            sb.setCharAt(start, sb.charAt(end));
            sb.setCharAt(end, tmp);
            start++;
            end--;
        }
    }

    // 遍历找到每个单词的边界，逐个反转恢复单词内部顺序
    private void reverseEachWord(StringBuilder sb) {
        int start = 0;
        for (int i = 0; i <= sb.length(); i++) {
            if (i == sb.length() || sb.charAt(i) == ' ') {
                reverse(sb, start, i - 1);
                start = i + 1;
            }
        }
    }
}
```

### Python

标准库一行解（`split()` 不带参数会自动按任意空白切分并丢弃空字符串，再反转拼接）：

```python
class Solution:
    def reverseWords(self, s: str) -> str:
        return ' '.join(s.split()[::-1])  # split()自动去除多余空格和首尾空格
```

手写实现（面试考察点：还原三步反转法——去空格、整体反转、单词内反转。因为 Python 字符串不可变，这里用 list 模拟原地过程）：

```python
class Solution:
    def reverseWords(self, s: str) -> str:
        arr = self._remove_extra_spaces(list(s))  # 第一步：去除多余空格
        arr = self._reverse(arr, 0, len(arr) - 1)  # 第二步：整体反转
        arr = self._reverse_each_word(arr)         # 第三步：单词内部再反转
        return ''.join(arr)

    def _remove_extra_spaces(self, arr: list[str]) -> list[str]:
        slow = 0
        fast = 0
        n = len(arr)
        while fast < n:
            if arr[fast] != ' ':
                if slow != 0:
                    arr[slow] = ' '  # 单词间补一个分隔空格
                    slow += 1
                while fast < n and arr[fast] != ' ':
                    arr[slow] = arr[fast]  # 整个单词依次写入
                    slow += 1
                    fast += 1
            else:
                fast += 1
        return arr[:slow]  # 截断到有效长度

    def _reverse(self, arr: list[str], left: int, right: int) -> list[str]:
        while left < right:  # 344题双指针反转模板
            arr[left], arr[right] = arr[right], arr[left]
            left += 1
            right -= 1
        return arr

    def _reverse_each_word(self, arr: list[str]) -> list[str]:
        start = 0
        n = len(arr)
        for i in range(n + 1):
            if i == n or arr[i] == ' ':
                self._reverse(arr, start, i - 1)  # 反转 [start, i-1] 这个单词
                start = i + 1
        return arr
```

### Go

```go
func reverseWords(s string) string {
    arr := removeExtraSpaces([]byte(s)) // 第一步：去除多余空格
    reverse(arr, 0, len(arr)-1)         // 第二步：整体反转
    reverseEachWord(arr)                // 第三步：单词内部再反转
    return string(arr)
}

// 双指针原地去除多余空格
func removeExtraSpaces(arr []byte) []byte {
    slow, fast := 0, 0
    n := len(arr)
    for fast < n {
        if arr[fast] != ' ' {
            if slow != 0 {
                arr[slow] = ' ' // 单词间补一个分隔空格
                slow++
            }
            for fast < n && arr[fast] != ' ' {
                arr[slow] = arr[fast] // 整个单词依次写入
                slow++
                fast++
            }
        } else {
            fast++
        }
    }
    return arr[:slow] // 截断到有效长度
}

// 反转 [left, right] 区间（344题双指针反转模板）
func reverse(arr []byte, left, right int) {
    for left < right {
        arr[left], arr[right] = arr[right], arr[left]
        left++
        right--
    }
}

// 遍历找到每个单词边界，逐个反转恢复内部字符顺序
func reverseEachWord(arr []byte) {
    start := 0
    n := len(arr)
    for i := 0; i <= n; i++ {
        if i == n || arr[i] == ' ' {
            reverse(arr, start, i-1)
            start = i + 1
        }
    }
}
```

## 总结

- 三步反转法（去空格 → 整体反转 → 单词内反转）是这题避免使用 `split` 类操作、实现 O(1) 额外空间的标准解法。
- 整体反转会把单词顺序和单词内部字符顺序同时反转，单词内反转就是专门用来抵消"内部字符顺序被反转"这个副作用的，两次反转叠加，只留下"单词顺序反转"的效果。
- 去除多余空格用的双指针写入技巧，跟"移除元素"类问题（比如快慢指针原地删除）其实是同一套思路：快指针负责读，慢指针负责写，只有满足条件才前移写指针。
- Python 由于字符串不可变，手写版本得转成 list 来模拟原地操作；标准库的 `split()[::-1]` 一行解已经隐含处理了多余空格的问题，代码最简洁，但也牺牲了对底层原理的展示。
