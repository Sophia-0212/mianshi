# 0151. 翻转字符串里的单词

**题目描述**

给定一个字符串 `s`，反转字符串中单词的顺序。单词之间用一个或多个空格分隔，字符串前后可能有多余的空格。要求返回的结果中，单词之间只保留一个空格，且首尾不能有空格。

```
示例：
输入: s = "  hello   world  "
输出: "world hello"

输入: s = "a good   example"
输出: "example good a"
```

## 思路

- 三步反转：去多余空格，整体反转，再逐词反转。整体反转改变词序，逐词反转恢复拼写。时间 O(n)；可变字符数组辅助空间 O(1)，Python/Go 转换字符串需 O(n) 空间。
- 分割拼接：按空白分词，逆序后用单空格连接。时间 O(n)，空间 O(n)。

手写实现（面试考察点：还原三步反转法——去空格、整体反转、单词内反转。因为 Python 字符串不可变，这里用 list 模拟原地过程）：

```python
# 依赖说明：len：Python 内置函数：返回容器中元素的数量。；range：Python 内置函数：生成按步长遍历的整数序列。

class Solution:
    # 方法：reverseWords；按题目要求处理输入并返回结果，核心算法见方法体。
    def reverseWords(self, s: str) -> str:
        arr = self._remove_extra_spaces(list(s))  # 第一步：去除多余空格
        arr = self._reverse(arr, 0, len(arr) - 1)  # 第二步：整体反转
        arr = self._reverse_each_word(arr)         # 第三步：单词内部再反转
        return ''.join(arr)

    # 方法：_remove_extra_spaces；按题目要求处理输入并返回结果，核心算法见方法体。
    def _remove_extra_spaces(self, arr: list[str]) -> list[str]:
        slow = 0
        fast = 0
        n = len(arr)
        while fast < n:
            if arr[fast] != ' ':
                if slow != 0:
                    arr[slow] = ' '  # 单词间补一个分隔空格
                    slow += 1
                while fast < n and arr[fast] != ' ':
                    arr[slow] = arr[fast]  # 整个单词依次写入
                    slow += 1
                    fast += 1
            else:
                fast += 1
        return arr[:slow]  # 截断到有效长度

    # 方法：_reverse；按题目要求处理输入并返回结果，核心算法见方法体。
    def _reverse(self, arr: list[str], left: int, right: int) -> list[str]:
        while left < right:  # 344题双指针反转模板
            arr[left], arr[right] = arr[right], arr[left]
            left += 1
            right -= 1
        return arr

    # 方法：_reverse_each_word；按题目要求处理输入并返回结果，核心算法见方法体。
    def _reverse_each_word(self, arr: list[str]) -> list[str]:
        start = 0
        n = len(arr)
        for i in range(n + 1):
            if i == n or arr[i] == ' ':
                self._reverse(arr, start, i - 1)  # 反转 [start, i-1] 这个单词
                start = i + 1
        return arr
```

## C++

### LeetCode 写法与原有示例

```cpp
// 依赖说明：string：C++ STL 字符串类型。

class Solution {
public:
    // 方法：reverseWords；按题目要求处理输入并返回结果，核心算法见方法体。
    string reverseWords(string s) {
        removeExtraSpaces(s);           // 第一步：去除多余空格
        reverse(s.begin(), s.end());    // 第二步：整体反转
        reverseEachWord(s);             // 第三步：单词内部再反转一次
        return s;
    }

private:
    // 双指针原地去除多余空格：压缩连续空格为一个，去除首尾空格
    // 方法：removeExtraSpaces；按题目要求处理输入并返回结果，核心算法见方法体。
    void removeExtraSpaces(string& s) {
        int slow = 0;
        for (int fast = 0; fast < s.size(); fast++) {
            if (s[fast] != ' ') {  // 遇到非空格字符，直接写入
                if (slow != 0) s[slow++] = ' ';  // 单词间补一个分隔空格（非首个单词）
                while (fast < s.size() && s[fast] != ' ') {
                    s[slow++] = s[fast++];  // 整个单词依次写入
                }
            }
        }
        s.resize(slow);  // 截断到有效长度
    }

    // 对每个单词（以空格分界）做局部反转，恢复单词内部字符顺序
    // 方法：reverseEachWord；按题目要求处理输入并返回结果，核心算法见方法体。
    void reverseEachWord(string& s) {
        int start = 0;
        for (int i = 0; i <= s.size(); i++) {
            if (i == s.size() || s[i] == ' ') {
                reverse(s.begin() + start, s.begin() + i);  // 反转 [start, i) 这个单词
                start = i + 1;
            }
        }
    }
};```

## 总结

- 三步反转法（去空格 → 整体反转 → 单词内反转）是这题避免使用 `split` 类操作、实现 O(1) 额外空间的标准解法。
- 整体反转会把单词顺序和单词内部字符顺序同时反转，单词内反转就是专门用来抵消"内部字符顺序被反转"这个副作用的，两次反转叠加，只留下"单词顺序反转"的效果。
- 去除多余空格用的双指针写入技巧，跟"移除元素"类问题（比如快慢指针原地删除）其实是同一套思路：快指针负责读，慢指针负责写，只有满足条件才前移写指针。
- Python 由于字符串不可变，手写版本得转成 list 来模拟原地操作；标准库的 `split()[::-1]` 一行解已经隐含处理了多余空格的问题，代码最简洁，但也牺牲了对底层原理的展示。
