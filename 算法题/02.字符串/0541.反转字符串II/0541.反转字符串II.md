# 0541. 反转字符串II

**题目描述**

给定一个字符串 `s` 和一个整数 `k`，从字符串开头算起，每隔 `2k` 个字符，就反转这 `2k` 字符中的前 `k` 个字符。

- 如果剩余字符少于 `k` 个，则将剩余字符全部反转。
- 如果剩余字符小于 `2k` 但大于或等于 `k` 个，则反转前 `k` 个字符，其余字符保持原样。

```
示例：
输入: s = "abcdefg", k = 2
输出: "bacdfeg"

解释：
按 2k=4 分组："abcd" "efg"
第一组反转前 k=2 个字符："ab"->"ba"，得到 "bacd"
第二组剩余 3 个字符（>=k 但 <2k），反转前 k=2 个字符："ef"->"fe"，得到 "feg"
拼接结果："bacdfeg"
```

## 思路

这题本质上就是 344 题双指针反转的**升级版**：核心反转逻辑没变，只是不再对整个字符串反转，而是按固定步长 `2k` 跳跃着遍历字符串，每次只反转当前区间里的前 `k` 个字符。

关键决策点在哪呢？在**遍历步长和区间边界的计算**上。可以用一个指针 `i` 以 `2k` 为步长遍历字符串（`i = 0, 2k, 4k, ...`），对每个 `i`，需要反转的区间就是 `[i, i+k-1]`。这里有三种情况得统一处理一下：

1. 从 `i` 到字符串末尾剩余字符数 `>= 2k`：正常反转 `[i, i+k-1]`。
2. 剩余字符数落在 `[k, 2k)` 之间：只反转前 `k` 个，也就是 `[i, i+k-1]`，后面的字符不用管，反正这次循环也碰不到它们。
3. 剩余字符数 `< k`：这时候反转区间应该是 `[i, len(s)-1]`，把剩下的全部反转掉。

这三种情况其实可以统一成一行代码：反转区间的右边界取 `min(i+k-1, len(s)-1)`。这样就不用写三个 if 分支了，逻辑更简洁——你想啊，无论剩余字符是多是少，"反转到 `i+k-1` 或者反转到字符串末尾（谁先到谁说了算）"这句话本身就已经把三种情况都概括进去了。

还有个细节：不需要真的一步步跳到 `i+2k` 再处理，直接让循环变量 `i` 以 `2k` 为步长自增（`i += 2*k`）就行，中间被跳过的 `k` 到 `2k-1` 这段字符天然保持原样，不用额外写代码处理。

复杂度分析：设字符串长度为 `n`，总共大概有 `n/(2k)` 个分组，每组反转最多 `k` 个字符，所以总的反转操作次数是 `O(n/(2k) * k) = O(n)`；空间复杂度上，C++/Java/Go 因为字符串或字符数组可变（或者可以转成可变结构），能做到 O(1) 额外空间，但 Python 字符串是不可变的，转成 list 操作后就需要 O(n) 空间来存中间结果了。

## 代码

### C++

```cpp
class Solution {
public:
    string reverseStr(string s, int k) {
        for (int i = 0; i < s.size(); i += 2 * k) {  // 以 2k 为步长跳跃遍历
            // 反转区间右边界取 min(i+k-1, size-1)，统一处理三种剩余长度情况
            int left = i;
            int right = min(i + k - 1, (int)s.size() - 1);
            while (left < right) {  // 344题双指针反转模板
                swap(s[left], s[right]);
                left++;
                right--;
            }
        }
        return s;
    }
};
```

### Java

```java
class Solution {
    public String reverseStr(String s, int k) {
        char[] arr = s.toCharArray();  // Java String 不可变，先转成字符数组
        for (int i = 0; i < arr.length; i += 2 * k) {  // 以 2k 为步长跳跃遍历
            int left = i;
            int right = Math.min(i + k - 1, arr.length - 1);  // 统一处理三种剩余长度
            while (left < right) {  // 344题双指针反转模板
                char tmp = arr[left];
                arr[left] = arr[right];
                arr[right] = tmp;
                left++;
                right--;
            }
        }
        return new String(arr);
    }
}
```

### Python

标准库一行解（利用切片对每个 `2k` 分组做局部反转，再拼接）：

```python
class Solution:
    def reverseStr(self, s: str, k: int) -> str:
        # 把字符串按 2k 切片，每片的前 k 个字符反转，拼接所有片段
        return ''.join(
            chunk[:k][::-1] + chunk[k:]  # 前k个反转+剩余部分原样（切片天然处理越界，不会报错）
            for chunk in (s[i:i + 2 * k] for i in range(0, len(s), 2 * k))
        )
```

手写实现（面试考察点：还原双指针反转 + 步长跳跃遍历，这是"分组处理"类问题的通用套路）：

```python
class Solution:
    def reverseStr(self, s: str, k: int) -> str:
        arr = list(s)  # Python字符串不可变，先转成list以便原地交换
        n = len(arr)
        for i in range(0, n, 2 * k):  # 以 2k 为步长跳跃遍历
            left = i
            right = min(i + k - 1, n - 1)  # 统一处理三种剩余长度情况
            while left < right:  # 344题双指针反转模板
                arr[left], arr[right] = arr[right], arr[left]
                left += 1
                right -= 1
        return ''.join(arr)
```

### Go

```go
func reverseStr(s string, k int) string {
    arr := []byte(s) // string 转 []byte 以便原地修改
    n := len(arr)
    for i := 0; i < n; i += 2 * k { // 以 2k 为步长跳跃遍历
        left := i
        right := i + k - 1
        if right > n-1 {
            right = n - 1 // 统一处理三种剩余长度情况
        }
        for left < right { // 344题双指针反转模板
            arr[left], arr[right] = arr[right], arr[left]
            left++
            right--
        }
    }
    return string(arr)
}
```

## 总结

- 这题就是 344 题双指针反转的直接复用，唯一新增的能力是"按固定步长跳跃遍历 + 计算每次反转的右边界"。
- 反转区间右边界统一写成 `min(i+k-1, n-1)`，这样能避免针对"剩余 <k"、"剩余在[k,2k)"、"剩余>=2k"这三种情况分别写分支判断，这也是处理分组边界问题时常用的简化技巧。
- 步长为 `2k` 的循环天然就跳过了不需要反转的后 `k` 个字符，不用额外写代码处理"保持原样"的部分。
- Python 因为字符串不可变，无论是库解的拼接方式还是手写的双指针方式，都得生成新对象或者转成 list，这也是它跟 C++/Java/Go 原地操作的本质区别所在。
