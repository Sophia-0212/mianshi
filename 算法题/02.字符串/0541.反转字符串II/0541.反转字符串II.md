# 0541. 反转字符串II

**题目描述**

给定一个字符串 `s` 和一个整数 `k`，从字符串开头算起，每隔 `2k` 个字符，就反转这 `2k` 字符中的前 `k` 个字符。

- 如果剩余字符少于 `k` 个，则将剩余字符全部反转。
- 如果剩余字符小于 `2k` 但大于或等于 `k` 个，则反转前 `k` 个字符，其余字符保持原样。

```
示例：
输入: s = "abcdefg", k = 2
输出: "bacdfeg"

解释：
按 2k=4 分组："abcd" "efg"
第一组反转前 k=2 个字符："ab"->"ba"，得到 "bacd"
第二组剩余 3 个字符（>=k 但 <2k），反转前 k=2 个字符："ef"->"fe"，得到 "feg"
拼接结果："bacdfeg"
```

## 思路

每隔 `2k` 个字符，用双指针反转区间 `[i,min(i+k,n)-1]`；不足 `k` 个全部反转。

时间 O(n)；可变字符数组辅助空间 O(1)，Python/Go 转换字符串需 O(n) 空间。

### LeetCode 写法与原有示例

标准库一行解（利用切片对每个 `2k` 分组做局部反转，再拼接）：

```python
# 依赖说明：len：Python 内置函数：返回容器中元素的数量。；range：Python 内置函数：生成按步长遍历的整数序列。

class Solution:
    # 方法：reverseStr；按题目要求处理输入并返回结果，核心算法见方法体。
    def reverseStr(self, s: str, k: int) -> str:
        # 把字符串按 2k 切片，每片的前 k 个字符反转，拼接所有片段
        return ''.join(
            chunk[:k][::-1] + chunk[k:]  # 前k个反转+剩余部分原样（切片天然处理越界，不会报错）
            for chunk in (s[i:i + 2 * k] for i in range(0, len(s), 2 * k))
        )```


手写实现（面试考察点：还原双指针反转 + 步长跳跃遍历，这是"分组处理"类问题的通用套路）：

```python
# 依赖说明：len：Python 内置函数：返回容器中元素的数量。；range：Python 内置函数：生成按步长遍历的整数序列。；min：Python 内置函数：返回最小值。

# 依赖说明：len：Python 内置函数：返回容器中元素的数量。；range：Python 内置函数：生成按步长遍历的整数序列。

class Solution:
    # 方法：reverseStr；按题目要求处理输入并返回结果，核心算法见方法体。
    def reverseStr(self, s: str, k: int) -> str:
        arr = list(s)  # Python字符串不可变，先转成list以便原地交换
        n = len(arr)
        for i in range(0, n, 2 * k):  # 以 2k 为步长跳跃遍历
            left = i
            right = min(i + k - 1, n - 1)  # 统一处理三种剩余长度情况
            while left < right:  # 344题双指针反转模板
                arr[left], arr[right] = arr[right], arr[left]
                left += 1
                right -= 1
        return ''.join(arr)```

### LeetCode 写法与原有示例

// 方法：reverseStr；按题目要求处理输入并返回结果，核心算法见方法体。
func reverseStr(s string, k int) string {
    arr := []byte(s) // string 转 []byte 以便原地修改
    n := len(arr)
    for i := 0; i < n; i += 2 * k { // 以 2k 为步长跳跃遍历
        left := i
        right := i + k - 1
        if right > n-1 {
            right = n - 1 // 统一处理三种剩余长度情况
        }
        for left < right { // 344题双指针反转模板
            arr[left], arr[right] = arr[right], arr[left]
            left++
            right--
        }
    }
    return string(arr)
}
```

## C++

### LeetCode 写法与原有示例

```cpp
class Solution {
public:
    // 方法：reverseStr；按题目要求处理输入并返回结果，核心算法见方法体。
    string reverseStr(string s, int k) {
        for (int i = 0; i < s.size(); i += 2 * k) {  // 以 2k 为步长跳跃遍历
            // 反转区间右边界取 min(i+k-1, size-1)，统一处理三种剩余长度情况
            int left = i;
            int right = min(i + k - 1, (int)s.size() - 1);
            while (left < right) {  // 344题双指针反转模板
                swap(s[left], s[right]);
                left++;
                right--;
            }
        }
        return s;
    }
};
```

## 总结

- 这题就是 344 题双指针反转的直接复用，唯一新增的能力是"按固定步长跳跃遍历 + 计算每次反转的右边界"。
- 反转区间右边界统一写成 `min(i+k-1, n-1)`，这样能避免针对"剩余 <k"、"剩余在[k,2k)"、"剩余>=2k"这三种情况分别写分支判断，这也是处理分组边界问题时常用的简化技巧。
- 步长为 `2k` 的循环天然就跳过了不需要反转的后 `k` 个字符，不用额外写代码处理"保持原样"的部分。
- Python 因为字符串不可变，无论是库解的拼接方式还是手写的双指针方式，都得生成新对象或者转成 list，这也是它跟 C++/Java/Go 原地操作的本质区别所在。
