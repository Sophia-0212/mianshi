# 35. 搜索插入位置

**题目描述**

给定一个排序数组和一个目标值，在数组中找到目标值，并返回其下标。如果目标值不存在于数组中，返回它将会被按顺序插入的位置。请必须使用时间复杂度为 O(log n) 的算法。

```
示例：
输入: nums = [1,3,5,6], target = 5
输出: 2
解释: 5在数组中，下标为2

输入: nums = [1,3,5,6], target = 2
输出: 1
解释: 2不在数组中，但应该插入到下标1的位置（1和3之间），插入后数组变为[1,2,3,5,6]

输入: nums = [1,3,5,6], target = 7
输出: 4
解释: 7应该插入到数组末尾，下标4
```

## 思路

二分查找：命中返回下标；未命中返回循环结束时的 `left`，即第一个大于等于 `target` 的位置。也可直接用 `bisect_left`。

时间 O(log n)，空间 O(1)。



## Python

### LeetCode 写法与原有示例

标准库一行解（`bisect_left` 本质就是本题要求的逻辑：返回第一个大于等于 target 的下标，若target存在则返回其下标，不存在则返回应插入的位置）：

```python
from bisect import bisect_left

# 依赖说明：Python 标准库 bisect：在有序列表中进行二分查找或插入。

class Solution:
    # 方法：searchInsert；按题目要求处理输入并返回结果，核心算法见方法体。
    def searchInsert(self, nums: list[int], target: int) -> int:
        return bisect_left(nums, target)  # 直接返回第一个>=target的下标
```


手写实现（面试考察点，还原 `bisect_left` 的二分查找底层逻辑）：

```python
# 依赖说明：len：Python 内置函数：返回容器中元素的数量。

class Solution:
    # 方法：searchInsert；按题目要求处理输入并返回结果，核心算法见方法体。
    def searchInsert(self, nums: list[int], target: int) -> int:
        left, right = 0, len(nums) - 1  # 左闭右闭区间
        while left <= right:
            mid = left + (right - left) // 2
            if nums[mid] == target:
                return mid              # 命中，直接返回下标
            elif nums[mid] < target:
                left = mid + 1          # target在右边，收缩左边界
            else:
                right = mid - 1         # target在左边，收缩右边界
        return left  # 区间收缩为空，left即为插入位置
```

## 总结

- 这题跟 0704 二分查找几乎是同一套代码框架，唯一的区别就是：找不到 target 的时候不返回 -1，而是返回 `left` 指针最后停留的那个位置，这个位置正好就是"第一个大于等于 target 的下标"，也就是合理的插入点。
- 想搞懂这类题，关键就是理解"二分查找收缩完之后 `left` 停在哪"——这个位置天生就满足"左边全都严格小于 target、自身以及右边全都大于等于 target"这个性质，而这恰好就是插入位置要满足的条件。
- 说白了，这题的解法本质上就是把 `bisect_left` 手写还原了一遍。如果你之前已经搞懂了 0034 题（查找左右边界）里"查找左边界"那部分的二分写法，会发现这两者的收缩逻辑几乎一模一样，都是命中或者大于 target 的时候往左收缩。
- 有个容易搞混的地方：如果你把代码写成命中之后也继续收缩（就像 0034 题查左边界那样），其实对这题一样能得到正确答案，因为 target 存在的时候它自己就是"第一个大于等于 target 的位置"；不过命中就直接返回的写法更简洁，毕竟这题不需要你去区分"是不是有多个相同的值"，只要找到一个下标就够了。
