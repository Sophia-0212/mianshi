# 189. 旋转数组

**题目描述**

给定一个数组 `nums`，将数组中的元素向右旋转 `k` 个位置，其中 `k` 是非负数。要求尽量在原地完成，使用空间复杂度为 O(1) 的算法。

```
示例：
输入: nums = [1,2,3,4,5,6,7], k = 3
输出: [5,6,7,1,2,3,4]
解释: 向右旋转1步: [7,1,2,3,4,5,6]
     向右旋转2步: [6,7,1,2,3,4,5]
     向右旋转3步: [5,6,7,1,2,3,4]

输入: nums = [-1,-100,3,99], k = 2
输出: [3,99,-1,-100]
```

## 思路

"向右旋转 k 位"你可以这样理解：把数组末尾的 k 个元素搬到最前面去，原来前面的元素整体往后挪一挪。那如果你直接开一个额外数组去模拟这个搬移过程，空间复杂度就是 O(n)了，不满足题目"原地"的要求；那如果每次只转一位，重复转 k 次呢？虽然确实是原地操作，但时间复杂度是 O(n*k)，k 一大效率就很低了。

这里要用一个挺巧妙的技巧，叫**三步反转法**，它能做到只用 O(1) 的额外空间、O(n) 的时间就把整体旋转搞定。这个技巧和字符串"右旋"那道题（比如卡码网 55 题：把字符串右旋 k 位）思路是完全一样的，说白了就是同一个"循环移位"的通用技巧，用在不同的数据结构上而已。

三步反转法具体怎么操作呢？

1. **先把整个数组反转一遍**：把 `nums` 整体反转一次。比如 `[1,2,3,4,5,6,7]` 反转完就变成 `[7,6,5,4,3,2,1]`。这一步的效果是，原来在末尾的元素被带到了前面，不过顺序是倒着的。
2. **反转前 k 个元素**：对刚才反转完的数组，再把前 `k` 个元素单独反转一次。以 `k=3` 为例，`[7,6,5 | 4,3,2,1]` 前3个反转一下就变成 `[5,6,7 | 4,3,2,1]`——这一步相当于"反转的反转"，把前 k 个元素的相对顺序又恢复成正常的了。
3. **反转剩下的 n-k 个元素**：把剩下这一段也反转一下，`[5,6,7 | 4,3,2,1]` 后半部分反转成 `[5,6,7 | 1,2,3,4]`，同样是把顺序恢复正常。

三步做完，就得到 `[5,6,7,1,2,3,4]`，正好就是向右旋转 3 位的结果。

那为什么这个方法是对的呢？你可以从"两段互换位置"这个角度想：向右旋转 k 位，其实等价于把数组切成两段——前面 `n-k` 个元素（记作 A 段）和后面 `k` 个元素（记作 B 段），旋转完的结果就是把 B 段和 A 段的位置换一换，变成 `B + A`，但每段里面元素的相对顺序是不变的。而"整体反转、再分两次局部反转"正好就实现了这个效果：第一步整体反转，把 `A+B` 变成 `reverse(B)+reverse(A)`——注意反转之后，原来在后面的 B 段跑到前面去了；第二步和第三步再分别把 `reverse(B)` 和 `reverse(A)` 各自反转回正常顺序，这样就得到了 `B+A`，正是我们想要的结果。

边界情况这里得留意一下：k 可能比数组长度 n 还大（题目允许 k 是任意非负数），这种情况下，旋转 k 位和旋转 `k % n` 位效果是完全一样的，为什么呢？因为转一圈（也就是转 n 位）等于没转，回到原样了。所以第一步要先对 k 取模：`k = k % n`，不然局部反转的时候下标就越界了。另外，如果 k 是 0，或者 `k % n == 0`，数组根本不需要任何变化，三步反转法在这种情况下也能正确处理——第二步相当于反转0个元素，第三步反转全部元素但配合第一步相当于反转了两次，等价于什么都没做。

复杂度这块：三次反转操作，每次都是线性扫描一遍，加起来还是 **O(n)** 时间；只用了交换变量需要的那几个常数空间，是 **O(1)** 空间，正好满足原地旋转的要求。

## 代码

### C++

```cpp
class Solution {
public:
    void rotate(vector<int>& nums, int k) {
        int n = nums.size();
        k %= n;  // k可能大于n，取模避免越界（转一圈等于没转）

        reverse(nums.begin(), nums.end());        // 第一步：整体反转
        reverse(nums.begin(), nums.begin() + k);  // 第二步：反转前k个元素
        reverse(nums.begin() + k, nums.end());    // 第三步：反转剩余n-k个元素
    }
};
```

### Java

```java
class Solution {
    public void rotate(int[] nums, int k) {
        int n = nums.length;
        k %= n; // k可能大于n，取模避免越界

        reverse(nums, 0, n - 1);      // 第一步：整体反转
        reverse(nums, 0, k - 1);      // 第二步：反转前k个元素
        reverse(nums, k, n - 1);      // 第三步：反转剩余n-k个元素
    }

    private void reverse(int[] nums, int left, int right) {
        while (left < right) {
            int temp = nums[left];
            nums[left] = nums[right];
            nums[right] = temp;
            left++;
            right--;
        }
    }
}
```

### Python

标准库中的切片操作可以简洁地表达旋转（虽然切片本身会产生新的临时数组，严格意义上不是O(1)空间，但作为库函数思路参考——`nums[:] = nums[-k:] + nums[:-k]` 的原理是直接拼接"后k个"和"前n-k个"两段）：

```python
class Solution:
    def rotate(self, nums: list[int], k: int) -> None:
        n = len(nums)
        k %= n  # 取模避免k大于n时越界
        nums[:] = nums[-k:] + nums[:-k]  # 后k个拼接前n-k个，原地赋值回nums
```

手写实现（面试考察点，三步反转法，严格 O(1) 额外空间）：

```python
class Solution:
    def rotate(self, nums: list[int], k: int) -> None:
        n = len(nums)
        k %= n  # k可能大于n，取模避免无意义的多余反转

        def reverse(left: int, right: int) -> None:
            while left < right:
                nums[left], nums[right] = nums[right], nums[left]
                left += 1
                right -= 1

        reverse(0, n - 1)      # 第一步：整体反转
        reverse(0, k - 1)      # 第二步：反转前k个元素
        reverse(k, n - 1)      # 第三步：反转剩余n-k个元素
```

```go
func rotate(nums []int, k int) {
    n := len(nums)
    k %= n // k可能大于n，取模避免越界

    reverse(nums, 0, n-1) // 第一步：整体反转

}

func reverse(nums []int, left, right int) {
    for left < right {
        nums[left], nums[right] = nums[right], nums[left]
        left++
        right--
    }
}
```

## 总结

- 三步反转法（整体反转 + 两段局部反转）是处理"循环移位"这类问题的通用技巧，不光能用在数组向右旋转上，字符串右旋（比如卡码网 55 题）也一样能用——两者底层的逻辑是完全一样的：把数组或者字符串看成两段，通过反转的组合来实现两段的位置互换，同时保持每段内部元素的顺序不变。
- 边界处理这里的关键，就是要先对 `k` 取模 `n`，因为转 n 位等于没转，你要是不取模，`k` 一旦比数组长度还大，反转区间就直接越界了。
- 对比一下"额外数组模拟"（O(n)空间）和"逐位旋转k次"（O(n*k)时间）这两种做法，三步反转法在空间和时间上都做到了最优——O(1) 空间、O(n) 时间，是这类问题的标准解法。
- 想真正理解这个技巧，关键是要想明白"反转"和"位置互换"之间的关系：两段各自反转一次、再整体反转一次（或者反过来，先整体反转再各自反转），都能实现两段位置互换、同时段内顺序不变，这个反转组合的规律是要牢牢记住的。
