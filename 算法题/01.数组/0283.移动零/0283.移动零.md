# 283. 移动零

**题目描述**

给定一个数组 `nums`，编写一个函数将所有 `0` 移动到数组的末尾，同时保持非零元素的相对顺序。要求必须在原数组上进行操作，不能拷贝额外的数组，且尽量减少操作次数。

```
示例：
输入: nums = [0,1,0,3,12]
输出: [1,3,12,0,0]

输入: nums = [0,0,1]
输出: [1,0,0]
```

## 思路

快慢指针：快指针遍历，将非零元素依次写到慢指针位置，最后把剩余位置补零。按原顺序写入，保持相对顺序。

时间 O(n)，空间 O(1)。



## Python

### LeetCode 写法与原有示例

本题要求原地操作且强调"减少操作次数"，标准库没有直接对应的一行原地解法（`nums.sort(key=lambda x: x == 0)` 虽然能得到正确结果，但排序的时间复杂度是 O(n log n)，不符合本题追求线性时间的初衷，因此不作为推荐解法），下面给出双指针的手写实现：

```python
# 依赖说明：len：Python 内置函数：返回容器中元素的数量。；range：Python 内置函数：生成按步长遍历的整数序列。

class Solution:
    # 方法：moveZeroes；按题目要求处理输入并返回结果，核心算法见方法体。
    def moveZeroes(self, nums: list[int]) -> None:
        slow = 0  # slow 指向下一个非零元素应存放的位置
        for fast in range(len(nums)):
            if nums[fast] != 0:
                nums[slow] = nums[fast]  # 把非零元素前移到slow位置
                slow += 1                 # slow右移，指向下一个待填充位置

        for i in range(slow, len(nums)):
            nums[i] = 0  # slow之后的位置全部填0```

            nums[i] = 0;
        }
    }
};

## 总结

- 这题跟"移除元素"（27题）说白了是同一套双指针模板的两种用法：27题是把等于目标值的元素排除到有效区间之外，这题是把非零元素往前收拢，两者 `slow`/`fast` 往前推进的逻辑是完全一样的，只是这题收尾的时候多一步——要把尾部清零。
- 双指针能保证非零元素的相对顺序不变，这是因为 `fast` 是严格从左往右扫的，`slow` 又是单调递增地去接收非零元素，这两者往前推进的相对顺序，就保证了原来的顺序被完整保留下来了。
- 容易漏掉的一步就是清零操作——光做"把非零元素往前搬"是不够的，如果不把 `slow` 之后的位置显式置零，数组末尾可能会残留脏数据，而不是真正的 0。
- 这种"原地把数组划分成两部分（满足条件的/不满足条件的）"的双指针技巧，其实还可以推广到别的分区问题上，比如按奇偶性分区、按正负性分区之类的，本质上都是用一个慢指针去维护"已处理区间"的边界。
