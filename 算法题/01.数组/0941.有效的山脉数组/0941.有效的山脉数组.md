# 941. 有效的山脉数组

**题目描述**

给定一个整数数组 `arr`，如果它是有效的山脉数组就返回 `true`，否则返回 `false`。

一个数组被称为山脉数组，需要满足以下条件：

- `arr.length >= 3`
- 存在某个下标 `i`（`0 < i < arr.length - 1`），满足：
  - `arr[0] < arr[1] < ... < arr[i-1] < arr[i]`（严格递增到 i）
  - `arr[i] > arr[i+1] > ... > arr[arr.length - 1]`（从 i 严格递减到末尾）

```
示例：
输入: arr = [2,1]
输出: false
解释: 数组长度小于3，且没有先增后减的结构

输入: arr = [0,3,2,1]
输出: true
解释: 先从0递增到3（山顶），再从3递减到1

输入: arr = [3,5,5]
输出: false
解释: 5,5相等，不满足严格递增（也不满足严格递减）
```

## 思路

双指针从两端向高处移动，均要求严格上升。最终必须在同一内点相遇：`0 < left == right < n-1`。

时间 O(n)，空间 O(1)。

本题没有直接对应的标准库一行解法（判断单峰形状是较特殊的逻辑，`sorted`/`bisect` 等库函数都不适用），因此只给出手写实现：

```python
# 依赖说明：len：Python 内置函数：返回容器中元素的数量。

class Solution:
    # 方法：validMountainArray；按题目要求处理输入并返回结果，核心算法见方法体。
    def validMountainArray(self, arr: list[int]) -> bool:
        n = len(arr)
        if n < 3:
            return False  # 山脉至少需要3个元素

        left = 0
        while left + 1 < n and arr[left] < arr[left + 1]:
            left += 1  # 从左往右爬坡，直到无法再上升

        right = n - 1
        while right - 1 >= 0 and arr[right] < arr[right - 1]:
            right -= 1  # 从右往左爬坡，直到无法再上升

        # 两指针必须汇合在同一个山顶，且不能是数组端点
        return left == right and left != 0 and right != n - 1```

## 总结

- 本题的双指针不是常见的"相向查找目标值"模式，而是"从两端各自贪心爬坡到能到达的最高点"，再通过判断两个终点是否重合来验证山脉的唯一性，这是双指针思想的一种变体应用。
- 严格递增/递减的要求意味着相邻元素相等时爬坡会立即停止，这个特性天然处理了"平台"这种非法情况，不需要额外的相等判断分支。
- 容易漏掉的边界是山顶不能出现在数组两端——如果只判断 `left == right` 而不排除端点，会把单调递增或单调递减的数组误判为有效山脉。
- 这道题与"寻找数组的峰值"类问题（如山脉数组的顶峰索引）思路相通，都是利用单调性来定位极值点，但本题额外要求验证整个数组必须严格满足单峰形状，而不仅仅是找到峰值位置。
