# 0209. 长度最小的子数组

**题目描述**

给定一个含有 `n` 个正整数的数组和一个正整数 `target`，找出该数组中满足其和大于等于 `target` 的长度最小的**连续**子数组，并返回其长度。如果不存在符合条件的子数组，返回 0。

```
示例：
输入: target = 7, nums = [2,3,1,2,4,3,3]
输出: 2
解释: 子数组 [4,3] 是该条件下的长度最小的子数组。
```

## 思路

先说暴力解法：枚举所有子数组的起点和终点，算区间和，这样搞时间复杂度是 O(n²)甚至更高。但你想啊，数组元素**全都是正整数**，这意味着"子数组的和"会随着右边界右移单调不减、随着左边界右移单调不增——这个单调性正是滑动窗口能生效的前提条件。

那我们就用**滑动窗口**（说白了本质就是同向双指针）去维护一个区间 `[left, right]`：

- `right` 指针负责往右扩张窗口，每扩张一步，就把 `nums[right]` 累加进当前的窗口和 `sum` 里
- 当 `sum >= target` 的时候，说明当前窗口已经满足条件了，这时候就要尝试**收缩**左边界：不断把 `left` 往右挪（同时把 `nums[left]` 从 `sum` 里减掉），只要收缩完还满足 `sum >= target`，就继续收缩，每次满足条件的时候都更新一下最小长度
- 直到 `sum < target` 了，说明不能再收缩了，就回到扩张右边界那个过程继续走

整个过程中，`left` 和 `right` 都只会往一个方向移动，不会往回退，所以两个指针加起来总的移动次数不会超过 `n`，均摊下来其实是 O(n)，不是 O(n²)。

这里跟二分查找不一样——滑动窗口不是靠比较中间值去跳跃式收缩区间的，而是靠维护区间"和"的单调性，用双指针做线性扫描去找最优区间。

- 时间复杂度：O(n)，`left` 和 `right` 各自累计移动都不超过 n 次
- 空间复杂度：O(1)，就维护窗口和跟最小长度这两个变量

## 代码

### C++

```cpp
class Solution {
public:
    int minSubArrayLen(int target, vector<int>& nums) {
        int n = nums.size();
        int left = 0;           // 窗口左边界
        int sum = 0;             // 当前窗口 [left, right] 的元素和
        int minLen = INT_MAX;    // 记录满足条件的最小窗口长度
        for (int right = 0; right < n; right++) { // right 负责扩张窗口
            sum += nums[right]; // 把新元素纳入窗口
            while (sum >= target) { // 窗口和已满足条件，尝试收缩左边界找更短窗口
                minLen = min(minLen, right - left + 1); // 更新最小长度
                sum -= nums[left]; // 移出左边界元素
                left++;             // 左边界右移，收缩窗口
            }
        }
        return minLen == INT_MAX ? 0 : minLen; // 没有找到满足条件的子数组则返回 0
    }
};
```

### Java

```java
class Solution {
    public int minSubArrayLen(int target, int[] nums) {
        int n = nums.length;
        int left = 0;              // 窗口左边界
        int sum = 0;                // 当前窗口元素和
        int minLen = Integer.MAX_VALUE; // 记录最小窗口长度
        for (int right = 0; right < n; right++) { // right 扩张窗口
            sum += nums[right];
            while (sum >= target) { // 满足条件，尝试收缩
                minLen = Math.min(minLen, right - left + 1);
                sum -= nums[left]; // 移出左边界
                left++;
            }
        }
        return minLen == Integer.MAX_VALUE ? 0 : minLen;
    }
}
```

### Python

这道题依赖"扩张 - 收缩"的动态过程来维护窗口边界，标准库没有能直接表达这种双指针收缩逻辑的一行解，因此只给手写实现。

```python
class Solution:
    def minSubArrayLen(self, target: int, nums: list[int]) -> int:
        n = len(nums)
        left = 0                # 窗口左边界
        window_sum = 0           # 当前窗口元素和
        min_len = float('inf')   # 记录最小窗口长度，初始设为无穷大
        for right in range(n):   # right 负责扩张窗口
            window_sum += nums[right]  # 把新元素纳入窗口
            while window_sum >= target:  # 窗口和已满足条件，尝试收缩
                min_len = min(min_len, right - left + 1)  # 更新最小长度
                window_sum -= nums[left]  # 移出左边界元素
                left += 1                  # 左边界右移
        return 0 if min_len == float('inf') else min_len  # 未找到则返回 0
```

### Go

```go
func minSubArrayLen(target int, nums []int) int {
    n := len(nums)
    left := 0      // 窗口左边界
    sum := 0        // 当前窗口元素和
    minLen := n + 1 // 记录最小窗口长度，用 n+1 表示"尚未找到"（不可能达到的长度）
    for right := 0; right < n; right++ { // right 扩张窗口
        sum += nums[right]
        for sum >= target { // 满足条件，尝试收缩
            if right-left+1 < minLen {
                minLen = right - left + 1 // 更新最小长度
            }
            sum -= nums[left] // 移出左边界
            left++
        }
    }
    if minLen == n+1 { // 说明循环中从未更新过，不存在满足条件的子数组
        return 0
    }
    return minLen
}
```

## 总结

- 滑动窗口能用的前提，是"窗口指标（这里指的是区间和）随边界移动是单调变化的"，这题就是靠数组元素全是正整数这个条件，才能保证右扩张和右收缩分别让 `sum` 单调增大或减小；要是数组里有负数，这种简单的双指针收缩逻辑就直接失效了。
- 外层 `for` 控制右指针扩张，内层 `while` 控制左指针收缩，看起来是两层循环嵌套，但均摊时间复杂度还是 O(n)，因为 `left` 总共移动的步数不会超过 `n`，别被"看起来像嵌套循环"这个表象带偏，误以为是 O(n²)。
- 有个容易出错的地方：更新最小长度这个动作，一定要放在 `while` 循环内部（也就是收缩之前），因为收缩前的窗口才是刚好满足条件的那个合法窗口；还有一个常见错误是漏判"根本不存在满足条件的子数组"的情况，忘了把初始设的那个极大值（`INT_MAX`/`inf`/`n+1`）转换成 0 再返回。
- 滑动窗口跟双指针说白了是同一类技巧在不同场景下的应用：双指针常用在"原地覆盖/两端收缩"这类场景，滑动窗口则专门用来"维护一段连续区间，去找满足某种和/计数条件的最优区间"。
