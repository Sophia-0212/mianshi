# 0704. 二分查找

**题目描述**

给定一个 n 个元素有序的（升序）整型数组 `nums` 和一个目标值 `target`，写一个函数搜索 `nums` 中的 `target`，如果目标值存在返回下标，否则返回 -1。

```
示例：
输入: nums = [-1,0,3,5,9,12], target = 9
输出: 4
解释: 9 出现在 nums 中并且下标为 4
```

要求：数组元素不重复，且是升序排列。

## 思路

二分查找：维护闭区间 `[left,right]`，初值 `[0,n-1]`。当 `left<=right`，比较中点与目标：相等返回；偏小令 `left=mid+1`，偏大令 `right=mid-1`。区间为空返回 -1。也可用 `bisect_left` 定位后检查是否相等。

时间 O(log n)，空间 O(1)。



## Python

### LeetCode 写法与原有示例

标准库一行解（`bisect`，底层同样是二分，`bisect_left` 返回第一个 `>= target` 的插入点）：

```python
from bisect import bisect_left

# 依赖说明：Python 标准库 bisect：在有序列表中进行二分查找或插入。；len：Python 内置函数：返回容器中元素的数量。

class Solution:
    # 方法：search；按题目要求处理输入并返回结果，核心算法见方法体。
    def search(self, nums: list[int], target: int) -> int:
        idx = bisect_left(nums, target)  # 找到 target 应插入的最左位置
        if idx < len(nums) and nums[idx] == target:  # 校验该位置确实等于 target
            return idx
        return -1```


手写实现（面试考察点，逐行还原二分逻辑）：

```python
# 依赖说明：len：Python 内置函数：返回容器中元素的数量。

class Solution:
    # 方法：search；按题目要求处理输入并返回结果，核心算法见方法体。
    def search(self, nums: list[int], target: int) -> int:
        left, right = 0, len(nums) - 1  # 左闭右闭区间 [left, right]
        while left <= right:  # 区间不为空时继续查找
            mid = left + (right - left) // 2  # 取中间下标
            if nums[mid] == target:
                return mid  # 命中
            elif nums[mid] < target:
                left = mid + 1  # target 在右半区
            else:
                right = mid - 1  # target 在左半区
        return -1  # 未命中```

## C++

### LeetCode 写法与原有示例

```cpp
class Solution {
public:
    // 方法：search；按题目要求处理输入并返回结果，核心算法见方法体。
    int search(vector<int>& nums, int target) {
        int left = 0, right = nums.size() - 1;  // 左闭右闭区间 [left, right]
        while (left <= right) {  // 区间不为空时继续查找
            int mid = left + (right - left) / 2;  // 防止 left+right 溢出
            if (nums[mid] == target) {
                return mid;  // 命中，直接返回下标
            } else if (nums[mid] < target) {
                left = mid + 1;  // target 在右半区，收缩左边界（mid 已排除）
            } else {
                right = mid - 1;  // target 在左半区，收缩右边界（mid 已排除）
            }
        }
        return -1;  // 区间收缩为空仍未命中，说明不存在
    }
};
```

## 总结

- 二分查找的关键就在于区间边界怎么定义——是左闭右闭还是左闭右开，这个一旦定下来，就必须保证循环条件、`mid` 的取值范围、边界更新方式这三者是自洽的，不能中间随便换套路。
- 这题数组没有重复元素是二分查找能直接用的前提，如果有重复元素、还要找某个目标的边界，那就得用变体了（比如 `bisect_left`/`bisect_right` 之间的差异，处理方式就不一样）。
