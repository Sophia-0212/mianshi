# 数组总结篇

- 快慢指针：快指针读，慢指针写，原地过滤并保序；如移除元素、移动零。时间 O(n)，辅助空间 O(1)。

```
// 同向双指针（覆盖类）伪代码
slow = 0
for fast in range(n):
    if 满足保留条件(nums[fast]):
        nums[slow] = nums[fast]
        slow += 1
return slow
```

- 滑动窗口：维护连续区间，右端扩张、左端收缩；需有支持单向移动的性质，如正整数区间和。时间 O(n)，辅助空间由窗口状态决定。

```
// 滑动窗口伪代码
left = 0
window_state = 初始值
for right in range(n):
    更新 window_state 纳入 nums[right]
    while window_state 满足条件:
        更新答案(right - left + 1)
        更新 window_state 移出 nums[left]
        left += 1
```

- 对撞指针：从两端选当前最大平方值，逆序填结果。时间 O(n)，结果空间 O(n)。
- 二分查找：有序区间比较中点并排除一半，边界约定保持一致。时间 O(log n)，空间 O(1)。
- 螺旋模拟：按方向填充并收缩边界，角点只处理一次。n×n 矩阵时间 O(n²)，辅助空间 O(1)。
