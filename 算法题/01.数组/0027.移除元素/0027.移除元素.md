# 0027. 移除元素

**题目描述**

给定一个数组 `nums` 和一个值 `val`，你需要**原地**移除所有数值等于 `val` 的元素，并返回移除后数组的新长度。不要使用额外的数组空间，必须仅使用 O(1) 额外空间并**原地**修改输入数组。元素的顺序可以改变，你不需要考虑数组中超出新长度后面的元素。

```
示例：
输入: nums = [3,2,2,3], val = 3
输出: 2, nums = [2,2,_,_]
解释: 你的函数应该返回新的长度 2，并且 nums 中的前两个元素均为 2。
你不需要考虑数组中超出新长度后面的元素。
```

## 思路

快慢指针：快指针遍历，遇到非 `val` 元素就写入慢指针位置，慢指针加一。返回慢指针，即保留元素个数。

时间 O(n)，空间 O(1)。



## Python

### LeetCode 写法与原有示例

这道题是"原地覆盖"类问题，没有对应的标准库一行解可以直接满足"O(1) 额外空间、原地修改"的要求（`list(filter(...))` 或列表推导式都会新建列表，不满足原地要求），因此只给手写实现。

```python
# 依赖说明：len：Python 内置函数：返回容器中元素的数量。；range：Python 内置函数：生成按步长遍历的整数序列。

class Solution:
    # 用快慢指针原地覆盖保留元素，返回有效区间长度。
    # 方法：removeElement；按题目要求处理输入并返回结果，核心算法见方法体。
    def removeElement(self, nums: list[int], val: int) -> int:
        slow = 0  # slow 指向下一个应写入"保留元素"的位置
        for fast in range(len(nums)):  # fast 遍历整个数组
            if nums[fast] != val:      # 当前元素需要保留
                nums[slow] = nums[fast]  # 覆盖写入到 slow 位置
                slow += 1                 # slow 前进
        return slow  # 新长度```

## C++

### LeetCode 写法与原有示例

```cpp
class Solution {
public:
    // 用快慢指针原地覆盖非 val 元素，返回有效区间长度。
    // 方法：removeElement；按题目要求处理输入并返回结果，核心算法见方法体。
    int removeElement(vector<int>& nums, int val) {
        int slow = 0; // slow 指向下一个应写入"保留元素"的位置
        for (int fast = 0; fast < nums.size(); fast++) { // fast 遍历整个数组
            if (nums[fast] != val) {   // 当前元素需要保留
                nums[slow] = nums[fast]; // 覆盖写入到 slow 位置
                slow++;                  // slow 前进，指向下一个待写入位置
            }
            // nums[fast] == val 时什么都不做，相当于跳过这个元素
        }
        return slow; // slow 最终等于保留元素的个数，即新长度
    }
};
```

## 总结

- 这题其实是"原地覆盖类"双指针的一个典型代表。它的核心思路不是去删内存，而是把"有效的元素"紧凑地搬到数组前面，最后用返回的新长度去隐式地界定有效区间。
- 快慢指针这里分工要说清楚：`fast` 是"探路的"，负责判断当前元素合不合法；`slow` 是"落笔的"，负责把合法元素写到该写的位置。这两个指针走的速度不一样，这就是这类题的核心。
- 有个坑要提一下，就是千万别在遍历过程中直接调用数组或者列表自带的 `erase`、`remove` 这种真正做内存搬移的接口，因为那样每次删除都是 O(n) 的开销，整体就退化成 O(n²) 了。正确的做法始终是一次遍历，O(n) 搞定。
- 这种双指针的技巧后面还会反复出现，比如"移除重复元素"、"数组分区"这些题，本质上都是"一个指针探测、一个指针落地"这个组合，把这个思路吃透了，后面很多题都能秒。
