# 0977. 有序数组的平方

**题目描述**

给定一个按**非递减顺序**排序的整数数组 `nums`，返回**每个数字的平方**组成的新数组，要求也按非递减顺序排序。

```
示例：
输入: nums = [-4,-1,0,3,10]
输出: [0,1,9,16,100]
解释: 平方后数组变为 [16,1,0,9,100]，排序后变为 [0,1,9,16,100]。
```

## 思路

- 双指针：平方最大值必在两端。比较两端绝对值，将较大者平方从后向前写入结果，再移动对应指针。时间 O(n)，空间 O(n)（结果），辅助空间 O(1)。
- 平方后排序：时间 O(n log n)，空间 O(n)（含结果）。

    def sortedSquares(self, nums: list[int]) -> list[int]:
        return sorted(x * x for x in nums)  # 平方后整体排序，简单但没利用原数组有序的条件```


手写实现（面试考察点，双指针 O(n) 解法，还原利用有序性的核心思路）：

```python
# 依赖说明：len：Python 内置函数：返回容器中元素的数量。

class Solution:
    # 方法：sortedSquares；按题目要求处理输入并返回结果，核心算法见方法体。
    def sortedSquares(self, nums: list[int]) -> list[int]:
        n = len(nums)
        result = [0] * n  # 结果数组，预先分配好大小
        left, right = 0, n - 1  # 双指针指向原数组两端
        pos = n - 1  # 结果数组从末尾开始填充
        while left <= right:  # 区间不为空时继续比较
            left_sq = nums[left] * nums[left]
            right_sq = nums[right] * nums[right]
            if left_sq > right_sq:
                result[pos] = left_sq  # 左端绝对值更大
                left += 1
            else:
                result[pos] = right_sq  # 右端绝对值更大或相等
                right -= 1
            pos -= 1  # 填充位置向前移动
        return result```

    n := len(nums)
    result := make([]int, n) // 结果数组
    left, right := 0, n-1    // 双指针指向原数组两端

            result[pos] = leftSq // 左端更大
            left++
        } else {
            result[pos] = rightSq // 右端更大或相等
            right--
        }
        pos-- // 填充位置向前移动
    }
    return result
}

## C++

### LeetCode 写法与原有示例

```cpp
class Solution {
public:
    // 方法：sortedSquares；按题目要求处理输入并返回结果，核心算法见方法体。
    vector<int> sortedSquares(vector<int>& nums) {
        int n = nums.size();
        vector<int> result(n); // 结果数组，大小与原数组一致
        int left = 0, right = n - 1; // 双指针指向原数组两端
        int pos = n - 1; // 结果数组从末尾开始填充（当前剩余范围里的最大值应放在最后）
        while (left <= right) { // 区间不为空时继续比较
            int leftSq = nums[left] * nums[left];
            int rightSq = nums[right] * nums[right];
            if (leftSq > rightSq) {
                result[pos] = leftSq; // 左端绝对值更大，其平方是当前最大值
                left++;               // 左指针右移，缩小范围
            } else {
                result[pos] = rightSq; // 右端绝对值更大或相等
                right--;                // 右指针左移
            }
            pos--; // 结果数组的填充位置向前移动
        }
        return result;
    }
};
```

## 总结

- 这题双指针的方向是"从两端往中间收缩"，跟常见的"从同一端出发"那种双指针不太一样，关键的前提是能证明"极值一定在边界上"，这需要结合题目条件（原数组有序、平方是把绝对值单调放大的操作）分析出来才行。
- 结果数组要**从后往前**填，因为每一轮比较选出来的都是当前剩余范围里的最大值，这个细节实现的时候容易弄反方向，得留意。
- 容易出错的地方：只比较 `nums[left]` 和 `nums[right]` 的原始值大小是没意义的，必须比较平方之后的值（或者等价地比较绝对值），因为负数原始值看着小，但平方完可能反而是最大的。
- 这种"利用已排序的特性，通过分析极值可能出现的位置来设计双指针方向"的思路，跟"有序数组的二分查找"其实共享同一个前提条件——都是先确认数组有序，再去挖掘可以利用的单调性质。
