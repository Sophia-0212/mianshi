# 34. 在排序数组中查找元素的第一个和最后一个位置

**题目描述**

给定一个按照升序排列的整数数组 `nums`，和一个目标值 `target`。请找出给定目标值在数组中的开始位置和结束位置。如果数组中不存在目标值 `target`，返回 `[-1, -1]`。

```
示例：
输入: nums = [5,7,7,8,8,10], target = 8
输出: [3,4]
解释: 8在数组中的下标3和4处，分别是第一个和最后一个位置

输入: nums = [5,7,7,8,8,10], target = 6
输出: [-1,-1]
解释: 数组中不存在6
```

## 思路

这题你可以理解成二分查找的一个变体。普通的二分查找，处理的场景是数组里元素不重复，找某个值在不在、下标是多少。但这一题不一样，数组里 target 是可以重复出现的，我要找的其实是这个值所占的**一段区间**，也就是它的左边界和右边界分别在哪。

那我的思路是什么呢？分别做两次二分查找：第一次专门去找"最左边那个等于 target 的位置"，第二次专门去找"最右边那个等于 target 的位置"。这两次查找的整体框架是一样的，区别就在于命中之后怎么收缩边界。

先说**找左边界**：当 `nums[mid] == target` 的时候，你不能立刻就返回，为什么呢？因为左边可能还藏着其他等于 target 的元素呢，所以还要继续往左边找，这时候就把右边界收缩一下，`right = mid - 1`，同时用一个变量把当前的 `mid` 记下来，当作候选答案。如果 `nums[mid] < target`，说明 target 在右边，`left = mid + 1`；如果 `nums[mid] > target`，说明 target 在左边，`right = mid - 1`。等循环跑完，最后一次记下来的候选答案，就是左边界。

再看**找右边界**，逻辑上其实是完全对称的。同样是命中 `nums[mid] == target` 的时候不能立刻返回，而是要继续往右边探，把左边界往右收缩，`left = mid + 1`，然后记下候选答案；剩下两种情况的收缩方式跟找左边界时一模一样。循环结束后，最后记的那个候选答案就是右边界。

所以你会发现，这两次二分查找唯一不一样的地方，就在于**命中 target 之后怎么收缩区间**：找左边界的时候命中了继续往左收（`right = mid - 1`），找右边界的时候命中了继续往右收（`left = mid + 1`）。这个小小的差异，正是这题跟标准二分查找（也就是 0704 题）最本质的区别——标准二分查找一旦命中直接返回结束，而这题命中了还得"再赌一把"，继续往同一个方向试探，直到确认这确实是边界才收手。

那为什么这么做就一定能找到正确的边界呢？说白了就是因为二分查找每一步都保证了：如果 target 真的存在，那它一定还留在当前的 `[left, right]` 区间里，不会被误删掉。找左边界的时候，每次命中都先把它记成候选答案，但不着急，继续往左半区间搜，万一左边还有 target，就用更小的下标去覆盖掉之前记的答案；这样跳出循环时留下来的，一定是满足条件里最小的那个下标。右边界的道理完全反过来，一样成立。

边界情况这里也得说一下：如果 target 压根就不在数组里，那两次二分查找都不会更新候选答案（一开始初始值设的是 -1），最终就返回 `[-1, -1]`。还有一点值得注意，就算你在查左边界的时候已经确认 target 是存在的了，我还是建议老老实实、完整地再跑一遍查右边界的二分逻辑，这样代码结构更清楚，也不用在一次遍历里同时维护两个指针，逻辑上会更绕。

复杂度这块很直观：两次独立的二分查找，每次都是 O(log n)，加起来还是 **O(log n)**，无非常数因子是2，不影响整体的渐进复杂度；空间上就用了几个变量，是 **O(1)**。

## 代码

### C++

```cpp
class Solution {
public:
    // 查找target的最左边界，找不到返回-1
    int findLeftBorder(vector<int>& nums, int target) {
        int left = 0, right = nums.size() - 1;
        int result = -1;
        while (left <= right) {
            int mid = left + (right - left) / 2;
            if (nums[mid] == target) {
                result = mid;       // 记录候选答案
                right = mid - 1;    // 命中后继续往左找更小的下标
            } else if (nums[mid] < target) {
                left = mid + 1;
            } else {
                right = mid - 1;
            }
        }
        return result;
    }

    // 查找target的最右边界，找不到返回-1
    int findRightBorder(vector<int>& nums, int target) {
        int left = 0, right = nums.size() - 1;
        int result = -1;
        while (left <= right) {
            int mid = left + (right - left) / 2;
            if (nums[mid] == target) {
                result = mid;       // 记录候选答案
                left = mid + 1;     // 命中后继续往右找更大的下标
            } else if (nums[mid] < target) {
                left = mid + 1;
            } else {
                right = mid - 1;
            }
        }
        return result;
    }

    vector<int> searchRange(vector<int>& nums, int target) {
        int leftBorder = findLeftBorder(nums, target);
        if (leftBorder == -1) return {-1, -1};  // 左边界都找不到，说明target不存在
        int rightBorder = findRightBorder(nums, target);
        return {leftBorder, rightBorder};
    }
};
```

### Python

标准库一行解（`bisect_left` 找第一个 `>= target` 的位置，`bisect_right` 找第一个 `> target` 的位置，两者结合即可确定边界，这正是二分查找左右边界思路的库函数实现）：

```python
from bisect import bisect_left, bisect_right

class Solution:
    def searchRange(self, nums: list[int], target: int) -> list[int]:
        left = bisect_left(nums, target)   # 第一个>=target的位置
        if left == len(nums) or nums[left] != target:
            return [-1, -1]  # 该位置不存在或不等于target，说明target不存在
        right = bisect_right(nums, target) - 1  # 第一个>target的位置再减1，即最后一个等于target的位置
        return [left, right]
```

手写实现（面试考察点，两次独立二分查找，分别处理左右边界的收缩差异）：

```python
class Solution:
    def searchRange(self, nums: list[int], target: int) -> list[int]:
        def find_left_border() -> int:
            left, right = 0, len(nums) - 1
            result = -1
            while left <= right:
                mid = left + (right - left) // 2
                if nums[mid] == target:
                    result = mid       # 记录候选答案
                    right = mid - 1    # 命中后继续往左找更小下标
                elif nums[mid] < target:
                    left = mid + 1
                else:
                    right = mid - 1
            return result

        def find_right_border() -> int:
            left, right = 0, len(nums) - 1
            result = -1
            while left <= right:
                mid = left + (right - left) // 2
                if nums[mid] == target:
                    result = mid       # 记录候选答案
                    left = mid + 1     # 命中后继续往右找更大下标
                elif nums[mid] < target:
                    left = mid + 1
                else:
                    right = mid - 1
            return result

        left_border = find_left_border()
        if left_border == -1:
            return [-1, -1]  # target不存在
        right_border = find_right_border()
        return [left_border, right_border]
```

## 总结

- 这题其实是在 0704 二分查找那套"左闭右闭区间、`left <= right` 循环条件"的基础上做了个变体：命中 target 之后不能立刻返回，而是要先记下候选答案，然后继续朝那个方向收缩，一直收缩到区间空了为止，这样才能保证你找到的是真正的边界，而不是随便命中的某一个位置。
- 找左边界跟找右边界，说白了唯一的差别就是命中之后往哪个方向收缩——左边界是收右指针，右边界是收左指针。把这一个差异想明白了，两种边界查找的写法就都掌握了，完全不需要死记硬背两套代码。
- 这里有个挺好的记忆点，就是跟 `bisect_left`/`bisect_right` 的对应关系：`bisect_left` 本质上就是找左边界的思路，`bisect_right - 1` 就是找右边界的思路，把库函数背后的原理搞懂了，面试的时候手写版本也能很快写出来。
- 还有个容易踩坑的地方，就是判断 target 到底存不存在的时机——一定要先确认左边界查到了结果（不是 -1），才有必要再去查右边界；如果左边界压根就没找到，那说明数组里根本没有这个 target，这时候第二次二分查找就不用再做了。
