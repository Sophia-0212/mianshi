# 数组理论基础

数组连续存储，通过下标计算地址，随机读写 O(1)：

```
address(i) = base + i * size
```

中间插入、删除需搬移元素，时间 O(n)；动态数组尾部追加均摊 O(1)，单次扩容 O(n)。存储空间 O(n)。

| 语言 | 固定数组／动态容器 |
|---|---|
| C++ | 数组／`vector` |
| Java | 数组／`ArrayList` |
| Python | `list` 存储连续的对象引用 |
| Go | 数组／`slice` 引用底层数组 |

Python 列表引用连续，不代表对象连续；Go 切片可能共享底层数组，扩容后可能改用新数组。区分长度与容量，访问下标不得越界。
