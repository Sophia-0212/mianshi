# 0059. 螺旋矩阵 II

**题目描述**

给定一个正整数 `n`，生成一个包含 `1` 到 `n²` 所有元素，且元素按顺时针螺旋顺序排列的 `n x n` 正方形矩阵。

```
示例：
输入: n = 3
输出: [[1,2,3],[8,9,4],[7,6,5]]
解释: 从左上角 1 出发，按顺时针方向螺旋填入 1~9，
最终形成外层顺时针、内层继续顺时针收缩的矩阵。
```

## 思路

模拟：维护上下左右边界，按右、下、左、上填充，每填完一边收缩对应边界。边界交错即结束，避免重复填角点；奇数阶矩阵需填中心。

时间 O(n²)，空间 O(n²)（结果矩阵），辅助空间 O(1)。

### LeetCode 写法与原有示例

本题是纯模拟类问题，填充顺序和边界收缩逻辑没有对应的标准库函数可以直接生成，因此只给手写实现。

```python
# 依赖说明：range：Python 内置函数：生成按步长遍历的整数序列。

class Solution:
    # 方法：generateMatrix；按题目要求处理输入并返回结果，核心算法见方法体。
    def generateMatrix(self, n: int) -> list[list[int]]:
        matrix = [[0] * n for _ in range(n)]  # n x n 结果矩阵
        top, bottom, left, right = 0, n - 1, 0, n - 1  # 四条边界
        num = 1  # 待填入的数字

        while num <= n * n:
            for col in range(left, right):  # 上边：从左到右，不含 right 这一列
                matrix[top][col] = num
                num += 1
            top += 1  # 上边界下移

            for row in range(top, bottom):  # 右边：从上到下，不含 bottom 这一行
                matrix[row][right] = num
                num += 1
            right -= 1  # 右边界左移

            for col in range(right, left, -1):  # 下边：从右到左，不含 left 这一列
                matrix[bottom][col] = num
                num += 1
            bottom -= 1  # 下边界上移

            for row in range(bottom, top, -1):  # 左边：从下到上，不含 top 这一行
                matrix[row][left] = num
                num += 1
            left += 1  # 左边界右移，一圈结束

        return matrix```

## Go

### LeetCode 写法与原有示例

```go
// 方法：generateMatrix；按题目要求处理输入并返回结果，核心算法见方法体。
func generateMatrix(n int) [][]int {
    matrix := make([][]int, n)
    for i := range matrix {
        matrix[i] = make([]int, n) // 初始化 n x n 结果矩阵
    }
    top, bottom, left, right := 0, n-1, 0, n-1 // 四条边界
    num := 1                                    // 待填入的数字

    for num <= n*n {
        for col := left; col < right; col++ {
            matrix[top][col] = num // 上边：从左到右
            num++
        }
        top++ // 上边界下移

        for row := top; row < bottom; row++ {
            matrix[row][right] = num // 右边：从上到下
            num++
        }
        right-- // 右边界左移

        for col := right; col > left; col-- {
            matrix[bottom][col] = num // 下边：从右到左
            num++
        }
        bottom-- // 下边界上移

        for row := bottom; row > top; row-- {
            matrix[row][left] = num // 左边：从下到上
            num++
        }
        left++ // 左边界右移
    }
    return matrix
}
```

## C++

### LeetCode 写法与原有示例

```cpp
class Solution {
public:
    vector<vector<int>> generateMatrix(int n) {
        vector<vector<int>> matrix(n, vector<int>(n, 0)); // n x n 结果矩阵
        int top = 0, bottom = n - 1, left = 0, right = n - 1; // 四条边界
        int num = 1; // 待填入的数字，从 1 开始递增
        while (num <= n * n) { // 直到填满 n*n 个数字为止
            for (int col = left; col < right && num <= n * n; col++) {
                matrix[top][col] = num++; // 上边：从左到右，不含 right 这一列
            }
            top++; // 上边界下移，本条边已填完
            for (int row = top; row < bottom && num <= n * n; row++) {
                matrix[row][right] = num++; // 右边：从上到下，不含 bottom 这一行
            }
            right--; // 右边界左移
            for (int col = right; col > left && num <= n * n; col--) {
                matrix[bottom][col] = num++; // 下边：从右到左，不含 left 这一列
            }
            bottom--; // 下边界上移
            for (int row = bottom; row > top && num <= n * n; row--) {
                matrix[row][left] = num++; // 左边：从下到上，不含 top 这一行
            }
            left++; // 左边界右移，一圈结束
        }
        return matrix;
    }
};
```

## 总结

- 这题的核心不在算法难度上，而是考察你"边界管理"这方面的工程能力：用 `top`/`bottom`/`left`/`right` 四个变量描述当前圈的范围，然后约定每条边"不包含终点"，这就是让四段循环能够无缝拼接、不重复不遗漏的关键设计。
- 循环不变量这个思想说白了就是，把"螺旋填充"这件事抽象成"填上边 → 收缩上边界 → 填右边 → 收缩右边界 → 填下边 → 收缩下边界 → 填左边 → 收缩左边界"这么一个固定套路，每一圈都重复同样的逻辑，这样就不用给四个方向分别写不同的特判代码了。
- 有个容易踩的坑：当 `n` 是奇数的时候，最后会剩下正中心那一个元素，如果边界收缩和循环条件没对齐好（比如到底用 `<=` 还是 `<` 去判断），很容易出现中心元素被重复填了，或者干脆漏填了。用 `num <= n*n` 作为整体的终止条件，可以给这类边界问题兜个底。
- 这个技巧跟"螺旋矩阵"这题（也就是给你一个矩阵，按螺旋顺序把它读出来，正好是本题的逆过程）用的是同一套边界模拟技巧，只是一个方向是填充、一个方向是读取，处理思路完全一致。
