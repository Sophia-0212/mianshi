# 1207. 独一无二的出现次数

**题目描述**

给你一个整数数组 `arr`，请你判断数组中每个数的出现次数是否都是独一无二的（即出现次数不能重复）。如果是，返回 `true`；否则返回 `false`。

```
示例：
输入: arr = [1,2,2,1,1,3]
输出: true
解释: 1出现3次，2出现2次，3出现1次，次数3、2、1互不相同

输入: arr = [1,2]
输出: false
解释: 1出现1次，2也出现1次，出现次数1重复了

输入: arr = [-3,0,1,-3,1,1,1,-3,10,0]
输出: true
```

## 思路

这题要判断的不是数值本身有没有重复，这里的关键是**每个数值对应的出现次数**有没有重复。所以你可以把它拆成两步来做：

第一步，先统计每个数值出现了多少次。这就是很典型的哈希计数场景嘛：遍历数组，用哈希表记录"值 -> 出现次数"。因为数组里的元素可能是负数（题目示例里就出现了 `-3`），所以用哈希表比用数组下标去计数更通用，不用去操心负数偏移这些麻烦事。

第二步，判断这些"出现次数"本身有没有重复。拿到哈希表之后，我们只关心它的**值集合**，也就是所有数值各自对应的出现次数，不关心到底是哪个数值对应哪个次数。把这些次数都丢进一个集合（set）里，如果集合的大小跟哈希表键的数量（也就是不同数值的个数）相等，那就说明没有两个不同的数值拥有相同的出现次数；要是集合变小了，说白了就是发生了次数冲突。

这里的关键决策点在于：**用集合去重来检测有没有重复，是判断"是否存在重复元素"最简洁的方式**。为什么呢？因为集合里的元素两两不同，如果把 n 个数放进集合之后，集合的大小小于 n，那就说明有重复；反过来，集合大小等于 n，就说明这 n 个数两两都不一样。这个思路就避免了对次数列表先排序再两两比较相邻元素这种麻烦做法，代码更简洁，也更符合"用哈希/集合解决重复检测问题"这个通用套路。

边界情况方面，你想啊，空数组，或者只有一种数值的数组，天然就满足"次数互不相同"，因为只有一个次数，根本不存在重复的可能，这个逻辑在集合去重的过程中会自动成立，不需要特殊处理。数组里有负数或者 0 也不影响哈希表计数的正确性，因为哈希表的键可以是任意能被哈希的值。

复杂度这块：第一步统计次数要遍历一次数组，是 O(n)；第二步把最多 n 个不同的次数值放进集合，也是 O(n)。整体时间复杂度就是 **O(n)**，空间复杂度上，哈希表和集合最多各存 O(n) 个元素，也是 **O(n)**。

## 代码

### C++

```cpp
class Solution {
public:
    bool uniqueOccurrences(vector<int>& arr) {
        unordered_map<int, int> count_map;         // 值 -> 出现次数
        for (int num : arr) {
            count_map[num]++;                       // 统计每个值出现的次数
        }

        unordered_set<int> occurrence_set;          // 用于去重判断次数是否重复
        for (auto& [value, count] : count_map) {
            occurrence_set.insert(count);           // 把出现次数放入集合
        }

        // 如果集合大小等于不同数值的个数，说明所有次数互不相同
        return occurrence_set.size() == count_map.size();
    }
};
```

### Java

```java
class Solution {
    public boolean uniqueOccurrences(int[] arr) {
        Map<Integer, Integer> countMap = new HashMap<>(); // 值 -> 出现次数
        for (int num : arr) {
            countMap.put(num, countMap.getOrDefault(num, 0) + 1); // 统计出现次数
        }

        Set<Integer> occurrenceSet = new HashSet<>(); // 用于去重判断
        for (int count : countMap.values()) {
            occurrenceSet.add(count); // 把出现次数放入集合
        }

        // 集合大小等于不同数值个数，说明次数互不相同
        return occurrenceSet.size() == countMap.size();
    }
}
```

### Python

标准库辅助解（`collections.Counter` 直接完成计数，底层是哈希表的封装，`Counter.values()` 拿到所有出现次数）：

```python
from collections import Counter

class Solution:
    def uniqueOccurrences(self, arr: list[int]) -> bool:
        counts = Counter(arr)              # 统计每个值出现的次数
        occurrence_values = counts.values() # 拿到所有次数（可能重复）
        # 转成集合去重后长度不变，说明次数互不相同
        return len(set(occurrence_values)) == len(occurrence_values)
```

手写实现（面试考察点，不依赖 `Counter`，手动维护哈希表和集合）：

```python
class Solution:
    def uniqueOccurrences(self, arr: list[int]) -> bool:
        count_map = {}                      # 值 -> 出现次数
        for num in arr:
            count_map[num] = count_map.get(num, 0) + 1  # 统计出现次数

        occurrence_set = set()              # 用于去重判断次数是否重复
        for count in count_map.values():
            occurrence_set.add(count)

        # 集合大小等于不同数值个数，说明所有次数互不相同
        return len(occurrence_set) == len(count_map)
```

### Go

```go
func uniqueOccurrences(arr []int) bool {
    countMap := make(map[int]int) // 值 -> 出现次数
    for _, num := range arr {
        countMap[num]++ // 统计每个值出现的次数
    }

    occurrenceSet := make(map[int]bool) // 用哈希集合模拟去重
    for _, count := range countMap {
        occurrenceSet[count] = true // 把出现次数放入集合
    }

    // 集合大小等于不同数值个数，说明次数互不相同
    return len(occurrenceSet) == len(countMap)
}
```

## 总结

- 这题说白了就是"两层哈希"思路的典型应用：第一层哈希表统计每个数值的出现次数，第二层用集合对这些次数做去重检测，这种"先统计、再对统计结果去重"的模式，在很多计数类问题里都挺常见的。
- 用集合大小和原数据个数做比较来判断有没有重复，是个挺通用的技巧，比手动排序之后再比较相邻元素要简洁得多，代码可读性也更高。
- 容易搞混的地方是判断的对象是什么——这题判断的是"出现次数"有没有重复，而不是"数值"本身有没有重复，读题的时候一定要看清楚问的到底是次数还是值。
- 跟其他哈希计数题比起来，比如判断两个字符串是不是字母异位词、找出出现次数最多的元素，这题特殊的地方就在于需要对"统计结果"再做一次去重判断，算是哈希思路的一次组合应用。
