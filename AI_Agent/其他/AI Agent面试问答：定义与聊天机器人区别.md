# 面试问答：什么是 AI Agent？它和普通聊天机器人有什么区别？

> AI Agent 是一个以目标为中心、能够自主完成任务的闭环系统。它先理解目标和当前状态，再决定下一步动作，调用工具获取结果，根据结果继续规划，直到任务完成或触发终止条件。
>
> 普通聊天机器人通常是“用户提问 → 模型生成回答”，主要负责生成文本；Agent 则是“理解目标 → 规划任务 → 调用工具 → 获取结果 → 判断是否完成 → 继续执行或结束”。核心区别不在于是否使用大模型，而在于 Agent 能否根据状态持续决策和执行动作。
>
> Agent 的自主性必须受控。我们会设置最大决策轮次、Token 和时间预算，检测重复工具调用，校验工具参数，并在高风险或异常情况下升级人工。因此，Agent 不是更会聊天的机器人，而是一个大模型驱动、可规划、可执行、可观测、可终止的任务系统。

## 追问：Agent 和工作流有什么区别？

> 工作流的执行路径由程序预先确定；Agent 的下一步动作由模型根据当前状态动态选择。生产系统通常采用“固定流程 + 局部 Agent 决策”，在保证可控的前提下获得灵活性。
