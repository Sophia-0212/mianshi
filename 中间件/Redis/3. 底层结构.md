# Redis 底层结构

## 逻辑结构不等于底层结构

Redis 会根据数据类型、数量和编码自动选择实现，以平衡速度与内存。

## SDS

Redis 用 SDS 保存字符串：

- 记录长度，获取长度为 O(1)。
- 二进制安全，可保存 `\\0`。
- 扩容预留空间，减少频繁分配。

## 哈希表

Hash 的基础结构。通过哈希函数定位字段，平均查询 O(1)。发生冲突时使用链式结构，并通过渐进式 rehash 降低阻塞。

## 跳表

ZSet 的有序索引结构：

```text
多层链表索引 → 快速定位 → 底层有序链表
```

查询、插入、删除平均 O(log n)，实现比平衡树更简单，适合范围查询。

## listpack

紧凑的连续内存结构，适合小集合，节省指针开销。元素过大或数量过多时会转换为更适合的结构。

## Intset

Set 只含整数且规模较小时使用，节省内存；加入不适合的元素后会升级。

## 面试关键

- Redis 对外暴露的是抽象数据结构。
- 底层编码可能动态变化。
- 小数据优先节省内存，大数据优先保证操作效率。
