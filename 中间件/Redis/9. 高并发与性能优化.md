# 高并发与性能优化

## 减少网络往返

使用 Pipeline 批量发送命令：

```text
多次请求 → 一次发送 → 批量返回
```

Pipeline 不提供事务语义，只减少 RTT。

## Lua 脚本

将多个命令放在 Redis 内原子执行，适合库存扣减、校验并扣减。

## 连接管理

- 使用连接池。
- 设置合理最大连接数。
- 设置超时和连接回收。
- 避免每次请求新建连接。

## 避免阻塞

不要在生产环境随意执行：

```text
KEYS *
HGETALL 超大 Hash
SMEMBERS 超大 Set
LRANGE 超大范围
DEL 大 Key
```

可使用：

```text
SCAN / HSCAN / SSCAN / ZSCAN
UNLINK
```

## 监控指标

- 命中率
- QPS
- 延迟
- 慢查询
- 内存使用率
- 大 Key、热 Key
- 连接数
- Keyspace 命中率

## 优化原则

```text
减少 RTT
减少 Value 大小
避免大 Key
避免阻塞命令
控制并发
监控后优化
```
