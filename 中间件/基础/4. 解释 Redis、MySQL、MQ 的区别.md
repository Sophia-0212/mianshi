# Redis、MySQL、MQ 的区别

| 组件 | 核心职责 | 典型特点 | 主要风险 |
|---|---|---|---|
| Redis | 缓存、计数、分布式锁 | 内存访问，速度快 | 数据丢失、缓存不一致 |
| MySQL | 持久化存储、事务 | 可靠、支持复杂查询 | 磁盘 I/O、并发瓶颈 |
| MQ | 异步、解耦、削峰 | 生产消费模型 | 丢消息、重复消费、积压 |

## 典型调用链

```text
请求
  ↓
Redis：优先读取热点数据
  ↓ 未命中
MySQL：读取持久化数据
  ↓
Redis：回写缓存
  ↓
MQ：异步处理非核心任务
```

## 核心区别

- Redis 解决访问速度问题。
- MySQL 解决数据持久化和事务问题。
- MQ 解决服务解耦、异步处理和流量削峰问题。

三者不能互相替代：Redis 通常不是唯一数据源，MQ 不是数据库，MySQL 也不适合承担高频缓存访问。
