# Redis 基础与核心直觉

是什么：是内存键值数据库；[支持多种数据结构](<2. 数据类型与底层实现.md>)、[持久化](<3. 持久化：RDB与AOF.md>)、[集群cluster](<5. 主从、哨兵与Cluster.md>)、发布订阅。

快的原因：内存读写、高效数据结构、I/O 多路复用。

应用于：[缓存](<4. 缓存生命周期与常见问题.md>)、计数、排行、[分布式锁](<6. 分布式锁.md>)、限流、延迟队列、会话。

不应该被应用于：复杂关联查询、强一致事务、无界大对象。

其中：

数据丢了怎么办？→持久化：RDB、AOF。

机器坏了怎么办？→高可用：主从、哨兵。

一台机器放不下怎么办？→水平扩展：Cluster。
