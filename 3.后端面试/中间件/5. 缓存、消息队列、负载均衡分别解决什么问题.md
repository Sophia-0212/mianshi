# 缓存、消息队列、负载均衡解决的问题

## 缓存：减少重复访问

```text
请求 → 缓存命中 → 快速返回
请求 → 缓存未命中 → 查询数据库 → 写入缓存
```

解决：

- 降低数据库压力。
- 缩短响应时间。
- 提高系统吞吐量。

代价：数据可能不一致，可能发生穿透、击穿、雪崩。

## 消息队列：异步解耦和削峰

```text
生产者 → MQ → 消费者
```

解决：

- 服务解耦。
- 非核心任务异步执行。
- 突发流量排队处理。

代价：消息可能重复、丢失、积压，业务需要幂等。

## 负载均衡：分发流量和消除单点

```text
客户端 → 负载均衡器 → 多个服务实例
```

解决：

- 横向扩容。
- 提高可用性。
- 分摊请求压力。

代价：引入节点健康检查、会话共享和流量分配问题。
