# Nginx 的作用

## 核心定位

Nginx 是高性能的反向代理服务器，也可作为 Web 服务器和负载均衡器。

## 主要功能

### 1. 反向代理

```text
客户端 → Nginx → 应用服务
```

客户端只访问 Nginx，应用服务地址对外隐藏。

### 2. 负载均衡

```text
Nginx
 ├── 服务实例 1
 ├── 服务实例 2
 └── 服务实例 3
```

常见策略：轮询、权重、IP Hash、最少连接。

### 3. HTTPS 终止

Nginx 负责 TLS 握手和证书管理，内部可使用 HTTP 或私有网络通信。

### 4. 限流与访问控制

可按 IP、接口、连接数限制流量，阻止异常请求。

## 为什么性能高

- 事件驱动。
- 非阻塞 I/O。
- epoll 等多路复用机制。
- 少量进程处理大量连接。

## 面试表达

Nginx 位于客户端和应用服务之间，负责反向代理、负载均衡、静态资源处理、HTTPS 终止和限流，从而提高系统的性能、可用性和安全性。
