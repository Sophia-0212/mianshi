MySQL 语法涵盖了数据定义语言（DDL）、数据操作语言（DML）、数据查询语言（DQL）、数据控制语言（DCL）等多个方面，下面为你详细介绍各部分的常见语法。

### 数据定义语言（DDL）



用于定义数据库、表、视图、索引等数据库对象。

#### 创建数据库

```SQL
CREATE DATABASE database_name;
```




示例：

```SQL
CREATE DATABASE test_db;
```


#### 删除数据库

```SQL
DROP DATABASE database_name;
```




示例：

```SQL
DROP DATABASE test_db;
```


#### 创建表

```SQL
CREATE TABLE table_name (
    column1 datatype constraint,
    column2 datatype constraint,
    ...
    PRIMARY KEY (one or more columns)
);
```




示例：

```SQL
CREATE TABLE employees (
    id INT AUTO_INCREMENT PRIMARY KEY,
    name VARCHAR(100) NOT NULL,
    age INT,
    department VARCHAR(50)
);
```


#### 修改表结构



- **添加列**

```SQL
ALTER TABLE table_name ADD column_name datatype constraint;
```




示例：

```SQL
ALTER TABLE employees ADD email VARCHAR(100);
```




- **修改列的数据类型**

```SQL
ALTER TABLE table_name MODIFY column_name new_datatype;
```




示例：

```SQL
ALTER TABLE employees MODIFY age TINYINT;
```




- **删除列**

```SQL
ALTER TABLE table_name DROP COLUMN column_name;
```




示例：

```SQL
ALTER TABLE employees DROP COLUMN email;
```


#### 删除表

```SQL
DROP TABLE table_name;
```




示例：

```SQL
DROP TABLE employees;
```


### 数据操作语言（DML）



用于对数据库中的数据进行插入、更新、删除等操作。

#### 插入数据

```SQL
INSERT INTO table_name (column1, column2, ...) VALUES (value1, value2, ...);
```




示例：

```SQL
INSERT INTO employees (name, age, department) VALUES ('John Doe', 30, 'HR');
```


#### 更新数据

```SQL
UPDATE table_name SET column1 = value1, column2 = value2, ... WHERE condition;
```




示例：

```SQL
UPDATE employees SET age = 31 WHERE name = 'John Doe';
```


#### 删除数据

```SQL
DELETE FROM table_name WHERE condition;
```




示例：

```SQL
DELETE FROM employees WHERE name = 'John Doe';
```


### 数据查询语言（DQL）



用于从数据库中查询数据。

#### 简单查询

```SQL
SELECT column1, column2, ... FROM table_name;
```




示例：

```SQL
SELECT name, age FROM employees;
```


#### 查询所有列

```SQL
SELECT * FROM table_name;
```




示例：

```SQL
SELECT * FROM employees;
```


#### 条件查询

```SQL
SELECT column1, column2, ... FROM table_name WHERE condition;
```




示例：

```SQL
SELECT name, age FROM employees WHERE age > 25;
```


#### 排序查询

```SQL
SELECT column1, column2, ... FROM table_name ORDER BY column_name [ASC|DESC];
```




示例：

```SQL
SELECT name, age FROM employees ORDER BY age DESC;
```


#### 分组查询

```SQL
SELECT column1, aggregate_function(column2) FROM table_name GROUP BY column1;
```




示例：

```SQL
SELECT department, COUNT(*) FROM employees GROUP BY department;
```


#### 连接查询

```SQL
SELECT table1.column1, table2.column2, ...
FROM table1
JOIN table2 ON table1.common_column = table2.common_column;
```




示例（内连接）：

```SQL
SELECT employees.name, departments.department_name
FROM employees
JOIN departments ON employees.department_id = departments.id;
```


### 数据控制语言（DCL）

用于管理用户对数据库对象的访问权限。

#### 创建用户

```SQL
CREATE USER 'username'@'host' IDENTIFIED BY 'password';
```




示例：

```SQL
CREATE USER 'new_user'@'localhost' IDENTIFIED BY 'password123';
```


#### 授予权限

```SQL
GRANT privilege_type ON database_name.table_name TO 'username'@'host';
```




示例：

```SQL
GRANT SELECT, INSERT ON test_db.employees TO 'new_user'@'localhost';
```


#### 撤销权限

```SQL
REVOKE privilege_type ON database_name.table_name FROM 'username'@'host';
```




示例：

```SQL
REVOKE INSERT ON test_db.employees FROM 'new_user'@'localhost';
```


#### 删除用户

```SQL
DROP USER 'username'@'host';
```




示例：

```SQL
DROP USER 'new_user'@'localhost';
```


### 事务处理

用于确保一组数据库操作的原子性。

#### 开始事务

```SQL
START TRANSACTION;
```


#### 提交事务

```SQL
COMMIT;
```


#### 回滚事务

```SQL
ROLLBACK;
```


示例：

```JavaScript
START TRANSACTION;
UPDATE accounts SET balance = balance - 100 WHERE account_id = 1;
UPDATE accounts SET balance = balance + 100 WHERE account_id = 2;
IF (/* 检查是否满足某些条件 */) THEN
    COMMIT;
ELSE
    ROLLBACK;
END IF;
```
