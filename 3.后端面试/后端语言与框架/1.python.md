# Python 高频 Top 10 面试题

## 1. Python 有哪些主要数据类型？

常见类型：`int`、`float`、`bool`、`str`、`list`、`tuple`、`dict`、`set`、`NoneType`。

按可变性分：

- **可变**：`list`、`dict`、`set`。
- **不可变**：`int`、`float`、`bool`、`str`、`tuple`。

## 2. `list` 和 `tuple` 有什么区别？

- `list` 可修改，`tuple` 不可修改。
- `list` 适合动态数据，`tuple` 适合固定数据。
- `tuple` 可作为字典 Key，前提是元素都可哈希。
- `tuple` 通常更节省内存，访问略快。

## 3. `==` 和 `is` 有什么区别？

- `==`：比较值是否相等。
- `is`：比较是否为同一个对象。

```python
a = [1, 2]
b = [1, 2]

a == b  # True
a is b  # False
```

判断空值应使用：

```python
if value is None:
    pass
```

## 4. 什么是浅拷贝和深拷贝？

- **浅拷贝**：只复制外层对象，嵌套对象仍共享。
- **深拷贝**：递归复制所有层级对象。

```python
import copy

b = copy.copy(a)      # 浅拷贝
c = copy.deepcopy(a)  # 深拷贝
```

嵌套列表、字典等场景要注意引用共享。

## 5. Python 的可变默认参数有什么问题？

默认参数只在函数定义时创建一次，多次调用会共享同一个对象：

```python
def add_item(item, items=[]):
    items.append(item)
    return items
```

正确写法：

```python
def add_item(item, items=None):
    if items is None:
        items = []
    items.append(item)
    return items
```

## 6. 什么是装饰器？如何实现？

装饰器接收一个函数，返回增强后的函数，常用于日志、鉴权、计时和重试。

```python
from functools import wraps

def log_call(func):
    @wraps(func)
    def wrapper(*args, **kwargs):
        print("开始执行")
        result = func(*args, **kwargs)
        print("执行结束")
        return result
    return wrapper
```

```python
@log_call
def query():
    pass
```

`@log_call` 等价于：

```python
query = log_call(query)
```

## 7. 生成器是什么？`yield` 有什么作用？

生成器按需产生数据，不一次性加载全部结果，适合大文件和大数据。

```python
def numbers():
    for i in range(3):
        yield i
```

特点：

- 惰性求值，节省内存。
- 每次调用 `next()` 执行到下一个 `yield`。
- 生成器只能顺序消费。

## 8. 什么是 GIL？多线程适合什么场景？

GIL（全局解释器锁）保证同一时刻只有一个线程执行 Python 字节码。

- **I/O 密集型**：适合多线程，例如网络请求、文件读写。
- **CPU 密集型**：优先多进程、C 扩展或其他计算方案。
- **大量 I/O 协程**：适合 `asyncio`。

GIL 不代表所有操作都线程安全，共享数据仍需同步控制。

## 9. `asyncio`、多线程、多进程有什么区别？

| 方式 | 适合场景 | 特点 |
|---|---|---|
| `asyncio` | 大量 I/O | 单线程协程，切换开销小 |
| 多线程 | I/O、阻塞库 | 共享进程内存，受 GIL 影响 |
| 多进程 | CPU 密集型 | 独立解释器，可利用多核 |

选择依据：任务类型，以及第三方库是否支持异步。

## 10. Python 如何处理异常和资源释放？

使用 `try-except-else-finally`：

```python
try:
    result = query()
except TimeoutError:
    retry()
except Exception as e:
    log_error(e)
else:
    process(result)
finally:
    close_resource()
```

资源管理优先使用 `with`：

```python
with open("data.txt", encoding="utf-8") as file:
    content = file.read()
```

`with` 依赖上下文管理器的 `__enter__` 和 `__exit__`，即使发生异常也能释放资源。

### Python 装饰器主要分为内置、标准库、框架和自定义四类。

| 来源 | 常见装饰器 | 作用 |
| --- | --- | --- |
| 内置 | `@property` | 将方法作为属性读取 |
|  | `@属性名.setter` | 定义属性赋值逻辑 |
|  | `@staticmethod` | 定义静态方法，不自动传入 self 或 cls |
|  | `@classmethod` | 定义类方法，自动传入 cls |
| 标准库 | `@functools.lru_cache` | 缓存函数结果，限制缓存数量 |
|  | `@functools.wraps` | 编写装饰器时，保留原函数名称、文档等信息 |
|  | `@dataclasses.dataclass` | 为类生成初始化、比较等方法 |
|  | `@abc.abstractmethod` | 声明抽象方法，配合抽象基类使用 |
|  | `@contextlib.contextmanager` | 将生成器函数转换成上下文管理器 |
| 框架 | Flask 的 `@app.route(...)` | 注册 HTTP 路由 |
|  | FastAPI 的 `@app.get(...)`、`@app.post(...)` | 注册接口 |
|  | pytest 的 `@pytest.fixture` | 定义测试依赖和准备、清理逻辑 |

## 中间件：

**中间件是为业务系统提供通用能力的软件，解决通信、缓存、消息、流量分发等问题。**

常见类型包括：

| 类型 | 代表组件 | 解决的问题 |
| --- | --- | --- |
| 缓存 | Redis | 减少数据库访问、缓存热点数据、实现分布式锁 |
| 消息队列 | Kafka、RabbitMQ、RocketMQ | 异步处理、系统解耦、削峰填谷 |
| 网关与代理 | Nginx、API 网关 | 请求路由、负载均衡、鉴权、限流 |
| 配置中心 | Nacos、Apollo | 集中管理和分发配置 |
| 注册中心 | ZooKeeper、Nacos | 服务注册与发现 |
